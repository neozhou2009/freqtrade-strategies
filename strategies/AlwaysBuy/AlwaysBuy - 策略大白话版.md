# AlwaysBuy 策略：量化界的"盲盒玩家"

> **外号**：无脑买入机器、测试专用工具人  
> **职业**：框架测试员 / 基准对照组  
> **时间框架**：5 分钟 (5m)

---

## 一、这策略是个啥？

简单说，**AlwaysBuy** 就是一个：
- 没有任何技术分析的"策略"
- 见到 K 线就买入的"盲盒玩家"
- 专门用来测试框架的工具

就像你闭着眼睛往股市里扔钱，扔到哪儿算哪儿 🎲

**一句话总结**：这不是交易策略，这是一个测试工具！

---

## 二、核心配置：说白了就是"买了就等"

### 止盈规则（ROI 表）

```
0 分钟后：利润 ≥ 100% 才卖出
100 分钟后：利润 ≥ 200% 才卖出
200 分钟后：利润 ≥ 300% 才卖出
300 分钟后：不卖了，等止损
```

**翻译**：这些止盈线高得离谱，基本等于"不主动止盈"。谁家策略指望翻倍才卖？这就是测试配置 🤣

### 止损规则

```
固定止损：亏 20% 才认输
追踪止损：利润到 3% 后，回调 0.5% 就跑
```

**翻译**：
- 固定止损 20%，这宽度能塞下一辆卡车
- 追踪止损还算正常，但问题是——你为啥要用追踪止损保护一个"盲买"策略？

## 三、1 个买入条件：我帮你翻译成"人话"

这策略的买入条件简单到让人怀疑人生：

### 🎯 第 1 类：无条件买入（1 个条件）

**代码逻辑**：
```python
dataframe.loc[:, ["enter_long", "enter_tag"]] = (1, "entry_reason")
```

**大白话**：

- 被 `max_open_trades` 限制才会停下来

**吐槽**：这策略的核心思想是——"我不看行情，我就买"。量化版的"闭眼投资法" 😂

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

AlwaysBuy 在回测中可能看起来"还行"（如果你选了一个涨势不错的交易对），但这纯属运气：
> **它没有交易逻辑，买什么都靠运气。回测选错币种，你看到的可能是亏损。**

### 无脑买入的隐藏风险

实盘时，这个策略会导致：
- **手续费消耗**：频繁买入卖出，手续费累积惊人
- **滑点损失**：市价单的滑点会进一步侵蚀收益
- **无风险管理**：连续亏损时没有任何保护机制

```
1. 只用 dry_run 模式测试
2. 不要投入任何真实资金
3. 用它验证框架后，换一个真正的策略
4. 如果你不知道什么是"真正的策略"，先学习基础知识
```

**记住**：这个策略的作用是测试框架，不是赚钱。用它来学习，用它来测试，但别用它来亏钱！

# CrossEMAStrategy 策略：双均线交叉的"极简主义"

> **外号**：量化界小学生 / 最简洁的趋势跟踪  
> **职业**：用两根 EMA 线 + 一个随机 RSI 混江湖  
> **时间框架**：1 小时

---

## 一、这策略是个啥？

简单说，**CrossEMAStrategy** 就是一个：
- 只有 **2 个指标** 的策略（ EMA28 + EMA48 + 随机 RSI ）
- 只有 **1 个买入条件** 的策略
- 只有 **1 个卖出条件** 的策略
- 代码量 **不到 100 行** 的策略

就像一个只用"看面相"就决定买不买的相亲对象——简单粗暴，但有时候还挺准！😅

## 二、核心配置：说白了就是"快进快出"

### 止盈规则（ROI 表）

```
0-30 分钟：赚 10% 就跑！
30-60 分钟：赚 5% 就跑！
60 分钟以后：赚 2% 就跑！
```

**翻译**：这策略很贪心，开盘就想赚 10%！但它也认命——随着时间推移，目标越来越低，毕竟"见好就收"嘛 😅

### 止损规则

```
硬止损：亏 99%（基本上等于没设置）
追踪止损：有！从盈利开始就跟踪
```

**翻译**：官方说"亏 99% 就割肉"，但实际上亏 99% 之前早就由追踪止损接管了。简单说就是——别让我亏太多，不然我撒腿就跑！🏃‍♂️

## 三、买入条件：就 1 个，简单到哭

### 核心逻辑（三重过滤）

```python
# 必须同时满足 3 个条件：
1. EMA28 > EMA48  # 短期均线在长期均线上方（金叉）
2. 随机RSI < 0.8  # 价格处于超卖区域，别追高
3. 成交量 > 0    # 确认真实交易，不是假信号
```

**大白话翻译**：

1. **"趋势向上了"**：短期均线穿越长期均线，说明行情开始启动
2. **"价格不算太贵"**：随机 RSI 低于 0.8，说明价格还没涨太高
3. **"这笔交易真实"**：有成交量支撑，不是庄家画的假突破

**经典台词**：
> "短期均线超过长期均线了，而且价格还没涨太贵，买点筹码试试！" 👍

3. **"这笔交易真实"**：有成交量确认，不是假突破

**经典台词**：

## 五、技术指标：就 3 个，数都数得过来

### 指标列表

| 指标 | 用途 | 大白话 |
|------|------|--------|
| **EMA28** | 28 周期指数移动平均 | 短期均线，反应灵敏 |
| **EMA48** | 48 周期指数移动平均 | 长期均线，过滤噪音 |
| **随机 RSI** | 动量指标 | 判断价格是"超买"还是"超卖" |

### EMA 交叉的原理

```
金叉（买入信号）：EMA28 从下方穿越 EMA48
  → 短期上涨趋势形成 → 买！

死叉（卖出信号）：EMA28 从上方穿越 EMA48
  → 短期下跌趋势形成 → 卖！
```

**比喻**：就像观察马拉松选手：
- **EMA28** 是**当前领先者**的位置（短期表现）
- **EMA48** 是**主力集团**的位置（长期趋势）
- 当领先者超过主力集团 → 行情要加速！
- 当领先者被主力集团追上 → 行情要减速！

### 随机 RSI 是什么？

```
随机 RSI = 把 RSI 值再做一次"随机化"处理
- 值 < 0.2：超卖区域，可能要反弹
- 值 > 0.8：超买区域，可能要回调
- 值在中间：观望
```

**大白话**：简单理解就是——随机 RSI 就是给 RSI 开了个"美颜"，让超买超卖信号更灵敏！

3. **单时间框架**：只用 1 小时，没有多周期确认
4. **可能踏空**：随机 RSI 阈值太高可能错过行情

## 十一、风险提醒：简单策略的隐藏坑

### 11.1 无独立保护机制

这策略没有：
- ❌ 资金保护参数
- ❌ 波动率保护
- ❌ 独立的最大持仓时间

**风险**：极端行情可能遭受较大亏损！

### 11.2 硬止损形同虚设

```python
stoploss = -0.99  # 亏 99% 才止损
```

这相当于没说！实际风险控制完全依赖追踪止损。

**建议**：如果担心极端行情，可手动设置更严格的止损，例如 -15%

### 11.3 单时间框架的局限

只用 1 小时周期，可能：
- 错过更大周期的趋势
- 被短期噪音干扰

**建议**：如果有条件，可以用更长周期作为参考

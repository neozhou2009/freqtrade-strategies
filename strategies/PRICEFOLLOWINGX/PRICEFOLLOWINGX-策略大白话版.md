# PRICEFOLLOWINGX 策略：一个"带保镖"的趋势跟踪者

## 一、这策略是个啥？

简单说，**PRICEFOLLOWINGX** 就是一个：
- 用 **7 种不同指标** 的策略（Fisher RSI、TEMA、布林带、EMA、Heikin Ashi 等）
- 带 **3 个保护机制** 的策略（最大回撤、止损保护、低利润保护）
- 会看 **订单簿** 的策略

就像一个出门要带 3 个保镖的富豪："交易可以亏，但不能连续亏！一个保镖管回撤，一个保镖管止损，一个保镖管低利润！" 💂

## 二、核心配置：说白了就是"保护优先"

### 止盈规则（ROI 表）

```
刚买入就赚 1.5%？→ 跑！
拿了 30 分钟赚 3%？→ 跑！（最高收益）
拿了 60 分钟赚 2.5%？→ 跑！
拿了 120 分钟赚 1.5%？→ 跑！
```

**翻译**：这策略收益预期不高，3% 就满足了，典型的"稳健思维"😅

### 止损规则

```
硬止损：亏 10% 直接割
追踪止损：赚 3% 后启动，回撤 2% 就跑
```

**翻译**：追踪止损是这策略的亮点，赚了钱后会自动跟着价格走！

### 3 个保镖（保护机制）

**保镖 1：最大回撤保护**
```
48 根 K 线内（12 小时）最多 5 笔交易
最大允许回撤 75%
触发后暂停 5 根 K 线（75 分钟）
```
**大白话**："12 小时内亏了 75%？别玩了，休息 75 分钟冷静一下！"

**保镖 2：止损保护**
```
24 根 K 线内（6 小时）最多 3 笔止损
每交易对独立计算
触发后暂停 5 根 K 线
```
**大白话**："6 小时内被止损 3 次？这个交易对先暂停，别跟它较劲！"

**保镖 3：低利润保护**
```
30 根 K 线内（7.5 小时）最多 2 笔低利润交易
利润低于 0.5% 视为低利润
触发后暂停 6 根 K 线
```
**大白话**："7.5 小时内赚了 2 笔小钱（低于 0.5%）？这交易对没油水，换个玩玩！"

**吐槽**：这策略的保护机制是真的豪华，3 个保镖 24 小时保护！🤣

## 三、买入条件：要同时满足 3 个条件

这策略的买入条件分两种模式：

### 🎯 模式 1：RSI 启用（超卖买入）

**核心逻辑**：
1. Fisher RSI 下穿阈值
2. TEMA < 布林带下轨
3. TEMA 下穿 EMA 低点

**大白话**：
> "Fisher RSI 都超卖了，价格跌破布林带下轨了，TEMA 也确认了——这还不买？"

### 🎯 模式 2：RSI 禁用（趋势买入）

**核心逻辑**：
1. TEMA > 布林带中轨
2. TEMA 上穿 EMA7

**大白话**：
> "TEMA 站上布林带中轨了，而且上穿 EMA7 了——趋势来了，上车！"

**吐槽**：这策略是真的"讲究"，买入还有两种模式可选！🤣

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **保护机制完善**：3 个保镖防止连续亏损
2. **多指标确认**：Fisher RSI + TEMA + 布林带多维度确认

4. **订单簿数据**：实时买卖价优化订单执行
5. **超参数优化**：可以自动找最佳参数

### ⚠️ 缺点（吐槽环节）

1. **复杂度高**：7 个指标 + 3 个保护，调试起来头疼
2. **订单簿依赖**：需要交易所支持 orderbook API
3. **参数敏感**：优化出来的参数可能过拟合
4. **15 分钟框架**：信号频率比 5 分钟低
5. **计算量大**：多指标 + 保护机制增加计算负担

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

PRICEFOLLOWINGX 的历史回测表现可能**非常优异**——但这有个陷阱：

> **多指标 + 超参数优化的策略更容易"拟合"出漂亮的回测曲线，因为参数组合多，可能刚好"背对"了那段历史行情。**

简单说就是：**回测数据好看，可能是因为它刚好"记住"了那段行情怎么走。**

### 复杂策略的隐藏风险

实盘时，复杂的逻辑可能导致：
- **信号过少**：15m 框架 + 多条件确认，可能很久没信号
- **保护机制频繁触发**：市场不好时可能频繁暂停
- **过拟合风险**：超参数优化结果可能过拟合

1. 先用最小资金量（如 100U）测试

## 一、策略概览

**ClucFiatROI** 是一个基于布林带和 Fisher RSI 的组合策略，融合了 Cluc 系列策略的经典逻辑。策略特色是使用了双重布林带系统（40 周期和 20 周期），并引入了订单簿（orderbook）检查机制来优化订单执行。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 2 种模式（BinHV45 变体 + Cluc 变体） |
| **卖出条件** | 多条件组合（布林带中轨 + EMA + Fisher RSI） |
| **保护机制** | 追踪止损 + 订单超时检查 |
| **时间框架** | 5 分钟 |
| **依赖库** | TA-Lib, technical, numpy |
| **特殊功能** | 订单簿检查、订单超时取消、双重布林带 |

## 三、买入条件详解

### 3.1 买入逻辑（无持仓时）

```python
# 无持仓时的买入条件（两种模式）
conditions = [
    # 模式 1：BinHV45 变体
    (
        (bb1_delta > close * bbdelta_close) &
        (closedelta > close * closedelta_close) &
        (tail < bb1_delta * bbdelta_tail) &
        (close < lower_bb1.shift()) &
        (close <= close.shift())
    )
    |
    # 模式 2：Cluc 变体
    (
        (close < ema_slow) &
        (close < close_bblower * lower_bb2) &
        (volume < volume_mean_slow.shift(1) * volume)
    )
]

# Fisher RSI 过滤
conditions.append(fisher_rsi < fisher)
```

**逻辑解析**：
- **模式 1（BinHV45 变体）**：
  - 布林带带宽 > 0.642%
  - 价格变化 > 0.883%
  - 下影线 < 带宽的 75.559%
  - 价格 < 前一根布林带下轨
  - 价格不高于前一根收盘价
- **模式 2（Cluc 变体）**：
  - 价格 < EMA48
  - 价格 < 布林带下轨×0.98585
  - 成交量 < 均量×18
- **Fisher RSI 过滤**：Fisher RSI < -0.97101（深度超卖）

## 四、卖出逻辑详解

### 4.1 卖出条件

```python
# 卖出条件
(
    (close * sell_bbmiddle_close) > mid_bb2 &    # 价格×0.95153 > 布林带中轨
    ema_fast > close &                            # EMA6 > 价格
    fisher_rsi > sell_fisher &                    # Fisher RSI > 0.60924
    volume > 0                                     # 成交量 > 0
)
```

**逻辑解析**：
- **价格接近中轨**：价格×0.95153 > 布林带中轨（价格接近中轨）
- **EMA 确认**：EMA6 在价格上方（短期趋势转弱）
- **Fisher RSI 超买**：Fisher RSI > 0.60924
- **成交量确认**：成交量大于 0

**综合含义**：价格回归布林带中轨附近，短期趋势转弱，Fisher RSI 超买时退出。

### 4.2 订单超时检查

```python
# 买入订单超时检查
def check_entry_timeout(self, pair, trade, order, **kwargs) -> bool:
    ob = self.dp.orderbook(pair, 1)
    current_price = ob["bids"][0][0]
    if current_price > order["price"] * 1.01:  # 价格上涨超过 1%
        return True  # 取消订单
    return False

# 卖出订单超时检查
def check_exit_timeout(self, pair, trade, order, **kwargs) -> bool:
    ob = self.dp.orderbook(pair, 1)
    current_price = ob["asks"][0][0]
    if current_price < order["price"] * 0.99:  # 价格下跌超过 1%
        return True  # 取消订单
    return False
```

**作用**：
- 防止订单因价格变动而无法成交
- 超过 1% 价格偏离时取消订单

## 七、策略优势与局限

### ✅ 优势

1. **双重布林带**：40 周期 + 20 周期，覆盖不同时间维度
2. **Fisher RSI**：归一化 RSI 更敏感
3. **订单簿检查**：使用实时订单簿优化订单执行
4. **订单超时**：防止订单因价格变动无法成交
5. **超参数优化**：关键参数来自超参数优化

### ⚠️ 局限

1. **复杂度高**：双重布林带 + 多指标，调试困难
2. **订单簿依赖**：需要交易所支持 orderbook API
3. **参数敏感**：超参数优化结果可能过拟合
4. **极宽松止损**：-34.299% 止损在极端行情下可能造成较大亏损
5. **计算量大**：双重布林带增加计算负担

# NostalgiaForInfinityNext_maximizer 策略大白话版

## 一、这个策略是干啥的？

想象你是一个炒股炒币的老手，但是你不想每天盯盘，想找一个靠谱的机器人帮你自动交易。NostalgiaForInfinityNext_maximizer 就是这样一款"智能交易助手"。

简单说，这个策略会：
1. 帮你盯着市场，寻找好的买入时机
2. 买入后帮你管理仓位，决定什么时候卖出
3. 尽量在赚钱的时候卖，亏钱的时候及时止损

## 二、这个策略有多"聪明"？

这个策略就像一个经验丰富的交易员，它不会盲目地买卖，而是会看很多"信号"：

### 看趋势
- 价格是在涨还是在跌？涨到什么程度了？
- 大趋势是向上还是向下？

### 看动能
- 现在买的人多还是卖的人多？
- 价格涨得快不快？是不是涨过头了？

### 看成交量
- 成交量大不大？
- 是有人在大量买入还是卖出？

### 看市场整体
- 比特币（市场老大）表现怎么样？
- 整个市场是恐慌还是贪婪？

## 三、什么时候会买入？

策略准备了 **43 种不同的买入方案**，就像一个工具箱里有 43 把不同的钥匙，针对不同的市场情况。

### 买入原则一：不追高

假设一个币从 100 块涨到了 150 块，策略不会在 150 块追进去。它会等价格回调到比如 130 块，而且出现"跌不动了"的信号时才考虑买入。

### 买入原则二：不抄底抄在半山腰

假设一个币从 100 块跌到了 80 块，策略不会马上买。它会继续观察：
- 跌的速度有没有放慢？
- 有没有出现反弹迹象？
- 成交量有没有异常？

只有当这些条件都满足了，才会考虑买入。

### 买入原则三：跟着大趋势走

如果比特币在涨，而且你关注的币也在涨，这时候买入成功率更高。策略会检查：
- 比特币是不是在涨？
- 这个币是不是处于上升趋势？

## 四、买入的几种常见情况

### 情况一：上升趋势中的回调

举个例子：
- 某币从 100 涨到 120，然后回调到 110
- 这时候如果 RSI（相对强弱指标）显示"短期超卖"
- 成交量也不大（说明不是大资金在抛售）
- 策略可能会买入

**大白话**：就像你在排队买奶茶，队伍太长了你不想排，但如果有几个人走了，队伍变短了，这时候去排队最划算。

### 情况二：布林带下轨买入

布林带就像一个"价格通道"，中间是平均价格，上下是波动范围。

当价格跌到布林带下轨附近：
- 说明价格跌得比较多了
- 如果成交量也不大
- 可能是被"错杀"了
- 策略会考虑买入

**大白话**：就像超市打折，平时卖 10 块的东西现在卖 8 块，而且没人抢，这时候买划算。

### 情况三：技术指标超卖

当多个指标都显示"超卖"：
- RSI 很低（比如低于 30）
- CTI（商品通道指数）接近 -1
- Williams %R 接近 -100

这时候价格可能跌过头了，反弹的概率较大。

**大白话**：就像皮球被按到水底，按得越深，弹起来的力量越大。

### 情况四：趋势突破

使用 Ichimoku（一目均衡表）等复杂指标：
- 当价格突破"云"的上沿
- 而且多条线都呈现多头排列
- 这时候策略会跟随趋势买入

**大白话**：就像开车看到前方绿灯亮了，而且前面的车都在加速，这时候跟着走是对的。

## 五、什么时候会卖出？

卖出比买入更重要！策略有 **20 多种卖出逻辑**，确保利润落袋为安。

### 卖出原则一：赚钱就跑

根据盈利多少，设置不同的卖出条件：

**赚了 1%-2%**：
- 如果 RSI 比较低（说明还没完全涨起来）
- 而且 CMF 为负（资金在流出）
- 就先卖掉锁定利润

**赚了 5%-10%**：
- RSI 要更低才卖
- 或者开始出现下跌信号

**赚了超过 20%**：
- 只要 RSI 不太高就可以卖
- 毕竟利润已经很可观了

**大白话**：就像你买彩票中了奖，小奖就赶紧兑现，别贪心。

### 卖出原则二：趋势变了就跑

当出现以下信号，说明趋势可能反转：
- RSI 超过 80（超买了）
- 价格连续好几天在布林带上轨之上
- EMA 死叉（短期均线跌破长期均线）

这时候不管赚没赚，策略都会考虑卖出。

**大白话**：就像你发现前面的路变窄了，还有点下坡，聪明人就会停下来。

### 卖出原则三：追涨后快速获利

对于一些"快速买入"的条件（条件 32-38），策略会采用"快进快出"的方式：

- 盈利 2%-6% 且 RSI > 80：马上卖
- 或者价格跌破某个 ATR 阈值：赶紧跑

**大白话**：就像你抢购限量商品，买到后转手就卖，赚个差价就跑。

### 卖出原则四：止损保护

如果买入后价格一直跌：
- 跌了 8%-12%：开始用 ATR 动态止损
- 跌了 12%-16%：收紧止损
- 跌了 16%-20%：更紧的止损
- 跌超过 20%：差不多该认输了

**大白话**：就像你打牌输了 100 块，再输下去就收不住了，不如及时止损。

## 六、什么情况不买？

### 不买情况一：刚大涨过（Pump 保护）

如果一个币在 24 小时内涨了超过 60%，策略不会追：
- 因为大涨后通常会回调
- 追进去容易被套

### 不买情况二：还在暴跌（Safe Dips）

如果一个币还在暴跌：
- 策略会等跌势放缓
- 等出现企稳信号
- 不会盲目抄底

### 不买情况三：比特币在跌（BTC 保护）

如果市场老大比特币在跌：
- 说明整个市场情绪不好
- 这时候买其他币风险更大
- 策略会选择观望

### 不买情况四：技术指标不好

- RSI 太高（超过 84）：已经涨过头了
- 成交量异常放大：可能有大资金在出货
- EMA 没有金叉：趋势还没确立

## 七、这个策略的"武器库"

### 趋势判断工具

**移动平均线（EMA/SMA）**
- 就像价格的平均成本线
- 价格在均线上方 = 上升趋势
- 价格在均线下方 = 下降趋势
- 短期均线上穿长期均线 = 金叉（看涨信号）

**一目均衡表（Ichimoku）**
- 日本人发明的复杂指标
- 可以判断趋势方向、支撑阻力、买卖信号
- 当价格在"云"之上 = 多头市场

**MODERI**
- 策略特有的趋势指标
- 判断长期、中期、短期趋势方向

### 超买超卖工具

**RSI（相对强弱指标）**
- 范围 0-100
- 高于 70 = 超买（可能要跌）
- 低于 30 = 超卖（可能要涨）

**布林带**
- 上轨、中轨、下轨
- 价格接近上轨 = 可能超买
- 价格接近下轨 = 可能超卖

**Williams %R**
- 类似 RSI，但更敏感
- 范围 -100 到 0
- 接近 0 = 超买
- 接近 -100 = 超卖

### 成交量工具

**CMF（Chaikin 资金流量）**
- 大于 0 = 资金流入
- 小于 0 = 资金流出

**MFI（资金流量指数）**
- 结合价格和成交量
- 高于 80 = 超买
- 低于 20 = 超卖

### 高级工具

**PMAX（Profit Maximizer）**
- 类似 Supertrend
- 用于判断趋势方向和止损位

**Kalman Filter**
- 卡尔曼滤波器
- 比普通均线更精准的价格预测

**ZLEMA**
- 零滞后移动平均线
- 比普通 EMA 响应更快

## 八、策略怎么赚钱？

### 赚钱方式一：趋势跟踪

在上升趋势中：
- 找回调点买入
- 等趋势继续
- 赚取趋势延续的利润

### 赚钱方式二：超卖反弹

在价格超卖时：
- 等价格跌过头
- 买入等待反弹
- 赚取反弹利润

### 赚钱方式三：波动率交易

利用布林带等指标：
- 价格触及下轨时买入
- 价格回到中轨或上轨时卖出
- 赚取波动利润

## 附录一：指标通俗解释

### RSI —— 价格"累不累"的指标

**什么是 RSI？**
RSI 就像是给价格"测体温"。如果价格涨得太快太多，RSI 就会变高，表示"累了"；如果价格跌得太厉害，RSI 就会变低，表示"冷了"。

**具体数值含义**：
- RSI > 70：价格涨太多了，可能要休息（回调）
- RSI < 30：价格跌太多了，可能要反弹

**举例**：
某币 RSI 达到 85，说明短期内买的人太多太疯狂，这时候追高很容易被套。反之，RSI 跌到 20，说明卖的人都卖完了，可能要涨了。

### 布林带 —— 价格的"安全范围"

**什么是布林带？**
布林带由三条线组成：上轨、中轨、下轨。中轨是平均价格，上下轨是波动的范围。就像给价格画了一个"活动区域"。

**怎么用？**
- 价格碰到上轨：可能涨过头了，要小心
- 价格碰到下轨：可能跌过头了，有机会反弹
- 布林带收窄：价格可能要大变动（暴风雨前的宁静）

**举例**：
价格一直在布林带中轨附近波动，突然突破上轨，这时候追高风险大。如果跌破下轨且开始反弹，可能是个买入机会。

### MACD —— 趋势的"方向盘"

**什么是 MACD？**
MACD 由两条线组成：快线（DIF）和慢线（DEA）。当快线从下往上穿过慢线，叫"金叉"，是买入信号；反之叫"死叉"，是卖出信号。

**怎么用？**
- 金叉 + 价格在上涨趋势：买入信号强
- 死叉 + 价格在下跌趋势：卖出信号强
- 柱状图变长：趋势在加强

**举例**：
快线刚刚金叉慢线，而且两条线都在往上走，这时候买进去，跟着趋势走，胜率较高。

### EMA/SMA —— 价格的"平均成本"

**什么是 EMA/SMA？**
移动平均线就是把过去一段时间的价格平均一下，画成一条线。EMA 是指数移动平均，对最近的价格更敏感；SMA 是简单平均，比较平滑。

**怎么用？**
- 价格在均线上方：多头市场，偏买入
- 价格在均线下方：空头市场，偏观望
- 短期均线金叉长期均线：买入信号
- 短期均线死叉长期均线：卖出信号

**举例**：
EMA12 上穿 EMA26，形成金叉，说明短期动能开始变强，可以考虑买入。

### Ichimoku（一目均衡表）—— 日本人的"全能工具"

**什么是一目均衡表？**
这是一个非常复杂但全面的指标，包含五条线和一个"云"区域。可以判断趋势、支撑阻力、买卖信号。

**怎么用？**
- 价格在云之上：多头市场
- 价格在云之下：空头市场
- 转换线上穿基准线：买入信号
- 延迟线在价格之上：趋势确认

**举例**：
价格从云的下方突破到上方，同时转换线金叉基准线，这是一个很强的买入信号，说明趋势从下跌转为上涨。

### Williams %R —— "恐惧与贪婪"指标

**什么是 Williams %R？**
这个指标告诉你当前价格在过去一段时间内的位置。范围是 -100 到 0。

**怎么用？**
- 接近 0：价格处于近期最高点附近，可能超买
- 接近 -100：价格处于近期最低点附近，可能超卖

**举例**：
Williams %R 达到 -98，说明价格在近期最低点附近，可能是抄底的好时机。但要注意，超卖之后可能还会更超卖，要结合其他指标。

### CMF（Chaikin 资金流量）—— "聪明钱"在干什么

**什么是 CMF？**
CMF 通过分析价格位置和成交量，判断资金是在流入还是流出。

**怎么用？**
- CMF > 0：资金在流入，买方力量强
- CMF < 0：资金在流出，卖方力量强

**举例**：
价格在涨，但 CMF 开始转负，说明"聪明钱"在卖出，散户在追高，这时候要小心，可能快见顶了。

### ATR（平均真实波幅）—— 波动有多大

**什么是 ATR？**
ATR 衡量价格的波动程度。数值越大，波动越剧烈。

**怎么用？**
- ATR 很大：市场波动大，止损要设宽一点
- ATR 很小：市场平静，可能要有大行情

**举例**：
平时 ATR 是 100，突然涨到 300，说明市场变得很疯狂，这时候交易要格外小心，止损位要设远一点，不然容易被洗出去。

## 附录二：常见交易场景模拟

### 场景一：牛市回调买入

**市场情况**：
- 比特币从 50000 涨到 60000，现在回调到 56000
- 某山寨币从 100 涨到 120，现在回调到 108
- RSI14 从 70 降到 35

**策略判断**：
1. 检查 EMA100_1h > EMA200_1h：是，说明中期趋势向上 ✓
2. 检查 SMA200 是否上升：是，长期趋势向上 ✓
3. 检查 RSI14 < 36：是，短期超卖 ✓
4. 检查 Safe Dips：价格没有暴跌，可以买 ✓
5. 检查 BTC 趋势：BTC 不在下跌趋势 ✓

**结果**：满足买入条件 1，策略会买入。

**后续卖出**：
- 假设买入后涨到 115（盈利约 6.5%）
- 此时 RSI14 = 45，CMF < 0
- 满足"盈利 6%-7%，RSI < 48，CMF < 0"的卖出条件
- 策略卖出，获利约 6.5%

### 场景二：熊市抄底失败

**市场情况**：
- 比特币从 60000 跌到 45000，还在跌
- 某币从 100 跌到 70，RSI14 = 25

**策略判断**：
1. 检查 BTC 是否下跌趋势：是，BTC 在跌 ✗
2. 满足 BTC_not_downtrend 的买入条件会跳过

## 附录四：策略优缺点总结

### 优点

1. **覆盖面广**
   - 43 个买入条件，各种市场情况都有应对
   - 20+ 种卖出逻辑，确保利润锁定

2. **风控完善**
   - Safe Dips 防止追跌
   - Safe Pump 防止追高
   - BTC 保护避免在市场下跌时入场

3. **可定制性强**
   - 每个条件都可以开关
   - 参数可以调整
   - 适合不同风格的交易者

4. **适应性好**
   - 牛市、熊市、震荡市都能运行
   - 不同市场环境有不同的买入条件

### 缺点

1. **复杂度高**
   - 新手可能看不懂
   - 参数太多，调优困难

2. **计算量大**
   - 大量指标计算
   - 需要较好的硬件支持

3. **可能过拟合**
   - 历史表现好不代表未来好
   - 需要持续监控和调整

4. **不是万能的**
   - 极端行情下可能失效
   - 需要合理管理预期

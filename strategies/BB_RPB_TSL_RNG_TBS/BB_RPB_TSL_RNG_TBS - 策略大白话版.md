# BB_RPB_TSL_RNG_TBS 策略：双面追踪大师

> **外号**：双面追踪大师  
> **职业**：买前追踪价格 + 买后追踪止损  
> **时间框架**：5分钟

---

## 一、这策略是个啥？

简单说，**BB_RPB_TSL_RNG_TBS** 就是 BB_RPB_TSL_RNG_2 的"Plus版"：
- 基础版的所有功能都有
- 加了个"追踪买入"功能——买入信号出现后不急着买，等价格再跌一点再买

就像你在超市看中一件商品，打折了但你觉得"还能再便宜点"，就等着。等价格反弹一点的时候，果断出手！

**TBS = Trailing Buy Strategy（追踪买入策略）**

---

## 二、和基础版有什么区别？

| 特性 | 基础版(RNG_2) | TBS版(RNG_TBS) |
|------|-------------|---------------|
| 追踪买入 | ❌ 没有 | ✅ 有 |
| 回测支持 | ✅ 可以 | ❌ 不行 |
| Hyperopt优化 | ✅ 可以 | ❌ 不行 |
| BTC信息对 | 固定BTC/USDT | 自动适配计价货币 |
| 卖出触发 | 稍慢 | 稍快（偏移<1） |

**一句话总结**：
> TBS版是实盘用的"精装版"，基础版是研发用的"简装版"

---

## 三、追踪买入：这策略的灵魂功能

### 3.1 追踪买入是啥意思？

普通买入：信号出现 → 立刻买入

追踪买入：信号出现 → 等价格再跌一点 → 价格反弹时买入

```
举个栗子：

信号价：100元
追踪后：99元买入

省了：1%
```

**大白话**：
> "你说可以买了，我再等等，看能不能捡到更便宜的"

### 3.2 追踪买入怎么工作？

就像钓鱼一样：

1. **发现鱼**：买入信号出现，价格100
2. **撒网等鱼**：开始追踪，设置上限=100.5（反弹0.5%就买）
3. **鱼往下钻**：价格跌到99，上限跟着下调到99.5
4. **鱼往上窜**：价格反弹到99.5，触发买入！

### 3.3 追踪买入的参数

| 参数 | 默认值 | 大白话解释 |
|------|--------|-----------|
| trailing_buy_max_stop | 2% | 价格涨超过起始价2%，就不追了 |
| trailing_buy_max_buy | 0% | 价格低于起始价就买 |
| trailing_expire_seconds | 1800秒 | 等了30分钟还不买就放弃 |

**翻译**：
- 等价格下跌，最多等30分钟
- 价格如果涨了超过2%，算了不追了
- 价格反弹时买入，捡到便宜货！

### 3.4 分级反弹阈值

| 价格跌幅 | 反弹多少就买 |
|---------|-------------|
| 跌6%以上 | 反弹2%就买 |
| 跌3%-6% | 反弹1%就买 |
| 跌0-3% | 反弹0.5%就买 |

**大白话**：
> "跌得越多，反弹阈值越宽——因为捡到的便宜更大，不用那么着急"

## 四、保护机制：双重追踪

### 买前追踪（追踪买入）

| 场景 | 动作 | 大白话 |
|------|------|--------|
| 信号出现 | 开始追踪 | "好，我看你还能跌多少" |
| 价格下跌 | 更新上限 | "继续跌，上限跟着降" |
| 价格反弹 | 触发买入 | "够了够了，下手！" |
| 价格上涨太多 | 停止追踪 | "涨太多了，算了不买" |
| 超时30分钟 | 停止追踪 | "等太久了，算了" |

### 买后追踪（追踪止损）

| 利润档位 | 止损保护 | 大白话 |
|---------|---------|--------|
| 刚入场 | -17.8% | "先留足空间" |
| 赚1.9%以上 | 开始保本 | "赚到钱了，开始收紧" |
| 赹6.5%以上 | 跟着利润走 | "赚大了，跟着走" |

**总结**：
> 买前等着捡便宜，买后保住赚到的钱——全程追踪，两头都顾！

## 七、这策略的"人格特点"

### ✅ 优点

1. **入场价更优**：追踪买入可能捡到更便宜的价格
2. **全程追踪**：买前追踪价格，买后追踪止损
3. **自动适配**：不管交易所用什么计价货币都能跑
4. **继承完整**：基础版的好东西全留着
5. **省计算资源**：只在新K线时计算

### ⚠️ 缺点

1. **不能回测**：追踪买入在回测里没法模拟
2. **不能优化**：Hyperopt用不了，得先用基础版调参数
3. **等太久可能错过**：30分钟超时，好的机会可能溜走
4. **API延迟影响**：实时追踪依赖API速度
5. **参数更复杂**：多了一堆追踪买入参数

## 九、实盘使用建议

### 9.1 配置流程

```
第一步：用基础版回测调参数
第二步：把参数复制到TBS版
第三步：dry-run模式跑TBS版
第四步：确认稳定后实盘
```

### 9.2 关键参数设置

```yaml
# config.json 关键设置
"dry_run": true,  # 先跑模拟！
"max_open_trades": 3,  # 同时最多3笔

# TBS版特殊设置
trailing_buy_order_enabled: true  # 启用追踪买入
trailing_expire_seconds: 1800  # 30分钟超时
```

### 9.3 硬件要求

和基础版一样：
- 交易对≤10个：8GB内存够用
- 交易对>10个：建议16GB

## 十、彩蛋：追踪买入的隐藏逻辑

看代码你会发现：

1. **强制买入功能**：
   > 超时+价格低于起始价+买入信号还在 → 强制买入
   > "等太久了但机会还在，那就买吧"

2. **上升趋势快速买入**：
   > trailing_buy_uptrend_enabled = False（默认关闭）
   > 如果开启：90秒内价格上涨超过2%就快速买入
   > "上升趋势来了，不等了直接买"

3. **买前买后双重追踪**：
   > 买前等便宜，买后保利润
   > 这策略从头到尾都在"追"

## 十二、⚠️ 重要警告

### 追踪买入的陷阱

**不能回测 ≠ 实盘一定好**

追踪买入在实盘中的效果取决于：
- API延迟：延迟太大可能错过最佳入场点
- 流动性：极端行情可能买不到
- 滑点：反弹时买入价格可能不理想

### 正确使用流程

```
回测 → 基础版调参数 → 参数迁移到TBS → dry-run → 实盘
```

**不要**直接用TBS版实盘，参数都没调过！

### 风险再强调

- 追踪买入等30分钟可能错过好机会
- API不稳定可能导致追踪失效
- 不支持回测意味着效果未知

**记住**：先研究再实盘，活着最重要！🙏

# BB_RPB_TSL_RNG 策略：精简版"超跌捕手"

> **外号**："精简版瑞士军刀"——删掉7个刀片，只保留最锋利的7个
> **职业**：超跌捕捉专家 + 平滑止损保镖
> **时间框架**：5分钟干活，盯着BTC风向标

---

## 一、这策略是个啥？

简单说，**BB_RPB_TSL_RNG** 就是一个：
- 从14个买入条件精简到7个，只保留核心超跌逻辑
- 用数学公式算止损，比分段止损更平滑
- 有个BTC风向标，大盘风向不对就暂停入场
- 可以单独开关某些买入条件，灵活调整

就像把**瑞士军刀拆掉一半刀片**，只保留最常用的那几个，轻装上阵 🗡️

## 二、核心配置：说白了就是"抄底+平滑止损"

### 止盈规则（ROI 表）

```
目标利润：10%才自动止盈
```

**翻译**：这策略比 BIV1 更保守，10%就止盈。不过实际还是主要靠追踪止损干活。

### 止损规则：用数学公式算的！

```
硬止损：-17.8%（利润低于1.9%时用）
追踪止损：利润越高，止损越紧（用公式算）
```

**翻译**：这策略的止损是**用公式连续算出来的**，不像 BIV1 那样分段：

| 利润 | 止损（大白话） |
|------|---------------|
| 0% | -17.8%（硬止损保底） |
| 1.9% | 1.9%（开始追踪） |
| 6.5% | 6.2%（追踪更紧） |
| 10% | 9.7%（利润差值继续累加） |

**数学公式翻译成人话**：
- 利润 1.9% ~ 6.5% 之间：止损从 1.9% 平滑过渡到 6.2%
- 利润超过 6.5%：止损跟着利润继续涨

**这比 BIV1 的分段止损更平滑**，就像高速公路连续变道，而不是分段刹车 🚗

## 四、保护机制：2层"保镖"

相比 BIV1 的3层保镖，RNG 版本简化到 **2层**：

| 保护类型 | 作用 | 大白话 |
|---------|------|--------|
| BTC保镖 | 大盘暴跌时暂停买入 | "盯着BTC风向标，大哥崩了小弟别送死" |
| 条件开关 | 可单独开关买入条件 | "觉得某个条件太严格？关掉它！" |

**注意**：RNG 版本**没有 1h 信息层保镖**！这是它和BIV1的最大区别。

**吐槽**：少了1h保镖，入场门槛降低，机会多了，但假信号风险也大了 🤣

## 五、卖出逻辑：数学公式算的

### 5.1 平滑追踪止损：利润越高越紧

```
利润区间           止损逻辑
──────────────────────────────────
<1.9%             硬止损 -17.8%
1.9%~6.5%         线性插值，从1.9%过渡到6.2%
>6.5%             6.2% + (利润-6.5%)
```

**大白话**：
- **利润 < 1.9%**：用硬止损，跌 17.8% 才跑——给足够的反弹空间
- **利润 1.9%~6.5%**：止损从 1.9% 平滑过渡到 6.2%——就像斜坡，不是台阶
- **利润 > 6.5%**：止损跟着利润涨，赚越多锁越紧

**数学公式（想看的可以看）**：
```python
# 利润区间 PF_1 到 PF_2 之间线性插值
sl_profit = SL_1 + ((利润 - PF_1) * (SL_2 - SL_1) / (PF_2 - PF_1))
```

|------|---------|--------|

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **简洁高效**：只有7个买入条件，比 BIV1 的14个好理解
2. **平滑止损**：用数学公式算，止损值连续变化，不是分段跳
3. **灵活开关**：可以单独开关 dip/break 条件，调整入场严格程度
4. **计算量小**：没有1h信息层，计算比 BIV1 快

### ⚠️ 缺点（吐槽环节）

1. **少了1h保镖**：没有大老板签字，假信号风险更高
2. **止损公式复杂**：虽然平滑，但5个参数调优有点难
3. **依赖BTC数据**：需要 BTC/USDT 交易对，没BTC数据策略会报错
4. **Hyperopt参数多**：虽然精简了条件，参数还是不少

**建议流程**：
1. 回测先看效果
2. 理解止损公式参数

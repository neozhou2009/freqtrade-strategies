## 一、这策略是个啥？

简单说，**CombinedBinHAndClucV4** 是一个"双刀流"超跌反弹策略的**进化版**：

- 由两个经典策略合并而来：**BinHV45** + **ClucMay72018**
- 两个策略各有绝活，只要其中一个触发就买入
- 专门抓那些"跌过头了要弹回来"的机会

**V4 相比 V3 的核心升级**：
- 止损放宽（-10% → -99%）：不让市场噪音震出去
- 追踪止损提前（3% → 2.5%）：更早锁定盈利
- 时间止损缩短（36.7 小时 → 5 小时）：不给亏损太多时间发酵
- 卖出更严格（4 根 K 线 → 5 根）：确认更久才让卖

就像一个老练的渔夫，撒了两张网——一张网急跌反弹的鱼，一张网缩量超跌的鱼。V4 版本的渔夫更有耐心了，也更懂得保护自己。🐟

## 二、核心配置：说白了就是"让利润奔跑，但也别死扛"

### 止盈规则（ROI 表）

```
累计收益 ≥ 1.9% → 触发止盈
```

**翻译**：赚够 1.9% 就跑，别贪心，落袋为安。（比 V3 高了 0.1%，小意思）

### 止损规则

```
固定止损：-99%（几乎不设限）
追踪止损：盈利 2.5% 后启动，保护 1% 利润（比 V3 提前了）
时间止损：持仓 5 小时后若亏损，强制市价跑路（比 V3 大幅缩短）
```

**翻译**：
- 固定止损几乎不用了——V4 的理念是"别被短期波动吓跑"
- 赚够 2.5% 之后开启"护盾"，从最高点回撤 1% 就跑（比 V3 更早保护）
- 持仓超过 5 小时还在亏？不熬了，市价走人（V3 是 36 小时，V4 更果断）

### 其他配置

| 配置项 | 值 | 大白话 |
|--------|-----|--------|
| 时间周期 | 5 分钟 | 短线高频 |
| 盈利才卖 | True | 亏钱状态下不许卖 |
| 盈利偏移 | 0.1% | 至少赚 0.1% 才能触发卖出 |

## 六、这策略的"人格特点"

如果把策略比作一个人：

### ✅ 优点（夸夸环节）

1. **双刀流猎手**：两套买入逻辑，覆盖急跌反弹和缩量反弹两种场景

2. **5 分钟噪声大**：短线周期容易被假信号忽悠，手续费也高
3. **单边下跌可能扛不住**：虽然时间止损 5 小时，但 -99% 止损等于没有
4. **卖出条件更严**：连续 5 根 K 线突破上轨才卖，可能错过最佳卖点

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

CombinedBinHAndClucV4 的历史回测表现往往**看起来不错**——但这有个陷阱：

> **均值回归策略在震荡市表现好，但遇到单边行情会惨败。**

简单说就是：**历史不会简单重复，过去震荡不代表未来还震荡。**

### V4 的特殊风险

V4 相比 V3 有几个**更激进**的设计：

1. **-99% 止损几乎禁用**
   
   - V3 有 -10% 硬止损，V4 几乎没了
   - 单边下跌可能扛很大浮亏
   - 只能靠 5 小时时间止损和追踪止损来保护

2. **5 小时时间止损缩短**
   
   - 好处：不陪你熬太久，更快认错
   - 坏处：可能错过需要更长时间发展的反弹

3. **卖出条件更严格（5 根 K 线）**
   
   - 好处：减少假突破
   - 坏处：可能错过最佳卖点

### 复杂策略的隐藏风险

实盘时，你可能遇到：

- **滑点风险**：高频交易，滑点累积起来可能吃掉利润
- **手续费侵蚀**：5 分钟周期交易频繁，手续费不是小数目
- **API 限速**：交易频率太高可能触发交易所限速
- **单边行情**：持续上涨卖飞，持续下跌扛浮亏，两边挨打


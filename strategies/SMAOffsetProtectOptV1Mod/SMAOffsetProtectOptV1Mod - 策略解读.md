## 一、策略概览

SMAOffsetProtectOptV1Mod 是一个基于简单移动平均偏移（SMA Offset）的趋势跟踪策略，结合 Elliott 波动振荡器（EWO）作为保护机制，RSI 作为辅助过滤。策略通过"低价买入+趋势确认"的双重逻辑，在市场回调时捕捉入场机会，同时利用追踪止损锁定利润。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 2 个独立买入信号，可独立触发 |
| **卖出条件** | 1 个基础卖出信号 + ROI 分级止盈 + 追踪止损 |
| **保护机制** | EWO 高低阈值保护 + RSI 过滤 |
| **时间框架** | 主时间框架 5m + 信息时间框架 1h |
| **依赖库** | talib, numpy, pandas, technical (ftt), qtpylib |

## 三、买入条件详解

### 3.1 可优化参数

策略采用 Freqtrade 的参数优化系统，所有关键参数均可通过 HyperOpt 优化：

| 参数类型 | 参数名 | 默认值 | 优化范围 | 说明 |
|---------|--------|--------|----------|------|
| **买入** | base_nb_candles_buy | 16 | 5-80 | EMA 周期 |
| **买入** | low_offset | 0.973 | 0.9-0.99 | 价格偏移系数 |
| **买入** | ewo_high | 5.672 | 2.0-12.0 | EWO 高阈值 |
| **买入** | ewo_low | -19.931 | -20.0 to -8.0 | EWO 低阈值 |
| **买入** | rsi_buy | 59 | 30-70 | RSI 买入阈值 |
| **卖出** | base_nb_candles_sell | 20 | 5-80 | 卖出 EMA 周期 |
| **卖出** | high_offset | 1.010 | 0.99-1.1 | 卖出价格偏移 |

### 3.2 买入条件详解

#### 条件 #1：趋势确认型买入
```python
# 逻辑
- 价格低于 EMA * low_offset（回调买入）
- EWO > ewo_high（强趋势确认）
- RSI < rsi_buy（未超买）
- 成交量 > 0（有效性检查）
```

**核心逻辑**：这是一个"趋势回调买入"策略。当价格回调到 EMA 下方一定比例时，如果 EWO 显示强趋势（> ewo_high），说明趋势依然强劲，回调是买入机会。RSI 条件确保不在过热时买入。

#### 条件 #2：深度超卖型买入
```python
# 逻辑
- 价格低于 EMA * low_offset（回调买入）
- EWO < ewo_low（深度负值）
- 成交量 > 0（有效性检查）
```

**核心逻辑**：这是一个"超跌反弹"策略。当 EWO 跌到极低水平（< ewo_low），说明市场极度悲观，可能出现反弹机会。此条件不要求 RSI 过滤，专注于捕捉极端超卖后的反弹。

### 3.3 买入条件分类

| 条件组 | 条件编号 | 核心逻辑 | 特点 |
|-------|---------|---------|------|
| 趋势跟随 | 条件 #1 | EWO 高值 + RSI 过滤 | 稳健型，顺势而为 |
| 逆向抄底 | 条件 #2 | EWO 低值 + 无 RSI 限制 | 激进型，抄底反弹 |

## 四、卖出逻辑详解

### 4.1 多层止盈系统

策略采用三级 ROI 止盈机制：

```
持有时间    目标利润率    说明
────────────────────────────────
立即        2.8%         最高利润目标
12 根 K 线   1.6%         中期利润目标
37 根 K 线   0.5%         最低利润目标
```

**设计理念**：持有时间越长，对利润要求越低。鼓励短期获利，但也给长期持有留有余地。

### 4.2 追踪止损机制

| 参数 | 值 | 说明 |
|------|------|------|
| trailing_stop | True | 启用追踪止损 |
| trailing_stop_positive | 0.1% | 追踪距离 |
| trailing_stop_positive_offset | 1% | 激活阈值 |
| trailing_only_offset_is_reached | True | 仅在达到阈值后启用 |

**工作机制**：
1. 当利润达到 1% 时，追踪止损激活
2. 止损线跟随价格上涨，保持 0.1% 的距离
3. 价格回撤触发止损，锁定利润

### 4.3 基础卖出信号（1 个）

```python
# 卖出信号 1: EMA 偏移卖出
- 价格 > EMA(base_nb_candles_sell) * high_offset
- 成交量 > 0
```

**触发条件**：当价格反弹超过 EMA 的 1.01 倍时，说明短期可能过热，触发卖出。

### 5.2 EWO（Elliott Wave Oscillator）详解

EWO 是本策略的核心保护指标：

```python
def EWO(dataframe, ema_length=5, ema2_length=35):
    ema1 = ta.EMA(df, timeperiod=ema_length)
    ema2 = ta.EMA(df, timeperiod=ema2_length)
    emadif = (ema1 - ema2) / df['close'] * 100
    return emadif
```

**策略中的参数**：fast_ewo = 50, slow_ewo = 200

**解读**：
- EWO 为正且较大：短期 EMA 高于长期 EMA，趋势向上
- EWO 为负且较小：短期 EMA 低于长期 EMA，趋势向下
- EWO 接近零：趋势不明朗或震荡

## 六、风险管理特色

### 6.1 EWO 保护机制

EWO（Elliott Wave Oscillator）作为核心保护指标：

| 保护类型 | 参数说明 | 默认值 |
|---------|---------|--------|
| EWO 高阈值 | 强趋势确认 | 5.672 |
| EWO 低阈值 | 极端超卖识别 | -19.931 |

**保护逻辑**：
- 买入时必须 EWO > ewo_high 或 EWO < ewo_low
- 避免在趋势不明朗时（EWO 接近零）买入

### 6.2 RSI 过滤机制

```python
rsi_buy = IntParameter(30, 70, default=59)
```

**设计理念**：
- RSI < rsi_buy 确保不在超买区买入
- 仅应用于趋势确认型买入（条件 #1）
- 深度超卖型买入不使用 RSI 过滤

### 6.3 成交量验证

所有买入和卖出条件都要求 `volume > 0`：
- 确保交易发生在有效市场环境
- 避免在流动性枯竭时交易

## 七、策略优势与局限

### ✅ 优势

1. **双重入场逻辑**：趋势跟随 + 抄底反弹，适应不同市场阶段
2. **参数可优化**：7 个 HyperOpt 参数，适合针对不同币种优化
3. **追踪止损**：锁定利润的同时给趋势发展空间
4. **EWO 保护**：避免在趋势不明朗时入场

### ⚠️ 局限

1. **震荡市场表现差**：EMA 偏移策略在横盘市场容易被反复止损
2. **参数敏感**：默认参数可能不适应当前市场，需要回测优化
3. **无多头/空头区分**：策略仅做多，无法在下跌市场获利
4. **固定止损**：10% 固定止损可能在波动大的币种上过于保守或激进

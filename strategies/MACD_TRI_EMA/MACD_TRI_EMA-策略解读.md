---

## 一、策略概览

**MACD_TRI_EMA** 是一个简洁的动量趋势策略，结合了 MACD 交叉信号和 TEMA（三重指数移动平均线）趋势过滤。策略名称中的"TRI"可能指的是 TEMA 指标，整体设计追求简单有效。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 1 个条件：MACD 金叉 + 价格 > TEMA |
| **卖出条件** | 1 个条件：MACD 死叉 |
| **保护机制** | 硬止损 |
| **时间框架** | 5 分钟 |
| **依赖库** | TA-Lib, technical (qtpylib) |
| **特殊功能** | TEMA 趋势过滤 |

## 二、策略配置解析

### 2.1 基础风险参数

```python
# ROI 退出表
minimal_roi = {
    "120": 0.0,    # 120 分钟后：保本退出
    "30": 0.04,    # 30 分钟后：4% 利润退出
    "15": 0.06,    # 15 分钟后：6% 利润退出
    "10": 0.15,    # 10 分钟后：15% 利润退出
}

# 止损设置
stoploss = -0.03  # -3% 硬止损
```

**设计思路**：
- **时间递减 ROI**：持仓时间越长，退出门槛越低
- **短期高收益**：10 分钟内达到 15% 利润即可退出
- **严格止损**：-3% 硬止损，控制单笔亏损

### 2.2 订单类型配置

使用 Freqtrade 默认配置。

## 三、买入条件详解

### 3.1 买入逻辑

```python
# 买入条件
dataframe.loc[
    (
        qtpylib.crossed_above(dataframe["macd"], dataframe["macdsignal"])  # MACD 金叉
        & (dataframe["close"].shift(1) > dataframe["tema"].shift(1))        # 前一根 K 线价格 > TEMA
    ),
    "buy",
] = 1
```

**逻辑解析**：
- **MACD 金叉**：MACD 线从下方上穿信号线，动量转强
- **TEMA 过滤**：价格在 TEMA 之上，确认上涨趋势
- **延迟确认**：使用 `shift(1)` 确认前一根 K 线已满足条件

### 3.2 指标计算

```python
# MACD 计算
macd = ta.MACD(dataframe)
dataframe["macd"] = macd["macd"]
dataframe["macdsignal"] = macd["macdsignal"]

# TEMA 计算（三重指数移动平均）
dataframe["tema"] = ta.TEMA(dataframe, timeperiod=13)
```

**TEMA 特点**：
- **三重平滑**：对 EMA 进行三次平滑处理
- **低延迟**：比传统 EMA 反应更快
- **趋势过滤**：价格在 TEMA 之上确认上涨趋势

## 四、卖出逻辑详解

### 4.1 卖出条件

```python
# 卖出条件
dataframe.loc[
    (qtpylib.crossed_above(dataframe["macdsignal"], dataframe["macd"])),  # MACD 死叉
    "sell",
] = 1
```

**逻辑解析**：
- **MACD 死叉**：信号线从下方上穿 MACD 线，动量转弱
- **对称设计**：买入用金叉，卖出用死叉，逻辑对称
- **及时退出**：动量转弱即退出，不等待 ROI

### 4.2 ROI 退出

```python
minimal_roi = {
    "120": 0.0,    # 120 分钟后保本
    "30": 0.04,    # 30 分钟后 4%
    "15": 0.06,    # 15 分钟后 6%
    "10": 0.15,    # 10 分钟后 15%
}
```

**退出优先级**：
1. MACD 死叉（技术信号）
2. ROI 达到（利润目标）
3. 硬止损（-3%）

## 五、技术指标体系

### 5.1 核心指标

| 指标类别 | 具体指标 | 参数 | 用途 |
|---------|---------|------|------|
| **动量指标** | MACD | 默认 (12/26/9) | 动量方向和交叉信号 |
| **趋势指标** | TEMA | 13 周期 | 趋势过滤 |

### 5.2 MACD 指标

**组成**：
- **MACD 线**：12 周期 EMA - 26 周期 EMA
- **信号线**：MACD 线的 9 周期 EMA
- **柱状图**：MACD 线 - 信号线（本策略未使用）

**信号**：
- **金叉**：MACD 线上穿信号线，买入信号
- **死叉**：信号线上穿 MACD 线，卖出信号

### 5.3 TEMA 指标

**计算**：
```
TEMA = 3×EMA1 - 3×EMA2 + EMA3
其中：
EMA1 = 13 周期 EMA
EMA2 = EMA1 的 13 周期 EMA
EMA3 = EMA2 的 13 周期 EMA
```

**特点**：
- 比传统 EMA 反应更快
- 减少延迟，更适合趋势跟踪
- 价格在 TEMA 之上确认上涨趋势

## 六、风险管理特色

### 6.1 硬止损

```python
stoploss = -0.03  # -3%
```

**说明**：严格止损，控制单笔亏损在 3% 以内。

### 6.2 时间递减 ROI

| 持仓时间 | 最小利润率 | 触发退出 |
|---------|-----------|---------|
| 10 分钟 | 15% | 快速获利退出 |
| 15 分钟 | 6% | 短期获利退出 |
| 30 分钟 | 4% | 中期获利退出 |
| 120 分钟 | 0% | 保本退出 |

**设计思路**：
- 短期高收益预期（10 分钟 15%）
- 持仓时间越长，预期越低
- 2 小时后保本退出，避免长期套牢

## 七、策略优势与局限

### ✅ 优势

1. **逻辑简洁**：仅 MACD + TEMA 两个指标，易于理解
2. **信号对称**：金叉买入，死叉卖出，逻辑清晰
3. **TEMA 低延迟**：比传统 EMA 反应更快
4. **严格止损**：-3% 止损控制风险
5. **计算量小**：指标少，对硬件要求低

### ⚠️ 局限

1. **无趋势过滤**：没有长期趋势判断（如 EMA200）
2. **无 BTC 关联**：不检测比特币大盘趋势
3. **参数固定**：MACD 和 TEMA 参数固定
4. **严格止损**：-3% 止损在高波动中可能频繁触发
5. **示例性质**：策略较简单，适合学习而非生产

| 市场环境 | 推荐配置 | 说明 |
|---------|---------|------|
| **震荡市** | 不推荐 | 动量策略在震荡市中假信号多 |
| **上涨趋势** | 推荐 | TEMA 过滤确保顺势交易 |
| **下跌趋势** | 暂停 | 无长期趋势过滤，易亏损 |
| **高波动** | 调整止损 | 可能需要放宽止损至 -5% |
| **低波动** | 调整 ROI | 降低 ROI 门槛适应小波动 |

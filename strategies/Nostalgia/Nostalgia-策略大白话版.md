> **外号**：选择困难症晚期患者

## 一、这策略是个啥？

简单说，**Nostalgia** 就是一个：
- 有 **31 种不同的买入理由** 的策略
- 每种理由还能自己开关（"今天心情不好，只用第 3 条"）
- 卖出的时候更是有 **无数种借口**（"赚够了跑"、"亏太多了割"、"感觉不对溜"）

就像一个买东西时能找出 31 个理由下单，但卖的时候能找出 100 个理由跑路的老韭菜 🤣

## 二、核心配置：说白了就是"赚多少跑，亏多少割"

### 止盈规则（ROI 表）

```
刚买入就赚 10%？→ 跑！
拿了 30 分钟赚 5%？→ 跑！
拿了 1 小时赚 2%？→ 赶紧跑！
```

**翻译**：持仓越久，要求越低。就像谈恋爱，刚认识要求高，时间久了"能过就行"😅

### 止损规则

```
硬止损：亏 10% 直接割，没商量
追踪止损：赚了钱后要回撤 1% 才跑，但要先赚够 3% 才启动
```

**翻译**：亏钱时心狠手辣，赚钱时给点宽容——典型的"截断亏损，让利润奔跑"

## 四、保护机制：31 层"保险丝"

每个买入条件都配了一套保护参数，就像给每个理由都上了保险：

| 保护类型 | 作用 | 大白话 |
|---------|------|--------|
| **EMA 快速** | 确保价格在 EMA200 之上 | "大趋势得是向上的吧？" |
| **EMA 慢速** | 1h 级别 EMA 也得向上 | "1 小时级别也不能是跌的吧？" |
| **SMA200 上升** | 200 日均线得是上涨的 | "长期趋势不能坏！" |
| **安全下跌** | 不能刚暴跌就买 | "刚跌了 20% 的刀子不能接！" |
| **安全上涨** | 不能刚暴涨就追 | "刚涨了 50% 的不能追高！" |
| **BTC 趋势** | BTC 不能在大跌 | "大哥不能崩，小弟才能涨！" |

**31 组保护参数** = 31 个买入条件 × 各配一套保险

这策略的谨慎程度，堪比相亲时查对方三代家谱 🤣

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **条件多到爆**：31 个买入条件，总有一个适合当前市场
2. **谨慎得要命**：31 组保护参数，各种防追高、防接刀
3. **止盈灵活**：赚得多就拿久点，赚得少就跑快点
4. **多时间框架**：5 分钟操作 + 1 小时看趋势 + BTC 看大哥脸色
5. **经典指标**：用的都是几十年验证过的指标，不是玄学

### ⚠️ 缺点（吐槽环节）

1. **参数多到头秃**：31 个条件 × N 个参数，优化起来能把你搞疯
2. **数据需求大**：需要充足的 1h 和 5m 历史数据，新币玩不了
3. **依赖外部库**：TA-Lib、technical 库，安装就能让你折腾半天
4. **可能过拟合**：31 个条件，说不定就是硬凑出来的"完美历史"
5. **计算量大**：每个周期算 20+ 指标，老电脑可能会卡

### 11.1 交易对配置

| 配置项 | 建议值 | 吐槽 |

| **时间框架** | 5m | 强制的，改不了，别挣扎 |

### 11.2 配置文件关键设置

```yaml
timeframe: 5m                    # 别改，改了就不灵了
use_exit_signal: true            # 用策略自己的卖出信号
exit_profit_only: false          # 该割就割，别硬扛
ignore_roi_if_entry_signal: true # 卖出信号来了，ROI 表靠边站
```

### 11.3 硬件要求（重要！）

这策略计算量巨大，对 VPS 内存有要求：

| 交易对数量 | 最低内存 | 推荐内存 | 体验 |
|-----------|---------|---------|------|
| 20-40 对 | 2GB | 4GB | 能跑，但别指望太快 |
| 40-80 对 | 4GB | 8GB | 舒服，推荐配置 |
| 80+ 对 | 8GB | 16GB | 土豪随意 |

**警告**：内存不够的话，策略可能会因为计算超时而卡顿，到时候亏钱别怪策略 😅

### 11.4 回测 vs 实盘

NFI 包含动态调仓和 Hold Support 功能，这些在普通回测里很难完全模拟。

**建议流程**：
1. 先回测看看大概表现
2. 模拟交易（Dry-Run）跑 1-3 个月
3. 实盘先用小资金测试
4. 稳定后再加大资金

**别一上来就梭哈**，策略再好也得磨合！

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

NFI 策略的历史回测表现往往**极其优异**——但这有个陷阱：

> **因为参数众多，策略很容易"拟合"过去行情的最优解，但这并不代表未来一定能盈利。**

简单说就是：**回测数据好看，可能是因为它太擅长"背答案"了。**

### 复杂策略的隐藏风险

实盘时，复杂的逻辑可能导致：
- **极端行情下的非预期行为**：比如连环止损、条件误触发
- **计算延迟**：指标太多，VPS 卡顿时可能错过最佳买卖点
- **保护机制失效**：理论上有很多保护，但真实市场中可能不如预期工作

### 我的建议（真心话）

```
1. 先用最小资金量（如 100U）测试
2. 实盘跑至少 1 个月，观察各种极端行情下的表现
3. 确认所有保护机制在真实市场中按预期工作
4. 稳定后再考虑加大资金
```

**记住**：策略是死的，市场是活的。再复杂的策略也怕黑天鹅。

## 三、买入条件详解

### 3.1 保护机制（26组）

每个买入条件都配有独立的保护参数组，构建了"条件+保护"的双重过滤体系。主要保护类型包括：

| 保护类型 | 参数说明 | 默认值示例 |
|---------|---------|-----------|
| EMA快慢关系 | 快均线是否在慢均线上方 | ema_26 > ema_200 |
| 收盘价位置 | 收盘价是否在EMA上方 | close > ema_200 |
| SMA200趋势 | SMA200是否处于上升状态 | sma_200 > sma_200.shift(28) |
| SMA200_1h趋势 | 1小时SMA200是否上升 | sma_200_1h > sma_200_1h.shift(50) |
| 安全下跌 | 价格下跌是否在安全范围内 | safe_dips_80 |
| 安全暴涨 | 价格暴涨后是否已回调到位 | safe_pump_24_70 |

## 附录A：安全暴跌与安全暴涨机制详解

### A.1 安全暴跌检测（safe_dips）

策略使用四个不同时间周期的跌幅阈值来判断当前下跌是否"安全"：

```python
def safe_dips(dataframe, thresh_0, thresh_2, thresh_12, thresh_144):
    """判断下跌是否在安全范围内"""
    return ((tpct_change_0 < thresh_0) &    # 当前K线跌幅
            (tpct_change_2 < thresh_2) &     # 2周期内跌幅
            (tpct_change_12 < thresh_12) &   # 12周期内跌幅
            (tpct_change_144 < thresh_144))  # 144周期内跌幅
```

策略定义了11个跌幅安全等级（10-110），每个等级有独立的四阈值组合：

| 等级 | 阈值1 | 阈值2 | 阈值3 | 阈值4 | 适用场景 |

### A.2 安全暴涨检测（safe_pump）

策略通过检测不同时间周期（24h/36h/48h）的涨幅来判断暴涨后是否可以安全入场：

```python
def safe_pump(dataframe, length, thresh, pull_thresh):
    """判断暴涨后是否已充分回调"""
    return (oc_pct_change < thresh) | \
           (range_maxgap_adjusted > range_height)
```

当满足以下任一条件时认为安全：
1. 区间涨幅未达到危险阈值（未发生暴涨）
2. 虽然暴涨，但回调幅度足够（价格已从高点回落）

def EWO(dataframe, sma1_length=50, sma2_length=200):
    """计算艾略特波浪振荡器值"""
    sma1 = ta.EMA(df, timeperiod=sma1_length)
    sma2 = ta.EMA(df, timeperiod=sma2_length)
    return (sma1 - sma2) / df['close'] * 100

# Cluc4 策略：布林带 + ROCR 的"趋势猎人"

> **外号**：1 分钟快手  
> **职业**：超短线捕手，专门抓趋势回调  
> **时间框架**：1 分钟（主）+ 1 小时（辅助）

---

## 一、这策略是个啥？

简单说，**Cluc4** 就是一个：

- 先看大方向（1 小时趋势向上），再找小机会（1 分钟布林带信号）
- 快进快出，持股时间通常几分钟到几十分钟
- 有两套买入模式，一套抓暴跌反弹，一套抓地量见地价

就像一个**精明的短线捕手**：先确认大方向对了，才会在小周期上出手。它的性格是——**谨慎但出手快**，见好就收，亏了就跑。

> 打个比方：这策略就像一个老练的渔夫，先看天气（ROCR 趋势）再撒网，不逆风捕鱼，只在鱼多的地方下钩。

---

## 二、核心配置：说白了就是"赚 1.5% 就跑，亏 1% 就认栽"

### 止盈规则（ROI 表）

| 持仓时间 | 目标利润 | 大白话 |
|---------|---------|--------|
| 0-20 分钟 | 1.5% | 快速获利，不恋战 |
| 20-30 分钟 | 0.5% | 没快速涨？降预期 |
| 30 分钟以上 | 0.1% | 保本就跑 |

**翻译**：这就是典型的短线策略，赚一点就满足，不像那些贪心策略非要翻倍才卖。

### 止损规则

```
stoploss = -1%
```

**翻译**：亏 1% 就认栽，绝不硬扛。这个止损非常紧凑——意味着你可能经常被止损出局，但每次亏得少。

## 三、2 个买入条件：我帮你分类好了

这策略的买入条件有个**硬门槛**：必须先过 ROCR 过滤这一关，然后才看具体信号。

### 🚪 先说硬门槛：ROCR 趋势过滤

```
1 小时 ROCR > 0.65
```

**大白话**：
> "只有当 1 小时级别处于上升趋势时，我才会考虑买入。逆势？想都别想！"

这就像过马路前先左右看看有没有车，确认安全了再走。ROCR 是变化率指标，168 周期 ROCR 在 1 小时图上相当于**一周**的价格变化。ROCR > 0.65 意味着过去一周价格涨了不少，趋势明显向上。

### 🎯 第 1 类：BinHV 变体——抓暴跌后反弹

**核心逻辑**：价格突然暴跌后收在下轨附近，下影线很短，说明跌不动了，可能要反弹！

**大白话**：
> "价格被打到地板上了，但没跌破太多，说明有人在接盘。这时候进去，捡个便宜！"

**6 个条件同时满足**：

| 条件 | 大白话翻译 |
|------|-----------|
| 布林带下轨有效 | 数据正常，不是异常值 |
| 布林带带宽 > 收盘价 × 0.6% | 波动够大，有操作空间 |
| 价格变化 > 收盘价 × 1.3% | 这根 K 线波动够剧烈 |
| 下影线 < 带宽 × 96.8% | 下影线很短，不是假跌 |
| 价格 < 前一根布林带下轨 | 价格跌破下轨，"便宜"了 |
| 价格 ≤ 前一根收盘价 | 价格没涨回去，还在低位 |

**一句话总结**：
> "价格突然大跌后收在下轨附近，下影线很短，跌不动了，反弹概率大！"

### 📉 第 2 类：Cluc 变体——抓地量见地价

**核心逻辑**：价格跌到极低位置，成交量极度萎缩（没人愿意卖了），说明底部可能到了！

**大白话**：
> "价格已经跌得没人愿意卖了，成交量萎缩到极点。这时候进去，就是捡带血筹码！"

**3 个条件同时满足**：

| 条件 | 大白话翻译 |
|------|-----------|
| 价格 < EMA50 | 价格在中期均线下方，偏弱 |
| 价格 < 布林带下轨 × 0.013 | 价格跌到极低位置 |
| 成交量 < 30 日均量 × 28 | 成交量极度萎缩（地量） |

**一句话总结**：
> "没人愿意卖了（地量），价格也跌到地板了，底部可能到了！"

### 买入逻辑总结

```
买入 = (1小时 ROCR > 0.65) AND (BinHV模式 OR Cluc模式)
```

## 五、卖出逻辑：简单粗暴

### 5.1 主要卖出条件

```
价格上穿布林带中轨 AND 有成交量
```

**大白话**：
> "价格涨到布林带中间位置了，说明可能到了压力区。走为上策，落袋为安！"

布林带中轨通常是 20 日均线，价格从下轨反弹到中轨，往往面临压力。策略选择在这里止盈，而不是贪心地等到上轨。

### 5.2 卖出条件优先级

```
ROI 止盈 > 信号卖出 > 止损
```

这意味着：
- 如果价格快速涨到 ROI 目标 → 按 ROI 退出
- 如果价格突破中轨 → 按信号卖出
- 如果都不满足且亏损达到 1% → 止损

### 5.3 盈利才卖

```python
exit_profit_only = True
```

**大白话**：只有赚钱的时候才主动卖出，亏钱就等止损触发。不手软，也不乱割肉。

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **有趋势保护**：ROCR 过滤确保不做逆势单，避免接飞刀
2. **双重买入模式**：两套模式增加机会，但不降低质量
3. **止损紧凑**：1% 止损，小亏多次，不会一次伤筋动骨
4. **快进快出**：1 分钟框架，持股时间短，资金利用率高
5. **简单易懂**：逻辑清晰，布林带 + ROCR，没有复杂条件

### ⚠️ 缺点（吐槽环节）

1. **可能错过趋势启动**：ROCR > 0.65 才买入，等趋势确认了，价格可能已经涨了不少
2. **交易频率高**：1 分钟框架，信号多，手续费是个大问题
3. **假突破多**：1 分钟框架假突破频繁，1% 止损可能被频繁触发
4. **需要盯盘**：短线策略，需要稳定网络和快速执行

## 十一、彩蛋：策略作者的"小心思"

仔细看代码，你会发现一些有趣的东西：

### 11.1 双布林带的玄机

Cluc4 使用两套布林带：

- **40 周期布林带**：更平滑，用于 BinHV 模式
- **20 周期布林带**：更敏感，用于 Cluc 模式

**大白话**：
> "两只眼睛看市场，一只看远（40 周期），一只看近（20 周期），两边都对上了才出手！"

### 11.2 ROCR 的秘密

ROCR（Rate of Change Ratio）衡量价格变化率：

```
ROCR = 当日收盘价 / N日前收盘价
```

168 周期 ROCR 在 1 小时图上 = 168 小时 = **7 天**（一周）

所以 ROCR > 0.65 的真正含义是：
> "过去一周价格涨了不少，趋势向上，可以顺势交易！"

### 11.3 手动交易者简化版

如果你想手动跟单，可以这样简化：

1. 打开 1 小时图，确认 ROCR > 0.65（或价格趋势向上）
2. 切换到 1 分钟图，添加布林带（20 周期，2 倍标准差）
3. 等待价格触及下轨附近
4. 买入，设置 1% 止损
5. 价格突破中轨时卖出

## 十三、⚠️ 风险再强调（这段一定要看）

### 高频交易的隐藏成本

Cluc4 是 **1 分钟级别**的高频策略，这意味着：

| 风险项 | 说明 |
|--------|------|
| **手续费** | 每次交易可能吃掉 0.1%-0.2% 利润 |
| **滑点** | 市价单可能买贵卖便宜 |
| **信号延迟** | 网络延迟可能导致错过最佳价位 |
| **假突破** | 1 分钟框架假突破频繁 |

**算笔账**：
- 假设每笔盈利 1.5%
- 扣除买入手续费 0.1% + 卖出手续费 0.1% = 0.2%
- 扣除滑点 0.1%
- **实际盈利 ≈ 1.2%**

**如果手续费 > 0.2%，这个策略可能不赚钱！**

### ROCR 过滤的风险

ROCR 过滤虽然避免了逆势交易，但也有风险：

> 在趋势**启动初期**，ROCR 可能还没到 0.65，这时候策略会**错过最佳入场点**。

等到 ROCR > 0.65 时，价格可能已经涨了不少。

### 连续止损的可能性

1% 的紧凑止损在以下情况可能导致**连续亏损**：

- 假突破频繁
- 高波动市场
- 数据延迟

**心理准备**：连续 5 次止损 = -5%，需要 5.3% 盈利才能回本。

### 实盘注意事项

| 注意事项 | 说明 |
|---------|------|
| 充分回测 | 在不同市场周期进行回测验证 |
| 模拟盘先行 | 实盘前先跑模拟盘至少一周 |
| 选择低手续费平台 | Maker/Taker 费率越低越好 |
| 关注网络延迟 | 选择延迟 < 100ms 的服务器 |
| 控制交易对数量 | 不要贪多，10-20 个为宜 |
| 定期检查参数 | 市场变化时可能需要调整 |

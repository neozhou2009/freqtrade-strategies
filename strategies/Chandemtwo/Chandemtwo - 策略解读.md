## 一、策略概览

**Chandemtwo** 是 Chandem 策略的增强版本，在买入和卖出条件上都进行了更严格的优化。核心逻辑仍然是基于 CMO（钱德动量振荡器）捕捉动量转捩点，但相比原版增加了 CMO 连续性确认和 CMO 回落卖出机制。策略追求更高收益，首级 ROI 高达 75.2%，同时配合更宽松的止损（-33.6%）以容纳更大的价格波动。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | CMO 连续3周期确认上穿零轴（shift(2)上穿，shift(1)≥0，当前≥0） |
| **卖出条件** | 价格上穿布林带上轨 OR CMO 下穿-35 |
| **保护机制** | 追踪止损（+1.523% 启动，+10.329% 触发） |
| **时间框架** | 5m |
| **依赖库** | TA-Lib, technical (qtpylib) |

## 三、买入条件详解

### 3.1 买入逻辑完整解析

```python
dataframe.loc[
    (
        # 条件 1: CMO 2周期前上穿零轴
        (qtpylib.crossed_above(dataframe["CMO"].shift(2), 0))
        # 条件 2: CMO 1周期前 >= 0
        & (dataframe["CMO"].shift(1) >= 0)
        # 条件 3: CMO 当前 >= 0
        & (dataframe["CMO"] >= 0)
    ),
    'buy'] = 1
```

**逻辑解析**：

1. **CMO 指标连续3周期确认上穿**：
   - 这是一个**更严格的动量确认机制**
   - 要求 CMO 不仅上穿零轴，还要连续3期保持在零轴上方
   - 相比 Chandem 的单期上穿（shift(1)），Chandemtwo 大幅降低了假信号概率

2. **时序确认的三重过滤**：
   - `crossed_above(dataframe["CMO"].shift(2), 0)`：2周期前确认上穿
   - `dataframe["CMO"].shift(1) >= 0`：1周期前保持正值
   - `dataframe["CMO"] >= 0`：当前保持正值
   - 这种设计确保买入信号发生在动量**持续增强**的阶段

### 3.2 指标计算

## 四、卖出逻辑详解

### 4.1 卖出条件（双触发机制）

```python
dataframe.loc[
    (
        # 条件 1: 价格上穿布林带上轨
        (qtpylib.crossed_above(dataframe['close'], dataframe['bb_upperband']))
        # 条件 2: CMO 下穿 -35
        | (qtpylib.crossed_below(dataframe["CMO"], -35))
    ),
    'sell'] = 1
```

**逻辑解析**：

1. **布林带上轨突破**：
   - 价格突破布林带上轨表示**价格处于极端高位**
   - 这是一个**趋势反转预警信号**
   - 与 Chandem 策略的卖出条件相同

2. **CMO 回落卖出（新增）**：
   - 当 CMO 从高位下穿 -35 时触发卖出
   - 这是一个**动量衰减信号**，表示上涨动量已经耗尽
   - 这是 Chandemtwo 相对于 Chandem 的关键改进

3. **双触发逻辑**：
   - 两种卖出条件是**或（OR）**关系
   - 任一条件满足即触发卖出信号
   - 增加了卖出机制的灵活性

### 4.2 ROI 退出机制

| 持仓时间 | 最小利润率 | 触发退出 |
|---------|-----------|---------|
| 0 分钟 | 75.2% | 达到即退出 |
| 827 分钟（约14小时） | 39.1% | 超过此时段 |
| 2168 分钟（约36小时） | 34.1% | 超过此时段 |
| 3527 分钟（约59小时） | 0% | 保本退出 |

**特别注意**：Chandemtwo 的首级 ROI 高达 75.2%，这是一个非常激进的目标。在大多数市场环境下，这个目标可能难以快速达成。

## 五、技术指标体系

### 5.1 核心指标

| 指标类别 | 具体指标 | 参数 | 用途 |
|---------|---------|------|------|
| **动量指标** | CMO | 50 周期 | 捕捉动量转捩点和动量衰减 |
| **波动指标** | Bollinger Bands | 25周期, 3.5σ | 识别价格极端 |
| **价格类型** | Typical Price | (H+L+C)/3 | 布林带计算基础 |

### 5.2 指标详解

#### CMO（Chande Momentum Oscillator）

- **计算公式**：类似 RSI 的动量指标
- **取值范围**：-100 到 +100
- **策略逻辑**：
  - CMO < 0 → 近期下跌动量占优
  - CMO > 0 → 近期上涨动量占优
  - CMO 从负转正 → 动量由空转多，买入信号
  - CMO 从高为下穿 -35 → 动量由多转空，卖出信号

#### 布林带（Bollinger Bands）

- **参数**：25 周期，3.5 倍标准差（较宽）
- **较宽的原因**：使用 3.5σ 而非常规的 2σ，可以过滤噪音
- **策略逻辑**：
  - 价格触及上轨 → 超买信号，触发卖出

## 六、风险管理特色

### 6.1 硬止损机制

```python
stoploss = -0.33572  # -33.6% 硬止损
```

- **33.6% 止损幅度**：非常宽松，给予价格充分波动空间
- **设计目的**：配合 75.2% 的高 ROI 目标，允许更大的回撤
- **风险提示**：单笔最大亏损可达 33.6%

### 6.2 追踪止损机制

- **启动条件**：利润 ≥ 1.523%
- **触发条件**：利润 ≥ 10.329%
- **锁定利润**：10.329% - 1.523% = 8.806%

### 6.3 ROI 退出机制

- **分阶段退出**：4 档 ROI，目标依次降低
- **逻辑**：早期追求极高利润，后期稳健退出

### 6.4 风险提示

- **无成交量过滤**：买入信号未验证成交量，可能产生假突破
- **极高止损风险**：33.6% 止损意味着需要极高胜率或高盈亏比
- **75.2% ROI 难以达成**：首级目标过高可能导致长期持仓
- **交易频率**：5m 框架下，由于买入条件更严格，信号可能更少

## 七、策略优势与局限

### ✅ 优势

1. **更严格的买入信号**：CMO 连续3期确认，大幅降低假信号概率
2. **双重卖出机制**：布林带上轨 + CMO 回落，卖出更灵活
3. **动量衰减检测**：新增 CMO 下穿 -35 卖出条件，能在动量减弱时及时退出
4. **极高 ROI 目标**：75.2% 目标收益，适合趋势强行情
5. **宽松止损**：33.6% 止损配合极高 ROI，给予价格充分波动空间
6. **追踪止损保护**：自动锁定利润，避免回吐

### ⚠️ 局限

1. **参数敏感**：CMO 周期（50）和布林带参数（25, 3.5）对结果影响较大
2. **75.2% ROI 过高**：首级目标可能难以在短期内达成，导致持仓时间过长
3. **33.6% 高止损**：需要极高胜率或高盈亏比才能盈利
4. **无趋势过滤**：策略没有均线趋势确认，可能逆势交易
5. **无成交量验证**：未使用成交量过滤信号
6. **不适合震荡市场**：高 ROI 目标在震荡市中难以实现

## 九、适用市场环境详解

### 9.1 策略核心逻辑

Chandemtwo 是一个**增强型动量突破策略**，其核心逻辑包含三个层面：

1. **动量增强层**：利用 CMO 连续3期确认捕捉动量从空转多的转折点
2. **动量衰减层**：利用 CMO 下穿 -35 检测动量衰减，及时退出
3. **价格极端层**：利用布林带上轨识别价格极端，触发卖出

| 首级 ROI | 28.4% | 75.2% |
| 止损 | -28% | -33.6% |
| 追踪止损启动 | 1.013% | 1.523% |
| 追踪止损触发 | 10.858% | 10.329% |

**结论**：Chandemtwo 是 Chandem 的激进版本，买入更严格，卖出更灵活，收益目标更高。

## 十、重要提醒：复杂性的代价

### 10.1 学习成本

- **指标理解**：需要理解 CMO 和布林带的含义及计算方法
- **参数敏感度**：50 周期 CMO 和 25 周期 3.5σ 布林带需要根据市场调整
- **信号频率**：5m 框架，但由于买入条件更严格，信号可能比 Chandem 少
- **持仓时间**：75.2% ROI 目标可能导致持仓时间较长

|-----------|---------|---------|

### 10.3 回测与实盘的差异

- **滑点影响**：5m 框架对滑点有一定敏感性
- **信号延迟**：CMO 计算需要一定历史数据
- **流动性风险**：使用典型价计算布林带，与收盘价略有差异
- **ROI 达成率**：75.2% 首级目标在回测中可能显示高收益，但实盘中难以达成

### 10.4 手动交易者建议

4. 观察布林带位置，价格接近上轨时准备卖出
5. 结合趋势均线判断，避免逆势交易

## 十一、总结

**Chandemtwo** 是一个**增强型动量突破交易策略**，相比 Chandem 进行了以下关键改进：

1. **更严格的买入信号**：CMO 连续3期确认上穿，大幅降低假信号概率
2. **新增 CMO 回落卖出**：CMO 下穿 -35 时触发卖出，能在动量衰减时及时退出

对于量化交易者而言，Chandemtwo 适合**趋势行情中追求高额盈利**的交易者，但需要关注：

- 75.2% ROI 目标过高可能导致长期持仓
- 33.6% 止损意味着需要极高胜率或高盈亏比
- 无趋势过滤可能产生的逆势交易

## 一、策略概览

Simple 是一个基于《The Simple Strategy》一书的趋势跟踪策略，由 Gert Wohlgemuth 开发。该策略的核心思路非常简洁：利用 MACD 判断趋势方向，结合布林带确认趋势强度，用 RSI 作为入场过滤器，形成一套简单但完整的交易系统。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 1 个买入信号，MACD+布林带+RSI 三重确认 |
| **卖出条件** | 1 个卖出信号，RSI 超买退出 |
| **保护机制** | 固定止损 + 固定止盈 |
| **时间框架** | 5 分钟 (5m) |
| **依赖库** | talib, qtpylib |

## 三、买入条件详解

### 3.1 唯一买入信号

策略采用单信号入场设计，逻辑清晰：

```python
# 买入信号
(
    (dataframe['macd'] > 0) &                              # MACD 在零轴上方
    (dataframe['macd'] > dataframe['macdsignal']) &        # MACD 上穿信号线
    (dataframe['bb_upperband'] > dataframe['bb_upperband'].shift(1)) &  # 布林带上轨向上
    (dataframe['rsi'] > 70)                                # RSI 大于 70（强势区域）
)
```

**条件拆解**：

| 条件 | 技术含义 | 逻辑说明 |
|------|---------|---------|
| MACD > 0 | 趋势确认 | 价格在均线上方，多头趋势确立 |
| MACD > Signal | 动量确认 | MACD 线上穿信号线，动能转强 |
| BB Upper 向上 | 波动扩张 | 布林带上轨向上，价格突破上沿 |
| RSI > 70 | 超买区域 | 价格进入强势区间 |

### 3.2 买入逻辑分析

这是一个典型的**趋势突破策略**：
1. **MACD > 0**：确认多头趋势，价格处于均线支撑之上
2. **MACD 上穿信号线**：等待 MACD 金叉确认，避免假突破
3. **布林带上轨向上**：价格突破布林带，波动率扩张
4. **RSI > 70**：虽然处于超买区域，但在强趋势中，超买可以更超买

## 四、卖出逻辑详解

### 4.1 卖出信号

```python
# 卖出信号
(dataframe['rsi'] > 80)
```

**设计思路**：
- 当 RSI 达到 80 以上时触发卖出
- 这是一种"极度过热"退出机制
- 在 70-80 之间持仓，让利润奔跑

### 4.2 卖出逻辑特点

| 特点 | 说明 |
|------|------|
| **简单直接** | 仅依赖 RSI 单一指标 |
| **利润空间** | RSI 从 70 到 80 通常有一定涨幅 |
| **风险控制** | 避免过度追高，及时止盈 |

## 五、技术指标体系

### 5.1 核心指标

| 指标类别 | 具体指标 | 参数 | 用途 |
|---------|---------|------|------|
| 趋势指标 | MACD | 默认参数 | 趋势方向判断、动量确认 |
| 动量指标 | RSI | 周期 7 | 入场过滤、出场信号 |
| 波动指标 | 布林带 | 周期 12，标准差 2 | 波动率扩张确认 |

### 5.2 指标计算

```python
# MACD 指标
macd = ta.MACD(dataframe)
dataframe['macd'] = macd['macd']
dataframe['macdsignal'] = macd['macdsignal']
dataframe['macdhist'] = macd['macdhist']

# RSI 指标（周期 7，较短）
dataframe['rsi'] = ta.RSI(dataframe, timeperiod=7)

# 布林带（周期 12，标准差 2）
bollinger = qtpylib.bollinger_bands(dataframe['close'], window=12, stds=2)
dataframe['bb_lowerband'] = bollinger['lower']
dataframe['bb_upperband'] = bollinger['upper']
dataframe['bb_middleband'] = bollinger['mid']
```

## 六、风险管理特色

### 6.1 固定止盈止损

| 参数 | 设置值 | 说明 |
|------|--------|------|
| 止盈 | 1% | 快速锁定利润 |
| 止损 | 25% | 较宽的止损空间 |

**特点**：
- 止盈非常激进，1% 即退
- 止损相对宽松，避免被频繁止损
- 这种设计适合高胜率、快进快出的交易风格

### 6.2 无追踪止损

策略未配置追踪止损（trailing_stop），采用固定止盈止损机制，逻辑简单清晰。

## 七、策略优势与局限

### ✅ 优势

1. **逻辑简单**：买入和卖出条件清晰明确，易于理解和调试
2. **参数少**：仅依赖 3 个核心指标，过拟合风险较低
3. **执行快速**：计算量小，适合高频交易场景
4. **经典策略**：基于出版的交易策略书籍，有理论基础

### ⚠️ 局限

1. **止损过宽**：25% 的止损可能导致较大回撤
2. **止盈过早**：1% 止盈可能错过大趋势行情
3. **RSI 70 入场**：在超买区域入场，存在回调风险
4. **无追踪止损**：无法锁定浮盈，可能回吐利润

## 九、适用市场环境详解

Simple 策略是一个典型的**短线趋势突破策略**。基于其代码架构和设计理念，它最适合 **强趋势市场**，而在震荡市场中表现不佳。

### 9.1 策略核心逻辑

- **顺势而为**：MACD > 0 确认多头趋势
- **动量确认**：MACD 金叉验证动能
- **突破入场**：布林带上轨向上确认突破
- **极端持仓**：RSI > 70 持仓，80 以上退出

### 9.2 不同市场环境表现

| 市场类型 | 表现评级 | 原因分析 |
| :--- | :--- | :--- |
| 📈 强趋势市场 | ⭐⭐⭐⭐☆ | RSI 超买可以更超买，顺势而为效果好 |
| 🔄 震荡市场 | ⭐⭐☆☆☆ | RSI 70-80 区间反复穿越，易被止损 |
| 📉 下跌趋势 | ⭐☆☆☆☆ | 买入条件难以触发，可能踏空或逆势 |
| ⚡️ 高波动市场 | ⭐⭐⭐☆☆ | 宽止损可能救场，但风险较大 |

1. 观察 MACD 是否在零轴上方
2. 等待 MACD 金叉确认
3. 确认布林带上轨向上
4. RSI 突破 70 后入场
5. RSI 达到 80 或利润 1% 后退出

## 十一、总结

**Simple** 是一个名副其实的"简单"策略。它的核心价值在于：

1. **极简设计**：仅用 3 个指标构建完整交易系统
2. **逻辑清晰**：买入卖出条件明确，无歧义
3. **易于优化**：参数少，优化空间明确

对于量化交易者而言，Simple 策略是一个很好的入门选择，也可以作为复杂策略的基础框架进行扩展。但需要注意其止损过宽、止盈过早的问题，建议根据实际市场环境调整参数。

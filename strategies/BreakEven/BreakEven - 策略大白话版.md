# BreakEven 策略大白话版

## 一、这策略是个啥？

**BreakEven**，中文可以叫"保本策略"或者"快速平仓策略"。

但说实话，这个名字有点误导——它并不是帮你"赚回本钱"的策略，而是一个**专门用来"快速把仓位移除"的工具。

想象一下这种情况：你正在交易，突然收到风声说市场可能要变天，或者你只是想把手上的单子赶紧处理掉去干别的——这时候 BreakEven 就是你的好帮手。

**一句话总结：这不是一个用来"买卖赚钱"的策略，而是一个用来"快速清仓"的工具。**

---

## 二、核心配置

这个策略的配置非常简单，就三个数字：

```python
minimal_roi = {
    "0": 0.01,      # 赚1%就卖
    "10": 0         # 持有10分钟后，不管赚赔都卖
}

stoploss = -0.05   # 赔5%就止损
```

| 参数 | 值 | 意思是 |
|------|-----|--------|
| 0: 0.01 | 1% | 只要你持仓开始后赚超过1%，立刻卖出 |
| 10: 0 | 10分钟 | 持有10分钟后，不管赚还是赔，都全部卖出 |
| stoploss | -5% | 如果赔超过5%，也卖 |

### 三种模式随你选

| 模式 | 配置 | 效果 |
|------|------|------|
| 保守模式 | 1%止盈 + 10分钟强制 | 赚1%就跑，10分钟到了也跑 |
| 激进模式 | 0%止盈 | 只要不赔钱就卖 |
| 暴力模式 | -1% | 强制全部卖出，不管盈亏 |

## 三、买入条件

**木有。**

这个策略根本**不产生买入信号**。

代码是这样的：

```python
def populate_entry_trend(self, dataframe, metadata):
    # 空的！没有任何买入条件
    dataframe.loc[(), 'buy'] = 0
    return dataframe
```

开发者说了：

> "有时候我就想赶紧把机器人停了，不想让仓位继续漂着。"

所以这个策略的定位很明确：**它不是用来开仓的，而是用来清仓的。**

## 四、保护机制

虽然策略本身很简单，但它的保护机制设计得挺巧妙的：

### 4.1 止盈保护：1%就跑

```
持仓 → 只要赚超过1% → 立刻卖出落袋
```

这叫什么？这叫**"见好就收"**。

不管后面是涨是跌，我只赚这1%就满足了。不贪心，就不会栽跟头。

### 4.2 时间保护：10分钟强制平仓

```
持仓 → 10分钟到了 → 不管赚赔都卖
```

这招太狠了，但也太有效了。

你想啊，如果你一直持有，可能会：
- 赚了的单子又赔回去（从盈利变亏损）
- 亏损的单子越亏越多
- 一直拿着不知道什么时候是个头

现在好了，10分钟到点就走，不纠结。

### 4.3 止损保护：赔5%就割

```
持仓 → 赔了5% → 触发止损卖出
```

这是最后的保险绳，防止真的跌妈不认。

---

## 五、卖出逻辑

这个策略的卖出是**全自动**的，完全不用你操心：

1. **情况一**：持仓赚钱了，赚超过1% → 自动卖出
2. **情况二**：持仓满10分钟了 → 自动卖出
3. **情况三**：持仓赔超过5%了 → 止损卖出

就这三种情况，清晰明了。

你不需要天天盯着盘面，策略会自动帮你处理。

## 七、适用场景

### 7.1 场景一：组合使用

先用你的主策略（比如趋势策略）开仓，等需要平仓的时候，切换到 BreakEven。

```
主策略开仓 → 市场有风险 → 切换BreakEven平仓
```

### 7.2 场景二：临时避险

突然收到什么风声，或者看到大盘不对劲，想赶紧跑路：

```
持有仓位 → 感觉不对 → 用BreakEven快速清仓
```

### 7.3 场景三：策略切换

从A策略换到B策略，先用 BreakEven 清空所有仓位：

```
策略A持仓 → 切换到BreakEven → 清仓 → 切换到策略B
```

### 7.4 场景四：资金回收

急需用钱，想把币变成钱：

```
有持仓 → 切换BreakEven → 全部变成U
```

## 十一、彩蛋

你知道开发者为什么设计这个策略吗？

> 有时候我想赶紧把机器人停了，但不想让持仓继续漂着。
> 
> 我可以 "/stopbuy" 然后等机器人根据规则平仓（等盈利、等止损...），但这通常需要等很久...
> 
> 我更想把所有已经盈利的仓位都平掉，避免亏损。

**所以这个策略的诞生，纯粹是因为：等不及了，想赶紧跑！**

这可能就是程序员的"急性子"吧 😄

---

## 十二、最后的最后

用 BreakEven 策略之前，你必须明白：

1. **它不是主策略**：不能单独用来开仓交易
2. **它是工具**：就像扳手一样，是用来完成特定任务的
3. **配合使用**：最好和你其他策略组合起来用
4. **注意成本**：频繁卖出可能会产生不少手续费

**把它当作你交易工具箱里的一把"瑞士军刀"，需要的时候拿出来用用，不需要的时候就放着。**

再说一次，这个策略有风险：

| 风险 | 说明 |

| ❌ 频繁交易 | 可能会产生很多手续费 |

| ❌ 不适合长线 | 10分钟就强制平仓了 |

**记住：BreakEven 是"跑路神器"，不是"赚钱神器"。**

用它来保护你的资产，而不是用它来盈利。

# Divergences 策略解读

## 一、策略概述

Divergences 策略是一款基于价格背离原理的技术分析交易策略，其核心理念源自经典技术分析理论——当价格走势与动量指标出现背离时，往往预示着趋势即将反转。该策略巧妙地将价格形态识别与 RSI 相对强弱指标相结合，在市场出现潜在反转信号时精准捕捉交易机会。

背离交易是技术分析领域中最具前瞻性的分析方法之一。与追涨杀跌的趋势跟踪策略不同，背离策略试图在趋势即将结束的临界点进场，具有"提前布局、风险可控"的显著特点。Divergences 策略正是对这一经典交易理念的系统化实现，通过严格的条件筛选和多重过滤机制，在捕捉反转机会的同时有效控制风险。

该策略适用于加密货币等高波动性市场，时间周期设定为 1 小时级别，既避免了短周期的噪音干扰，又能在相对合理的响应时间内捕捉交易信号。策略采用追踪止损机制，确保在趋势反转时及时锁定利润，体现了"截断亏损、让利润奔跑"的经典交易智慧。

## 二、核心理论依据

### 2.1 背离原理

背离（Divergence）是技术分析中的核心概念，指价格走势与技术指标走势出现方向不一致的现象。根据物理学中的动量守恒定律类比，当价格持续上涨但上涨动能在衰减，或价格持续下跌但下跌动能在减弱时，往往预示着趋势即将发生转变。

在 Divergences 策略中，背离的定义基于价格形态的局部极值识别。策略采用五根 K 线的形态组合来识别潜在的背离信号：

**看涨背离形态**：
```
价格形态示意：
      - 
  - -   - -
  4 3 2 1 0  (K线位置编号)
```
在第 2 根 K 线位置形成局部最低点，该点的收盘价同时低于前后相邻 K 线（第 1 和第 3 根）的收盘价，且第 4 根 K 线收盘价高于第 2 根。这种形态暗示价格已经形成了一个局部底部，可能即将向上反转。

**看跌背离形态**：
```
价格形态示意：
  - -   - -
      - 
  4 3 2 1 0  (K线位置编号)
```
在第 2 根 K 线位置形成局部最高点，该点的收盘价同时高于前后相邻 K 线的收盘价，且第 4 根 K 线收盘价低于第 2 根。这种形态暗示价格已经形成了一个局部顶部，可能即将向下反转。

### 2.2 RSI 超卖过滤

相对强弱指标（RSI）是衡量价格动量强弱的经典指标，取值范围为 0-100。RSI 低于 30 通常被视为超卖区域，表明价格下跌过度，可能存在反弹机会。

Divergences 策略采用更为保守的 RSI 阈值设定，要求 RSI 必须小于等于 40 才能触发买入信号。这一设定避免了在 RSI 尚未充分释放下跌动能时过早进场的问题。相对于传统的 30 阈值，40 的设定使得策略能够在更多潜在反转点位进场，同时 RSI 仍处于相对低位，保留了反弹空间。

### 2.3 多重时间框架验证

虽然策略主体运行在 1 小时周期，但通过引入 24 根 K 线（约 24 小时）的成交量均值和 68 根 K 线（约 68 小时）的价格均值，策略隐性地引入了更高时间框架的市场背景信息。这种多重时间框架的思考方式，确保交易信号与更大级别的市场趋势保持一致。

## 三、买入条件分析

### 3.1 入场信号组合

Divergences 策略的买入条件极为精简，仅包含两个核心条件的组合：

```
买入条件 = (RSI <= 40) AND (看涨背离形态成立)
```

**条件一：RSI <= 40**
- 当前 RSI 值必须小于或等于 40
- 确保市场处于相对超卖状态
- 为价格反弹提供动能基础

**条件二：看涨背离形态**
- 必须满足五根 K 线的形态组合条件
- 代码逻辑：
  ```python
  dataframe['bullish_div'] = (
      (dataframe['close'].shift(4) > dataframe['close'].shift(2)) &
      (dataframe['close'].shift(3) > dataframe['close'].shift(2)) &
      (dataframe['close'].shift(2) < dataframe['close'].shift(1)) &
      (dataframe['close'].shift(2) < dataframe['close'])
  )
  ```
- 形态解读：第 2 根 K 线（相对当前位置向前推 2 根）形成局部最低点

### 3.2 入场时机选择

策略采用即时入场模式，当条件满足时立即开仓。这种设计基于以下考量：

1. **信号时效性**：背离形态本身就是反转预警信号，及时入场才能最大化收益空间
2. **风险前置控制**：通过严格的条件筛选，确保信号质量
3. **简化决策流程**：避免过度优化导致的曲线拟合问题

### 3.3 信号过滤逻辑

虽然买入条件看似简单，但实际上蕴含了多层过滤：

- **价格形态过滤**：五根 K 线的形态要求确保不是随机波动
- **动量过滤**：RSI <= 40 确保下跌动能已经充分释放
- **位置过滤**：形态中的第 2 根 K 线作为锚定点，确保信号的可追溯性

## 四、卖出条件分析

### 4.1 出场信号

Divergences 策略的卖出条件同样简洁明了：

```
卖出条件 = 看跌背离形态成立
```

看跌背离形态的代码实现：
```python
dataframe['bearish_div'] = (
    (dataframe['close'].shift(4) < dataframe['close'].shift(2)) &
    (dataframe['close'].shift(3) < dataframe['close'].shift(2)) &
    (dataframe['close'].shift(2) > dataframe['close'].shift(1)) &
    (dataframe['close'].shift(2) > dataframe['close'])
)
```

形态解读：第 2 根 K 线（相对当前位置向前推 2 根）形成局部最高点，收盘价高于前后相邻 K 线，暗示价格可能即将下跌。

### 4.2 卖出逻辑特点

值得注意的是，策略的卖出信号设计存在一些值得探讨的特点：

1. **独立卖出信号**：卖出信号独立于买入信号，不考虑持仓状态
2. **无条件卖出**：只要出现看跌背离，就会触发卖出信号
3. **潜在风险**：在上涨趋势中可能出现频繁的虚假卖出信号

**建议改进方向**：
- 可增加持仓利润检查：仅在盈利时才执行卖出
- 可增加趋势过滤：仅在上涨趋势出现反转信号时卖出
- 可结合其他指标：如 MACD 死叉确认

### 4.3 盈利保护机制

策略设置了 `sell_profit_only = True`，这意味着只有在持仓盈利的情况下才会响应卖出信号。这是一个重要的风控措施，避免在亏损时被震荡出局。

## 五、风险管理机制

### 5.1 止损设置

Divergences 策略采用固定百分比止损：

```
止损比例：-10%
```

这意味着当持仓亏损达到 10% 时，策略会自动平仓止损。这一设置的特点：

- **固定比例**：适用于所有交易对和市场环境
- **中等宽松**：10% 的止损空间对于加密货币市场而言相对宽松，给予价格足够的波动空间
- **风险可控**：单笔最大亏损明确锁定在 10%

### 5.2 追踪止损机制

策略启用了追踪止损功能，这是本策略风险管理的核心亮点：

```python
trailing_stop = True
trailing_stop_positive = 0.05
trailing_stop_positive_offset = 0.2
trailing_only_offset_is_reached = True
```

**参数解读**：

| 参数 | 数值 | 含义 |
|------|------|------|
| trailing_stop | True | 启用追踪止损 |
| trailing_stop_positive | 0.05 | 追踪止损回撤比例为 5% |
| trailing_stop_positive_offset | 0.20 | 利润达到 20% 后激活追踪止损 |
| trailing_only_offset_is_reached | True | 仅在利润达标后才启用追踪止损 |

**运作机制**：

1. **等待阶段**：利润未达到 20% 前，不启用追踪止损
2. **激活阶段**：利润达到 20% 后，追踪止损被激活
3. **执行阶段**：追踪止损线设置为最高价的 -5%

**案例演示**：
假设买入价格为 100 USDT：

| 最高价 | 利润率 | 止损价位 | 说明 |
|--------|--------|----------|------|
| 100 | 0% | 90 | 固定止损 |
| 110 | 10% | 90 | 固定止损，未达标 |
| 120 | 20% | 90 | 达标，追踪止损激活 |
| 130 | 30% | 123.5 | 追踪止损上移 |
| 140 | 40% | 133 | 追踪止损继续上移 |
| 回落到 135 | 35% | 133 | 触发追踪止损，平仓 |

最终实现 33% 的实际利润，而非理论上的 40%。

### 5.3 止盈策略

策略采用了较为宽松的 ROI 设置：

```python
minimal_roi = {
    "0": 1  # 100% 利润目标
}
```

这意味着策略不会因为达到固定利润目标而主动平仓，而是依赖追踪止损机制来实现利润锁定。这种设计的优势在于：

1. **让利润奔跑**：不人为限制盈利空间
2. **趋势跟随**：顺应趋势让利润最大化
3. **简化决策**：减少参数优化负担

## 六、辅助指标体系

### 6.1 核心交易指标

**RSI（相对强弱指数）**
- 周期：默认 14
- 用途：入场过滤条件（RSI <= 40）
- 特点：作为主要动量指标

**MACD（移动平均收敛发散）**
- 组成：MACD 线、信号线、柱状图
- 用途：辅助判断趋势方向
- 可视化：在图表子图中显示

**CCI（商品通道指数）**
- 周期设置：170（长周期）和 34（短周期）
- 用途：识别超买超卖区域
- 特点：双周期组合提供多时间框架视角

### 6.2 趋势判断指标

**EMA 指数移动平均线**
```python
EMA 周期：3, 5, 10, 21, 50, 100, 200
```
- 短期：EMA3, EMA5（快速反应）
- 中期：EMA10, EMA21（主趋势）
- 长期：EMA50, EMA100, EMA200（大趋势）

**TEMA（三重指数移动平均）**
- 周期：9
- 特点：比 EMA 响应更快，减少滞后性

**SAR（抛物线转向）**
- 用途：追踪止损参考
- 特点：自动调整止损位

### 6.3 波动性指标

**布林带（Bollinger Bands）**
```python
周期：20
标准差：2
```
- 上轨、中轨、下轨
- bb_percent：价格在布林带中的位置
- bb_width：布林带宽度（波动性指标）

### 6.4 其他辅助指标

| 指标 | 说明 |
|------|------|
| ADX | 趋势强度指标 |
| MFI | 资金流量指标 |
| Fast K/D | 快速随机指标 |
| HT Sine | 希尔伯特变换正弦波（周期指标）|

## 七、时间框架与参数配置

### 7.1 主时间框架

```python
timeframe = '1h'
```

策略运行在 1 小时周期，这一设置的意义：

1. **信号质量**：相比分钟级别，小时级别信号更可靠
2. **噪音过滤**：减少市场短期波动的干扰
3. **响应速度**：相比日线级别，小时级别响应更及时
4. **交易频率**：适中的交易频率，避免过度交易

### 7.2 启动周期设置

```python
startup_candle_count = 30
```

策略需要至少 30 根 K 线的数据才能开始产生有效信号。这确保：

- RSI 计算的准确性
- 移动平均线的稳定性
- 形态识别的可靠性

### 7.3 订单配置

```python
order_types = {
    'buy': 'limit',      # 限价买入
    'sell': 'limit',     # 限价卖出
    'stoploss': 'market' # 市价止损
}

order_time_in_force = {
    'buy': 'gtc',   # Good Till Cancel
    'sell': 'gtc'   # Good Till Cancel
}
```

订单类型说明：
- **限价买卖**：确保成交价格不劣于设定价格
- **市价止损**：止损时优先执行速度而非价格
- **GTC 有效期**：订单持续有效直到成交或取消

## 八、策略优劣势分析

### 8.1 策略优势

**1. 理论基础扎实**
- 背离原理是经过市场验证的经典理论
- RSI 作为过滤条件，提高信号可靠性
- 多重指标辅助判断，增加决策依据

**2. 逻辑简洁明了**
- 入场条件清晰：RSI 超卖 + 看涨背离
- 出场条件明确：看跌背离
- 代码可读性强，易于理解和维护

**3. 风险管理完善**
- 10% 固定止损保护本金
- 追踪止损机制锁定利润
- 盈利卖出保护机制

**4. 适用性广泛**
- 不依赖特定交易对
- 参数设置相对稳定
- 可适应不同市场环境

### 8.2 潜在风险

**1. 震荡市场风险**
- 横盘震荡时可能频繁触发假信号
- 背离形态在震荡市容易失效
- 可能造成连续小亏损

**2. 趋势市场风险**
- 在强趋势中逆势交易
- 背离信号可能多次失败
- 错过主趋势行情

**3. 信号频率问题**
- 卖出信号可能过于频繁
- 无趋势过滤机制
- 可能过早离场

**4. 参数敏感性**
- RSI 阈值设定可能不适用于所有市场
- 背离形态识别标准固定
- 未考虑不同币种特性

### 8.3 改进建议

**1. 趋势过滤**
```python
# 建议增加趋势判断
(dataframe['ema21'] > dataframe['ema50'])  # 上升趋势中只做多
```

**2. 多时间框架确认**
- 可增加 4 小时或日线级别的趋势确认
- 避免在逆大级别趋势时交易

**3. 动态参数**
- 根据市场波动性动态调整 RSI 阈值
- 根据币种特性优化参数

**4. 成交量确认**
- 可增加成交量验证
- 确保反转有足够的资金支持

## 九、回测建议与注意事项

### 9.1 回测配置建议

**时间范围**
- 建议回测周期：至少 6 个月以上
- 涵盖牛市、熊市、震荡市等不同市场环境
- 避免仅使用单一市场环境数据

**交易对选择**
- 选择流动性较好的主流币种
- 避免流动性差的小币种
- 考虑交易费用对收益的影响

**参数设置**
- 初期使用默认参数进行基准测试
- 后期可针对特定币种优化
- 注意避免过度拟合

### 9.2 关键监控指标

| 指标 | 说明 | 建议目标 |
|------|------|----------|
| 年化收益率 | 整体盈利能力 | > 30% |
| 最大回撤 | 风险水平 | < 30% |
| 夏普比率 | 风险调整收益 | > 1.0 |
| 胜率 | 盈利交易占比 | > 40% |
| 盈亏比 | 平均盈利/平均亏损 | > 1.5 |
| 交易次数 | 信号频率 | 适中 |

### 9.3 实盘注意事项

**1. 逐步上线**
- 先在模拟环境充分测试
- 小仓位实盘验证
- 逐步增加仓位

**2. 风险控制**
- 单策略仓位不超过总资金的 30%
- 设置最大日/周亏损限额
- 定期检查策略表现

**3. 市场监控**
- 关注市场重大事件
- 极端行情时暂停策略
- 保持对市场的敬畏

## 十一、总结

Divergences 策略是一款基于经典技术分析理论构建的趋势反转交易策略。通过对价格背离形态的识别，结合 RSI 动量指标的过滤，策略在市场潜在反转点进行交易，试图捕捉趋势拐点的交易机会。

策略的核心优势在于其理论基础的扎实性和逻辑的简洁性。背离交易是技术分析中经过长期验证的有效方法，而 RSI 指标则提供了额外的动量确认，两者结合形成了相对可靠的交易信号体系。追踪止损机制的设计更是体现了"让利润奔跑"的经典交易智慧。

然而，任何策略都有其局限性。Divergences 策略在强趋势行情中可能表现欠佳，震荡市场中也可能产生较多假信号。建议使用者在充分理解策略逻辑的基础上，结合自身的风险承受能力和市场判断，对策略进行适当的调整和优化。

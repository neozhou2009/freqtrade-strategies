# Divergences 策略大白话版

## 一、这策略是干嘛的？

你好！今天我们来聊聊一个叫 Divergences（背离）的交易策略。这名字听着挺高大上，其实原理特别简单——就是找"价格骗人"的时候下手。

什么叫价格骗人？举个例子：比如一个币价格一直在涨，涨涨涨，但是呢，它的"劲儿"其实在变小。这就像一个人跑步，虽然还在往前跑，但明显跑不动了，停下来是迟早的事。这时候我们就要准备反手做空。

反过来也一样：价格一直在跌，但下跌的"劲儿"越来越小，那反弹可能就要来了，这时候我们就要准备抄底。

这个策略就是用电脑程序自动识别这些"劲头变了"的时刻，帮我们抓住反转的机会。

---

## 二、什么意思？"背离"到底是个啥？

咱们用大白话说说"背离"这个概念。

想象你在看一个人爬楼梯：
- 正常情况：上一层楼梯，累一点；再上一层，再累一点。这时候体力消耗和爬楼高度是"一致"的。
- 背离情况：还在继续往上爬，但是越爬越轻松，或者越爬越吃力却还在爬。这就叫"背离"——体力和表现不一致。

换到币圈：
- **正常上涨**：价格上涨 + RSI 指标也涨 = 动能充足，还要涨
- **背离上涨**：价格还在涨 + RSI 指标已经不涨了 = 动能不足，可能要跌

这个策略就是盯着这种"不一致"的情况。当价格创新低，但 RSI 不创新低，说明卖家的劲头用完了，买家可能要反击了。这就是我们要抓住的入场机会！

## 三、策略具体怎么干活？

### 第一步：盯着价格形态

策略用五根 K 线来判断"底"在哪里。不是五毛钱的那个五毛，是五根蜡烛图的意思。

**看涨形态（找底部）**：
```
画个图你看：
      - 
  - -   - -
  编号：4 3 2 1 0
  
第 2 根 K 线是最低点
```

用大白话说就是：往前数第 2 根 K 线是个坑，比前后的都低，而且更早的那根（第 4 根）比这个坑高。这说明啥？说明价格曾经跌下去过，现在又有点往上走的迹象。

**看跌形态（找顶部）**：
```
画个图你看：
  - -   - -
      - 
  编号：4 3 2 1 0
  
第 2 根 K 线是最高点
```

用大白话说就是：往前数第 2 根 K 线是个顶，比前后的都高，而且更早的那根（第 4 根）比这个顶低。这说明啥？说明价格曾经涨上去过，现在有点往下掉的意思。

### 第二步：看 RSI 给不给力

光有价格形态还不够，还得看 RSI 指标确认一下。

RSI 就像个体力计，数值 0-100：
- 高于 70：这波涨得太猛了，有点虚
- 低于 30：这波跌得太狠了，该反弹了

策略用的门槛是 40，为啥不是 30？因为 40 更宽松一点，能抓到更多机会，同时 RSI 在这个位置还算是"不太高"，还有反弹空间。

**买入条件：** RSI ≤ 40 + 看到看涨形态 = 开多！

### 第三步：卖的时候怎么办？

策略的卖出条件很简单：看到看跌形态就卖。

但是有个保护措施：只有赚钱的时候才卖！如果你还在亏钱，就算看到看跌形态，策略也不会卖。这是为啥？因为怕你被震荡洗出去，亏着卖太心疼了。

## 四、止损怎么设？亏了怎么办？

策略设了三道防线保护你的钱：

### 第一道防线：固定止损 10%

简单粗暴，亏损达到 10% 就认输离场。这个比例在币圈算是比较宽容的，给价格一点"折腾"的空间，不会因为正常波动就被震出去。

### 第二道防线：追踪止损

这是策略的精华！啥叫追踪止损？就是止损价位会跟着利润往上跑，但不会往下掉。

举个例子：
- 你 100 块买的
- 涨到 120 块（利润 20%）——追踪止损激活！
- 涨到 150 块——止损跟着到 142.5 块（150 × 0.95）
- 涨到 200 块——止损跟着到 190 块
- 跌回 190 块——触发止损，卖出，赚 90 块！

如果用固定止损呢？可能 100 块买的，跌到 90 块就卖了，白白错过后面的大涨。

### 第三道防线：盈利保护

策略设置了 `sell_profit_only = True`，意思是只有在赚钱的时候才会响应卖出信号。这个机制能避免你被市场的小波动忽悠出去。

## 五、止盈怎么设？赚了什么时候走？

策略的止盈设计很有意思，它不设"赚到多少钱就跑"的硬性目标。

```python
minimal_roi = {"0": 1}  # 意思是利润达到 100% 才主动卖
```

但实际上，因为有追踪止损在，你不会等到 100%。通常涨到一定程度，价格回调就会触发追踪止损，帮你锁定利润。

这种设计的哲学是：**不要人为限制赚钱的上限，让利润自由奔跑！**

举个实际例子：
- 100 块买入
- 涨到 120，追踪止损激活，止损位在 114 块
- 继续涨到 180，止损位跟着到 171 块
- 开始回调，跌到 171，卖出
- 实际赚了 71%！

如果用固定止盈（比如赚 30% 就卖），你就只能赚 30 块，错过了后面的 41 块。

## 六、这个策略用了哪些指标？

策略用了一大堆指标，但核心就几个，其他的都是辅助参考：

### 核心指标

**RSI（相对强弱指数）**
- 这是最重要的！用来判断超买超卖
- 策略用 RSI ≤ 40 来确认买入时机

**MACD（移动平均收敛发散）**
- 经典的趋势指标
- 在这个策略里主要是辅助判断

### 辅助指标

**布林带**
- 上轨、下轨像两条边界线
- 价格碰到下轨可能要反弹

**EMA 均线（7 条！）**
- 从 3 周期到 200 周期都有
- 可以判断趋势方向：短期均线在上 = 上涨趋势

**CCI 指标（两个周期）**
- 170 周期和 34 周期
- 用来找超买超卖区域

**SAR 抛物线**
- 像个自动追踪止损
- 价格在上面 = 持仓，价格穿过去 = 可能要反转

还有好多其他的，但策略的买卖信号主要就靠 RSI 和价格形态，其他的都是"仅供参考"。

## 七、这个策略适合什么市场？

### 适合的市场

**1. 震荡市场**
价格上上下下，没有明确的大趋势。这时候背离策略最有效——在底部抄多，在顶部做空，来回吃波段。

**2. 趋势末端**
大趋势快结束的时候，背离信号经常能抓到反转点。比如牛市末期，价格还在涨，但 RSI 已经不涨了，策略会及时提示风险。

### 不太适合的市场

**1. 单边暴涨暴跌**
比如某个币一天涨 50%，这种极端行情背离信号会失效。因为价格动量太强了，你逆势做空肯定亏。

**2. 假突破频繁的市场**
价格老是假突破，突破以后又回来，这时候背离信号也容易被打脸。

**3. 流动性很差的小币**
成交量太小的币，指标会失真，背离信号也不可靠。

### 最佳使用场景

- 主流币种（BTC、ETH 等）
- 1 小时时间周期
- 市场波动适中，不是极端行情

## 八、代码是怎么写的？

咱们看看核心代码，我用大白话解释：

### 识别看涨背离

```python
dataframe['bullish_div'] = (
    (dataframe['close'].shift(4) > dataframe['close'].shift(2)) &  # 第4根比第2根高
    (dataframe['close'].shift(3) > dataframe['close'].shift(2)) &  # 第3根也比第2根高
    (dataframe['close'].shift(2) < dataframe['close'].shift(1)) &  # 第2根比第1根低
    (dataframe['close'].shift(2) < dataframe['close'])            # 第2根比当前低
)
```

翻译成人话：
- 找到一个"坑"（第 2 根 K 线最低）
- 这个坑比左右两边的 K 线都低
- 而且坑出现之前的价格（第 4 根）比坑高
- 这说明价格跌下去过，现在又回升了

### 识别看跌背离

```python
dataframe['bearish_div'] = (
    (dataframe['close'].shift(4) < dataframe['close'].shift(2)) &  # 第4根比第2根低
    (dataframe['close'].shift(3) < dataframe['close'].shift(2)) &  # 第3根也比第2根低
    (dataframe['close'].shift(2) > dataframe['close'].shift(1)) &  # 第2根比第1根高
    (dataframe['close'].shift(2) > dataframe['close'])            # 第2根比当前高
)
```

翻译成人话：
- 找到一个"顶"（第 2 根 K 线最高）
- 这个顶比左右两边的 K 线都高
- 而且顶出现之前的价格（第 4 根）比顶低
- 这说明价格涨上去过，现在在往下跌

### 买入信号

```python
dataframe.loc[
    ((dataframe['rsi'] <= 40) & (dataframe['bullish_div'])),
    'buy'
] = 1
```

翻译成人话：RSI 小于等于 40，而且看到看涨形态，那就买！

### 卖出信号

```python
dataframe.loc[
    (dataframe['bearish_div']),
    'sell'
] = 1
```

翻译成人话：看到看跌形态，那就卖！

简单吧？核心逻辑就这么几行代码。

## 九、这个策略有啥优点？

### 优点一：理论基础扎实

背离原理不是什么新发明，几十年前技术分析大师就在用了。这个策略把经典理论用代码实现了，靠谱！

### 优点二：逻辑简单清晰

你看代码就知道了，核心逻辑就几句。简单意味着什么？意味着容易理解、容易调试、不容易出 bug。

### 优点三：风控设计合理

- 10% 止损保护本金
- 追踪止损保护利润
- 盈利保护避免被洗盘

三道防线，层层保护。

### 优点四：不贪心

策略不设硬性的止盈目标，让利润自由跑。这才是赚钱的正确姿势！

### 优点五：通用性强

不管是 BTC 还是山寨币，不管是牛市还是熊市，策略都能用。不需要针对不同币种调太多参数。

## 十、这个策略有啥缺点？

### 缺点一：震荡市容易被骗

如果市场一直横盘震荡，价格忽上忽下，背离信号会频繁出现，可能造成连续小亏损。

### 缺点二：强趋势中会逆势

如果市场单边大涨或大跌，背离信号会失效。因为强势趋势的动量太强了，逆势交易就是找打。

### 缺点三：卖出信号可能太敏感

策略看到看跌形态就卖，但有时候只是小回调，后面还会继续涨。这可能导致过早离场。

### 缺点四：没有趋势过滤

策略没有判断"现在是大趋势还是震荡市"，而是无差别交易。如果能加上趋势判断，效果可能更好。

### 缺点五：参数相对固定

RSI 阈值固定在 40，形态识别也固定用 5 根 K 线。但不同币种、不同市场环境，最优参数可能不一样。

## 十一、能怎么改进？

### 改进一：加个趋势过滤

只在上涨趋势里做多，不在下跌趋势里做多。怎么判断趋势？可以看 EMA 均线：

```python
# 如果短期均线在长期均线之上，才算上涨趋势
(dataframe['ema21'] > dataframe['ema50'])
```

### 改进二：多时间框架确认

看 1 小时周期的信号之前，先看看 4 小时或日线是不是同一个方向。如果大周期是下跌趋势，那 1 小时的做多信号就别做了。

### 改进三：用成交量确认

背离信号出现的时候，如果成交量也在放大，说明有资金进场了，信号更可靠。

```python
(dataframe['volume'] > dataframe['mean24volume'])  # 成交量大于24小时均值
```

### 改进四：动态调整参数

根据市场波动性动态调整 RSI 阈值。波动大的时候放宽一点，波动小的时候收紧一点。

### 改进五：优化卖出逻辑

现在的卖出信号只看价格形态，可以增加一些确认条件：

```python
# 卖出条件更严格
(dataframe['bearish_div']) &  # 看跌形态
(dataframe['rsi'] > 60) &     # RSI 超买区
(dataframe['close'] > dataframe['ema21'])  # 价格在均线上方
```

## 十二、实盘怎么用？

### 第一步：回测验证

千万别直接上实盘！先跑历史数据测试：

1. 找至少 6 个月的历史数据
2. 包含牛市、熊市、震荡市
3. 看看策略表现怎么样
4. 重点看最大回撤和夏普比率

### 第二步：模拟盘测试

回测通过了，先在模拟盘跑：

1. 用模拟资金交易
2. 观察策略的实际表现
3. 确认没有 bug
4. 至少跑 1-2 个月

### 第三步：小仓位实盘

模拟盘表现不错，再上实盘：

1. 先用小资金（比如总仓位的 10-20%）
2. 设置好风控参数
3. 定期检查策略表现
4. 遇到极端行情可以暂停

### 第四步：持续监控

实盘运行后要持续监控：

1. 每周检查收益和回撤
2. 关注市场大事件
3. 必要时调整参数
4. 保持策略的稳定性

## 十三、总结一下

Divergences（背离）策略是一个简单但有效的趋势反转策略。它用最经典的背离原理——当价格走势和动量指标不一致时，往往预示着反转——来捕捉交易机会。

**核心逻辑三句话：**
1. 看到价格创新低但 RSI 不创新低 = 买
2. 看到价格创新高但 RSI 不创新高 = 卖
3. 用追踪止损保护利润

**适合谁用：**
- 有一定技术分析基础的人
- 希望在震荡市和趋势转折点获利的人
- 不想追涨杀跌，想抄底摸顶的人

**注意事项：**
- 不要在单边暴涨暴跌市场使用
- 回测和模拟盘必须做
- 小仓位开始，逐步加大
- 持续学习，持续改进

这个策略最大的价值在于，它把几十年前的经典理论用代码实现了，让你不用每天盯盘，电脑自动帮你找机会。但记住，任何策略都不是万能的，理解它的原理，知道它的适用场景，才能用好它！

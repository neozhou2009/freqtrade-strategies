# EMA50 策略：最经典的"均线突破"

> **外号**：均线突破王 / 简单粗暴  
> **职业**：价格上穿 EMA50 就买，下穿就卖  
> **时间框架**：5 分钟

---

## 一、这策略是个啥？

简单说，**EMA50** 就是：
- 价格上穿 50 周期指数移动平均线（EMA50）→ 买入
- 价格下穿 EMA50 → 卖出
- 就这么简单！

就像一个直男追女神：**她点头（价格上穿）就追，她摇头（价格下穿）就跑**，一点不纠结！😂

这是**最经典的趋势跟踪策略**，简单到没朋友！

---

## 二、核心配置：说白了就是"趋势跟随"

### 止盈规则（ROI 表）

```
立即出场（0分钟）     → 赚 27.8% 就跑！
39分钟后             → 赚 8.7% 就跑！
124分钟后            → 赚 3.8% 就跑！
135分钟后            → 保本退出
```

**翻译**：这策略鸡贼！一上来就要赚大钱（27.8%），等越久要求越低——典型的**趋势跟随**，抓大趋势！

### 止损规则

```
硬止损：-33.3%
追踪止损：启动点 17.2%，偏移 21.2%
```

**翻译**：-33.3% 止损非常宽松，给了足够空间！因为策略靠趋势吃饭，不会频繁交易。

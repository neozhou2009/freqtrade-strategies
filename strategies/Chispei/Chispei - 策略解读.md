## 一、策略概览

Chispei 是一个基于**移动平均线交叉**与**动量指标**结合的趋势跟踪策略。该策略设计简洁，通过13周期SMA与25周期SMA的交叉判断趋势方向，同时借助21周期动量指标(MOM)过滤假信号并确认入场时机。

策略核心逻辑：在下跌趋势的相对底部区域（MOM<15），当短期均线向上突破长期均线时入场；在上涨趋势结束（动量减弱 MOM<80）且均线死叉时退出。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 2个独立条件（AND关系） |
| **卖出条件** | 2个基础条件（AND关系） |
| **保护机制** | 无额外买入保护机制，纯技术信号 |
| **时间框架** | 4小时 (4h) |
| **依赖库** | talib, technical, numpy |

## 三、买入条件详解

### 3.1 买入条件逻辑

策略有**1组**买入条件，包含**2个**子条件（AND关系）：

#### 条件组合：动量底部 + 均线多头

```python
# 买入信号：动量超卖 + 均线金叉
(
    (dataframe['mom'] < 15) &          # 动量指标低于15（超卖区域）
    (dataframe['fastMA'] > dataframe['slowMA'])  # 13日均线 > 25日均线（多头排列）
)
```

| 子条件 | 指标 | 阈值 | 含义 |
|--------|------|------|------|
| 条件#1 | MOM (21) | < 15 | 动量处于相对低点，可能存在反弹机会 |
| 条件#2 | SMA (13/25) | 快线 > 慢线 | 短期均线向上突破长期均线，形成金叉 |

**满足条件**：两个条件同时满足时触发买入信号。

### 3.2 买入条件分析

| 条件组 | 条件编号 | 核心逻辑 | 信号强度 |
|-------|---------|---------|---------|
| 趋势反转 | #1 | MOM<15 表示市场处于超卖状态，存在反弹需求 | 适中 |
| 趋势确认 | #2 | 均线金叉确认趋势转多，提升信号可靠性 | 强 |

## 四、卖出逻辑详解

### 4.1 多层止盈系统

策略采用**分级止盈（ROI）机制**，根据持仓时间自动触发不同水平的止盈：

| 持仓时间 | 收益率 | 备注 |
|---------|--------|------|
| 0-20分钟 | 4% | 立即入场则触发最低止盈 |
| 20-30分钟 | 5% | 短持仓期止盈 |
| 30-60分钟 | 10% | 1小时内达10%止盈 |
| 60-120分钟 | 10% | 2小时内保持10%目标 |
| 120-2599分钟 | 7.9% | 中期持仓降低预期 |
| 2599-1836分钟 | 67.6% | 特殊时间窗口高收益 |
| 5127分钟+ | 0% | 强制平仓 |

**设计特点**：1836-2599分钟时间窗口存在异常高收益（67.6%），这可能是一个回测优化的结果，实盘需谨慎验证。

### 4.2 基础卖出信号

```python
# 卖出信号：动量高位回落 + 均线死叉
(
    (dataframe['mom'] < 80) &           # 动量低于80（从高位回落）
    (dataframe['fastMA'] < dataframe['slowMA'])  # 13日均线 < 25日均线（死叉）
)
```

| 子条件 | 指标 | 阈值 | 含义 |
|--------|------|------|------|
| 条件#1 | MOM (21) | < 80 | 动量从高点回落，市场动能减弱 |
| 条件#2 | SMA (13/25) | 快线 < 慢线 | 短期均线跌破长期均线，形成死叉 |

## 五、技术指标体系

### 5.1 核心指标

| 指标类别 | 具体指标 | 参数 | 用途 |
|---------|---------|------|------|
| 趋势指标 | SMA (Simple Moving Average) | 13周期 | 快速移动平均线，捕捉短期趋势 |
| 趋势指标 | SMA (Simple Moving Average) | 25周期 | 慢速移动平均线，确认长期趋势 |
| 动量指标 | MOM (Momentum) | 21周期 | 衡量价格变动速度，识别超买超卖 |

### 5.2 指标计算逻辑

```python
# 指标计算
dataframe['fastMA'] = ta.SMA(dataframe, timeperiod=13)   # 13日简单移动平均
dataframe['slowMA'] = ta.SMA(dataframe, timeperiod=25)   # 25日简单移动平均
dataframe['mom'] = ta.MOM(dataframe, timeperiod=21)      # 21日动量指标
```

**动量指标(MOM)说明**：
- MOM = 当前价格 - N日前价格
- MOM > 0：价格呈上涨趋势
- MOM < 0：价格呈下跌趋势
- MOM接近0：价格处于震荡或转折点

## 七、策略优势与局限

### ✅ 优势

1. **指标简洁高效**：仅使用3个技术指标，逻辑清晰，易于理解和优化
2. **多指标确认**：结合动量与均线两种指标，减少假信号干扰
3. **趋势跟踪能力强**：高止损设计让策略能够充分捕捉趋势行情
4. **时间框架适中**：4小时框架兼顾趋势判断与交易频率

### ⚠️ 局限

1. **高止损风险**：-32%的止损在震荡市场中可能导致较大亏损
2. **参数敏感**：MOM阈值（15/80）和均线周期（13/25）可能需要根据市场调整
3. **趋势反转滞后**：均线死叉通常发生在趋势反转后，卖出可能不够及时
4. **缺乏保护机制**：没有额外的买入保护（如成交量过滤、RSI确认等）

## 九、适用市场环境详解

Chispei 是一个**趋势跟踪型策略**，基于技术指标的交叉信号进行交易。它最适合**趋势明确、波动率适中的市场**，而在**低波动震荡市**中表现不佳。

### 9.1 策略核心逻辑

- **动量过滤**：MOM<15时入场，表明在下跌趋势的相对底部寻找反弹机会；MOM<80时出场，表明在上涨动能减弱时退出
- **均线确认**：通过SMA金叉/死叉确认趋势方向，避免被短期波动误导
- **让利润奔跑**：高止损设计允许策略持有仓位直至趋势结束

### 9.2 不同市场环境表现

| 📉 趋势下跌 | ⭐⭐⭐⭐ | 同样逻辑适用于做空，可捕捉下跌趋势 |
| 🔄 震荡市场 | ⭐⭐ | 均线频繁交叉产生假信号，高止损导致亏损 |
| ⚡️ 快速波动 | ⭐⭐⭐ | 4小时框架可能滞后，但高止损可保护本金 |

## 十、重要提醒：复杂性的代价

### 10.1 策略简洁性

Chispei 是一个**相对简洁**的策略，代码量小，仅包含：
- 3个技术指标计算
- 1个买入条件组合
- 1个卖出条件组合

这意味着：

| 差异点 | 影响 | 建议 |

| 流动性 | 大资金可能无法即时成交 | 分批建仓 |

### 10.3 手动交易者建议

# Ichimoku 策略：日本"一目均衡"的云端交易

> **外号**：云层大师 / 日本老法师  
> **职业**：趋势跟踪派 + 技术分析派  
> **时间框架**：5分钟

---

## 一、这策略是个啥？

**Ichimoku**（一目均衡表）是日本发明的**全能型技术分析工具**，就像一个"五星级酒店"——设施齐全，什么都有！

核心逻辑：
- 转折线上穿基准线 + 云层红色 → 买！
- 卖出条件？**没写！** 😅

---

## 二、核心配置：追踪止损是亮点

### 止盈规则

```
ROI = 100% （理论值，实际靠追踪止损）
```

**翻译**：设置得很高，实际上靠追踪止损出场 🎯

### 止损规则

```
-10% 硬止损
```

### 追踪止损 ⭐⭐⭐⭐⭐

```
盈利 > 2% 后启动追踪
回撤 1% 自动平仓
```

**翻译**：赚钱了别急着跑，让利润飞一会儿！🚀

---

## 三、一目均衡表：五根线的秘密

这策略有**五根核心线**，就像交响乐团的五个声部：

| 线条 | 名字 | 大白话 |
|-----|------|--------|
| **Tenkan** | 转折线 | "短期小鲜肉"（9周期） |
| **Kijun** | 基准线 | "中期老腊肉"（26周期） |
| **Senkou A** | 先行上线A | "云层上沿" |
| **Senkou B** | 先行上线B | "云层下沿" |
| **云层** | Cloud | "两线之间的区域" |

### 🎯 买入条件

```python
(tenkan昨天 < kijun昨天) & (tenkan今天 > kijun今天) & (云层是红色)
```

**大白话**：
> "短期线从下面突破中期线 + 之前云层是空的 → 买！"

**翻译成人话**：
- Tenkan > Kijun = "短期选手超过中期选手，势头起来了！"
- 红色云层 = "之前是下降趋势，现在可能要反转"

---

## 四、保护机制：靠追踪止损

| 保护类型 | 作用 |
|---------|------|
| 追踪止损 | 盈利 > 2% 后启用，回撤 1% 自动跑 |
| 硬止损 | 亏 10% 强制平仓 |

**评价**：虽然有追踪止损，但没有技术层面的保护，缺少灵魂 🚧

---

## 五、卖出逻辑：一个大坑！

### ⚠️ 严重问题

```python
# 卖出条件
dataframe.loc[(), "sell"] = 1  # 空的！
```

**这策略没有明确的卖出条件！**

### 实际怎么退出？

| 退出方式 | 怎么触发 |
|---------|---------|
| 追踪止损 | 盈利 > 2%，回撤 1% |
| 硬止损 | 亏 10% |
| 天知道 | 卖出不明确 |

**吐槽**：这就像买了个车没有刹车，太危险了！🚗💨

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **日本原装**：经过几十年市场验证的经典策略
2. **全面分析**：趋势、支撑、阻力一次性搞定
3. **云层可视化**：哪里是"坑"一眼看出
4. **追踪止损**：保护利润有一套

### ⚠️ 缺点（吐槽环节）

1. **卖出条件没写**：这是致命伤！
2. **参数固定**：9, 26, 52 不一定适合所有币
3. **学起来复杂**：五根线绕来绕去
4. **有滞后性**：等信号出来可能晚了
5. **震荡市不行**：横盘时会疯掉

## 七、云层怎么看？

```
     ┌─────────────┐  ← Senkou A (上沿)
     │    云层     │
     └─────────────┘  ← Senkou B (下沿)

价格在云层上面 = 强势上涨 ☀️
价格在云层下面 = 强势下跌 🌧️
价格在云层中间 = 震荡整理 ☁️
```

## 一、策略概览

**Ichimoku** 是一个基于日本经典技术分析工具"一目均衡表"（Ichimoku Cloud）的趋势跟踪策略。策略核心逻辑是利用 Tenkan-sen（转换线）和 Kijun-sen（基准线）的金叉死叉信号，配合云层（Kumo）判断趋势方向。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 1 个条件：TK 金叉 + 云层确认 |
| **卖出条件** | 无技术卖出，依赖追踪止损 |
| **保护机制** | 追踪止损 |
| **时间框架** | 5 分钟 |
| **依赖库** | technical (ichimoku 函数) |
| **特殊功能** | 一目均衡表完整实现 |

## 三、买入条件详解

### 3.1 买入逻辑

```python
# 买入条件
dataframe.loc[
    (
        (dataframe["tenkan"].shift(1) < dataframe["kijun"].shift(1))  # 前一根 K 线：Tenkan < Kijun
        & (dataframe["tenkan"] > dataframe["kijun"])                   # 当前 K 线：Tenkan > Kijun
        & (dataframe["cloud_red"] == True)                             # 在云层之上
    ),
    "buy",
] = 1
```

**逻辑解析**：
- **TK 金叉**：Tenkan-sen（转换线）从下方上穿 Kijun-sen（基准线）
- **云层确认**：价格在云层（Kumo）之上，确认上涨趋势
- **趋势跟踪**：仅在上涨趋势中做多

### 3.2 一目均衡表指标

```python
# 一目均衡表计算
ichi = ichimoku(dataframe)
dataframe["tenkan"] = ichi["tenkan_sen"]      # 转换线（9 周期）
dataframe["kijun"] = ichi["kijun_sen"]        # 基准线（26 周期）
dataframe["senkou_a"] = ichi["senkou_span_a"] # 先行带 A
dataframe["senkou_b"] = ichi["senkou_span_b"] # 先行带 B
dataframe["cloud_green"] = ichi["cloud_green"] # 云层绿色（上涨）
dataframe["cloud_red"] = ichi["cloud_red"]     # 云层红色（下跌）
```

**一目均衡表组件**：
- **转换线（Tenkan-sen）**：9 周期高低点中点
- **基准线（Kijun-sen）**：26 周期高低点中点
- **先行带 A（Senkou Span A）**：转换线和基准线中点，前移 26 周期
- **先行带 B（Senkou Span B）**：52 周期高低点中点，前移 26 周期
- **云层（Kumo）**：先行带 A 和 B 之间的区域

## 七、策略优势与局限

1. **经典指标**：一目均衡表是日本经典技术分析工具
2. **完整系统**：包含转换线、基准线、云层完整组件

3. **参数固定**：一目均衡表参数固定为 9/26/52
4. **迟行线未使用**：未使用 Chikou Span（迟行线）确认
5. **示例性质**：策略较简单，适合学习而非生产

## 一、这策略是个啥？

简单说，**Ichimoku** 就是一个：

- 用日本经典技术分析"一目均衡表"的趋势策略
- 靠转换线和基准线金叉找入场点
- 必须在云层之上才做多，云下不做空

就像一个老派的日本武士，讲究"顺势而为，云上战斗" 🗾

一目均衡表（Ichimoku Kinko Hyo）翻译过来就是"一目了然的均衡表"，日本人起名字就这么直接——看一眼就知道趋势在哪，不需要猜。

## 二、核心配置：说白了就是"追趋势，让利润飞"

### 止盈规则（ROI 表）

```python
minimal_roi = {"0": 1}  # 100% 利润退出
```

**翻译**：100% 利润才止盈？兄弟，这基本就是"我不管"，让追踪止损来干活。策略作者的意思很明确：**我不预测止盈点，趋势走多远我走多远。**

### 止损规则

```python
stoploss = -0.1  # -10% 硬止损

# 追踪止损
trailing_stop = True
trailing_stop_positive = 0.01           # 1% 追踪
trailing_stop_positive_offset = 0.02    # 2% 启动
trailing_only_offset_is_reached = True  # 利润达 2% 才启动
```

**翻译**：
- 亏 10% 就认怂（硬止损）
- 赚到 2% 之后，开始追踪止损
- 从最高点回撤 1%，就落袋为安

**大白话**：这止损逻辑就是"我不贪，但也不怕"。趋势来了就跟着走，趋势反转了就跑，典型的趋势跟踪打法。

## 三、1 个买入条件：简单直接

这策略的买入条件就 **1 个**，非常简单：

### 🎯 TK 金叉 + 云层确认

**核心逻辑**：转换线（Tenkan）从下方穿过基准线（Kijun），同时价格在云层之上。

```python
# 买入条件
(
    (dataframe["tenkan"].shift(1) < dataframe["kijun"].shift(1))  # 昨天：Tenkan < Kijun
    & (dataframe["tenkan"] > dataframe["kijun"])                  # 今天：Tenkan > Kijun
    & (dataframe["cloud_red"] == True)                            # 价格在云层之上
)
```

**大白话**：
> "转换线上穿基准线 = 短期趋势转强；价格在云层之上 = 长期趋势向上。两个条件同时满足，我就入场做多。"

就这么简单。没有复杂的条件组合，没有几十个参数，就是两个指标打个招呼，云层再点个头，齐活。

## 四、一目均衡表：五根线的禅意

Ichimoku 看起来复杂，其实就五根线：

| 指标 | 周期 | 计算方式 | 大白话 |
|------|------|---------|--------|
| **转换线（Tenkan-sen）** | 9 | 9 周期高低点中点 | "短期趋势线，反映最近 9 根 K 线的价格区间中心" |
| **基准线（Kijun-sen）** | 26 | 26 周期高低点中点 | "中期趋势线，反映最近 26 根 K 线的价格区间中心" |
| **先行带 A（Senkou Span A）** | 26 | (转换线 + 基准线) / 2，前移 26 根 | "云层的上边界（或下边界，取决于价格位置）" |
| **先行带 B（Senkou Span B）** | 26 | 52 周期高低点中点，前移 26 根 | "云层的下边界（或上边界）" |
| **迟行线（Chikou Span）** | - | 当前收盘价，后移 26 根 | "策略没用这根线，但它是确认信号的关键" |

**云层（Kumo）**：先行带 A 和 B 之间的区域。

- 云层向上（A > B）= 绿云 = 看涨
- 云层向下（A < B）= 红云 = 看跌

本策略用的是 `cloud_red`，意思是价格在云层之上（看涨状态）。

**大白话理解**：

想象云层就是一片"势力范围"：

- 价格在云层之上 = 牛市，多头占优
- 价格在云层之下 = 熊市，空头占优
- 价格在云层里面 = 混战，谁也不服谁

转换线和基准线就像两个侦察兵：

- 转换线跑得快（9 周期），反应敏捷
- 基准线走得稳（26 周期），代表主力方向

当转换线从下方穿过基准线 = "侦察兵追上主力了，一起往上冲！"

## 五、卖出逻辑：我不预测，让市场告诉我

### 5.1 无技术卖出信号

这策略最奇葩的地方：**没有技术卖出信号。**

```python
def populate_exit_trend(self, dataframe: DataFrame, metadata: dict) -> DataFrame:
    dataframe.loc[(), "sell"] = 1  # 始终允许卖出，但没有条件
    return dataframe
```

**大白话**：
> "什么时候卖？我不猜。市场什么时候反转，追踪止损什么时候告诉我。"

这就是典型的趋势跟踪思维：**不预测顶和底，让利润跑，反转了再跑。**

### 5.2 追踪止损：真正的退出机制

虽然没技术卖出，但追踪止损就是"看不见的卖":

| 阶段 | 利润 | 追踪止损 |
|------|------|---------|
| 刚入场 | 0% - 2% | 未启动，硬止损 -10% |
| 利润启动 | > 2% | 启动追踪止损 |
| 趋势延续 | 继续涨 | 止损线跟着往上走 |
| 趋势反转 | 回撤 1% | 触发止损，退出 |

**大白话**：
- 赚到 2%，我开始保护利润
- 价格继续涨，止损线跟着涨
- 从最高点跌 1%，赶紧跑

**经典台词**：
> "趋势是我朋友，但朋友也会翻脸。翻脸之前我先溜。"

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **经典指标**：一目均衡表是日本几十年的经典，经过无数市场验证
2. **逻辑简单**：就一个买入条件，不会让你"选择困难症"
3. **趋势过滤**：云层确认确保顺势交易，不会逆势抄底
4. **追踪止损**：适合趋势行情，能锁定大部分利润
5. **代码简洁**：约 60 行，新手也能看懂

### ⚠️ 缺点（吐槽环节）

1. **无卖出信号**：完全依赖追踪止损，可能错过主动止盈机会
2. **无 BTC 关联**：不检测比特币大盘，独立交易风险大
3. **参数固定**：9/26/52 是经典参数，但未必最优
4. **迟行线未用**：一目均衡表有 5 根线，策略只用了 4 根
5. **示例性质**：策略较简单，适合学习，不适合直接实盘

## 十一、彩蛋：一目均衡表的历史

### 11.1 发明者的故事

一目均衡表由日本记者**细田悟一**（Goichi Hosoda）在 1930 年代发明。他花了 30 年时间研究完善这套系统，笔名"一目山人"。

**"一目"** 的意思就是"看一眼就明白"，"均衡"就是平衡，"表"就是图表。

**大白话**：一个日本记者花了 30 年搞出来的东西，你就知道这玩意儿有多靠谱了。

### 11.2 为什么参数是 9/26/52？

| 参数 | 来源 | 大白话 |
|------|------|--------|
| 9 | 日本传统工作日 | "以前日本一周工作 6 天，一个半月 ≈ 9 天" |
| 26 | 日本传统月份 | "以前日本一个月 ≈ 26 个工作日" |
| 52 | 日本传统年份 | "一年 ≈ 52 周 ≈ 2 个月工作日" |

**吐槽**：这参数是按 1930 年代日本历法来的，现在加密货币 7×24 小时交易，这参数还适用吗？

答案是：**依然适用**。因为这些参数本质上是捕捉短期、中期、长期趋势的时间尺度，跟具体市场无关。

### 11.3 迟行线为什么没用？

本策略没用迟行线（Chikou Span），这是个小遗憾。

迟行线的作用：把当前价格画在 26 根 K 线之前，用来确认趋势。

- 当前价格 > 26 根 K 线前的价格 = 看涨确认
- 当前价格 < 26 根 K 线前的价格 = 看跌确认

**如果想改进策略**，可以加上迟行线确认：

```python
# 建议添加
& (dataframe["close"] > dataframe["close"].shift(26))  # 迟行线确认
```

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

Ichimoku 的历史回测表现往往不错——但有个陷阱：

> **趋势策略在趋势市场中表现优异，但在震荡市场中会被反复打脸。**

简单说就是：**牛市它是神，震荡市它是韭菜。**

### 策略的隐藏风险

实盘时要注意：

1. **无技术卖出**：完全依赖追踪止损，可能错过主动止盈机会
2. **滞后指标**：一目均衡表是滞后指标，信号可能延迟
3. **参数固定**：9/26/52 是经典参数，但加密货币市场波动大，可能需要调整
4. **无 BTC 关联**：不检测比特币大盘，BTC 暴跌时山寨币信号可能失效
5. **震荡市杀手**：宽幅震荡中，TK 金叉死叉频繁，手续费会吃掉利润

### 我的建议（真心话）

```
1. 先回测：至少 3 个月数据，覆盖牛市、震荡、熊市
2. 再模拟：模拟盘运行 1-2 周，观察信号质量
3. 后小仓：小仓位实盘测试，不要超过总资金的 5%
4. 慢放大：确认策略表现正常后，再逐步放大仓位
5. 加改进：考虑添加迟行线确认、BTC 关联、技术卖出信号
```

**记住**：一目均衡表是好指标，但好指标也需要好市场。趋势来的时候，它会带你飞；震荡来的时候，它也会带你亏。

**最后提醒**：策略再经典，市场教做人时也不会打招呼。轻仓测试，活着最重要！🙏

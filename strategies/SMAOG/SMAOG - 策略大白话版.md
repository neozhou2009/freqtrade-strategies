# SMAOG 策略："三层防弹衣"的升级版抄底手

> **外号**：防弹抄底手、OG 老炮儿
> **职业**：带三层保护的稳健抄底手
> **时间框架**：5 分钟（适合日内交易）

---

## 一、这策略是个啥？

简单说，**SMAOG** 就是一个：
- 在 SMAIP3v2 基础上"加了三层防弹衣"
- 卖出时更"挑剔"，只在动量减弱时才卖
- 用"递进式止盈"，持仓越久目标越低

就像 SMAIP3v2 的"加强版"，多穿了三层防弹衣，抄底更谨慎，卖出更精明 🛡️

---

## 二、核心配置：说白了就是"赚够了再跑"

### 止盈规则（ROI 表）

```
刚入场        → 赚够 10% 就跑
持仓 30 分钟后 → 赚够 5% 就跑
持仓 60 分钟后 → 赚够 2% 就跑
```

**翻译**：刚入场时目标高（10%），但时间越久越"急"，最后 2% 也跑。这设计挺聪明的——别让资金被套太久。

### 止损规则

```
亏到 23% → 认赔出局
利润到 2% → 启动追踪止损，回撤 0.5% 就跑
```

**翻译**：
- 止损和 SMAIP3v2 一样，比较"大方"
- 但追踪止损更敏感（0.5% vs SMAIP3v2 的 0.3%），更快锁定利润

## 三、1 个买入条件：但保护很厚

这策略也是 1 个买入信号，但保护机制多了：

### 🎯 核心买入：趋势向上 + 价格回调 + 没崩盘（三层检测）

**大白话**：
> "大趋势向上（EMA50 > EMA200），价格在长期均线上方，现在回调到买入线以下，而且——重点来了——最近 10 分钟、1 小时、12 小时都没有暴跌，那我就买入！"

**代码翻译**：
```python
EMA50 > EMA200                    # 中期趋势向上
价格 > EMA200                      # 长期趋势也向上
pair_is_bad < 1                   # 三层暴跌检测都没触发
价格 < 买入阈值(MA × 0.968)        # 回调到位了
有成交量                          # 不是死币
→ 买入！
```

## 四、保护机制：3 层"暴跌防护网"

SMAOG 比 SMAIP3v2 多了一层长期保护，而且用的是 rolling 方式：

| 保护层级 | 时间范围 | 阈值 | 大白话 |
|---------|---------|------|--------|
| 第 1 层 | 10 分钟（2 根 K 线） | 19.8% | "刚才崩了 20%，别碰！" |
| 第 2 层 | 1 小时（12 根 K 线） | 17.2% | "这一小时崩了 17%，再等等！" |
| 第 3 层 | 12 小时（144 根 K 线） | 55.5% | "今天崩了 55%，这币有问题！" |

这设计比 SMAIP3v2 更全面——短中长期都有保护，防止你在各种时间尺度上"接飞刀" 🛡️

## 五、卖出逻辑：比买入更"挑剔"

### 5.1 基础卖出：涨过线 + 动量减弱

```
价格 > 卖出阈值(EMA × 0.985)
AND（以下任一条件）
  - 开盘价比上一根低（价格走弱）
  - RSI < 50（动量不足）
  - RSI 在下降（动量衰减）
→ 卖出
```

**大白话**：
> "价格涨过卖出了？等等，我看下动量……嗯，开盘价低了 / RSI 弱了 / RSI 在降，好吧，那就卖。"

这和 SMAIP3v2 不一样——SMAIP3v2 是价格到了就卖，SMAOG 会再看看动量，强劲就继续拿 😎

### 5.2 对比：SMAIP3v2 vs SMAOG

| 维度 | SMAIP3v2 | SMAOG |
|------|----------|-------|
| 暴跌保护层数 | 2 层 | 3 层（多了 12 小时） |
| 保护方式 | shift 固定 K 线 | rolling 滑动窗口 |
| 卖出动量过滤 | 无 | 有（3 个条件） |
| 智能退出拒绝 | 有 | 无 |
| ROI 设计 | 固定 2.6% | 递进式（10%/5%/2%） |

**一句话**：SMAOG 更"谨慎"，保护更多，但失去了 SMAIP3v2 的"智能退出拒绝"功能。

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **三层保护到位**：短中长期暴跌检测，防接飞刀更全面
2. **卖出更精明**：动量过滤避免过早卖出
3. **递进式止盈**：持仓越久越容易退出，不让资金套牢
4. **保护参数可优化**：三层阈值都支持 Hyperopt 优化

### ⚠️ 缺点（吐槽环节）

1. **参数优化受限**：买卖核心参数不能优化，只有保护参数可以
2. **计算量更大**：3 个 rolling 窗口，老机器可能有点吃力
3. **保护可能过敏感**：三层保护可能错过一些"假暴跌"后的机会

## 一、策略概览

SMAOG 是 SMAIP 系列的演进版本，在原有移动平均线偏移策略基础上，增强了暴跌保护机制（3 层 rolling 检测）和更精细的退出条件。策略名称中的 "OG" 暗示其为"元老级"增强版本。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 1 个核心买入信号（趋势过滤 + 价格偏离 + 暴跌保护） |
| **卖出条件** | 1 个卖出信号（含动量过滤） + 追踪止损 + ROI 止盈 |
| **保护机制** | 3 组 rolling 窗口"坏币种"检测阈值 |
| **时间框架** | 5 分钟主时间框架 |
| **依赖库** | talib (技术指标计算), freqtrade.strategy |

## 三、买入条件详解

### 3.1 保护机制（3 组 Rolling 窗口）

策略通过 3 层 rolling 窗口的 `pair_is_bad` 检测机制防止在极端行情中买入：

| 保护类型 | Rolling 窗口 | 默认阈值 | 检测逻辑 |
|---------|-------------|---------|---------|
| pair_is_bad_0 | 144 根 K 线 | 0.555 (55.5%) | 12 小时内最低价跌幅 |
| pair_is_bad_1 | 12 根 K 线 | 0.172 (17.2%) | 1 小时内最低价跌幅 |
| pair_is_bad_2 | 2 根 K 线 | 0.198 (19.8%) | 10 分钟内最低价跌幅 |

**逻辑详解**：
```python
pair_is_bad = (
    ((open.rolling(144).min() - close) / close >= 0.555) |   # 12小时暴跌
    ((open.rolling(12).min() - close) / close >= 0.172) |    # 1小时暴跌
    ((open.rolling(2).min() - close) / close >= 0.198)       # 10分钟暴跌
)
```

**设计理念**：覆盖短、中、长期暴跌检测，提供全方位保护。

### 3.2 核心买入条件

```python
# 买入逻辑
(
    (dataframe['ema_50'] > dataframe['ema_200']) &           # EMA50 上穿 EMA200，趋势向上
    (dataframe['close'] > dataframe['ema_200']) &             # 收盘价在 EMA200 之上
    (dataframe['pair_is_bad'] < 1) &                          # 非坏币种状态
    (dataframe['close'] < dataframe['ma_offset_buy']) &       # 价格低于买入阈值
    (dataframe['volume'] > 0)                                  # 有成交量
)
```

**条件解析**：
1. **趋势确认**：EMA50 > EMA200，确保中期趋势向上
2. **价格位置**：收盘价 > EMA200，确保处于长期上涨趋势中
3. **安全检查**：非"坏币种"状态（3 层保护）
4. **买入机会**：价格低于动态计算的买入阈值（MA × low_offset）
5. **流动性**：确保有成交量

### 3.3 移动平均线偏移机制

策略使用动态偏移来计算买卖阈值：

```python
# 买入阈值计算
ma_offset_buy = SMA/EMA(N根K线) × low_offset
# low_offset 默认 0.968，即均线下方 3.2%

# 卖出阈值计算
ma_offset_sell = EMA(N根K线) × high_offset  
# high_offset 默认 0.985，即均线上方 -1.5%
```

## 四、卖出逻辑详解

### 4.1 卖出条件（含动量过滤）

```python
# 卖出逻辑
(
    (dataframe['close'] > dataframe['ma_offset_sell']) &     # 价格高于卖出阈值
    (                                                          # 动量过滤（满足其一）
        (dataframe['open'] < dataframe['open'].shift(1)) |   # 当前开盘价低于前一根
        (dataframe['rsi_exit'] < 50) |                        # RSI < 50
        (dataframe['rsi_exit'] < dataframe['rsi_exit'].shift(1))  # RSI 下降中
    ) &
    (dataframe['volume'] > 0)                                  # 有成交量
)
```

**设计思路**：与 SMAIP3v2 不同，SMAOG 在卖出时增加了动量过滤条件，只在动量减弱时才卖出，避免在强劲上涨中过早离场。

### 4.2 动量过滤条件详解

| 条件 | 含义 | 设计目的 |
|------|------|---------|
| open < open.shift(1) | 当前开盘价低于前一根 K 线 | 价格开始走弱 |
| RSI(2) < 50 | RSI 低于中性线 | 动量转弱 |
| RSI < RSI.shift(1) | RSI 正在下降 | 动量衰减 |

**逻辑**：满足以上任意一个条件，说明动量开始减弱，可以卖出。

### 4.3 多层止盈体系

| 利润水平 | 退出机制 | 触发条件 |
|---------|---------|---------|
| 10% | ROI 止盈 | 立即生效 |
| 5%（30 分钟后）| ROI 止盈 | 持仓超过 30 分钟 |
| 2%（60 分钟后）| ROI 止盈 | 持仓超过 60 分钟 |
| 2%+ | 追踪止损激活 | 利润超过 2% |
| 回撤 0.5%+ | 追踪止损触发 | 从最高点回撤 0.5% |

## 六、风险管理特色

### 6.1 三层暴跌保护

策略采用 3 层 rolling 窗口检测暴跌：

```python
# 短期保护（10 分钟）
(open.rolling(2).min() - close) / close >= 0.198

# 中期保护（1 小时）
(open.rolling(12).min() - close) / close >= 0.172

# 长期保护（12 小时）
(open.rolling(144).min() - close) / close >= 0.555
```

**设计理念**：覆盖不同时间尺度的暴跌情况，防止在极端行情中买入。

### 6.2 动量退出过滤

卖出时增加动量过滤条件，避免在强劲上涨中过早离场：

- 价格开始走弱（开盘价下降）
- 动量转弱（RSI < 50）
- 动量衰减（RSI 下降）

### 6.3 递进式 ROI 设计

```python
minimal_roi = {
    "0": 0.10,   # 刚入场，目标 10%
    "30": 0.05,  # 30 分钟后，目标降为 5%
    "60": 0.02   # 60 分钟后，目标降为 2%
}
```

**设计理念**：持仓时间越长，盈利目标越低，避免长时间套牢。

## 七、策略优势与局限

### ✅ 优势

1. **三层暴跌保护**：短中长期全覆盖，比 SMAIP3v2 更安全
2. **动量退出过滤**：不在上涨强劲时卖出，最大化利润
3. **递进式 ROI**：根据持仓时间调整盈利目标
4. **参数可选择性优化**：保护参数可优化，核心参数固定

### ⚠️ 局限

1. **参数优化受限**：买入卖出参数设置 `optimize=False`
2. **止损空间较大**：23% 止损对保守交易者可能过宽
3. **计算量增加**：3 个 rolling 窗口计算，增加计算负担

## 九、适用市场环境详解

SMAOG 是 SMAIP 系列的增强版，通过多层保护机制提升安全性，最适合**明确的上涨趋势市场**，在极端行情中有更好的防护能力。

### 9.1 策略核心逻辑

- **三层防护**：10 分钟、1 小时、12 小时三级暴跌检测
- **趋势为王**：只在 EMA50 > EMA200 且价格 > EMA200 时买入
- **动量退出**：不在强劲上涨中卖出，等待动量减弱

### 9.2 不同市场环境表现

| 市场类型 | 表现评级 | 原因分析 |
| :--- | :--- | :--- |
| 📈 明显上涨 | ⭐⭐⭐⭐⭐ | 完美匹配策略逻辑，回调买入后趋势延续 |
| 🔄 震荡上涨 | ⭐⭐⭐⭐☆ | 三层保护减少暴跌买入风险 |
| 📉 下跌趋势 | ⭐☆☆☆☆ | 趋势过滤阻止买入，但暴跌保护会标记更多币种 |
| ⚡️ 高波动横盘 | ⭐⭐☆☆☆ | 频繁进出，但三层保护可能过于敏感 |

### 9.3 关键配置建议

| 配置项 | 建议值 | 说明 |
|--------|--------|------|
| 交易对 | 主流币种 | 流动性好，暴跌检测更准确 |
| rolling 窗口 | 根据币种波动率调整 | 高波动币种可适当放宽阈值 |
| ROI | 可调整时间参数 | 适应不同交易风格 |

## 十、重要提醒：复杂性的代价

### 10.1 学习成本

策略逻辑较 SMAIP3v2 更复杂，需要理解：
- 三层 rolling 窗口暴跌检测机制
- 动量退出过滤条件
- 递进式 ROI 设计

### 10.2 硬件要求

| 交易对数量 | 最低内存 | 推荐内存 |
|-----------|---------|---------|
| 1-10 对 | 2GB | 4GB |
| 10-50 对 | 4GB | 8GB |
| 50+ 对 | 8GB | 16GB |

**注意**：3 个 rolling 窗口计算会增加计算量，建议适当增加内存配置。

### 10.3 回测与实盘的差异

- rolling 窗口计算在实盘中的表现可能与回测有差异
- 动量退出过滤在高频波动中可能频繁触发

### 10.4 手动交易者建议

1. 理解三层暴跌保护的逻辑
2. 观察动量退出过滤的实际效果
3. 根据交易对调整保护阈值

## 十一、总结

**SMAOG** 是 SMAIP 系列的增强版本，通过三层暴跌保护机制和动量退出过滤，提升了策略的安全性。它的核心价值在于：

1. **三层防护**：短中长期暴跌检测全覆盖
2. **动量退出**：不在上涨强劲时卖出，最大化利润
3. **递进式 ROI**：根据持仓时间动态调整盈利目标

对于量化交易者而言，这是一个适合在波动较大的上涨趋势中使用的策略，建议根据实际交易对调整保护阈值。

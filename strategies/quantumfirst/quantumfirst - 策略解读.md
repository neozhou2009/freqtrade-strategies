## 一、策略概览

quantumfirst 是一个结合成交量突破与动量反转的短线策略。其核心逻辑是在价格低于均线时寻找成交量异常放大的机会，利用 Fisher RSI 等指标确认超卖反转信号。策略设计简洁但有效，适合中等波动市场。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 6 个条件组合，需同时满足（AND 逻辑） |
| **卖出条件** | 2 组 OR 信号，任一触发即卖出 |
| **保护机制** | ROI 分级止盈 + 追踪止损 |
| **时间框架** | 5 分钟级别 |
| **依赖库** | talib, qtpylib, numpy, pandas |

## 三、买入条件详解

### 3.1 买入信号（单一条件组，6 个指标）

策略采用**全指标确认模式**，所有条件必须同时满足：

```python
dataframe.loc[
    (
        (dataframe['close'] > 0.00000200) &                    # 条件1: 价格过滤
        (dataframe['volume'] > dataframe['volume'].rolling(200).mean() * 4) &  # 条件2: 成交量爆发
        (dataframe['close'] < dataframe['sma']) &              # 条件3: 价格低于均线
        (dataframe['fastd'] > dataframe['fastk']) &            # 条件4: 随机指标金叉
        (dataframe['rsi'] > 0) &                               # 条件5: RSI > 0（几乎总是满足）
        (dataframe['fastd'] > 0) &                             # 条件6: FastD > 0（几乎总是满足）
        (dataframe['fisher_rsi_norma'] < 38.900000000000006)    # 条件7: Fisher RSI 归一化 < 38.9
    ),
    'buy'] = 1
```

### 3.2 条件解读

| 条件编号 | 指标 | 阈值 | 市场含义 |
|---------|------|------|---------|
| #1 | 收盘价 | > 0.00000200 | 过滤低价币种，避免流动性问题 |
| #2 | 成交量 | > 200周期均量 × 4 | 成交量异常爆发（4倍均值） |
| #3 | 收盘价 | < SMA(40) | 价格低于均线，处于相对低位 |
| #4 | FastD | > FastK | 随机指标快线向上穿越慢线（金叉） |
| #5 | RSI | > 0 | RSI 为正（几乎总是满足） |
| #6 | FastD | > 0 | 随机指标为正（几乎总是满足） |
| #7 | Fisher RSI 归一化 | < 38.9 | Fisher RSI 处于超卖区域 |

**买入逻辑总结**：
- 这是一个**成交量确认的反转策略**
- 核心是"价格低于均线 + 成交量爆发 + 动量反转"
- 成交量 4 倍均值是关键信号，表明有大资金进入
- Fisher RSI 归一化 < 38.9 确认超卖状态
- 随机指标金叉作为入场时机确认

## 四、卖出逻辑详解

### 4.1 卖出信号（2 组 OR 条件）

策略采用**双重退出机制**，任一组条件满足即触发卖出：

```python
# 信号组 1: RSI 反转确认
(
    (qtpylib.crossed_above(dataframe['rsi'], 50)) &   # RSI 上穿 50
    (dataframe['macd'] < 0) &                          # MACD < 0（空头趋势）
    (dataframe['minus_di'] > 0)                       # 负向动量指标 > 0
)

# 信号组 2: SAR + Fisher RSI 组合
(
    (dataframe['sar'] > dataframe['close']) &         # SAR 高于收盘价（看空信号）
    (dataframe['fisher_rsi'] > 0.3)                   # Fisher RSI > 0.3（超买区间）
)
```

### 4.2 卖出条件详解

| 信号组 | 条件 | 市场含义 |
|--------|------|---------|
| **组 1** | RSI 上穿 50 | RSI 从超卖区进入中性区，反弹到位 |
| | MACD < 0 | 仍处于空头趋势，谨慎为上 |
| | Minus DI > 0 | 负向动量存在，趋势可能反转 |
| **组 2** | SAR > 收盘价 | 抛物线指标发出看空信号 |
| | Fisher RSI > 0.3 | Fisher RSI 进入超买区 |

**卖出逻辑总结**：
- 信号组 1：RSI 反弹到中性区，但整体趋势仍偏空，及时止盈
- 信号组 2：SAR 发出看空信号 + Fisher RSI 超买，双重确认离场
- 两组信号是 OR 关系，任一触发即卖出

### 4.3 ROI 分级止盈

| 时间（分钟） | 目标收益 | 说明 |
|------------|---------|------|
| 0 | 5% | 开仓即时止盈阈值 |
| 20 | 4% | 20 分钟后降低要求 |
| 40 | 3% | 40 分钟后进一步降低 |
| 80 | 2% | 80 分钟后继续降低 |
| 1440 (24h) | 1% | 一天后保底收益 |

## 五、技术指标体系

### 5.1 核心指标

| 指标类别 | 具体指标 | 用途 |
|---------|---------|------|
| 趋势指标 | SMA(40) | 价格相对位置判断 |
| 动量指标 | RSI | 超买超卖判断 |
| 变换指标 | Fisher RSI | RSI 的非线性变换，放大极值信号 |
| 随机指标 | FastK, FastD | 短期动量与入场时机 |
| 成交量 | Volume | 异常放量检测 |
| 趋势反转 | SAR | 趋势转向信号 |
| 趋势强度 | MACD, MINUS_DI | 趋势方向与强度判断 |

### 5.2 关键指标计算

```python
# MACD
macd = ta.MACD(dataframe)
dataframe['macd'] = macd['macd']
dataframe['macdsignal'] = macd['macdsignal']

# 负向动量指标
dataframe['minus_di'] = ta.MINUS_DI(dataframe)

# RSI
dataframe['rsi'] = ta.RSI(dataframe)

# Fisher RSI（非线性变换，放大极端值）
rsi = 0.1 * (dataframe['rsi'] - 50)
dataframe['fisher_rsi'] = (numpy.exp(2 * rsi) - 1) / (numpy.exp(2 * rsi) + 1)
# Fisher RSI 归一化版本（0-100 范围）
dataframe['fisher_rsi_norma'] = 50 * (dataframe['fisher_rsi'] + 1)

# 随机指标快速版
stoch_fast = ta.STOCHF(dataframe)
dataframe['fastd'] = stoch_fast['fastd']
dataframe['fastk'] = stoch_fast['fastk']

# SAR
dataframe['sar'] = ta.SAR(dataframe)

# SMA
dataframe['sma'] = ta.SMA(dataframe, timeperiod=40)
```

### 5.3 Fisher RSI 解读

Fisher RSI 是一种特殊的指标变换：
- **原始 RSI**：范围 0-100
- **Fisher 变换后**：范围 -1 到 +1
- **归一化版本**：范围 0-100

Fisher 变换的作用是**放大极端值**，使超买超卖信号更明显：
- Fisher RSI < -0.94（归一化 < 3）：极端超卖
- Fisher RSI > 0.3（归一化 > 65）：超买区域

## 六、风险管理特色

### 6.1 成交量爆发确认

策略要求成交量是 200 周期均量的 4 倍：
```python
dataframe['volume'] > dataframe['volume'].rolling(200).mean() * 4
```
这确保只有**大资金进入**时才考虑入场，避免虚假突破。

### 6.2 价格低位入场

要求价格低于 40 周期 SMA：
```python
dataframe['close'] < dataframe['sma']
```
确保在**相对低位**进场，而非追高。

### 6.3 追踪止损保护

- 盈利 1% 后启动追踪
- 偏移 2%，给价格足够波动空间
- 锁定利润的同时不轻易被震出

## 七、策略优势与局限

### ✅ 优势

1. **成交量确认**：4 倍成交量确保有大资金进入
2. **Fisher RSI 增强**：放大极端信号，提高准确性
3. **双重卖出机制**：两组 OR 信号，及时止盈
4. **逻辑清晰**：量价结合，反转确认，步骤明确

### ⚠️ 局限

1. **低价币过滤**：0.00000200 的价格过滤可能排除一些机会
2. **成交量要求严格**：4 倍均量可能错过一些温和放量机会
3. **追踪止损偏保守**：1% 激活、2% 偏移可能在波动中被止损
4. **无保护机制**：没有止损保护参数，仅靠固定止损

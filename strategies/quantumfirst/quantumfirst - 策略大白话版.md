## 一、这策略是个啥？

简单说，**quantumfirst** 就是一个：
- 专门盯着"大资金进场"的策略
- 在价格低于均线时寻找反转机会
- 用 Fisher RSI 这种"变形金刚"指标确认信号

就像一个**股市侦探**，专门跟踪那些"突然放量"的股票，在别人恐慌的时候跟着大资金进场 🕵️

---

## 二、核心配置：说白了就是"稳扎稳打"

### 止盈规则（ROI 表）

```
0 分钟：赚 5% 就跑
20 分钟：赚 4% 也行
40 分钟：赚 3% 走人
80 分钟：赚 2% 凑合
1440 分钟（24小时）：赚 1% 也要
```

**翻译**：这策略比 mark_strat_opt 更"有耐心"。开仓想赚 5%，但过了一天哪怕赚 1% 也行。**不像前面那个半小时就急了** 😅

### 止损规则

```
固定止损：-10%
追踪止损：盈利超过 1% 后启动，锁定 2% 的利润空间
```

**翻译**：止损设 10%，比前面的 20% 更紧。追踪止损也更"佛系"，赚 1% 就开始追，但偏移有 2%，给你更多波动空间。

## 三、7 个买入条件：层层把关

这策略的买入条件也是**全部满足才能进场**，我来给你拆解：

### 💰 第一类：过滤"垃圾币"（1 个条件）

**条件 #1：收盘价 > 0.00000200**

```python
dataframe['close'] > 0.00000200
```

**大白话**：
> "过滤掉那些低价到'不值钱'的山寨币。避免那些流动性差、可能归零的币种。"

### 📊 第二类：成交量"爆了"（1 个条件）

**条件 #2：成交量 > 200 周期均量 × 4**

```python
dataframe['volume'] > dataframe['volume'].rolling(200).mean() * 4
```

**大白话**：
> "成交量要是最近 200 根 K 线平均成交量的 **4 倍**！啥意思？就是今天有大资金进场了，有人在疯狂买入。没有量，一切都白搭。"

### 📉 第三类：价格够"便宜"（1 个条件）

**条件 #3：收盘价 < SMA(40)**

```python
dataframe['close'] < dataframe['sma']
```

**大白话**：
> "价格要低于 40 周期均线。就是不追高，等价格'打折'了再买。这策略比较'抠'，只买便宜的。"

### 📈 第四类：动量"反转"信号（4 个条件）

**条件 #4：FastD > FastK（随机指标金叉）**

```python
dataframe['fastd'] > dataframe['fastk']
```

**大白话**：
> "随机指标的快线超过了慢线，这是经典的'金叉'信号。意味着短期动量开始向上反转。"

**条件 #5：RSI > 0**

```python
dataframe['rsi'] > 0
```

**大白话**：
> "RSI 大于 0？这是废话条件，RSI 怎么可能小于 0 😅 可能是代码规范要求，或者作者之前试过别的阈值。"

**条件 #6：FastD > 0**

```python
dataframe['fastd'] > 0
```

**大白话**：
> "FastD 大于 0？也是废话条件。随机指标怎么可能小于 0？可能是写代码时为了格式统一加的。"

**条件 #7：Fisher RSI 归一化 < 38.9**

```python
dataframe['fisher_rsi_norma'] < 38.900000000000006
```

**大白话**：
> "这个就比较有意思了！Fisher RSI 是对普通 RSI 做'数学变形'，让极端值更明显。归一化值 < 38.9 意味着价格处于**超卖区域**。注意看这个小数点后面的 `000000000000006`，一看就是 hyperopt 跑出来的参数 😂"

## 四、卖出逻辑：两组信号，任一触发就跑

### 4.1 卖出信号（两组 OR 关系）

这策略的卖出比较灵活，**两组信号任一触发就卖出**：

#### 🚨 组 1：RSI 反弹确认

| 条件 | 代码 | 大白话 |
|------|------|--------|
| RSI 上穿 50 | `crossed_above(rsi, 50)` | RSI 从超卖区回到中性区 |
| MACD < 0 | `macd < 0` | 整体趋势还是空头 |
| Minus DI > 0 | `minus_di > 0` | 有负向动量存在 |

**大白话**：
> "RSI 反弹到 50 了，但 MACD 还是负的，整体趋势还是弱。这时候趁反弹到位赶紧跑，别贪心。"

#### 🚨 组 2：SAR + Fisher RSI 组合

| 条件 | 代码 | 大白话 |
|------|------|--------|
| SAR > 收盘价 | `sar > close` | 抛物线指标发出看空信号 |
| Fisher RSI > 0.3 | `fisher_rsi > 0.3` | Fisher RSI 进入超买区 |

**大白话**：
> "SAR 说趋势要反转了，Fisher RSI 也超买了。双重信号确认，赶紧撤！"

## 五、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **成交量确认**：4 倍均量确保有大资金进场，不是假突破
2. **不追高**：要求价格低于均线，只在"打折"时买
3. **双重退出**：两组卖出信号，灵活止盈
4. **指标组合丰富**：Fisher RSI 这种"变形金刚"指标用得好

### ⚠️ 缺点（吐槽环节）

1. **低价币过滤太死板**：0.00000200 的阈值可能过滤掉一些好机会
2. **成交量要求太严**：4 倍均量，有些温和放量机会会错过
3. **有"废话条件"**：RSI > 0 和 FastD > 0 基本永远满足
4. **Fisher RSI 参数精确到小数点后很多位**：`38.900000000000006` 这种数字，一看就是过拟合

## 十二、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

quantumfirst 的回测表现可能不错，但要注意：

> **成交量信号有延迟风险。** 看到放量的时候，价格可能已经涨了，你进场时已经不是"底部"了。

### 这个策略的隐藏风险

1. **成交量虚假突破**：放量也可能是主力出货，不一定是建仓
2. **低价币过滤失效**：币价涨了之后，原来的阈值就不适用了
3. **参数过拟合**：那个 `38.900000000000006`，一看就是历史数据的"最优解"
4. **追踪止损太紧**：1% 激活、2% 偏移，波动大时容易被震出

### 我的建议（真心话）

```
1. 把这个策略当"成交量警报器"，而不是全自动交易
2. 信号触发后，人工看一下 K 线形态再决定
3. 别太迷信那些精确到小数点后 N 位的参数
4. 可以把成交量倍数调低到 3 倍，增加信号频率
5. 低价币过滤阈值根据实际币种调整
```

**记住**：成交量是很好的信号，但不是万能的。主力也可能"做量"骗你进场！

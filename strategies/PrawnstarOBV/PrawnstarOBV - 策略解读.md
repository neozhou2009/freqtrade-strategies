## 一、策略概览

PrawnstarOBV 是一个基于成交量能量指标（OBV）的趋势跟踪策略。该策略巧妙地将成交量分析与相对强弱指标（RSI）结合，通过捕捉成交量变化来预判价格走势，在市场底部寻找买入机会。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 3 个独立买入信号组合，可独立触发 |
| **卖出条件** | 无主动卖出信号，依赖 ROI 和追踪止损 |
| **保护机制** | 追踪止损 + 分级 ROI 止盈 |
| **时间框架** | 1 小时 (1h) |
| **依赖库** | talib, qtpylib |

## 三、买入条件详解

### 3.1 核心指标体系

策略使用两个核心指标：

| 指标 | 参数 | 用途 |
|------|------|------|
| **OBV** | 默认 | 能量潮指标，衡量买卖力量 |
| **OBV SMA** | 7 周期 | OBV 的 7 日简单移动平均 |
| **RSI** | 默认（14 周期） | 相对强弱指标 |

### 3.2 买入条件解析

策略的买入逻辑由三个独立条件组成，使用 OR 关系连接：

#### 条件 #1：OBV 金叉 + RSI 确认
```python
(qtpylib.crossed_above(dataframe['obv'], dataframe['obvSma'])) &
(dataframe['rsi'] < 50)
```

**逻辑**：
- OBV 上穿其 7 日均线，表示成交量能量转强
- RSI < 50 确认市场处于弱势区域
- 结合两者寻找底部反转信号

#### 条件 #2：OBV 偏离度异常
```python
((dataframe['obvSma'] - dataframe['close']) / dataframe['obvSma'] > 0.1)
```

**逻辑**：
- 当 OBV 均线与收盘价的偏离度超过 10%
- 表明成交量能量与价格出现显著背离
- 可能是抄底机会

#### 条件 #3：OBV 趋势增强 + RSI 确认
```python
(dataframe['obv'] > dataframe['obv'].shift(1)) &
(dataframe['obvSma'] > dataframe['obvSma'].shift(5)) &
(dataframe['rsi'] < 50)
```

**逻辑**：
- OBV 高于前一根 K 线，能量在增加
- OBV SMA 高于 5 根 K 线前，趋势向上
- RSI < 50 确认市场处于弱势
- 三重确认，提高信号可靠性

### 3.3 买入条件分类汇总

| 条件组 | 条件编号 | 核心逻辑 | 触发难度 |
|-------|---------|---------|---------|
| 金叉类 | #1 | OBV 上穿均线 + RSI 弱势 | 中等 |
| 偏离类 | #2 | 量价偏离度异常 | 较高 |
| 趋势类 | #3 | OBV 趋势向上 + RSI 弱势 | 中等 |

## 五、技术指标体系

### 5.1 核心指标

| 指标类别 | 具体指标 | 用途 |
|---------|---------|------|
| 成交量指标 | OBV | 衡量买卖力量对比 |
| 趋势指标 | OBV SMA(7) | 平滑 OBV，判断趋势方向 |
| 动量指标 | RSI | 判断超买超卖区域 |

### 5.2 OBV 指标深度解析

OBV（On Balance Volume）是一个累积指标：

- **计算方式**：价格上涨日成交量累加，下跌日成交量累减
- **核心逻辑**：成交量先于价格变化
- **信号意义**：
  - OBV 上升 + 价格下跌 = 底部可能形成
  - OBV 下降 + 价格上涨 = 顶部可能形成

### 5.3 指标协同效应

```
OBV ───┐
       ├──→ 买入信号判断
RSI ───┘
```

- OBV 提供成交量方向的判断
- RSI 提供市场强弱区域的确认
- 两者结合提高信号的可靠性

## 六、风险管理特色

### 6.1 多层止损保护

```
第一层：15% 固定止损
第二层：分级 ROI 止盈
第三层：4% 激活后的追踪止损
```

**设计意图**：
- 固定止损作为最后防线
- ROI 止盈锁定时间价值
- 追踪止损保护已有利润

### 6.2 时间维度风险控制

| 时间节点 | 风险控制措施 |
|---------|-------------|
| 买入时刻 | OBV + RSI 双重确认 |
| 179 分钟后 | 目标收益降至 13.7% |
| 810 分钟后 | 目标收益降至 2.5% |
| 1024 分钟后 | 强制保本退出 |

### 6.3 成交量风险考量

- OBV 侧重成交量分析
- 在低流动性市场可能产生假信号
- 需配合交易量过滤使用

## 七、策略优势与局限

### ✅ 优势

1. **量价结合**：将成交量纳入分析，比单纯价格分析更全面
2. **三重买入条件**：不同条件从不同角度确认底部，提高信号质量
3. **保护机制完善**：追踪止损 + ROI 止盈 + 固定止损三重保护
4. **适合趋势反转**：专注于底部捕捉，适合抄底操作

### ⚠️ 局限

1. **无主动卖出**：完全依赖止损止盈机制，可能错过更好的出场点
2. **震荡市不利**：RSI < 50 的限制可能导致频繁信号
3. **1 小时周期**：信号较慢，不适合高频交易
4. **OBV 假信号**：成交量指标在某些市场条件下可能失效

## 九、适用市场环境详解

PrawnstarOBV 是一个典型的**抄底型策略**。基于其代码架构和指标组合，它最适合**震荡市中的底部捕捉**，而在单边下跌或快速上涨市场时表现不佳。

### 9.1 策略核心逻辑

- **成交量先行**：OBV 理论认为成交量先于价格变化
- **弱势确认**：RSI < 50 确保只在市场弱势时入场
- **趋势反转捕捉**：OBV 上穿均线意味着资金开始流入

### 9.2 不同市场环境表现

| 市场类型 | 表现评级 | 原因分析 |
| :--- | :--- | :--- |
| 📈 单边上涨 | ⭐⭐☆☆☆ | RSI < 50 限制导致错过机会 |
| 🔄 震荡市场 | ⭐⭐⭐⭐⭐ | 核心设计场景，捕捉底部反转 |
| 📉 单边下跌 | ⭐⭐☆☆☆ | 可能抄在半山腰 |
| ⚡️ 高波动市 | ⭐⭐⭐☆☆ | 信号可能频繁，需配合过滤 |

### 9.3 关键配置建议

| 配置项 | 建议值 | 说明 |
|--------|--------|------|
| 止损 | -0.15 | 可根据风险偏好调整 |

| 交易对 | 主流币种 | 流动性好的币种 OBV 更可靠 |

## 十一、总结

**PrawnstarOBV** 是一个以成交量分析为核心的趋势反转捕捉策略。它的核心价值在于：

1. **量价结合**：将 OBV 成交量分析与 RSI 弱势确认结合
2. **多重保护**：追踪止损 + ROI 止盈 + 固定止损三重防线
3. **专注底部**：RSI < 50 限制确保只在弱势区域入场

对于量化交易者而言，这是一个适合震荡市场底部捕捉的策略，但需注意单边行情中的局限性。

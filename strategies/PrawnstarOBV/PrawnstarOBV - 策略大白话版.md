# PrawnstarOBV 策略：成交量的秘密侦探

> **外号**：量价神探  
> **职业**：专门在市场底部嗅探资金流入的侦探  
> **时间框架**：1 小时

---

## 一、这策略是个啥？

简单说，**PrawnstarOBV** 就是一个：

- 盯着成交量不放的"窥探者"
- 只在市场弱势时才出手的"抄底达人"
- 用 OBV（能量潮指标）找资金流入的"资金追踪器"

就像一个在菜市场门口蹲着的黄牛，谁在大量买货、谁在悄悄出货，他心里门儿清 🕵️

---

## 二、核心配置：说白了就是"稳健抄底"

### 止盈规则（ROI 表）

```
刚买入时：目标是赚 29.6%（挺贪的）
3 小时后：降到赚 13.7% 就行
13.5 小时后：赚 2.5% 也凑合
17 小时后：保本就走，不玩了
```

**翻译**：这策略就是"新官上任三把火"——刚买入时志气满满要赚大钱，时间一长就开始佛系了，最后保本也认了。就像你追姑娘，刚开始非她不娶，三个月后觉得"能做朋友也行" 🤣

### 止损规则

```
硬止损：亏 15% 就跑路
追踪止损：赚了 4% 之后，回撤 0.1% 就落袋为安
```

**翻译**：赚了 4% 之后变得特别怂，从最高点回撤一丁点就跑。这叫"捂紧钱包"模式——盈利之后一分钱都不想吐出来。

## 三、3 个买入条件：我帮你分类好了

这策略的买入条件分三类，我给你归好了：

### 🎯 第 1 类：金叉抄底（条件 #1）

**核心逻辑**：OBV 上穿均线 + RSI 弱势确认

**大白话**：
> "成交量能量突然变强了，而且市场还在弱势区域——这可能是底部反转的信号！"

**代码片段**：
```python
OBV 上穿 OBV 均线
且 RSI < 50
```

**解读**：
- OBV（能量潮）是成交量的累计指标
- 当 OBV 上穿其 7 日均线，说明资金开始流入
- RSI < 50 确保我们是在弱势区域抄底
- 就像在说："有钱开始进场了，但市场还便宜——机会来了！"

---

### 📉 第 2 类：偏离抄底（条件 #2）

**核心逻辑**：量价偏离度超过 10%

**大白话**：
> "成交量的均线跟价格差太远了，肯定有猫腻，抄底机会！"

**代码片段**：
```python
(OBV 均线 - 收盘价) / OBV 均线 > 0.1
```

**解读**：
- 这个条件判断成交量能量和价格的偏离程度
- 当偏离度超过 10%，说明量价关系出现异常
- 可能是底部的信号——就像商品打折促销，但买的人突然变多了

---

### 🔍 第 3 类：趋势确认（条件 #3）

**核心逻辑**：OBV 环比上升 + OBV 均线趋势向上 + RSI 弱势

**大白话**：
> "成交量在涨，成交量均线也在涨，但 RSI 还在弱势——稳稳的底部信号！"

**代码片段**：
```python
OBV > 前一根 OBV
且 OBV 均线 > 5 根前的 OBV 均线
且 RSI < 50
```

**解读**：
- OBV 比前一根高：能量在增加
- OBV 均线比 5 根前高：趋势向上
- RSI < 50：还在弱势区域
- 三重确认，更加保险

## 四、保护机制：3 层"防盗门"

这个策略没有主动卖出，全靠保护机制：

| 保护层 | 作用 | 大白话 |
|-------|------|--------|
| 固定止损 | 亏 15% 就跑 | "亏太多了，不玩了！" |
| ROI 止盈 | 时间越长目标越低 | "等太久没意思，保本走吧" |
| 追踪止损 | 盈利 4% 后，回撤 0.1% 就跑 | "赚的钱一毛都不能少！" |

这设计就像：刚进门想赚大钱，等久了就佛系，赚了钱就捂紧钱包 🤐

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

2. **三重确认**：三个不同角度确认底部，信号更可靠

3. **可能抄在半山腰**：弱势区抄底，底下面还有底
4. **1 小时周期较慢**：对快速行情反应迟钝

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

PrawnstarOBV 的回测可能表现不错——但这有个陷阱：

> **因为 RSI 和 OBV 都是常见指标，参数很容易被"拟合"到历史最优，但这不代表未来有效。**

简单说就是：**历史成绩单好，不代表下次考试还能考好。**

### 复杂策略的隐藏风险

实盘时，这个策略可能导致：
- **错过牛市**：RSI < 50 的限制在牛市时完全失效
- **抄底抄在半山腰**：弱势区买入，下面可能还有更低
- **追踪止损被扫**：0.1% 的追踪距离太紧，波动可能就扫掉了

### 我的建议（真心话）

```
1. 震荡市使用，单边市绕道
2. 止损可以适当放宽到 -0.10
3. 追踪止损距离可以调到 0.5%-1%
4. 配合趋势过滤器使用
```

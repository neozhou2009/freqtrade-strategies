## 一、这策略是个啥？

简单说，XebTradeStrat 就是一个：
- **只看一根均线就下单**的超级简单策略
- **根本不关心什么时候卖**的甩手掌柜
- **1分钟K线**上玩短线的急性子

就像你在马路上看到有人闯红灯——不是因为他素质差，而是因为他根本不管红绿灯，只看有没有车。XebTradeStrat 也差不多，它只管"短期均线从下面窜上来"这个信号，别的都不 cared 😂

## 二、核心配置：说白了就是"见好就收"

### 止盈规则（ROI 表）

```
持仓 < 2分钟 → 赚 0.2% 就跑 🤏
持仓 2-4分钟 → 赚 0.5% 就跑 🏃
持仓 > 4分钟  → 赚 1% 必须要跑 🤑
```

**翻译**：
这个策略的核心理念就是"见好就收"。甭管你持有多久，反正赚够了就跑。2分钟内赚 0.2% 就满足，4分钟以上才要求赚 1%。这不是"贪心不足蛇吞象"，而是"蚊子腿也是肉"——主打的就是一个积少成多！

### 止损规则

```
亏损 1% → 认赔走人 🏳️
利润回吐 0.05% → 立刻锁定利润 🪤
```

**翻译**：
亏 1% 就割肉，跑得比兔子还快。赚钱的时候更夸张，只要利润回吐 0.05%（也就是 0.0005），二话不说直接平仓。这也太保守了吧！有时候一根 K 线波动都不止 0.05% 啊 😅

## 三、1 个买入条件：我帮你分类好了

这策略只有**1 个买入条件**，简单到令人发指：

### 🎯 核心逻辑：EMA 黄金交叉

**代码逻辑**：
```python
# 5日均线 > 10日均线（多头排列）
# 且 昨天 5日均线 < 10日均线（今天刚刚金叉）
# 且 有成交量（不是空气币）
→ 买入！
```

**大白话**：
> "报告老板！5日均线刚刚从下面窜上来超过了10日均线，而且今天有实际成交量，没有庄家割韭菜！买！"

这就是经典的**黄金交叉**——均线界的"表白成功"。短期均线从下方突破长期均线，通常被解读为"要涨了"的信号。

## 五、卖出逻辑：比买入更佛系

### 5.1 分级止盈：赚多少跑

| 持仓时间 | 止盈点 | 策略心理 |
|---------|--------|---------|
| < 2 分钟 | 0.2% | 赶紧跑路，落袋为安 |
| 2-4 分钟 | 0.5% | 稍微贪一下 |
| > 4 分钟 | 1% | 这是我最后的底线 |

**大白话**：
持有不到 2 分钟就赚 0.2% 跑路——这也太急了吧？有时候手续费都不止 0.2% 啊！这是典型的"宁可错过，不可过错"心态。

### 5.2 特殊场景退出

| 场景 | 触发条件 | 大白话 |
|------|---------|--------|
| 止损 | 亏 1% | 认栽，不挣扎 |
| 追踪止损 | 利润回吐 0.05% | "我的钱是我的，一分都不能少！" |

**翻译**：
这个策略的追踪止损设置得太保守了。0.05% 是什么概念？也就是涨 1% 马上就跑，稍微回调一点点就被踢下车。这种设计在震荡市里会被反复打脸——买进去就涨，涨完就跌，跌一点点就被止损，然后看着价格又涨回去...心态会崩的 😅

4. **不管趋势**：牛市熊市都用同一套，容易逆势交易
5. **资金利用率低**：买了就跑，交易次数太多，手续费肉疼

## 十、想跑这个策略？先看看这些配置

### 10.1 交易对配置

| 配置项 | 建议值 | 吐槽 |

### 10.2 配置文件关键设置

```json
{
    "timeframe": "1m",
    "stoploss": -0.01,
    "minimal_roi": {
        "0": 0.01,
        "2": 0.005,
        "4": 0.002
    },
    "trailing_stop": true,
    "trailing_stop_positive": 0.0005
}
```

### 10.3 硬件要求（重要！）

这策略计算量极小，对硬件几乎没要求：

| 交易对数量 | 最低内存 | 推荐内存 | 体验 |
|-----------|---------|---------|------|
| 1-10 个 | 256MB | 512MB | 纵享丝滑 |
| 10-50 个 | 512MB | 1GB | 可能稍微卡顿 |
| 50+ 个 | 1GB | 2GB | 建议减少数量 |

**警告**：1 分钟 K 线本身数据量很大，即使策略简单，如果跑 100+ 交易对，API 请求也会很频繁，可能触发交易所限流 😅

### 10.4 回测 vs 实盘

**主要差异**：
1. **滑点**：1 分钟高频交易对滑点极其敏感，实盘成交价往往比回测差
2. **流动性**：大额订单可能买不到足够的量
3. **API 限流**：高频请求可能被交易所ban

**建议流程**：
1. **回测**：先跑 3 个月数据看看
2. **纸上交易**：模拟盘跑 1 个月
3. **小额实盘**：用 5%-10% 资金测试
4. **逐步加仓**：确认有效后再放大仓位

**别一上来就梭哈**，策略再好也得磨合！尤其是这种简单策略，往往回测美如画，实盘烂如渣。

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

XebTradeStrat 的回测数据往往看起来"还行"——但这有个陷阱：
- 1 分钟K线历史数据可能有很多"未来函数"
- 回测不考虑滑点和手续费
- 极端行情下策略完全失效

简单说就是：
> "回测赚100倍都不叫本事，实盘不亏钱才是本事。"

### 简单策略的隐藏风险

实盘时，你会发现：
- **假信号太多**：金叉是假的，买了就跌
- **止损太频繁**：1% 止损根本不够波动用的
- **手续费太高**：买买卖都要手续费，几百块就没了
- **心态会崩**：连续止损10次，你会怀疑人生

### 我的建议（真心话）

```
1. 别把它当主要策略，当练习工具
2. 实盘前必须模拟盘测试至少1个月
3. 资金控制在能承受亏损的范围
4. 准备好随时手动干预
5. 记住：简单不等于容易赚钱
```

**记住**：

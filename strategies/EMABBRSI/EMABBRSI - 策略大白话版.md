# EMABBRSI 策略：均线 + 布林带 + RSI 的"三合一"

> **外号**：三合一过滤器  
> **职业**：用 3 种指标确认趋势，只买"确定性"信号  
> **时间框架**：1 小时

---

## 一、这策略是个啥？

简单说，**EMABBRSI** 就是把三种常用指标组合起来：
- EMA 均线交叉（判断趋势方向）
- 布林带突破（找入场点）
- RSI 确认（过滤假信号）

就像一个相亲角：**要有钱（EMA）、有房（布林带）、有车（RSI）**——三个条件都满足才肯嫁！😂

这是**1 小时级别**的中长期策略，适合捕捉**趋势行情**！

## 二、核心配置：说白了就是"趋势跟随"

### 止盈规则（ROI 表）

```
立即出场（0分钟）     → 赚 14.14% 就跑！
25分钟后              → 赚 4.59% 就跑！
41分钟后              → 赚 2.07% 就跑！

```

**翻译**：这策略追求的是**中等趋势**，14% 就跑路，不贪心！

### 止损规则

```
硬止损：-20%
```

**翻译**：-20% 止损比较合理，给了足够波动空间！

## 三、3 个买入条件：我帮你分类好了

### 🎯 第 1 类：布林带下轨突破 + RSI 确认
**核心逻辑**：价格跌破布林带下轨后反弹 + RSI 确认企稳

**大白话**：
> "价格跌到布林带下轨了，而且 RSI 也从超卖恢复，说明跌够了，要反弹！"

**触发条件**：
- RSI > 33
- 收盘价从下方穿过布林带下轨

---

### 📈 第 2 类：EMA200 支撑买入
**核心逻辑**：价格回踩 EMA200 均线获得支撑

**大白话**：
> "价格跌到 200 日均线附近了，这是长期成本线，应该有支撑！"

**触发条件**：
- 前一 K 收盘价 > EMA200
- 本 K 低点 < EMA200（刺穿）
- 收盘价 > EMA200（收回）

---

### 🚀 第 3 类：黄金交叉（EMA50 上穿 EMA200）
**核心逻辑**：短期均线从下方穿过长期均线

**大白话**：
> "50 日均线穿过 200 日均线了，这是典型的多头信号！"

**触发条件**：
- EMA50 从下方穿过 EMA200

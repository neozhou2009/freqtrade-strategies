## 一、策略概览

**EMABBRSI** 是一种结合 EMA 交叉、RSI 和布林带突破的综合策略。策略在 1 小时时间框架下运行，通过多个买入条件提高信号质量。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 3 个独立条件（布林带突破 / EMA200 支撑 / 黄金交叉） |
| **卖出条件** | 2 个条件（布林带上轨 + RSI 超买 / 死亡交叉） |
| **时间框架** | 1 小时 |
| **依赖库** | TA-Lib, technical |

## 六、风险管理特色

### 6.1 无独立保护机制

策略没有独立的保护参数，主要依赖：
- 宽松硬止损（-20%）
- 时间止损（67 分钟后保本）
- 多条件过滤减少假信号

### 6.2 多条件组合的优势

三个买入条件互相配合，提高信号质量。

## 七、策略优势与局限

### ✅ 优势

1. **多条件确认**：3 种指标过滤，减少假信号
2. **中长期策略**：1 小时级别，不用天天看盘
3. **逻辑清晰**：每个条件都有明确逻辑
4. **适合趋势市**：趋势行情表现好

### ⚠️ 局限

1. **信号较少**：条件严格，可能很久都不买
2. **RSI > 91 太严格**：实际很难触发
3. **无保护机制**：震荡市可能连续亏损

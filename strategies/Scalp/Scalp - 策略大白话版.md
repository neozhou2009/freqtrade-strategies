# Scalp 策略：一分钟赚 1% 的小蜜蜂

> **外号**：蚊子肉收割机  
> **职业**：超短线狙击手  
> **时间框架**：1 分钟（够快吧？）

---

## 一、这策略是个啥？

简单说，**Scalp** 就是一个：
- 1 分钟看盘，赚 1% 就跑
- 用大量小交易覆盖偶尔的大亏损
- 作者建议同时跑 60+ 个交易对

就像一只勤劳的小蜜蜂，每次只采一点蜜，但采的花多了，蜜也就多了。🐝

---

## 二、核心配置：说白了就是"蚊子肉也是肉"

### 止盈规则（ROI 表）

```
利润 ≥ 1% → 立即止盈
```

**翻译**：看到 1% 利润就跑，多一秒都不等。这就像捡硬币，捡到就跑。

### 止损规则

```
亏损 ≥ 4% → 认栽！
```

**翻译**：止损是止盈的 4 倍！这就像赌 1 块钱赢 4 块钱，但输了要赔 16 块。需要超高的胜率才能赚钱。😅

## 三、1 个买入条件：简单粗暴

这策略的买入条件就一个，超级简单：

### 🎯 唯一买入信号

**核心逻辑**：超卖 + 趋势 + 反转确认

**大白话**：
> "价格开盘在 EMA 下面，而且 ADX 显示有趋势（不是乱震荡），随机指标已经超卖了，然后 K 线上穿 D 线，这时候我就冲进去！"

**经典台词**：

| 条件 | 代码 | 大白话翻译 |
|------|------|-----------|
| 条件 1 | `open < ema_low` | "开盘价在 EMA 下面，说明在下跌" |
| 条件 2 | `adx > 30` | "ADX 大于 30，有趋势在，不是瞎震荡" |
| 条件 3 | `fastk < 30` | "K 值低于 30，超卖了" |
| 条件 4 | `fastd < 30` | "D 值也低于 30，确认超卖" |
| 条件 5 | `fastk 上穿 fastd` | "K 线上穿 D 线，反转信号！" |

**简单说**：**跌到位了 + 有趋势 + 开始反弹 = 买！**

## 四、卖出逻辑：两种方式跑路

### 4.1 目标止盈

```
利润达到 1% → 跑！
```

**大白话**：赚够 1% 就撤，不贪心。

### 4.2 主动卖出信号

有两种情况会主动卖：

| 信号 | 条件 | 大白话 |
|------|------|--------|
| **EMA 止盈** | `open >= ema_high` | "价格跑到 EMA 上方了，该跑了" |
| **超买退出** | `fastk 上穿 70` | "K 值超过 70，超买了，赶紧跑" |
| **超买退出** | `fastd 上穿 70` | "D 值也超过 70，确认超买，快跑" |

**大白话**：
- 价格反弹到 EMA 上方 → 赚够了，撤！
- 随机指标超买 → 到顶了，撤！

## 五、指标系统：简单得可怜

### 5.1 EMA 三兄弟

```
ema_high = EMA(5) of high price
ema_close = EMA(5) of close price  
ema_low = EMA(5) of low price
```

**大白话**：用 5 周期的 EMA 分别追踪高、收、低价，形成一个"通道"。

### 5.2 ADX 趋势强度

```
ADX > 30 → 有趋势
ADX < 20 → 无趋势（震荡）
```

**大白话**：ADX 用来判断有没有趋势，小于 30 的时候策略根本不会买。

### 5.3 Stochastic Fast（随机快线）

```
K 周期：5
K 平滑：3
D 平滑：3
```

**大白话**：用快速版随机指标，反应更灵敏，适合 1 分钟的超短线。

### 5.4 布林带（仅绘图用）

```python
# 这个是画图用的，策略逻辑里没用！
bollinger = qtpylib.bollinger_bands(dataframe['close'], window=20, stds=2)
```

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **简单易懂**：就一个买入条件，小学生都能看懂
2. **执行快速**：1 分钟周期，快进快出
3. **目标明确**：1% 止盈，不纠结
4. **指标精简**：就 3 个核心指标，不花哨
5. **适合自动化**：规则明确，程序执行毫无压力

### ⚠️ 缺点（吐槽环节）

1. **风险收益比太差**：止损 4%，止盈 1%，赢 4 次才够亏 1 次
2. **没保护机制**：代码里啥保护都没有，得自己配
3. **手续费吃人**：高频交易手续费累积起来吓死人
4. **需要超多交易对**：作者建议 60+ 个，VPS 成本高
5. **网络延迟敏感**：1 分钟周期，延迟大点信号就废了

### 10.4 手续费影响（超级重要！）

超短线策略对手续费超级敏感：

```
假设手续费 0.1%（买 + 卖 = 0.2%）：
- 止盈 1%，手续费吃掉 0.2%，实际赚 0.8%
- 手续费占利润的 20%！

如果手续费 0.2%（买 + 卖 = 0.4%）：
- 止盈 1%，手续费吃掉 0.4%，实际赚 0.6%
- 手续费占利润的 40%！
```

**建议**：
- 找低手续费的交易所（VIP、返佣）
- 回测时务必加上手续费
- 如果手续费太高，这策略可能白干

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

Scalp 策略回测看起来可能很美：每次赚 1%，累积起来很可观。但要注意：

> **高频交易的手续费和滑点是隐藏杀手。回测 1% 止盈，实盘可能只赚 0.6%。**

简单说就是：**理论很美好，实盘很骨感。**

### 风险收益比是个大坑

这策略的风险收益比是 1:4：
- 赢 4 次才能抵消亏 1 次
- 需要至少 80% 胜率才能盈亏平衡
- 考虑手续费后，需要更高的胜率

### 高频交易的隐藏风险

实盘时，高频交易可能导致：
- **滑点累积**：每笔交易都有滑点，高频累积起来吓人
- **网络延迟**：1 分钟周期，信号稍纵即逝
- **交易所限流**：太频繁可能被交易所限制
- **手续费侵蚀**：高频交易手续费是最大敌人

### 我的建议（真心话）

```
1. 必须加上保护机制（原代码没有！）
2. 务必找低手续费渠道
3. 回测一定要加上手续费
4. 先用模拟盘测试至少 1 个月
5. 确认胜率能到 70%+ 再实盘
6. 实盘仓位从很小开始
```

**记住**：止损是止盈的 4 倍，赢 4 次才够亏 1 次。胜率不够高，这策略就是送钱机器！🙏

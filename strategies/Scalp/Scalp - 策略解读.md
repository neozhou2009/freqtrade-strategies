## 一、策略概览

Scalp 是一个专注于微小利润的超短线（Scalping）策略，设计理念是"大量小赚覆盖小亏"。策略采用 1 分钟时间框架，目标止盈仅 1%，止损 4%，通过高频交易积累收益。推荐同时运行至少 60 个交易对，以分散风险并提高整体盈利概率。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 1 个买入信号，超卖反弹逻辑 |
| **卖出条件** | 2 类卖出信号（EMA 止盈 + 超买退出） |
| **保护机制** | 无内置保护机制（依赖外部配置） |
| **时间框架** | 1 分钟（超短线） |
| **依赖库** | talib, qtpylib, pandas |
| **推荐同时持仓** | ≥ 60 个交易对 |

### 2.1 基础风险参数

# ROI 退出表

- **设计哲学**：通过大量交易分散风险，用胜率优势积累收益

**设计理念**：

## 三、买入条件详解

### 3.1 唯一买入信号

Scalp 策略采用单一买入信号，逻辑简洁明了：

```python
# 买入条件
(
    (dataframe['open'] < dataframe['ema_low']) &      # 开盘价低于 EMA 低点
    (dataframe['adx'] > 30) &                          # ADX > 30（趋势强度）
    (
        (dataframe['fastk'] < 30) &                    # Fast K < 30（超卖）
        (dataframe['fastd'] < 30) &                    # Fast D < 30（超卖）
        (qtpylib.crossed_above(dataframe['fastk'], dataframe['fastd']))  # K 线上穿 D 线
    )
)
```

### 3.2 买入逻辑拆解

| 条件 | 指标 | 阈值 | 含义 |
|------|------|------|------|
| **条件 1** | 开盘价 < EMA(5) 低点 | - | 价格在 EMA 低点下方开盘 |
| **条件 2** | ADX | > 30 | 趋势强度足够，非无方向震荡 |
| **条件 3** | Fast K | < 30 | 随机指标处于超卖区间 |
| **条件 4** | Fast D | < 30 | 随机指标确认超卖 |
| **条件 5** | Fast K 上穿 Fast D | - | 随机指标金叉，反转信号 |

### 3.3 买入信号特点

**信号类型**：超卖反弹型

**适用场景**：
- 下跌趋势中的短期反弹
- 横盘震荡中的超卖位置
- 趋势行情中的回调买入

**不适用场景**：
- 单边暴涨行情（无超卖机会）
- 无趋势震荡（ADX < 30）

## 四、卖出逻辑详解

### 4.1 ROI 止盈

```
利润率阈值    止盈比例
──────────────────────
≥ 1%         立即止盈
```

**设计理念**：追求微小但稳定的利润，通过高频交易积累收益。

### 4.2 卖出信号

策略使用两类卖出信号：

```python
# 卖出条件
(
    (dataframe['open'] >= dataframe['ema_high'])  # 条件 1：开盘价 >= EMA 高点
) |
(
    (qtpylib.crossed_above(dataframe['fastk'], 70)) |  # 条件 2：Fast K 上穿 70
    (qtpylib.crossed_above(dataframe['fastd'], 70))    # 条件 3：Fast D 上穿 70
)
```

**卖出信号分类**：

| 信号类型 | 触发条件 | 含义 |
|---------|---------|------|
| **EMA 止盈** | 开盘价 ≥ EMA(5) 高点 | 价格反弹到 EMA 上方 |
| **超买退出** | Fast K 上穿 70 | 随机指标进入超买区 |
| **超买退出** | Fast D 上穿 70 | 随机指标确认超买 |

### 4.3 卖出逻辑特点

**多维度出场**：
- EMA 方向：价格反弹到位即出
- 随机指标：进入超买即出，不贪心

**出场特点**：
- 快进快出，不持仓过久
- 利润达到 1% 或指标超买即退出

## 五、技术指标体系

### 5.1 核心指标

| 指标类别 | 具体指标 | 用途 |
|---------|---------|------|
| **EMA 系列** | EMA(5) 高/收/低 | 价格通道判断 |
| **趋势强度** | ADX | 确认趋势存在 |
| **随机指标** | Stochastic Fast (5,3,3) | 超卖超买判断 |
| **布林带** | 20 周期，2 倍标准差 | 辅助参考（仅绘图用） |

### 5.2 EMA 三线系统

```python
# EMA 计算
dataframe['ema_high'] = ta.EMA(dataframe, timeperiod=5, price='high')
dataframe['ema_close'] = ta.EMA(dataframe, timeperiod=5, price='close')
dataframe['ema_low'] = ta.EMA(dataframe, timeperiod=5, price='low')
```

**设计理念**：
- 使用 EMA 而非 SMA，反应更快
- 分别计算高、收、低价的 EMA
- 构建动态价格通道

### 5.3 随机指标 Fast 版本

```python
# Stochastic Fast 参数
stoch_fast = ta.STOCHF(dataframe, 5, 3, 0, 3, 0)
# 参数解读：K 周期 5，K 平滑 3，D 平滑 3
```

**为什么用 Fast 而非 Slow**：
- Fast 版本反应更快，适合 1 分钟超短线
- 更早捕捉反转信号
- 牺牲一定稳定性换取速度

## 六、风险管理特色

### 6.1 无内置保护机制

策略代码中未定义 `protections` 属性，这意味着：

- 无冷却期保护
- 无最大回撤保护
- 无止损频率限制
- 完全依赖外部配置

**建议配置**：在 `config.json` 中手动添加保护机制：

```json
{
  "protections": [
    {
      "method": "CooldownPeriod",
      "stop_duration": 5
    },
    {
      "method": "MaxDrawdown",
      "trade_limit": 20,
      "stop_duration": 60,
      "max_allowed_drawdown": 0.15
    },
    {
      "method": "StoplossGuard",
      "lookback_period": 60,
      "trade_limit": 3,
      "stop_duration": 30
    }
  ]
}
```

### 6.2 风险收益比分析

| 项目 | 数值 | 分析 |
|------|------|------|
| 止盈目标 | 1% | 微小利润 |
| 止损线 | 4% | 止损是止盈的 4 倍 |
| 风险收益比 | 1:4 | 需要约 80% 胜率才能盈亏平衡 |

**风险提示**：
- 单笔风险较高（4% 止损）
- 需要高胜率支撑
- 适合用大量交易分散风险

### 6.3 多交易对策略

策略作者建议同时运行至少 60 个交易对：

> "we recommend to have at least 60 parallel trades at any time to cover non avoidable losses."

**设计理念**：
- 通过大量并行交易分散风险
- 用胜率优势覆盖单笔亏损
- 大数法则发挥作用

## 七、策略优势与局限

### ✅ 优势

1. **逻辑简洁**：买入卖出条件清晰，易于理解和维护
2. **执行快速**：1 分钟周期，入场出场迅速
3. **指标精简**：仅使用 EMA、ADX、Stochastic 三个核心指标
4. **适合量化**：规则明确，适合自动化执行
5. **止盈明确**：1% 目标清晰，不贪心

### ⚠️ 局限

1. **风险收益比差**：止损 4%，止盈 1%，需要极高胜率
2. **无保护机制**：需手动配置，容易被忽视
3. **网络依赖强**：1 分钟周期对延迟敏感
4. **交易成本高**：高频交易手续费累积可观
5. **需要大量交易对**：60+ 交易对对 VPS 性能有要求

## 九、适用市场环境详解

Scalp 是一个超短线策略，核心是 **捕捉超卖反弹机会**。基于其代码架构，它最适合 **有趋势的高波动市场**，而在 **低波动无趋势市场** 时表现不佳。

### 9.1 策略核心逻辑

- **快速出场**：1% 止盈或超买退出

## 十、重要提醒：高频交易的代价

### 10.1 手续费影响

超短线策略对手续费极其敏感：

```
假设手续费 0.1%：
- 单笔交易成本：0.2%（买入 + 卖出）
- 止盈 1% 中，手续费占 20%！
- 实际净收益：1% - 0.2% = 0.8%
```

**建议**：
- 使用低手续费交易所
- 考虑手续费返还
- 回测时务必包含手续费

### 10.2 硬件要求

| 交易对数量 | 最低内存 | 推荐内存 |
|-----------|---------|---------|
| 60 对 | 4GB | 8GB |
| 100 对 | 8GB | 16GB |
| 150+ 对 | 16GB | 32GB |

### 10.3 网络延迟影响

1 分钟周期对延迟敏感：

- 理想延迟：< 100ms
- 可接受延迟：100-500ms
- 危险延迟：> 500ms

**建议**：
- 选择靠近交易所的 VPS
- 使用稳定的网络连接
- 避免高峰期交易

### 10.4 回测与实盘的差异

高频策略回测与实盘差异显著：

| 因素 | 回测 | 实盘 |
|------|------|------|
| **滑点** | 可忽略 | 显著 |
| **成交速度** | 瞬时 | 受延迟影响 |
| **手续费** | 可能未计入 | 必须计入 |
| **市场冲击** | 无 | 大单有影响 |

## 十一、总结

**Scalp** 是一个设计简洁的超短线策略。它的核心价值在于：

1. **逻辑清晰**：单一买入信号，易于理解和维护
2. **执行迅速**：1 分钟周期，快进快出
3. **目标明确**：1% 止盈，不贪心

对于量化交易者而言，这是一个适合高频交易的策略，但需要注意：

- **风险收益比差**：需要高胜率支撑
- **无内置保护**：需手动配置
- **手续费侵蚀**：高频交易手续费累积可观
- **网络敏感**：1 分钟周期对延迟要求高

建议在充分回测并配置保护机制后，先用小仓位实盘测试，确认效果后再扩大规模。

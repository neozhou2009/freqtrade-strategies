# NostalgiaForInfinityV4 策略大白话版

## 一、这个策略是干啥的？

你有没有想过让电脑自动帮你炒币？NostalgiaForInfinityV4（咱们叫它NFI4吧）就是干这个的——它是一个自动交易策略，专门用来在加密货币市场上自动买入和卖出。

简单来说，它就像一个24小时不睡觉的"机器人交易员"，盯着K线图看，符合条件就买，赚到钱就卖，亏到一定程度就止损。它的设计理念是：跟着大趋势走，在价格回调的时候买入，等价格涨过头了就卖出。

这个策略是给Freqtrade这个开源交易机器人用的，Freqtrade就像个交易平台，而NFI4就是跑在上面的"交易大脑"。

---

## 二、它用多长时间看盘？

NFI4用的是两个时间周期一起看：

**主视角：5分钟K线**
就是每5分钟形成一个新蜡烛图，这是策略做决定的主要依据。5分钟周期比较灵活，既能抓住日内波动，又不会太敏感导致频繁交易。

**辅助视角：1小时K线**
这是用来确认大方向的。当1小时图上趋势向上，而5分钟图上价格回调时，才会考虑买入。这样就能避免"大趋势往下却去抄底"这种亏钱操作。

打个比方：5分钟图就像放大镜，帮你看清楚细节；1小时图就像望远镜，帮你确认大方向。两个一起用，看得更准。

## 三、用到了哪些技术指标？

别被吓到，虽然指标不少，但每个都有用处。我一个个给你讲清楚：

### 3.1 移动平均线（MA）

这就是把过去N根K线的价格加起来除以N，算出一个"平均价"。有两种：

**EMA（指数移动平均线）**：更重视最近的价格，反应快。策略里用了EMA12、EMA20、EMA26、EMA50、EMA100、EMA200。

**SMA（简单移动平均线）**：所有价格一视同仁，比较平滑。策略里用了SMA5、SMA30、SMA200。

用这些线干啥呢？主要是判断趋势。比如当价格在EMA200上方，说明长期趋势向上；当EMA50在EMA200上方，说明中期趋势向上。策略大部分买入条件都要求"趋势向上"，就是靠这些均线判断的。

### 3.2 RSI（相对强弱指标）

这是个0到100之间的数字，用来判断价格是不是"过头了"：

- RSI低于30：价格可能跌太多了，随时可能反弹——**该看看能不能买了**
- RSI高于70：价格可能涨太多了，随时可能回调——**该考虑卖了**

策略大量使用RSI。买入时要求RSI低（表示超卖），卖出时要求RSI高（表示超买）。

### 3.3 MFI（资金流量指标）

跟RSI很像，但它还考虑了成交量。简单理解就是"带成交量的RSI"。策略在买入条件里用它来确认：不仅价格超卖了，而且资金也在流出——这时候买入更安全。

### 3.4 布林带（Bollinger Bands）

就是三条线：中间是移动平均线，上下各一条是标准差轨道。价格大部分时间在带子里跑。

- 价格碰到下轨：可能跌多了，要反弹
- 价格碰到上轨：可能涨多了，要回调

策略用两套布林带：一套20周期（反应快），一套40周期（更稳定）。买入时常用"价格低于下轨"作为信号，卖出时用"价格突破上轨"作为信号。

### 3.5 鳄鱼线（Alligator）

这个指标名字挺酷，三条线分别叫"嘴唇"、"牙齿"、"下颚"。鳄鱼嘴巴张开的时候就是趋势来了：

- 嘴唇>牙齿>下颚：上涨趋势（鳄鱼张嘴向上）
- 三条线纠缠：横盘震荡（鳄鱼睡觉）
- 嘴唇<牙齿<下颚：下跌趋势（鳄鱼张嘴向下）

策略在买入条件8里用这个指标抓趋势启动的机会。

### 3.6 EWO（艾略特波浪震荡指标）

这是一个自定义指标，计算方法是：

```
EWO = (短期EMA - 长期EMA) / 当前价格 × 100
```

- EWO为正：短期动量比长期强，可能在上涨波浪
- EWO为负：短期动量比长期弱，可能在下跌波浪

策略用这个指标来辅助判断"是不是该抄底了"或者"趋势是不是要反转了"。

## 四、怎么防止"接飞刀"？

"接飞刀"就是价格正在暴跌的时候你去买，结果越买越跌。NFI4设计了专门的**下跌保护机制**。

它检查四个时间维度的下跌幅度：

| 时间范围 | 常规保护阈值 | 严格保护阈值 |
|---------|------------|------------|
| 单根K线 | < 2% | < 1.5% |
| 2根K线 | < 14% | < 6% |
| 12根K线（1小时） | < 32% | < 24% |
| 144根K线（12小时） | < 50% | < 40% |

只有这四个条件**全部满足**，才会考虑买入。这就像一个安全网，帮你避免在价格崩跌过程中去"接飞刀"。

---

## 五、怎么防止"追高"？

追高就是价格已经涨了很多你还去买，结果买在山顶上。NFI4设计了**暴涨保护机制**。

它检查24小时、36小时、48小时三个时间窗口的最高涨幅：

| 时间窗口 | 常规保护 | 严格保护 |
|---------|---------|---------|
| 24小时 | 涨幅<46% 或 回调够深 | 涨幅<40% 或 回调够深 |
| 36小时 | 涨幅<56% 或 回调够深 | 涨幅<56% 或 回调够深 |
| 48小时 | 涨幅<85% 或 回调够深 | 涨幅<68% 或 回调够深 |

举个例子：如果某个币24小时涨了50%，超过了46%的阈值。但如果它从最高点已经回调了不少，策略还是可以考虑买入。这就是为什么条件里有个"或回调够深"——涨太多没关系，只要回调了，风险就释放了。

## 六、什么时候买？

NFI4设计了**17个买入条件**，每个条件都可以单独开或关。我挑几个典型的给你讲：

### 条件1：趋势+超卖组合买入

**简单说**：大趋势向上，价格短期回调超卖了，就买。

**具体要求**：
- 1小时EMA50在EMA200上方（大趋势向上）
- SMA200在往上走（20根K线前更高）
- 没暴跌也没暴涨（保护机制通过）
- 36小时内至少涨了2.2%（不是死币）
- 1小时RSI在30-80之间
- 5分钟RSI低于36
- MFI低于26

**人话翻译**：大方向对，小周期超卖，成交量正常，抄底！

### 条件3：布林带反弹买入

**简单说**：价格跌破布林带下轨，可能会弹回来，就买。

**具体要求**：
- 价格在1小时EMA200附近（大支撑位）
- EMA排列整齐（趋势向上）
- 布林带够宽（波动够大）
- 收盘价低于下轨
- 收盘价创了新低

**人话翻译**：价格跌破下轨，就像橡皮筋拉太紧，松手后会弹回来。

### 条件8：鳄鱼线趋势买入

**简单说**：鳄鱼嘴张开了，趋势来了，跟着买。

**具体要求**：
- 1小时趋势向上
- 鳄鱼三条线排列：嘴唇>牙齿>下颚
- 三条线都在往上走
- 当前K线是阳线
- RSI不太高

**人话翻译**：鳄鱼张嘴了，还张得越来越大，赶紧跟着走！

### 条件17：极度超卖买入

**简单说**：跌惨了，可能反弹，搏一把。

**具体要求**：
- 下跌保护开启（最严格模式）
- 价格低于EMA20的95.8%
- EWO低于-12（极度负值）

**人话翻译**：跌太多了，反弹概率大，但用最严格的保护机制防止继续暴跌。

## 七、什么时候卖？

卖出也很重要，买了不卖等于没赚。NFI4有**8个卖出条件**，我给你讲讲：

### 条件1：连续超买卖出

**简单说**：RSI太高，价格连续6根K线在布林带上轨上面，卖！

**条件**：RSI>79.5，连续6根K线收盘价>上轨

**人话**：涨疯了，已经完全脱离正常区间，赶紧落袋为安。

### 条件3：RSI极值卖出

**简单说**：RSI超过82，不管其他条件，直接卖。

**人话**：太热了，随时可能冷却，先跑了再说。

### 条件4：双周期超买卖出

**简单说**：5分钟RSI和1小时RSI都超买，两个周期一起喊"该卖了"。

**条件**：5分钟RSI>73.4，1小时RSI>79.6

**人话**：短周期和长周期都说过热了，可信度更高。

### 条件7：趋势反转卖出

**简单说**：1小时RSI超买，同时短期均线死叉，卖！

**条件**：1小时RSI>81.7，EMA12下穿EMA26

**人话**：不仅过热，趋势也开始转向了，果断离场。

## 八、止盈怎么分层次？

NFI4最聪明的地方是**分层止盈**。简单说就是：赚得越多，对卖出条件越宽松。

看这个表格：

| 已经赚了 | RSI低于这个值就卖 |
|---------|-----------------|
| >25% | 50（很宽松） |
| >8% | 48 |
| >5% | 43 |
| >3% | 36 |
| >1% | 30（很严格） |

**人话翻译**：
- 只赚了1%，RSI要跌到30才卖（要求苛刻）
- 已经赚了25%，RSI跌到50就卖（比较容易触发）

为什么这么设计？因为赚得越多，越要保护利润。只要RSI开始走弱，就赶紧卖掉一部分。

另外还有"均线下方保护止盈"：

| 已经赚了 | 触发条件 |
|---------|---------|
| >2% | 价格跌破EMA200 |
| >3.5% | SMA200开始下降 |
| >7% | 价格跌破EMA100 |

**人话**：赚了钱之后，如果价格开始跌破重要均线，不管RSI怎么样，先卖出保护利润。

## 九、追踪止盈是啥意思？

还有一种止盈方式叫**追踪止盈**，就像遛狗一样，跟着价格走，但保持在一定距离。

**策略设置**：
- 当盈利超过3%，开始"遛狗"
- 止盈线设在最高点下方1%

**举个例子**：
- 你买入后价格涨到盈利5%，这时候最高点记录为5%
- 价格回落到盈利4%，还在1%范围内，继续持有
- 价格继续回落到盈利3.9%，从最高点（5%）回落了1.1%，超过1%了，卖出！

**人话**：给价格一定的"活动空间"，但如果从最高点回落太多，就赶紧卖掉。

## 十、止损怎么设置？

止损就是亏到一定程度就认输，防止越亏越多。

**固定止损**：-10%
- 亏到10%就自动卖出，不给你犹豫的机会

**追踪止损**：
- 盈利超过3%后激活
- 追踪距离1%

**人话**：
- 刚买入的时候，最大亏损10%
- 赚到3%以后，改成"从最高点回落1%就卖"

## 十一、运行这个策略要配啥？

### 必须设置：

```
时间周期：5分钟（必须，不能改）
use_sell_signal: true（必须启用）
sell_profit_only: false（必须关闭）
ignore_roi_if_buy_signal: true（必须开启）
```

### 建议设置：

```
并行交易数：4-6个
计价货币：USDT/BUSD等稳定币
每个交易对资金：无限模式（让策略自己分配）
交易对数量：40-80个
```

### 千万别碰：

```
杠杆代币（*BULL, *BEAR, *UP, *DOWN）
新上市的币（数据不够）
流动性太差的币
```

## 十二、怎么用好这个策略？

### 第一步：先回测！

**别一上来就实盘**，先用历史数据测试：

```bash
freqtrade backtesting --strategy NostalgiaForInfinityV4 --timerange 20230101-20231231
```

看看过去一年能赚多少，最大回撤多少。

### 第二步：看哪些条件效果好

策略有17个买入条件和8个卖出条件，每个都可以单独开关。你可以：

- 先全部打开回测
- 然后一个一个关掉看效果
- 找出哪些条件贡献最大

### 第三步：模拟盘验证

回测表现好，不代表实盘也好。先开模拟盘跑几天，看看有没有意外情况。

### 第四步：小资金实盘

确认没问题了，先用小资金实盘，逐步加仓。

## 十三、优缺点总结

### 优点：

✅ **条件模块化**：17买8卖，可以自由组合，灵活调整

✅ **保护机制全**：下跌保护、暴涨保护，防止极端行情

✅ **双周期验证**：1小时看方向，5分钟找机会，可靠性高

✅ **止盈分层次**：赚得越多，保护越严，符合人性

✅ **参数可优化**：所有关键参数都能调，可以针对不同币种优化

### 缺点：

❌ **参数太多**：100多个参数，新手容易搞晕

❌ **止损较宽**：-10%的止损，单笔亏损可能较大

❌ **时间框架固定**：只能用5分钟，想用别的周期要大改

❌ **启动数据多**：需要33小时以上的历史数据才能运行

❌ **优化难**：参数太多，优化起来很慢，还容易过拟合

### 适合谁用：

- 有一定Freqtrade使用经验的人
- 愿意花时间调参优化的人
- 想要中长期稳定收益的人
- 能承受一定波动的人

### 不适合谁：

- 刚入门的新手
- 想一夜暴富的人
- 不喜欢折腾参数的人
- 对回撤敏感的人

## 最后的话

NostalgiaForInfinityV4是一个设计精良的趋势+反转策略。它的核心思想很简单：**跟着趋势走，回调就买入，涨多了就卖出**。但实现起来很复杂，用了大量的指标和保护机制。

用好这个策略的关键是：**理解它为什么这样做决定**。每个买入条件、每个卖出条件、每个保护机制，背后都有它的逻辑。理解了这些，你才能在市场变化时做出正确的调整。

记住：**没有完美的策略，只有适合你的策略**。NFI4在合适的市场环境下表现很好，但也会遇到不顺的时候。保持学习，持续优化，才是量化交易的长期生存之道。

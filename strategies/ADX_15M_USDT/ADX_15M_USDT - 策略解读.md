## 一、策略概览

ADX_15M_USDT 是一个专为 15 分钟级别设计的 USDT 交易对策略。该策略在 ADXMomentum 的基础上进行了优化，引入了分级止盈系统和更精细的入场条件。核心特点是通过 DI 交叉捕捉趋势启动点，并利用分时 ROI 实现收益最大化。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 4 个条件（趋势强度+方向强度+交叉信号） |
| **卖出条件** | 4 个条件（趋势反转信号） |
| **保护机制** | 分级 ROI 止盈 + -12.55% 止损 |
| **时间框架** | 15 分钟 (15m) |
| **依赖库** | talib (ADX, PLUS_DI, MINUS_DI, SAR, MOM), qtpylib |
| **启动蜡烛** | 约 30 根（依赖指标周期） |

## 二、策略配置解析

### 2.1 分级止盈系统（ROI 表）

```python
# ROI 退出表
minimal_roi = {
    "0": 0.26552,    # 立即达到 26.552% 利润退出
    "30": 0.10255,   # 持仓 30 分钟后，最低 10.255% 利润退出
```

**设计思路**：
- **高止盈目标**：默认目标 26.55%，捕捉较大趋势
- **时间衰减**：随持仓时间延长，止盈目标降低，提高成交概率
- **动态适应**：持仓 9 小时后不再要求利润，交由信号控制

### 2.2 止损设置

```python
stoploss = -0.1255  # -12.55% 止损
```

**设计理念**：
- 止损比例适中（约 12.55%）
- 比 ADXMomentum 的 -25% 更严格
- 适合 15 分钟级别的中短线交易

## 三、买入条件详解

### 3.1 核心指标组合

策略使用独立的买入和卖出指标集：

| 指标类别 | 买入指标 | 卖出指标 | 参数 |
|---------|---------|---------|------|
| 趋势强度 | adx | sell-adx | 14 周期 |
| 多头强度 | plus_di | sell-plus_di | 25 周期 |
| 空头强度 | minus_di | sell-minus_di | 25 周期 |
| 趋势跟踪 | sar | sell-sar | 默认 |
| 动量 | mom | sell-mom | 14 周期 |

**设计特点**：买入和卖出使用完全独立的指标集，可以实现更灵活的参数调优。

### 3.2 买入条件详解

```python
def populate_entry_trend(self, dataframe: DataFrame, metadata: dict) -> DataFrame:
    dataframe.loc[
        (
            (dataframe['adx'] > 16) &                                      # 条件1
            (dataframe['minus_di'] > 4) &                                  # 条件2
            (dataframe['plus_di'] > 20) &                                  # 条件3
            (qtpylib.crossed_above(dataframe['plus_di'], dataframe['minus_di']))  # 条件4
        ),
        'buy'] = 1
    return dataframe
```

#### 条件解析

| 条件编号 | 条件内容 | 技术含义 |
|---------|---------|---------|
| 条件 #1 | `adx > 16` | ADX 大于 16，表示有一定趋势（比 ADXMomentum 的 25 更宽松） |
| 条件 #2 | `minus_di > 4` | 空头方向指标大于 4（非极端空头状态） |
| 条件 #3 | `plus_di > 20` | 多头方向指标大于 20，多头力量较强 |
| 条件 #4 | `plus_di 上穿 minus_di` | 多头方向指标上穿空头，确认趋势启动 |

### 3.3 买入信号分类

| 信号维度 | 指标 | 判断标准 | 与 ADXMomentum 对比 |
|---------|------|---------|-------------------|
| **趋势强度** | ADX | > 16（更宽松） | ADXMomentum 要求 > 25 |
| **方向强度** | PLUS_DI | > 20（稍宽松） | ADXMomentum 要求 > 25 |
| **交叉确认** | DI 交叉 | 上穿确认 | ADXMomentum 仅对比大小 |
| **空头过滤** | MINUS_DI | > 4（确保非极端） | ADXMomentum 无此条件 |

**关键区别**：ADX_15M_USDT 使用 DI **交叉**信号，而非简单的对比，能更精确捕捉趋势启动点。

## 四、卖出逻辑详解

### 4.1 卖出信号系统

```python
def populate_exit_trend(self, dataframe: DataFrame, metadata: dict) -> DataFrame:
    dataframe.loc[
        (
            (dataframe['adx'] > 43) &                                      # 条件1
            (dataframe['minus_di'] > 22) &                                # 条件2
            (dataframe['plus_di'] > 20) &                                  # 条件3
            (qtpylib.crossed_above(dataframe['sell-minus_di'], dataframe['sell-plus_di']))  # 条件4
        ),
        'sell'] = 1
    return dataframe
```

### 4.2 卖出条件解析

| 条件编号 | 条件内容 | 技术含义 |
|---------|---------|---------|
| 条件 #1 | `adx > 43` | 趋势极度强势（ADX 很高） |
| 条件 #2 | `minus_di > 22` | 空头方向指标较强 |
| 条件 #3 | `plus_di > 20` | 多头方向指标仍在高位 |
| 条件 #4 | `minus_di 上穿 plus_di` | 空头上穿多头，趋势反转 |

### 4.3 卖出条件设计分析

卖出条件的设计与买入条件存在明显差异：

| 维度 | 买入条件 | 卖出条件 | 设计意图 |
|------|---------|---------|---------|
| **ADX 阈值** | > 16（宽松） | > 43（严格） | 买入要宽松，卖出要严格 |
| **DI 交叉** | 多头上穿 | 空头上穿 | 捕捉趋势反转 |
| **MINUS_DI** | > 4 | > 22 | 卖出时要求空头已经很强 |

### 4.4 退出机制总结

策略有四种退出方式：

| 退出方式 | 触发条件 | 说明 |
|---------|---------|------|
| **ROI 止盈** | 利润 ≥ 26.55%（立即） | 捕捉大趋势 |
| **ROI 衰减** | 时间衰减目标 | 提高成交概率 |
| **止损** | 亏损 ≥ 12.55% | 风险控制 |
| **信号卖出** | 四条件全部满足 | 趋势反转信号 |

```python
# 买入指标
```

## 六、风险管理特色

### 6.1 分级止盈机制

```
持仓时间      最低利润要求
────────────────────────────
0-30 分钟     26.552%
30-210 分钟   10.255%
210-540 分钟  3.545%
540+ 分钟     无要求
```

**设计理念**：
- 早期追求高收益（26.55%）
- 随时间推移降低预期
- 最终交由信号控制

### 6.2 止损设置

**与 ADXMomentum 对比**：

### 6.3 qtpylib 交叉检测

## 七、策略优势与局限

### ✅ 优势

1. **分级止盈系统**：时间衰减机制提高成交概率，平衡收益与成交
2. **交叉信号精确**：使用 DI 交叉而非简单对比，捕捉趋势启动点
3. **买入条件宽松**：ADX > 16 比传统 25 更宽松，增加交易机会
4. **独立指标集**：买入卖出指标独立，便于未来优化
5. **15 分钟级别**：适合日内交易，资金周转快

### ⚠️ 局限

1. **卖出条件严格**：ADX > 43 可能难以满足，导致持仓时间过长
2. **参数复杂**：ROI 表参数需要根据市场调整
3. **指标冗余**：MOM 和 SAR 计算但未使用
4. **止盈目标较高**：26.55% 的目标可能在震荡市场难以达成

## 九、适用市场环境详解

ADX_15M_USDT 属于**趋势突破型策略**。基于其代码架构，它最适合**趋势启动初期**，而在**震荡市**时可能产生假信号。

### 9.1 策略核心逻辑

- **宽松入场**：ADX > 16 放宽条件，增加交易机会

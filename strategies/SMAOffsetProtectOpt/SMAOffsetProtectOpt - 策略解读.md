## 一、策略概览

SMAOffsetProtectOpt 是一个基于移动平均线偏移的价格突破策略，结合 Elliott Wave Oscillator（EWO）和 RSI 进行趋势过滤。其核心理念是利用均线偏移创造一个"打折区"，在价格低于偏移均线时寻找买入机会，同时通过 EWO 判断市场动能方向。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 2 个独立买入信号，基于 EWO 高/低阈值分流 |
| **卖出条件** | 1 个基础卖出信号 + ROI 分级退出 |
| **保护机制** | RSI 过滤 + EWO 动能过滤 + 固定止损 |
| **时间框架** | 主时间框架 5m + 信息时间框架 1h |
| **依赖库** | talib, numpy, qtpylib, technical |

## 三、买入条件详解

### 3.1 核心买入逻辑

策略使用 **EMA 偏移买入线** 作为核心入场参考：

```python
ma_buy = EMA(close, base_nb_candles_buy) * low_offset
```

**偏移系数的作用**：当 `low_offset = 0.975` 时，买入线被下移 2.5%，创造一个"打折区"，只有价格低于均线的 97.5% 时才会触发买入。

### 3.2 双通道买入条件

#### 条件 #1：EWO 高阈值买入（趋势确认型）

```python
# 逻辑
- 收盘价 < ma_buy（价格低于偏移均线）
- EWO > ewo_high（EWO 高于高阈值，表示上涨动能）
- RSI < rsi_buy（RSI 未过热）
- 成交量 > 0
```

**解读**：价格回调到打折区，但 EWO 显示上涨动能依然强劲，属于"强势回调买入"。

#### 条件 #2：EWO 低阈值买入（极端超卖型）

```python
# 逻辑
- 收盘价 < ma_buy（价格低于偏移均线）
- EWO < ewo_low（EWO 低于低阈值，表示极端超卖）
- 成交量 > 0
```

**解读**：价格深度下跌，EWO 达到极端负值，可能触底反弹，属于"抄底买入"。

### 3.3 买入条件分类

| 条件组 | 条件编号 | 核心逻辑 | 适用场景 |
|-------|---------|---------|---------|
| 趋势回调 | #1 | EWO 高 + RSI 正常 | 上升趋势中的健康回调 |
| 极端抄底 | #2 | EWO 极低 | 超卖反弹机会 |

## 四、卖出逻辑详解

### 4.1 卖出信号机制

策略使用 **EMA 偏移卖出线** 作为退出参考：

```python
ma_sell = EMA(close, base_nb_candles_sell) * high_offset
```

当 `high_offset = 1.012` 时，卖出线被上移 1.2%，形成"溢价区"。

### 4.2 卖出条件

```python
# 卖出信号
- 价格向下穿越 ma_sell（crossed_below）
- 成交量 > 0
```

**注意**：虽然卖出线在均线上方，但触发条件是"向下穿越"，意味着价格从高位回落到卖出线以下时触发卖出。

## 五、技术指标体系

### 5.1 核心指标

| 指标类别 | 具体指标 | 用途 |
|---------|---------|------|
| 趋势指标 | EMA（可变周期） | 确定趋势方向和买卖基准线 |
| 动量指标 | Elliott Wave Oscillator (EWO) | 判断市场动能强度和超买超卖 |
| 摆动指标 | RSI（14周期） | 过滤过热买入信号 |
| 成交量 | Volume | 确保市场流动性 |

### 5.2 Elliott Wave Oscillator (EWO) 详解

```python
def EWO(dataframe, ema_length=5, ema2_length=35):
    ema1 = EMA(close, ema_length)   # 快速 EMA
    ema2 = EMA(close, ema2_length)  # 慢速 EMA
    emadif = (ema1 - ema2) / close * 100
    return emadif
```

**EWO 解读**：
- 正值越大 = 上涨动能越强
- 负值越大 = 下跌动能越强（超卖）
- 零轴附近 = 市场震荡

策略使用 `fast_ewo=50` 和 `slow_ewo=200`，这是一个相对慢速的 EWO 配置。

## 六、风险管理特色

### 6.1 多层过滤机制

| 过滤层 | 机制 | 作用 |
|--------|------|------|
| 第一层 | 价格偏移（low_offset） | 只在打折区买入 |
| 第二层 | EWO 高/低阈值 | 确认市场动能状态 |
| 第三层 | RSI 过滤 | 防止追高 |
| 第四层 | 固定止损 | 兜底风险控制 |

### 6.2 时间递减 ROI

策略采用时间递减的 ROI 配置，避免持仓过久导致利润回撤。这是一种"落袋为安"的设计思路。

### 6.3 参数可优化性

策略提供了大量可优化参数（通过 `IntParameter` 和 `DecimalParameter`），支持超参数优化。但需注意：

- 过度优化可能导致过拟合
- 建议使用 out-of-sample 数据验证

## 七、策略优势与局限

### ✅ 优势

1. **双重买入通道**：EWO 高/低阈值形成两个互补的买入入口，既有趋势回调买入，也有极端抄底买入
2. **偏移均线设计**：通过偏移系数创造安全边际，避免"追涨杀跌"
3. **参数灵活度高**：大量可优化参数，适应不同市场环境
4. **时间递减 ROI**：合理控制持仓时间，减少回撤风险

### ⚠️ 局限

1. **未启用追踪止损**：固定止损在波动剧烈时可能过早出局
2. **EWO 参数偏慢**：50/200 的 EWO 配置反应较慢，可能错过快速行情
3. **信息时间框架未利用**：声明了 1h 信息层但未在逻辑中使用
4. **卖出信号单一**：仅依赖均线穿越，可能错过其他退出机会

## 九、适用市场环境详解

SMAOffsetProtectOpt 是典型的 **"均值回归 + 趋势过滤"** 策略。基于其代码架构和参数配置，它最适合 **震荡上升趋势市场**，而在极端趋势市场中表现可能受限。

### 9.1 策略核心逻辑

- **偏移买入线**：通过将 EMA 下移 2.5%，创造一个"打折区"，只在价格低于趋势时买入
- **EWO 双通道**：高阈值用于趋势确认，低阈值用于极端抄底
- **RSI 辅助**：防止在 RSI 过高时追入

### 9.2 不同市场环境表现

## 一、策略概览

**NostalgiaForInfinityV1**（简称 NFI V1）是 NostalgiaForInfinity（原版）的第一个正式优化版本。作为 NFI 系列的 V 系列开山之作，V1 版本确立了整个 V 系列的核心架构和参数体系。

V1 版本的特点是"稳扎稳打"——在保留原版核心优势的基础上，进行了参数的精细化调整和优化。相比原版，V1 提供了更稳定的配置和更完善的风控体系，成为后续 V2、V3、V4 等版本演进的基础模板。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 多组买入信号，涵盖趋势确认、支撑反弹、背离反转等类型 |
| **卖出条件** | 多层动态止盈 + 止损保护 + 追踪止损 |
| **保护机制** | EMA/SMA 趋势保护 + 波动控制 + 多周期验证 |
| **时间框架** | 15 分钟主框架 + 1 小时信息框架 |
| **依赖库** | pandas, numpy, TA-Lib, technical |

## 二、策略配置解析

### 2.1 基础风险参数

```python
# ROI 退出表
minimal_roi = {
    "0": 0.10,    # 立即退出：10% 利润
    "30": 0.06,   # 30 分钟后：6% 利润
    "60": 0.03,   # 60 分钟后：3% 利润
    "120": 0.015  # 120 分钟后：1.5% 利润
}

# 止损设置
stoploss = -0.10  # -10% 硬止损

# 追踪止损
trailing_stop = True
trailing_only_offset_is_reached = True
trailing_stop_positive = 0.03      # 3% 追踪启动点
trailing_stop_positive_offset = 0.05  # 5% 偏移触发
```

**设计思路**：
- **四级 ROI 目标**：10% → 6% → 3% → 1.5%，渐进止盈设计
- **适中止损**：-10% 是标准止损设置，给市场足够波动空间
- **保守追踪**：3% 启动，5% 偏移，适合趋势延续

### 2.2 订单类型配置

```python
order_types = {
    'entry': 'limit',
    'exit': 'limit',
    'stoploss': 'limit',
    'stoploss_on_exchange': False
}
```

**配置说明**：
- 全部使用限价单，避免滑点损失
- 止损由 Freqtrade 管理，不在交易所执行

## 三、买入条件详解

### 3.1 保护机制

V1 版本的每个买入条件都配有独立的保护参数组：

| 保护类型 | 参数说明 | 功能描述 |
|---------|---------|---------|
| **EMA 趋势保护** | 快速 EMA 与慢速 EMA 关系 | 判断多空趋势方向 |
| **SMA 支撑** | 价格与 SMA 位置关系 | 过滤逆势交易 |
| **波动率控制** | 安全下跌/上涨阈值 | 避免追高杀跌 |
| **时间过滤** | 持仓时间与交叉验证 | 防止过早入场 |
| **成交量确认** | OBV 趋势验证 | 确认资金流向 |
| **1h 周期确认** | 高周期趋势验证 | 多周期共振 |

### 3.2 核心买入条件类型

#### 条件组 1：趋势确认型
- EMA 多头排列确认
- 价格站上关键均线
- 成交量配合

#### 条件组 2：支撑反弹型
- 价格触及 EMA/SMA 支撑位
- 获得有效支撑后反弹
- 动量指标确认

#### 条件组 3：背离信号型
- 价格创新低但指标未创新低
- 底背离信号确认
- 动量转强验证

#### 条件组 4：多周期共振型
- 15m 周期出现信号
- 1h 周期趋势确认
- 多时间框架一致

### 3.3 买入条件汇总表

| 条件组 | 信号类型 | 核心指标 |
|-------|---------|---------|
| 趋势确认 | 趋势信号 | EMA, SMA |
| 支撑反弹 | 反弹信号 | EMA 支撑位 |
| 背离信号 | 反转信号 | RSI, MFI |
| 多周期共振 | 确认信号 | 15m + 1h |

## 四、卖出逻辑详解

### 4.1 多层止盈系统

V1 采用四级渐进式止盈机制：

```
利润率区间     阈值       信号名称
──────────────────────────────────
0-30 分钟     10%       快速获利
30-60 分钟     6%       中期目标
60-120 分钟    3%       保守退出
120 分钟+      1.5%     尾盘保本
```

### 4.2 特殊卖出场景

| 场景 | 触发条件 | 信号名称 |
|------|---------|---------|
| 均线死叉 | 短期均线跌破长期均线 | 趋势退出 |
| RSI 超买 | RSI 超过特定阈值 | 动量退出 |
| 布林带上轨 | 价格触及上轨 | 阻力退出 |
| 追踪止损触发 | 利润回撤超过阈值 | 锁定利润 |

### 4.3 基础卖出信号

1. **均线死叉**：趋势转弱的经典信号，短期均线下穿长期均线
2. **RSI 超买**：动量达到极端，RSI 超过阈值
3. **布林带上轨**：遇到技术阻力，价格触及上轨
4. **追踪止损**：利润回撤到阈值，锁定收益

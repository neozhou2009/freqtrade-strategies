## 一、策略概览

StrategyScalpingFast 是一个专注于**超短线剥头皮**的轻量级策略。它通过 EMA 包络线判断价格相对位置，结合多个超卖指标（Stochastic Fast、CCI、MFI）在极端超卖区域捕捉反转机会。策略代码简洁高效，适合高频交易场景。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 1 个复合买入信号，包含 5 个子条件的严格筛选 |
| **卖出条件** | 1 个复合卖出信号，EMA 上沿突破 + 指标超买双重确认 |
| **保护机制** | 固定止损 10%，无追踪止损 |
| **时间框架** | 1m 执行 + 5m 辅助参考 |
| **依赖库** | talib, qtpylib |

## 三、买入条件详解

### 3.1 核心买入逻辑

策略采用**多维度超卖确认**的入场机制，所有条件必须同时满足：

```python
# 买入条件组合
(
    (dataframe['open'] < dataframe['ema_low']) &      # 价格低于 EMA 下轨
    (dataframe['adx'] > 30) &                         # 趋势强度足够
    (dataframe['mfi'] < 30) &                         # 资金流量超卖
    (
        (dataframe['fastk'] < 30) &                   # 快速 K 超卖
        (dataframe['fastd'] < 30) &                   # 快速 D 超卖
        (qtpylib.crossed_above(dataframe['fastk'], dataframe['fastd']))  # K 上穿 D
    ) &
    (dataframe['cci'] < -150)                         # CCI 极端超卖
)
```

### 3.2 条件拆解分析

| 序号 | 条件 | 阈值 | 逻辑意义 |
|------|------|------|---------|
| 1 | `open < ema_low` | - | 开盘价位于 EMA 下轨之下，价格处于相对低位 |
| 2 | `ADX > 30` | 30 | 趋势强度指标，确保有足够动能 |
| 3 | `MFI < 30` | 30 | 资金流量指数超卖，资金流出接近极限 |
| 4 | `fastk < 30 & fastd < 30` | 30 | 随机指标双线超卖 |
| 5 | `fastk 上穿 fastd` | - | 金叉确认，超卖反转信号 |
| 6 | `CCI < -150` | -150 | 商品通道指数极端超卖 |

### 3.3 条件协同分析

这是一个**严格的多重确认系统**：

1. **位置确认**：EMA 下轨判断价格相对位置
2. **动能确认**：ADX 确保趋势强度
3. **资金确认**：MFI 判断资金流向
4. **技术确认**：Stochastic 金叉作为入场触发
5. **极端确认**：CCI 确保处于极端超卖状态

**触发概率**：由于 6 个条件同时满足，触发频率较低，但信号质量较高。

## 四、卖出逻辑详解

### 4.1 卖出信号结构

```python
# 卖出条件组合
(
    (
        (dataframe['open'] >= dataframe['ema_high'])  # 价格触及 EMA 上轨
    ) |
    (
        (qtpylib.crossed_above(dataframe['fastk'], 70)) |  # 快速 K 进入超买
        (qtpylib.crossed_above(dataframe['fastd'], 70))    # 快速 D 进入超买
    )
) & (dataframe['cci'] > 150)  # CCI 确认超买
```

### 4.2 卖出逻辑分析

| 触发场景 | 条件组合 | 信号含义 |
|---------|---------|---------|
| 场景 1 | `open >= ema_high` 且 `CCI > 150` | 价格触及上轨，且超买确认 |
| 场景 2 | `fastk 上穿 70` 且 `CCI > 150` | 随机指标超买，CCI 确认 |
| 场景 3 | `fastd 上穿 70` 且 `CCI > 150` | 随机 D 线超买，CCI 确认 |

### 4.3 卖出逻辑特点

- **或门设计**：三个超买信号只要一个触发即可，提高卖出灵敏度
- **CCI 必选**：无论哪种场景，CCI 必须大于 150 才能触发卖出
- **对称设计**：买入用 CCI < -150，卖出用 CCI > 150，形成完美对称

## 七、策略优势与局限

### ✅ 优势

1. **代码简洁**：约 100 行代码，易于理解和维护，计算开销低
2. **信号严格**：6 重条件确认，信号质量高，假信号少
3. **对称设计**：买入超卖 (-150) 和卖出超买 (+150) 形成完美对称
4. **快速周转**：1% ROI + 1 分钟框架，资金周转效率高
5. **硬件友好**：指标计算简单，对 VPS 配置要求低

### ⚠️ 局限

1. **触发频率低**：多重条件同时满足的机会较少
2. **无追踪止损**：趋势行情可能过早离场
3. **止损较宽**：10% 止损对于剥头皮策略可能偏大
4. **未使用辅助框架**：定义了 5m 框架但未实际使用
5. **极端行情风险**：暴跌行情可能止损被频繁触发

# Dracula 策略：黑暗使者的"吸血"哲学

> **外号**：黑暗使者 / 布林带猎手  
> **职业**：专门等待价格跌到布林带下轨然后"吸血"买入的猎手  
> **时间框架**：1 分钟 + 5 分钟信息层

---

## 一、这策略是个啥？

简单说，**Dracula** 就是一个：
- 等价格跌到布林带下轨（相当于"地板价"）
- 同时还要看资金有没有流入（CMF > 0）
- 再看看有没有支撑位接着
- 确认没问题就买入的策略

就像去淘宝买衣服，非要等到"限时降价" + "有货" + "店铺还活着" 才下单的精明买家 😏

## 二、核心配置：说白了就是"跌多少买"

### 止盈规则（ROI 表）

```
持仓时间     最小利润率    说人话
────────────────────────────────
0 分钟       10%         一买入就涨 10%？赶紧跑！
30 分钟      5%         持有半小时了，还赚 5%？也可以跑了
60 分钟      2%         都拿了一个小时了，赚 2% 卖了吧
```

**翻译**：这策略设定的止盈目标挺高的，一上来就要赚 10%！可能是觉得既然都跌到布林带下轨了，那反弹应该会比较猛。

### 止损规则

```
硬止损：-20%
追踪止损：利润达到 1% 后启动，从高点回撤 3% 触发
```

**翻译**：
- 买入后跌了 20%？认赔出场，别犹豫！
- 赚钱了？从最高点回落 3% 就跑，别贪心！

## 三、2 个买入条件：我帮你分类好了

这策略的买入条件挺复杂的，我给你归了 2 类：

### 🎯 第 1 类：布林带下轨 + 资金流入 + 支撑确认

**核心逻辑**：价格刚碰到布林带下轨，之前在支撑位上方，现在资金还在流入

**大白话**：
> "哇！价格跌到地板了（布林带下轨），而且钱还在往里流（CMF > 0），前面有支撑位撑着，不会跌太深，买它！"

**代表条件**：
- `bb_bbl_i == 1`：价格触及布林带下轨
- `cmf > 0`：资金流入（钱在往市场里跑）
- `close >= support`：价格不低于支撑位
- `lost_protect`：过去 10 根 K 线 EMA 没涨飞

---

### 🎯 第 2 类：布林带下轨 + 直接支撑

**核心逻辑**：价格直接跌到布林带下轨，开盘就高于支撑位

**大白话**：
> "开盘就站上支撑位了，现在价格刚碰到布林带下轨，完美！"

**代表条件**：
- `bb_bbl_i == 1`：触及布林带下轨
- `open >= support`：开盘价高于支撑位
- 其他条件同第一类

## 四、保护机制：1 层"防坑"保护

这策略有个"止损保护"（lost_protect），相当于给你加了个保险丝：

| 保护类型 | 作用 | 大白话 |
|---------|------|--------|
| lost_protect | 确保 EMA 没有涨太疯 | "别在已经涨了很多的时候去接盘！" |

原理：过去 10 根 K 线中，EMA 从来没高于收盘价的 107%。如果 EMA 涨飞了，说明这币已经涨了很多了，就不再买入，防止追高。

这策略还挺谨慎的，知道"追高会死翘翘" 😅

## 五、卖出逻辑：比买入更花哨

Dracula 的卖出逻辑有 5 种场景，比买入还复杂：

### 5.1 阻力位反转跑路

```
触发条件：
- 前一根 K 线突破布林带上轨
- 当前 K 线收阴（下跌）
- 价格接近阻力位
```
> "涨到阻力位了，而且开始收阴了，快跑！"

### 5.2 强势反转跑路

```
触发条件：
- 当前 K 线突破布林带上轨
- 当前 K 线收阴
- 开盘价远离阻力位
```
> "涨太猛了，都突破布林带上轨了，肯定要回调，跑！"

### 5.3 趋势反转跑路

```
触发条件：
- 当前 K 线收阴
- EMA 远高于收盘价（超过 7%）
```
> "EMA 都涨飞了，价格开始下跌，趋势要变，跑！"

### 5.4 布林带下轨止盈

```
触发条件：
- 当前 K 线收阴
- 价格接近布林带下轨
- 当前有利润
```
> "又跌回布林带下轨了，拿到利润赶紧跑！"

### 5.5 SMA 信号退出

```
触发条件：
- 买入标记包含 "sma"
- 利润 >= 1%
```
> "涨了 1% 了，SMA 信号触发，跑！"

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **条件严格**：要同时满足布林带 + 资金流 + 支撑位，假信号少
2. **资金流过滤**：CMF > 0 确保资金流入，不是"假涨"
3. **动态支撑阻力**：支撑位是实时计算的，不是死板的固定值
4. **保护机制**：防止在高位追涨
5. **卖出场景多**：5 种不同卖出方式，覆盖各种情况

### ⚠️ 缺点（吐槽环节）

1. **条件太严**：经常找不到符合条件的交易机会
2. **1 分钟太短**：K 线噪声太大，容易被"假信号"骗
3. **没有趋势判断**：不看你是在上涨趋势还是下跌趋势，容易逆势交易
4. **参数难调**：buy_bbt、ewo 这些参数需要精细调整

## 八、总结：这策略到底咋样？

### 一句话评价
> "一个很谨慎的'地板价买入'策略，但条件太严，经常找不到机会"

### 适合谁用？
- ✅ 有耐心的人（信号少，需要等）
- ✅ 喜欢做"低吸"的人（专等价格跌到布林带下轨）
- ✅ 追求信号质量的人（多条件确认，假信号少）

### 不适合谁？
- ❌ 想要频繁交易的人（条件太严，没信号）
- ❌ 新手（代码复杂，难理解）
- ❌ 喜欢追涨的人（这策略是越跌越买）

### 我的建议

1. **先把时间框架从 1m 改成 5m**：1 分钟K线太短了，噪声太大
2. **增加趋势过滤**：加个 EMA200 趋势判断，上涨趋势才做多
3. **别贪心**：止盈目标 10% 已经很高了，达到了就跑
4. **多观察**：这策略信号少，但每一个都是"精挑细选"的

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

Dracula 的历史回测表现看起来不错——但有几个坑：

> **因为支撑/阻力位是动态计算的，回测中可能出现"未来函数"，即用未来的数据计算过去的支撑位，这会导致回测效果虚高。**

简单说就是：**回测时会用的支撑位，其实是你"偷看"了未来！**

### 复杂策略的隐藏风险

实盘时，复杂的逻辑可能导致：
- **信号减少**：条件太严，经常找不到机会
- **参数敏感**：buy_bbt 等参数稍微变一点，信号就完全不一样
- **计算延迟**：动态支撑阻力需要实时计算，可能有延迟

### 我的建议（真心话）

```
1. 先用 5m 时间框架测试，别用 1m
2. 模拟盘跑 2-4 周，观察信号频率
3. 小资金实盘 1 个月，确认有效再加大
4. 永远设置止损，别侥幸！
5. 记住：震荡市才是它的主场
```

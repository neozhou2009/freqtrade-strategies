## 一、策略概览

**Hacklemore3** 是 Hacklemore 系列的第三版本，一个基于 5 分钟时间框架的趋势跟踪策略。相比 Hacklemore2（15 分钟版本），Hacklemore3 的核心创新在于**双模式卖出机制**：盈利时采用动态追踪止损保护利润，亏损时依赖趋势和动量指标判断退出时机。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 上升趋势 + RMI 强势 + SAR 确认 + 成交量过滤 |
| **卖出条件** | 双模式：盈利时动态追踪止损 / 亏损时趋势+动量判断 |
| **保护机制** | 追踪止损 + 硬止损 + ROI 分级止盈 |
| **时间框架** | 5 分钟（短线级别） |
| **依赖库** | TA-Lib, technical (RMI, qtpylib) |

### 与 Hacklemore2 的区别

| 对比项 | Hacklemore2 | Hacklemore3 |
|--------|-------------|-------------|
| 时间框架 | 15 分钟 | 5 分钟 |
| 交易频率 | 中等 | 较高 |
| 卖出逻辑 | 统一模式 | 双模式（盈利/亏损分治） |
| 止盈策略 | ROI 分级为主 | 动态追踪为主 |
| 适用场景 | 中线趋势 | 短线波段 |

## 三、买入条件详解

### 3.1 核心买入逻辑

策略采用四重确认机制，所有条件必须同时满足：

| 条件编号 | 条件名称 | 逻辑描述 |
|---------|---------|---------|
| 条件 1 | 上升趋势确认 | `up_trend == True`（近期新高判断） |
| 条件 2 | RMI 强势 | `RMI > 55` 且 `RMI >= RMI.rolling(3).mean()` |
| 条件 3 | SAR 确认 | `sar < close`（价格在 SAR 上方） |
| 条件 4 | 成交量过滤 | `volume < volume_ma * 30` |

### 3.2 买入条件详解

#### 条件 #1：上升趋势确认
```python
dataframe['up_trend'] == True
```

**逻辑解析**：
- 通过价格创出近期新高来确认上升趋势
- 确保只在趋势明确时进场
- 避免在震荡或下跌市场中频繁交易

#### 条件 #2：RMI 强势
```python
(dataframe['RMI'] > 55) & (dataframe['RMI'] >= dataframe['RMI'].rolling(3).mean())
```

**逻辑解析**：
- RMI（Relative Momentum Index）是 RSI 的变体，更注重动量变化
- RMI > 55 表明动量处于强势区域
- RMI 高于其 3 周期均值，确认动量正在增强

#### 条件 #3：SAR 确认
```python
dataframe['sar'] < dataframe['close']
```

**逻辑解析**：
- 抛物线转向指标（SAR）位于价格下方
- 确认当前处于上升趋势
- 提供额外的趋势方向验证

#### 条件 #4：成交量过滤
```python
dataframe['volume'] < dataframe['volume_ma'] * 30
```

**逻辑解析**：
- 成交量不应异常放大
- 避免在极端行情（如突发新闻）中入场
- 正常成交量环境更有利于趋势延续

### 3.3 买入信号综合判断

策略的买入逻辑可概括为：
> **趋势确认 + 动量强势 + 多重验证** —— 只有在上升趋势明确、RMI 动量走强、SAR 确认趋势方向，且成交量正常时才考虑入场。

## 四、卖出逻辑详解

### 4.1 双模式卖出机制

Hacklemore3 的核心创新在于**根据持仓盈亏状态采用不同的退出策略**：

| 模式 | 触发条件 | 核心逻辑 |
|------|---------|---------|
| **亏损模式** | `current_profit < 0` | 趋势破坏 + 动量衰减 → 退出 |
| **盈利模式** | `current_profit > 0` | 动态追踪止损 → 保护利润 |

### 4.2 亏损模式：趋势判断退出

```python
# 卖出信号 1: 下降趋势确认
dataframe['dn_trend'] == True

# 卖出信号 2: RMI 动量弱势
dataframe['RMI'] < 50
```

**逻辑解析**：
- 当持仓处于亏损状态时，策略更关注趋势是否被破坏
- `dn_trend == True` 表明趋势已经反转
- `RMI < 50` 表明动量已经衰减到弱势区域
- 两个条件同时满足时触发卖出

**设计理念**：
> 亏损时，给趋势"第二次机会"——只有当趋势明确反转且动量衰减时才认赔出局，避免被正常波动震出局。

### 4.3 盈利模式：动态追踪止损

```python
# 动态追踪止损逻辑
if current_profit > 0:
    # 价格跌破最高价的 80%
    price_drop = current_price < max_price * 0.8
    # 连续下跌
    consecutive_drop = dataframe['close'] < dataframe['close'].shift(1)
    
    if price_drop and consecutive_drop:
        sell_signal = True
```

**逻辑解析**：
- 当持仓有盈利时，策略记录持仓期间的最高价
- 如果价格跌破最高价的 80%（回撤 20%），且出现连续下跌，触发卖出
- 这种机制允许利润奔跑，同时在趋势转折时及时保护

**设计理念**：
> 盈利时"让利润奔跑"——只要价格没有大幅回撤，就继续持有，用动态止损保护已有利润。

### 4.4 ROI 分级止盈机制

策略同时保留了 ROI 分级止盈：

| 持仓时间 | 目标利润 | 设计意图 |
|---------|---------|---------|
| 立即 | 15% | 捕捉强势趋势的大利润 |
| 5 分钟后 | 1.5% | 快速锁定，适应短线节奏 |

## 五、技术指标体系

### 5.1 核心指标

| 指标类别 | 具体指标 | 用途 |
|---------|---------|------|
| **动量指标** | RMI (Relative Momentum Index) | 判断动量强弱和方向 |
| **趋势指标** | EMA | 确认趋势方向 |
| **反转指标** | SAR (Parabolic SAR) | 趋势反转确认 |
| **趋势判断** | 近期新高 | 确认上升趋势 |
| **成交量** | Volume MA | 过滤异常成交量 |

### 5.2 RMI 指标详解

**RMI（Relative Momentum Index）** 是 RSI 的变体：

- 传统 RSI 计算价格变化，RMI 计算动量变化
- 相比 RSI，RMI 对趋势变化更敏感
- 参数设置：通常使用默认周期
- 超买区域：RMI > 70
- 超卖区域：RMI < 30
- 强势区域：RMI > 55（本策略买入阈值）
- 弱势区域：RMI < 50（本策略卖出阈值）

### 5.3 SAR 指标详解

**抛物线转向指标（Parabolic SAR）**：

- 用于判断趋势方向和反转点
- SAR 在价格下方：上升趋势
- SAR 在价格上方：下降趋势
- 本策略使用 SAR 作为趋势确认

## 六、风险管理特色

### 6.1 追踪止损机制

```python
trailing_stop = True
trailing_stop_positive = 0.02
trailing_stop_positive_offset = 0.03
```

**设计理念**：
- 当利润达到 2% 时启动追踪止损
- 追踪偏移量 3%，给予一定回调空间
- 有效保护已有利润，同时不过早被震出局

### 6.2 硬止损保护

```python
stoploss = -0.10  # -10%
```

**设计理念**：
- 适中止损幅度，适合趋势策略
- 给予足够的波动空间
- 避免"止损后立即反弹"的尴尬

### 6.3 多层风险防护

| 保护层 | 触发条件 | 作用 |
|--------|---------|------|
| ROI 止盈 | 达到目标利润 | 锁定收益 |
| 追踪止损 | 盈利 2% 后回撤 | 保护利润 |
| 动态止损 | 盈利时价格回撤 20% | 趋势转折退出 |
| 趋势止损 | 亏损 + 趋势反转 | 控制损失 |
| 硬止损 | -10% | 最后防线 |

## 七、策略优势与局限

### ✅ 优势

1. **双模式卖出机制**：盈利时保护利润，亏损时给趋势"第二次机会"，逻辑清晰合理
2. **短线适应性强**：5 分钟时间框架，适合短线交易和快速反应
3. **风险控制完善**：追踪止损 + 硬止损 + 动态止损 + ROI 分级，多层保护
4. **多指标确认**：RMI + SAR + 趋势判断，信号可靠

### ⚠️ 局限

1. **交易成本较高**：5 分钟级别交易频繁，手续费和滑点影响较大
2. **震荡市场表现一般**：趋势策略的通病，震荡市中可能频繁止损
3. **参数敏感性**：RMI 阈值、SAR 参数需要根据不同交易对调整
4. **滞后性**：趋势确认存在滞后，可能错过最佳入场点

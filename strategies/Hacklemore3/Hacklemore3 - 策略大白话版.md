# Hacklemore3 策略：5分钟短线版

> **外号**：短线猎手  
> **时间框架**：5 分钟

---

## 一、这策略是个啥？

**Hacklemore3** 是 Hacklemore2 的5分钟短线版本，也是我上次的兄弟策略。但它有个更"聪明"的地方：**赚钱了会用动态追踪止损保护，亏钱了就看趋势跑不跑**。

**大白话比喻**：
> 就像开车：
> - 赚钱了：系上安全带（动态追踪止损）
> - 亏钱了：看路况不对就跑（趋势破了就卖）

---

## 二、核心配置

```
止盈：15%（刚买）→ 1.5%（5分钟后）
止损：-10%
追踪止损：2% 启动，3% 偏移
```

---

## 三、买入条件

跟 Hacklemore2 几乎一样：
1. 上升趋势
2. RMI > 55
3. SAR 在价格下方
4. 成交量正常

---

## 四、卖出：分两种情况

### 情况 1：亏钱时
```
dn_trend == True 且 RMI < 50
```
→ "趋势破了，赶紧跑！"

### 情况 2：赚钱时
```
current_price > max_price * 0.8 且 连续下跌
```
→ "已经赚了不少，价格开始跌了，动态追踪止损启动！"

---

## 五、总结

### 一句话评价
> "赚钱了懂得保护，亏钱了该跑就跑！"

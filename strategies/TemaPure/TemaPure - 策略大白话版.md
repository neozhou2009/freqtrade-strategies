# TemaPure 策略：布林带里的"区间捕手"

> **外号**：区间捕手  
> **职业**：布林带下轨抄底专家  
> **时间框架**：5 分钟（节奏刚刚好）

---

## 一、这策略是个啥？

简单说，**TemaPure** 就是一个：
- 在布林带下轨"捡便宜"的抄底党
- 等动量转正才动手的"确认派"
- 下轨买入上轨卖的"区间玩家"

就像在商场打折季蹲守，等商品跌破心理价位再入手，涨到高点就卖掉 🛍️

## 二、核心配置：说白了就是"有耐心地赚钱"

### 止盈规则（四级 ROI 表）

```
0 分钟：赚 40.5% 就跑（贪心版）
265 分钟（约 4.4 小时）：赚 24.7% 也行
743 分钟（约 12.4 小时）：赚 5.9% 也凑合
1010 分钟（约 16.8 小时）：保本就跑
```

**翻译**：这策略很有耐心！刚买入时目标 40%，但持仓越久目标越低，超过 17 小时没赚到钱就保本退出。

### 止损规则

```
硬止损：-9.75%（亏到这儿就认栽）
追踪止损：盈利 21.26% 后启动，几乎锁定所有利润
```

**翻译**：一旦盈利超过 21%，追踪止损会紧随其后，几乎不会让利润跑掉。

## 三、1 个买入条件：这策略很"挑剔"

买入条件虽然只有一个，但是双重确认：

### 🎯 买入条件：TEMA 触及布林带下轨 + CMO 动量转正

**技术实现**：
```python
# TEMA 低于或等于布林带下轨TA
# 同时 CMO 从下方穿过 0 轴
```

**大白话翻译**：
> "价格跌到布林带下轨外面或刚好在下轨上，说明超卖了。但还不能急，等 CMO 动量指标从负数变成正数，说明趋势开始转强了，这时候才上车！"

**通俗理解**：
- TEMA <= 下轨 = 价格"便宜"了
- CMO 上穿 0 = 动量从负变正，趋势确认
- 两个条件一起 = 不是死猫跳，是真反弹

## 四、1 个卖出信号：简单粗暴，上轨就跑

卖出逻辑非常简单：

### 卖出信号

| 信号 | 触发条件 | 大白话 |
|------|---------|--------|
| **卖出** | TEMA 穿过布林带上轨TA | "涨够了，跑！" |

**大白话翻译**：
> "价格涨到布林带上轨外面，说明超买了，可能到顶了，赶紧卖掉落袋为安。"

### 一个有趣的设计

这策略的布林带参数是"非对称"的：

| 位置 | 标准差倍数 | 作用 |
|------|-----------|------|
| **上轨** | 3.5 倍 | 很宽松，价格要涨很多才卖 |
| **下轨** | 1.0 倍 | 很严格，价格稍微超卖就触发 |

**翻译**：
- 买入很谨慎（下轨收紧，轻易不买）
- 卖出很宽松（上轨放宽，给价格更多上涨空间）
- 结果：持单时间更长，捕捉更大趋势

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **入场谨慎**：非对称布林带 + CMO 双重确认，不容易踩坑
2. **持单空间大**：上轨放宽到 3.5 倍标准差，给价格充分上涨空间
3. **止盈灵活**：四级 ROI 配合追踪止损，能锁住利润
4. **逻辑清晰**：下轨买、上轨卖，区间交易逻辑完整

### ⚠️ 缺点（吐槽环节）

1. **卖出太简单**：只看 TEMA 穿上轨，没有动量确认
2. **没有弱势退出**：不像其他策略有"跌太多就跑"的逻辑
3. **信号较少**：买入条件严格，可能好几天都没信号
4. **可能持单过久**：卖出条件宽松，有时候等不到

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

TemaPure 的回测可能看起来稳健——但区间策略有它的陷阱：

> **布林带参数对具体币对非常敏感，同样的参数在不同币对上效果可能天差地别。**

简单说就是：**BTC 上赚钱的参数，放在山寨币上可能亏死。**

### 区间策略的隐藏风险

实盘时，区间策略可能导致：
- **突破失效**：价格突破布林带后可能继续走，不是每次都会回头
- **参数敏感**：标准差倍数差一点，信号可能差很多
- **趋势风险**：单边趋势中，区间策略会反复被打脸

### 我的建议（真心话）

```
1. 先用历史数据测试具体币对的布林带参数
2. 非对称设计可能不适合所有币对，可以尝试调整
3. 回测时加上足够的滑点和手续费
4. 实盘先用小资金测试，至少跑一个月
```

**记住**：区间策略在震荡市场赚钱，在趋势市场亏钱。认清当前市场环境最重要！

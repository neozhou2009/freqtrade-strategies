## 一、策略概览

TemaPure 是一个基于三重指数移动平均线（TEMA）与布林带区间判断的趋势跟踪策略，结合钱德动量摆动指标（CMO）确认入场时机。该策略在价格触及布林带下沿且动量转正时入场，在价格触及布林带上沿时退出，追求区间内的完整趋势收益。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 1 个组合买入信号，需同时满足 TEMA 位置条件与 CMO 穿越条件 |
| **卖出条件** | 1 个基础卖出信号，基于 TEMA 突破布林带上轨 |
| **保护机制** | 四级 ROI 止盈 + 追踪止损系统 |
| **时间框架** | 5 分钟主时间框架 |
| **信息时间框架** | stake_currency/USDT 作为参考币对 |
| **依赖库** | talib.abstract, qtpylib.indicators |

### 2.1 基础风险参数

```python
# ROI 退出表（四级止盈）
minimal_roi = {

    "265": 0.24708,  # 265 分钟后目标 24.708%
    "743": 0.05892,  # 743 分钟后目标 5.892%
    "1010": 0        # 1010 分钟后保本退出
}

# 止损设置

# 追踪止损
trailing_stop = True
trailing_stop_positive = 0.2126        # 盈利 21.26% 后启动
trailing_stop_positive_offset = 0.2225  # 启动后允许回撤至 22.25%
trailing_only_offset_is_reached = True  # 仅在达到偏移后激活
```

**设计思路**：
- 四级递减 ROI：追求短期高收益，随着时间推移逐步降低目标
- 追踪止损参数高度接近（21.26% vs 22.25%），盈利后快速锁定
- 硬止损约 9.75%，提供最后防线

## 三、买入条件详解

### 3.1 核心买入逻辑

策略采用单一组合买入条件：

```python
# 买入信号
(
    (dataframe['TEMA'] <= dataframe['bb_lowerbandTA'])
    & 
    (qtpylib.crossed_above(dataframe['CMO'], 0))
)
```

#### 条件解析

| 条件组件 | 逻辑描述 | 技术含义 |
|---------|---------|---------|
| **TEMA <= 布林带下轨TA** | TEMA 位于或低于 bb_lowerbandTA | 价格处于超卖区域 |
| **CMO 上穿 0** | CMO 从负值穿越到正值 | 动量由负转正确认 |

### 3.2 技术指标参数

| 指标 | 参数 | 用途 |
|------|------|------|
| **TEMA** | 周期 25 | 三重指数移动平均线，判断价格位置 |
| **布林带下轨TA** | 周期 25，上标准差 3.5，下标准差 1.0 | 超卖区域判断 |
| **CMO** | 周期 50 | 动量确认，识别趋势转换 |

### 3.3 双布林带系统

策略使用了两组布林带参数：

```python
# 布林带组 1：标准布林带
bollinger = qtpylib.bollinger_bands(..., window=25, stds=2.0)

# 布林带组 2：非对称布林带（用于信号判断）
bollingerTA = ta.BBANDS(..., timeperiod=25, nbdevup=3.5, nbdevdn=1.0)
```

**非对称布林带设计**：
- 上轨使用 3.5 倍标准差（更宽松的上限）
- 下轨使用 1.0 倍标准差（更严格的下限）
- 目的：买入信号更谨慎（下轨收紧），卖出信号更宽松（上轨放宽）

## 四、卖出逻辑详解

### 4.1 卖出信号系统

策略定义了单一卖出信号：

```python
# 卖出信号
(qtpylib.crossed_above(dataframe["TEMA"], dataframe["bb_upperbandTA"]))
```

| 信号编号 | 触发条件 | 信号含义 |
|---------|---------|---------|
| **卖出信号** | TEMA 从下方穿过布林带上轨TA | 价格进入超买区域，趋势可能反转 |

### 4.2 卖出逻辑设计思路

- **区间交易逻辑**：下轨买入、上轨卖出，捕捉布林带区间内的趋势
- **非对称设计**：买入用 1.0 倍标准差下轨（严格），卖出用 3.5 倍标准差上轨（宽松）
- **与 ROI 配合**：技术信号与四级止盈共同保护利润

### 4.3 注释掉的卖出条件

代码中存在被注释的卖出条件：

```python
# (qtpylib.crossed_below(dataframe['close'], dataframe['bb_upperbandTA']))
# & 
# (dataframe["CMO"] >= 35)
```

这表明作者曾考虑过动量确认的卖出条件，但最终选择了更简单的 TEMA 穿越上轨逻辑。

## 五、技术指标体系

### 5.1 核心指标

| 指标类别 | 具体指标 | 用途 |
|---------|---------|------|
| **趋势指标** | TEMA(25) | 价格趋势追踪 |
| **波动指标** | 布林带(25, 2.0) | 标准布林带（未用于信号） |
| **波动指标** | 布林带TA(25, 3.5/1.0) | 非对称布林带（用于信号） |
| **动量指标** | CMO(50) | 动量确认，识别趋势转换 |

### 5.2 非对称布林带的意义

| 参数 | 标准布林带 | 信号布林带TA | 差异 |
|------|-----------|-------------|------|
| 周期 | 25 | 25 | 相同 |
| 上轨标准差 | 2.0 | 3.5 | 上轨放宽 |
| 下轨标准差 | 2.0 | 1.0 | 下轨收紧 |

**设计意图**：
- 下轨收紧：只有价格明显超卖时才触发买入
- 上轨放宽：允许价格有更大的上涨空间再触发卖出
- 结果：持单时间可能更长，捕捉更大的趋势

### 5.3 信息时间框架

策略使用 `stake_currency/USDT` 作为信息币对：

```python
def informative_pairs(self):
    return [(f"{self.config['stake_currency']}/USDT", self.timeframe)]
```

## 六、风险管理特色

### 6.1 四级 ROI 止盈系统

| 时间 | 目标收益 | 说明 |
|------|---------|------|
| 0 分钟 | 40.505% | 即时追求高收益 |
| 265 分钟（约 4.4 小时） | 24.708% | 随时间降低目标 |
| 743 分钟（约 12.4 小时） | 5.892% | 进一步降低 |
| 1010 分钟（约 16.8 小时） | 0% | 保本退出 |

**设计思路**：
- 短期追求高收益，不急于止盈
- 随持仓时间增加，逐步降低收益预期
- 超过约 17 小时无显著收益则保本退出

### 6.2 追踪止损机制

| 参数 | 数值 | 说明 |
|------|------|------|
| `trailing_stop_positive` | 21.26% | 触发追踪止损的盈利阈值 |
| `trailing_stop_positive_offset` | 22.25% | 追踪止损的参考高点 |
| `trailing_only_offset_is_reached` | True | 仅在达到偏移后激活 |

**特点**：参数差值极小（仅 1%），意味着盈利达到 22.25% 后，止损线将紧随其后，几乎立即锁定约 21% 的利润。

### 6.3 止损与止盈配置

| 类型 | 数值 | 说明 |
|------|------|------|
| 硬止损 | -9.754% | 最大亏损容忍度 |
| ROI 目标 | 40.5% → 0% | 四级递减止盈 |
| 盈利保护 | 动态追踪 | 几乎锁定所有利润 |

## 七、策略优势与局限

### ✅ 优势

1. **入场严格**：非对称布林带下轨收紧 + CMO 上穿 0 双重确认，降低假信号
2. **持单空间大**：上轨放宽至 3.5 倍标准差，允许价格充分上涨
3. **多级止盈**：四级 ROI 配合追踪止损，兼顾盈利空间与风险控制
4. **逻辑简洁**：买卖条件清晰，参数设计有针对性

### ⚠️ 局限

1. **卖出信号单一**：仅依赖 TEMA 穿越上轨，无动量确认
2. **无弱势退出**：不像 TemaMaster3 有弱势区卖出信号，可能持单过久
3. **参数固定**：无保护机制组，缺乏灵活性
4. **可能错过机会**：买入条件严格，在温和市场中可能信号较少

## 九、适用市场环境详解

TemaPure 是一个区间交易策略。基于其非对称布林带设计和四级 ROI 配置，它最适合**震荡市场中的趋势捕捉**，而在单边趋势中表现可能不佳。

### 9.1 策略核心逻辑

- **区间交易**：下轨买入、上轨卖出，完整的布林带区间策略
- **非对称设计**：买入严格（1.0 倍标准差）、卖出宽松（3.5 倍标准差）
- **动量确认**：CMO 上穿 0 确保趋势转强
- **多级止盈**：时间递减 ROI 配合追踪止损

### 9.2 不同市场环境表现

| 市场类型 | 表现评级 | 原因分析 |
| :--- | :--- | :--- |
| 📈 **慢牛趋势** | ⭐⭐⭐⭐☆ | 上轨宽松设计允许持单捕捉趋势 |
| 🔄 **横盘震荡** | ⭐⭐⭐⭐⭐ | 理想场景，上下轨反复触及 |
| 📉 **趋势下跌** | ⭐⭐☆☆☆ | CMO 过滤可能不足，有接飞刀风险 |
| ⚡️ **高波动** | ⭐⭐⭐☆☆ | 信号较少但质量高 |

### 9.3 关键配置建议

| 配置项 | 建议值 | 说明 |
|--------|--------|------|
| 时间框架 | 5 分钟（默认） | 平衡信号频率与噪音 |
| 止损调整 | 可适当收紧 | -9.75% 对短线可能偏宽 |
| 布林带参数 | 可尝试调整标准差 | 根据具体币对波动性 |
| CMO 阈值 | 可提高到 5 或 10 | 更严格的动量确认 |

## 十、重要提醒：区间策略的代价

- 策略期望持仓数小时
- 追求较大的收益空间
- 需要耐心等待信号

区间策略在回测中可能表现良好，但实盘需注意：
- 布林带参数对具体币对敏感
- 非对称设计在极端行情中可能失效
- CMO 参数需要根据市场调整

5 分钟框架相对友好：
- 可考虑手动执行

- 严格执行买入卖出条件，避免情绪干扰

## 十一、总结

**TemaPure** 是一个专注于布林带区间交易的策略。它的核心价值在于：

1. **非对称布林带设计**：买入严格、卖出宽松，追求更大趋势空间
2. **多级止盈系统**：四级 ROI 配合追踪止损，平衡盈利与风险
3. **动量确认入场**：CMO 上穿 0 确保趋势转强
4. **区间交易逻辑**：下轨买入、上轨卖出，策略逻辑完整

对于量化交易者而言，这是一个适合震荡和温和趋势市场的区间策略，但需注意：
- 买入条件严格，信号可能较少
- 卖出条件单一，可能持单过久
- 参数可能需要根据具体交易对和市场环境优化
- 建议先进行充分回测验证

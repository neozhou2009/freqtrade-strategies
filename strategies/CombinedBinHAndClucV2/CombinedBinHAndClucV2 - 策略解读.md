## 一、策略概览

**CombinedBinHAndClucV2** 是经典双策略组合 **CombinedBinHAndCluc** 的增强版本，由 iterativ 开发。该策略在原版基础上引入了**多时间框架分析**和**趋势过滤机制**，通过 1 小时级别的 SSL 通道判断市场大趋势，在 5 分钟级别执行交易，配合 MFI 资金流量和 StochRSI 动量指标进行三层信号验证，显著提升了信号的可靠性。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 3 层过滤：大趋势(SSL) + 动量(MFI/StochRSI) + 形态(BinHV45/ClucMay72018) |
| **卖出条件** | 1 个基础卖出信号 + 阶梯式 ROI 止盈 |
| **保护机制** | StoplossGuard（24 根 K 线内每交易对最多 2 笔，12 根 K 线冷却） |
| **时间框架** | 主 5m + 辅助 1h |
| **止损设置** | -5%（较原版 -10% 更紧） |
| **依赖库** | TA-Lib, numpy, qtpylib, technical |

### 2.1 基础风险参数

```python
# 分阶段 ROI 止盈表
minimal_roi = {
```

**设计思路**：
- **激进 ROI**：0% 门槛即 10% 止盈，30 分钟 5%，适合短线快速获利
- **紧凑止损**：-5% 止损线更紧，降低单笔最大亏损风险
- **多时间框架**：1h 判断趋势，5m 执行交易，过滤逆势信号
- **信号优先**：`ignore_roi_if_entry_signal = True` 允许新买入信号覆盖 ROI 退出

### 2.2 交易保护机制

```python
protections = [
    {
        "method": "StoplossGuard",
        "lookback_period_candles": 24,      # 回看 24 根 K 线
        "trade_limit": 2,                   # 最多 2 笔交易
```

**保护逻辑**：
- 同一交易对在 24 根 K 线（2 小时）内最多开 2 笔交易
- 触发限制后需等待 12 根 K 线（1 小时）冷却
- 防止频繁开仓导致手续费损耗和过度交易

## 三、买入条件详解

V2 版本的买入条件采用**三层过滤**机制，必须全部满足才能触发买入信号。这种设计大幅提高了信号质量，但也降低了信号频率。

### 3.1 第一层：大趋势过滤（1h SSL 通道）

**SSL 通道指标**：基于 ATR 调整的动态支撑阻力带

```python
# 计算 SSL 通道
ssl_down, ssl_up = SSLChannels(dataframe, length=25)
dataframe['ssl_high'] = (ssl_up > ssl_down).astype('int') * 3

# 趋势判断条件
(dataframe['ssl_high'] > 0)  # SSL 通道向上，表示上涨趋势
```

**逻辑解读**：
- SSL 通道向上：价格位于 1h 级别的上涨趋势中
- 只在顺大势的前提下才考虑买入
- 过滤逆势交易，降低被套风险

### 3.2 第二层：动量过滤（MFI + StochRSI）

```python
# MFI（资金流量指标）
dataframe['mfi'] = ta.MFI(dataframe, timeperiod=30)

# StochRSI（随机相对强弱指标）
stoch = ta.STOCHRSI(dataframe, 30, 35, 2, 2)
dataframe['srsi_fk'] = stoch['fastk']   # K 值
dataframe['srsi_fd'] = stoch['fastd']   # D 值

# 动量条件：MFI 和 K 值都在上升
(dataframe['mfi'].shift().rolling(3).mean() > dataframe['mfi']) &
(dataframe['srsi_fk'].shift().rolling(3).mean() > dataframe['srsi_fk'])
```

**逻辑解读**：
- **MFI 上升**：资金流入增加，买盘力量增强
- **StochRSI K 值上升**：短期动量转强
- **3 周期移动平均平滑**：避免单周期噪声干扰

### 3.3 第三层：形态过滤（BinHV45 或 ClucMay72018）

第三层采用"或门"逻辑，满足以下任一形态即可。

#### 3.3.1 BinHV45 模式

**波动突破形态**：捕捉价格快速跌破布林带下轨后的反弹机会

```python
(
    dataframe['lower'].shift().gt(0) &                    # 布林带存在
    dataframe['bbdelta'].gt(dataframe['close'] * 0.008) & # 带宽 > 0.8%
    dataframe['closedelta'].gt(dataframe['close'] * 0.0175) & # 波动 > 1.75%
    dataframe['tail'].lt(dataframe['bbdelta'] * 0.25) &   # 下影线 < 25%
    dataframe['close'].lt(dataframe['lower'].shift()) &   # 跌破下轨
    dataframe['close'].le(dataframe['close'].shift())      # 收盘走弱
)
```

**逻辑分解**：
| 条件 | 参数 | 说明 |
|------|------|------|
| 布林带存在 | lower > 0 | 前一周期布林带下轨有效 |
| 带宽阈值 | bbdelta > close × 0.8% | 布林带开口足够大 |
| 波动阈值 | closedelta > close × 1.75% | 价格波动足够剧烈 |
| 下影线限制 | tail < bbdelta × 25% | 短下影线，说明下跌后有支撑 |
| 跌破下轨 | close < lower.shift() | 价格跌破布林带下轨 |
| 收盘走弱 | close ≤ close.shift() | 当前收盘价低于前一根 K 线 |

#### 3.3.2 ClucMay72018 模式

**缩量反弹形态**：在成交量萎缩时逢低吸纳

```python
(
    (dataframe['close'] < dataframe['ema_slow']) &        # 低于 EMA50
    (dataframe['close'] < 0.985 * dataframe['bb_lowerband']) & # 跌破下轨
    (dataframe['volume'] < dataframe['volume_mean_slow'].shift(1) * 20) # 缩量
)
```

**逻辑分解**：
| 条件 | 参数 | 说明 |
|------|------|------|
| 低于 EMA | close < EMA50 | 价格低于长期均线，处于弱势 |
| 跌破下轨 | close < 98.5% × 下轨 | 价格跌破布林带下轨 |
| 成交量萎缩 | volume < 20 × 均量 | 当前成交量极低，卖压枯竭 |

### 3.4 买入条件汇总

| 过滤层 | 条件名称 | 核心逻辑 | 时间框架 |
|--------|----------|----------|----------|
| 第一层 | SSL 通道 | 上涨趋势确认 | 1h |
| 第二层 | MFI | 资金流入确认 | 5m |
| 第二层 | StochRSI | 动量转强确认 | 5m |
| 第三层 | BinHV45 | 波动突破形态 | 5m |
| 第三层 | ClucMay72018 | 缩量反弹形态 | 5m |

## 四、卖出逻辑详解

### 4.1 技术卖出：布林带上轨突破

**触发条件**：

```python
qtpylib.crossed_below(dataframe['close'], dataframe['bb_upperband'])
```

**逻辑解读**：
- 价格下穿布林带上轨时触发卖出
- 表示价格可能从上涨转为回调
- 与买入时的下轨突破形成对称

### 4.2 ROI 阶梯止盈

| 持仓时间 | 止盈阈值 | 设计思路 |
|----------|----------|----------|
| 0 分钟（即时） | 10% | 快速捕获大幅波动 |
| 30 分钟 | 5% | 波段中间目标 |
| 60 分钟 | 2% | 防止利润回吐 |
| 120 分钟 | 1% | 防止久拿不卖 |

**设计逻辑**：
- 0 分钟 10%：捕获瞬时大幅波动，快速锁定利润
- 时间越长要求越低：避免持仓过久导致资金效率下降
- 阶梯式设计：平衡获利空间与资金周转效率

### 4.3 止损退出

**触发条件**：亏损达到 5% 强制平仓

**逻辑解读**：
- -5% 止损比原版 -10% 更紧
- 配合多时间框架过滤，错误交易应更少
- 单笔最大亏损可控

## 七、策略优势与局限

### ✅ 优势

1. **多时间框架分析**：1h 趋势过滤 + 5m 信号执行，避免逆势交易
2. **三层信号过滤**：趋势 + 动量 + 形态，大幅提高信号可靠性
3. **动态趋势识别**：SSL 通道自动识别市场方向
4. **资金流向验证**：MFI 确认资金流入，避免假突破
5. **交易保护机制**：避免频繁开仓导致的手续费损耗
6. **紧凑止损**：-5% 止损降低单笔风险
7. **阶梯止盈**：多层次保护利润

### ⚠️ 局限

1. **信号稀少**：三层过滤叠加，可能大幅降低买入频率
2. **时间框架依赖**：1h 趋势判断可能有滞后
3. **参数耦合**：各层参数相互影响，调优难度大
4. **卖出逻辑简单**：仅依靠上轨突破，缺乏追踪止损
5. **无动态止损**：可能踏空趋势行情

## 九、适用市场环境详解

CombinedBinHAndClucV2 是 Freqtrade 生态中定位为**趋势回调型**的多时间框架组合策略。基于其代码架构和三层过滤特性，它最适合 **明确上涨趋势中的回调买入机会**，而在 **震荡或下跌** 环境中表现可能不佳。

### 9.1 策略核心逻辑

- **趋势为王**：SSL 通道判断 1h 级别大趋势，只做顺大势交易

- **动量确认**：StochRSI 验证短期动能，避免追高
- **形态买入**：BinHV45 或 ClucMay72018 形态确认入场点

## 十一、总结

**CombinedBinHAndClucV2** 是一个面向有一定经验的交易者的**多时间框架趋势回调策略**。其核心价值在于：

1. **多维度信号验证**：通过 1h SSL 趋势 + 5m MFI/StochRSI 动量 + 形态三层过滤，大幅提高买入信号质量
2. **紧凑风控**：-5% 止损配合阶梯式 ROI，平衡风险与收益
3. **交易保护**：StoplossGuard 防止过度交易

对于量化交易者而言，此策略适合理解多时间框架分析、能接受较低信号频率、追求信号可靠性的用户。不建议高频交易者或喜欢频繁操作的用户使用。实盘前请充分回测和模拟盘验证。

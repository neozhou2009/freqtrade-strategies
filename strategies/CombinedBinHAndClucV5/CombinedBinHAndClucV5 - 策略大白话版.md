## 一、这策略是个啥？

简单说，**CombinedBinHAndClucV5** 是一个"双刀流"超跌反弹策略的**更贪心版**：

- 由两个经典策略合并而来：**BinHV45** + **ClucMay72018**
- 两个策略各有绝活，只要其中一个触发就买入
- 专门抓那些"跌过头了要弹回来"的机会

**V5 相比 V4 的核心升级**：
- 止盈提高（1.9% → 2.0%）：想多赚一点点
- 追踪止损更晚启动（2.5% → 2.75%）：让趋势跑更远
- 追踪止损更能扛（回撤 1% → 1.25%）：不被小回调震出去
- 卖出更严格（5 根 K 线 → 6 根）：减少假突破干扰

就像一个老练的渔夫，撒了两张网——一张网急跌反弹的鱼，一张网缩量超跌的鱼。V5 版本的渔夫更"贪心"了，不满足于小赚，想吃满整个波段。🐟

## 二、核心配置：说白了就是"更贪心，更敢扛"

### 止盈规则（ROI 表）

```
累计收益 ≥ 2.0% → 触发止盈
```

**翻译**：赚够 2.0% 就跑，比 V4 多赚 0.1%。别小看这 0.1%，积少成多！

### 止损规则

```
固定止损：-99%（几乎不设限）
追踪止损：盈利 2.75% 后启动，保护 1.25% 利润
时间止损：持仓 5 小时后若亏损，强制市价跑路
```

**翻译**：
- 固定止损几乎不用了——V5 的理念是"别被短期波动吓跑"
- 赚够 2.75% 之后开启"护盾"，从最高点回撤 1.25% 就跑（比 V4 更能扛）
- 持仓超过 5 小时还在亏？不熬了，市价走人

### 其他配置

| 配置项 | 值 | 大白话 |
|--------|-----|--------|
| 时间周期 | 5 分钟 | 短线高频 |
| 盈利才卖 | True | 亏钱状态下不许卖 |
| 盈利偏移 | 0.1% | 至少赚 0.1% 才能触发卖出 |

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

CombinedBinHAndClucV5 的历史回测表现往往**看起来不错**——但这有个陷阱：

> **均值回归策略在震荡市表现好，但遇到单边行情会惨败。**

简单说就是：**历史不会简单重复，过去震荡不代表未来还震荡。**

### V5 的特殊风险

V5 相比 V4 有几个**更激进**的设计：

1. **-99% 止损几乎禁用**
   
   - V3 有 -10% 硬止损，V5 几乎没了
   - 单边下跌可能扛很大浮亏
   - 只能靠 5 小时时间止损和追踪止损来保护

2. **追踪止损更晚启动（2.75%）**
   
   - 好处：让趋势跑更远，吃更多波段
   - 坏处：如果涨到 2.5% 就回调，可能卖在更低位置

3. **追踪止损更能扛（1.25% 回撤）**
   
   - 好处：小回调不跑，不会被震出去
   - 坏处：可能从最高点回落更多才卖

4. **卖出条件更严格（6 根 K 线）**
   
   - 好处：减少假突破
   - 坏处：可能错过最佳卖点

### 复杂策略的隐藏风险

实盘时，你可能遇到：

- **滑点风险**：高频交易，滑点累积起来可能吃掉利润
- **手续费侵蚀**：5 分钟周期交易频繁，手续费不是小数目
- **API 限速**：交易频率太高可能触发交易所限速
- **单边行情**：持续上涨卖飞，持续下跌扛浮亏，两边挨打

### 我的建议（真心话）

```
1. 先判断市场环境：震荡市或趋势延续用，单边下跌市慎用
2. 小资金测试：别上来就梭哈，先小资金跑 1-2 周
3. 关注手续费：选低手续费平台，否则利润全交手续费了
4. 手动加止损：V5 的 -99% 止损太激进，手动交易建议设 5%-10%
5. 别指望暴富：这是刷零花钱的策略，不是财富密码
```

**记住**：V5 的核心理念是"让利润奔跑"，但市场教做人时也不会打招呼。轻仓测试，活着最重要！🙏

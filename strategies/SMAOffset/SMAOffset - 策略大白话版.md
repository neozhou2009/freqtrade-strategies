# SMAOffset 策略：均价打折买，溢价就卖

> **外号**：均线偏移王  
> **职业**：均值回归专家  
> **时间框架**：5 分钟

---

## 一、这策略是个啥？

简单说，**SMAOffset** 就是一个：
- 等价格跌到均线以下一定比例，买入
- 等价格涨到均线以上一定比例，卖出
- 简单到不能再简单！

就像去菜市场买菜 🥕：平时 5 块一斤的菜，今天打折 4.8 块（低于均价），买！明天涨价到 5.1 块（高于均价），卖！

---

## 二、核心配置：说白了就是"一条均线两道线"

### 止盈规则（ROI 表）

```
100% 利润才退出
```

**翻译**：ROI 基本是摆设，策略靠卖出信号和追踪止损离场。

### 止损规则

```
固定止损：-10%
追踪止损：立即激活，锁定 99.99% 利润
```

**翻译**：亏 10% 认栽。但只要赚了一点点，止损线就跟着价格往上爬，几乎锁住所有利润。这是极度保守的设计！

---

## 三、1 个买入条件：简单到怀疑人生

这策略的买入条件就一个，真的就一个：

### 🎯 唯一买入：均线打折买

**核心逻辑**：价格比均线低 4.2%，就买！

**大白话**：
> "平时这货价格在均线附近晃悠，现在跌到均线下方 4.2% 了，便宜了！买点等它涨回来！"

**详细台词**：
```
价格 < 均线 × 0.958  →  买入！
有成交量              →  确认
```

**可调参数**：
| 参数 | 默认值 | 作用 |
|------|--------|------|
| base_nb_candles_buy | 30 | 均线周期（30 根 K 线） |
| low_offset | 0.958 | 打折比例（4.2% 折扣） |
| buy_trigger | SMA | 均线类型（可选 EMA） |

**举个例子**：
- 均线价格 100 块
- 打折线 = 100 × 0.958 = 95.8 块
- 现价跌到 95.5 块 → 触发买入！

---

## 四、1 个卖出条件：简单到怀疑人生 x2

卖出也只有一个条件：

### 🎯 唯一卖出：均线溢价卖

**核心逻辑**：价格比均线高 1.2%，就卖！

**大白话**：
> "平时这货价格在均线附近，现在涨到均线上方 1.2% 了，贵了！卖了等它跌回来！"

**详细台词**：
```
价格 > 均线 × 1.012  →  卖出！
有成交量             →  确认
盈利状态             →  才卖
```

**可调参数**：
| 参数 | 默认值 | 作用 |
|------|--------|------|
| base_nb_candles_sell | 30 | 均线周期（30 根 K 线） |
| high_offset | 1.012 | 溢价比例（1.2% 加价） |
| sell_trigger | EMA | 均线类型（默认比买入更敏感） |

**举个例子**：
- 均线价格 100 块
- 溢价线 = 100 × 1.012 = 101.2 块
- 现价涨到 101.5 块 → 触发卖出！

## 五、保护机制：两个保命符

这策略虽然简单，但保护机制一点不含糊：

| 保护类型 | 作用 | 大白话 |
|---------|------|--------|
| 固定止损 | -10% | "亏太多了认栽" |
| 追踪止损 | 锁定 99.99% 利润 | "有赚就锁，一分不留" |
| 仅盈利卖出 | 只在盈利时卖 | "亏钱不卖，等反弹" |

**吐槽**：追踪止损锁定 99.99% 利润，这简直是"有赚就跑"的极致版！😅

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **逻辑简单**：就一条均线两个偏移，小学生都能看懂
2. **计算快**：只算均线，老电脑也能跑
3. **参数灵活**：买卖参数独立，可以分别调优
4. **保护到位**：追踪止损很激进，不太会亏利润

### ⚠️ 缺点（吐槽环节）

1. **太简单了**：没有趋势判断，可能逆势交易 🤣
2. **震荡市才香**：趋势行情会被打脸
3. **追踪止损太激进**：刚有利润就锁，可能少赚
4. **没有成交量和动量过滤**：只有价格判断

### 适合谁用？

- ❌ 追求复杂策略的人

### 我的建议
1. **震荡币种优先**：选价格波动有规律的币
2. **调参建议**：low_offset 可以调到 0.93-0.96，等更大折扣
3. **配合趋势指标**：可以加个 RSI 或 MACD 过滤
4. **注意手续费**：震荡市交易频繁，手续费可能吃利润

## 九、这策略在什么市场能赚钱？

### 9.1 核心逻辑：均值回归

SMAOffset 是一个典型的"均值回归"策略。

**它的赚钱哲学**："价格最终会回归均线，趁便宜买，趁贵卖"

- **假设前提**：价格围绕均线波动
- **买入时机**：价格低于均线一定比例
- **卖出时机**：价格高于均线一定比例

### 9.2 不同市场表现（说人话版）

| 市场类型 | 表现评级 | 大白话解释 |
| :--- | :--- | :--- |
| 📈 上涨趋势 | ⭐⭐☆☆☆ | 价格一直涨，等不到回调，或者回调很浅 |
| 🔄 震荡市场 | ⭐⭐⭐⭐⭐ | 价格来回晃，均线策略完美发挥 |
| 📉 下跌趋势 | ⭐⭐☆☆☆ | 价格一直跌，抄底抄在半山腰 |
| ⚡️ 剧烈波动 | ⭐⭐⭐☆☆ | 追踪止损有用，但可能过早离场 |

**一句话总结**：震荡市是它的主场，趋势市是它的克星！

### 10.4 回测 vs 实盘

这个策略回测和实盘差异可能主要在：
- **手续费**：震荡市交易频繁，手续费是真金白银
- **滑点**：实际成交价和预期可能有差异
- **极端行情**：暴涨暴跌时均线会失效

**建议流程**：
1. 回测时加上手续费设置
2. 纸盘测试至少 1 周
3. 选震荡币种实盘
4. 监控手续费占比

**别一上来就梭哈**，先试试水！

## 十一、彩蛋：策略作者的"小心思"

仔细看代码，你会发现一些有趣的东西：

1. **买卖均线可以不同**：
   > "买入用 SMA，卖出用 EMA——买入更稳健，卖出更敏感"

   > "这是有多怕亏利润？有赚就锁！"

3. **ROI 设为 100%**：
   > "基本上就是放弃 ROI，全靠卖出信号"

4. **参数独立设计**：
   > "买卖参数分开，想怎么调就怎么调"

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

SMAOffset 在震荡市回测可能表现不错——但注意：

> **均值回归的前提是价格会回归，但强趋势时这个前提不存在！**

简单说就是：**如果价格一直涨或一直跌，这策略就废了**

### 策略的致命弱点

实盘时，要特别注意：
- **趋势风险**：上涨趋势中等不到回调，下跌趋势中抄底被套
- **手续费风险**：震荡市交易频繁，手续费可能吃掉大部分利润
- **过早离场**：追踪止损太激进，可能刚有利润就跑了

### 我的建议（真心话）

```
1. 只在震荡市使用这个策略
2. 识别趋势：如果价格一直在均线上方或下方，暂停策略
3. 设置最小盈利阈值，避免频繁交易
4. 关注手续费，计算是否划算
```

**记住**：策略越简单，适用场景越窄。震荡市薅羊毛可以，趋势市就别用了！

## 一、策略概览

SMAOffset 是一个简洁高效的均线偏移策略，其核心逻辑是：当价格低于均线的某个偏移比例时买入，当价格高于均线的某个偏移比例时卖出。策略支持在 SMA（简单移动平均）和 EMA（指数移动平均）之间切换，通过参数优化适应不同市场环境。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 1 个：价格低于偏移均线 |
| **卖出条件** | 1 个：价格高于偏移均线 |
| **保护机制** | 追踪止损 + 仅盈利卖出 |
| **时间框架** | 5 分钟 (5m) |
| **依赖库** | talib, numpy, qtpylib |

## 三、买入条件详解

### 3.1 可优化参数组

策略提供多组可优化参数：

| 参数类型 | 参数名 | 默认值 | 优化范围 |
|---------|--------|--------|---------|
| 买入均线周期 | base_nb_candles_buy | 30 | 5-80 |
| 买入偏移 | low_offset | 0.958 | 0.8-0.99 |
| 买入均线类型 | buy_trigger | SMA | SMA/EMA |

### 3.2 买入条件详解

#### 唯一买入条件：偏移均线低位买入
```python
# 逻辑
- 价格低于偏移均线 (close < ma_offset_buy)
- 成交量大于 0

# 其中
ma_offset_buy = MA(close, base_nb_candles_buy) * low_offset
```

**解读**：当价格低于移动平均线的 95.8%（默认偏移 0.958）时，触发买入信号。这本质上是一个"均值回归"策略——假设价格会回归均线，在价格偏低时买入，等待回归。

**参数说明**：
- `base_nb_candles_buy`：均线周期，周期越长越平滑
- `low_offset`：偏移比例，越小越保守（等待更大跌幅）
- `buy_trigger`：均线类型，SMA 更平滑，EMA 更敏感

## 四、卖出逻辑详解

### 4.1 追踪止损机制

策略采用激进的追踪止损设计：

```
激活条件     锁定利润
──────────────────────
立即激活     99.99%
```

**解读**：只要有利润，追踪止损就会激活，几乎锁定全部利润。这是一种极度保守的利润保护策略。

### 4.2 卖出信号

#### 唯一卖出条件：偏移均线高位卖出
```python
# 逻辑
- 价格高于偏移均线 (close > ma_offset_sell)
- 成交量大于 0

# 其中
ma_offset_sell = MA(close, base_nb_candles_sell) * high_offset
```

**解读**：当价格高于移动平均线的 101.2%（默认偏移 1.012）时，触发卖出信号。这同样是均值回归逻辑——在价格偏高时卖出，等待回调。

**参数说明**：
- `base_nb_candles_sell`：卖出均线周期（默认 30）
- `high_offset`：卖出偏移比例（默认 1.012）
- `sell_trigger`：卖出均线类型（默认 EMA）

### 4.3 仅盈利卖出

```python
sell_profit_only = True
```

**解读**：策略只在盈利状态下才会响应卖出信号。这保护了策略不在亏损时离场，避免"割肉"。

## 五、技术指标体系

### 5.1 核心指标

| 指标类别 | 具体指标 | 用途 |
|---------|---------|------|
| 趋势类 | SMA/EMA | 偏移买卖线计算 |

### 5.2 均线偏移原理

均线偏移是本策略的核心概念：

```
买入线 = MA(价格, 周期) × 偏移比例
卖出线 = MA(价格, 周期) × 偏移比例
```

**核心思想**：
- 不直接用均线作为买卖点
- 而是用均线的某个偏移比例作为触发线
- 买入偏移 < 1：等价格跌到均线下方一定比例
- 卖出偏移 > 1：等价格涨到均线上方一定比例

### 5.3 SMA vs EMA 选择

| 均线类型 | 特点 | 适用场景 |
|---------|------|---------|
| SMA | 更平滑，反应较慢 | 趋势明确的市场 |
| EMA | 更敏感，反应较快 | 波动较大的市场 |

策略支持买入和卖出使用不同的均线类型，默认买入用 SMA，卖出用 EMA。

## 六、风险管理特色

### 6.1 双重保护机制

| 保护类型 | 参数 | 作用 |
|---------|------|------|
| 固定止损 | -10% | 最后防线 |
| 追踪止损 | 99.99% | 锁定利润 |

### 6.2 仅盈利卖出

```python
sell_profit_only = True
```

**解读**：避免亏损时被卖出信号触发离场，保护资金。

### 6.3 参数隔离设计

策略的买入和卖出参数完全独立：

```python
base_nb_candles_buy    # 买入均线周期
base_nb_candles_sell   # 卖出均线周期
low_offset             # 买入偏移
high_offset            # 卖出偏移
buy_trigger            # 买入均线类型
sell_trigger           # 卖出均线类型
```

**优势**：可以针对入场和离场分别优化，灵活性高。

## 七、策略优势与局限

### ✅ 优势

1. **逻辑简洁**：一个买入条件 + 一个卖出条件，易于理解和维护
2. **参数独立**：买入和卖出参数分开优化，灵活性高
3. **保护到位**：追踪止损 + 仅盈利卖出，双重保护
4. **计算高效**：只计算均线，资源消耗低

### ⚠️ 局限

1. **均值回归假设**：假设价格会回归均线，但在强趋势中可能失灵
2. **横盘震荡风险**：在无趋势震荡中可能频繁交易，手续费侵蚀利润
3. **无趋势过滤**：没有趋势判断指标，可能逆势交易
4. **追踪止损过激进**：锁定 99.99% 利润可能导致过早离场

## 九、适用市场环境详解

SMAOffset 是一个典型的均值回归策略，适合 **震荡市场**，而在 **强趋势市场** 表现可能不佳。

### 9.1 策略核心逻辑

- **买入逻辑**：价格低于均线一定比例 → 超跌 → 买入等待回归
- **卖出逻辑**：价格高于均线一定比例 → 超买 → 卖出等待回调
- **假设前提**：价格围绕均线波动，极端价格会回归

### 9.2 不同市场环境表现

| 市场类型 | 表现评级 | 原因分析 |
| :--- | :--- | :--- |
| 📈 上涨趋势 | ⭐⭐☆☆☆ | 价格持续上涨，买入信号可能被套 |
| 🔄 震荡市场 | ⭐⭐⭐⭐⭐ | 价格围绕均线波动，完美契合 |
| 📉 下跌趋势 | ⭐⭐☆☆☆ | 价格持续下跌，可能抄底被套 |
| ⚡️ 剧烈波动 | ⭐⭐⭐☆☆ | 追踪止损保护利润，但可能过早离场 |

### 9.3 关键配置建议

| 配置项 | 震荡市建议 | 趋势市建议 |
|--------|----------|----------|
| low_offset | 0.95-0.97 | 0.90-0.95 |
| high_offset | 1.03-1.05 | 1.01-1.03 |
| base_nb_candles | 20-30 | 50-80 |

## 十、重要提醒：简洁不代表简单

### 10.1 学习成本

策略逻辑简单，但要调好参数需要理解：
- 均线周期对策略的影响
- 偏移比例的市场适应性
- SMA 和 EMA 的选择

### 10.2 硬件要求

| 交易对数量 | 最低内存 | 推荐内存 |
|-----------|---------|---------|
| 1-50 对 | 1GB | 2GB |
| 50-200 对 | 2GB | 4GB |

### 10.3 回测与实盘的差异

- 追踪止损的滑点可能影响实际收益
- 震荡市场中的频繁交易会产生较多手续费
- 建议设置最小盈利阈值

### 10.4 手动交易者建议

- 理解均线偏移概念：价格偏离均线多少时入场
- 关注震荡市，避免强趋势市场
- 设定最小交易间隔，避免过度交易

## 十一、总结

**SMAOffset** 是一个极简的均线偏移均值回归策略。它的核心价值在于：

1. **逻辑清晰**：低买高卖，均值回归，简单直观
2. **参数独立**：买卖参数分开优化，适应性强
3. **保护到位**：追踪止损 + 仅盈利卖出，风险可控

对于量化交易者而言，这是一个适合震荡市场的轻量级策略，但在强趋势市场中需要谨慎使用或结合趋势过滤指标。

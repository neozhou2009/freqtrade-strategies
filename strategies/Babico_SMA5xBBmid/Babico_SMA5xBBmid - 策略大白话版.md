## 二、核心配置：简单到不需要解释

### 止盈规则（ROI 表）

```
持仓时间        目标利润率
──────────────────────────
立即            10%
30 天后         5%
60 天后         2%
```

**翻译**：
- 刚买进去想赚 10%
- 拿了 1 个月还没赚到，目标降到 5%
- 拿了 2 个月还没赚到，目标降到 2%
- 时间越久，要求越低

### 止损规则

```
固定止损：-10%
追踪止损：盈利超过 3% 后启动，追踪幅度 1%
```

**翻译**：
- 亏 10% 就认输
- 赚了 3% 以上就开始保护利润，回撤 1% 就卖

## 三、1 个买入条件：金叉买入

### 🎯 唯一买入信号：EMA5 上穿布林带中轨

**大白话**：
> "5 日均线上穿 20 日均线，买入！"

**为什么？**
- EMA5 代表短期价格趋势
- 布林带中轨就是 20 日均线
- 短期均线穿越中期均线，说明短期趋势变强了

**经典台词**：
```
当 EMA5 > 布林带中轨（刚穿越）
```
→ "金叉！趋势转强，买入！"

## 四、1 个卖出条件：死叉卖出

### 📉 唯一卖出信号：EMA5 下穿布林带中轨

**大白话**：
> "5 日均线下穿 20 日均线，卖出！"

**为什么？**
- 短期趋势转弱了
- 价格跌破了中期平均成本
- 可能要下跌了

**经典台词**：
```
当 EMA5 < 布林带中轨（刚穿越）
```
→ "死叉！趋势转弱，跑路！"

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **简单到极致**：代码不到 80 行，看一眼就懂
2. **逻辑对称**：买和卖完全对称，不偏不倚
3. **经典方法**：均线交叉是最老牌的技术分析
4. **计算量小**：不烧 CPU，不占内存
5. **四重保护**：信号 + ROI + 止损 + 追踪止损

### ⚠️ 缺点（吐槽环节）

1. **信号滞后**：均线是滞后指标，等交叉时趋势已经走了一段
2. **震荡市惨**：横盘时反复金叉死叉，来回被割
3. **没有过滤**：什么金叉都信，没有趋势强度确认
4. **参数单一**：5 日和 20 日固定，没法优化

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

均线交叉策略在**历史回测中看起来还不错**——但这有个陷阱：

> **均线是滞后指标，金叉时趋势已经走了一段，死叉时已经回撤了不少。**

简单说就是：**吃鱼只能吃中段，鱼头鱼尾都吃不到。**

### 震荡市的噩梦

均线交叉策略在震荡市会：
- **频繁交叉**：今天金叉明天死叉
- **反复止损**：每次止损 10%，几次就亏大了
- **手续费累积**：进进出出，手续费比利润还多

### 我的建议（真心话）

```
1. 只在有明显趋势的币种上使用
2. 添加趋势强度过滤（如 ADX > 25）
3. 添加成交量确认
4. 震荡期暂停交易或切换其他策略
5. 先模拟盘测试，看策略表现
```

**记住**：策略再简单，市场也不简单。轻仓测试，活着最重要！🙏

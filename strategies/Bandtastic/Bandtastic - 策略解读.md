## 一、策略概览

Bandtastic 是一个基于布林带的突破交易策略，核心思想是利用布林带的多层标准差通道捕捉价格极端位置的机会。策略最大特点是高度可配置性，通过 Hyperopt 参数可以灵活组合买入/卖出的保护条件和触发条件，适合不同市场环境的优化调参。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 4 种布林带下轨触发 + 3 种可选保护条件 |
| **卖出条件** | 4 种布林带上轨触发 + 3 种可选保护条件 |
| **保护机制** | RSI、MFI、EMA 三维过滤，可独立开关 |
| **时间框架** | 15m 主时间框架 |
| **依赖库** | talib, pandas, qtpylib |

**设计思路**：

- 止损 34.5% 相对宽松，给价格足够的波动空间
- 追踪止损设置使得一旦盈利 5.8% 就启动保护，锁定至少 1% 利润

## 三、买入条件详解

### 3.1 保护机制（3 组可选）

每个买入保护条件都可以独立开关：

| 保护类型 | 参数说明 | 默认值 | 开关状态 |
|---------|---------|--------|---------|
| **RSI 过滤** | RSI < buy_rsi 时触发 | 52 | 默认关闭 |
| **MFI 过滤** | MFI < buy_mfi 时触发 | 30 | 默认关闭 |
| **EMA 过滤** | 快线 > 慢线时趋势向上 | 快211/慢364 | 默认关闭 |

**默认配置**：所有保护条件默认关闭，仅依赖布林带触发信号。

### 3.2 买入触发条件（4 种模式）

策略提供 4 种布林带下轨突破模式，通过 `buy_trigger` 参数选择：

| 触发模式 | 触发条件 | 含义 |
|---------|---------|------|
| **bb_lower1** | close < bb_lowerband1 | 价格跌破 1 倍标准差下轨 |
| **bb_lower2** | close < bb_lowerband2 | 价格跌破 2 倍标准差下轨 |
| **bb_lower3** | close < bb_lowerband3 | 价格跌破 3 倍标准差下轨 |
| **bb_lower4** | close < bb_lowerband4 | 价格跌破 4 倍标准差下轨 |

**默认配置**：`bb_lower1`（1 倍标准差下轨）

### 3.3 买入条件逻辑

```python
# 完整买入逻辑（伪代码）
conditions = []

# 1. 保护条件（可选）
if buy_rsi_enabled:
    conditions.append(RSI < 52)
if buy_mfi_enabled:
    conditions.append(MFI < 30)
if buy_ema_enabled:
    conditions.append(EMA(211) > EMA(364))

# 2. 触发条件（必选其一）
if buy_trigger == 'bb_lower1':
    conditions.append(close < bb_lowerband1)
# ... 其他触发模式类似

# 3. 成交量过滤
conditions.append(volume > 0)

# 所有条件同时满足才买入
```

## 四、卖出逻辑详解

### 4.1 卖出保护条件（3 组可选）

| 保护类型 | 参数说明 | 默认值 | 开关状态 |

| **sell-bb_upper3** | close > bb_upperband3 | 价格突破 3 倍标准差上轨 |
| **sell-bb_upper4** | close > bb_upperband4 | 价格突破 4 倍标准差上轨 |

## 五、技术指标体系

### 5.1 核心指标

| 指标类别 | 具体指标 | 用途 |
|---------|---------|------|
| **布林带** | 4 组布林带（1/2/3/4 倍标准差） | 买卖触发 |
| **动量指标** | RSI（相对强弱指数） | 超买超卖过滤 |
| **成交量指标** | MFI（资金流量指标） | 资金流向过滤 |
| **趋势指标** | EMA（指数移动平均） | 趋势方向过滤 |

### 5.2 布林带配置

策略使用 4 组不同标准差的布林带：

```python
# 标准布林带参数
window = 20  # 20 周期
stds = 1/2/3/4  # 1/2/3/4 倍标准差

# 典型价格计算
typical_price = (high + low + close) / 3
```

**意义**：
- 1 倍标准差：约 68% 价格波动范围
- 2 倍标准差：约 95% 价格波动范围
- 3 倍标准差：约 99.7% 价格波动范围
- 4 倍标准差：极端异常值

## 七、策略优势与局限

### ✅ 优势

1. **高度灵活**：16 个 Hyperopt 参数可针对不同市场环境优化
2. **布林带经典策略**：利用统计规律捕捉极端价位
3. **多层标准差**：4 种触发强度可选，适应不同风险偏好
4. **追踪止损完善**：自动锁定利润，避免回撤吞噬收益

### ⚠️ 局限

1. **默认参数简单**：默认关闭大部分保护条件，依赖单一触发
2. **止损偏宽**：34.5% 止损对风险厌恶者过于激进
3. **需优化调参**：策略设计依赖 Hyperopt 优化，默认配置可能不够稳健
4. **布林带局限**：趋势行情中布林带持续扩张，下轨触发可能过早

## 九、适用市场环境详解

Bandtastic 是典型的**均值回归策略**，核心逻辑是"价格偏离布林带下轨后回归"。这种策略最适合震荡市场，在趋势行情中表现不佳。

### 9.1 策略核心逻辑

- **布林带原理**：价格在统计范围内波动，极端偏离会回归
- **多层标准差**：提供不同强度的触发信号
- **可选过滤**：RSI/MFI/EMA 可增强信号质量

### 9.2 不同市场环境表现

| 市场类型 | 表现评级 | 原因分析 |
| :--- | :--- | :--- |
| 📈 慢牛震荡 | ⭐⭐⭐⭐⭐ | 价格上下波动，布林带下轨触发有效 |
| 🔄 横盘整理 | ⭐⭐⭐⭐☆ | 均值回归逻辑完美契合 |
| 📉 单边下跌 | ⭐⭐☆☆☆ | 布林带下移，下轨触发过早 |
| ⚡️ 剧烈波动 | ⭐☆☆☆☆ | 止损可能被频繁触发 |

### 9.3 关键配置建议

| 配置项 | 建议值 | 说明 |
|--------|--------|------|
| buy_trigger | bb_lower2 | 2 倍标准差更稳健 |
| sell_trigger | sell-bb_upper2 | 配合买入使用 |
| buy_rsi_enabled | True | 开启 RSI 过滤 |
| buy_rsi | 40 | 降低超卖阈值 |
| stoploss | -0.25 | 收紧止损 |

## 十一、总结

**Bandtastic** 是一个设计精巧的布林带突破策略。它的核心价值在于：

1. **高度可配置**：16 个 Hyperopt 参数覆盖买入卖出的各个环节
2. **多层触发选择**：4 种标准差强度适应不同风险偏好
3. **经典均值回归逻辑**：布林带下轨买入、上轨卖出

对于量化交易者而言，Bandtastic 是学习 Hyperopt 参数优化的优秀案例。但需要注意，默认配置过于简单，实际使用时建议开启 RSI/MFI/EMA 保护条件，并通过回测验证最优参数组合。

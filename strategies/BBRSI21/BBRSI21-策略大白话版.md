# BBRSI21 策略：一个"极简主义"的抄底高手

> **外号**：抄底小能手  
> **职业**：量化界的"极简主义者"——能少写一行代码绝不多写

---

## 一、这策略是个啥？

简单说，**BBRSI21** 就是一个：
- 只有 **1 个买入条件** 的策略
- 只有 **1 个卖出条件** 的策略
- 代码只有 **80 多行**（Nostalgia 的零头都不到）

就像一个买东西只看两个指标的直男："跌破布林带没？RSI 够低没？都满足了就买！" 🤣

---

## 二、核心配置：说白了就是"等极端行情"

### 止盈规则（ROI 表）

```
刚买入就赚 22.77%？→ 跑！
拿了 31 分钟赚 6.16%？→ 跑！
拿了 78 分钟赚 3.23%？→ 跑！
拿了 105 分钟？→ 保本也跑！
```

**翻译**：这策略预期每笔交易赚大钱，首级 ROI 就设 22.77%，比 Nostalgia 的 10% 高了一倍多！

### 止损规则

```
硬止损：亏 30% 直接割（够宽松）
追踪止损：赚 24.8% 后才启动，回撤 17.8% 就跑
```

**翻译**：这策略心很大，-30% 才止损，但赚了钱后锁定利润也很狠——典型的"要么大赚，要么大亏"😅

## 三、买入条件：就 1 个，简单粗暴

这策略的买入条件少到感人，就 1 个：

### 🎯 布林带 + RSI 双杀

**核心逻辑**：价格跌破布林带下轨 + RSI < 21

**大白话**：
> "价格都跌破布林带下轨了，而且 RSI 都到 21 以下了（比常规 30 低得多），这还不抄底更待何时？"

**代码翻译**：
```python
# 买入条件
(价格 < 布林带下轨) AND (RSI < 21)
```

**经典台词**：
- "RSI < 21 可不是随便设的，比常规 30 低多了，说明市场真的慌了！"
- "布林带下轨是统计意义上的低位，跌破 2 倍标准差，反弹概率高！"

## 五、卖出逻辑：比买入还简单

### 5.1 技术卖出：1 个条件

**触发条件**：
```python
(价格 > 布林带上轨) AND (RSI > 99)
```

**大白话**：
> "价格都突破布林带上轨了，而且 RSI 都到 99 了（接近最大值 100），这还不跑等啥？"

**吐槽**：RSI > 99 这个条件太极端了，实际交易中很少触发，大部分时候是靠 ROI 退出的。

### 5.2 ROI 退出：这才是主力

```
利润率      持仓时间    触发退出
───────────────────────────────
```

**大白话**：

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **简单到哭**：就 2 个指标，小学生都能看懂
2. **信号质量高**：RSI < 21 条件严格，不是随便乱买
3. **计算量小**：老电脑都能跑，VPS 512MB 内存就够了
4. **经典组合**：布林带 + RSI 几十年验证过的
5. **适合学习**：想学量化？从这个策略开始！

### ⚠️ 缺点（吐槽环节）

1. **信号太少**：RSI < 21 和 RSI > 99 都是极端情况，可能一天都没几个信号
2. **没趋势过滤**：不管大盘涨跌都买，下跌趋势中容易"抄底抄在半山腰"
3. **没 BTC 关联**：比特币崩了它也不知道，继续傻傻地买
4. **止损太宽**：-30% 止损，遇到极端行情可能亏到肉疼
5. **卖出条件形同虚设**：RSI > 99 太难触发，主要靠 ROI 退出

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

BBRSI21 的历史回测表现可能**非常优异**——但这有个陷阱：

> **简单的策略更容易"拟合"出漂亮的回测曲线，因为参数少，优化空间小，但这并不代表未来一定能盈利。**

简单说就是：**回测数据好看，可能是因为它刚好"背对"了那段历史行情。**

### 简单策略的隐藏风险

实盘时，简单的逻辑可能导致：
- **信号过少**：可能几天都没一个交易，资金利用率低
- **极端行情失效**：连续暴跌时，RSI < 21 可能连续触发，连续亏损
- **无趋势保护**：下跌趋势中没有自动停止机制

### 我的建议（真心话）

```
1. 先用最小资金量（如 100U）测试
2. 实盘跑至少 2-4 周，观察信号频率
3. 确认在下跌趋势中的表现（可能会连续亏损）
4. 考虑自己加个趋势过滤（如 EMA200）
```

**记住**：策略越简单，越要警惕市场环境的變化。活着最重要！

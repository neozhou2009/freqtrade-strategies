> **策略类型**: 布林带 + Fisher RSI 过滤 + 双模式确认  
> **时间框架**: 1 分钟 (1m)

---

## 一、策略概览

**Cluc7werk** 是一个基于布林带和 Fisher RSI 指标的极短线交易策略。策略核心特点是引入 Fisher RSI 变换进行超卖过滤，同时采用双模式买入机制（布林带反弹 + EMA 缩量回调）。相比 Cluc5werk，Cluc7werk 简化了多时间框架分析，专注于 1 分钟周期的日内交易。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 2 种模式（布林带反弹 + EMA 缩量回调） + Fisher RSI 过滤 |
| **买入确认** | 单次信号触发（无连续确认） |
| **卖出条件** | 价格触及布林中轨 + EMA 向下 + Fisher RSI 超买 |
| **保护机制** | Fisher RSI 过滤 + 硬止损 + 追踪止损 |
| **时间框架** | 1 分钟 |
| **依赖库** | TA-Lib, qtpylib, numpy |
| **特殊功能** | Inverse Fisher RSI 变换、双模式买入 |

## 三、买入条件详解

### 3.1 核心过滤条件（必须满足）

**Fisher RSI 变换**：
```python
# 计算过程
rsi = ta.RSI(dataframe, timeperiod=9)
rsi_transformed = 0.1 * (rsi - 50)
dataframe['fisher-rsi'] = (np.exp(2 * rsi_transformed) - 1) / (np.exp(2 * rsi_transformed) + 1)

# 过滤条件
dataframe['fisher-rsi'].lt(params['fisher'])  # fisher-rsi < -0.22987
```

- Fisher RSI 是对传统 RSI 的 Inverse Fisher 变换，将 RSI 值从 [0, 100] 映射到 [-1, 1] 区间
- fisher-rsi < -0.22987 表示 RSI 低于约 38（超卖区域）
- 这是策略的第一层保护，确保只在超卖区域考虑买入

### 3.2 模式一：布林带反弹买入

```python
# 条件 A：布林带反弹形态
(
    dataframe['bb1-delta'].gt(dataframe['close'] * params['bbdelta-close']) &
    dataframe['closedelta'].gt(dataframe['close'] * params['closedelta-close']) &
    dataframe['tail'].lt(dataframe['bb1-delta'] * params['bbdelta-tail']) &
    dataframe['close'].lt(dataframe['lower-bb1'].shift()) &
    dataframe['close'].le(dataframe['close'].shift())
)
```

**条件解析**：

1. **bb1-delta > close × 0.00732**：布林带中轨与下轨的距离占收盘价的 0.732% 以上，表示布林带具有一定宽度
2. **closedelta > close × 0.01825**：收盘价较前一根 K 线有明显的绝对上涨（1.825%），这个阈值较高
3. **tail < bb1-delta × 0.94138**：K 线下影线长度小于布林带宽度的 94.138%，表示下影线相对紧凑
4. **close < lower-bb1.shift()**：收盘价低于前一根 K 线的布林下轨，形成"跌破"形态
5. **close ≤ close.shift()**：收盘价不高于前一根 K 线收盘价，确认价格走势疲软

**形态解读**：这种模式捕捉的是"假突破"后的反弹机会。价格短暂跌破布林下轨后迅速反弹，形成类似锤子线的形态。条件中 closedelta 要求较高（1.825%），意味着需要比较明显的上涨动量。

### 3.3 模式二：EMA 缩量回调买入

```python
# 条件 B：EMA 缩量回调形态
(
    (dataframe['close'] < dataframe['ema_slow']) &
    (dataframe['close'] < params['close-bblower'] * dataframe['lower-bb2']) &
    (dataframe['volume'] < (dataframe['volume_mean_slow'].shift(1) * params['volume']))
)
```

**条件解析**：

1. **close < ema_slow**：收盘价低于 48 周期 EMA，处于长期均线下方
2. **close < lower-bb2 × 0.0199**：收盘价低于布林下轨的 1.99%，即价格跌破布林下轨
3. **volume < volume_mean_slow.shift(1) × 16**：成交量低于前一次 24 均量的 16 倍（缩量）

**形态解读**：这种模式捕捉的是急跌后的超卖反弹机会。价格在 EMA 下方且跌破布林下轨，同时成交量萎缩，表明卖压衰竭。

### 3.4 买入信号触发机制

```python
# 买入信号：满足 Fisher RSI 过滤 + 任一模式
dataframe.loc[
    (dataframe['fisher-rsi'].lt(params['fisher'])) &
    (
        模式A条件 | 模式B条件
    ),
    'buy'
] = 1
```

**设计意图**：相比 Cluc5werk 的双重确认（连续两根 K 线），Cluc7werk 简化了确认机制，单次满足条件即触发买入。这使得入场更加灵敏，但可能增加假信号风险。

## 四、卖出逻辑详解

### 4.1 卖出条件

```python
dataframe.loc[
    ((dataframe['close'] * params['sell-bbmiddle-close']) > dataframe['mid-bb2']) &
    dataframe['ema_fast'].gt(dataframe['close']) &
    dataframe['fisher-rsi'].gt(params['sell-fisher']) &
    dataframe['volume'].gt(0)
    ,
    'sell'
] = 1
```

**条件解析**：

1. **价格触及布林中轨**：`close × 0.99184 > mid-bb2`，收盘价达到布林中轨的 99.184% 以上，接近中轨位置
2. **短期均线向下**：`ema_fast > close`，6 周期 EMA 高于当前价格，表示短期趋势走弱
3. **Fisher RSI 超买**：`fisher-rsi > 0.26832`，对应 RSI 高于约 63，表示进入超买区域
4. **有效成交量**：成交量大于 0

**形态解读**：卖出条件结合了价格位置（触及布林中轨）、技术指标（均线转向 + 超买）和成交量验证。这种多重确认确保在价格开始走弱时退出。

## 六、风险管理特色

### 6.1 多层保护机制

1. **Fisher RSI 过滤层**：确保只在超卖区域（RSI < 38）考虑买入
2. **双模式买入层**：两种互补的买入模式覆盖不同场景
3. **硬止损层**：-10% 止损，相比 Cluc5werk 更为紧凑
4. **追踪止损层**：1% 利润后激活，保护浮盈

### 6.2 止盈策略

- **ROI 渐进退出**：随着持仓时间增加，逐步降低止盈目标（10% → 7% → 5% → 3%）
- **追踪止损保护**：在趋势延续时保留更多利润
- **多重条件退出**：价格触及布林中轨 + 均线转向 + 超买确认

### 6.3 风险收益特征

| 参数 | 值 | 说明 |
|------|-----|------|
| **最大持仓** | 5 个交易对 | 分散风险 |
| **止盈目标** | 10% / 7% / 5% / 3% | 激进型目标 |
| **止损** | -10% | 紧凑型止损 |
| **追踪止损激活** | 1% 利润 | 低门槛激活 |
| **平均持仓时间** | 预计 1-4 小时 | 极短线交易 |

### 6.4 与 Cluc5werk 的风险管理对比

| 特征 | Cluc5werk | Cluc7werk |
|------|-----------|-----------|
| 止损 | -22.4% | -10% |
| 首目标利润 | 2.13% | 10% |
| 追踪止损激活 | 18.6% | 1% |
| 趋势过滤 | 1小时 ROCR | Fisher RSI |
| 买入确认 | 连续2根K线 | 单次信号 |

## 七、策略优势与局限

### 7.1 优势

1. **激进的目标利润**：10% 的首目标利润远高于大多数策略
2. **Fisher RSI 过滤**：相比简单 RSI，Inverse Fisher 变换提供了更好的超买超卖信号
3. **双模式买入**：两种互补的买入模式覆盖不同场景
4. **紧凑的止损**：-10% 止损相比 Cluc5werk 更为保守
5. **低门槛追踪止损**：1% 即可激活追踪，及时保护利润
6. **无多时间框架依赖**：简化了分析流程，只需 1 分钟数据

### 7.2 局限

1. **时间框架过短**：1 分钟级别容易受到市场噪音影响
2. **单次确认风险**：相比连续确认，单次信号可能增加假信号概率
3. **激进目标难以达到**：10% 目标在单笔交易中可能难以实现
4. **流动性要求**：需要交易量大的交易对才能正常运作
5. **高波动依赖**：需要市场有足够波动才能触发买入条件

## 八、适用场景建议

### 8.1 推荐使用场景

- **高波动币种**：如 ALT、SHIB 等 meme 币或新上线代币
- **快速反弹行情**：策略擅长捕捉超卖后的快速反弹
- **流动性充足的市场**：需要交易量大的交易对以避免滑点
- **追求高收益的投资者**：10% 目标利润适合激进型交易者

### 8.2 不推荐使用场景

- **低波动币种**：波动不足难以触发买入条件
- **横盘震荡市场**：Fisher RSI 过滤可能过于严格
- **流动性差的交易对**：滑点可能导致实际收益下降
- **稳健型投资者**：10% 目标可能过于激进

### 8.3 变体建议

基于 Cluc7werk 可以考虑以下调整：

| 调整方向 | 修改建议 |
|----------|----------|
| 保守型 | 提高止损到 -15%，降低首目标到 5% |
| 稳健型 | 增加连续两根K线确认机制 |
| 趋势型 | 添加 1 小时 ROCR 趋势过滤 |

## 九、适用市场环境详解

### 9.1 最佳市场环境

1. **高波动性**：价格经常出现大幅波动，触发布林带突破
2. **快速下跌后反弹**：Fisher RSI < -0.22987 捕捉超卖机会
3. **充足流动性**：交易深度好，买卖价差小

### 9.2 表现一般的市场

1. **横盘震荡**：Fisher RSI 过滤会过滤掉大部分信号
2. **阴跌行情**：持续下跌可能无法触发反弹模式
3. **低波动率**：布林带收窄，难以触发买入条件

### 9.3 市场环境识别

建议结合以下指标判断市场环境：

- **Fisher RSI 值**：低于 -0.3 应密切关注买入机会
- **布林带宽度**：扩大时增加交易频率
- **成交量**：放大时市场活跃度更高

## 十、重要提醒：复杂性的代价

### 10.1 激进目标的风险

Cluc7werk 设定 10% 的首目标利润，这是一个非常激进的目标。在实际交易中：

1. **滑点影响**：实际成交价可能与信号价格有偏差
2. **流动性风险**：大额订单可能无法以目标价格成交
3. **市场冲击**：买入时可能推动价格上涨，减少实际利润

### 10.2 参数稳定性建议

- **使用默认参数**：不建议随意修改已优化的参数
- **分时段验证**：在不同时间段进行回测验证
- **小额实盘测试**：实盘前进行充分模拟测试
- **密切监控**：由于目标利润较高，需要更密切的市场监控

### 10.3 监控要点

1. **成交率**：目标订单是否能够成交
2. **持仓时间**：是否在合理时间内达到目标
3. **信号频率**：信号过少或过多都可能是问题
4. **回撤情况**：账户整体回撤是否在可接受范围

## 十一、总结

Cluc7werk 是一个设计激进的极短线交易策略，融合了 Fisher RSI 变换、布林带形态识别和双模式买入机制。其核心特点是高目标利润（10%）和紧凑的止损设置（-10%）。

**关键特点**：

- 使用 Fisher RSI 进行超卖过滤，确保买入安全性
- 两种互补的买入模式（布林带反弹 + EMA 缩量回调）
- 单次信号触发，入场更加灵敏
- 激进的目标利润设定（10% 首目标）

**使用建议**：

- 建议在有经验的情况下使用，新手谨慎
- 优先选择高流动性交易对
- 保持参数不变，避免过度优化
- 结合市场环境监控信号质量
- 做好风险管理，不要超过可承受的仓位

**风险提示**：

- 10% 目标利润在单笔交易中可能难以实现
- 1 分钟时间框架容易受到噪音影响
- 单次确认机制可能增加假信号概率

策略的回测表现需要进一步验证，投资者应意识到极短线策略的固有风险，并进行充分的实盘测试后再应用于实际资金。

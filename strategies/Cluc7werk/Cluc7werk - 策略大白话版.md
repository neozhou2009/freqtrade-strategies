## 一、这策略是个啥？

简单说，**Cluc7werk** 就是一个：

- 用 **Fisher RSI** 判断是不是跌惨了
- 跌惨了就用 **布林带** 找机会抄底
- 目标利润 **10%**，敢想敢干
- 止损 **-10%**，亏了也跑得快

就像一个**专门在医院门口等救护车的黄牛**——看到有人出车祸（暴跌）就冲上去，捡便宜货，然后转手卖出。但问题是：救护车来得快不快？🤔

## 二、核心配置：说白了就是"贪心又胆小"

### 止盈规则（ROI 表）

```
第0分钟   → 赚10%就跑（真敢想！）
第60分钟  → 赚7%就跑（还能接受）
第120分钟 → 赚5%就跑（开始急了）
第240分钟 → 赚3%就跑（算了，能赚就行）
```

**翻译**：这策略刚进场就想着赚10%，就像刚进赌场就想赢大钱。但如果运气不好，4小时后赚个3%也勉强收手。

### 止损规则

```
硬止损: -10%（亏10%必须走人）
追踪止损: 赚1%后激活，赚1.26%时锁定利润
```

**翻译**：
- 亏10%就认栽，不拖泥带水
- 赚1%就开始保护利润，赚1.26%就把止损往上提

**吐槽**：这策略的目标利润和止损是对称的——赚10%或亏10%。就像打赌：要么翻倍要么清零，刺激！

### 持仓管理

```
最多同时持有 5 个交易对
```

**翻译**：别把鸡蛋放一个篮子里，最多5个篮子。

## 三、2 个买入条件：跌惨了才买

这策略的买入逻辑很简单：**跌到妈都不认识了才考虑买**。具体有2种模式：

### 🎯 模式一：布林带反弹（适合急跌后反转）

**核心逻辑**：价格跌穿布林带下轨，但很快又弹回来——这是"假突破"！

**大白话**：
> "我本来以为要跌死了，结果一根针扎下去又弹回来，下影线短短的——这是骗人的！"

**条件拆解**：

| 条件 | 数值 | 大白话 |
|------|------|--------|
| 布林带宽度 | > 0.732% | 布林带要够宽，不能是缩量横盘 |
| 收盘价变化 | > 1.825% | 要有明显波动，死气沉沉的不买 |
| 下影线长度 | < 94.138% | 下影线要短，不能有长尾巴 |
| 收盘价位置 | < 前一根的下轨 | 必须是"跌破"形态 |
| 走势确认 | ≤ 前一根收盘价 | 确认还是弱势 |

**想象图**：价格像跳水一样扎下去，但刚碰到水面就弹回来了，留下一根短短的"针"。这就是机会！

---

### 📉 模式二：EMA 缩量回调（适合阴跌后企稳）

**核心逻辑**：价格在长期均线下方，跌破布林带，而且成交量萎缩——卖不动了！

**大白话**：
> "价格一路跌，均线都压在头顶上，布林带也兜不住了，但成交量越来越小——这是卖光了，该反弹了！"

**条件拆解**：

| 条件 | 数值 | 大白话 |
|------|------|--------|
| 价格位置 | < 48周期EMA | 在长期均线下方（弱势区域） |
| 跌破程度 | < 布林下轨 × 1.99% | 跌穿了布林带 |
| 成交量 | < 24均量 × 16 | 缩量到极点 |

**想象图**：价格像水慢慢流干，最后只剩一点水珠（成交量萎缩），这时候就该反弹了。

---

### 🔑 门槛条件：Fisher RSI 必须 < -0.22987

这是**必须满足的前提条件**！

**Fisher RSI 是啥？**
- 就是把普通 RSI 变换了一下，值从 0-100 变成 -1 到 1
- **低于 -0.23 ≈ RSI 低于 38**，就是超卖区
- **高于 0.27 ≈ RSI 高于 63**，就是超买区

**大白话**：
> "只有跌到脸都绿了（RSI < 38）才考虑买，涨得红光满面（RSI > 63）就赶紧跑！"

**吐槽**：这策略表面激进，其实挺怂的——亏10%就跑，赚1%就开始保护。但问题是目标利润是10%，赚1%只是开始，最后可能只赚个"手续费"🤣

|------|------|--------|

**大白话**：

**吐槽**：这卖出条件设计得挺精妙——既要涨到位，又要涨不动了，还要有量配合。相当于**三个人都点头才能走**。

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **目标明确**：10%利润目标，不玩虚的
2. **反应快**：单次信号就买，不等连续确认
3. **保护到位**：4层保险丝，不会傻亏
4. **专注超卖**：只在跌惨了买，有安全边际
5. **参数简化**：不用多时间框架，只看1分钟

### ⚠️ 缺点（吐槽环节）

1. **目标太高**：10%在单笔交易中经常达不到，容易"高开低走"
2. **1分钟图太短**：噪音多到让你怀疑人生
3. **单次确认**：不像Cluc5werk要连续2根K线，可能买在半山腰
4. **滑点杀手**：波动大的币买卖价差也大，实际利润被吃掉
5. **心理压力大**：1分钟图盯着看，心脏不好的别用

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

Cluc7werk 的历史回测表现可能**看起来很诱人**——但这有个陷阱：

> **因为目标是10%，策略很容易"赢小亏大"——大多数时候赚个3-5%就卖了，偶尔亏个10%。**

简单说就是：**赚的时候赚不多，亏的时候亏满仓。**

### 复杂策略的隐藏风险

实盘时，复杂的逻辑可能导致：

- **信号错过**：1分钟图变化快，信号出现到你下单可能已经涨了
- **滑点吃利润**：波动大的币买卖价差大，3%利润可能只剩1%
- **手续费杀手**：频繁交易手续费不少，利润被吃掉
- **情绪干扰**：看着账户涨涨跌跌，容易手动干预

### 我的建议（真心话）

```
1. 先用模拟盘跑1个月，看看实际效果
2. 选择流动性好的主流币对，避开小币种

4. 止损可以放宽到-15%，给自己点空间

```

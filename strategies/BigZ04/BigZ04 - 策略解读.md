# BigZ04 策略深度解读

## 一、策略概览

BigZ04 是 BigZ03 的 **改进版本**，由 ilya 开发。该策略在 BigZ03 基础上优化了买入条件，增加了条件10（1小时超卖 + MACD反转），使信号更加丰富。策略保持"低回撤、快卖出"的核心设计理念，但通过新增条件提供了更多的入场机会。

### 核心特征表

| 特征项 | 配置值 |
|--------|--------|
| 时间框架 | 5分钟（5m） |
| 信息时间框架 | 1小时（1h） |
| 止盈（ROI） | 0-10分钟：2.8%，10-40分钟：1.8%，40-180分钟：0.5%，180分钟以上：1.8% |
| 止损 | -0.99（使用自定义止损） |
| 跟踪止损 | 启用，正向1%，触发偏移2.5% |
| 买入条件数 | 13个（比BigZ03多1个） |
| 适合交易对数 | 2-4个 |
| 核心特色 | 新增条件10：1小时超卖+MACD反转 |

### 条件10：1小时超卖 + MACD反转（新增核心）

这是BigZ04的核心新增功能，设计用于捕捉大级别的趋势反转：

```python
(
    # 1小时RSI极度超卖（<35）
    (dataframe["rsi_1h"] < 35.0) &
    
    # 1小时价格位于布林下轨下方
    (dataframe["close_1h"] < dataframe["bb_lowerband_1h"]) &
    
    # MACD柱状体为正（多头动能）
    (dataframe["hist"] > 0) &
    
    # 2根K线前MACD柱状体为负（金叉进行中）
    (dataframe["hist"].shift(2) < 0) &
    
    # 5分钟RSI低于40.5
    (dataframe["rsi"] < 40.5) &
    
    # MACD柱状体足够强（>开盘价*0.12%）
    (dataframe["hist"] > dataframe["close"] * 0.0012) &
    
    # 阳线确认
    (dataframe["open"] < dataframe["close"])
)
```

**条件10深度解析**：

| 要素 | 要求 | 意义 |
|------|------|------|
| rsi_1h < 35 | 1小时RSI超卖 | 大周期超卖 |
| close_1h < bb_lowerband_1h | 1小时价格在下轨 | 位置超跌 |
| hist > 0 | MACD柱为正 | 动能转多 |
| hist.shift(2) < 0 | 2根K线前为负 | 金叉进行中 |
| rsi < 40.5 | 5分钟RSI较低 | 小周期配合 |
| hist > close * 0.0012 | MACD柱足够强 | 反弹有力度 |
| open < close | 阳线 | 收盘确认 |

**条件10的设计逻辑**：

1. **大周期超卖**：1小时RSI低于35表示市场极度超卖，反弹概率高
2. **位置超跌**：价格位于布林下轨下方是强烈的超卖信号
3. **动能反转**：MACD从负转正，表明下跌动能已经耗尽
4. **双重确认**：5分钟RSI也需要配合，但不能太高（避免追高）
5. **强度验证**：MACD柱状体必须足够强，确保反弹有持续动力

### 4.2 自定义止损

```python
def custom_stoploss(
    self,
    pair: str,
    trade: "Trade",
    current_time: datetime,
    current_rate: float,
    current_profit: float,
    **kwargs,
) -> float:
    # 盈利状态不触发
    if current_profit > 0:
        return 0.99
    
    # 持仓50分钟后检查
    trade_time_50 = trade.open_date_utc + timedelta(minutes=50)
    
    if current_time > trade_time_50:
        try:
            # 获取持仓50分钟时的K线数据
            dataframe, _ = self.dp.get_analyzed_dataframe(pair, self.timeframe)
            # 假设已计算number_of_candle_shift
            candle = dataframe.iloc[-number_of_candle_shift].squeeze()
            
            # 1小时RSI < 30，等待恢复
            if candle["rsi_1h"] < 30:
                return 0.99
            
            # 价格高于EMA200，还在下跌，2.5%触发止损
            if candle["close"] > candle["ema_200"]:
                if current_rate * 1.025 < candle["open"]:
                    return 0.01
            
            # 继续下跌，1.5%止损
            if current_rate * 1.015 < candle["open"]:
                return 0.01
        
        except:
            return 0.5
    
    return 0.99
```

**止损逻辑关键点**：
- 50分钟观察期：不主动止损
- RSI例外：1小时RSI<30时等待反弹
- 趋势保护：EMA200之上额外检查
- 硬性底线：亏损超1.5%强制止损

## 一、这个策略是干啥的？

简单说，这是一个**自动帮你买卖加密货币**的程序。

它的核心思路是：**在币价下跌的时候分批买入，等币价涨起来了再分批卖出赚钱。**

就像去菜市场买菜，大妈们最喜欢在菜价便宜的时候多囤点，等涨价了再卖出去。这个策略就是帮你做这件事的"机器人大妈"。

### 这个策略适合谁？

- 有一定编程基础，会用 Freqtrade 的朋友
- 想在加密货币市场稳定赚钱的人
- 能接受偶尔亏损，追求长期盈利的投资者

## 二、策略的工作流程是怎样的？

想象你在看一个币的价格走势图：

```
价格
  ↑
  │      ○───○ 卖出区
  │     ╱     ╲
  │    ╱       ╲
  │   ╱         ○───○ 买入区
  │  ╱         ╱
  │ ╱         ╱
  │○─────────○
  └─────────────→ 时间
```

策略的工作流程：

1. **盯盘**：24小时不间断监控币价
2. **找机会**：发现有币跌到了"便宜"的位置
3. **买入**：自动下单买入
4. **持有**：等币价涨起来
5. **卖出**：涨到目标价位自动卖出赚钱

## 三、策略的核心密码——"69道门"

这个策略最厉害的地方是它有 **69 个不同的买入条件**。

什么意思？就像你开了 69 家店，每家店卖不同的东西，只要有顾客来任何一家店买东西，你就赚钱了。

### 这些买入条件分几类？

#### 类型一：捡漏型

**特点**：等币价跌得很惨了再买，捡便宜货。

举例：某币从 100 块跌到 50 块，跌了一半。策略会觉得"太便宜了"，开始买入。

**代码里怎么体现**：
```python
rsi_14 < 35.0       # RSI 指标低于 35，说明跌多了
r_14 < -90.0        # 价格变化率低于 -90，严重超卖
```

#### 类型二：趋势回调型

**特点**：币价总体在涨，但中间有小回调，在回调时买入。

举例：比特币从 3 万涨到 4 万，中间回调到 3.8 万，这时候买入，等它继续涨到 4.5 万再卖。

**代码里怎么体现**：
```python
ema_200 > ema_200.shift(12)   # 200均线在上升，说明大趋势向上
close < ema_20 * 0.97         # 价格低于均线 3%，是回调机会
```

#### 类型三：支撑位反弹型

**特点**：币价跌到某个"支撑位"，历史上每次跌到这里都会反弹，所以在支撑位买入。

举例：某币每次跌到 100 块都会反弹，现在又跌到 100 块附近，策略买入。

**代码里怎么体现**：
```python
close > sup_level_1d          # 价格在日线支撑位之上
low < sup_level_1d * 0.99     # 低点触及了支撑位
```

## 四、卖出策略——"阶梯式止盈"

策略的卖出逻辑很有意思，叫**阶梯式止盈**。

### 什么是阶梯式止盈？

简单说就是：**你赚得越多，我越容易让你卖出。**

举例：

- 你刚买入，赚了 1%：这时候卖出条件很严格，因为还没赚够
- 你赚了 5%：卖出条件变宽松了，可以锁定收益
- 你赚了 10%：非常容易卖出，赶紧落袋为安

### 为什么这样设计？

假设你买入一个币：

1. **刚买入**：你肯定不想卖，因为才刚开始
2. **赚了 3%**：有点小赚，但还想看看能不能涨更多
3. **赚了 8%**：不少了，如果有什么风吹草动就卖了吧
4. **赚了 15%**：太多了！赶紧卖掉落袋为安！

策略就是模拟这种人性化的卖出决策。

## 五、策略用了哪些"工具"？

策略就像一个修车师傅，有很多工具用来判断什么时候买、什么时候卖。

### 工具一：RSI 指标

**是什么**：一个 0-100 的数字，用来判断币价是"太贵"还是"太便宜"。

- RSI > 70：太贵了，可能会跌
- RSI < 30：太便宜了，可能会涨

**策略怎么用**：
```python
rsi_14 < 35.0   # RSI 低于 35，币价便宜，考虑买入
rsi_14 > 70.0   # RSI 高于 70，币价贵了，考虑卖出
```

### 工具二：EMA 均线

**是什么**：把过去一段时间的价格平均一下，画成一条线。

- EMA12：最近 12 根K线的平均价格，反映短期趋势
- EMA200：最近 200 根K线的平均价格，反映长期趋势

**策略怎么用**：
```python
close > ema_200    # 价格在长期均线上方，大趋势向上
ema_12 > ema_26    # 短期均线上穿长期均线，金叉，看涨
```

### 工具三：布林带

**是什么**：在均线上下各画两条线，形成一个"通道"。

- 价格碰到上轨：可能要跌
- 价格碰到下轨：可能要涨

**策略怎么用**：
```python
close < bb20_2_low * 0.98   # 价格跌破布林带下轨，超卖，买入机会
```

### 工具四：CMF 资金流量

**是什么**：看流入这个币的钱是多还是少。

- CMF > 0：钱在流入，好事
- CMF < 0：钱在流出，坏事

**策略怎么用**：
```python
cmf < -0.1    # 资金在流出，可能要跌，赶紧卖出
cmf > 0.1     # 资金在流入，可能要涨
```

### 工具五：R 指标（策略自研）

**是什么**：策略自己研发的指标，用来衡量价格变化的速度和程度。

```python
r_14 < -90    # 14根K线内价格跌了很多，抄底机会
r_480 > -30   # 长期来看跌幅不大，不是熊市
```

## 六、策略的"安全带"——风险管理

开车要系安全带，交易也要有风险管理。策略有几个保护机制：

### 保护一：止损

如果买入后一直跌怎么办？策略会帮你止损。

```python
stoploss = -0.10   # 亏损 10% 就止损卖出
```

举例：100 块买入，跌到 90 块自动卖出，防止亏更多。

### 保护二：追踪止损

赚了钱之后怎么保护利润？用追踪止损。

```python
trailing_stop = True
trailing_stop_positive = 0.01
trailing_stop_positive_offset = 0.03
```

举例：
- 100 块买入
- 涨到 103 块，启动追踪止损
- 涨到 110 块，止损位变成 109 块
- 跌回 109 块，自动卖出，赚 9%

### 保护三：BTC 联动

比特币是大哥，大哥跌了，小弟们往往也要跌。

```python
if btc_not_downtrend_1h:   # 如果比特币不在跌
    允许买入                 # 才允许买入
```

这样在 BTC 大跌的时候，策略会减少买入，避免"接飞刀"。

## 七、多时间框架——"望远镜+显微镜"

策略同时看 4 个时间周期，就像同时用望远镜和显微镜：

### 四个时间周期

| 时间周期 | 作用 | 比喻 |
|---------|------|------|
| 日线（1d） | 看大趋势 | 望远镜，看远一点 |
| 小时线（1h） | 看中期走势 | 望远镜，看近一点 |
| 15分钟（15m） | 找精确入场点 | 显微镜，看细一点 |
| 5分钟（5m） | 执行交易 | 动手操作 |

### 为什么要这样？

举例说明：

1. **日线看趋势**：比特币日线在涨，大趋势向上 ✓
2. **小时看回调**：小时线出现回调，到了支撑位 ✓
3. **15分钟找入场**：15分钟 RSI 超卖，短期见底 ✓
4. **5分钟执行**：现在买入！

这就是"大趋势向上 + 小趋势回调"的完美入场点。

## 八、策略的"大脑"——买入条件详解

让我们看几个典型的买入条件：

### 条件 1：半摆动抄底

**大白话解释**：
- 币价最近有过上涨（有热度）
- 现在跌了一些（RSI < 35）
- 但还没跌到崩盘（小时 RSI 还健康）
- 结论：这是回调，可以买入

**适合场景**：上升趋势中的短期回调。

### 条件 3：布林带下轨抄底

**大白话解释**：
- 布林带够宽（波动够大）
- 价格跌破下轨（超卖）
- 影线很短（真跌，不是假摔）
- 结论：反弹机会来了

**适合场景**：波动较大的震荡行情。

### 条件 17：深度抄底

**大白话解释**：
- 短期跌了很多（R14 < -99）
- 长期也跌了很多（R480 < -90）
- 小时也跌了很多（R480_1h < -93）
- RSI 历史低位
- 结论：这是崩盘式的下跌，但也是抄底的好机会

**适合场景**：极端下跌行情（风险高，收益也可能高）。

### 条件 22：日线支撑反弹

**大白话解释**：
- 价格到了日线支撑位
- 曾跌破支撑位但收盘收回
- 支撑位有效
- 结论：支撑位反弹机会

**适合场景**：关键支撑位附近的反弹交易。

## 十、如何使用这个策略？

### 第一步：安装 Freqtrade

```bash
git clone https://github.com/freqtrade/freqtrade.git
cd freqtrade
./setup.sh -i
```

### 第二步：安装依赖

```bash
pip install pandas_ta ta-lib technical
```

### 第三步：配置文件

在 `config.json` 里设置：

```json
{
    "timeframe": "5m",
    "use_sell_signal": true,
    "sell_profit_only": false,
    "ignore_roi_if_buy_signal": true,
    "max_open_trades": 6
}
```

### 第四步：运行

```bash
freqtrade trade --strategy NostalgiaForInfinityXw
```

## 十二、常见问题解答

### Q1：这个策略能赚多少钱？

**答**：没有固定答案。根据历史回测和实盘经验，年化收益可能在 20%-100% 之间，取决于市场行情和参数设置。

### Q2：会不会亏光？

**答**：策略有 10% 的止损，单笔最大亏损 10%。如果管理好资金，不会亏光。但极端行情下可能出现连续亏损。

### Q3：需要一直开着电脑吗？

**答**：是的。建议使用云服务器（VPS）24小时运行。推荐 AWS、DigitalOcean 等服务商。

### Q4：怎么知道策略有效？

**答**：
1. 先做历史回测
2. 再做模拟盘（干跑）
3. 最后小资金实盘
4. 确认盈利后加大资金

### Q5：参数需要经常调整吗？

**答**：建议每季度做一次参数优化。加密市场变化快，去年的好参数今年可能就不行了。

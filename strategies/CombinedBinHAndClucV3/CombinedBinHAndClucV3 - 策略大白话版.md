## 一、这策略是个啥？

简单说，**CombinedBinHAndClucV3** 是一个"双刀流"超跌反弹策略：

- 由两个经典策略合并而来：**BinHV45** + **ClucMay72018**
- 两个策略各有绝活，只要其中一个触发就买入
- 专门抓那些"跌过头了要弹回来"的机会

就像一个老练的渔夫，撒了两张网——一张网急跌反弹的鱼，一张网缩量超跌的鱼。鱼进哪张网都行，总有一款适合你。🐟

## 二、核心配置：说白了就是"赚点就跑，亏多了认栽"

### 止盈规则（ROI 表）

```
累计收益 ≥ 1.8% → 触发止盈
```

**翻译**：赚够 1.8% 就跑，别贪心，落袋为安。

### 止损规则

```
固定止损：-10%
追踪止损：盈利 3% 后启动，保护 1% 利润
时间止损：持仓 36.7 小时后若亏损，强制市价跑路
```

**翻译**：
- 最多亏 10%，到线就认栽
- 赚够 3% 之后开启"护盾"，从最高点回撤 1% 就跑
- 持仓超过 36 小时还在亏？不熬了，市价走人

### 其他配置

| 配置项 | 值 | 大白话 |
|--------|-----|--------|
| 时间周期 | 5 分钟 | 短线高频 |
| 盈利才卖 | True | 亏钱状态下不许卖 |

## 六、这策略的"人格特点"

如果把策略比作一个人：

### ✅ 优点（夸夸环节）

1. **双刀流猎手**：两套买入逻辑，覆盖急跌反弹和缩量反弹两种场景，适应性更强

3. **单边行情死得惨**：连续上涨会卖飞，连续下跌会反复止损
4. **卖出条件苛刻**：连续 5 根 K 线突破上轨才卖，可能错过最佳卖点

```yaml
# 最小收益目标

# 止损
stoploss: -0.10  # 10% 硬止损

# 追踪止损
trailing_stop: True
trailing_stop_positive: 0.01  # 保护 1% 利润
trailing_stop_positive_offset: 0.03  # 盈利 3% 后启动
```

### 10.3 硬件要求（重要！）

5 分钟周期策略计算量不算大，但交易频率高：

| 交易对数量 | 最低配置 | 推荐配置 | 体验 |
|-----------|---------|---------|------|
| 1-10 个 | 2 核 2G | 2 核 4G | 丝滑 |
| 10-30 个 | 2 核 4G | 4 核 8G | 流畅 |
| 30+ 个 | 4 核 8G | 4 核 16G | 可能需要优化 |

**警告**：交易频率高，API 限速可能是瓶颈，别跑太多交易对！

### 10.4 回测 vs 实盘

回测时看起来很美好，实盘会有差异：

1. **滑点**：回测按理想价格成交，实盘可能有滑点
2. **手续费**：高频交易手续费累积起来很可观
3. **延迟**：网络延迟可能导致错过最佳价格
4. **流动性**：小币种可能卖不出去

**建议流程**：
1. 先回测 3 个月历史数据
2. 小资金实盘测试 1-2 周
3. 确认盈利后再放大资金
4. 定期检查和调整参数

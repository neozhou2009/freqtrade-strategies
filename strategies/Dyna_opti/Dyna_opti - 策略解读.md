## 一、策略概览

**Dyna_opti** 是一个高度参数化的复杂策略，由 @werkkrew 开发。策略融合了多种技术指标（布林带、RMI、ATR、SSL通道等），并实现了动态止盈和自定义止损机制。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 1 个主买入条件 + 信息层保护机制 |
| **卖出条件** | 动态 ROI + 自定义止损 |
| **保护机制** | 2 组买入保护参数（信息层过滤） |
| **时间框架** | 5 分钟（主）+ 1 小时（信息层） |
| **依赖库** | TA-Lib, technical, numpy |

## 三、买入条件详解

### 3.1 信息层保护机制

策略使用 1 小时时间框架作为信息层，添加两层保护：

```python
# 上界保护
if inf_guard == 'upper' or 'both':
    conditions.append(
        close <= 3d_low + inf_pct_adr_top * adr
    )

# 下界保护
if inf_guard == 'lower' or 'both':
    conditions.append(
        close >= 3d_low + inf_pct_adr_bot * adr
    )
```

### 3.2 核心买入条件（BinHV45 策略）

```python
# 布林带突破买入
conditions.append(
    bb_lowerband.shift() > 0 &                          # 前一K有布林带下轨
    bbdelta > close * bbdelta_close &                   # 布林带宽度足够
    closedelta > close * closedelta_close &              # 收盘价变化足够
    tail < bbdelta * tail_bbdelta &                     # 下影线短
    close < bb_lowerband.shift() &                      # 收盘价跌破下轨
    close <= close.shift()                              # 收盘价不高于前一K
)
```

## 四、卖出逻辑详解

### 4.1 动态 ROI 系统

策略使用 `min_roi_reached_dynamic` 实现动态止盈：

| 趋势类型 | 触发条件 | ROI 值 |
|---------|---------|--------|
| RMI 趋势 | RMI 上升计数 >= 3 | 100% (不退出) |
| SSL 趋势 | SSL 通道向上 | 100% (不退出) |
| 蜡烛趋势 | 连续上涨蜡烛 >= 3 | 100% (不退出) |

### 4.2 自定义止损逻辑

```python
def custom_stoploss(...):
    if current_profit < cstp_threshold:     # 利润 < -5%
        if cstp_bail_how == 'time':        # 时间方式
            if trade_dur > cstp_bail_time: # 超过 961 分钟
                return 0.001               # 强制退出
        if cstp_bail_how == 'roc':         # ROC 方式
            if sroc <= cstp_bail_roc:      # ROC < -1.8%
                return 0.001
```

# ClucMay72018 策略：超卖捡漏王

> **外号**：超卖捡漏王 / 布林带刺客  
> **职业**：逆势抄底专业户  
> **时间框架**：5 分钟

---

## 一、这策略是个啥？

简单说，**ClucMay72018** 就是一个：
- 价格跌到布林带下面去了？买！
- 价格涨回布林带中间了？卖！
- 啥？成交量突然放大了？那不买了，怕是坑 🕳️

就像你去逛二手市场一样：
> "这个东西原价 100，现在打 5 折还没人要，肯定便宜了，我买！等它回到 7 折，我就卖掉赚一笔！"

这就是典型的**均值回归**思路——价格偏离正常区间太远了，迟早要回来。

策略作者是 **Gert Wohlgemuth**，设计的理念就是：在超卖的地方捡便宜，等价格回到正常水平就卖出。听起来是不是有点像"价值投资者"？但实际上它是个**短线交易策略**，5 分钟级别，专门吃日内波动。

### 止盈规则（ROI 表）

```python
minimal_roi = {
    "0": 0.01  # 赚 1% 就跑路
}
```

**翻译**：甭管那么多，赚够 1% 我就走人！

### 止损规则

```python
stoploss = -0.05  # 亏 5% 认赔
```

**翻译**：最多亏 5%，再跌我就跑路，别想让我套牢！

### 时间框架

```python
timeframe = '5m'  # 5 分钟级别
```

**大白话**：这是个**日内策略**，不隔夜持仓，当天买当天卖。

## 三、1 个买入条件：我帮你拆开了看

这策略的买入条件看起来只有一个，但实际上**内有乾坤**，由 3 个子条件组成，只有三个条件同时满足才会买入：

### 🎯 核心买入公式

```
买入 = (价格 < EMA100) AND (价格 < 布林带下轨 × 0.985) AND (成交量 < 均量的 20 倍)
```

我来给你翻译成人话：

| 子条件 | 代码 | 大白话 |
|-------|------|--------|
| 条件 1 | `close < ema100` | 价格必须在长期均线下面，不能在上涨趋势中追高 |
| 条件 2 | `close < 0.985 × bb_lowerband` | 价格必须比布林带下轨还低 1.5%，必须是超超超卖 |
| 条件 3 | `volume < 均量 × 20` | 成交量不能太大，防止买到"暴跌如山倒"的假反弹 |

**拟人化解读**：

> 策略内心 os："哎呀，这个币价格已经跌到亲妈都不认识了，而且还在缩量下跌，不是那种恐慌踩踏。我看准了，这波跌透了，我进去捡个漏，等它涨回来我就跑！"

## 四、保护机制：成交量过滤

这策略没有像其他策略那样的一大堆保护参数，但它有一个**隐性保护**：

| 保护类型 | 作用 | 大白话 |
|---------|------|--------|
| 成交量过滤 | 成交量 < 30日均量 × 20 | 必须是"悄悄"下跌，不能是放量暴跌 |

**为什么这个很重要？**

你想啊，如果是放量下跌，说明市场恐慌，大家都在抛售，你这时候进去买，不是接飞刀是什么？策略聪明的很，它要的是**缩量下跌**，说明卖方已经没什么力气了，价格差不多见底了，这时候买入胜算才大。

```
布林带中轨 ─────────────── ✅  到这里就卖！均值回归完成

```

**拟人化解读**：

> 策略内心 os："好了好了，价格已经从谷底爬回来了，回到正常水平了，我不贪，见好就收，卖卖卖！"

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **简单粗暴**：就一个买入条件、一个卖出条件，不用记那么多复杂的规则
2. **逆势抄底**：专门买超跌的币，听起来就很酷有没有？
3. **计算量小**：不用跑复杂的模型，电脑、手机都能跑
4. **震荡市场专用**：在横盘震荡的市场里如鱼得水
5. **日内交易**：当天结算，不担心隔夜风险

### ⚠️ 缺点（吐槽环节）

1. **卖得太早**：价格突破中轨就跑了，后面可能还有大涨，但跟你没关系了
2. **趋势市场完蛋**：遇到连续下跌趋势，可能一直买一直亏
3. **参数固定**： EMA100 和布林带参数都是写死的，可能需要根据不同币种调整
4. **牛市跟你没关系**：价格上涨时根本不触发买入条件，眼看着别人赚钱

|-----------|---------|---------|------|

### 10.4 回测 vs 实盘

**注意事项**：

1. **滑点**：实盘买入价格往往比回测价格高，建议设置 0.001 滑点
2. **流动性**：小币种可能买不到足够的量
3. **市场深度**：极端行情下市价单可能成交在很糟糕的价格

**建议流程**：
1. 先用模拟盘跑一周
2. 观察策略表现是否符合预期
3. 小资金上实盘测试
4. 确认没问题后再加大仓位

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

ClucMay72018 的回测表现看起来**挺不错**——尤其是在震荡市场里，均值回归策略往往能稳定盈利。但有个问题：

> **历史表现不代表未来！** 市场风格会变，以前有效的策略以后可能失效。

### 逆势策略的隐藏风险

这个策略是**逆势抄底**，听起来很酷，但有个致命问题：

- **越跌越买可能抄到半山腰**：你觉得跌够了，实际上可能才开始跌
- **趋势来的时候一直亏**：连续下跌趋势中，策略会反复买入、反复止损
- **卖太早错过大涨**：价格突破中轨就跑了，后面的大肉跟你没关系

### 我的建议（真心话）

```
1. 先用模拟盘测试，别一上来就真金白银
2. 选择震荡市场使用，趋势来了就停
3. 一定要设止损！5% 是底线
4. 别贪心，策略让你赚 1% 就跑，你别想着赚 10%
5. 关注市场环境，比调整参数重要 100 倍
```

**记住**：
> **"策略是死的，市场是活的。活着最重要！"** 🏥

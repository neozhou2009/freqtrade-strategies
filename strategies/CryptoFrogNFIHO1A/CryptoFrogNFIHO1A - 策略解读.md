## 一、策略概览

**CryptoFrogNFIHO1A** 是 CryptoFrogNFI 的超参数优化版本（HO = HyperOpt），经过系统的超参数优化后确定了最优的买入/卖出条件开启/禁用组合。

该策略在 CryptoFrogNFI 的基础上，通过大量的回测和超参数优化，找到了最佳的 24 个买入条件和 8 个卖出条件的使用组合。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 24 个独立买入信号，已优化条件开关组合 |
| **卖出条件** | 8 个基础卖出信号 + 多层动态止盈逻辑 |
| **保护机制** | 隐式保护 + 自定义止损 + 动态 ROI |
| **时间框架** | 5 分钟主时间框架 + 1 小时信息时间框架 |
| **依赖库** | TA-Lib, finta (technical), cachetools, numpy, pandas |

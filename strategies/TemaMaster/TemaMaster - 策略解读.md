## 一、策略概览

TemaMaster 是一个基于三重指数移动平均线 (TEMA) 和布林带突破的趋势跟踪策略。策略核心思想是捕捉价格在布林带下轨附近的反转机会，并结合动量指标 (CMO) 进行过滤，同时利用追踪止损锁定大利润。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 1 个复合买入信号（TEMA 上穿 BB 下轨 + CMO 过滤） |
| **卖出条件** | 无主动卖出信号，依赖 ROI 和追踪止损 |
| **保护机制** | 追踪止损 + 仅盈利卖出 |
| **时间框架** | 5 分钟 (5m) |
| **依赖库** | talib, qtpylib |
| **信息对** | stake_currency/USDT (参考汇率) |

## 三、买入条件详解

### 3.1 保护机制

本策略主要依靠追踪止损和 ROI 退出，无传统买入保护参数。

### 3.2 买入条件详解

#### 条件 #1：TEMA 突破布林带下轨

```python
# 逻辑
- TEMA(18) 上穿布林带下轨
- CMO(14) > -5
```

**核心指标说明**：

| 指标 | 参数 | 用途 |
|------|------|------|
| TEMA (Triple EMA) | 周期 18 | 平滑价格趋势 |
| Bollinger Bands | 周期 26, 标准差 1.4 | 波动率通道 |
| CMO (Chande Momentum Oscillator) | 周期 14 | 动量过滤 |

**买入逻辑解读**：

1. **TEMA 上穿 BB 下轨**：价格从下方突破布林带下轨，可能意味着超卖反弹
2. **CMO > -5**：动量指标不过于负面，排除极端下跌情况

## 四、卖出逻辑详解

### 4.1 ROI 分级退出系统

策略采用多级 ROI 退出机制：

```
时间 (分钟)    最低收益率    说明
─────────────────────────────────────
0            20.937%      初始激进目标
238          6.449%       约 4 小时后降低期望
1931         1.703%       约 32 小时后进一步降低
3474         0%           约 58 小时后强制退出
```

**设计理念**：
- 开仓时追求高收益 (20%+)
- 随时间推移降低预期，避免长期套牢
- 约 2.5 天后强制退出，不留过夜风险

### 4.2 追踪止盈机制

| 参数 | 值 | 说明 |
|------|-----|------|
| trailing_stop_positive | 17.017% | 追踪距离 |
| trailing_stop_positive_offset | 26.713% | 启动阈值 |
| trailing_only_offset_is_reached | True | 仅达到阈值后启动 |

**工作原理**：
- 利润达到 26.713% 后，启动追踪止损
- 从最高点回撤超过 17% 时卖出
- 这意味着：即使涨到 +30%，跌到 +13% 才会触发卖出

### 4.3 卖出信号

```python
# 卖出条件：空（无主动卖出信号）
```

策略不依赖技术指标卖出，完全依靠 ROI 和追踪止损。

## 五、技术指标体系

### 5.1 核心指标

| 指标类别 | 具体指标 | 用途 |
|---------|---------|------|
| 趋势指标 | TEMA (Triple EMA) | 平滑价格，识别趋势方向 |
| 波动率指标 | Bollinger Bands | 判断超买超卖区域 |
| 动量指标 | CMO | 过滤极端动量情况 |
| 统计指标 | STDDEV, MA, COEFFV | 辅助计算波动率 |

### 5.2 指标计算详解

#### TEMA (三重指数移动平均线)

```python
TEMA = 3 * EMA - 3 * EMA(EMA) + EMA(EMA(EMA))
```

- 周期：18
- 特点：比普通 EMA 更平滑，延迟更低

#### Bollinger Bands (布林带)

```python
中轨 = SMA(26)
上轨 = 中轨 + 1.4 × 标准差
下轨 = 中轨 - 1.4 × 标准差
```

- 周期：26
- 标准差倍数：1.4（比默认 2 更窄）

#### CMO (钱德动量摆动指标)

```python
CMO = 100 × (上涨日总和 - 下跌日总和) / (上涨日总和 + 下跌日总和)
```

- 周期：14
- 范围：-100 到 +100

| 阶段 | 时间范围 | 目标收益 | 风险偏好 |

| 保守期 | 1931-3474 分钟 | 1.703% | 低风险 |

| 未达阈值 | 利润 < 26.713% | 仅靠 ROI 或止损 |

## 七、策略优势与局限

### ✅ 优势

1. **追踪止盈设计**：让利润奔跑，适合捕捉大趋势
2. **多指标组合**：TEMA + BB + CMO 三重过滤
3. **分级 ROI**：平衡收益预期与持仓时间
4. **信息对配置**：支持参考汇率信息

### ⚠️ 局限

1. **无主动卖出**：完全依赖 ROI 和追踪止损
2. **参数激进**：初始 ROI 目标 20%+，可能难以达成
3. **追踪止损阈值高**：26.7% 才启动，可能错过中等涨幅
4. **宽止损**：-14.8% 止损较宽，单笔亏损可能较大

## 十、重要提醒：激进策略的风险

### 10.1 追踪止盈的双刃剑

追踪止盈设计在高收益预期下很美好，但：

- **高阈值问题**：26.7% 才启动追踪，中等涨幅无法保护
- **宽回撤空间**：17% 回撤空间，可能从高点回落很多

### 10.2 ROI 参数的激进性

| ROI 阶段 | 目标 | 问题 |
|---------|------|------|
| 初始 | 20.937% | 加密货币一天 20% 不常见 |
| 4 小时后 | 6.449% | 相对合理 |
| 32 小时后 | 1.703% | 可能太低 |

### 10.3 硬件要求

| 交易对数量 | 最低内存 | 推荐内存 |
|-----------|---------|---------|
| 1-10 对 | 2GB | 4GB |
| 10-50 对 | 4GB | 8GB |

策略计算量中等，需要适当硬件支持。

### 10.4 回测与实盘的差异

激进参数在回测中可能表现很好（因为选择了最优参数），但实盘中：

- **高 ROI 目标难以达成**：20% 涨幅不是常有
- **追踪止盈可能用不上**：大多数交易达不到 26.7%

## 二、核心配置：说白了就是"参数自己调，敢赌敢亏"

### 止盈规则（ROI 表）

```
持仓 0-33 分钟：赚 27% 就跑
持仓 33-64 分钟：赚 8.5% 就跑
持仓 64-244 分钟：赚 4.1% 就跑
持仓 244 分钟后：不赚钱也跑
```

**翻译**：比 SwingHigh 更激进！上来就想赚 27%，比原来 16% 还贪心。不过持仓时间也更长，最长 4 小时。

### 止损规则

```
硬止损：-34.34%（亏这么多直接砍）
追踪止损：没有！这策略居然没追踪止损！
```

**翻译**：止损空间给得更大了，-34% 呢！但居然没追踪止损，这点不如 SwingHigh。赚钱了得自己盯着点。

## 三、参数优化：这策略的"黑科技"

### 3.1 Hyperopt 是个啥？

简单说，Hyperopt 就是让电脑帮你找最优参数。

**大白话**：
> "你告诉我哪些参数可以调、范围是多少，我来跑几百次回测，找出最赚钱的组合。"

### 3.2 可优化的参数

| 参数 | 范围 | 优化后的值 |
|------|------|-----------|
| CCI 买入阈值 | -200 ~ 200 | -175 |
| CCI 买入周期 | 10 ~ 80 | 72 |
| RSI 买入阈值 | 10 ~ 90 | 90 |
| RSI 买入周期 | 10 ~ 80 | 36 |
| CCI 卖出阈值 | -200 ~ 200 | -106 |
| CCI 卖出周期 | 10 ~ 80 | 66 |
| RSI 卖出阈值 | 10 ~ 90 | 88 |
| RSI 卖出周期 | 10 ~ 80 | 45 |

**吐槽**：8 个参数全都能优化！这是把选择困难症交给了电脑 😅

## 四、1 个买入条件：CCI 跌狠了就买

### 🎯 唯一买入条件：CCI 超卖 + RSI 确认

**核心逻辑**：
- CCI(72) < -175（超卖）
- RSI(36) < 90（动量确认）

**大白话**：
> "CCI 用 72 周期看超卖，跌到 -175 以下就买。RSI 用 36 周期确认一下。"

**代码长这样**：
```python
(dataframe[f'cci-{self.buy_cciTime.value}'] < self.buy_cci.value) &
(dataframe[f'rsi-{self.buy_rsiTime.value}'] < self.buy_rsi.value)
```

**吐槽**：RSI < 90 这个条件...正常 RSI 就在 0-100 之间，< 90 几乎总是成立。所以实际上就是看 CCI！这 RSI 是来凑数的吗？🤔

---

## 五、1 个卖出条件：CCI 回升就走

### 📉 唯一卖出条件：CCI 回升 + RSI 超买

**核心逻辑**：
- CCI(66) > -106（注意是负值！）
- RSI(45) > 88（接近超买）

**大白话**：
> "CCI 从 -175 回升到 -106 就卖。RSI 超过 88 也确认卖。"

**代码长这样**：
```python
(dataframe[f'cci-sell-{self.sell_cciTime.value}'] > self.sell_cci.value) &
(dataframe[f'rsi-sell-{self.sell_rsiTime.value}'] > self.sell_rsi.value)
```

**注意**：卖出阈值是 -106，还是负数！正常 CCI 超买是 > 100，这里用负值...可能是 Hyperopt 优化出来的"特殊解"。

**对比一下**：
- 买入：CCI < -175
- 卖出：CCI > -106
- 差距只有 69 点！买卖点很接近。

```bash
# 优化买入参数
freqtrade hyperopt --hyperopt-loss SharpeHyperOptLoss --spaces buy --strategy SwingHighToSky

# 优化卖出参数
freqtrade hyperopt --hyperopt-loss SharpeHyperOptLoss --spaces sell --strategy SwingHighToSky

```

**注意**：优化完记得把新参数写进策略文件！

### 10.2 硬件要求

| 交易对数量 | 最低内存 | 推荐内存 | 体验 |
|-----------|---------|---------|------|
| 1-10 对 | 2GB | 4GB | 丝滑 |
| 10-50 对 | 4GB | 8GB | 流畅 |
| 50+ 对 | 8GB | 16GB | Hyperopt 时可能会慢 |

**Hyperopt 注意**：优化参数时计算量大，建议用高性能机器。

### 10.3 回测 vs 实盘

**回测注意**：
- Hyperopt 可能过度拟合历史数据
- 建议用不同时间段数据验证
- 不要只用最近的数据优化

**建议流程**：
1. 用 180 天数据做 Hyperopt
2. 用另外 90 天数据验证参数
3. 模拟盘跑 1 个月
4. 确认稳定后再上实盘

**别一上来就用"最优参数"实盘**，可能只是过拟合！

## 十三、⚠️ 风险再强调（这段一定要看）

### Hyperopt 优化的陷阱

SwingHighToSky 最大的风险就是**过拟合**：

> **历史最优 ≠ 未来最优。你找的是过去最赚钱的参数，但市场在变。**

简单说就是：**"考试成绩好不代表工作能力强。"**

### 过拟合的表现

如果你发现：
- 回测收益率爆表
- 实盘表现差很多
- 参数值特别"奇怪"（比如 RSI < 90）

那就可能是过拟合了。

### 没追踪止损的风险

这个策略**没有追踪止损**！这意味着：
- 赚了钱没人帮你锁
- 回撤可能很大
- 需要自己设手动止盈

### 我的建议（真心话）

```
1. Hyperopt 用多时间段验证，别只看一个时期
2. 参数太"奇怪"的要警惕
3. 自己加个追踪止损配置
4. 轻仓测试，别上来就梭哈
5. 定期重新优化参数
```

**记住**：参数优化是双刃剑，用好了能适应市场，用不好就是过拟合。活着最重要！🙏

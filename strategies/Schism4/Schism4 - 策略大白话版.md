# Schism4 策略：动量派的"双确认狙击手"

> **外号**：双确认狙击手、趋势跟随者  
> **职业**：多时间框架动量交易专家  
> **时间框架**：5分钟做决策，1小时看大势

---

## 一、这策略是个啥？

简单说，**Schism4** 就是一个：
- 先看大趋势（1小时RSI），再找入场点（5分钟RMI）
- 买入条件严格，卖出靠ROI自动止盈
- 专门给BTC/ETH质押币做了额外优化
- 有持仓信号的"续命机制"，趋势好的时候多拿一会儿

就像一个**狙击手**：先在高处观察敌情（1小时趋势），等目标进入最佳射程（5分钟动量），再开枪 🎯

---

## 二、核心配置：说白了就是"渐进止盈+宽松止损"

### 止盈规则（ROI 表）

```
时间        目标利润
─────────────────────
0 分钟       5%       刚买入就要 5%，胃口大
10 分钟      2.5%     10分钟后降门槛
20 分钟      1.5%     20分钟后继续降
30 分钟      1%       半小时后要求更低
12 小时      0.5%     半天后能赚点就行
24 小时      0%       一天后免费退出
```

**翻译**：这策略挺"贪心"的，刚买入就要5%利润。但如果你拿得久，它也会慢慢妥协——12小时后赚0.5%就卖，24小时后免费送你出局。

### 止损规则

```
固定止损：-30%
动态止损：亏损时才触发，随时间变化
```

**翻译**：止损位在-30%，但策略有个"动态止损"机制，在还没亏到-30%之前，如果趋势变坏，会提前止损。

## 三、5个买入条件：我帮你分类好了

这策略的买入条件有点复杂，我给你归了3类：

### 🎯 第1类：趋势确认条件（3个）

**核心逻辑**：确认大趋势向上，动量足够

**大白话**：
> "我只有在确认趋势向上、而且动量到位的时候才会买入"

**代表条件**：
- **1小时 RSI ≤ 58**：大周期没过热，还有上涨空间
- **RMI 上升趋势**：慢速RMI连续3根K线有2根上涨
- **慢速 RMI ≤ 55**：动量没到天花板

### ⚡ 第2类：动量入场条件（2个）

**核心逻辑**：找到具体入场点

**大白话**：
> "趋势确认后，我要等动量指标给出信号"

**代表条件**：
- **快速 RMI ≥ 11**：短期动量开始起来
- **Momentum Pinball ≥ 26**：ROC算出来的动量强度达标

### 💰 第3类：BTC/ETH专属条件（2个，质押币专用）

**核心逻辑**：如果你用BTC或ETH做质押币，还要检查大盘状态

**大白话**：
> "兄弟，你用BTC做本钱，那我还得看看BTC自己争不争气"

**代表条件**：
- **质押币RSI < 90 或 法币RSI > 64**：BTC没过热，或者汇率有利
- **质押币1小时RMI < 25**：大周期动量还没爆发

## 四、保护机制：3道"防火墙"

每个买入条件都配了一套保护机制，就像给交易装了三道防火墙：

| 保护类型 | 作用 | 大白话 |
|---------|------|--------|
| 入场确认 | 价格波动 >1% 就取消 | "你涨太快了，我不追" |
| 买入超时 | 订单挂太久自动取消 | "等太久不成交，撤了吧" |
| 卖出超时 | 价格跌太多取消卖出单 | "价格跌太快，我重新挂单" |

这机制有点像一个**挑剔的买家**：价格合适才买，涨太快就不追了 🧐

## 五、卖出逻辑：比买入更聪明

### 5.1 分级止盈：赚多少跑

这策略的卖出信号**只作为动态止损**使用，真正的止盈靠ROI表。

**大白话**：
- 刚买完想赚5%
- 10分钟后降到2.5%
- 一直降到24小时后"能出来就行"

### 5.2 动态止损：亏多少撤

```
持仓时间      亏损容忍度
─────────────────────────
0 分钟        -3%       刚买可以稍微亏点
150 分钟      -1.5%     中间过渡
300 分钟      0%        5小时后不赚就跑
```

**大白话**：
> "兄弟，我刚买可以让你亏3%，但5小时后你还亏钱，我就不陪你玩了"

### 5.3 特殊场景退出

| 场景 | 触发条件 | 大白话 |
|------|---------|--------|
| 曾盈利但未达ROI | RMI下穿50 | "本来赚过的，先出来保本" |
| 始终亏损 | RMI下穿10 | "这波判断错了，止损吧" |

### 5.4 仓位管理卖出

这是这策略最聪明的地方：

**大白话**：
> "如果我还有很多空闲仓位，我就要求更严格的卖出条件；如果仓位满了，我就让最大的那个输家先出来"

具体算法：
- 1个空闲仓位：平均利润 >= -4% 才能卖
- 4个空闲仓位：平均利润 >= -1% 才能卖
- 0个空闲仓位：最大的输家无条件退出

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **双重确认**：5分钟+1小时，不容易被骗线
2. **动态参数**：止损阈值随时间变化，越等越急
3. **仓位联动**：卖出时考虑其他仓位的盈亏，整体观念好
4. **质押币适配**：专门为BTC/ETH质押优化
5. **持仓续命**：趋势好时忽略ROI继续持有

### ⚠️ 缺点（吐槽环节）

1. **参数太多**：7个买入参数+2个卖出参数，调参要疯了 🤯
2. **ROI太贪心**：刚买入就要求5%，可能错过很多机会
3. **止损太大**：-30%的硬止损，对保守派来说是"肉疼"
4. **回测不准**：大量用实时数据，回测结果别太信

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

Schism4 的历史回测表现可能**很不错**——但这有个陷阱：

> **因为这策略有7个买入参数+2个卖出参数，很容易"拟合"过去行情的最优解，但这并不代表未来一定能盈利。**

简单说就是：**"背答案"考高分，不代表真懂了**

### 复杂策略的隐藏风险

实盘时，复杂的逻辑可能导致：
- **数据库查询延迟**：实时查询持仓可能拖慢交易
- **参数敏感**：一个参数调错，整体效果崩盘
- **极端行情失灵**：黑天鹅事件可能让所有指标失效

### 我的建议（真心话）

```
1. 先用纸盘跑至少2周，观察实际表现
2. ROI目标可以适当降低，5%有点贪
3. 止损可以考虑调小到-25%
4. 每天检查持仓情况，了解策略行为
```

**记住**：策略再好，市场教做人时也不会打招呼。轻仓测试，活着最重要！🙏

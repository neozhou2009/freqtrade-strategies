## 一、策略概览

**EMAVolume** 是一个基于 EMA 交叉和成交量确认的趋势跟踪策略，由 Gert Wohlgemuth 开发。策略使用双 EMA 交叉（13/34）生成买卖信号，并通过成交量过滤来确认信号有效性。策略特色是逻辑简洁，适合学习 EMA 交叉策略。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 1 个条件：EMA 金叉 + 成交量确认 |
| **卖出条件** | 1 个条件：EMA 死叉 |
| **保护机制** | 硬止损 |
| **时间框架** | 15 分钟 |
| **依赖库** | TA-Lib, technical |
| **特殊功能** | 成交量过滤 |

## 三、买入条件详解

### 3.1 买入逻辑

```python
# 买入条件
dataframe.loc[
    (
        (qtpylib.crossed_above(dataframe["ema13"], dataframe["ema34"])) &  # EMA13 上穿 EMA34
        (dataframe["volume"] > dataframe["volume"].rolling(window=10).mean())  # 成交量 > 10 周期均量
    ),
    "buy",
] = 1
```

**逻辑解析**：
- **EMA 金叉**：EMA13 上穿 EMA34，确认短期趋势转强
- **成交量确认**：成交量大于 10 周期均量，确认信号有效性

### 3.2 指标计算

```python
# EMA
dataframe["ema13"] = ta.EMA(dataframe, timeperiod=13)
dataframe["ema34"] = ta.EMA(dataframe, timeperiod=34)
dataframe["ema7"] = ta.EMA(dataframe, timeperiod=7)
dataframe["ema21"] = ta.EMA(dataframe, timeperiod=21)
dataframe["ema50"] = ta.EMA(dataframe, timeperiod=50)
dataframe["ema200"] = ta.EMA(dataframe, timeperiod=200)

# 成交量移动平均
dataframe["volume_mean"] = dataframe["volume"].rolling(window=10).mean()
```

## 四、卖出逻辑详解

### 4.1 卖出条件

```python
# 卖出条件
dataframe.loc[
    (qtpylib.crossed_below(dataframe["ema13"], dataframe["ema34"])),  # EMA13 下穿 EMA34

```

**逻辑解析**：
- **EMA 死叉**：EMA13 下穿 EMA34，确认短期趋势转弱

## 七、策略优势与局限

### ✅ 优势

1. **逻辑简洁**：EMA 交叉 + 成交量，易于理解
2. **成交量过滤**：排除低成交量假信号
3. **高 ROI**：50% ROI，预期捕捉大趋势
4. **计算量小**：指标少，对硬件要求低
5. **学习价值高**：适合学习 EMA 交叉策略

### ⚠️ 局限

1. **无趋势过滤**：没有长期趋势判断（如 EMA200）
2. **无 BTC 关联**：不检测比特币大盘趋势
3. **高 ROI**：50% ROI 可能过早退出
4. **15 分钟框架**：信号频率较低
5. **多层 EMA 未使用**：计算了多层 EMA 但仅使用 13/34

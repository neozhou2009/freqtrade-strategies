## 一、策略概览

NostalgiaForInfinityV7_SMA 是 NostalgiaForInfinity 系列的一个重要变体，在原有 V7 版本基础上强化了 SMA（简单移动平均线）相关的趋势判断和保护机制。该策略由 iterativ 团队开发，是 Freqtrade 量化交易框架中最受欢迎的策略系列之一，以其复杂的条件体系和精细的风险控制著称。

策略名称中的"SMA"强调了其对简单移动平均线的特殊依赖——不同于其他版本偏重 EMA，本策略在趋势判断和买入保护中大量使用 SMA200 作为核心参考基准，配合 EMA 快慢线构建多层次的入场过滤网。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 26 个独立买入信号（条件 #1-#26，#25 缺失），均可独立启用/禁用 |
| **卖出条件** | 8 个基础卖出信号 + custom_sell 中的多层动态止盈系统 |
| **保护机制** | 每个买入条件配 7-10 组独立保护参数（EMA、SMA、安全回撤、安全拉升等） |
| **时间框架** | 主时间框架 5m，信息时间框架 1h |
| **依赖库** | freqtrade.vendor.qtpylib.indicators, numpy, talib.abstract, pandas, functools.reduce, datetime, timedelta, technical.indicators.zema |
| **启动蜡烛数** | 400 根（需要足够历史数据计算所有指标） |

## 三、买入条件详解

### 3.1 保护机制架构（26 组）

每个买入条件都配有独立的保护参数组，这是 NostalgiaForInfinity 系列的核心特色。策略通过 `CategoricalParameter` 定义了可配置的保护开关：

| 保护类型 | 参数名 | 说明 | 默认值示例 |
|---------|--------|------|-----------|
| EMA 快线判断 | `ema_fast` | EMA 快线是否高于 EMA200 | True/False |
| EMA 快线周期 | `ema_fast_len` | 快线周期选择 | 26/50/100/200 |
| EMA 慢线判断 | `ema_slow` | 1h EMA 慢线是否高于 EMA200 | True/False |
| EMA 慢线周期 | `ema_slow_len` | 慢线周期选择 | 26/50/100/200 |
| 收盘价在 EMA 快线上方 | `close_above_ema_fast` | 收盘价 > 指定 EMA | True/False |
| 收盘价在 EMA 慢线上方 | `close_above_ema_slow` | 收盘价 > 指定 1h EMA | True/False |
| SMA200 上升 | `sma200_rising` | SMA200 是否比 N 根前高 | True/False |
| SMA200 上升周期 | `sma200_rising_val` | 比较周期 | 20/30/36/44/50 |
| 1h SMA200 上升 | `sma200_1h_rising` | 1h SMA200 是否上升 | True/False |
| 安全回撤 | `safe_dips` | 是否启用安全回撤检测 | True/False |
| 安全回撤等级 | `safe_dips_type` | 回撤检测严格程度 | 10/50/80/100 |
| 安全拉升 | `safe_pump` | 是否启用安全拉升检测 | True/False |
| 安全拉升等级 | `safe_pump_type` | 拉升检测严格程度 | 10/50/100/120 |
| 安全拉升周期 | `safe_pump_period` | 拉升检测时间窗口 | 24/36/48 小时 |

### 3.2 安全回撤机制（Safe Dips）

策略定义了 11 个等级的安全回撤检测参数，用于判断当前价格是否处于"安全"的回撤位置：

```python
# 回撤检测阈值示例（等级 50）
buy_dip_threshold_50_1 = 0.02   # 0 周期顶部变化阈值
buy_dip_threshold_50_2 = 0.14   # 2 周期顶部变化阈值
buy_dip_threshold_50_3 = 0.32   # 12 周期顶部变化阈值
buy_dip_threshold_50_4 = 0.50   # 144 周期顶部变化阈值
```

**核心逻辑**：通过计算多个时间周期的"顶部百分比变化"（top_percent_change），判断价格从区间顶部的回落程度，避免在过度追高时入场。

### 3.3 安全拉升机制（Safe Pump）

策略对"拉升后入场"场景进行了精细控制，通过 12 个等级（10-120）和 3 个时间窗口（24h/36h/48h）的组合，构建了 36 套拉升检测参数：

```python
# 拉升检测示例（等级 50，48h 窗口）
buy_pump_pull_threshold_50_48 = 1.75  # 回撤调整阈值
buy_pump_threshold_50_48 = 0.85       # 拉升幅度阈值
```

**核心逻辑**：`safe_pump()` 方法判断价格在经历大幅拉升后是否已经"冷却"——要么拉升幅度不大（低于阈值），要么已经有足够的回调空间。

### 3.4 典型买入条件示例

## 四、卖出逻辑详解

### 4.1 多层止盈系统（custom_sell）

策略的核心退出机制在 `custom_sell()` 方法中实现，采用分层的动态止盈系统，根据不同利润区间和 RSI 状态触发退出：

**常规止盈表**：

```
利润率区间           RSI 阈值    信号名称
──────────────────────────────────────────
> 20%               < 34       signal_profit_11
10%-12%             < 42       signal_profit_10
9%-10%              < 55       signal_profit_9
8%-9%               < 54       signal_profit_8
7%-8%               < 48       signal_profit_7
6%-7%               < 45       signal_profit_6
5%-6%               < 43       signal_profit_5
4%-5%               < 42       signal_profit_4
3%-4%               < 37       signal_profit_3
2%-3%               < 35       signal_profit_2
1%-2%               < 34       signal_profit_1
0.1%-1%             < 34       signal_profit_0
```

**设计理念**：利润越高，对 RSI 的要求越宽松——大利润时只要 RSI 不太极端就退出，小利润时需要更明确的超卖信号才持有。

### 4.2 EMA200 下方特殊止盈

当收盘价低于 EMA200 时，策略启动另一套止盈参数：

```python
# EMA200 下方止盈示例
sell_custom_under_profit_11 = 0.20  # 20% 利润
sell_custom_under_rsi_11 = 34       # RSI < 34 触发
```

**逻辑**：在均线压力下，更积极地锁定利润，避免反弹失败。

### 4.3 拉升后止盈（Pump Sell）

策略检测 24h/36h/48h 内的价格涨幅，对"拉升"品种采用更宽松的止盈策略：

```python
# 48h 拉升检测阈值
sell_pump_threshold_48_1 = 0.90  # 48h 内涨幅 > 90%
sell_pump_threshold_48_2 = 0.70  # 48h 内涨幅 > 70%
sell_pump_threshold_48_3 = 0.50  # 48h 内涨幅 > 50%
```

**对应止盈逻辑**：如果品种在 48h 内涨幅超过 90%，则使用 `signal_profit_p_1_*` 系列信号退出。

### 4.4 追踪止盈（Trailing Profit）

策略内置三套追踪止盈逻辑：

| 追踪组 | 利润区间 | RSI 区间 | 回撤阈值 |
|-------|---------|---------|---------|
| Trail 1 | 16%-60% | 20-50 | 3% |
| Trail 2 | 10%-40% | 20-50 | 3% |
| Trail 3 | 6%-20% | - | 5% |

**触发条件**：当前利润低于最高利润超过阈值时退出。

### 4.5 恢复性退出（Recovery Exit）

针对曾经亏损但已回本的交易：

```python
# 恢复退出 1
sell_custom_recover_profit_1 = 0.04
sell_custom_recover_min_loss_1 = 0.12  # 曾经亏损 > 12%

# 恢复退出 2
sell_custom_recover_profit_min_2 = 0.01
sell_custom_recover_profit_max_2 = 0.05
sell_custom_recover_min_loss_2 = 0.06
sell_custom_recover_rsi_2 = 46
```

**逻辑**：曾经深度亏损的持仓，在回本到一定程度时主动退出，避免二次深套。

### 4.6 长持仓退出

```python
sell_custom_long_profit_min_1 = 0.03
sell_custom_long_profit_max_1 = 0.04
sell_custom_long_duration_min_1 = 900  # 持仓 > 900 分钟（15 小时）
```

**逻辑**：持仓时间过长且有微利时，主动退出释放资金。

## 六、风险管理特色

### 6.1 分层买入保护

策略的买入保护机制是其最大特色。每个买入条件都可以独立配置以下保护：

| 保护层级 | 保护类型 | 风险规避 |
|---------|---------|---------|
| 第 1 层 | EMA 趋势 | 避免逆势交易 |
| 第 2 层 | SMA200 方向 | 避免在下跌趋势中抄底 |
| 第 3 层 | 安全回撤 | 避免追高 |
| 第 4 层 | 安全拉升 | 避免在暴涨后接盘 |
| 第 5 层 | 收盘价位置 | 确保价格在合理区间 |

### 6.2 动态止盈系统

**层级设计**：

1. **基础层**：ROI 表 + 固定止损
2. **动态层**：custom_sell 分层止盈（12 层常规 + 12 层 EMA200 下方）
3. **场景层**：拉升后止盈、追踪止盈
4. **恢复层**：亏损恢复后主动退出
5. **时间层**：长持仓微利退出

### 6.3 多维度风险控制

```python
# 保护参数示例（条件 #14）
buy_14_protection__ema_fast = True           # EMA50 > EMA200
buy_14_protection__ema_slow = True           # EMA50_1h > EMA200_1h
buy_14_protection__sma200_rising = True      # SMA20 上升（30 周期）
buy_14_protection__sma200_1h_rising = True   # SMA200_1h 上升（50 周期）
buy_14_protection__safe_dips = True          # 安全回撤等级 10
buy_14_protection__safe_pump = True          # 安全拉升等级 70（24h）
```

## 七、策略优势与局限

### ✅ 优势

1. **极强的适应性**：26 个买入条件覆盖了趋势跟踪、均值回归、突破、反转等多种市场形态，理论上可以适应各种行情。

2. **精细的风险控制**：分层止盈 + 多重买入保护，在入场和出场两端都有完善的防御机制。

3. **可定制性强**：每个条件都可独立启用/禁用，保护参数可独立配置，方便针对特定市场优化。

4. **双时间框架验证**：1h 信息层提供了更高维度的趋势确认，减少假信号。

5. **社区验证**：NostalgiaForInfinity 系列经过多年社区实盘检验，参数经过大量优化。

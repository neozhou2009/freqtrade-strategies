## 一、策略概览

SMAOffsetProtectOptV1 是一个基于**EMA偏移策略**的量化交易策略，通过价格相对移动平均线的偏移位置来识别买入和卖出时机，并使用**Elliott Wave Oscillator (EWO)** 作为保护机制，配合 RSI 过滤假信号。策略名称中的 "Protect" 强调了其多层保护机制，"OptV1" 表示优化版本 1。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 2 个独立买入信号，可灵活切换 |
| **卖出条件** | 1 个基础卖出信号 + ROI表止盈 + 追踪止损 |
| **保护机制** | EWO趋势保护 + RSI超买过滤 |
| **时间框架** | 主框架 5m + 信息框架 1h |
| **依赖库** | talib, numpy, pandas, technical, qtpylib |

## 二、策略配置解析

### 2.1 基础风险参数

```python
# ROI 退出表
minimal_roi = {
    "0": 0.01  # 立即达到 1% 利润即退出
}

# 止损设置
stoploss = -0.10  # 10% 固定止损

# 追踪止损
trailing_stop = True
trailing_stop_positive = 0.001   # 正向追踪阈值 0.1%
trailing_stop_positive_offset = 0.01  # 偏移量 1%
trailing_only_offset_is_reached = True  # 仅在达到偏移后启用追踪
```

**设计思路**：
- ROI 设置为立即 1%，结合 `ignore_roi_if_buy_signal=True`，策略在有买入信号时会忽略 ROI，让利润奔跑
- 追踪止损设置较为激进（0.1%），能够快速锁定利润
- 10% 的固定止损提供了较大的容错空间

### 2.2 订单类型配置

```python
use_sell_signal = True
sell_profit_only = True
sell_profit_offset = 0.01
ignore_roi_if_buy_signal = True
```

**关键设置**：
- `sell_profit_only=True`：仅在盈利时响应卖出信号
- `ignore_roi_if_buy_signal=True`：**核心差异化设置**，当存在买入信号时忽略 ROI 限制，允许策略继续持有

## 三、买入条件详解

### 3.1 保护机制（2 组）

策略名称中的 "Protect" 体现在 **EWO（Elliott Wave Oscillator）** 保护机制上：

| 保护类型 | 参数说明 | 默认值 |
|---------|---------|--------|
| **EWO 高阈值** | 当 EWO > ewo_high 时认为是上升趋势回调 | 5.638 |
| **EWO 低阈值** | 当 EWO < ewo_low 时认为是深度超卖 | -19.993 |
| **RSI 过滤** | RSI < rsi_buy 防止追高 | 61 |

**EWO 计算**：
```python
def EWO(dataframe, ema_length=5, ema2_length=35):
    ema1 = ta.EMA(df, timeperiod=ema_length)
    ema2 = ta.EMA(df, timeperiod=ema2_length)
    emadif = (ema1 - ema2) / df['close'] * 100
    return emadif
```

策略使用自定义 EWO 参数：`fast_ewo=50`, `slow_ewo=200`（注意这是策略内定义的特殊参数，与计算函数的默认值不同）。

### 3.2 典型买入条件示例

#### 条件 #1：趋势回调买入
```python
# 逻辑
- 价格 < EMA(base_nb_candles_buy) * low_offset  # 价格低于偏移后的均线
- EWO > ewo_high  # 上升趋势确认
- RSI < rsi_buy  # 未超买
- volume > 0  # 有成交量
```

**解读**：这是一个"上升趋势回调买入"策略。当价格回调到均线下方一定比例（低偏移），同时 EWO 显示上升趋势（> 5.638），且 RSI 未过热（< 61），则认为是良好的买入时机。

#### 条件 #2：深度超卖买入
```python
# 逻辑
- 价格 < EMA(base_nb_candles_buy) * low_offset  # 价格低于偏移后的均线
- EWO < ewo_low  # 深度超卖
- volume > 0  # 有成交量
```

**解读**：这是一个"超跌反弹"策略。当价格低于偏移均线，同时 EWO 显示极度超卖（< -19.993），不考虑 RSI，直接买入博反弹。

### 3.3 2 个买入条件分类

| 条件组 | 条件编号 | 核心逻辑 |
|-------|---------|---------|
| 趋势回调类 | 条件 #1 | EWO高阈值 + RSI过滤，捕捉上升趋势中的回调机会 |
| 超跌反弹类 | 条件 #2 | EWO低阈值，捕捉极端超卖后的反弹机会 |

## 四、卖出逻辑详解

### 4.1 单层止盈系统

策略采用**单一ROI阈值 + 追踪止损**机制：

```
利润率区间      阈值       信号名称
──────────────────────────────────
立即            1%         minimal_roi
追踪止损        0.1%       trailing_stop_positive
```

### 4.2 特殊卖出场景

| 场景 | 触发条件 | 信号名称 |
|------|---------|---------|
| 均线偏离卖出 | close > EMA(base_nb_candles_sell) * high_offset | 卖出信号 |
| 盈利保护 | 利润 > 1% + 有买入信号存在 | 忽略ROI |

**核心设计**：`ignore_roi_if_buy_signal=True` 是该策略的独特设计。当市场仍然存在买入信号时，即使达到 1% 的 ROI 阈值，策略也会继续持有，让利润奔跑。

### 4.3 基础卖出信号（1 个）

```python
# 卖出信号 1: 均线偏离卖出
- close > EMA(base_nb_candles_sell) * high_offset  # 价格高于偏移后的均线
- volume > 0  # 有成交量
```

**参数默认值**：
- `base_nb_candles_sell = 49`（EMA 周期）
- `high_offset = 1.006`（高偏移系数）

**解读**：当价格上涨超过 49 周期 EMA 的 0.6% 时触发卖出信号。

## 六、风险管理特色

### 6.1 多层止损保护

策略采用**三层止损机制**：

1. **固定止损**：-10% 硬止损，防止极端亏损
2. **追踪止损**：盈利 1% 后启用 0.1% 追踪，快速锁定利润
3. **信号止损**：卖出信号触发时退出

### 6.2 买入信号保护

`ignore_roi_if_buy_signal=True` 的设计理念：
- 避免在强势趋势中过早离场
- 让盈利头寸有更大空间奔跑
- 仅在趋势反转时（卖出信号）退出

### 6.3 RSI 过滤机制

RSI < 61 的条件防止在以下情况买入：
- 价格已大幅上涨后的追高
- 短期过热的风险位置

## 七、策略优势与局限

### ✅ 优势

1. **参数可优化性强**：7 个可优化参数，适应不同市场环境
2. **双层买入逻辑**：既捕捉趋势回调，也捕捉超跌反弹
3. **利润保护机制**：`ignore_roi_if_buy_signal` 让盈利头寸更充分
4. **代码简洁高效**：逻辑清晰，计算量适中

### ⚠️ 局限

1. **单一时间框架决策**：虽有 1h 信息层，但实际决策主要基于 5m
2. **震荡市场风险**：EMA 偏移策略在横盘市场容易频繁止损
3. **无波动率过滤**：未使用 ATR 等波动率指标，可能在高波动时误判

### 10.3 回测与实盘的差异

EMA 偏移策略在回测中容易产生**过拟合**，因为：
- EMA 周期参数可以完美匹配历史数据
- 偏移系数可以精确调整到最优
- 实盘中市场结构变化会导致参数失效

### 10.4 手动交易者建议

如果想手动应用此策略的逻辑：
1. 使用 16 周期 EMA 作为动态支撑线
2. 当价格低于 EMA 的 2.2% 左右时关注
3. 确认 EWO 为正值（趋势向上）
4. RSI 低于 61 时考虑入场
5. 价格回到 EMA 上方 0.6% 时考虑离场

# SMAOffsetProtectOptV1 策略：均线偏离保护策略

> **外号**："抄底小能手"、"均线两侧的猎手"  
> **职业**：专门在均线附近捡漏的量化猎人  
> **时间框架**：5分钟（短跑选手）

---

## 一、这策略是个啥？

简单说，**SMAOffsetProtectOptV1** 就是一个：
- 在价格偏离均线太远时买入的"抄底"策略
- 用 Elliott Wave 指标确认趋势方向
- 配合 RSI 防止追高
- 有个特别的设计：只要有买入信号就忽略 ROI 限制，让利润奔跑

就像 **在菜市场收摊前去捡漏** —— 专门等价格被打压到均线以下一定比例时，再去"捡便宜" 🛒

## 二、核心配置：说白了就是"见好就收+贪心模式"

### 止盈规则（ROI 表）

```
时间      利润目标
──────────────────
0分钟      1%
```

**翻译**：这策略有点"贪"，默认设置是赚到 1% 就跑... 

**但是！** 有个反人类设计：`ignore_roi_if_buy_signal=True`

> "只要市场还有买入信号，老子就不跑！让利润飞一会儿！"

这就像你本来打算赚 1 块就收手，结果发现还能继续赚，干脆让子弹再飞一会儿 🚀

### 止损规则

```
固定止损：-10%
追踪止损：盈利 1% 后启用，追踪 0.1%
```

**翻译**：
- **固定止损**：亏 10% 认赔，不多废话
- **追踪止损**：一旦开始赚钱，就用 0.1% 的"粘性"跟着价格走，锁定利润

## 三、2 个买入条件：我帮你分类好了

这策略的买入条件其实很简洁，就 2 个，但各有千秋：

### 🎯 第 1 类：趋势回调买入（条件 #1）
**核心逻辑**：价格回调到均线下方 + 趋势仍然向上 + 没追高

**大白话**：
> "均线是爸爸，价格是儿子。儿子离家出走了（价格低于均线），但爸爸还健康（EWO 为正），而且儿子没发烧（RSI 不高），这时候去把儿子找回来！"

**代码翻译**：
```python
close < EMA * 0.978  # 价格比均线低 2.2% 左右
AND EWO > 5.638      # 趋势向上（EWO 为正且较高）
AND RSI < 61         # 没过热
```

---

### 🎯 第 2 类：深度超卖买入（条件 #2）
**核心逻辑**：价格暴跌 + EWO 极度负值 = 超跌反弹机会

**大白话**：
> "价格被打压得太惨了，EWO 都跌到 -20 了，这时候去捡尸体！不需要看 RSI，干就完了！"

**代码翻译**：
```python
close < EMA * 0.978  # 价格比均线低 2.2% 左右
AND EWO < -19.993    # 极度超卖
```

**吐槽**：这条件 #2 简直是"抄底狂魔"专用，专门在暴跌时进场博反弹，风险较大但潜在收益也高 🎰

## 四、保护机制：2 层"防坑网"

每个买入条件都配有保护参数，就像 **过安检要过两道门**：

| 保护类型 | 作用 | 大白话 |
|---------|------|--------|
| EWO 阈值 | 判断趋势强度 | "这波下跌是真崩还是假摔？" |
| RSI 过滤 | 防止追高 | "别在山顶站岗！" |

**EWO 是个啥？** 全称 Elliott Wave Oscillator（艾略特波浪震荡指标），其实就是**快 EMA 和慢 EMA 的差值**。这个策略用了 50 和 200 周期的 EMA 来算 EWO，非常"长远视角"。

> 正值 = 快线在慢线上面 = 短期比长期强 = 上升趋势
> 负值 = 快线在慢线下面 = 短期比长期弱 = 下降趋势

## 五、卖出逻辑：简单粗暴

### 5.1 单一卖出信号

就一个条件：

```python
close > EMA(49周期) * 1.006
```

**大白话**：
> "价格涨到 49 周期均线上方 0.6%，拜拜了您嘞！"

### 5.2 特殊设置：有买入信号就赖着不走

`ignore_roi_if_buy_signal=True` 这行代码是这策略的"小心机"：

**场景**：
1. 价格涨了 1%，本来该卖了
2. 但策略一看："嘿，市场还有买入信号呢！"
3. 策略："那就不卖了，继续持有！"

**大白话**：
> "本来赚 1% 就想跑，但发现市场还在抢筹，那就再等等！"

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **逻辑清晰**：没那么多花里胡哨，均线偏离 + EWO 确认 + RSI 过滤，三板斧
2. **双模式买入**：既抓趋势回调，也抓超跌反弹，两条腿走路
3. **贪心有度**：`ignore_roi_if_buy_signal` 让盈利头寸能多飞一会儿
4. **参数可优化**：7 个参数都能调，适应不同市场

### ⚠️ 缺点（吐槽环节）

1. **信息时间框架没真正用上**：定义了 1h 信息层，但决策全在 5m 上，有点浪费
2. **震荡市容易被收割**：EMA 偏移策略在横盘时就像韭菜，来回被割
3. **无波动率过滤**：没考虑 ATR，高波动时可能误判

## 十一、彩蛋：策略作者的"小心思"

仔细看代码，你会发现一些有趣的设计：

1. **EWO 用了 50/200 周期**：比默认的 5/35 慢很多，说明作者想要更稳定的趋势判断
   > "我不求快，我求稳！"

2. **买入 EMA 是 16，卖出 EMA 是 49**：买入快，卖出慢，这设计有点意思
   > "进场要快，出场要慢——因为要让利润奔跑！"

3. **low_offset=0.978, high_offset=1.006**：低 2.2% 买，高 0.6% 卖，这不对称设计
   > "抄底要狠，跑路要快！"

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

SMAOffsetProtectOptV1 的历史回测表现往往**看起来不错**——但这有个陷阱：

> **因为参数可以调优，策略很容易"拟合"过去行情的最优解，但这并不代表未来一定能盈利。**

简单说就是：**历史业绩不代表未来表现**——这句废话其实是真理。

### 复杂策略的隐藏风险

实盘时，简单的逻辑可能导致：
- **滑点**：价格瞬息万变，回测假设完美成交
- **延迟**：网络延迟可能导致信号失效
- **交易所限制**：API 限制可能导致下单失败
- **极端行情**：黑天鹅事件会让一切策略失效

### 我的建议（真心话）

```
1. 先跑 dry_run 模式至少 1 周
2. 看看信号质量如何，买卖时机是否合理
3. 调整参数后再跑模拟
4. 小仓位实盘试水（别超过总资金 5%）
5. 持续监控，发现问题及时调整
```

**记住**：策略再好，市场教做人时也不会打招呼。轻仓测试，活着最重要！🙏

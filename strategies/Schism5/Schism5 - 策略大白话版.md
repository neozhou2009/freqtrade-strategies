# Schism5 策略：会"看脸色"的牛熊变色龙

> **外号**：牛熊变色龙、自适应玩家  
> **职业**：市场状态自适应交易员  
> **时间框架**：5分钟做决策，1小时看脸色

---

## 一、这策略是个啥？

简单说，**Schism5** 就是一个：
- 会看市场"脸色"（1小时RSI判断牛熊）
- 牛市更谨慎，熊市更积极
- 止损会"慢慢收紧"，越等越保本
- 逻辑比Schism4简洁，参数更少

就像一个**变色龙**：根据环境（牛熊）调整自己的行为，灵活应对 😎

---

## 二、核心配置：说白了就是"激进止盈+渐进止损"

### 止盈规则（ROI 表）

```
时间        目标利润
─────────────────────────
0 分钟       14%      刚买就想要14%，胃口超大！
34 分钟      8%       半小时后降到8%
86 分钟      4%       1.5小时后降到4%
203 分钟     0%       3.4小时后保本退出
```

**翻译**：这策略比Schism4更"贪心"！刚买入就想要14%利润。3.4小时后就妥协了——能出来就行。

### 止损规则：会"慢慢收紧"的止损

```
持仓时间      止损位置
───────────────────────────
0 分钟        -30%      刚买可以亏30%
27.5 分钟     -26%      渐渐收紧
55 分钟       -16%      继续收紧
82.5 分钟     -9%       接近保本
110 分钟      接近0%    基本保本！
```

**翻译**：这止损有个"时间锁"——刚买给你30%的容错空间，但越等越收紧，2小时后就基本保本止损了。

## 三、牛熊自适应：这策略的"看脸色"机制

### 怎么判断牛熊？

**大白话**：
> "我看看1小时RSI，大于60就是牛市，小于60就是熊市"

```python
# 牛市标记
dataframe['bull'] = (1h_RSI > 60) ? 20 : 0
```

### 牛熊买入有什么不同？

| 市场状态 | 买入条件 | 大白话 |
|---------|---------|--------|
| 牛市 | RSI < 39 | "牛市要等价格回调更多才入场，更谨慎" |
| 熊市 | RSI < 49 | "熊市看到一点反弹信号就入场，更积极" |

**大白话**：
> "牛市里大家都在买买买，我等到回调多一点再进；熊市里大家都悲观，我看到一点好转就冲进去抄底"

### 牛熊卖出有什么不同？

| 市场状态 | 卖出条件 | 大白话 |
|---------|---------|--------|
| 牛市 | RSI > 86 | "涨太多了，先出来" |
| 熊市 | RSI > 86 | "涨太多了，先出来" |

**吐槽**：卖出阈值牛熊一样？这有点奇怪啊 🤔 可能是作者觉得86已经是超买极限了

## 四、买入条件：就2个，简单多了

Schism5比Schism4简单多了，就2个买入条件：

### 🎯 牛市买入（RSI下穿39）

**大白话**：
> "牛市里，等RSI跌破39（超卖），我就入场抄底"

```python
# 牛市买入
(dataframe['bull'] > 0) & RSI下穿(39)
```

### 🐻 熊市买入（RSI下穿49）

**大白话**：
> "熊市里，等RSI跌破49（没那么超卖），我就入场"

```python
# 熊市买入
(dataframe['bull'] == 0) & RSI下穿(49)
```

### 持仓续命机制

如果你已经有持仓了，还有一套"续命"逻辑：

```python
# RMI阈值从30慢慢涨到70（4小时内）
rmi_grow = linear_growth(30, 70, 0, 240, open_minutes)

# 条件
RMI上升趋势 == True
当前利润 > 历史最高利润 * 利润因子
RMI >= rmi_grow
```

**大白话**：
> "趋势还在，我就继续拿着。RMI从30慢慢涨到70，越等要求越高"

### 5.1 ROI止盈：激进版

这是Schism5最有意思的地方！

```

```

**大白话**：
> "兄弟，刚买给你30%容错空间。但2小时后你还亏钱，我就不陪你玩了——必须保本退出"

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **牛熊自适应**：会看市场脸色，调整策略行为
2. **参数少**：就4个核心参数（牛熊买卖RSI），简单明了
3. **渐进止损**：从宽松到收紧，平衡风险
4. **持仓续命**：趋势好时忽略ROI继续持有
5. **逻辑清晰**：比Schism4容易理解

### ⚠️ 缺点（吐槽环节）

1. **ROI太贪心**：14%的初始目标？做梦吧 🤣
2. **单一指标**：主要就靠RSI，缺少多重确认
3. **卖出没差异**：牛熊卖出阈值一样，有点奇怪
4. **回测不准**：同样用实时数据，回测别太信

## 八、总结：这策略到底咋样？

> "一个会看脸色的变色龙，牛市谨慎熊市积极，适合震荡市场"

### 适合谁用？

- ❌ 单边趋势爱好者（自适应在趋势中发挥不大）
- ❌ 追求多重确认的人（这策略就靠RSI）
- ❌ 只信回测数据的人

### 我的建议
1. **调低ROI目标**：14%改成10%或更低，更现实
2. **关注止损收紧**：2小时后基本保本止损，注意这个时间节点
3. **理解牛熊判断**：1小时RSI>60是关键
4. **看RSI下穿信号**：这是核心买卖触发

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

Schism5 的历史回测表现可能**很惊艳**——14%的目标偶尔也能达到。但这有个陷阱：

> **因为ROI目标激进，回测时那些"刚好达到14%"的案例可能都是运气，实盘很难复制。**

简单说就是：**"彩票中奖的案例，不代表天天能中奖"**

### 渐进止损的风险

止损收紧机制看起来很聪明，但也有风险：
- **价格突然暴跌**：2小时后止损接近0%，一次大跌可能直接触发
- **震荡行情**：止损收紧过程中可能反复触发小额亏损
- **错过反弹**：保本止损后价格反弹，就错过了

### 我的建议（真心话）

```
1. ROI目标调到10%或更低，别贪14%
2. 止损收紧时间可以延长到130分钟
3. 牛熊判断可以加入其他确认指标
4. 每天检查持仓，理解策略行为
```

**记住**：策略再好，市场教做人时也不会打招呼。轻仓测试，活着最重要！🙏

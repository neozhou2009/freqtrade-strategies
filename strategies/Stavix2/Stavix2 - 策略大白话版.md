## 一、这策略是个啥？

简单说，Stavix2 就是一个：
- **看云图决定买卖**的技术派策略
- **价格突破云就买，跌破云就卖**的简单逻辑
- **1分钟K线**上玩趋势跟踪的急性子
- **有买入也有卖出**的双向选手

这个策略用的是日本著名的"一目均衡表"（Ichimoku Cloud）。这名字听起来就很厉害——"一目"就是"一眼"的意思，"均衡"就是"平衡"，"表"就是图表。意思就是"让你看一眼就能知道市场走势"的超级图表！

> "我的策略就像诸葛亮——足不出户，只看天上的云，就知道下一步要干嘛！"

## 二、核心配置：说白了就是"突破云层就冲"

### 止盈规则（ROI 表）

```
持仓 → 赚 15% 就跑 🤑
```

**翻译**：
15% 的止盈目标！在 1 分钟K线上，这是非常激进的目标。这意味着你需要等到一个比较大的趋势才能触发止盈。

### 止损规则

```
亏损 10% → 认赔走人 🏳️
利润回吐 1% → 立刻锁定利润 🪤（但要先赚够 3%）
```

**翻译**：
- 10% 固定止损，亏到肉疼
- 追踪止损：必须先赚 3%，然后利润回吐到只赚 2%（3%-1%）就会触发

## 三、1 个买入条件：日本"云图三保险"

这策略有 **1 个买入条件**，但这个条件有 **三重确认**：

### 🎯 核心逻辑：三保险买入

**代码逻辑**：
```python
# 条件1：收盘价 > 云图上沿（Senkou Span A）
# 条件2：收盘价 > 云图下沿（Senkou Span B）
# 条件3：基线（金叉）上穿转换线
→ 买入！
```

**大白话**：
> "报告老板！价格突破云层了，而且短期均线从下面冲上来超过长期均线了——这是要涨啊！买！"

这就相当于：
1. 🌤️ **价格突破云层**：从云里面冲出来了，看得见了
2. 🌥️ **价格在云上面**：不是刚刚好露出头，是整个都在云上面
3. 📈 **均线金叉**：短期趋势开始加速

三保险，缺一不可！

### 云图是个啥？

日本的"一目均衡表"由5条线组成，看起来像一团云，所以叫"云图"：

| 线条 | 名字 | 作用 |
|-----|-----|------|
| 转换线 | Tenkan-sen | 短期的"天气趋势" |
| 基线 | Kijun-sen | 中期的"季节变化" |
| 云图A | Senkou Span A | 云的上面那层 |
| 云图B | Senkou Span B | 云的下面那层 |
| 迟行线 | Chikou Span | 滞后的"确认" |

** Stavix2 使用的参数**：
- 转换线周期：200
- 基线周期：350
- 滞后：75

这参数...也太长了吧！200+350，一般人根本记不住啊！

## 四、卖出逻辑：对称的"三保险"

### 卖出条件

**代码逻辑**：
```python
# 条件1：收盘价 < 云图上沿
# 条件2：收盘价 < 云图下沿  
# 条件3：转换线（死叉）下穿基线
→ 卖出！
```

**大白话**：
> "价格跌到云里面去了，而且短期均线也从上面掉下来了——这是要跌啊！卖！"

**对称性**：
买入和卖出的逻辑是完全对称的，只是方向相反。这策略真的很公平——多头空头都能玩！

## 五、保护机制：0 层"裸奔"

这策略没有显式的保护机制，因为三重条件本身就是保护：
- 价格必须在云上面（强势）
- 均线必须金叉（动量确认）

但没有：
- ❌ RSI 过滤
- ❌ 成交量验证
- ❌ BTC 保护
- ❌ 时间过滤

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **经典理论**：日本"一目均衡表"，有 decades 的历史验证
2. **多维确认**：三重条件，降低假信号概率

4. **参数太长**：200+350的参数，普通用户根本不懂
5. **无保护机制**：没有额外的过滤条件

- **止损太远**：10% 止损在1分钟上太大了
- **止盈太难**：15%基本上触发不了

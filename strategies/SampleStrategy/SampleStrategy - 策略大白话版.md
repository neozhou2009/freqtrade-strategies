## 一、这策略是个啥？

简单说，**SampleStrategy** 就是一个：
- 26个买入条件（你说多不多？）
- 8个卖出条件 + custom_sell动态止盈
- 每个买入条件都有独立保护参数组
- 多时间框架验证（5m+1h）

就像一个相亲要查三代家谱的谨慎投资者，任何入场都要经过层层审查 🤣

## 二、核心配置：说白了就是"层层保险"

### 止盈规则（ROI 表）

```
刚买入 → 利润 10% 就跑
30分钟后 → 利润 5% 就跑
60分钟后 → 利润 2% 就跑
```

**翻译**：时间是金钱的敌人，持仓越久利润目标越低。这不是贪心，是防止利润回吐。

### 止损规则

```
固定止损：-10%
追踪止损：利润3%后启动，回落1%就锁利
```

**翻译**：亏10%认栽，赚3%后开始保护利润，别让煮熟的鸭子飞了。

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **防御无敌**：26组保护参数，几乎任何入场都要经过审查
2. **灵活组合**：买入条件可单独开关，想用哪个就用哪个
3. **动态止盈**：custom_sell 不是简单的ROI表，而是根据利润动态调整
4. **多时间框架**：1h确认大趋势，5m执行入场

### ⚠️ 缺点（吐槽环节）

1. **条件太多**：26个买入条件，自己都快记不住了 🤣
2. **参数爆炸**：300多个参数，调优简直噩梦
3. **计算量大**：需要400根K线的启动数据
4. **过拟合风险**：参数太多容易"背答案"

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

SampleStrategy 的历史回测表现往往**极其优异**——但这有个陷阱：

> **因为参数众多，策略很容易"拟合"过去行情的最优解，但这并不代表未来一定能盈利。**

简单说就是：**背答案的学生考试厉害，但不代表真懂**

### 复杂策略的隐藏风险

实盘时，复杂的逻辑可能导致：
- **信号延迟**：计算量大，可能错过最佳入场点
- **滑点放大**：限价单可能因为市场波动执行失败
- **维护困难**：参数太多，出了问题很难排查

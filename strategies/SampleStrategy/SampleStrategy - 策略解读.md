## 一、策略概览

**SampleStrategy** 是一个基于 NostalgiaForInfinityV7 架构的高度复杂趋势跟踪策略。该策略通过多达 26 个独立买入条件和 8 个卖出条件，构建了一个全方位的信号捕获系统，并配备了多层动态保护机制以确保入场安全性。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 26 个独立买入信号，可独立启用/禁用 |
| **卖出条件** | 8 个基础卖出信号 + custom_sell 动态止盈逻辑 |
| **保护机制** | 26 组买入保护参数（EMA过滤、安全Dip、安全Pump等） |
| **时间框架** | 主时间框架 5m + 信息时间框架 1h |
| **依赖库** | talib, qtpylib, technical (zema) |

- ROI 表采用递进式设计，时间越长利润目标越低
- 10% 固定止损作为底线保护
- 追踪止损用于锁定利润，在利润达到 3% 后启动

## 七、策略优势与局限

### ✅ 优势

1. **多层防护系统**：26组独立保护参数，有效过滤虚假信号
2. **灵活的买入组合**：可单独启用/禁用任意买入条件，便于优化
3. **动态止盈机制**：custom_sell 提供利润锁定和回落保护
4. **多时间框架验证**：1h信息层提供大周期趋势确认

### ⚠️ 局限

1. **复杂度高**：参数多达数百个，调优难度大
2. **计算资源需求**：startup_candle_count = 400，需要较长的历史数据
3. **过拟合风险**：众多参数可能导致历史表现优异但实盘差异大

## 十一、总结

**SampleStrategy** 是一个 **高度复杂的多条件趋势跟踪策略**。它的核心价值在于：

1. **防御性设计**：26组保护参数构建多层安全网
2. **灵活组合**：买入条件可独立控制，便于针对性优化
3. **动态止盈**：custom_sell 提供利润保护机制

对于量化交易者而言，此策略适合 **有经验的用户进行二次开发**，不建议新手直接实盘使用。建议先进行 dry-run 测试，并根据具体市场调整买入条件的启用组合。

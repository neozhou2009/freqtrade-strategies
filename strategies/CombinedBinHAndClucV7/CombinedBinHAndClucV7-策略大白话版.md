
**模式 2：RSI 超买**
```python

```

**大白话**：
> "RSI 都 77 了（超买）——这还不跑？"

### 5.2 自定义止损：亏损超过 280 分钟

**触发条件**：
```python

```

**大白话**：
> "亏了快 5 小时了，别等了，赶紧跑，把位置让给更好的交易！"

### 5.3 确认退出：根据 RSI 阻止过早退出

**触发条件**：
```python
if 卖出原因 == "roi":
    if 利润 > 10% AND RSI > 34:
        阻止退出（让利润奔跑）
    elif 利润 > 3% AND RSI > 38:
        阻止退出
    elif 利润 > 0% AND RSI > 50:
        阻止退出
```

**大白话**：
> "赚得挺多，RSI 还高着呢，别跑，让利润再跑跑！"

**吐槽**：这策略是真的"纠结"，一边要止损，一边又要让利润奔跑！🤣

## 六、这策略的"人格特点"

### ✅ 优点
1. **多策略组合**：4 种买入模式，覆盖不同场景
2. **信息时间框架**：1h 确认趋势，减少假信号

2. **没 BTC 关联**：比特币崩了它也不知道
3. **参数敏感**：优化出来的参数可能过拟合
4. **计算量大**：多指标 + 信息时间框架增加计算负担
5. **几乎无硬止损**：-99% 止损形同虚设

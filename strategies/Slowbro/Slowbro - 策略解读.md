## 一、策略概览

Slowbro 是一个极简主义的趋势跟踪策略，其设计哲学可以用"慢即是快"来概括。策略名称源自宝可梦中的"呆壳兽"（Slowbro），寓意其缓慢但稳健的操作风格。核心思路是通过追踪 30 日价格区间，在价格触及 30 日低点时买入，触及 30 日高点时卖出，实现低买高卖的趋势跟随。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 1 个买入信号：价格上穿 30 日最低价 |
| **卖出条件** | 1 个卖出信号：价格上穿 30 日最高价 |
| **保护机制** | 无独立保护机制，依赖 ROI 和止损 |
| **时间框架** | 1 小时主框架 + 1 天信息框架 |
| **依赖库** | qtpylib（交叉检测）、merge_informative_pair（数据合并） |

# ROI 退出表
minimal_roi = {

**设计思路**：

- 7 天后目标利润达 100%，适合捕捉大级别趋势行情

- 买入：限价单

## 三、买入条件详解

### 3.1 核心买入逻辑

Slowbro 采用单一的区间突破买入逻辑：

```python
def populate_entry_trend(self, dataframe: DataFrame, metadata: dict) -> DataFrame:
    dataframe.loc[
        (
            qtpylib.crossed_above(dataframe['close'], dataframe[f"30d-low_{self.inf_timeframe}"])
        ),
        'buy'] = 1
    return dataframe
```

**触发条件**：
- 收盘价从下方向上穿越 30 日最低价线

### 3.2 信息时间框架的作用

策略使用日线（1d）作为信息层，计算 30 日价格区间：

```python
def populate_indicators(self, dataframe: DataFrame, metadata: dict) -> DataFrame:
    informative = self.dp.get_pair_dataframe(pair=metadata['pair'], timeframe=self.inf_timeframe)
    informative['30d-low'] = informative['close'].rolling(30).min()
    informative['30d-high'] = informative['close'].rolling(30).max()
    
    dataframe = merge_informative_pair(dataframe, informative, self.timeframe, self.inf_timeframe, ffill=True)
    return dataframe
```

**关键计算**：
- `30d-low`：过去 30 天的最低收盘价
- `30d-high`：过去 30 天的最高收盘价
- 使用前向填充（ffill）将日线数据映射到小时线

## 四、卖出逻辑详解

### 4.1 卖出信号

与买入对称，采用区间突破卖出：

```python
def populate_exit_trend(self, dataframe: DataFrame, metadata: dict) -> DataFrame:
    dataframe.loc[
        (
            qtpylib.crossed_above(dataframe['close'], dataframe[f"30d-high_{self.inf_timeframe}"])
        ),
        'sell'] = 1
    return dataframe
```

**触发条件**：
- 收盘价从下方向上穿越 30 日最高价线

### 4.2 卖出配置

```python
use_sell_signal = True       # 启用卖出信号
sell_profit_only = True      # 仅在盈利时卖出
ignore_roi_if_buy_signal = False  # 买入信号优先级低于 ROI
```

**设计思路**：
- `sell_profit_only = True` 确保不会亏损卖出（依赖止损保护）
- 卖出信号与 ROI 机制配合使用

## 五、技术指标体系

### 5.1 核心指标

| 指标类别 | 具体指标 | 用途 |
|---------|---------|------|
| 价格区间 | 30 日滚动最低价 | 买入触发线 |
| 价格区间 | 30 日滚动最高价 | 卖出触发线 |
| 交叉检测 | qtpylib.crossed_above | 信号触发判断 |

### 5.2 信息时间框架指标（日线）

策略使用日线作为信息层，提供更高维度的趋势判断：

- **30 日最低价**：作为买入触发线，价格触及此线代表进入超跌区域
- **30 日最高价**：作为卖出触发线，价格突破此线代表进入超涨区域
- **前向填充**：将日线数据无缝映射到小时线，保持信号连续性

## 六、风险管理特色

### 6.1 区间交易思想

Slowbro 的风险管理核心在于区间界定：
- **买入边界**：30 日最低价作为"地板"
- **卖出边界**：30 日最高价作为"天花板"
- **持仓周期**：从地板到天花板的趋势跟踪

### 6.2 时间分级 ROI

| 持仓时间 | 目标利润 | 风险收益比 |
|---------|---------|-----------|
| 即时 | 10% | 1:1 |
| 1 天 | 20% | 2:1 |
| 2 天 | 30% | 3:1 |
| 7 天 | 100% | 10:1 |

### 6.3 止损保护

- **固定止损**：-10%，与首级 ROI 对称
- **盈利卖出限制**：`sell_profit_only = True` 防止亏损时过早离场

## 七、策略优势与局限

### ✅ 优势

1. **极简设计**：代码仅约 100 行，易于理解和维护
2. **趋势跟踪**：基于 30 日区间，捕捉中长趋势
3. **参数少**：无需优化大量指标参数，降低过拟合风险
4. **资源消耗低**：计算量小，适合大规模并行运行

### ⚠️ 局限

1. **信号稀少**：单一买入条件，交易频率可能较低
2. **滞后性**：30 日区间对市场变化反应较慢
3. **震荡市风险**：在横盘震荡中可能频繁触发假信号
4. **无动态调整**：不根据市场波动调整参数

## 九、适用市场环境详解

Slowbro 是典型的**区间突破趋势跟踪策略**。基于其代码架构和设计理念，它最适合**有明确趋势的慢牛市场**，而在**剧烈震荡或快速下跌**时表现不佳。

### 9.1 策略核心逻辑

- **区间定义**：使用 30 日滚动窗口定义"地板"和"天花板"
- **顺势而为**：价格突破地板买入，突破天花板卖出
- **时间框架嵌套**：日线区间 + 小时线触发，平衡稳定性和灵敏度

### 9.2 不同市场环境表现

| 市场类型 | 表现评级 | 原因分析 |
| :--- | :--- | :--- |
| 📈 慢牛市场 | ⭐⭐⭐⭐⭐ | 价格稳步上涨，区间逐步上移，完美匹配策略逻辑 |
| 🔄 震荡市场 | ⭐⭐☆☆☆ | 价格反复穿越区间边界，触发大量假信号 |
| 📉 熊市 | ⭐⭐⭐☆☆ | 区间下移过程中可做空信号，但设计初衷为做多 |
| ⚡️ 高波动 | ⭐⭐☆☆☆ | 价格剧烈波动导致区间快速变化，信号滞后 |

### 9.3 关键配置建议

| 配置项 | 建议值 | 说明 |
|--------|--------|------|
| 时间框架 | 1h（默认） | 平衡信号频率和可靠性 |
| 止损 | -10%（默认） | 与 ROI 对称，可根据风险偏好调整 |
| 交易对 | 主流币种 | 流动性好，趋势相对明确 |

> **策略编号**: #4 (465 个策略中的第 4 个)  
> **策略类型**: 布林带 + RSI 均值回归  
> **时间框架**: 1 小时 (1h)

---

## 一、策略概览

**BbandRsi** 是一个经典的均值回归策略，由作者 Gert Wohlgemuth 从 C# 项目 Mynt 移植到 Freqtrade 平台。与 BBRSI21 类似，但采用更宽松的条件和 1 小时时间框架，适合捕捉更大级别的波动。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 1 个条件：RSI < 30 + 价格 < 布林带下轨 |
| **卖出条件** | 1 个条件：RSI > 70 |
| **保护机制** | 无独立保护参数，依赖硬止损 |
| **时间框架** | 1 小时 |
| **依赖库** | TA-Lib, technical (qtpylib) |

## 二、策略配置解析

### 2.1 基础风险参数

```python
# ROI 退出表
minimal_roi = {
    "0": 0.1    # 立即退出：10% 利润
}

# 止损设置
stoploss = -0.25  # -25% 硬止损
```

**设计思路**：
- **低 ROI 门槛**：10% 即可退出，说明策略追求快速周转
- **宽松止损**：-25% 硬止损给予充分波动空间，适合 1 小时级别
- **无追踪止损**：依赖技术信号退出

### 2.2 订单类型配置

使用 Freqtrade 默认配置（未在策略中显式定义）。

## 三、买入条件详解

### 3.1 买入逻辑

```python
# 买入条件
dataframe.loc[
    (
        (dataframe["rsi"] < 30)                          # RSI 低于 30（超卖）
        & (dataframe["close"] < dataframe["bb_lowerband"])  # 价格低于布林带下轨
    ),
    "buy",
] = 1
```

**逻辑解析**：
- **RSI 超卖**：RSI < 30 是传统超卖阈值
- **布林带下轨突破**：价格跌破 2 倍标准差布林带下轨
- **双重确认**：两个条件同时满足才触发买入

### 3.2 与 BBRSI21 的对比

| 特征 | BbandRsi | BBRSI21 |
|------|----------|---------|
| 时间框架 | 1h | 5m |
| RSI 买入阈值 | < 30 | < 21 |
| RSI 卖出阈值 | > 70 | > 99 |
| ROI | 10% | 22.77% |
| 止损 | -25% | -30% |
| 布林带标准差 | 2 倍 | 3 倍 |

**结论**：BbandRsi 条件更宽松，适合捕捉 1 小时级别的波动。

## 四、卖出逻辑详解

### 4.1 卖出条件

```python
# 卖出条件
dataframe.loc[
    (dataframe["rsi"] > 70),  # RSI 高于 70（超买）
    "sell",
] = 1
```

**逻辑解析**：
- **RSI 超买**：RSI > 70 是传统超买阈值
- **单一条件**：仅 RSI 超买即触发卖出，不要求布林带上轨突破
- **宽松退出**：相比买入条件的严格，卖出更灵活

### 4.2 ROI 退出

```python
minimal_roi = {"0": 0.1}  # 10% 利润立即退出
```

**说明**：低门槛 ROI，追求快速周转。

## 五、技术指标体系

### 5.1 核心指标

| 指标类别 | 具体指标 | 参数 | 用途 |
|---------|---------|------|------|
| **波动指标** | Bollinger Bands | 20 周期，2 倍标准差 | 价格边界判断 |
| **动量指标** | RSI | 14 周期 | 超买超卖判断 |

### 5.2 指标计算

```python
# RSI 计算
dataframe["rsi"] = ta.RSI(dataframe, timeperiod=14)

# 布林带计算（20 周期，2 倍标准差）
bollinger = qtpylib.bollinger_bands(
    qtpylib.typical_price(dataframe), window=20, stds=2
)
dataframe["bb_lowerband"] = bollinger["lower"]
dataframe["bb_middleband"] = bollinger["mid"]
dataframe["bb_upperband"] = bollinger["upper"]
```

## 七、策略优势与局限

### ✅ 优势

1. **逻辑简单清晰**：仅 2 个指标，易于理解和监控
2. **经典阈值**：RSI 30/70 是传统超买超卖阈值
3. **时间框架友好**：1 小时级别适合大多数交易者
4. **计算量小**：指标少，对硬件要求低
5. **快速周转**：10% ROI 即可退出，资金利用率高

### ⚠️ 局限

1. **无趋势过滤**：没有 EMA/SMA 趋势判断，可能在单边下跌中连续亏损
2. **无 BTC 关联分析**：不检测比特币大盘趋势
3. **宽松止损风险**：-25% 止损在极端行情下可能造成较大亏损
4. **卖出条件单一**：仅 RSI > 70 即卖出，可能过早退出趋势
5. **无追踪止损**：未启用追踪止损，可能错失大趋势利润

## 九、适用市场环境详解

BbandRsi 是经典的均值回归策略，基于"价格围绕均值波动"的核心假设。

### 9.1 策略核心逻辑

- **均值回归思想**：价格跌破布林带下轨后，大概率会回归中轨
- **RSI 超卖确认**：RSI < 30 确认市场情绪悲观，反弹概率高
- **快速退出**：RSI > 70 即退出，不贪心

### 9.2 不同市场环境表现

| 市场类型 | 表现评级 | 原因分析 |
| :--- | :--- | :--- |
| 📈 慢牛/震荡向上 | ★★★★☆ (好) | 均值回归 + 上涨趋势，表现良好 |
| 🔄 宽幅震荡 | ★★★★★ (最佳) | 震荡行情是均值回归策略的理想环境 |
| 📉 单边暴跌 | ★★☆☆☆ (较差) | 无趋势过滤，可能连续接下跌刀子 |
| ⚡️ 极端横盘 | ★★★☆☆ (中性) | 波动太小，信号减少但风险也低 |

### 9.3 关键配置建议

| 配置项 | 建议值 | 说明 |
|--------|--------|------|
| **交易对数量** | 20-40 个 USDT 交易对 | 1h 信号频率适中 |
| **最大持仓数** | 3-6 个订单 | 1h 级别不宜过多仓位 |
| **仓位模式** | 固定仓位 | 建议固定仓位，控制风险 |
| **时间框架** | 1h | 强制要求，不可更改 |

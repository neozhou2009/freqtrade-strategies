# BBandsRSI 策略：抄底小能手

> **外号**：超卖猎人  
> **职业**：专业抄底，等待反弹  
> **时间框架**：5m（5 分钟）

---

## 一、这策略是个啥？

简单说，**BBandsRSI** 就是一个：
- 布林带下轨 + RSI 超卖 = 买买买
- RSI 超买 = 卖卖卖
- 典型的"抄底"策略

就像超市打折：价格跌破底线（布林带下轨），大家都恐慌抛售（RSI 超卖），这时候你去捡便宜货 🛒

---

## 二、核心配置：说白了就是"抄底等反弹"

### 止盈规则（ROI 表）

```python
minimal_roi = {"0": 0.0}  # 没有固定止盈目标
```

**翻译**：赚多少看市场给多少，不设上限，追踪止损帮你锁利润。

### 止损规则

```
固定止损：-15%（很宽！）
追踪止损：开启
```

**翻译**：能扛 15% 的亏损，给价格足够的波动空间。但赚钱了会帮你锁定，不让利润变亏损。

---

## 三、1 个买入条件：专业抄底姿势

### 🎯 经典组合：布林带 + RSI

```python
(rsi < 30) & (close < bb_lowerband) & (volume > 0)
```

**大白话**：
> "RSI 低于 30，说明大家吓坏了；价格跌破布林带下轨，说明真的便宜。这时候入场，等反弹！"

| 条件 | 参数 | 人话解释 |
|------|------|---------|
| RSI 超卖 | < 30 | 市场恐慌，过度抛售 |
| 价格破下轨 | < BB下轨 | 统计学上的极端低价 |
| 有成交量 | > 0 | 不是死盘 |

**为什么用两个条件？**
- 单一条件容易假信号
- 两个条件都满足，反弹概率更高

---

## 四、1 个卖出条件：赚够了就跑

### 📉 RSI 超买就卖

```python
(rsi > 70) & (volume > 0)
```

**大白话**：
> "RSI 超过 70 了，大家太乐观了，该获利了结了。"

注意：卖出只看 RSI，不看布林带位置。简单粗暴。

## 五、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **经典组合**：布林带 + RSI 是老牌黄金搭档，有效性有目共睹
2. **双重确认**：不是瞎抄底，有统计+情绪双重保险
3. **止损宽**：15% 的止损空间，不怕被小波动扫出去
4. **追踪止损**：让利润跑，不急着止盈

### ⚠️ 缺点（吐槽环节）

1. **逆势操作**：抄底是逆着趋势来，趋势强的时候会接飞刀 🗡️
2. **卖出简单**：只看 RSI，不看价格是否真的高估
3. **止损宽**：一次亏损可能就是 15%，肉疼
4. **没 ROI 目标**：可能错过最佳获利点，盈利回撤

## 八、这策略在什么市场能赚钱？

### 8.1 核心逻辑：均值回归

BBandsRSI 的赚钱哲学很简单：

**物极必反，跌多了会涨**

- **布林带下轨**：统计学告诉我们，95% 的价格都在布林带内
- **RSI 超卖**：心理学告诉我们，恐慌过度就会反弹
- **两者结合**：大概率捡到便宜货

### 8.2 不同市场表现（说人话版）

| 市场类型 | 表现评级 | 大白话解释 |
| :--- | :--- | :--- |
| 📈 强上涨 | ⭐⭐ | 卖太早，后面涨跟你没关系 |
| 🔄 震荡盘整 | ⭐⭐⭐⭐⭐ | 完美环境，反复抄底逃顶 |
| 📉 强下跌 | ⭐ | 抄底抄在半山腰，越抄越低 |
| ⚡️ 高波动 | ⭐⭐⭐ | 机会多，但风险也大 |

**一句话总结**：震荡市场是主场，趋势市场是客场。

## 十二、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

BBandsRSI 在震荡市场回测效果会很好——但这有个陷阱：

> **你怎么知道接下来是震荡还是趋势？**

简单说就是：**震荡市场赚得盆满钵满，趋势市场亏得怀疑人生。**

### 均值回归策略的隐藏风险

实盘时，均值回归策略可能导致：
- **接飞刀**：强下跌趋势中，越抄越低
- **卖太早**：强上涨趋势中，卖完就涨
- **黑天鹅**：极端行情下，均值不回归

### 我的建议（真心话）

```
1. 先判断市场状态（震荡/趋势）
2. 震荡用这个，趋势换策略
3. 小仓位测试
4. 设置止损，别扛单
5. 分批建仓更安全
```

**记住**：抄底不可怕，可怕的是不知道自己在抄底还是在接飞刀！🙏

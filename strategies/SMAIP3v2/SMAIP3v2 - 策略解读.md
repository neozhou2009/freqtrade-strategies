> **时间框架**: 5 分钟 (5m)

## 一、策略概览

SMAIP3v2 是一个基于移动平均线偏移的趋势跟踪策略，通过动态计算买卖阈值来捕捉价格回调后的反弹机会。该策略结合 EMA 趋势过滤和"坏币种"检测机制，在保持趋势跟踪的同时规避极端行情。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 1 个核心买入信号（趋势过滤 + 价格偏离） |
| **卖出条件** | 1 个基础卖出信号 + 追踪止损 + ROI 止盈 |
| **保护机制** | 2 组"坏币种"检测阈值 |
| **时间框架** | 5 分钟主时间框架 |
| **依赖库** | talib (技术指标计算), freqtrade.strategy |

# ROI 退出表

## 三、买入条件详解

### 3.1 保护机制（2 组）

策略通过 `pair_is_bad` 检测机制防止在极端行情中买入：

| 保护类型 | 参数说明 | 默认值 |
|---------|---------|--------|
| pair_is_bad_1 | 12 根 K 线前的开盘价与当前收盘价跌幅阈值 | 0.130 (13%) |
| pair_is_bad_2 | 6 根 K 线前的开盘价与当前收盘价跌幅阈值 | 0.075 (7.5%) |

**逻辑**：当价格在过去 6-12 根 K 线内发生剧烈下跌（超过阈值），则标记为"坏币种"，暂停买入。

### 3.2 核心买入条件

```python
# 买入逻辑
(
    (dataframe['ema_50'] > dataframe['ema_200']) &           # EMA50 上穿 EMA200，趋势向上
    (dataframe['close'] > dataframe['ema_200']) &             # 收盘价在 EMA200 之上
    (dataframe['pair_is_bad'] < 1) &                          # 非坏币种状态
    (dataframe['close'] < dataframe['ma_offset_buy']) &       # 价格低于买入阈值
    (dataframe['volume'] > 0)                                  # 有成交量
)
```

**条件解析**：
1. **趋势确认**：EMA50 > EMA200，确保中期趋势向上
2. **价格位置**：收盘价 > EMA200，确保处于长期上涨趋势中
3. **安全检查**：非"坏币种"状态，避免追高或抄底暴跌币
4. **买入机会**：价格低于动态计算的买入阈值（MA × low_offset）
5. **流动性**：确保有成交量

### 3.3 移动平均线偏移机制

策略使用动态偏移来计算买卖阈值：

```python
# 买入阈值计算
ma_offset_buy = SMA/EMA(N根K线) × low_offset
# low_offset 默认 0.968，即均线下方 3.2%

# 卖出阈值计算
ma_offset_sell = EMA(N根K线) × high_offset  
# high_offset 默认 0.985，即均线上方 -1.5%（稍低于均线）
```

## 四、卖出逻辑详解

### 4.1 卖出条件

```python
# 卖出逻辑
(
    (dataframe['close'] > dataframe['ma_offset_sell']) &      # 价格高于卖出阈值
    (dataframe['volume'] > 0)                                  # 有成交量
)
```

**设计思路**：当价格反弹超过卖出阈值时获利离场。

### 4.2 智能退出拒绝机制

策略实现了 `confirm_trade_exit` 方法，在某些情况下拒绝卖出：

```python
# 拒绝退出条件
if sell_reason in ['roi', 'sell_signal', 'trailing_stop_loss']:
    if (last_candle['open'] > previous_candle_1['open']) &    # 当前 K 线开盘价更高
       (last_candle['rsi'] > 50) &                             # RSI > 50
       (last_candle['rsi'] > previous_candle_1['rsi']):       # RSI 上升中
        return False  # 拒绝退出
```

**设计思路**：当市场动量仍然强劲（价格高开、RSI 上升）时，拒绝卖出以获取更多利润。

### 4.3 多层止盈体系

| 利润水平 | 退出机制 | 触发条件 |
|---------|---------|---------|
| 2.6% | ROI 止盈 | 立即生效 |
| 1.8%+ | 追踪止损激活 | 利润超过 1.8% |
| 回撤 0.3%+ | 追踪止损触发 | 从最高点回撤 0.3% |

## 六、风险管理特色

### 6.1 双重趋势过滤

策略要求同时满足中期趋势（EMA50 > EMA200）和长期趋势（价格 > EMA200），双重确认后才考虑买入，大幅降低逆势交易风险。

### 6.2 动态"坏币种"检测

通过监测过去 6-12 根 K 线的价格变化，识别暴跌币种并暂停买入：

```python
pair_is_bad = (
    ((open.shift(12) - close) / close >= 0.130) |  # 12 根 K 线跌幅 >= 13%
    ((open.shift(6) - close) / close >= 0.075)      # 6 根 K 线跌幅 >= 7.5%
)
```

### 6.3 智能退出拒绝

在退出信号触发时，额外检查市场动量。如果动量仍然强劲，则拒绝退出继续持有，最大化利润空间。

## 七、策略优势与局限

### ✅ 优势

1. **趋势确认严谨**：双重 EMA 过滤确保只在上涨趋势中交易
2. **暴跌规避机制**：坏币种检测防止在极端行情中抄底
3. **利润保护完善**：追踪止损 + 智能退出拒绝双重保护
4. **参数可优化空间大**：多项参数支持 Hyperopt 优化

### ⚠️ 局限

1. **止损空间较大**：23% 止损对保守交易者可能过宽
2. **横盘市场表现一般**：作为趋势策略，横盘时可能频繁小亏
3. **单时间框架**：仅使用 5 分钟，缺乏多时间框架确认

## 九、适用市场环境详解

SMAIP3v2 是典型的趋势跟踪策略，最适合**明确的上涨趋势市场**，而在横盘或下跌市场中表现不佳。

### 9.1 策略核心逻辑

- **趋势为王**：只在 EMA50 > EMA200 且价格 > EMA200 时买入
- **回调买入**：等待价格回调到动态阈值下方才入场
- **智能持有**：动量强劲时拒绝卖出，最大化利润

### 9.2 不同市场环境表现

| 市场类型 | 表现评级 | 原因分析 |
| :--- | :--- | :--- |
| 📈 明显上涨 | ⭐⭐⭐⭐⭐ | 完美匹配策略逻辑，回调买入后趋势延续 |
| 🔄 震荡上涨 | ⭐⭐⭐⭐☆ | 仍能获利，但回调可能触发止损 |
| 📉 下跌趋势 | ⭐☆☆☆☆ | 趋势过滤会阻止大部分买入，资金利用率低 |
| ⚡️ 高波动横盘 | ⭐⭐☆☆☆ | 频繁进出，手续费侵蚀利润 |

### 9.3 关键配置建议

| 配置项 | 建议值 | 说明 |
|--------|--------|------|
| 交易对 | 主流币种 | 流动性好，趋势更明显 |
| pair_is_bad 阈值 | 根据波动率调整 | 高波动币种可适当放宽 |
| ROI | 可提高至 3-5% | 适应不同风险偏好 |

## 十一、总结

**SMAIP3v2** 是一个设计精良的趋势跟踪策略，通过移动平均线偏移实现回调买入，同时配合智能退出机制最大化利润。它的核心价值在于：

1. **趋势确认严谨**：双重 EMA 过滤，避免逆势交易
2. **风险控制完善**：坏币种检测 + 追踪止损 + 智能退出拒绝
3. **参数可优化性强**：支持 Hyperopt 进行参数优化

对于量化交易者而言，这是一个适合在明确上涨趋势中使用的策略，建议在趋势行情中部署，横盘期适当降低仓位或暂停。

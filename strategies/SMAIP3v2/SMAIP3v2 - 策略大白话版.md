# SMAIP3v2 策略："抄底小能手"的智能抄底指南

> **外号**：抄底小能手、趋势狙击手
> **职业**：专挑回调买入，涨了就跑
> **时间框架**：5 分钟（适合日内交易）

---

## 一、这策略是个啥？

简单说，**SMAIP3v2** 就是一个：
- 只在上涨趋势中干活
- 专门等价格回调时买入
- 还有个"脑子"会在赚钱时拒绝卖出（觉得还能涨）

就像一个"抄底小能手"，但人家不瞎抄，必须是大趋势向上、价格回调到位、而且没有暴跌风险才出手 🎯

---

## 二、核心配置：说白了就是"趋势向上等回调"

### 止盈规则（ROI 表）

```
赚够 2.6% → 立马跑
```

**翻译**：这策略比较"急"，赚到 2.6% 就收工，不贪。当然，有追踪止损保护，有时候能赚到更多。

### 止损规则

```
亏到 23% → 认赔出局
利润到 1.8% → 启动追踪止损，回撤 0.3% 就跑
```

**翻译**：
- 止损挺"大方"，给足了波动空间
- 但一旦赚钱了，马上开启"保命模式"，回撤一点就跑

---

## 三、1 个买入条件：条件不多，但够用

这策略就 1 个买入信号，但逻辑严谨得很：

### 🎯 核心买入：趋势向上 + 价格回调 + 没崩盘

**大白话**：
> "大趋势向上（EMA50 > EMA200），价格在长期均线上方，现在回调到买入线以下，而且最近没有暴跌，那我就买入！"

**代码翻译**：
```python
EMA50 > EMA200                    # 中期趋势向上
价格 > EMA200                      # 长期趋势也向上
pair_is_bad < 1                   # 最近没暴跌
价格 < 买入阈值(MA × 0.968)        # 回调到位了
有成交量                          # 不是死币
→ 买入！
```

## 四、保护机制：2 层"暴跌防护网"

策略有个叫 `pair_is_bad` 的机制，专门防暴跌：

| 保护类型 | 作用 | 大白话 |
|---------|------|--------|
| pair_is_bad_1 | 12 根 K 线跌幅超 13% 标记为坏 | "一小时前崩了 13%，别抄底！" |
| pair_is_bad_2 | 6 根 K 线跌幅超 7.5% 标记为坏 | "半小时前崩了 7.5%，再等等！" |

这设计挺聪明的——防止你在"飞刀落地前"去接飞刀 🤣

## 五、卖出逻辑：比买入更有意思

### 5.1 基础卖出：涨过线就跑

```
价格 > 卖出阈值(EMA × 0.985) → 卖出
```

**大白话**：价格反弹超过卖出线，赚够了就跑。

### 5.2 智能退出拒绝：这策略会"思考"

最有趣的是 `confirm_trade_exit` 方法：

**代码逻辑**：
```python
如果要卖出（ROI/信号/追踪止损）:
    如果 当前K线开盘价更高 且 RSI>50 且 RSI还在涨:
        拒绝退出！觉得还能涨！
```

**大白话**：
> "卖出信号来了？等等，我看下现在行情……嗯，开盘价更高，RSI 还在涨，动量很足，我选择不卖，继续拿！"

这就像个有主见的交易员，不是机械执行，而是会"思考"一下要不要真的走 😎

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **趋势确认严谨**：双重均线过滤，不会在下跌趋势乱买
2. **暴跌保护到位**：坏币种检测防止接飞刀
3. **利润保护完善**：追踪止损 + 智能退出拒绝，该跑时跑，该拿时拿
4. **参数可优化**：支持 Hyperopt 调参，适应不同币种

### ⚠️ 缺点（吐槽环节）

1. **止损有点宽**：23% 的止损，心脏不好的可能会受不了
2. **横盘期难受**：趋势策略通病，横盘时会被反复打脸
3. **单时间框架**：只看 5 分钟，没有更大周期确认

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

SMAIP3v2 的历史回测表现可能**还不错**——但要注意：

> **智能退出拒绝机制在实盘中的表现可能与回测有差异，尤其是在流动性不足或剧烈波动的市场。**

简单说就是：**回测看的是历史数据，实盘面对的是未知市场。**

### 复杂策略的隐藏风险

实盘时要注意：
- **滑点风险**：5 分钟级别交易，滑点可能吃掉部分利润
- **交易所限制**：某些交易所 API 可能有延迟
- **黑天鹅事件**：暴跌时可能触发止损失败

### 我的建议（真心话）

```
1. 先模拟盘测试至少 1 个月
2. 关注智能退出拒绝的实际效果
3. 选流动性好的主流币
4. 横盘期减仓或暂停
5. 止损可以调窄一点（比如 -15%），看个人风险承受
```

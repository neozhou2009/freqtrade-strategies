## 一、这策略是个啥？

**CombinedBinHAndClucHyperV0** 翻译过来就是"结合布林带和 Cluc 的超参数优化版 V0"。

简单说就是：
- 把两个老策略 **BinHV45** 和 **ClucMay72018** 强行撮合在一起
- 谁说了买，就听谁的（"或门"逻辑）
- **重点来了**：这是一个"超级进化版"，12 个参数可以随便调！
- 时间框架是 **1 分钟**，主打的就是一个"快"！

就像一个有两个超级军师的将军："军师 A 说买，买！军师 B 说买，也买！而且我还能根据市场情况随时调整军师的判断标准！" 🧙‍♂️⚡

## 二、核心配置：参数多到头皮发麻

### 止盈规则（分阶段）
```
0 分钟时：赚 10%？→ 跑！
30 分钟后：赚 5%？→ 跑！
60 分钟后：赚 2%？→ 跑！
```
**大白话**：刚开始要求高一点（10%），等久了就降低要求（2%），这就是时间换空间！

### 止损规则
```
亏 10%？→ 割！
```
**大白话**：允许你亏 10%，给你足够的面子！

### 追踪止损
```
赚超过 0.8% 后启动追踪
```
**大白话**：赚钱了别高兴太早，跌破 0.8% 利润就得跑！

### 可调参数（12 个！）

| 参数 | 默认值 | 意思 |
|------|--------|------|
| buy_a_bbdelta_rate | 0.016 | 布林带要多宽才买 |
| buy_a_closedelta_rate | 0.0088 | 波动多大才买 |
| buy_a_tail_rate | 0.9 | 下影线多短才买 |
| buy_a_time_window | 21 | 布林带看几天 |
| buy_a_min_sell_rate | 1.03 | 卖出安全垫 |
| buy_b_close_rate | 0.979 | 价格离布林带下轨多远 |
| buy_b_ema_slow | 50 | 均线看几天 |
| buy_b_time_window | 20 | 布林带周期 |
| buy_b_volume_mean_slow_window | 30 | 成交量均线看几天 |
| buy_b_volume_mean_slow_num | 20 | 成交量萎缩多少倍 |
| sell_bb_middleband_window | 91 | 卖出看几天布林带 |
| sell_trailing_stop_positive_offset | 0.008 | 追踪止损触发点 |

**大白话**：这就是为什么叫 Hyper（超参数优化）版——参数多到自己都记不住！😅

## 三、买入条件：2 种模式，任选其一

这策略有两种买入模式，只要满足其中一个就触发买入：

### 🎯 模式 1：BinHV45（锤子形态 Plus）

**触发条件**（优化版）：
1. 布林带带宽要够宽（> 收盘价的 1.6%）
2. 价格波动要够大（> 收盘价的 0.88%）
3. 下影线要短（< 带宽的 90%）
4. **收盘价跌破布林带下轨**
5. **收盘价低于前一根**
6. 布林带中轨要高于收盘价的 1.03 倍

**大白话**：
> "价格跌到布林带下面去了，而且是个锤子形态（短下影线），上面还有布林带中轨撑着——这不稳了？买它！"

### 🎯 模式 2：ClucMay72018（缩量反弹 Plus）

**触发条件**（优化版）：
1. 价格在 EMA50 下方
2. 价格 < 布林带下轨的 97.9%
3. **成交量极度萎缩**（< 均量的 1/20）

**大白话**：
> "价格跌到布林带下面了，没人交易了（地量），这不正常吗？买它！"

**总结**：两种模式核心都是一个意思——"价格跌到布林带下面去了，可能要反弹！"

## 一、这策略是个啥？

简单说，**Strategy004** 就是一个：
- 专门找"跌过头"的机会
- 但不瞎抄底，要先确认有趋势
- 用两套随机指标做双重验证
- 趋势强+超卖=进场

就像一个老练的猎人，不会看到猎物就冲，而是先确认风向（趋势），再找到最佳伏击点（超卖），最后稳稳出手 🎯

---

## 二、核心配置：说白了就是"快进快出"

### 止盈规则（ROI 表）

```
持仓60分钟以上 → 赚1%就跑
持仓30-60分钟  → 赚3%就跑
持仓20-30分钟  → 赚4%就跑
一开仓就涨    → 赚5%就跑
```

**翻译**：这策略急性子，越快赚钱越急着跑。开仓后如果立马涨到5%，毫不犹豫离场。要是磨磨唧唧一小时才涨，1%也认了，赶紧撤退。

### 止损规则

```
固定止损：-10%
追踪止损：盈利2%后启动，回撤1%触发
```

**翻译**：给10%的容错空间，不是一亏就跑。但一旦赚了2%，就开始盯着——如果又跌回去1%，那就保住剩下的利润走人。

## 三、买入条件：一个信号，七个关卡

这策略的买入条件虽然只有一个信号，但里面藏了七个关卡，**每个都必须通过**：

### 🎯 关卡1：趋势强度确认

```python
(dataframe['adx'] > 50) | (dataframe['slowadx'] > 26)
```

**大白话**：
> "ADX超过50（超级强趋势），或者慢ADX超过26（起码有趋势），两个满足一个就行。没趋势？不玩。"

### 📉 关卡2：CCI超卖

```python
dataframe['cci'] < -100
```

**大白话**：
> "CCI指标低于-100，确实跌狠了。"

### 🎲 关卡3&4：双重随机超卖

```python
# 快速随机（5根K线）
fastk-previous < 20 且 fastd-previous < 20

# 慢速随机（50根K线）  
slowfastk-previous < 30 且 slowfastd-previous < 30
```

**大白话**：
> "快看——5根K线的随机指标双双低于20，这是短线超卖。
> 慢看——50根K线的随机指标双双低于30，中线也确认超卖。
> 两边都说'跌够了'，才算过关！"

### 🔀 关卡5：随机金叉

```python
fastk-previous < fastd-previous 且 fastk > fastd
```

**大白话**：
> "上一根K线，K线在D线下方；这一根K线，K线跑到D线上方去了——金叉！反弹开始了！"

### 💧 关卡6：成交量过滤

```python
dataframe['mean-volume'] > 0.75
```

**大白话**：
> "平均成交量得有0.75以上，太干的不碰。"

### 💰 关卡7：价格过滤

```python
dataframe['close'] > 0.00000100
```

**大白话**：
> "收盘价得超过0.00000100，太便宜的币不碰，流动性可能有问题。"

## 四、卖出逻辑：四重确认离场

### 4.1 卖出条件组合

```python
(slowadx < 25) &                    # 趋势弱了
((fastk > 70) | (fastd > 70)) &      # 随机指标超买了
(fastk-previous < fastd-previous) &  # 上一根K线K在D上
(close > ema5)                       # 价格还在均线之上
```

**大白话翻译**：

> "怎么卖？四个条件同时满足才走：
> 1. 慢ADX跌到25以下——趋势确实弱了
> 2. 快速K或D超过70——随机指标超买了
> 3. 上一根K线，K还在D上面——确认还没死叉
> 4. 价格还在EMA5上方——趁还在均线上面赶紧卖"

**吐槽**：这卖出条件有点"贪婪"，想在最高点附近离场。问题是市场不一定给你这个机会 😅

### 4.2 ROI止盈作为保底

如果卖出信号迟迟不来，ROI止盈会保底：
- 开仓20分钟内涨到5% → 自动止盈
- 持仓30分钟涨到3% → 自动止盈
- 持仓一小时只涨1% → 也认了，走人

## 五、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **不抄无趋势的底**：ADX过滤确保只在有趋势时进场，减少"接飞刀"风险
2. **双重随机验证**：快慢两个周期都确认超卖，信号更可靠
3. **成交量过滤**：不碰流动性差的币，避免滑点
4. **追踪止损保护**：赚了就保护起来，不让利润飞走

### ⚠️ 缺点（吐槽环节）

1. **条件太多太苛刻**：七个条件全满足才能进场，可能错过不少机会
2. **参数写死**：不支持优化，市场变了只能干瞪眼
3. **ADX滞后**：等ADX涨起来，趋势可能都走一半了
4. **卖得太"理想"**：想卖在最高点附近，实际可能卖不出去

## 十二、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

Strategy004 的历史回测表现可能**看起来不错**——但有个陷阱：

> **超卖反转策略最大的坑：超卖可以更超卖。**

简单说就是：**你觉得跌够了，市场告诉你"我还能跌"。**

### 复杂策略的隐藏风险

实盘时，复杂的逻辑可能导致：
- **信号稀少**：七个条件全满足太难，可能一天都没信号
- **错过行情**：条件太严，眼睁睁看着机会溜走
- **ADX滞后**：等ADX确认趋势，可能已经涨了一段
- **限价单风险**：急跌急涨时限价可能成交不了

### 我的建议（真心话）

```
1. 先模拟盘跑两周，看看实际信号频率
2. 如果信号太少，考虑放宽条件（自己改代码）
3. 别用在持续下跌的币上，抄底抄在半山腰
4. 止损严格执行，10%就是10%
5. 配合其他策略一起用，别单吊这个
```

## 二、核心配置：说白了就是"快进快出"

### 止盈规则（ROI 表）

```
持仓 0-10 分钟：赚 3.8% 就跑
持仓 10-40 分钟：赚 2.8% 也行
持仓 40-180 分钟：赚 1.5% 凑合
持仓 180 分钟以上：赚 1.8% 咱撤
```

**翻译**：这策略的核心哲学是"快"！越快赚到钱越好，时间越久越急着卖。

### 止损规则

```
硬止损：禁用默认止损（-99%，基本等于没设）
实际止损：自定义止损逻辑
跟踪止损：盈利超过 1% 后启动，止损线上移 2.5%
```

**翻译**：策略不设固定止损，但有一个50分钟的"观察期"。过了观察期还亏钱？那就根据情况决定要不要止损。

- **条件 4**：1 小时 RSI < 16.5 + 价格在布林下轨 → "大周期极度超卖，反弹概率高！"

### 📉 第 2 类：布林带下轨类（条件 1、2、12）

**核心逻辑**：价格接近或跌破布林下轨就买

**代表条件**：

## 五、卖出逻辑：50 分钟生死线

### 5.1 自定义止损（核心）

```python
if 持仓时间 < 50 分钟:
    不主动止损，给市场时间反转

if 持仓时间 >= 50 分钟:
    if 1 小时 RSI < 40:
        继续持有，等反弹
    elif 价格在 EMA200 之上 and 当前价格比开仓时跌了 2.5%:
        止损 1%，承认判断失误
    elif 当前价格比开仓时跌了 1.5%:
        止损 1%，认栽
```

**大白话**：
- **前 50 分钟**：不着急，给点时间让市场喘口气
- **50 分钟后**：
  - RSI 还是很低？那就等等，别止损在最低点
  - 还在跌？那就止损吧，承认这波判断错了

### 5.2 跟踪止损

```
盈利 > 1% 后激活跟踪止损
止损线跟随价格上涨，保持在盈利位往下 2.5%
```

**大白话**：赚了钱之后，策略会跟着价格涨，跌下来 2.5% 就自动卖出，保住利润。

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **信号丰富**：14 个条件，市场形态怎么变都有机会入场
2. **双重确认**：5 分钟入场 + 1 小时确认，减少假信号
3. **时间止损智能**：不是简单粗暴的固定止损，会根据 RSI 判断
4. **成交量过滤**：pumpdump 检测降低被骗的概率

### ⚠️ 缺点（吐槽环节）

1. **条件太多**：14 个条件×多个参数，优化难度极高
2. **交易频率高**：信号多意味着可能频繁交易，手续费肉疼
3. **参数固定**：没有自适应能力，不同市场可能需要手动调整
4. **只适合牛市**：所有条件都要求价格在 EMA200 之上，熊市基本废了

BcmbigzV1 的历史回测表现往往**看起来很美**——但这有个陷阱：

> **14 个条件×多个参数，很容易"拟合"过去行情的最优解，但这并不代表未来一定能盈利。**

简单说就是：**历史考试拿了满分，不代表高考能考好。**

### 复杂策略的隐藏风险

实盘时，14 个买入条件可能导致：
- **过度交易**：信号太多，手续费累积成山
- **参数敏感性**：某个阈值微调，结果天差地别
- **难以归因**：赚了不知道哪个条件赚的，亏了也不知道为什么

### 信号质量参差不齐

14 个条件不是每个都好用：
- 有些条件可能长期不触发
- 有些条件触发后胜率很低
- 你需要时间观察哪些条件靠谱

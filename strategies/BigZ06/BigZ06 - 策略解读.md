## 一、策略概览

**BigZ06** 是由开发者 ilya 创建的一个量化交易策略，灵感来源于 iterativ 的 CombinedBinHAndClucV6。该策略的核心设计理念是：**尽可能降低回撤，在低点买入，快速卖出获利**。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 14个独立条件 |
| **卖出条件** | ROI + 自定义止损 + 追踪止损 |
| **保护机制** | 自定义智能止损 |
| **时间框架** | 5分钟主周期 + 1小时辅助 |
| **建议持仓数** | 3-5个交易对 |

### 设计哲学

策略作者的四大核心目标：

1. **尽可能降低回撤**（Make drawdown as low as possible）
2. **在下跌时买入**（Buy at dip）
3. **快速卖出释放资金**（Sell quick as fast as you can）
4. **软性检测市场上涨，硬性检测市场下跌**

## 三、买入条件详解

BigZ06 包含14个独立的买入条件（buy_condition_0 至 buy_condition_13），每个条件都有独立的开关参数可调。

### 条件0：RSI超卖 + 趋势确认

- 收盘价在200日EMA上方（上升趋势）
- 5分钟RSI低于30（超卖）
- 过去3根K线呈下跌态势
- 1小时RSI低于71（中期不过热）

### 条件1：布林带下轨反弹 + 成交量萎缩

- 价格触及布林带下轨附近
- 成交量较前一根K线萎缩至3.8分之一
- 收盘为阴线（下跌后反弹）

### 条件2：布林带下轨买入

- 收盘价在布林带下轨以内（2%安全边际）
- 成交量萎缩

### 条件3：RSI深度超卖

- 5分钟RSI极低（14.2）
- 成交量大幅萎缩

### 条件4：1小时RSI超卖

- 1小时RSI极度超卖（16.5）
- 价格在布林带下轨

### 条件5-7：MACD金叉 + 布林带

- EMA26 > EMA12（短期均线在上）
- MACD柱状图为正
- 价格在布林带下轨

### 条件8-9：双RSI超卖

- 1小时RSI < 20
- 5分钟RSI < 28

### 条件10：1小时布林带下轨 + MACD反转

- 1小时K线处于布林带下轨
- MACD柱状图由负转正
- 5分钟RSI < 40.5

### 条件11：布林带收窄 + MACD连续上涨

- 布林带宽度收窄至10%以内
- MACD连续5根K线为正
- RSI > 51（偏强）

### 条件12：缩量阴线 + 布林带

- 价格短暂刺穿布林带下轨
- 收盘价收在下轨内部
- 阴线（卖压释放）

### 条件13：CMF资金流出 + RSI超卖

- Chaikin Money Flow 极度负值（-0.435）
- RSI < 22
- 长期趋势向上

## 四、卖出逻辑详解

### 4.1 主动卖出（Exit Signal）

当收盘价突破布林带中轨的101%时，触发卖出信号。策略作者注释"Don't be greedy, sell fast"。

### 4.2 ROI 阶梯止盈

| 持仓时间 | 止盈目标 |
|---------|---------|
| 立即 | 2.8% |
| 10分钟后 | 1.8% |
| 40分钟后 | 0.5% |
| 180分钟后 | 1.8% |

### 4.3 自定义止损（Custom Stoploss）

这是BigZ06最核心的风险管理机制：

| 情况 | 条件 | 止损幅度 |
|------|------|---------|
| 盈利中 | profit > 0 | 继续持有 |
| 交易>50分钟且RSI_1h<40 | 超卖 | 等待反弹 |
| 交易>50分钟且EMA200_1h上涨 | 上涨趋势 | 10%止损 |
| 交易>50分钟且价格续跌 | 下跌确认 | 1%止损 |

## 六、风险管理特色

### 6.1 多层防护体系

BigZ06 的风险管理堪称"三层防护"：

1. **第一层：买入筛选**
   - 14个条件从不同角度过滤买入信号
   - 强调成交量萎缩（卖压枯竭）
   - 要求趋势向上（EMA200）

2. **第二层：时间止损**
   - 50分钟后如果还在亏损，强制检视
   - 根据RSI和价格位置决定是否止损

3. **第三层：追踪止损**
   - 盈利后启动1%移动止损
   - 触发阈值2.5%

### 6.2 特色设计

- **默认止损禁用**（-99%）：完全依靠自定义逻辑
- **exit_profit_only = True**：只在盈利时卖出，防止割肉
- **快速卖出哲学**：0.5%就肯卖，不贪心
- **拒绝"套牢"**：50分钟后强制决策，不无限等待

## 七、策略优势与局限

### 优势

1. **回撤控制优秀**：策略核心目标就是低回撤
2. **多条件冗余**：14个独立条件，任何一个触发都能买入
3. **不依赖单一指标**：综合运用RSI、BB、MACD、成交量
4. **智能止损**：根据市场位置动态调整止损策略
5. **适合震荡市**：在下跌后买入的设计适合区间震荡

### 局限

1. **信号过于密集**：14个条件可能导致信号过多
2. **快速卖出可能错失大行情**：0.5%就止盈可能放跑黑马
3. **对交易对质量要求高**：需要波动性适中的币种
4. **参数固化**：默认值已经高度优化，调整空间有限
5. **复杂难懂**：14个条件的交互作用难以完全预测

## 十、重要提醒：复杂性的代价

### 策略复杂度的代价

BigZ06 是一个高度复杂的策略，14个买入条件意味着：

1. **难以回测优化**：条件之间的相互作用复杂
2. **过拟合风险**：历史表现可能过度依赖特定参数
3. **难以解释**：为什么在某个点位买入？
4. **难以手动干预**：信号逻辑不透明

### 建议

- **不要轻易修改参数**：默认值是作者长期优化的结果
- **充分回测**：在任何实盘前进行充分回测
- **小资金试错**：先用小资金验证
- **监控日志**：观察哪些条件在触发

## 十一、总结

BigZ06 是一个设计精巧的"买跌卖快"型策略，其核心理念是：

> **低回撤、买在回调、赚了就跑**

### 关键要点回顾

| 要点 | 内容 |
|------|------|
| 策略类型 | 均值回归/买跌型 |
| 持仓时间 | 短（分钟级） |
| 止盈目标 | 0.5%-2.8% |
| 风险控制 | 自定义止损+追踪止损 |
| 复杂度 | 高（14个条件） |

### 适合人群

- 追求稳定收益、厌恶大幅回撤
- 有耐心进行参数优化和回测
- 理解并接受"赚了就跑"理念

### 不适合人群

- 追求暴富、期望抓到十倍币
- 喜欢长线持有
- 无法接受频繁交易

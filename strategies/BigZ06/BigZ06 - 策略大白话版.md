## 一、这策略是个啥？

**BigZ06 = 一个"怕死"但"跑得快"的交易员**

这个策略的创始人 ilya（就一个老外程序员）被币圈割怕了，设计了这个策略。它的核心思想就三点：

1. **跌的时候买** —— 别追涨，要抄底
2. **涨了就跑** —— 别贪心，见好就收
3. **赶紧跑，别套牢** —— 亏了别死扛，50分钟内决定割不割

简单说就是：**低买快卖，不贪心，死命控回撤**。

## 四、保护机制：3层"防弹衣"

每个买入条件都配了一套保护参数，就像穿了3层防弹衣：

| 保护类型 | 作用 | 大白话 |
|---------|------|--------|
| 买入筛选 | 必须成交量萎缩 + 在EMA200上方 | "别接飞刀，要顺势抄底" |
| 50分钟时间止损 | 持仓超过50分钟还亏就开始判断 | "给你50分钟表现，不行就割" |
| 追踪止损 | 盈利后启动移动止损 | "赚了别吐回去" |

**50分钟止损逻辑**：这是最特色的设计！

```
持仓超过50分钟还在亏钱 → 强制检查：
├─ 如果1小时RSI还在40以下 → 不割，等反转
├─ 如果价格比开盘跌了3.5%以上 → 割！亏1%
└─ 如果价格比开盘跌了2.5%以上 → 割！亏1%
```

**大白话**：持仓50分钟后要么反弹，要么认亏1%跑路，绝不一直套着。🤣

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

BigZ06的历史回测表现往往不错——但这有个陷阱：

> **因为参数多，策略很容易"拟合"过去行情，但这并不代表未来一定能盈利。**

简单说就是：**背答案的学生，换个题目可能就不会了。**

### 复杂策略的隐藏风险

实盘时，复杂的逻辑可能导致：
- **市价单滑点**：高波动时买在比报价高5-10%的地方
- **小币种流动性**：某些币根本买不进去、卖不出来
- **参数固化**：默认值是作者回测很久的结果，新手别乱改
- **回测≠实盘**：回测赚钱不代表实盘赚钱
- **频繁交易**：策略交易频率不低，手续费成本要算进去

### 我的建议（真心话）

```
1. 先模拟盘至少跑1个月
2. 小资金起步，别超过总资金20%
3. 设置总亏损报警，超过10%暂停
4. 定期复盘，该优化优化
5. 别把所有钱押一个策略上
```

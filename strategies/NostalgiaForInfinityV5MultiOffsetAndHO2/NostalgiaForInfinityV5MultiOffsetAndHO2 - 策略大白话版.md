## 二、核心配置：说人话版

### 2.1 止盈止损（简单粗暴）

```
止盈：赚 1% 就考虑跑
止损：亏 10% 强制割
追踪止损：赚了 3% 后启动，回撤 1% 就走
```

**翻译**：
- **止盈**：这货不贪心，1%就开始考虑落袋为安
- **止损**：10%的止损比一般的策略（25%）要紧不少，保护资金
- **追踪止损**：赚够了就开始保护利润，不让到手的肥肉飞了

### 2.2 多偏移均线系统（核心黑科技）

这策略有个独门绝技：**5种均线，每种都有"买入价"和"卖出价"**

| 均线类型 | 买入价格（偏低） | 卖出价格（偏高） | 啥意思 |
|---------|-----------------|-----------------|-------|
| SMA | ×0.919 | ×1.047 | 简单均线，买卖价差8%左右 |
| EMA | ×0.983 | ×1.059 | 指数均线，反应更快 |
| TRIMA | ×0.943 | ×1.014 | 三角均线，更平滑 |
| T3 | ×0.975 | ×1.072 | 超平滑均线 |
| KAMA | ×0.962 | ×1.081 | 自适应均线，自己调整敏感度 |

**大白话翻译**：
> 比如SMA均线的价格是100块
> - 买入价 = 100 × 0.919 = 91.9块（等跌到这儿才买）
> - 卖出价 = 100 × 1.047 = 104.7块（涨到这儿就卖）

**这就是"抄底逃顶"的量化版本！**

## 三、保护机制：三道防火墙

这策略有三道"保命符"，确保你不被市场毒打：

### 3.1 下跌保护（safe_dips）

**目的**：不在暴跌过程中抄底

```
三个级别：
- 标准：允许跌 2% → 14% → 32% → 50%（逐步放宽）
- 严格：允许跌 1.5% → 6% → 24% → 40%（更紧）
- 宽松：允许跌 2.6% → 24% → 42% → 66%（更宽）
```

**比喻**：就像接飞刀，不会在刀刚飞出去的时候接，要等刀落地了再捡 🗡️

### 3.2 暴涨保护（safe_pump）

**目的**：不在暴涨后追高

```
三个时间段（24/36/48小时）：
- 标准：如果涨幅超过 50%/56%/85%，或者没回调，就不买
- 严格：涨幅超过 40%/56%/68% 就不碰
- 宽松：涨幅超过 66%/70%/130% 才不碰
```

**比喻**：这币刚涨了50%？别追了，等回调再进！🚀

### 3.3 追踪止损

```
机制：
- 先赚够 3%
- 然后开启"保镖模式"
- 价格回撤 1% 就跑
```

**比喻**：赚到钱了，就雇个保镖盯着，一有风吹草动就带着钱跑 💰

## 四、26个买入条件：说人话版

是的，你没看错，**26个买入条件**！这策略简直是"选择困难症"晚期患者设计出来的 😅

让我给你分类说说：

### 4.1 第一类：趋势确认型（条件1-4）

**共同特点**：必须确认大趋势向上才动手

**条件#1**（严格下跌捕捉）：
> "1小时EMA金叉 + 5分钟RSI超卖 + 严格保护机制 = 入场"

**大白话**：
> 大盘在涨，但这币短期跌多了，正好抄个底！

**条件#2**（布林带反弹）：
> "1小时RSI - 5分钟RSI > 39 + 价格低于布林下轨 = 入场"

**大白话**：
> 大盘还凑合，但这币短期暴跌到布林带下面了，可能反弹！

**条件#3**（BB40形态）：
> "布林带够宽 + 价格波动明显 + 下影线不太长 + 收盘低于下轨 = 入场"

**大白话**：
> 这是一种经典的"布林带下轨反弹"形态！

**条件#4**（低成交量反弹）：
> "成交量低 + 价格低于布林下轨 = 入场"

**大白话**：
> 大家都不关注了，正好悄悄进场 👀

### 4.2 第二类：EMA分离型（条件5-8）

**核心逻辑**：EMA26和EMA12的分离程度

**条件#5**（标准EMA分离）：
> "EMA26比EMA12高 1.9% + 价格低于布林下轨 = 入场"

**大白话**：
> 短期均线跑太快，偏离长期均线了，可能会回归！

### 4.3 第三类：MA偏移策略（条件9-11）

**核心逻辑**：利用偏移均线寻找入场点

**条件#9**：
> "价格低于EMA20×0.97 + 低于布林下轨×0.985 = 入场"

**大白话**：
> 等价格跌到EMA20下面3%再买，稳！

### 4.4 第四类：EWO波浪策略（条件12-17）

**核心指标**：Elliott Wave Oscillator（艾略特波浪震荡器）

**条件#12**（EWO高值）：
> "EWO > 2 + RSI < 30 = 入场"

**大白话**：
> 波浪指标显示还在上升通道，但短期超卖了，好机会！

**条件#13**（EWO低值）：
> "EWO < -10.4 = 入场"

**大白话**：
> 波浪指标负值太大，可能触底反弹！

### 4.5 第五类：综合过滤型（条件14-18）

**特点**：条件最多，确认最严格

**条件#18**（最严格）：
> "7个趋势确认 + 下跌保护 + 暴涨保护 + RSI < 26 + 低于布林下轨"

**大白话**：
> 这是最"处女座"的入场条件，所有检查清单都打勾才动手！

### 4.6 第六类：EMA穿越型（条件19）

**条件#19**：
> "前一根K线在EMA100上方 → 本根K线下探EMA100 → 收盘回到EMA100上方"

**大白话**：
> 这叫"假跌破"或"探底回升"，经典的支撑位测试形态！

### 4.7 第七类：极端RSI型（条件20-21）

**条件#20**：
> "5分钟RSI < 26 + 1小时RSI < 20 = 入场"

**条件#21**：
> "5分钟RSI < 23 + 1小时RSI < 24 = 入场"

**大白话**：
> 两眼一闭，RSI跌到姥姥家了，搏反弹！

### 4.8 第八类：多偏移MA型（5个条件）

**核心逻辑**：为每种均线各设一个买入条件

```python
for 均线 in [SMA, EMA, TRIMA, T3, KAMA]:
    if 价格 < 偏移买入价 AND (EWO极端高 OR EWO极端低):
        买入！
```

**大白话**：
> 5条均线，哪条触发了都买，增加机会！

## 十一、这策略的"小心思"

### 11.1 EWO指标的双向使用

一般策略只用EWO的正值或负值，这策略两个都用：
- EWO > 7.714：趋势延续时买入
- EWO < -16.744：触底反弹时买入

**比喻**：左右开弓，两边都捞 🎯

### 11.2 RSI的反向使用

传统用法：RSI < 30买入，RSI > 70卖出
这策略：在某些条件下，RSI > 70也买！

**原因**：强者恒强，强势币可能继续涨

### 11.3 多时间框架协同

1小时：告诉你要不要进场（大趋势）
5分钟：告诉你什么时候进场（精确入场）

**比喻**：将军下令，士兵执行 👨‍✈️

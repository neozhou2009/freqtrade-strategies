# Stinkfist 策略：波动市场的"深潜捕手"

> **外号**：深潜捕手  
> **职业**：波动市场抄底专家  
> **时间框架**：5 分钟（主）+ 1 小时（辅助）

## 一、这策略是个啥？

简单说，**Stinkfist** 就是一个：
- 擅长在波动中找机会的"抄底型"策略
- 有专门的加仓逻辑（持仓越久，加仓门槛越高）
- 自带三层价格保护机制
- 居然还有 BTC 和 ETH 的专属版本

就像一个**经验丰富的深潜捕手** 🤿——在水面观察（1小时信息层）确定下潜位置，然后潜入水中（5分钟执行）捕捉猎物。而且这家伙还特别谨慎，入水前要查三遍安全装备！

## 二、核心配置：说白了就是"稳健抄底"

### 止盈规则（ROI 表）

```
时间        利润目标
────────────────────
即刻        5%
10 分钟     2.5%
20 分钟     1.5%
30 分钟     1%
12 小时     0.5%
24 小时     平仓走人
```

**翻译**：刚买进去，目标 5% 利润。时间越久，目标越低——有点像你追姑娘，追太久热情就下降了。

### 止损规则

```
止损线：-40%
```

**翻译**：40% 的硬止损！这很宽松。就像你老妈说"亏 40% 再回家找我"——给足了容错空间。但也意味着如果真的止损，会很疼 😅

## 三、买入条件：两个场景两套逻辑

这策略有**两套买入逻辑**，我来给你拆解：

### 🎯 场景 1：新开仓（4 个条件必须同时满足）

**核心逻辑**：在 3 天低点附近找机会

**大白话**：
> "等价格跌到 3 天低点 + 80% 波动范围的位置，动量指标显示超卖，连续下跌开始反弹，且均线形成金叉——然后才敢入场。"

**4 个条件详解**：

| 条件 | 大白话翻译 |
|------|-----------|
| 价格位置 | 价格 ≤ 3 天最低价 + 80% 日波动范围（抄底区域） |
| Momentum Pinball < 30 | 动量指标显示超卖状态 |
| Streak ROC > 下轨 | 连续变化率开始回升 |
| MA Cross == 1 | 均线金叉确认趋势反转 |

### 🔄 场景 2：加仓（动态增长逻辑）

**核心逻辑**：根据持仓时间和利润决定是否加仓

**大白话**：
> "已经买了？那就看看情况。持仓时间越久，加仓门槛越高（RMI 从 30 涨到 70）。而且你当前这笔交易还得赚钱才能加仓——亏钱了就别想加仓了！"

**动态门槛表**：

| 持仓时间 | RMI 门槛 | 能否加仓条件 |
|---------|---------|-------------|
| 0 分钟 | 30 | 比较容易 |
| 3 小时 | 50 | 中等难度 |
| 6 小时 | 60 | 比较难 |
| 12 小时 | 70 | 很难 |

## 四、保护机制：三层"防坑"设计

每个买入都配了三层保护，就像三道保险：

| 保护类型 | 作用 | 大白话 |
|---------|------|--------|
| 入场价格保护 | 订单价格与当前价格偏差 > 1% 时拒绝 | "别想滑点坑我！" |
| 买入超时检查 | 价格偏离 > 1% 时取消订单 | "价格变了？不要了！" |
| 卖出超时检查 | 价格偏离 < 1% 时取消订单 | "价格变了？不卖了！" |

这就像你去买东西：
1. **入场前**：先问价，如果现在价格比标价贵 1% 以上，扭头就走
2. **下单后**：如果价格又变了，干脆取消订单
3. **卖的时候**：同样的逻辑，防止被坑

## 五、卖出逻辑：看情况"跑"

### 5.1 动态止损：持仓越久止损越紧

```
持仓时间      止损阈值
─────────────────────
0 分钟        -3%
300 分钟      0%（盈利才能卖）
```

**大白话**：
- 刚买入：允许亏 3% 再跑
- 持仓 5 小时：必须盈利才能卖（动态门槛变成 0%）

这是在告诉你：**持仓越久，越要严格止损——别死扛！**

### 5.2 卖出信号组合

| 条件 | 大白话 |
|------|--------|
| RMI 趋势反转 | RMI 趋势向下了 |
| 利润判断 | 有利润时 RMI < 50 就跑，没利润时 RMI < 10 就跑 |
| 全局仓位管理 | 有其他持仓时，会综合考虑要不要卖这个 |

### 5.3 全局视角：这策略会"看大局"

```python
# 策略会跟踪所有持仓
other_trades = 其他交易数量
avg_other_profit = 其他交易平均利润
biggest_loser = 当前是不是亏最多的那个
free_slots = 还剩多少空仓位
```

**大白话**：
> "这策略会看你所有持仓的情况。如果你这笔是最亏的，它会优先处理。如果还有空仓位，可能就再等等。"

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **谨慎抄底**：三层价格保护，不是看到低价就冲
2. **动态调整**：持仓时间越久，门槛越高——防止无脑加仓
3. **全局视角**：看所有持仓的综合表现，不是孤立判断
4. **专属版本**：BTC 和 ETH 都有优化过的参数版本
5. **信息层辅助**：用 1 小时框架辅助判断，视野更开阔

### ⚠️ 缺点（吐槽环节）

1. **止损太宽**：40% 的止损，真触发会很肉疼
2. **复杂度高**：自定义指标一堆，出问题很难排查
3. **加仓风险**：趋势逆转时加仓可能放大亏损
4. **依赖实时数据**：频繁获取价格和订单簿，对 VPS 要求高

实盘和回测可能有差异：

- **全局仓位管理**：回测可能无法完全体现

**建议流程**：
1. 先用默认参数回测
2. 再用单交易对干跑测试
3. 确认价格保护机制正常工作
4. 逐步扩展到多交易对

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

Stinkfist 的历史回测表现可能**很好看**——但有个陷阱：

> **复杂的策略容易"拟合"过去行情的最优解，但这并不代表未来一定能盈利。**

简单说就是：**历史成绩单不代表期末考试分数！**

### 复杂策略的隐藏风险

实盘时，复杂的逻辑可能导致：
- **价格保护频繁触发**：价格波动大时订单可能总被取消
- **加仓时机不理想**：趋势逆转时加仓放大亏损
- **API 调用过多**：频繁获取价格可能导致限流

### 我的建议（真心话）

```
1. 从 BTC 或 ETH 专属版本开始测试
2. 初始只用 1-2 个交易对
3. 设置比 40% 更紧的止损（比如 -20%）
4. 观察价格保护机制的触发频率
5. 确认能接受再扩大规模
```

**记住**：波动市场是机会，也是陷阱。策略再好，市场教做人时也不会打招呼。轻仓测试，活着最重要！🙏

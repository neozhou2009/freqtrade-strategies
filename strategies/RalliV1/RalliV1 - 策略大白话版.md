# RalliV1 策略：选择困难症晚期患者的杰作

> **外号**：六条件狂魔、参数调优师的最爱
> **职业**：什么都想要，什么都不放过
> **时间框架**：5 分钟（主）+ 1 小时（信息层）

---

## 一、这策略是个啥？

简单说，**RalliV1** 就是一个：
- 有 **6 个买入条件** 的复杂策略
- 有 **12 个可调参数** 的调优狂魔
- 用了一堆技术指标（EMA、SMA、HMA、RSI、EWO...）
- 为了"不错过任何机会"而生的策略

就像一个**相亲要求清单写了三页纸**的人：要帅、要有钱、要温柔、要幽默、要会做饭、要...结果就是——**条件太多，反而很难找到满意的** 🤣

## 二、核心配置：说白了就是"层层加码"

### 止盈规则（ROI 表）

```
时间        利润目标
────────────────────
0 分钟      4%      → 刚买入就想赚 4%
40 分钟     3.2%    → 没赚到就降低期望
87 分钟     1.8%    → 再降一点
201 分钟    0%      → 算了，随便吧
```

**翻译**：刚买入时信心满满，想着要赚 4%；时间久了就开始佛系，"赚点就行"；最后干脆让追踪止损来决定。

就像谈恋爱：
- 刚认识：我要找完美的另一半！
- 3 个月后：差不多就行...
- 半年后：能过日子的就行 🤣

### 止损规则

```
固定止损：亏 30% 割肉（这心真大...）
追踪止损：盈利 3% 后启动，回撤 0.5% 触发
自定义止损：持仓 140 分钟没利润 → 0.5% 紧止损
```

**翻译**：
- 固定止损 30%，这心理素质，一般人扛不住
- 但有追踪止损保护，盈利 3% 后就开始"落袋为安"
- 如果持仓 2 个多小时还没赚到钱，直接收紧止损跑路

## 三、6 个买入条件：我帮你分类好了

这策略的买入条件**多得离谱**，我给你归了 3 类：

### 🎯 第 1 类：下跌趋势组（3 个条件）

**核心逻辑**：MA < EMA100，下跌趋势中找反转机会

**大白话**：
> "现在是下跌趋势，价格被打压了。我要找那种 EWO 显示可能反转、RSI 显示超卖的时机买入。"

**代表条件**：条件 #1、#2、#3

**经典台词**：
- **条件 #1**：`MA < EMA100 且 close < MA * 0.975 且 EWO > 2.327`
  > "跌是跌了，但 EWO 显示有反弹迹象，抄底吧！"

- **条件 #2**：`MA < EMA100 且 close < MA * 0.955 且 RSI < 25`
  > "跌得更惨了！RSI 都低于 25 了，这次真的到底了！"

- **条件 #3**：`MA < EMA100 且 EWO < -20.988`
  > "EWO 都跌到负值极点了，反弹肯定要来！"

---

### 📈 第 2 类：上涨趋势组（3 个条件）

**核心逻辑**：MA > EMA100，上涨趋势中找回调买入

**大白话**：
> "现在是上涨趋势，等它回调的时候买进去。"

**代表条件**：条件 #4、#5、#6

**经典台词**：
- **条件 #4**：`MA > EMA100 且 close < MA * 0.975 且 RSI < 60`
  > "上涨趋势中的回调机会！RSI 还没到超买，可以买！"

- **条件 #5**：`MA > EMA100 且 close < MA * 0.955 且 RSI < 25`
  > "涨得好好的突然大跌？抄底！"

- **条件 #6**：`MA > EMA100 且 EWO < -20.988`
  > "上涨趋势中 EWO 变负值了，这是捡漏的好机会！"

---

### 🔧 第 3 类：特殊条件组

**贯穿所有条件的公共要求**：

| 条件 | 阈值 | 大白话 |
|------|------|--------|
| RSI_fast | 4 < x < 35 | 快速 RSI 不能太极端 |
| volume | > 0 | 必须有成交量 |
| close | < ma_sell * high_offset | 价格不能太高 |

**翻译**：不管哪个条件，都得满足"成交量正常"、"RSI 别太极端"、"价格别太高"这三个基本要求。

## 四、保护机制：4 层"保险丝"

这策略有四层止损保护，就像四道保险丝：

| 保险丝 | 触发条件 | 大白话 |
|---------|---------|--------|
| ROI 止盈 | 利润达标 | "赚到目标了，跑！" |
| 追踪止损 | 盈利 3% 后回撤 0.5% | "利润缩水了，保住本金！" |
| 自定义止损 | 持仓 140 分钟无利润 | "拿了半天没赚到钱，止损！" |
| 固定止损 | 亏 30% | "认栽了，割肉！" |

这设计很实用：**能赚就赚，赚不到就止损，绝不死扛！** 但 30% 的固定止损确实有点狠 😅

## 五、卖出逻辑：比买入还花哨

### 5.1 卖出信号（2 个条件）

**条件 #1：上涨趋势确认退出**
```
HMA50 > EMA100 且
close > SMA9 且
close > ma_sell * 1.0 且
RSI_fast > RSI_slow
```

**大白话**：
> "价格上涨突破了均线，而且 RSI 动能向上，涨得差不多了，跑吧！"

**条件 #2：下跌趋势退出**
```
close < EMA100 且
close > ma_sell * 0.991 且
RSI_fast > RSI_slow
```

**大白话**：
> "本来是下跌趋势，但价格反弹了一点，趁早跑吧！"

### 5.2 卖出确认：会"拒绝"卖出的策略

这策略有个 `confirm_trade_exit` 函数：

```python
if RSI < 45 且 HMA50 > EMA100:
    return False  # 拒绝卖出！
```

**大白话**：
> "等等！虽然卖出信号触发了，但 RSI 还没到 45，而且趋势还在向上，我再拿一会儿！"

这就像：你女朋友说"我们分手吧"，你说"不，我觉得还有救" 🤣

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **信号多**：6 个买入条件，基本什么行情都能找到入场机会
2. **参数可调**：12 个参数可以优化，适配不同品种
3. **智能止损**：自定义止损函数，不会傻傻死扛
4. **有主见**：卖出确认机制，上涨趋势中拒绝轻易卖出
5. **EWO 创新**：用 Elliott Wave 振荡器判断趋势，有点意思

### ⚠️ 缺点（吐槽环节）

1. **太复杂了**：6 个买入条件 + 12 个参数，看着就头大
2. **容易过拟合**：参数越多，越容易"背答案"
3. **计算量大**：EMA、HMA、EWO 一堆指标，CPU 压力山大
4. **条件重叠**：有些条件其实差不多，感觉是为了凑数
5. **1 小时时间框架没用**：代码里声明了但没实际用，占着茅坑不拉屎

## 八、总结：这策略到底咋样？

### 一句话评价
> "条件多到记不住，参数多到调不完，但设计思路值得学习。"

### 适合谁用？
- ✅ 参数调优爱好者（12 个参数等你调）
- ✅ 量化研究者（学习复杂策略设计）
- ✅ 有耐心的玩家（需要反复回测优化）
- ✅ 资金量大的玩家（多品种分散风险）

### 不适合谁？
- ❌ 新手（太复杂，容易搞混）
- ❌ 追求简单的玩家（代码 300+ 行）
- ❌ 讨厌调参的玩家（12 个参数头都大）
- ❌ 小资金玩家（手续费可能吃掉利润）

### 我的建议
1. **先用默认参数**：别急着调，先看看基准表现
2. **分批调参**：一次只调 1-2 个参数，别一次调太多
3. **Walk-Forward 分析**：验证参数稳定性，避免过拟合
4. **控制仓位**：策略再好，也别梭哈

## 十、想跑这个策略？先看看这些配置

### 10.1 交易对配置

| 配置项 | 建议值 | 吐槽 |
|--------|--------|------|
| 交易对 | 5-20 个 | 别太多，计算量会爆炸 |
| 时间框架 | 5m | 默认就好，别改 |
| 起动 K 线数 | 200 | 需要 200 根 K 线计算指标 |

### 10.2 配置文件关键设置

```yaml
# 止损
stoploss: -0.30  # 30% 止损，心真大

# 追踪止损
trailing_stop: true
trailing_stop_positive: 0.005
trailing_stop_positive_offset: 0.03
trailing_only_offset_is_reached: true

# 卖出设置
use_sell_signal: true
sell_profit_only: true
sell_profit_offset: 0.01
```

### 10.3 硬件要求（重要！）

这策略计算量**巨大**，对 VPS 内存有要求：

| 交易对数量 | 最低内存 | 推荐内存 | 体验 |
|-----------|---------|---------|------|
| 1-10 个 | 2GB | 4GB | 还行 |
| 10-30 个 | 4GB | 8GB | 有点卡 |
| 30+ 个 | 8GB | 16GB | 老电脑可能扛不住 |

**警告**：交易对太多的话，计算可能超时，5 分钟 K 线可能来不及算完！😅

### 10.4 回测 vs 实盘

**回测很美好**，实盘要小心：
- 参数多 → 容易过拟合历史数据
- 条件复杂 → 实盘可能表现和回测不一样
- 计算量大 → 实盘可能延迟

**建议流程**：
1. 用默认参数回测，看看基准表现
2. 用 Walk-Forward 分析，验证参数稳定性
3. 模拟盘测试，验证实盘表现
4. 小仓位实盘，确认效果后放大

**别一上来就梭哈**，复杂策略更容易出问题！

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

RalliV1 的历史回测表现可能**极其优异**——但这有个陷阱：

> **因为参数众多，策略很容易"拟合"过去行情的最优解，但这并不代表未来一定能盈利。**

简单说就是：**你是在背答案，不是在学知识。** 😅

### 复杂策略的隐藏风险

实盘时，复杂的逻辑可能导致：
- **计算延迟**：K 线更新了但指标还没算完
- **信号冲突**：多个条件可能给出矛盾的信号
- **参数不稳定**：今天最优的参数，明天可能就废了
- **过拟合风险**：越复杂的策略，越容易过拟合历史数据

### 我的建议（真心话）

```
1. 先用默认参数，别急着优化
2. 用 Walk-Forward 分析验证参数稳定性
3. 模拟盘至少跑 1 个月
4. 实盘仓位控制在总资金的 10% 以内
5. 如果连续亏损，立刻停止，重新评估
```

**记住**：策略再好，市场教做人时也不会打招呼。轻仓测试，活着最重要！

**最后提醒**：复杂策略就像精密仪器，看起来很厉害，但也更容易坏。简单可靠，往往比复杂完美更重要！🙏

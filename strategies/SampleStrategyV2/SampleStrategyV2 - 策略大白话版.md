## 一、这策略是个啥？

简单说，**SampleStrategyV2** 就是一个：
- 官方提供的示例策略（真的就是教材）
- 1个买入条件 + 1个卖出条件（干净利落）
- RSI超卖反弹 + TEMA动量确认 + Heikin Ashi趋势
- 3个Hyperopt参数可以调优

就像一本量化交易的入门教科书，不复杂，但教的东西都是干货 📖

## 二、核心配置：说白了就是"简单粗暴"

### 止盈规则（ROI 表）

```
刚买入 → 利润 4% 就跑
30分钟后 → 利润 2% 就跑
60分钟后 → 利润 1% 就跑
```

**翻译**：时间越久利润目标越低，这设计和复杂策略一样，就是不贪。

### 止损规则

```
固定止损：-20%
追踪止损：利润1%后启动，回落0.5%就锁利
```

**翻译**：止损20%比较宽松，适合波动大的加密货币。追踪止损是保护小幅利润。

## 三、买入条件：一个就够！

### 🎯 唯一的买入信号

**核心逻辑**：RSI超卖反弹 + TEMA低位上升 + HA趋势向上

**大白话**：
> "RSI跌到30以下然后反弹，TEMA在布林带下轨附近开始上升，Heikin Ashi趋势向上，成交量不为零。"

**详细拆解**：

| 子条件 | 代码 | 大白话 |
|-------|------|--------|
| **RSI穿越** | crossed_above(rsi, 30) | "RSI从30以下穿上来，超卖开始反弹" |
| **趋势向上** | trend_dir > 0 | "Heikin Ashi趋势方向是向上的" |
| **TEMA低位** | tema <= bb_middleband | "TEMA在布林带中轨以下，位置不高" |
| **TEMA上升** | tema > tema.shift(1) | "TEMA正在往上走，动量转强" |
| **有成交量** | volume > 0 | "市场有活动，不是死币" |

**一句话**：
> "RSI说可以买，TEMA说正在上涨，HA说趋势向上，那就买吧！"

## 五、技术指标：这策略用的家伙

### 核心武器

| 指标 | 用途 | 大白话 |
|------|------|--------|
| **RSI(14)** | 超买超卖判断 | "情绪指标，太低买太高卖" |
| **TEMA(9)** | 三重指数均线 | "快速均线，反应灵敏" |
| **布林带(20)** | 波动边界 | "价格走廊，上轨卖下轨买" |
| **Heikin Ashi** | 价格平滑 | "平滑K线，噪音少" |
| **MACD(1h)** | 大周期趋势 | "1小时趋势方向" |
| **ADX** | 趋势强度 | "趋势强不强" |

### Heikin Ashi 是啥？

**大白话解释**：
Heikin Ashi 是一种特殊的K线平滑技术。普通K线波动大，噪音多。Heikin Ashi把价格平均化，让趋势更清晰。

就像给照片加了"降噪滤镜"，趋势看得更清楚。

**trend_dir 怎么算**：
```
趋势方向 = SMA(SMA(ha_close_sma288 - ha_open_sma288, 5), 5)
```

> 计算HA收盘和开盘的差值，再双重平滑。大于0就是上升趋势。

### ✅ 优点（夸夸环节）

1. **结构清晰**：代码简洁，适合学习

### ⚠️ 缺点（吐槽环节）

1. **买入太少**：只有一个信号，可能错过机会
2. **止损宽松**：20%止损有点大，亏钱可能多
3. **保护不足**：没有暴涨保护、EMA过滤等安全措施
4. **信号稀疏**：条件严格，信号可能不够多

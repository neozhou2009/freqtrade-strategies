## 五、卖出逻辑：比买入更花哨

### 5.1 分级止盈：赚多少跑

```
利润 ≥ 20% → RSI < 30 就跑（让利润飞一会儿）
利润 12%-20% → RSI < 42 就跑（差不多得了）
利润 10%-12% → RSI < 46 就跑（落袋为安）
利润 9%-10% → RSI < 50 就跑（有点赚就行）
...
利润 1.2%-2% → RSI < 34 + CMF<0 才跑（小利也要看指标）
```

**大白话**：
- 赚得多 → 心态稳，让 RSI 再高点才跑
- 赚得少 → 心态慌，RSI 稍微降点就跑
- CMF<0 → 资金在流出，小利也跑

就像打麻将：
> 赢得多时手气好，多打几把；赢少时赶紧收手，别贪！🀄

### 5.2 空头市场止盈（价格在 EMA200 之下）

在空头市场，止盈更激进：

```
利润 9%-10%：
  → RSI < 52 就跑，或者 RSI > 82 也跑！

利润 7%-8%：
  → RSI < 54 就跑，或者 RSI > 80 也跑！
```

**大白话**：
> "在熊市里，反弹随时可能结束。RSI 高了赶紧跑，RSI 低了也赶紧跑——横竖就是赶紧跑！🏃"

### 5.3 Pump 专用止盈

```
如果 48 小时涨幅 > 90%（暴涨币）：
  利润 ≥ 20% → RSI < 30 就跑
  利润 10%-20% → RSI < 34 就跑
  ...
  利润 1%-2% → RSI < 34 就跑
```

**大白话**：
> "这币涨太猛了，随时可能崩。哪怕只赚 1%，RSI 一降赶紧跑！🚀"

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **防御性强到变态**：44 层保护参数，几乎不可能在错误时机入场——除非你故意把所有保护都关了 😅

2. **信号种类丰富**：趋势跟踪、均值回归、布林带回踩、一目均衡表...想要啥类型都有

3. **止盈非常智能**：分级止盈 + 追踪止盈 + 特殊场景退出，不会让你"坐过山车"

4. **社区验证过**：Freqtrade 生态最出名的开源策略之一，经过大量实盘检验

5. **高度可定制**：44 个条件每个都能独立开关，想用哪个用哪个

### ⚠️ 缺点（吐槽环节）

1. **复杂到想哭**：4000+ 行代码，44 个买入条件，光是理解就要好几天。新手看到可能直接劝退 😭

2. **计算量大**：需要 480 根 K 线预热，计算一大堆指标。老电脑可能会卡成 PPT 💻

3. **过拟合风险**：参数这么多，很容易"背答案"——对历史数据表现完美，对未来一塌糊涂 📚

4. **回测欺骗性强**：回测效果通常极好，但实盘可能差一大截（滑点、延迟、流动性问题）

5. **学习曲线陡峭**：想完全搞懂这个策略，没有 1-2 个月下不来

## 十、想跑这个策略？先看看这些配置

### 10.1 交易对配置

| 配置项 | 建议值 | 吐槽 |
|--------|--------|------|
| 交易对数量 | 40-80 对 | 少了信号不够，多了算不过来 |

| 黑名单 | *BULL, *BEAR 等杠杆代币 | 这些代币波动太大，策略扛不住 |

### 10.2 配置文件关键设置

```yaml
# config.json 关键设置
"timeframe": "5m"              # 必须 5m
"use_sell_signal": true        # 必须开启
"sell_profit_only": false      # 必须关闭
"ignore_roi_if_buy_signal": true  # 必须开启
```

**翻译**：这些设置搞错了，策略会跑偏。就像汽车加错油，跑是能跑，但发动机要废 ⛽

### 10.3 硬件要求（重要！）

这策略计算量巨大，对 VPS 内存有要求：

| 交易对数量 | 最低内存 | 推荐内存 | 体验 |
|-----------|---------|---------|------|
| 40-60 对 | 4GB | 8GB | 勉强能用 |
| 60-80 对 | 8GB | 16GB | 流畅 |
| 80+ 对 | 16GB | 32GB | 舒服 |

**警告**：内存不足会导致计算超时，错过交易机会。别为了省钱买个 2GB VPS，到时候亏的比省的多 😅

### 10.4 回测 vs 实盘

**回测效果**：通常极好。因为 44 个条件总有一些能"命中"历史最佳入场点。

**实盘效果**：可能差一大截。原因：
- 滑点：实际成交价和理论价不一样
- 延迟：信号发出到实际成交有时间差
- 流动性：有些币想卖的时候没人接盘

**建议流程**：
1. 先回测，理解策略逻辑
2. 再纸面交易（dry_run），验证实时表现
3. 小仓位实盘，逐步放大
4. 定期复盘，调整参数

**别一上来就梭哈**，策略再好也得磨合！

2. **重视保护机制**：safe_dips（别在暴跌中接飞刀）和 safe_pump（别追高）的理念非常实用

### 复杂策略的隐藏风险

实盘时，复杂的逻辑可能导致：

- **计算延迟**：信号太多，计算耗时，错过最佳入场点
- **过拟合陷阱**：历史表现完美，实盘一塌糊涂
- **参数敏感**：改一个参数，表现天差地别
- **维护困难**：出问题了不知道哪个条件有 bug

4. 小仓位实盘验证，逐步放大

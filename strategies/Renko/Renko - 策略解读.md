## 一、策略概览

Renko 是一个基于 Renko 砖块图（Renko Chart）的趋势跟踪策略。Renko 图是一种特殊的图表形式，只关注价格变化而忽略时间因素，通过"砖块"的排列来识别趋势方向。策略的核心思想是在趋势反转或延续时入场，跟随趋势获利。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 2 种买入信号（趋势反转向上、趋势延续） |
| **卖出条件** | 1 种卖出信号（趋势反转向下） |
| **保护机制** | 分级止盈 + 10% 止损 + 趋势反转离场 |
| **时间框架** | 15 分钟 (15m) |
| **依赖库** | talib, pandas, numpy, qtpylib |

## 三、买入条件详解

### 3.1 Renko 砖块图原理

Renko 图的核心是"砖块"概念：

```
趋势向上时：
┌─────┐
│ 绿砖 │  价格上涨超过 1 个砖块大小
├─────┤
│ 绿砖 │
└─────┘

趋势向下时：
┌─────┐
│ 红砖 │  价格下跌超过 1 个砖块大小
├─────┤
│ 红砖 │
└─────┘
```

**砖块大小**：动态计算，使用 ATR（平均真实波幅）的均值

```python
dataframe['ATR'] = ta.ATR(dataframe, timeperiod=5)
brick_size = np.mean(dataframe['ATR'])
```

### 3.2 趋势反转规则

Renko 图的趋势反转需要 **2 个砖块的反向移动**：

```python
# 上升趋势转为下降趋势
if trend and bricks <= -2:
    trend = not trend  # 反转
    bricks += 1
    # ...生成红色砖块

# 下降趋势转为上升趋势
if not trend and bricks >= 2:
    trend = not trend  # 反转
    bricks -= 1
    # ...生成绿色砖块
```

**大白话**：
- 上升趋势时，需要下跌 2 个砖块才能确认反转
- 下降趋势时，需要上涨 2 个砖块才能确认反转
- 这种设计过滤了假突破

### 3.3 买入条件详解

策略有 2 种买入信号：

#### 条件 #1：趋势反转向上

```python
if row['previous-trend'] == False and row['trend'] == True:
    dataframe.loc[..., 'buy'] = 1
```

**逻辑**：
- 前一个砖块趋势为下降（False）
- 当前砖块趋势为上升（True）
- 趋势反转，买入信号

#### 条件 #2：趋势延续

```python
if row['previous-trend'] == True and row['trend'] == True:
    dataframe.loc[..., 'buy'] = 1
```

**逻辑**：
- 前一个砖块趋势为上升（True）
- 当前砖块趋势仍为上升（True）
- 趋势延续，买入信号（加仓或继续持有）

### 3.4 买入条件分类

| 条件组 | 条件编号 | 核心逻辑 |
|-------|---------|---------|
| 趋势反转 | #1 | 从下降趋势转为上升趋势，买入信号 |
| 趋势延续 | #2 | 上升趋势持续，继续买入/加仓信号 |

## 四、卖出逻辑详解

### 4.1 分级止盈系统

策略采用分级止盈机制：

```
持仓时间    止盈阈值    说明
─────────────────────────────────
0 分钟      10%        初始期望较高
30 分钟     5%         时间推移，降低期望
60 分钟     2%         时间过长，落袋为安
```

**设计理念**：
- 初期给予较大利润空间
- 时间越长，越倾向于获利了结
- 避免长时间持仓带来的风险

### 4.2 趋势反转卖出

```python
# 当趋势从上升转为下降时，标记为卖出
else:
    dataframe.loc[..., 'sell'] = 1
```

**逻辑**：
- 当前趋势为下降（False）时，触发卖出
- 这是一种"趋势跟随"的出场方式

### 4.3 保护机制

```python
sell_profit_only = True       # 仅在盈利时使用卖出信号
sell_profit_offset = 0.1      # 利润偏移保护
```

**设计**：
- 只在盈利时响应卖出信号
- 额外 0.1 的利润偏移作为保护

## 五、技术指标体系

### 5.1 核心指标

| 指标类别 | 具体指标 | 用途 |
|---------|---------|------|
| 波动率 | ATR(5) | 动态计算砖块大小 |
| 趋势 | Renko 砖块趋势 | 判断趋势方向和反转 |

### 5.2 Renko 砖块图详解

Renko 图是一种独特的图表形式：

**特点**：
1. **忽略时间**：只有价格变化超过砖块大小才生成新砖块
2. **过滤噪音**：小幅度价格波动不产生砖块
3. **趋势清晰**：绿色砖块连续表示上升趋势，红色砖块连续表示下降趋势

**砖块大小计算**：
```python
dataframe['ATR'] = ta.ATR(dataframe, timeperiod=5)
brick_size = np.mean(dataframe['ATR'])
```

ATR（Average True Range）衡量市场波动性，其均值作为砖块大小可以自适应不同币种的波动特性。

## 六、风险管理特色

### 6.1 趋势反转保护

Renko 图的反转规则需要 2 个砖块的反向移动：

```
趋势向上：需要下跌 2 砖块才能确认反转
趋势向下：需要上涨 2 砖块才能确认反转
```

**优势**：
- 过滤假突破
- 确认趋势反转需要更强的信号
- 减少被震出局的风险

### 6.2 分级止盈机制

| 持仓时间 | 止盈阈值 | 风险控制 |
|---------|---------|---------|
| 0-30 分钟 | 10% | 给予趋势发展空间 |
| 30-60 分钟 | 5% | 时间成本考量 |
| 60+ 分钟 | 2% | 快速获利了结 |

### 6.3 盈利保护

```python
sell_profit_only = True
```

只在盈利时响应卖出信号，避免在亏损时被动离场。

## 七、策略优势与局限

### ✅ 优势

1. **过滤噪音**：Renko 图忽略时间因素，专注于价格变化
2. **趋势清晰**：砖块颜色直观显示趋势方向
3. **反转确认严格**：需要 2 个砖块反向移动才确认反转
4. **自适应砖块大小**：ATR 动态计算，适应不同币种

### ⚠️ 局限

1. **忽略时间因素**：在快速行情中可能反应滞后
2. **砖块大小依赖 ATR**：低波动市场砖块过小，信号过多
3. **复杂计算**：需要在 `populate_indicators` 中构建完整的 Renko 图
4. **数据转换**：输出的是 Renko 数据帧而非原始数据帧

## 十、重要提醒：复杂性的代价

### 10.1 学习成本

Renko 图是一种较为特殊的图表形式，需要理解：
- Renko 砖块的生成规则
- 趋势反转的确认机制
- 砖块大小与 ATR 的关系

### 10.2 硬件要求

| 交易对数量 | 最低内存 | 推荐内存 |
|-----------|---------|---------|
| 10 个以下 | 2 GB | 4 GB |
| 10-50 个 | 4 GB | 8 GB |
| 50 个以上 | 8 GB | 16 GB |

### 10.3 回测与实盘的差异

**数据转换问题**：
- `populate_indicators` 返回的是 Renko 数据帧
- 不是原始的时间序列数据
- 回测时需要注意数据结构

**实盘挑战**：
- Renko 图的实时计算需要实时更新
- 砖块大小会随 ATR 变化

### 10.4 手动交易者建议

Renko 图适合手动交易者：
- 趋势方向直观（砖块颜色）
- 进出场信号明确（趋势反转）
- 可以与传统 K 线图结合使用

## 十一、总结

**Renko** 是一个**基于 Renko 砖块图的趋势跟踪策略**。它的核心价值在于：

1. **过滤噪音**：Renko 图忽略时间因素，专注于价格变化
2. **趋势清晰**：砖块颜色直观显示趋势方向
3. **反转确认严格**：2 个砖块反向移动确认反转，减少假信号

对于量化交易者而言，Renko 提供了一种独特的视角来观察市场趋势，但其数据转换的复杂性需要特别注意。策略的设计理念"趋势反转时入场，趋势延续时加仓"值得借鉴。

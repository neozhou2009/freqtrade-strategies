# Renko 策略：用"俄罗斯方块"看趋势

> **外号**：俄罗斯方块  
> **职业**：趋势观察员（用砖块说话）  
> **时间框架**：15 分钟

---

## 一、这策略是个啥？

简单说，**Renko** 就是一个：
- 用"砖块图"代替 K 线图
- 只看价格变化，不管时间流逝
- 趋势变了就进场，趋势没了就跑路

就像**俄罗斯方块** 🧱 —— 一块一块往上堆，趋势向上就堆绿砖，趋势向下就堆红砖，简单直观！

---

## 二、核心配置：说白了就是"给趋势时间，但别贪太久"

### 止盈规则（ROI 表）

```
刚进场        → 赚 10% 就跑
持有 30 分钟  → 赚 5% 就跑
持有 60 分钟  → 赚 2% 就跑
```

**翻译**：
> "我给你时间让趋势发展，但时间越久我越着急。刚开始我想要 10%，30 分钟后 5% 也行，再过半小时 2% 就够了，赶紧落袋为安！"

### 止损规则

```
亏损 10% → 割肉止损
```

**翻译**：
> "亏 10% 我就认输，不多废话。"

---

## 三、Renko 砖块图：把 K 线变成"积木"

### 3.1 啥是 Renko 图？

普通 K 线图：每个时间点一根 K 线，不管价格变不变。

Renko 图：**只有价格变化够了，才画一块砖**。

```
上升趋势（绿砖）：
┌─────┐
│ 🟢 │  价格涨了超过 1 砖块
├─────┤
│ 🟢 │  
├─────┤
│ 🟢 │
└─────┘

下降趋势（红砖）：
┌─────┐
│ 🔴 │  价格跌了超过 1 砖块
├─────┤
│ 🔴 │
└─────┘
```

**大白话**：
> "K 线是看时间的，每 15 分钟画一根。Renko 是看价格的，价格动够了才画一块。这样就过滤掉了那些磨磨唧唧的小波动！"

### 3.2 砖块大小怎么定？

**动态计算**：用 ATR（平均真实波幅）的均值

```python
brick_size = 平均 ATR
```

**大白话**：
> "砖块大小不是固定的，是根据市场波动来定的。波动大的币种砖块大，波动小的币种砖块小，自动适配！"

### 3.3 趋势反转规则：2 块砖才认账

这是 Renko 最聪明的地方：

| 当前趋势 | 反转条件 | 说明 |
|---------|---------|------|
| 向上（绿砖） | 下跌 2 块砖 | 才确认转为下降趋势 |
| 向下（红砖） | 上涨 2 块砖 | 才确认转为上升趋势 |

**大白话**：
> "趋势变了不能只说一声就算，得连续 2 块砖反方向才认账。这样就不会被假突破骗了！"

## 四、买入条件：2 种情况可以进场

策略有 2 种买入信号，说白了就是：

### 🎯 信号 #1：趋势反转向上

```
前一块是红砖（下降）→ 当前是绿砖（上升）
```

**大白话**：
> "之前趋势向下，现在转成向上了。反转确认，进场！"

### 🎯 信号 #2：趋势延续

```
前一块是绿砖（上升）→ 当前还是绿砖（上升）
```

**大白话**：
> "趋势还在往上走，继续持有或加仓！"

---

## 五、卖出逻辑：趋势没了就跑

### 5.1 趋势反转卖出

```
当前趋势变成红色（下降）→ 卖出
```

**大白话**：
> "绿砖变红砖了，趋势反转向下，赶紧跑！"

### 5.2 分级止盈：时间越久越着急

| 持仓时间 | 止盈阈值 | 心态 |
|---------|---------|------|
| 刚进场 | 10% | "让子弹飞一会儿" |
| 30 分钟后 | 5% | "差不多了吧？" |
| 60 分钟后 | 2% | "赶紧走吧，别墨迹了" |

**大白话**：
> "刚进场时我期望高，想赚 10%。但时间越久我越着急，给你 60 分钟够了，2% 我也认了，落袋为安！"

### 5.3 盈利保护机制

```python
sell_profit_only = True  # 只在盈利时才响应卖出信号
```

**大白话**：
> "亏钱的时候先别急着卖，等回本了再说。盈利了才开始考虑止盈。"

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **直观清晰**：砖块颜色就是趋势方向，傻子都能看懂
2. **过滤噪音**：小波动不产生砖块，清净多了
3. **反转确认严格**：2 块砖才认账，不容易被骗
4. **自适应**：砖块大小随市场波动自动调整

### ⚠️ 缺点（吐槽环节）

1. **忽略时间**：快速行情可能反应慢半拍
2. **低波动市场拉胯**：波动小的时候砖块太多，信号乱飞
3. **计算复杂**：要把原始数据转成 Renko 数据，费脑子
4. **数据结构变了**：输出的不是原始 K 线，回测要注意

|---------|---------|------|

| 高波动乱跳 | 🤔 谨慎 | 砖块大小可能跟不上变化 |
| 单边大涨/大跌 | ✅ 完美 | 趋势方向清晰，Renko 发挥所长 |

2. **适合趋势行情**：震荡市慎用

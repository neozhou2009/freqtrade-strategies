# DevilStra 策略大白话版

## 一、这个策略是干啥的？

想象一下，你有一个超级聪明的交易助手，它能把上百种技术指标自由组合，自动找出最适合每个币种的交易规则——这就是 DevilStra 策略。

名字里的 "Devil"（魔鬼）不是说要干坏事，而是来自策略作者的一句诗：魔鬼比上帝更强，但只有上帝能创造新生命，而魔鬼擅长把小东西组合成大力量。简单说，这个策略**不发明新指标，而是把现有的指标玩出花来**。

**适合谁用**：
- 想自动化交易的懒人
- 有多个币种想同时操作的人
- 不想天天盯盘的上班族
- 愿意花时间做参数优化的人

**不适合谁**：
- 想当天就能交易的人（需要先优化参数）
- 只做一个币的人（策略设计是多币种）
- 追求高频交易的人（4小时周期）

## 二、核心玩法：咒语系统

这个策略最特别的地方就是"咒语"系统。

### 2.1 什么是咒语？

你可以把"咒语"理解为**一套预设的交易规则**。每个咒语里都有：

- **买入规则**：3个条件，全部满足就买
- **卖出规则**：3个条件，全部满足就卖

策略里定义了 9 个基础咒语，名字都很神秘：

| 咒语 | 可以理解为 |
|-----|----------|
| Zi（紫） | 紫色系规则 |
| Gu（古） | 古典派规则 |
| Lu（路） | 趋势路径规则 |
| La（拉） | 拉升捕捉规则 |
| Si（思） | 深思熟虑规则 |
| Pa（帕） | 平衡派规则 |
| De（德） | 稳健派规则 |
| Ra（拉） | 太阳能量规则 |
| Cu（库） | 库存管理规则 |

### 2.2 咒语长啥样？

看一个例子（Zi 咒语的买入部分）：

```
买入条件1：MINUS_DI指标 除以 BOP指标 大于 0.1763
买入条件2：HT_TRENDMODE指标 上穿 MACD指标
买入条件3：CORREL指标 下穿并持续低于 DEMA指标
```

三个条件都满足，就买入！

### 2.3 每个币用不同的咒语

这才是最妙的地方——策略通过 Hyperopt（超级优化）自动给每个币分配最适合它的咒语组合。

比如优化后可能得到：
```
BTC 用 Zi 咒语
ETH 用 Lu 咒语
SOL 用 Ra 咒语
...
```

每个币都有一套量身定做的交易规则！

## 三、指标库：150+种武器

策略调用了 TA-Lib 技术指标库，里面有超过 150 种指标。

### 3.1 常用指标类型

**趋势类**：MA、EMA、MACD、ADX 等
**动量类**：RSI、KDJ、威廉指标等
**波动类**：布林带、ATR 等
**成交量类**：OBV、成交量均线等
**形态类**：各种K线形态（十字星、锤子线等60多种）

### 3.2 指标是怎么被调用的？

策略用一种"配方"格式来指定指标：

```
SMA-14          → 14周期简单移动平均线
MACD-0-50       → 50周期MACD的第0列（MACD线）
BBANDS-1-20     → 20周期布林带的中轨
CDLDOJI         → 十字星形态
```

系统会自动解析这些配方，计算对应的指标值。

### 3.3 所有指标都归一化

为了让不同量级的指标可以比较，所有指标值都会被"拉伸"到 0-1 之间：

```
原始值：50, 80, 120, 200
归一化后：0, 0.2, 0.47, 1.0
```

这样 RSI（0-100）和 MACD（可能是负数）就能放在一起比较了。

## 四、操作符：16种判断方式

有了指标，还需要比较方法。策略定义了 16 种操作符：

### 4.1 简单比较

| 操作符 | 例子 | 通俗解释 |
|-------|------|---------|
| `>` | MA快 > MA慢 | 快线在慢线之上 |
| `<` | RSI < 30 | RSI低于30 |
| `=` | 价格 ≈ 均线 | 价格紧贴均线 |

### 4.2 交叉判断

| 操作符 | 例子 | 通俗解释 |
|-------|------|---------|
| `CA` | 快线上穿慢线 | 金叉，买入信号 |
| `CB` | 快线下穿慢线 | 死叉，卖出信号 |
| `C` | 任意交叉 | 方向不确定的穿越 |

### 4.3 和数值比

| 操作符 | 例子 | 通俗解释 |
|-------|------|---------|
| `>R` | RSI > 0.7 | RSI高于阈值 |
| `<R` | RSI < 0.3 | RSI低于阈值 |
| `=R` | RSI ≈ 0.5 | RSI在中轴附近 |

### 4.4 比率判断

| 操作符 | 例子 | 通俗解释 |
|-------|------|---------|
| `/>R` | 快线/慢线 > 1.1 | 快线比慢线高10%以上 |
| `/<R` | 快线/慢线 < 0.9 | 快线比慢线低10%以上 |

### 4.5 趋势判断

| 操作符 | 例子 | 通俗解释 |
|-------|------|---------|
| `UT` | 指标高于自身均线 | 上升趋势中 |
| `DT` | 指标低于自身均线 | 下降趋势中 |
| `CUT` | 刚上穿自身均线且继续向上 | 趋势转强的瞬间 |
| `CDT` | 刚下穿自身均线且继续向下 | 趋势转弱的瞬间 |

## 五、买入信号怎么产生

### 5.1 买入流程图

```
检查交易对是第几个
    ↓
找到对应的咒语（比如第3个币用 Ra 咒语）
    ↓
获取咒语里的买入参数（3组条件）
    ↓
条件1 AND 条件2 AND 条件3
    ↓
全部满足 → 买入！
```

### 5.2 一个实际的买入例子

假设 ETH 用了 "Zi" 咒语：

**检查条件1**：
- 主指标：MINUS_DI-50（负方向指标）
- 对比指标：BOP-4（力量指标）
- 操作符：/>R（比率大于）
- 阈值：0.1763
- 计算：MINUS_DI / BOP > 0.1763？
- 结果：True ✓

**检查条件2**：
- 主指标：HT_TRENDMODE-50（趋势模式）
- 对比指标：MACD-0-50（MACD线）
- 操作符：CA（上穿）
- 检查：趋势模式线刚上穿MACD？
- 结果：True ✓

**检查条件3**：
- 主指标：CORREL-128（相关性指标）
- 对比指标：DEMA-52（双指数均线）
- 操作符：CDT（交叉下降并持续）
- 检查：相关性刚下穿均线且继续向下？
- 结果：True ✓

**结论**：三个都满足，买入信号触发！

## 六、卖出信号怎么产生

卖出逻辑和买入完全对称，也是"每个币有自己的卖出咒语"。

### 6.1 卖出流程

```
检查交易对位置
    ↓
找到对应的卖出咒语
    ↓
获取卖出参数（3组条件）
    ↓
条件1 AND 条件2 AND 条件3
    ↓
全部满足 → 卖出！
```

### 6.2 卖出条件的特点

卖出条件通常检测：
- 价格动力减弱
- 趋势转向信号
- 看跌K线形态出现
- 指标从高位回落

### 6.3 其他卖出触发

除了指标触发，还有：

**ROI 止盈**：
| 时间 | 目标收益 |
|-----|---------|
| 立即 | 57.4% |
| 29小时后 | 15.8% |
| 63小时后 | 8.9% |
| 110小时后 | 0%（无论如何都卖） |

**止损**：
- 跌 28% 就自动卖出

## 七、怎么优化参数

这个策略**不能直接用**，必须先优化参数！

### 7.1 第一步：设置交易对数量

打开策略文件，找到这行：
```python
PAIR_LIST_LENGHT = 269
```

改成你的交易对数量 +1。比如你有 50 个币，就改成 51。

### 7.2 第二步：准备配置文件

config.json 必须用**静态交易对列表**：
```json
{
    "pairlists": [{
        "method": "StaticPairList"
    }]
}
```

不能有动态添加删除币的逻辑。

### 7.3 第三步：运行优化

```bash
freqtrade hyperopt \
    --hyperopt-loss SharpeHyperOptLoss \
    --spaces buy sell \
    --strategy DevilStra \
    --epochs 500
```

这个过程可能要跑几个小时甚至几天，取决于：
- 你的电脑配置
- 数据量大小
- 优化轮数

### 7.4 第四步：粘贴结果

优化完成后，会输出类似这样的结果：

```python
buy_params = {
    "buy_spell": "Zi,Lu,Ra,Ra,La,Si,Pa,...",
}

sell_params = {
    "sell_spell": "La,Pa,De,De,La,Si,Si,...",
}
```

把这些粘贴到策略文件里的指定位置。

## 八、咒语是怎么生成的

你可能会问：那 9 个基础咒语是从哪来的？

### 8.1 GodStraNew 策略

作者提到这些咒语来自另一个策略叫 "GodStraNew"。简单说：

1. 先用 GodStraNew 生成一些交易规则
2. 把这些规则"变形"成咒语格式
3. 每个咒语就是一个完整的买卖规则组合

### 8.2 咒语的转换过程

```
GodStraNew 输出：
    buy_params = {...}
    sell_params = {...}

转换为咒语：
    "咒语名": {
        "buy_params": {...},
        "sell_params": {...}
    }
```

所以你也可以：
1. 用其他策略生成好的参数
2. 转换成咒语格式
3. 添加到 SPELLS 字典里

## 十一、常见问题解答

### Q1：为什么每个币用不同的咒语？

因为不同币的走势特性不同。BTC 可能适合趋势型规则，而某个山寨币可能适合震荡型规则。让每个币有自己的"专属规则"，能提高胜率。

### Q2：优化要多久？

取决于：
- 交易对数量（越多越慢）
- 数据时间跨度（越长越慢）
- epochs 次数（越多越准但越慢）

一般来说，50个币、2年数据、500轮优化，可能需要 6-24 小时。

### Q3：多久重新优化一次？

建议：
- 每季度重新优化一次
- 或者当策略表现明显下滑时重新优化
- 市场环境大变化时（如牛熊转换）重新优化

### Q4：可以只用买入策略吗？

可以，但需要在策略里修改。默认是买入和卖出都要用咒语。

### Q5：能不能自己加新的咒语？

完全可以！只需要：
1. 在 SPELLS 字典里加新条目
2. 用相同的格式定义 buy_params 和 sell_params
3. 重新优化让系统选择是否使用你的新咒语

## 十二、优缺点总结

### 优点

| 优点 | 说明 |
|-----|------|
| 高度自动化 | 优化后全自动运行 |
| 个性化规则 | 每个币有专属策略 |
| 指标丰富 | 150+ 种指标可选 |
| 模块化设计 | 容易扩展和维护 |
| 风控完善 | ROI止盈 + 固定止损 |

### 缺点

| 缺点 | 说明 |
|-----|------|
| 初始设置复杂 | 需要先优化参数 |
| 依赖历史数据 | 可能在新环境下失效 |
| 计算资源要求高 | 优化过程耗时耗力 |
| 不够透明 | 很难解释为什么买卖 |
| 可能过拟合 | 参数太精确反而不好 |

## 十三、给你的建议

### 新手建议

1. **先小规模测试**：用少量币种（5-10个）开始
2. **用较短时间优化**：先做 100-200 轮看看效果
3. **纸盘测试**：优化后先用模拟交易验证
4. **小额实盘**：确认有效再用真钱

### 进阶建议

1. **添加自己的咒语**：基于你对市场的理解创建新规则
2. **调整参数范围**：PAIN_RANGE 影响优化空间
3. **监控表现变化**：如果胜率下降，考虑重新优化
4. **组合其他策略**：可以作为多策略系统的一部分

### 最后的话

DevilStra 是一个很有创意的策略，它把"组合的力量"发挥到了极致。但它不是"躺着赚钱"的神器——需要你投入时间优化参数，也需要你持续监控表现。

记住量化交易的铁律：**历史表现不代表未来收益**。不管回测多漂亮，都要谨慎对待真实资金。

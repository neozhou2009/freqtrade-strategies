## 一、这策略是个啥？

简单说，**Strategy001_custom_sell** 就是一个：
- 在 Strategy001 基础上加了 RSI 自定义卖出
- EMA 金叉买入，RSI 超买止盈
- 多了一个"聪明卖出"的功能

就像 **驾校练习车装了自动刹车** 🚗💨 —— 保留了新手友好的特性，还加了个保命功能！

## 五、卖出逻辑：这里有新东西！

### 5.1 基础卖出信号（和 Strategy001 一样）

**大白话**：
> "EMA50 上穿 EMA100，价格跌破 EMA20，HA 蜡烛变红了？那就跑！"

### 5.2 新增！RSI 自定义卖出 🎉

这是本策略的核心升级！

**大白话**：
> "RSI 超过 70 了？还赚钱？那就主动卖出，不等均线死叉了！"

**代码长这样**：
```python
def custom_sell(...):
    if (RSI > 70) and (当前盈利 > 0):
        return "rsi_profit_sell"  # 卖出！
```

**这意味着什么？**
- RSI > 70 = 最近涨幅太大，可能要回调
- 盈利 > 0 = 确保赚钱才卖
- 主动卖出 = 不等均线信号，提前锁定利润

### 5.3 三种卖出方式对比

| 卖出方式 | 触发条件 | 大白话 |
|---------|---------|--------|
| ROI 退出 | 时间+收益达标 | "赚够了就跑" |
| 追踪止损 | 盈利后回撤 | "利润不能吐回去" |
| **RSI 卖出** | **RSI > 70 且盈利** | **"涨太快了，先落袋为安"** |

## 十一、彩蛋：代码里的"小心思"

仔细看 custom_sell 函数，你会发现：

```python
if (current_candle['rsi'] > 70) and (current_profit > 0):
    return "rsi_profit_sell"
```

**有趣的地方**：

1. **盈利才卖**：`current_profit > 0` 确保不亏着卖
   > "亏钱的时候别追卖，让止损来处理"

2. **返回卖出原因**：`"rsi_profit_sell"` 便于分析
   > "知道是 RSI 触发的卖出，方便回测优化"

3. **简单直接**：只有两行核心逻辑
   > "能一行搞定的，绝不写两行"

## 十三、⚠️ 风险再强调（这段一定要看）

### RSI 止盈的双刃剑

RSI 自定义卖出在回测中可能表现很好——但有个陷阱：

> **强趋势中 RSI 可能长期超买，过早卖出会踏空大行情。**

简单说就是：**涨了就卖，卖了还涨，拍断大腿！** 🦵

### 增强策略的隐藏风险

实盘时，RSI 卖出可能遇到：
- **踏空风险**：卖了之后继续涨，心态崩了
- **频繁交易**：RSI 反复超买超卖，手续费吃利润
- **限价单不成交**：想卖的时候价格已经下来了

### 我的建议（真心话）

```
1. 先对比 Strategy001 和这个版本的回测结果
2. 看看 RSI 卖出到底帮你多赚了还是少赚了
3. 根据币种特性调整 RSI 阈值（70 不是万能的）
4. 强趋势行情考虑提高阈值到 75-80
5. 震荡行情考虑降低阈值或干脆不用 RSI 卖出
```

**记住**：RSI 超买不代表一定会跌，可能只是涨得太猛了。策略是死的，市场是活的！

## 一、策略概览

Strategy001_custom_sell 是 Strategy001 的增强版本，在原有 EMA 均线交叉 + Heikin Ashi 趋势跟踪逻辑的基础上，新增了基于 RSI 的自定义卖出条件。这一改进使得策略能够在 RSI 超买且盈利时主动止盈，提升资金周转效率。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 1 个买入信号（与 Strategy001 相同） |
| **卖出条件** | 1 个基础卖出信号 + RSI 自定义卖出 |
| **保护机制** | 追踪止损机制 + RSI 超买卖出 |
| **时间框架** | 5 分钟主框架 |
| **依赖库** | talib, qtpylib |
| **与 Strategy001 差异** | 新增 RSI 指标 + custom_sell 函数 |

### 4.2 自定义卖出逻辑（custom_sell）

这是 Strategy001_custom_sell 的核心增强功能：

```python
def custom_sell(self, pair: str, trade: 'Trade', current_time: 'datetime', 
                current_rate: float, current_profit: float, **kwargs):
    # 获取当前K线数据
    dataframe, _ = self.dp.get_analyzed_dataframe(pair=pair, timeframe=self.timeframe)
    current_candle = dataframe.iloc[-1].squeeze()
    
    # RSI 超买 + 盈利时卖出
    if (current_candle['rsi'] > 70) and (current_profit > 0):
        return "rsi_profit_sell"
    
    return None
```

**自定义卖出触发条件**：

| 条件编号 | 条件描述 | 技术含义 |
|---------|---------|---------|
| 条件 1 | RSI > 70 | 超买状态，可能回调 |
| 条件 2 | 当前盈利 > 0 | 确保在盈利时才卖出 |
| 卖出原因 | "rsi_profit_sell" | 便于日志分析和回测统计 |

**设计优势**：
- **主动止盈**：在 RSI 超买时主动锁定利润，不等待趋势反转
- **盈利保护**：仅在盈利时触发，避免亏损时追卖
- **资金效率**：提前止盈释放资金，提高周转率

### 5.1 核心指标

| 蜡烛图 | Heikin Ashi | 过滤噪音、确认趋势方向 |
| 震荡指标 | RSI (14) | 超买超卖判断、自定义卖出触发 |

### 5.2 RSI 指标详解

**相对强弱指数（RSI）** 计算公式：
```
RSI = 100 - (100 / (1 + RS))
其中 RS = 平均上涨幅度 / 平均下跌幅度
```

**RSI 在本策略中的作用**：
- **周期**：14（标准参数）
- **超买阈值**：70（RSI > 70 视为超买）
- **触发条件**：超买 + 盈利

**为什么选择 RSI > 70**：
- RSI 超过 70 表示近期涨幅过大
- 可能面临短期回调或盘整
- 此时主动止盈可以锁定利润

## 七、策略优势与局限

### ✅ 优势

1. **主动止盈**：RSI 超买卖出机制在行情冲高时提前锁定利润
2. **资金效率高**：提前止盈释放资金，增加交易机会
3. **保持简洁**：在 Strategy001 基础上只增加少量代码，易于理解和维护

### ⚠️ 局限

1. **RSI 假信号**：强趋势中 RSI 可能长期超买，过早卖出会踏空
2. **参数固定**：RSI 70 的阈值可能不适用于所有币种
3. **趋势依赖**：与 Strategy001 相同，在震荡市场中表现不佳

### 与 Strategy001 对比

| 止盈效率 | 被动 | 主动 |
| 资金周转 | 一般 | 较高 |
| 适用场景 | 趋势行情 | 趋势行情 + 波动行情 |

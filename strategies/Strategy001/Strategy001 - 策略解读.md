## 一、策略概览

## 二、策略配置解析

### 2.1 基础风险参数

```python
# ROI 退出表
minimal_roi = {

    "20":  0.04,   # 20分钟后，4%收益退出
    "0":   0.05    # 立即，5%收益退出
}

# 止损设置
stoploss = -0.10   # 固定止损 -10%

# 追踪止损
trailing_stop = True
trailing_stop_positive = 0.01      # 正收益 1% 后激活
trailing_stop_positive_offset = 0.02  # 偏移 2%
```

**设计思路**：
- ROI 表采用倒序设计，持仓时间越长，目标收益越低，体现"快速止盈、保住利润"的理念
- 10% 的固定止损相对宽松，给予趋势足够的回调空间
- 追踪止损在盈利 2% 后开始生效，回撤 1% 触发，兼顾利润保护和趋势跟随

### 2.2 订单类型配置

```python
order_types = {
```

| 指标类别 | 具体指标 | 用途 |

### 3.2 买入条件逻辑

```python
def populate_entry_trend(self, dataframe: DataFrame, metadata: dict) -> DataFrame:
    dataframe.loc[
        (
            qtpylib.crossed_above(dataframe['ema20'], dataframe['ema50']) &
            (dataframe['ha_close'] > dataframe['ema20']) &
            (dataframe['ha_open'] < dataframe['ha_close'])  # green bar
        ),
        'buy'] = 1
    return dataframe
```

**买入信号触发条件（三条件同时满足）**：

| 条件编号 | 条件描述 | 技术含义 |
|---------|---------|---------|
| 条件 1 | EMA20 上穿 EMA50 | 短期均线金叉，趋势转强信号 |
| 条件 2 | HA 收盘价 > EMA20 | 价格位于短期均线上方，确认上涨趋势 |
| 条件 3 | HA 开盘价 < HA 收盘价 | Heikin Ashi 绿色蜡烛，趋势确认 |

**设计特点**：
- EMA 金叉提供趋势转向信号
- Heikin Ashi 蜡烛图过滤市场噪音，避免假突破
- 三重确认机制降低误判概率

## 四、卖出逻辑详解

### 4.1 卖出信号

```python
def populate_exit_trend(self, dataframe: DataFrame, metadata: dict) -> DataFrame:
    dataframe.loc[
        (
            qtpylib.crossed_above(dataframe['ema50'], dataframe['ema100']) &
            (dataframe['ha_close'] < dataframe['ema20']) &
            (dataframe['ha_open'] > dataframe['ha_close'])  # red bar
        ),
        'sell'] = 1
    return dataframe
```

**卖出信号触发条件（三条件同时满足）**：

| 条件编号 | 条件描述 | 技术含义 |
|---------|---------|---------|
| 条件 1 | EMA50 上穿 EMA100 | 中期趋势反转，可能是上涨中继 |
| 条件 2 | HA 收盘价 < EMA20 | 价格跌破短期均线，趋势转弱 |
| 条件 3 | HA 开盘价 > HA 收盘价 | Heikin Ashi 红色蜡烛，下跌确认 |

**注意**：此处 EMA50 上穿 EMA100 在趋势跟踪策略中通常被视为上涨中继信号，但结合价格跌破 EMA20 和红色 HA 蜡烛，形成一个趋势反转的过滤条件。

### 4.2 多重退出机制

策略提供多层退出保护：

| 退出机制 | 触发条件 | 优先级 |
|---------|---------|--------|
| ROI 退出 | 达到时间-收益目标 | 高 |
| 追踪止损 | 盈利后回撤 1% | 中 |
| 固定止损 | 亏损达到 10% | 高 |
| 信号卖出 | 满足卖出条件 | 低 |

## 五、技术指标体系

### 5.1 核心指标

| 指标类别 | 具体指标 | 用途 |
|---------|---------|------|
| 移动平均线 | EMA20 | 短期趋势、动态支撑/阻力 |
| 移动平均线 | EMA50 | 中期趋势、金叉/死叉信号 |
| 移动平均线 | EMA100 | 长期趋势、过滤震荡 |
| 蜡烛图 | Heikin Ashi | 过滤噪音、确认趋势方向 |

### 5.2 Heikin Ashi 蜡烛图

Heikin Ashi（平均蜡烛图）是一种特殊的蜡烛图计算方法：

```
HA Close = (Open + High + Low + Close) / 4
HA Open = (前一根 HA Open + 前一根 HA Close) / 2
```

**优势**：
- 平滑价格波动，减少假信号
- 趋势期间连续同色蜡烛，易于识别
- 适合趋势跟踪策略

## 六、风险管理特色

### 6.1 追踪止损机制

```python
trailing_stop = True
trailing_stop_positive = 0.01      # 正收益 1% 后激活
trailing_stop_positive_offset = 0.02  # 价格上涨 2% 后开始追踪
```

**工作原理**：
1. 当盈利达到 2% 时，追踪止损开始激活
2. 止损线跟随价格上涨而上移
3. 当价格从高点回落超过 1% 时，触发止损卖出

**示例**：
- 买入价格：100 USDT
- 价格涨到 102 USDT（盈利 2%）：追踪止损激活
- 价格涨到 105 USDT：止损线跟随到 103.95 USDT
- 价格回落到 103.95 USDT：触发追踪止损卖出

### 6.2 ROI 时间衰减

| 持仓时间 | 目标收益 | 设计意图 |
|---------|---------|---------|
| 0 分钟 | 5% | 快速爆发行情 |
| 20 分钟 | 4% | 短期趋势 |
| 30 分钟 | 3% | 中短期趋势 |
| 60 分钟 | 1% | 时间换空间，降低预期 |

### 6.3 风险参数汇总

| 参数 | 值 | 说明 |
|------|-----|------|
| 固定止损 | -10% | 最大单笔亏损 |
| 追踪止损激活 | +2% | 开始追踪的盈利阈值 |
| 追踪止损距离 | 1% | 回撤触发值 |
| 最大目标收益 | 5% | 立即止盈目标 |

## 七、策略优势与局限

### ✅ 优势

1. **简洁易懂**：代码不到 100 行，逻辑清晰，是学习 Freqtrade 策略开发的最佳入门案例
2. **多重确认**：EMA 交叉 + HA 蜡烛图双重过滤，减少假信号
3. **风险可控**：追踪止损 + 固定止损双重保护，保护利润

### ⚠️ 局限

1. **趋势依赖**：在震荡市场中可能频繁止损
2. **信号滞后**：EMA 属于滞后指标，入场时机可能偏晚
3. **参数固定**：未提供超参数优化接口，需要手动调整

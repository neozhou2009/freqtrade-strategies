## 一、策略概览

**Chandem** 是一个基于 CMO（钱德动量振荡器）的动量突破策略，融合了布林带突破信号进行卖出判断。策略核心逻辑简洁：利用 CMO 指标捕捉价格动量的转捩点，当 CMO 从负值上穿零轴时买入，当价格突破布林带上轨时卖出。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | CMO 从负值上穿零轴（今日 CMO ≥ 0 且 昨日 CMO < 0） |
| **卖出条件** | 价格上穿布林带上轨（布林带参数：25周期，3.5倍标准差） |
| **保护机制** | 追踪止损（+1.013% 启动，+10.858% 触发） |
| **时间框架** | 5m |
| **依赖库** | TA-Lib, technical (qtpylib) |

## 三、买入条件详解

### 3.1 买入逻辑完整解析

```python
dataframe.loc[
    (
        # 条件 1: CMO 今日 >= 0
        (dataframe["CMO"] >= 0)
        # 条件 2: CMO 昨日 < 0（上穿零轴）
        & (qtpylib.crossed_above(dataframe["CMO"].shift(1), 0))
    ),
    'buy'] = 1
```

**逻辑解析**：

1. **CMO 指标上穿零轴**：
   - CMO（Chande Momentum Oscillator）是一个动量指标
   - 当 CMO 从负值转为正值，表示短期动量转强
   - 这是一个经典的**动量反转信号**

2. **时序确认**：
   - `dataframe["CMO"].shift(1)` 获取昨日 CMO 值
   - `crossed_above` 确保是上穿而非仅仅超越零轴
   - 避免了在零轴附近反复波动的虚假信号

### 3.2 指标计算

```python
# CMO 计算
dataframe['CMO'] = ta.CMO(dataframe, timeperiod=50)

# 布林带计算（qtpylib 版）
bollinger = qtpylib.bollinger_bands(
    qtpylib.typical_price(dataframe),  # 使用典型价 = (H+L+C)/3
    window=25, 
    stds=3.5  # 3.5 倍标准差
)
dataframe['bb_lowerband'] = bollinger['lower']
dataframe['bb_middleband'] = bollinger['mid']
dataframe['bb_upperband'] = bollinger['upper']

# 布林带计算（TA-Lib 版，仅用于参考）
bollingerTA = ta.BBANDS(dataframe, timeperiod=25, nbdevup=3.2, nbdevdn=3.2)
```

## 四、卖出逻辑详解

### 4.1 卖出条件

```python
dataframe.loc[
    (
        # 条件：价格上穿布林带上轨
        (qtpylib.crossed_above(dataframe['close'], dataframe['bb_upperband']))
    ),
    'sell'] = 1
```

**逻辑解析**：

1. **布林带上轨突破**：
   - 价格突破布林带上轨通常表示**价格处于极端高位**
   - 这是一个**趋势反转预警信号**
   - 配合高 ROI 目标，策略在价格极端时锁定利润

2. **与其他退出机制的配合**：
   - 卖出信号触发后，还需满足 `exit_profit_only = True`
   - 必须有利润才会实际卖出

### 4.2 ROI 退出机制

|---------|-----------|---------|
| 0 分钟 | 28.4% | 达到即退出 |

| 1740 分钟（约29小时） | 6.6% | 超过此时段 |

## 五、技术指标体系

### 5.1 核心指标

| 指标类别 | 具体指标 | 参数 | 用途 |
|---------|---------|------|------|
| **动量指标** | CMO | 50 周期 | 捕捉动量转捩点 |
| **波动指标** | Bollinger Bands | 25周期, 3.5σ | 识别价格极端 |
| **价格类型** | Typical Price | (H+L+C)/3 | 布林带计算基础 |

### 5.2 指标详解

#### CMO（Chande Momentum Oscillator）

- **计算公式**：类似 RSI 的动量指标
- **取值范围**：-100 到 +100
- **策略逻辑**：
  - CMO < 0 → 近期下跌动量占优
  - CMO > 0 → 近期上涨动量占优
  - CMO 从负转正 → 动量由空转多，买入信号

#### 布林带（Bollinger Bands）

- **参数**：25 周期，3.5 倍标准差（较宽）
- **较宽的原因**：使用 3.5σ 而非常规的 2σ，可以过滤噪音
- **策略逻辑**：
  - 价格触及上轨 → 超买信号，触发卖出

## 六、风险管理特色

### 6.1 硬止损机制

```python
stoploss = -0.28031  # -28% 硬止损
```

- **28% 止损幅度**：非常宽松，给予价格充分波动空间
- **设计目的**：配合高 ROI 目标，允许短期较大回撤
- **风险提示**：单笔最大亏损可达 28%

### 6.2 追踪止损机制

- **启动条件**：利润 ≥ 1.013%
- **触发条件**：利润 ≥ 10.858%
- **锁定利润**：10.858% - 1.013% = 9.845%

### 6.3 ROI 退出机制

- **分阶段退出**：4 档 ROI，目标依次降低
- **逻辑**：早期追求高利润，后期稳健退出

### 6.4 风险提示

- **无成交量过滤**：买入信号未验证成交量，可能产生假突破
- **宽松止损**：28% 止损意味着需要更高胜率才能盈利
- **交易频率**：5m 框架交易频率适中

## 七、策略优势与局限

### ✅ 优势

1. **信号简洁**：买入和卖出条件各只有一个，清晰易懂
2. **动量捕捉**：CMO 上穿零轴是经典的动量转强信号
3. **宽松止损**：28% 止损配合 28% ROI，适合趋势行情
4. **布林带辅助**：3.5σ 宽布林带可以过滤假突破
5. **追踪止损**：有效锁定利润，避免回吐

### ⚠️ 局限

1. **参数敏感**：CMO 周期（50）和布林带参数（25, 3.5）对结果影响较大
2. **单一买入信号**：没有其他指标确认，可能产生假信号
3. **高止损风险**：28% 止损意味着需要高胜率或高盈亏比
4. **无趋势过滤**：策略没有均线趋势确认，可能逆势交易
5. **无成交量验证**：未使用成交量过滤信号

## 九、适用市场环境详解

### 9.1 策略核心逻辑

Chandem 是一个**动量突破型策略**，其核心逻辑包含两个层面：

1. **动量层**：利用 CMO 识别价格动量从空转多的转折点
2. **突破层**：利用布林带上轨识别价格极端，触发卖出

### 9.2 不同市场环境表现

| 市场类型 | 表现评级 | 原因分析 |
| :--- | :--- | :--- |
| 📈 上升趋势 | ⭐⭐⭐⭐⭐ | CMO 上穿发生在趋势初期，布林上轨突破在趋势末期，完整捕捉 |
| 📉 下降趋势 | ⭐⭐☆☆☆ | CMO 可能频繁上穿产生假信号，缺乏趋势过滤 |
| 🔄 震荡市场 | ⭐⭐⭐☆☆ | CMO 在零轴附近波动，可能产生多次信号 |
| ⚡ 极端波动 | ⭐⭐⭐⭐☆ | CMO 对极端价格变动敏感，布林带参数需调整 |

### 9.3 关键配置建议

| 配置项 | 建议值 | 说明 |
|--------|--------|------|
| 交易对 | 趋势性强的高流动性币种 | 趋势行情效果最佳 |
| 手续费 | < 0.1% | 配合高 ROI 目标需要低手续费 |
| ROI | 20%-30% | 初始目标，根据市场调整 |
| 止损 | -20% 到 -30% | 与初始 ROI 匹配 |

## 十、重要提醒：复杂性的代价

### 10.1 学习成本

- **指标理解**：需要理解 CMO 和布林带的含义及计算方法
- **参数敏感度**：50 周期 CMO 和 25 周期 3.5σ 布林带需要根据市场调整
- **信号频率**：5m 框架信号频率适中，但仍需持续监控

### 10.2 硬件要求

| 交易对数量 | 最低内存 | 推荐内存 |
|-----------|---------|---------|
| 5-10 对 | 1 GB | 2 GB |
| 20-30 对 | 2 GB | 4 GB |

### 10.3 回测与实盘的差异

- **滑点影响**：5m 框架对滑点有一定敏感性
- **信号延迟**：CMO 计算需要一定历史数据
- **流动性风险**：使用典型价计算布林带，与收盘价略有差异

### 10.4 手动交易者建议

1. 监控 CMO 从负转正的金叉信号
2. 确认 CMO 上穿时成交量配合
3. 观察布林带位置，价格接近上轨时准备卖出
4. 结合趋势均线判断，避免逆势交易

## 十一、总结

**Chandem** 是一个**动量突破型交易策略**，其核心价值在于：

1. **简洁的信号逻辑**：CMO 上穿买入，布林上轨突破卖出
2. **高 ROI 目标**：首级 28.4% 盈利目标，追求大幅获利
3. **宽松止损**：28% 止损给予价格充分波动空间
4. **追踪止损保护**：自动锁定利润，避免回吐

对于量化交易者而言，Chandem 适合**趋势行情中追求大幅盈利**的交易者，但需要关注：
- 宽松止损带来的单笔较大亏损风险
- 无趋势过滤可能产生的逆势交易
- 参数敏感度需要根据市场调整

建议先在模拟盘进行充分测试，确认策略有效性后再进行实盘交易。

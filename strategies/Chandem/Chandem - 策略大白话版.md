# Chandem 策略：动量突破 + 布林带逃顶

> **外号**：动量猎手  
> **职业**：专门捕捉价格"由跌转涨"瞬间的顺势交易者  
> **时间框架**：5 分钟

---

## 一、这策略是个啥？

简单说，**Chandem** 就是一个：
- 用 CMO 指标找"价格由跌转涨"的转折点买入
- 等价格涨到"太离谱"的时候（布林带上轨）卖出
- 目标是赚一笔大的（28%！），但也允许亏一笔大的（28%！）

就像一个**耐心的猎人**：
- 趴在草丛里等猎物现身（CMO 上穿零轴）
- 猎物跑得太远就收网（价格突破布林上轨）
- 吃中间那段最肥的肉 🍖

**一句话总结**：
> "趋势刚启动时入场，价格涨到极端时跑路——简单粗暴但有效！"

## 二、核心配置：说白了就是"赚 28% 就跑，亏 28% 就认栽"

### 止盈规则（ROI 表）

```
0 分钟     → 28.4% 利润 → 跑！
16 小时    → 9.3% 利润  → 跑！
29 小时    → 6.6% 利润  → 跑！
51 小时    → 0% 利润    → 跑！（保本）
```

**翻译成人话**：
> "刚入场时野心很大，要赚 28%！但随着时间推移，目标越来越低。熬了快 2 天还没赚到钱？那就保本走人，别耗了。"

**这设计啥意思？**
- 追求暴利：刚入场时目标 28%
- 时间成本：拖得越久，目标越低
- 止损认赔：51 小时还没赚钱就直接清仓

### 止损规则

```
硬止损 = -28%
```

**翻译成人话**：
> "亏 28% 就认栽，别跟市场犟。虽然肉疼，但这就是游戏规则。"

**大白话**：这策略很"豪横"——要赚大的，也允许亏大的。你受得了吗？

### 追踪止损

```
利润达到 1.013%    → 启动追踪
利润达到 10.858%   → 锁定 9.8% 利润
```

**翻译成人话**：
> "一旦利润超过 10%，我就开始盯着。要是跌回来，赚够 9.8% 我就跑路——绝不贪心！"

## 三、1 个买入条件：CMO 上穿零轴

别看这策略代码写了老长，**买入条件其实只有 1 个**！

```
CMO 今日 ≥ 0   AND   CMO 昨日 < 0
```

### 🎯 买入信号：动量由空转多

**大白话**：
> "昨天还跌得欢，今天居然开始涨了——这就是我要的转折点！入场！"

### CMO 是啥？（说人话版）

CMO（Chande Momentum Oscillator）= **钱德动量振荡器**

别被名字吓到，其实就是：
- **值为负**：最近跌得比涨得多 → 下跌动量占优
- **值为正**：最近涨得比跌得多 → 上涨动量占优
- **从负转正**：动量从"跌"变成"涨" → **买入信号！**

### 为什么用 50 周期？

```
50 根 5 分钟 K 线 = 约 4 小时
```

这意味着 CMO 看的是**过去 4 小时**的整体动量，不是几分钟的短期波动，而是中期趋势的转变。

**大白话**：
> "我不关心你 5 分钟前发生了什么，我只关心过去 4 小时你是涨是跌。从跌转涨？那就是我的入场点！"

**大白话总结**：

## 五、卖出逻辑：价格"涨太离谱"就跑

### 卖出条件：价格突破布林带上轨

```
收盘价上穿 布林带上轨
```

**大白话**：
> "价格涨到布林带的'天花板'了！这意味着价格已经'太离谱了'，赶紧跑！"

### 布林带是啥？（说人话版）

**布林带** = 价格波动的"轨道"或"走廊"

```
───────────── 上轨（天花板）← 涨到这就"太离谱"了
      ↕ 股价
───────────── 中轨（均价）
      ↕ 股价
───────────── 下轨（地板）
```

- **中轨**：过去 25 根 K 线的平均价格
- **上下轨**：中轨 ± 3.5 倍标准差
- **3.5 倍标准差**：比普通的 2 倍更宽——只有涨得"特别离谱"才触发

**大白话**：
> "普通布林带太敏感，涨一点点就碰上轨。我用 3.5σ 加宽轨道，只有涨得'太变态'才卖——吃最肥的那段肉！"

### 卖出时机的艺术

这个策略的卖出逻辑其实很聪明：

1. **买入时机**：CMO 从负转正 → 趋势刚启动
2. **卖出时机**：价格突破布林上轨 → 趋势快结束

**大白话**：
> "我是吃鱼身的人——鱼头（趋势启动前）和鱼尾（趋势快结束时）都不吃，只吃中间最肥的那段！"

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

| 优点 | 说明 |
|------|------|
| 🎯 **信号简洁** | 买入 1 个条件，卖出 1 个条件，清清楚楚 |
| 🧠 **逻辑直接** | CMO 上穿买入，布林上轨卖出，不搞花里胡哨 |

| 🍖 **追求暴利** | 28% ROI 目标，不是那种赚 2% 就跑的策略 |

### ⚠️ 缺点（吐槽环节）

| 缺点 | 说明 |
|------|------|
| 💀 **止损太宽** | -28% 止损，单笔亏损可能很大 |
| 🎲 **赌性太强** | 高 ROI + 高止损，完全是高风险高回报风格 |
| 🚫 **没趋势过滤** | 没有均线确认趋势，可能逆势买入 |
| 🚫 **没成交量确认** | 信号不验证成交量，可能假突破 |
| 😵 **可能被震荡市收割** | CMO 在零轴反复穿越，频繁打脸 |

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

Chandem 的历史回测表现可能**还不错**——但这有个陷阱：

> **因为参数是优化过的，策略很容易"拟合"过去行情，但这并不代表未来一定能盈利。**

简单说就是：**"背答案"和"会做题"是两回事！**

### 复杂策略的隐藏风险

实盘时，你要注意：

- **宽止损风险**：28% 止损意味着单笔可能亏损很大
- **逆势交易风险**：没有趋势过滤，可能抄底抄在半山腰
- **假突破风险**：没有成交量确认，可能是假信号
- **参数敏感性**：CMO 周期和布林带参数对结果影响很大

### 我的建议（真心话）

```
1. 先模拟盘测试至少 2 周，看看策略是否适合你的风格
2. 调整止损到你能接受的范围内（比如 -15% 到 -20%）
3. 加入趋势确认（比如 MA200 或 EMA 趋势）
4. 加入成交量过滤（买入时成交量放大）
5. 小资金起步，逐步加仓
```

### 特别提醒

⚠️ **28% 的止损不是开玩笑的！**

如果你有 10000 U：
- 亏损 28% = 亏 2800 U
- 连续亏损 3 次 = 亏 8400 U
- 你还剩 1600 U……

**记住**：策略再好，市场教做人时也不会打招呼。轻仓测试，活着最重要！🙏

## 一、策略概览

Heracles（赫拉克勒斯）是一个基于波动率极端值捕捉的超长期趋势策略。策略名称源自希腊神话中最伟大的英雄——赫拉克勒斯，象征着力量与耐力。正如其名，这是一个需要极大耐心的策略：12 小时时间框架，持仓时间可达 7 天以上。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | Donchian Channel 百分位低于 Keltner Channel 宽度（波动率极端压缩） |
| **卖出条件** | MACD Signal 下穿 EMA(12) |
| **保护机制** | 硬止损 + 追踪止损 |
| **时间框架** | 12 小时（超长线） |
| **持仓周期** | 最长可达 7.5 天以上 |

## 三、买入条件详解

### 3.1 核心买入逻辑

策略的核心买入条件可概括为：

```python
Donchian_Channel_Percentile < Keltner_Channel_Width
```

**逻辑解析**：
- Donchian Channel 百分位反映价格在区间内的相对位置
- Keltner Channel 宽度反映市场波动率
- 当百分位低于宽度时，表明价格处于波动率极端压缩状态

### 3.2 买入条件详解

#### 波动率压缩信号

**技术含义**：
- 波动率极端压缩是市场即将选择方向的前兆
- 类似"弹簧压缩"原理：压缩越紧，释放时能量越大
- 在低波动期入场，等待趋势突破

**入场时机判断**：

| 市场状态 | Donchian 百分位 | Keltner 宽度 | 信号 |
|---------|---------------|-------------|------|
| 极端压缩 | 很低 | 相对较高 | ✅ 买入 |
| 正常波动 | 中等 | 中等 | ⏸️ 观望 |
| 高波动 | 很高 | 很高 | ❌ 不买 |

### 3.3 买入信号综合判断

策略的买入逻辑可概括为：
> **等波动压缩到极致再进场** —— 当 Donchian 百分位远低于 Keltner 宽度时，表明市场能量正在积蓄，即将释放。

## 四、卖出逻辑详解

### 4.1 卖出条件

策略采用 MACD 与 EMA 的交叉信号作为退出依据：

```python
MACD_Signal 下穿 EMA(12)
```

**逻辑解析**：
- MACD Signal 是 MACD 指标的信号线
- EMA(12) 是快速指数移动平均线
- 当 Signal 下穿 EMA(12)，表明短期动量转弱

### 4.2 卖出信号详解

| 信号名称 | 触发条件 | 技术含义 |
|---------|---------|---------|
| MACD 动量衰减 | Signal < EMA(12) | 短期上涨动量减弱 |
| 趋势确认反转 | Signal 持续低于 EMA | 可能进入下跌趋势 |

### 4.3 ROI 分级止盈机制

策略采用分阶段止盈策略：

| 持仓时间 | 目标利润 | 设计意图 |
|---------|---------|----------|
| 立即 | 32.8% | 捕捉大趋势的主升浪 |
| 27 小时后 | 17.9% | 趋势延续时降低预期 |
| 4 天后 | 5.4% | 长期持仓保守锁定 |
| 7.5 天后 | 保本 | 时间止损，强制退出 |

**设计理念**：
- 超长期策略追求大趋势
- 分级止盈在趋势延续时逐步锁定
- 时间止损避免无限期持仓

## 五、技术指标体系

### 5.1 核心指标

| 指标类别 | 具体指标 | 用途 |
|---------|---------|------|
| **波动率指标** | Keltner Channel | 测量市场波动率宽度 |
| **位置指标** | Donchian Channel | 判断价格在区间内的相对位置 |
| **趋势指标** | MACD | 判断趋势方向和动量 |
| **趋势指标** | EMA(12) | 快速趋势参考，辅助卖出判断 |

### 5.2 指标协同关系

```
入场信号链：
Keltner Channel 宽度 → 判断波动率状态
        ↓
Donchian Channel 百分位 → 判断价格位置
        ↓
波动率压缩确认 → 入场

出场信号链：
MACD Signal → 动量方向
        ↓
EMA(12) → 快速趋势参考
        ↓
Signal 下穿 EMA → 出场
```

### 5.3 波动率压缩原理

**核心概念**：
- 低波动率状态是市场能量积蓄阶段
- 波动率不可能永远维持在极端低位
- 突破方向可通过其他指标辅助判断

**数学表达**：
```
波动率压缩程度 = Keltner_Width - Donchian_Percentile
压缩程度越高 → 突破概率越大
```

## 六、风险管理特色

### 6.1 硬止损与追踪止损结合

```python
stoploss = -0.0466              # 硬止损
trailing_stop_positive = 0.024  # 追踪止损启动点
```

**设计理念**：

| 止损类型 | 触发条件 | 保护目标 |
|---------|---------|---------|
| 硬止损 | -4.66% | 限制最大亏损 |
| 追踪止损 | 利润 > 2.4% | 锁定盈利空间 |

**特点分析**：
- 硬止损相对紧窄（-4.66%），快速止损
- 追踪止损启动点 2.4%，锁定早期盈利
- 两者结合，既保护本金又锁定利润

### 6.2 时间止损机制

策略的时间止损设计：

| 时间节点 | 止盈目标 | 含义 |
|---------|---------|------|
| 立即 | 32.8% | 理想目标 |
| 27 小时 | 17.9% | 降低预期 |
| 4 天 | 5.4% | 保守锁定 |
| 7.5 天 | 保本 | 时间止损 |

**设计意图**：
- 超长期持仓并非无限期持有
- 随时间延长降低盈利预期
- 7.5 天后强制保本退出

### 6.3 持仓时间管理

超长期策略的特殊考量：

| 风险因素 | 管理方式 |
|---------|---------|
| 市场变化 | 时间止损控制持仓时长 |

## 七、策略优势与局限

### ✅ 优势

1. **捕捉大趋势**：32.8% 的初始目标体现趋势跟随定位
2. **无需频繁盯盘**：12h 时间框架，信号频率低
3. **波动率先行**：在突破前入场，享受主升浪
4. **风险控制明确**：硬止损 + 追踪止损双重保护

### ⚠️ 局限

1. **持仓时间长**：最长可达 7 天以上，资金占用时间长
2. **信号频率低**：需要耐心等待机会
3. **紧窄止损风险**：-4.66% 可能在正常波动中被触发
4. **不适合急性子**：需要极强的耐心

## 二、核心配置：说白了就是"全面覆盖"

### 止盈规则（ROI 表）

```
持仓 < 30分钟 → 赚 10% 就跑 🤑
持仓 30-60分钟 → 赚 5% 就跑 📈
持仓 > 60分钟 → 赚 2% 就跑 💨
```

**翻译**：
这个止盈设计很聪明：
- 早期（<30分钟）：目标是抓大趋势，10%才跑
- 中期（30-60分钟）：稍微降低预期，5%
- 后期（>60分钟）：2%也跑了，别贪心

### 止损规则

```
亏损 10% → 认赔走人 🏳️
追踪止损 → 赚 3% 后激活，1% 回撤触发
```

**翻译**：
- 10% 固定止损，标准设置
- 追踪止损很保守：必须先赚 3%，然后利润回吐到只赚 2% 就触发

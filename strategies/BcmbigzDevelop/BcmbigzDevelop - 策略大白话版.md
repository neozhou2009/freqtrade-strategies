## 三、22 个买入条件：我帮你分类好了

这策略的买入条件超级多，我给你归了 3 大类：

### 🎯 第一类：bzv7 家族（14 个条件）
**核心逻辑**：RSI 过滤 + 成交量过滤 + 布林带突破

**大白话**：
> "市场不能太弱（RSI 不能太高），成交量要有规律（先大后小），价格要够便宜（碰布林带下轨）"

**代表条件**：

- **bzv7_0**：RSI 超卖 + 强势确认
  ```python
  rsi < 30 & rsi_1h < 71 & 收盘价在 EMA200 上方
  ```
  > "5分钟要超卖，1小时也要强势，还要在上涨趋势中！"

- **bzv7_1-2**：布林带安全区域
  ```python
  收盘价 < bb_lowerband * 0.989
  ```
  > "价格要在布林带下轨附近，不能太远！"

- **bzv7_3-4**：1小时 RSI 过滤
  ```python
  rsi_1h < 16.5-35 & 价格 < bb_lowerband
  ```
  > "1小时也要超卖！"

- **bzv7_5-7**：MACD 交叉
  ```python
  ema26 > ema12 & macd 差值 > 阈值 & 价格 < bb_lowerband
  ```
  > "MACD 要金叉，价格要够便宜！"

- **bzv7_8-9**：双 RSI 过滤
  ```python
  rsi_1h < 20 & rsi < 28
  ```
  > "5分钟和1小时都要超卖！"

### 🎯 第二类：v6 家族（4 个条件）
**核心逻辑**：EMA 多头排列 + 布林带突破

**大白话**：
> "要在上涨趋势中（EMA 多头），价格要回调到布林带下轨！"

**经典台词**：
- v6_0：`收盘价 > EMA200 & 收盘价 < EMA50 & 价格 < bb_lowerband`
  > "长期趋势向上，短期回调到支撑位，买！"

### 🎯 第三类：v8 家族（5 个条件）
**核心逻辑**：SSL 通道 + EMA 交叉 + 多时间框架确认

**大白话**：

## 五、卖出逻辑：比买入更花哨

### 5.1 分级止盈：赚多少跑

```
盈利 14-30% + RSI < 58 → 跑！
盈利 8-14% + RSI < 56 → 跑！
盈利 4-8% + RSI < 50 → 跑！
盈利 1-4% + RSI < 50 → 跑！
盈利 0-1% + SMA200 死叉 → 跑！
```

**大白话**：
- "赚大钱的时候，别贪婪，见好就收！"
- "赚小钱的时候，RSI 一到就撤！"

### 5.2 追踪止盈

```
盈利 10-40% + 价格从高点回撤 > 3% → 跑！
盈利 2-10% + 价格从高点回撤 > 1.5% → 跑！
```

**大白话**：
> "已经赚了不少了，吐回一部分就跑！"

### 5.3 自定义止损

```python
if 盈利:
    持有（让利润奔跑）
elif 持仓 > 240 分钟:
    if rsi_1h < 35:
        持有（等反弹）
    elif 价格 > EMA200:
        割肉 10%
    elif 价格继续下跌:
        割肉 1%
```

**大白话**：
> "亏钱的时候要看情况：如果市场还要跌就死扛，如果反弹无力就割肉！"

## 一、策略概览

Strategy002 是一个基于超卖反弹的经典量化策略，通过 RSI、Stochastic 和布林带的超卖信号寻找价格底部，并配合锤子线蜡烛图形态确认反转时机。策略设计简洁明了，适合作为入门级量化策略学习。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 1 个综合买入信号，四个指标必须同时满足 |
| **卖出条件** | 1 个基础卖出信号，基于 SAR 和 Fisher RSI |
| **保护机制** | 固定止损 + 追踪止损双重保护 |
| **时间框架** | 5m 单一时间框架 |
| **依赖库** | talib, qtpylib, numpy |

## 三、买入条件详解

### 3.1 单一买入信号

策略采用严格的四条件叠加，所有条件必须同时满足：

```python
(dataframe['rsi'] < 30) &                    # 条件1：RSI超卖
(dataframe['slowk'] < 20) &                  # 条件2：Stochastic超卖
(dataframe['bb_lowerband'] > dataframe['close']) &  # 条件3：价格跌破布林下轨
(dataframe['CDLHAMMER'] == 100)              # 条件4：锤子线形态确认
```

### 3.2 条件逻辑分析

| 条件编号 | 指标 | 条件值 | 市场含义 |
|---------|------|--------|---------|
| #1 | RSI | < 30 | 进入超卖区域，价格可能被过度抛售 |
| #2 | Stochastic 慢K | < 20 | 动量指标确认超卖状态 |
| #3 | 收盘价 < 布林下轨 | 价格跌破下轨 | 价格偏离均值过大 |
| #4 | 锤子线形态 | == 100 | 蜡烛图形态确认反转信号 |

### 3.3 买入逻辑总结

策略在以下情况买入：
1. RSI 指标显示市场处于超卖状态（<30）
2. Stochastic 指标的慢K线也确认超卖（<20）
3. 价格已经跌破布林带下轨，出现异常偏离
4. K线出现锤子线形态，表明可能出现反转

**典型场景**：价格急剧下跌后的底部反转机会

## 四、卖出逻辑详解

### 4.1 卖出信号

```python
(dataframe['sar'] > dataframe['close']) &   # 条件1：SAR反转
(dataframe['fisher_rsi'] > 0.3)              # 条件2：Fisher RSI确认强势
```

**逻辑分析**：

| 条件 | 指标 | 条件值 | 含义 |
|------|------|--------|------|
| #1 | Parabolic SAR | > 收盘价 | 价格跌破SAR支撑位，趋势可能反转 |
| #2 | Fisher RSI | > 0.3 | 动量已脱离超卖区域 |

### 4.2 ROI 分级止盈

```
持仓时间    最小利润目标
────────────────────────
0-20分钟    5%
20-30分钟   4%
30-60分钟   3%
60分钟+     1%
```

**设计理念**：随着持仓时间延长，降低盈利期望，优先锁定收益。

## 五、技术指标体系

### 5.1 核心指标

| 指标类别 | 具体指标 | 用途 |
|---------|---------|------|
| 动量指标 | RSI (14) | 识别超卖/超买 |
| 动量指标 | Stochastic (慢K) | 确认超卖状态 |
| 波动指标 | Bollinger Bands (20, 2) | 判断价格偏离 |
| 趋势指标 | Parabolic SAR | 判断趋势反转 |
| 动量指标 | Fisher RSI | RSI的变形，增强信号 |
| 形态指标 | Hammer 蜡烛图 | 确认反转形态 |

### 5.2 指标计算详解

**Fisher RSI 变换**：
```python
rsi = 0.1 * (dataframe['rsi'] - 50)
dataframe['fisher_rsi'] = (numpy.exp(2 * rsi) - 1) / (numpy.exp(2 * rsi) + 1)
```
- 将 RSI 从 [0, 100] 映射到 [-1, 1]
- 增强极端值的敏感度

## 六、风险管理特色

### 6.1 双重止损机制

| 止损类型 | 触发条件 | 说明 |
|---------|---------|------|
| 固定止损 | 亏损达 10% | 硬性保护线 |
| 追踪止损 | 利润回撤 1%（利润>2%后） | 锁定浮动利润 |

### 6.2 分级止盈保护

- 分层利润目标：从 5% 逐步降至 1%
- 时间加权：持仓越久，容忍越低
- 与追踪止损配合，形成多层退出机制

### 6.3 订单类型配置

| 场景 | 订单类型 | 优势 |
|------|---------|------|
| 常规买卖 | 限价单 | 减少滑点 |
| 紧急止损 | 市价单 | 确保成交 |

## 七、策略优势与局限

### ✅ 优势

1. **逻辑清晰**：四个买入条件明确，易于理解和调试
2. **超卖捕捉**：多指标共振确认超卖底部，减少假信号
3. **形态确认**：锤子线蜡烛图增加反转可信度
4. **风险控制完善**：固定止损 + 追踪止损 + 分级止盈

### ⚠️ 局限

1. **买入机会有限**：四条件同时满足的概率较低
2. **依赖反转行情**：在持续下跌趋势中可能反复止损
3. **单一时间框架**：5分钟框架噪音较多，可能产生误判
4. **缺少过滤机制**：没有交易量确认或大盘趋势过滤

## 一、策略概览

Strategy003 是一个相对复杂的超卖反弹策略，在 Strategy002 的基础上增加了更多过滤条件。它使用 RSI、Fisher RSI、MFI、Stochastic Fast、EMA 均线组和 SMA 均线的多重组合，通过严格的条件筛选寻找高质量的反转机会。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 1 个综合买入信号，包含 8 个子条件 |
| **卖出条件** | 1 个基础卖出信号，基于 SAR 和 Fisher RSI |
| **保护机制** | 固定止损 + 追踪止损双重保护 |
| **时间框架** | 5m 单一时间框架 |
| **依赖库** | talib, qtpylib, numpy |

## 三、买入条件详解

### 3.1 综合买入信号

策略采用极其严格的多条件组合，所有条件必须同时满足：

```python
(dataframe['rsi'] < 28) &                                          # 条件1：RSI超卖
(dataframe['rsi'] > 0) &                                            # 条件2：RSI有效性检查
(dataframe['close'] < dataframe['sma']) &                          # 条件3：价格低于SMA
(dataframe['fisher_rsi'] < -0.94) &                                 # 条件4：Fisher RSI极端超卖
(dataframe['mfi'] < 16.0) &                                        # 条件5：MFI资金流量超卖
(                                                                   # 条件6：趋势过滤（二选一）
    (dataframe['ema50'] > dataframe['ema100']) |                   # 6a：中期趋势向上
    (qtpylib.crossed_above(dataframe['ema5'], dataframe['ema10'])) # 6b：短期金叉
) &
(dataframe['fastd'] > dataframe['fastk']) &                        # 条件7：Stochastic动量向上
(dataframe['fastd'] > 0)                                            # 条件8：动量有效性检查
```

### 3.2 条件逻辑分析

| 条件编号 | 指标 | 条件值 | 市场含义 |
|---------|------|--------|---------|
| #1 | RSI | < 28 | 进入深度超卖区域 |
| #2 | RSI | > 0 | 有效性检查（排除异常数据） |
| #3 | 收盘价 vs SMA(40) | 价格 < SMA | 价格低于中期均线 |
| #4 | Fisher RSI | < -0.94 | 极端超卖（接近-1的下限） |
| #5 | MFI | < 16.0 | 资金流量枯竭，卖压过度 |
| #6a | EMA50 vs EMA100 | EMA50 > EMA100 | 中期趋势向上（多选一） |
| #6b | EMA5 vs EMA10 | 金叉 | 短期反弹信号（多选一） |
| #7 | FastD vs FastK | FastD > FastK | 动量向上反转 |
| #8 | FastD | > 0 | 有效性检查 |

### 3.3 买入逻辑总结

策略在以下所有条件满足时才买入：
1. **深度超卖**：RSI < 28（比普通超卖30更严格）
2. **极端动量**：Fisher RSI < -0.94（接近极值）
3. **资金枯竭**：MFI < 16.0（卖压过度释放）
4. **价格低位**：低于 SMA40 中期均线
5. **趋势确认**：要么中期趋势向上（EMA50>EMA100），要么短期金叉
6. **动量反转**：Stochastic Fast 的 D线在 K线上方且大于0

**典型场景**：价格暴跌后出现深度超卖，同时市场有反弹迹象

## 五、技术指标体系

### 5.1 核心指标

| 指标类别 | 具体指标 | 用途 |
|---------|---------|------|
| 动量指标 | RSI (14) | 识别超卖/超买 |
| 动量指标 | Fisher RSI | RSI的变形，增强极端值敏感度 |
| 资金流指标 | MFI | 资金流量强度 |
| 动量指标 | Stochastic Fast | 快速动量指标 |
| 趋势指标 | EMA (5/10/50/100) | 多周期趋势判断 |
| 趋势指标 | SMA (40) | 中期趋势参考 |
| 趋势指标 | Parabolic SAR | 趋势反转信号 |
| 波动指标 | Bollinger Bands | 计算中用但未作为条件 |

### 5.2 指标计算详解

**Fisher RSI 变换**：
```python
rsi = 0.1 * (dataframe['rsi'] - 50)
dataframe['fisher_rsi'] = (numpy.exp(2 * rsi) - 1) / (numpy.exp(2 * rsi) + 1)
```
- 将 RSI 从 [0, 100] 映射到 [-1, 1]
- < -0.94 表示极端超卖

**EMA 均线组**：
```python
dataframe['ema5'] = ta.EMA(dataframe, timeperiod=5)   # 短期
dataframe['ema10'] = ta.EMA(dataframe, timeperiod=10) # 短期
dataframe['ema50'] = ta.EMA(dataframe, timeperiod=50) # 中期
dataframe['ema100'] = ta.EMA(dataframe, timeperiod=100) # 长期
```

与 Strategy002 相比，Strategy003 增加了：
- **MFI 资金流指标**：确保卖压过度释放
- **EMA 均线组**：过滤趋势方向
- **更严格的 RSI 阈值**：28 vs 30

## 七、策略优势与局限

### ✅ 优势

1. **多重确认**：8个子条件确保信号质量
2. **趋势过滤**：EMA 均线组避免逆势抄底
3. **资金流确认**：MFI 指标确保卖压释放
4. **极端值捕捉**：Fisher RSI < -0.94 捕捉极端超卖

### ⚠️ 局限

1. **信号稀少**：8个条件同时满足概率极低
2. **过度拟合风险**：条件过多可能导致历史数据表现好但实盘差
3. **复杂性增加**：维护和调试难度增加
4. **单一时间框架**：5分钟框架噪音问题依然存在

## 十、重要提醒：复杂性的代价

### 10.1 学习成本

- 策略涉及多个指标组合，需要一定技术分析基础
- EMA 均线组的使用需要理解趋势过滤原理
- Fisher RSI 变换需要一定数学理解

### 10.2 硬件要求

| 交易对数量 | 最低内存 | 推荐内存 |
|-----------|---------|---------|
| 1-10 个 | 2GB | 4GB |
| 10-50 个 | 4GB | 8GB |

### 10.3 回测与实盘的差异

- 多条件组合在回测中可能产生"完美匹配"偏差
- 实盘中条件越多，假信号概率也越高
- EMA 金叉等信号存在滞后性

### 10.4 手动交易者建议

策略逻辑可手动执行，但需要：
1. 同时监控多个指标
2. 熟练使用均线系统判断趋势
3. 理解 MFI 资金流量指标的含义

## 一、策略概览

SuperTrendPure 是一个基于 SuperTrend 指标的纯趋势跟踪策略。策略设计极为简洁，仅依赖单一指标进行交易决策，体现了"少即是多"的量化哲学。策略通过 ATR（平均真实波幅）构建动态支撑阻力线，捕捉趋势转换点。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 1 个独立买入信号（收盘价上穿 SuperTrend 线） |
| **卖出条件** | 1 个基础卖出信号（收盘价下穿 SuperTrend 线） |
| **保护机制** | 分级 ROI + 止损 + 追踪止损三重保护 |
| **时间框架** | 1h |
| **依赖库** | talib, qtpylib, numpy |

## 三、买入条件详解

### 3.1 核心买入逻辑

策略仅有一个买入条件，逻辑清晰：

```python
# 买入条件
(
    (qtpylib.crossed_above(dataframe['close'], dataframe['st'])) &  # 收盘价上穿 SuperTrend 线
    (dataframe['volume'].gt(0))                                       # 有成交量
)
```

**技术解读**：
- **crossed_above**：收盘价从下方穿越 SuperTrend 线，形成趋势反转信号
- **volume > 0**：基础成交量过滤，避免零成交异常

### 3.2 SuperTrend 指标参数

```python
supertrend = self.supertrend(dataframe, 2, 8)  # multiplier=2, period=8
```

| 参数 | 值 | 说明 |
|------|-----|------|
| **ATR 周期** | 8 | 短周期 ATR，响应较快 |
| **ATR 乘数** | 2 | 标准乘数，中等敏感度 |

**SuperTrend 计算逻辑**：
1. 计算 True Range 和 ATR（SMA 平滑）
2. 计算基础上下轨：(最高+最低)/2 ± 乘数 × ATR
3. 计算最终上下轨（考虑趋势连续性）
4. 根据价格与轨道关系确定趋势方向

## 四、卖出逻辑详解

### 4.1 基础卖出信号

```python
# 卖出条件
(
    (qtpylib.crossed_below(dataframe['close'], dataframe['st'])) &  # 收盘价下穿 SuperTrend 线
    (dataframe['volume'].gt(0))                                        # 有成交量
)
```

**技术解读**：
- **crossed_below**：收盘价从上方跌破 SuperTrend 线，趋势反转信号
- 信号与买入条件完全对称，形成完整的趋势跟踪闭环

### 4.2 分级止盈系统

策略通过 ROI 表实现分级止盈：

| 持仓时间 | 目标收益率 | 说明 |
|---------|-----------|------|
| 0 分钟 | 8.7% | 即时止盈目标 |
| 372 分钟（~6 小时） | 5.8% | 首次降级 |
| 861 分钟（~14 小时） | 2.9% | 二次降级 |
| 2221 分钟（~37 小时） | 0% | 保本退出 |

### 4.3 追踪止损机制

| 参数 | 值 | 说明 |
|------|-----|------|
| **trailing_stop** | True | 启用追踪止损 |
| **trailing_stop_positive** | 0.05 | 盈利 5% 后开始追踪 |
| **trailing_stop_positive_offset** | 0.144 | 盈利 14.4% 后激活 |
| **trailing_only_offset_is_reached** | False | 达到偏移前也追踪 |

**工作机制**：
- 当盈利达到 5% 时，追踪止损开始记录最高价
- 当盈利达到 14.4% 时，从最高价回撤触发止损
- 回撤幅度由 Freqtrade 自动计算

## 五、技术指标体系

### 5.1 核心指标

| 指标类别 | 具体指标 | 用途 |
|---------|---------|------|
| **趋势指标** | SuperTrend (ATR 乘数 2, 周期 8) | 趋势方向判断、买卖信号生成 |
| **波动率指标** | ATR (Average True Range) | 动态轨道宽度计算 |
| **基础过滤** | Volume | 成交量有效性验证 |

### 5.2 SuperTrend 指标详解

策略内置了 SuperTrend 计算函数，核心逻辑如下：

```python
def supertrend(self, dataframe, multiplier, period):
    # 1. 计算真实波幅和 ATR
    df['TR'] = ta.TRANGE(df)
    df['ATR'] = ta.SMA(df['TR'], period)
    
    # 2. 计算基础轨道
    df['basic_ub'] = (df['high'] + df['low']) / 2 + multiplier * df['ATR']
    df['basic_lb'] = (df['high'] + df['low']) / 2 - multiplier * df['ATR']
    
    # 3. 计算最终轨道（考虑连续性）
    # 4. 确定趋势方向
    df[stx] = np.where((df[st] > 0.00), 
                       np.where((df['close'] < df[st]), 'down', 'up'), 
                       np.NaN)
```

**输出**：
- `ST`：SuperTrend 线值（支撑/阻力位）
- `STX`：趋势方向（'up' 或 'down'）

## 六、风险管理特色

### 6.1 宽止损设计

- **止损值**：-26.5%
- **设计理由**：趋势策略需要足够空间应对正常回调
- **适用场景**：中长线趋势交易，非高频短线

### 6.2 追踪止损保护

- **激活阈值**：14.4% 盈利
- **追踪起点**：5% 盈利
- **保护效果**：确保趋势行情中锁定大部分利润

### 6.3 时间衰减机制

- **ROI 降级**：从 8.7% 逐级降至 0
- **时间限制**：最长持仓约 37 小时
- **风险控制**：避免无限期持仓亏损扩大

## 七、策略优势与局限

### ✅ 优势

1. **极简设计**：单一指标，逻辑清晰，易于理解和调试
2. **趋势捕捉**：基于 ATR 动态轨道，自适应市场波动
3. **风险可控**：多级止盈 + 追踪止损，攻守兼备
4. **计算高效**：指标计算简单，适合大量交易对并行

### ⚠️ 局限

1. **震荡市劣势**：纯趋势策略在横盘震荡市场容易反复止损
2. **滞后性**：SuperTrend 作为趋势指标，入场有延迟
3. **单一维度**：未考虑成交量变化、动量确认等辅助条件
4. **参数敏感**：ATR 周期和乘数参数对表现影响较大

## 九、适用市场环境详解

SuperTrendPure 是一个典型的单因子趋势策略。基于其代码架构，它最适合 **单边趋势行情**，而在 **震荡整理行情** 时表现不佳。

### 9.1 策略核心逻辑

- **趋势识别**：通过价格突破 ATR 动态轨道判断趋势转换
- **顺势交易**：上穿做多，下穿退出
- **动态适应**：轨道宽度随 ATR 变化，自动适应市场波动

### 9.2 不同市场环境表现

| 市场类型 | 表现评级 | 原因分析 |
| :--- | :--- | :--- |
| 📈 **单边上涨** | ⭐⭐⭐⭐⭐ | SuperTrend 完美跟踪上涨趋势，获利空间大 |
| 🔄 **震荡整理** | ⭐⭐☆☆☆ | 频繁穿越轨道，反复止损，磨损严重 |
| 📉 **单边下跌** | ⭐⭐⭐☆☆ | 空仓观望，无交易（需配合做空策略） |
| ⚡️ **剧烈波动** | ⭐⭐⭐☆☆ | ATR 快速扩大，轨道变宽，信号减少 |

### 9.3 关键配置建议

| 配置项 | 建议值 | 说明 |
|--------|--------|------|
| **时间框架** | 1h-4h | 过短周期噪音大，过长周期滞后明显 |
| **交易对选择** | 趋势性强的品种 | 避免横盘币种 |
| **ATR 乘数** | 2-3 | 乘数越大信号越少越可靠 |

## 二、核心配置：说白了就是"稳中求进"

### 止盈规则（ROI 表）

```
刚买：赚 8.7% 就跑
等 6 小时还没赚到 8.7%：赚 5.8% 就跑
等 14 小时还没赚到：赚 2.9% 也行
等了 37 小时还没赚到：保本也跑，不跟你玩了
```

**翻译**：这策略有点"急脾气"，刚买入时目标高，持仓越久越想脱手。但这也很合理——趋势策略就是要趁热打铁，拖太久说明趋势可能已经结束了。

### 止损规则

```
硬止损：亏 26.5% 认输
追踪止损：赚了 14.4% 以后，从最高点回撤就跑
```

**翻译**：
- **硬止损 -26.5%**：这止损挺宽的，给趋势留足了回调空间。毕竟趋势交易嘛，要有耐心让利润奔跑。
- **追踪止损**：赚钱后自动保护利润，防止"到手的鸭子飞了"。

## 五、SuperTrend 指标：这根线是啥？

你可能会问：这根神奇的线到底是啥？

### SuperTrend 线的构成

SuperTrend 其实就是用 **ATR（平均真实波幅）** 画出来的动态支撑阻力线：

```
上轨 = (最高价 + 最低价) / 2 + 2 × ATR
下轨 = (最高价 + 最低价) / 2 - 2 × ATR
```

**翻译**：
- 取每天的最高价和最低价的中间值
- 往上加 2 倍的波动幅度（上轨）
- 往下减 2 倍的波动幅度（下轨）
- 价格在哪个轨道上面，就显示哪个轨道

### 这个策略用的参数

| 参数 | 值 | 通俗解释 |
|------|-----|---------|
| **ATR 周期** | 8 根 K 线 | 算最近 8 小时的平均波动 |
| **ATR 乘数** | 2 倍 | 轨道宽度 = 2 倍波动 |

**特点**：周期 8 比较短，反应快；乘数 2 比较标准，不太敏感也不太迟钝。

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **极简设计**：一个指标，一页代码，五分钟看懂。学量化从它开始准没错。
2. **趋势捕捉强**：大趋势来了，这策略能吃满整个行情。
3. **风控到位**：分级止盈 + 追踪止损，该进进该退退。
4. **计算高效**：跑 100 个交易对都不带喘气的。

### ⚠️ 缺点（吐槽环节）

1. **震荡市是噩梦**：横盘时这策略会反复打脸，买进去就跌破，卖完又涨上来……"左右挨打"。
2. **入场有点慢**：趋势指标嘛，总是等趋势走出来才进场，鱼头鱼尾都吃不到。
3. **只有一个维度**：不看成交量变化，不看动量，不看背离……万一这根线骗人呢？
4. **参数敏感**：ATR 周期和乘数稍微改改，表现可能差很多。

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

SuperTrendPure 的历史回测往往表现不错——在趋势行情里更是亮眼。但这有个陷阱：

> **趋势策略在震荡市会持续亏损，而市场 70% 的时间都在震荡。**

简单说就是：**你等的那个大趋势，可能要等很久很久……**

### 简单策略的隐藏风险

实盘时，看似简单的策略也有坑：
- **假突破**：价格刚突破就跌回来，典型"诱多"
- **滑点成本**：趋势突破时往往行情快，滑点不小
- **心理压力**：连续止损后还能坚持吗？

### 我的建议（真心话）

```
1. 先用这策略学习量化，别指望一上来就赚钱
2. 选趋势性强的币种（BTC、ETH 这种主流币）
3. 震荡时期主动降低仓位或暂停策略
4. 别频繁改参数——参数不是越多越好，也不是越调越好
```

**记住**：简单的策略不代表能赚钱，但简单的策略能让你 **快速理解为什么赚钱或为什么亏钱**——这才是学习的价值！🙏

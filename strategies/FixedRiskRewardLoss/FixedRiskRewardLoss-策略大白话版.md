# FixedRiskRewardLoss 策略：一个"数学家"式的止损管家

> **外号**：风险计算器  
> **职业**：量化界的"会计"——每笔交易都要算清楚风险/回报比  
> **时间框架**：5 分钟（短线选手）

---

## 一、这策略是个啥？

简单说，**FixedRiskRewardLoss** 就是一个：
- **教学示例策略**（不是用来赚钱的，是用来学习的）
- 演示怎么算风险/回报比
- 演示怎么做保本止损

就像一个买东西前先算清楚"亏多少、赚多少"的精算师："这笔交易我最多亏 100，至少要赚 350 才值得做！" 🧮

---

## 二、核心配置：说白了就是"精打细算"

### 止损规则

```
硬止损：亏 10% 直接割（兜底用）
自定义止损：风险/回报比 3.5:1 + 保本机制
```

**翻译**：这策略的重点是教你怎么做资金管理，交易逻辑反而是次要的。

## 四、止损机制：这才是主角

### 4.1 风险/回报比 3.5:1

**核心逻辑**：
1. 先算初始风险（ATR × 2）
2. 止盈目标 = 风险 × 3.5
3. 确保每笔交易至少赚 3.5 倍风险

**大白话**：
> "这笔交易我最多亏 100U，那至少要赚 350U 才值得做！"

**代码翻译**：
```python
# 风险计算
风险 = 开仓价 - 初始止损价
止盈目标 = 开仓价 + 风险 × 3.5
```

**经典台词**：
- "这才是这策略的主角，买入逻辑只是配角！"
- "学会这个，你就能算清楚每笔交易值不值得做！"

---

### 4.2 保本机制

**触发条件**：利润达到 1 倍风险

**大白话**：
> "赚够 1 倍风险了（比如风险 100，赚了 100），赶紧把止损调到保本位，这单最少不能亏！"

**代码翻译**：
```python
# 保本逻辑
if 当前利润 >= 1 倍风险:
    止损 = 开仓价 + 手续费  # 保本
```

---

### 4.3 三阶段止损

| 阶段 | 条件 | 止损位 | 大白话 |
|------|------|--------|--------|
| **初始** | 刚开仓 | ATR × 2 止损 | "先设个止损，最多亏这么多" |
| **保本** | 赚 1 倍风险 | 开仓价 + 手续费 | "赚够了，保本再说" |
| **止盈** | 赚 3.5 倍风险 | 止盈目标价 | "达到目标，获利了结" |

## 十三、⚠️ 风险再强调（这段一定要看）

### 这是示例策略！

FixedRiskRewardLoss 是**教学示例策略**，不是生产策略：

> **这策略没有买入逻辑，直接实盘会亏损。**

简单说就是：**人家是教材，不是印钞机！**

### 示例策略的隐藏风险

实盘时，简单的逻辑可能导致：
- **连续亏损**：没有买入条件，随机买入胜率低
- **震荡市被打脸**：可能频繁触发止损
- **无趋势保护**：下跌趋势中也会买入

### 我的建议（真心话）

```
1. 把这策略当教材，不要直接实盘
2. 理解风险/回报比计算原理
3. 在此基础上添加自己的买入逻辑
4. 添加趋势过滤、BTC 关联等保护机制
5. 完善后再考虑实盘
```

**记住**：这是教材，学会后你要自己写策略！

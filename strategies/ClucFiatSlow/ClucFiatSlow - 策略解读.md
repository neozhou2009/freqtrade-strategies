## 一、策略概览

ClucFiatSlow 是一个基于布林带（Bollinger Bands）和反 Fisher 变换 RSI 的**中低频交易策略**，是 ClucFiatROI 的慢速版本。该策略通过捕捉布林带收窄后的突破行情，结合成交量过滤和趋势确认，在波动市场中寻找中等周期的交易机会。相比 ROI 版本的 5 分钟时间框架，Slow 版本采用 15 分钟框架，显著降低了交易频率和市场噪音干扰。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 2 个独立买入模式（新开仓 + 持仓加仓） |
| **卖出条件** | 阶梯 ROI + 追踪止损 + 信号触发 |
| **保护机制** | 订单超时保护 + 成交量过滤 + 止损机制 |
| **时间框架** | 主时间框架 15m |
| **依赖库** | ta-lib（技术指标计算） |

## 三、买入条件详解

### 3.1 保护机制概述

策略内置多层保护机制，确保买入信号的有效性：

| 保护类型 | 参数说明 | 默认值 |
|---------|---------|--------|
| 订单超时保护 | 买入订单价格超过下单价 1% 时取消 | 0.01 |
| 成交量过滤 | 新开仓成交量需低于均线 24 倍 | 24 |
| Fisher 过滤 | Fisher RSI 需低于阈值才允许买入 | -0.88923 |

### 3.2 买入模式分类

策略采用双重买入模式，针对不同市场状态设计：

#### 模式 A：新开仓买入

**前置条件**：Fisher RSI < -0.88923（市场处于超卖状态）

满足以下**条件组 A1 或条件组 A2**：

**条件组 A1 - 布林带收窄突破**：
```python
# 核心逻辑
- bbdelta > close × 0.00835        # 布林带宽度足够
- closedelta > close × 0.00765     # 价格有明显变动
- tail < bbdelta × 0.68234          # 下影线较短（卖方支撑弱）
- close < lower_bb1.shift()         # 收盘价跌破布林下轨
- close ≤ close.shift()             # 收盘价不高于前一根 K 线
```

**条件组 A2 - 趋势反弹**：
```python
# 核心逻辑
- close < ema_slow                  # 价格低于 72 周期 EMA
- close < 0.01082 × lower_bb2       # 价格深入布林下轨区域
- volume < volume_mean × 24         # 成交量萎缩（缩量下跌）
```

#### 模式 B：持仓中加仓

当已存在活跃持仓时，买入条件简化为：

```python
# 加仓逻辑
- close > close.shift()             # 价格高于前一根 K 线
- close > sar                       # 价格高于 SAR 指标（趋势确认）
```

### 3.3 买入条件汇总

| 模式 | 条件组 | 核心逻辑 | 市场含义 |
|------|--------|---------|---------|
| 新开仓 | A1 | 布林带收窄后跌破下轨 | 突破反转信号 |
| 新开仓 | A2 | 价格远离均线且缩量 | 超跌反弹机会 |
| 加仓 | B | 价格上涨且趋势向上 | 顺势加仓 |

## 七、策略优势与局限

### ✅ 优势

1. **双时间框架设计**：15 分钟主框架配合 72 周期 EMA，降低噪音干扰
2. **双重买入模式**：同时捕捉突破和反弹机会，增加信号数量
3. **Fisher 变换**：将 RSI 归一化到 [-1, 1] 区间，减少极端值影响
4. **阶梯 ROI**：根据持仓时间动态调整止盈目标，平衡收益与风险
5. **追踪止损**：保护既有利润，允许趋势延续时获取更大收益
6. **更长持仓时间**：720 分钟 ROI 周期，适合无法频繁盯盘的交易者

### ⚠️ 局限

1. **中等止损**：-25.20% 止损仍可能导致单笔较大亏损
2. **参数敏感**：6 个买入参数 + 2 个卖出参数依赖 Hyperopt 优化
3. **布林带依赖**：在持续单边趋势中可能失效
4. **持仓时间长**：面临隔夜风险和突发消息风险
5. **盈亏比挑战**：止盈 3.56% vs 止损 25.2%，需较高胜率支持

## 十、重要提醒：复杂性的代价

ClucFiatSlow 策略包含 6 个买入参数和 2 个卖出参数，共 8 个可调参数。理解每个参数的含义和相互作用需要一定时间投入。建议用户：

2. 对比回测结果与实盘表现的差异

多参数策略存在**过拟合风险**：参数基于历史数据优化，可能对未来无效。具体表现：

- 回测表现优异但实盘亏损
- 参数在不同市场环境下表现差异大
- 需要定期重新优化参数

## 十一、总结

**ClucFiatSlow** 是一个设计精巧的中低频交易策略，是 ClucFiatROI 的慢速版本。通过 15 分钟的时间框架和更长的 EMA 周期（72 周期），该策略在保持捕捉突破机会能力的同时，显著降低了交易频率和市场噪音干扰。

它的核心价值在于：

1. **稳健的时间框架**：15 分钟框架相比 5 分钟更稳定，适合无法频繁盯盘的交易者
2. **更长的持仓周期**：720 分钟 ROI 周期允许持有一整天，为日内上班族提供便利
3. **保守的风险控制**：25.2% 止损相比 ROI 版本更保守，体现中低频策略理念
4. **灵活的止盈机制**：阶梯 ROI + 追踪止损的组合，平衡收益保护与趋势追踪

对于量化交易者而言，ClucFiatSlow 提供了一个在波动市场中进行波段交易的实用框架。建议在充分回测和小资金实盘验证后，结合严格的风险管理使用。记住：**参数众多意味着需要定期优化，历史表现不代表未来收益**。

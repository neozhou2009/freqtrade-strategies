# ClucFiatSlow 策略：稳健的波段猎手

> **外号**：慢大哥、稳中求胜派
> **职业**：中低频波段交易员
> **时间框架**：15 分钟 (15m)

---

## 一、这策略是个啥？

简单说，**ClucFiatSlow** 就是一个：

- 用 **15分钟K线** 看盘（比5分钟慢3倍，更稳重）
- 专门在 **布林带收窄的地方埋伏**
- 等 **价格突破后捞一波** 就跑
- 可以 **持仓一整天** 都不着急

就像一个**不急不躁的老猎人**——在猎物可能出现的地方蹲好，不急着出手，等机会成熟了再一枪命中 🎯

名字里的"Slow"就是它的性格：**不追求快准狠，要的是稳扎稳打慢慢赚！**

它是 ClucFiatROI 的"慢大哥"，兄弟俩一个急性子（5分钟框架），一个慢性子（15分钟框架），但核心逻辑都是布林带突破。

## 二、核心配置：说白了就是"见好就收，该跑就跑"

### 止盈规则（ROI 表）

```
持仓时间      止盈目标
───────────────────────
0 分钟       3.56%     ← 买完立刻赚这么多就跑
15 分钟      2.99%     ← 拿一刻钟，预期降一点
30 分钟      1.85%     ← 拿半小时，再降
60 分钟      1.32%     ← 拿一小时，降
180 分钟     0.90%     ← 拿三小时，降
360 分钟     0.50%     ← 拿六小时，降
720 分钟+    0%        ← 超过12小时，全靠追踪止损
```

**翻译**：**越早赚钱越好，时间久了期望就低了。** 但好消息是，可以拿一整天！

### 止损规则

```
硬止损：-25.20%（亏四分之一就认栽）
追踪止损：盈利超过2.58%时启动，锁定0.91%的利润
```

**翻译**：
- **亏到25%？** 算了，这把不行，撤退！
- **赚了超过2.58%？** 好的，启动"保住战果"模式，至少锁定0.91%的利润！

## 三、2类买入条件：我帮你分类好了

这策略的买入条件分两大类，就像搞对象分"追新"和"追加"：

### 🎯 第 1 类：新开仓买入（要满足一堆条件）

**前提**：Fisher RSI < -0.88923（市场已经跌得差不多了，属于超卖状态）

然后，满足 **A组 或 B组** 之一：

**A组：布林带收窄突破**
> "我发现布林带开始收窄了，价格跌破下轨，而且下影线短——说明卖方力道要衰竭了，这是个机会！"

**大白话翻译**：
- 布林带宽度够大（有波动空间）
- 收盘价跌破布林下轨（便宜了）
- 下影线短（卖方支撑弱，可能要反弹）
- 价格有明显变动（不是死水一潭）

**B组：趋势反弹**
> "价格已经远低于72日均线了，而且成交量萎缩——这种缩量下跌，很可能是假摔，反弹机会来了！"

**大白话翻译**：
- 价格在长周期均线下方（跌多了）
- 成交量萎缩（没人卖了，可能要反弹）
- 价格深入布林下轨区域（超跌了）

---

### 📈 第 2 类：持仓中加仓（简单粗暴）

如果已经持仓了，买入条件变简单：

> "价格在涨，而且趋势确认向上——加仓！"

**大白话翻译**：
- 收盘价高于前一根K线（价格在涨）
- 收盘价高于SAR指标（上涨趋势确认）

**这逻辑很像**：已经买了这只股票，看它还在涨，那就再加点！

## 四、保护机制：3道"安全带"

每个买入动作都配了保护措施，就像开车系安全带：

| 保护类型 | 作用 | 大白话 |
|---------|------|--------|
| 买入订单超时 | 价格涨超1%时取消买入订单 | "下单时价格突然跳涨，这单先不算了" |
| 卖出订单超时 | 价格跌超1%时取消卖出订单 | "下单时价格突然暴跌，这单先不算了" |
| 成交量过滤 | 成交量低于均线的24倍才买入 | "量太大说明太疯狂，别追高" |

**吐槽**：这策略挺谨慎的，宁可错过，不要做错 🤣

## 五、卖出逻辑：比买入更讲究

### 5.1 阶梯止盈：赚多少跑

这策略的止盈设计很人性化：

| 持仓时间 | 止盈目标 | 心态 |
|---------|---------|------|
| 0分钟 | 3.56% | 刚买就赚这么多？立刻跑！ |
| 15分钟 | 2.99% | 拿了一刻钟，还是不错 |
| 30分钟 | 1.85% | 半小时了，预期放低点 |
| 1小时 | 1.32% | 挺久了，差不多得了 |
| 3小时 | 0.90% | 该考虑撤退了 |
| 6小时 | 0.50% | 有点久了 |
| 12小时+ | 0%（靠追踪止损） | 随缘，能赚多少算多少 |

**大白话**：
- **刚买入就赚3.5%？** 太好了，马上跑！
- **拿了半天还在水里？** 算了，交给追踪止损处理吧。

### 5.2 追踪止损：保护战果

```
触发条件：盈利超过 2.58%
止损位置：锁定盈利 0.91%
```

**大白话**：
> "赚了超过2.58%？好的，启动保命模式！如果价格回头，至少还能保住0.91%的利润。"

**举个例子**：
- 你10块钱买入，涨到10.30块（盈利3%）
- 追踪止损启动，止损线设在10.09块（锁定0.9%利润）
- 如果价格继续涨到10.50，止损线跟着上移到10.45
- 如果价格跌回10.45，触发止损，你还能赚4.5%

### 5.3 卖出信号

满足以下条件会主动卖出：

- 收盘价接近布林中轨（涨回来了）
- 9日均线开始下行（短期趋势转弱）
- Fisher RSI进入超买区（涨太多了）
- 有成交量（不是死盘）

**大白话**：
> "涨到布林带中间了，均线开始拐头，动量指标也说涨多了——差不多得了，落袋为安！"

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **稳健**：15分钟框架，不追求高频，噪音更少
2. **耐心**：72日均线观察长期趋势，不急着追涨杀跌
3. **灵活止盈**：阶梯ROI + 追踪止损组合，既能保底又能追涨
4. **加仓机制**：持仓后条件简化，顺势加仓更灵活
5. **持仓时间长**：可以拿一整天，适合上班族

### ⚠️ 缺点（吐槽环节）

1. **止损太大**：-25.20%的止损，这要是被打掉可肉疼 🤕
2. **参数多**：6个买入参数 + 2个卖出参数，调起来头疼
3. **盈亏比挑战**：止盈3.56% vs 止损25.2%，需要胜率够高才能盈利
4. **布林带依赖**：单边趋势市可能失效
5. **隔夜风险**：持仓时间长，怕半夜出消息

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

ClucFiatSlow 的历史回测表现可能**看起来不错**——但这有个陷阱：

> **因为参数是优化过的，策略很容易"拟合"过去行情的最优解，但这并不代表未来一定能盈利。**

简单说就是：**考试答案都背了，但下次考试换题了 😅**

### 复杂策略的隐藏风险

实盘时，你要注意：
- **止损太大**：-25.2%的止损，一笔交易可能亏掉账户的四分之一
- **盈亏比挑战**：止盈3.56% vs 止损25.2%，需要至少87.7%的胜率才能盈亏平衡（实际不可能）
- **参数敏感**：6个买入参数，可能需要定期优化
- **隔夜风险**：持仓时间长，怕半夜出消息

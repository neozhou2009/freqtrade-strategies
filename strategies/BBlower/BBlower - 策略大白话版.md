# BBlower 策略：布林带下轨的"反弹猎人"

> **外号**：抄底小能手、布林带"钓鱼佬"  
> **职业**：专钓超卖反弹，布林带下轨等鱼上钩  
> **时间框架**：5 分钟线

---

## 一、这策略是个啥？

简单说，**BBlower** 就是一个：
- 专门盯着布林带下轨的策略
- 等价格跌到下轨附近才开始动手
- 但不是看见下轨就买，还要看 RSI 动量确认

就像一个**有耐心的钓鱼佬** 🎣——不乱撒网，只在鱼多的地方下钩，而且要看到鱼才收杆。

## 二、核心配置：说白了就是"大赚小亏"

### 止盈规则（ROI 表）

```
持仓时间        目标利润率
──────────────────────────
立即            32.477%      ← 开局就想赚 30%+
220 分钟后      13.561%      ← 约 3.7 小时降一档
962 分钟后      10.732%      ← 约 16 小时再降
2115 分钟后     0%           ← 35 小时强制卖
```

**翻译**：这策略很"贪心"，一上来就想赚 32%！但时间久了就慢慢降低预期，35 小时后无论亏赚都走人。

### 止损规则

```
固定止损：-13.912%
追踪止损：盈利超过 30.425% 后启动，追踪幅度 29.846%
```

**翻译**：
- 亏到 -14% 就认栽走人
- 但如果赚到了 30%+，就会启动追踪止损，"咬住"利润不松口

## 三、1 个买入条件：严格得像"相亲查三代"

这策略的买入条件**非常严格**，我给你拆开说：

### 🎯 唯一买入信号：布林带下轨反弹 + RSI 动量确认

**大白话**：
> "价格跌破布林带下轨不是买入信号，还要看 RSI 连续 4 根 K 线都在涨才行！"

**详细逻辑**：

1. **RSI 连续上升（4 根 K 线）**
   ```
   当前 RSI > 上一根 RSI > 上上一根 RSI > 再上一根 RSI
   ```
   > "动量在增强，多头在发力，不是假反弹"

2. **RSI 还在超卖区（RSI < 50）**
   > "还没涨过头，还有空间"

3. **TEMA（三重均线）上穿布林带下轨**
   > "价格真的从下轨反弹了，不是骗人的"

**经典台词**：
- 条件 1-4：`RSI 连续上升` → "动量确认，不是死猫跳"
- 条件 5：`RSI < 50` → "还在低位，不追高"
- 条件 6：`TEMA 上穿 BB 下轨` → "价格真反弹了，开仓！"

## 五、卖出逻辑：依赖系统，不靠信号

### 5.1 没有主动卖出信号

策略的 `populate_exit_trend` 函数是**空的**！

**大白话**：
- "我不判断什么时候卖，交给 ROI 表和止损系统处理"
- 买进去之后，要么到止损，要么到止盈，要么超时

### 5.2 卖出依赖三套机制

| 机制 | 说明 |
|------|------|
| ROI 止盈 | 时间越久，止盈门槛越低 |
| 固定止损 | -14% 认输 |
| 追踪止损 | 赚到 30% 后启动，锁住利润 |

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **入场条件严格**：4 根 K 线 RSI 连续上升 + 布林带反弹，不是什么鱼都上钩
2. **不追高**：RSI < 50 才买，确保在相对低位入场
3. **风控完善**：三套保护机制，死得不会太惨

### ⚠️ 缺点（吐槽环节）

1. **信号太少**：连续 4 根 K 线 RSI 上升这个条件太苛刻了
2. **没有主动卖出**：完全靠 ROI 和止损，市场反转也不会主动撤退
3. **追踪止损门槛太高**：30% 的盈利要求，大概率用不上
4. **计算浪费**：算了 4 组布林带，结果只用 1 组 🤦

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

BBlower 的历史回测表现可能**看起来不错**——但这有个陷阱：

> **严格的买入条件意味着信号稀少，实盘可能等一天都没信号。**

简单说就是：**条件越严格，机会越少。你可能在回测里看到一堆完美的反弹，但实盘时大部分时间都在空仓。**

### 复杂参数的隐藏风险

实盘时，一些问题可能导致：
- **信号过少**：连续 4 根 K 线 RSI 上升的条件太苛刻
- **追踪止损用不上**：30% 的门槛在实盘中几乎不可能触发
- **没有主动退出**：市场反转时不会主动撤退

### 我的建议（真心话）

```
1. 降低 ROI 止盈门槛，比如改成 10%-20%
2. 调整追踪止损到 10%-15%，更实用
3. 添加卖出信号，比如 RSI > 70 或布林带上轨
4. 减少布林带计算，从 4 组改成 1-2 组
5. 先模拟盘测试信号频率
```

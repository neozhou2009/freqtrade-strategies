## 二、核心配置：说白了就是"见好就收"

### 止盈规则（ROI 表）

```
5分钟K线数    目标利润    翻译
────────────────────────────────
0 根          5%          开仓就赚 5%？跑！
15 根 (75分钟) 4%        观望一下
51 根 (255分钟) 3%      趋势还行
```

**翻译**：这策略急性子！开仓就想赚 5%，等得越久要求越低。熬到 240 分钟（约 20 小时）还不爆发？那就放飞自我不管了 🎈

### 止损规则

```
硬止损线：-32%  ← 基本不会触发
动态止损：
  赚 2% 以内：最多亏 2%
  赚 2%~4.7%：动态上移，亏 2%→4.6%
  赚 4.7% 以上：开启"让利润奔跑"模式
```

**翻译**：这策略鸡贼得很！亏钱的时候它很"大方"（-32% 才割肉），赚钱的时候反而小气了（涨 2% 就开始各种保护）。典型的小钱不想亏，大钱想多赚 😏

### 追踪止损

```
启动条件：赚 0.1%
追踪距离：距现价 1.2%
```

# NotAnotherSMAOffsetStrategyHOv3 策略大白话版

## 一、这个策略是干啥的？

想象你是个买菜高手，每天在菜市场转悠。你知道菜价会波动，有时候贵有时候便宜。这个策略就像是一个自动买菜卖菜的机器人，它的核心思路很简单：

**便宜的时候买，贵的时候卖。**

但问题是：什么叫便宜？什么叫贵？

这个策略用了一个聪明的办法——看"平均价"。如果现在的菜价远低于平均价，那就是便宜了；如果远高于平均价，那就是贵了。

更厉害的是，它还会看"风向"（市场情绪）。不是便宜就买，还要确认风向是不是要变了。比如菜价便宜是因为快坏了（市场要崩），还是因为今天刚好没人买（暂时回调）。这就是这个策略厉害的地方。

---

## 二、策略的名字啥意思？

**NotAnotherSMAOffsetStrategyHOv3**，看起来很吓人对吧？拆开来说：

- **NotAnother**：意思是"不是又一个普通策略"，这是作者在秀优越感，说他这个策略不一样
- **SMA**：Simple Moving Average，简单移动平均线，就是那个"平均价"
- **Offset**：偏移，意思是价格偏离平均价多少
- **HO**：可能是 HyperOpt，就是用机器自动优化参数的意思
- **v3**：第三版，前面还有 v1 和 v2

所以这个名字翻译成人话就是：**"不是普通货的均线偏移策略·自动优化版·第三版"**

## 三、用的是什么指标？

### 3.1 移动平均线（MA）

这是策略的核心。平均价就是最近一段时间的平均收盘价。

策略用了好几种"平均线"：

| 线的名字 | 怎么算的 | 用来干嘛 |
|---------|---------|---------|
| ma_buy | EMA，8根K线 | 判断买入价够不够便宜 |
| ma_sell | EMA，16根K线 | 判断卖出价够不够贵 |
| ema_100 | EMA，100根K线 | 看大趋势 |
| sma_9 | SMA，9根K线 | 短期趋势判断 |
| hma_50 | HMA，50根K线 | 中期趋势，比EMA更顺滑 |

**EMA** 是"指数移动平均线"，越近的价格权重越大，反应更快。
**SMA** 是"简单移动平均线"，所有价格权重一样。
**HMA** 是"Hull移动平均线"，专门设计来减少滞后的。

### 3.2 EWO 指标

**EWO = Elliott Wave Oscillator**，艾略特波动指标。

说白了就是两条EMA的差值，用来判断市场的"气势"：
- 正数大：气势强，价格在涨
- 负数大：气势弱，价格在跌
- 接近零：气势要变，可能要转向

这个策略用的参数很特别：快线50周期，慢线200周期。普通用法是5和35，这个策略用的是更长周期的，所以反应更慢但更稳。

### 3.3 RSI 指标

**RSI = Relative Strength Index**，相对强弱指标。

就是个0-100的数字：
- 大于70：超买，价格涨过头了
- 小于30：超卖，价格跌过头了

这个策略用了三个RSI：
- RSI(14)：标准版
- RSI(4)：快速版，反应更快
- RSI(20)：慢速版，反应更稳

## 四、什么时候买入？

策略有**三种买入信号**，满足任何一种就可以买。我们一个一个说：

### 4.1 第一种：ewo1（强势回调买入）

这是最常用的买入信号，适合这种情况：**大趋势在涨，但今天突然跌了一点**。

具体条件（用大白话说）：
1. **快速RSI小于35**：说明短期内价格跌得有点急
2. **价格比均线低1.4%以上**（close < ma_buy × 0.986）：确认是真正的便宜
3. **EWO大于4.179**：说明大趋势还是在涨，只是暂时回调
4. **RSI(14)小于58**：不是已经涨疯了才回调

翻译成人话：**大趋势涨得好好的，今天突然跌了一下，快去买！**

### 4.2 第二种：ewo2（深度回调买入）

这个信号更严格，要求价格跌得更深。

具体条件：
1. 快速RSI小于35
2. **价格比均线低5.6%以上**（close < ma_buy × 0.944）：要求更大的折扣
3. EWO大于-2.609（可以是负的）
4. RSI(14)小于58
5. **RSI(14)还要小于25**：双重确认超卖

翻译成人话：**价格跌得有点狠了，但还没崩，可能是抄底的好机会。**

### 4.3 第三种：ewolow（恐慌抄底买入）

这个信号是给"别人恐慌我贪婪"的情况设计的。

具体条件：
1. 快速RSI小于35
2. 价格比均线低1.4%以上
3. **EWO小于-16.917**：这说明市场极度悲观

翻译成人话：**大家都吓得卖股票了，这时候去捡便宜货。**

### 4.4 三种买入信号对比

| 信号 | 适合场景 | 风险程度 | 预期收益 |
|------|---------|---------|---------|
| ewo1 | 强趋势正常回调 | 低 | 稳定 |
| ewo2 | 深度回调 | 中 | 较高 |
| ewolow | 市场恐慌 | 高 | 可能很高，也可能继续跌 |

## 五、什么时候卖出？

卖出逻辑比买入简单一点，但有两个不同的"卖出套餐"：

### 5.1 套餐一：涨够了，该走了

条件：
1. **价格高于9周期SMA**：短期趋势向上
2. **价格高于卖出均线1.8%**（close > ma_sell × 1.018）：赚够了
3. **RSI大于50**：还处于多头状态
4. **快速RSI大于慢速RSI**：动量还在往上
5. 有成交量

翻译成人话：**涨得挺好，趁还在涨赶紧卖了。**

### 5.2 套餐二：涨不动了，撤吧

条件：
1. **价格跌破50周期HMA**：中期趋势可能要变
2. **价格还在卖出均线之上**（close > ma_sell × 1.054）：但还没跌太多
3. **快速RSI还大于慢速RSI**：但动量可能要转向了

翻译成人话：**趋势有点要变坏的苗头了，趁还赚钱赶紧跑。**

### 5.3 特殊情况：卖了又后悔？

策略有个"反悔机制"：如果卖出信号触发了，但检查发现：
- 50周期HMA还在100周期EMA上面（大趋势没坏）
- 价格却跌到了100周期EMA的95%以下

这时候策略会说：**"等等，大趋势没坏，现在卖亏了，取消卖出！"**

这是为了防止被短期波动吓出去。

## 六、亏了怎么办？——止损机制

策略有三道防线保护你的钱：

### 6.1 第一道防线：固定止损

```python
stoploss = -0.3  # 亏30%就强制卖出
```

意思就是：**最多亏30%，到了就认输。**

你可能会说："30%太多了吧？"

这要看你交易的是什么。加密货币一天波动10%很正常，设置太紧的止损会被来回打脸。30%是比较宽松的设置，适合波动大的市场。

### 6.2 第二道防线：追踪止损

```python
trailing_stop_positive = 0.005        # 回撤0.5%就触发
trailing_stop_positive_offset = 0.025 # 盈利2.5%后激活
```

什么意思呢？

- 刚买入时，固定止损（-30%）生效
- **当你赚了2.5%之后**，追踪止损开始工作
- 此后，最高价回撤0.5%就自动卖出

举个例子：
- 你100块买入
- 价格涨到102.5，追踪止损激活，此时止损价是102.5×(1-0.5%)=101.99
- 价格继续涨到110，止损价变成110×(1-0.5%)=109.45
- 价格从110跌到109.45，触发止损卖出
- 你赚了9.45%

这个机制让你**锁定利润**，不会从赚变成亏。

### 6.3 第三道防线：ROI目标

```python
minimal_roi = {
    "0": 0.10,   # 一开始目标是10%
    "30": 0.05,  # 30分钟后降到5%
    "60": 0.02   # 60分钟后只要2%就卖
}
```

这是说：
- 刚买入，要赚10%才满意
- 持仓30分钟还没赚够，5%也可以接受
- 持仓60分钟还在磨，2%赶紧走了

这叫**时间价值**：钱在账户里躺太久也不是好事，不如早点变现去找下一个机会。

### 6.4 第四道防线：滑点保护

有时候你下单价是100，实际成交价却是98，这2块钱差价就是**滑点**。

策略设置：
```python
'max_slippage': -0.02  # 最多接受2%滑点
'retries': 3           # 滑点太大可以拒绝3次
```

如果滑点超过2%，策略会拒绝成交，等下一次机会。

## 七、策略用的时间周期

### 7.1 主时间框架：5分钟

策略用**5分钟K线**做交易决策。

5分钟是什么概念？
- 每5分钟产生一根新K线
- 每小时12根
- 每天288根

这个周期比较适中：
- **比1分钟稳定**：噪音少，假信号少
- **比1小时及时**：不会错过太多机会

### 7.2 辅助时间框架：1小时

策略还会看1小时K线，用来判断**大趋势**。

比如在5分钟上看到买入信号，但1小时趋势是向下的，可能就要谨慎一点。

## 八、策略的参数有哪些？

策略有很多可调节的参数，就像汽车的各种设置一样：

### 8.1 买入相关参数

| 参数 | 现在的值 | 意思 |
|------|---------|------|
| base_nb_candles_buy | 8 | 买入均线用几根K线算 |
| low_offset | 0.986 | 价格要比均线便宜1.4% |
| low_offset_2 | 0.944 | 深度买入要便宜5.6% |
| ewo_high | 4.179 | 动量要高于这个才买 |
| ewo_low | -16.917 | 动量要低于这个才抄底 |
| ewo_high_2 | -2.609 | 第二种买入的动量阈值 |
| rsi_buy | 58 | RSI要低于这个 |

### 8.2 卖出相关参数

| 参数 | 现在的值 | 意思 |
|------|---------|------|
| base_nb_candles_sell | 16 | 卖出均线用几根K线算 |
| high_offset | 1.054 | 价格要比均线贵5.4% |
| high_offset_2 | 1.018 | 另一个卖出溢价 |

### 8.3 这些参数能改吗？

能！策略用了 `DecimalParameter` 和 `IntParameter`，可以用 Freqtrade 的超参数优化功能自动找最优值。

但要注意：**历史最优 ≠ 未来最优**。不要过度优化！

## 九、策略适合什么市场？

### 9.1 适合的市场

**牛市**：
- 上涨趋势中经常有回调，策略可以不断"抄底"
- ewo1信号频繁触发
- 追踪止损能帮你抓住大涨

**震荡市**：
- 价格来回波动，低买高卖正合适
- 三种买入信号可以抓住不同深度的回调

**温和熊市**：
- ewolow信号可以捕捉超跌反弹
- 但要小心持续下跌

### 9.2 不太适合的市场

**单边暴涨**：
- 策略可能卖太早，错过后面的大涨
- 解决办法：调高high_offset

**单边暴跌**：
- 策略可能多次抄底抄在半山腰
- 解决办法：停止交易或调低ewo_low阈值

**极度平静的市场**：
- 价格波动太小，触发不了买入卖出
- 手续费可能把利润吃光

## 十、怎么用这个策略？

### 10.1 第一步：回测

在历史数据上测试策略表现：

```bash
freqtrade backtesting \
  --strategy NotAnotherSMAOffsetStrategyHOv3 \
  --timerange 20230101-20231231 \
  --timeframe 5m
```

看看：
- 总收益是多少？
- 最大回撤是多少？
- 胜率是多少？
- 交易了多少次？

### 10.2 第二步：模拟交易

用假钱跑策略：

```bash
freqtrade trade \
  --strategy NotAnotherSMAOffsetStrategyHOv3 \
  --dry-run
```

观察：
- 策略什么时候买？
- 什么时候卖？
- 有没有奇怪的信号？

建议模拟运行至少2周。

### 10.3 第三步：小资金实盘

用你能承受亏损的钱开始实盘：
- 不要一开始就梭哈
- 从小金额开始，验证策略真的能赚钱
- 观察滑点、延迟等实际问题

### 10.4 第四步：监控和调整

定期检查：
- 每周看一次策略表现
- 发现问题及时调整参数
- 市场环境变化时考虑暂停

## 十一、策略的优缺点

### 11.1 优点

| 优点 | 说明 |
|------|------|
| 逻辑清晰 | 就是在均线附近找便宜货买 |
| 三重买入信号 | 不同市场情况都有对应策略 |
| 风险控制完善 | 止损、追踪止损、ROI都有 |
| 参数可调 | 可以根据不同币种优化 |
| 代码规范 | 容易理解和修改 |

### 11.2 缺点

| 缺点 | 说明 |
|------|------|
| 依赖参数 | 当前参数是优化过的，可能过拟合 |
| 震荡市可能亏 | 价格来回穿越均线会产生假信号 |
| 追涨能力弱 | 设计思路是抄底，不适合追涨 |
| 需要维护 | 不是"设置好就不管"的类型 |

## 十二、和类似策略比较

### 12.1 和普通均线策略比

普通均线策略通常就是：价格上穿均线买，下穿卖。

这个策略更聪明：
- 不是简单地穿均线就交易
- 还要看EWO动量、RSI超卖
- 有不同的"折扣力度"选项

### 12.2 和纯动量策略比

纯动量策略追涨杀跌，什么涨买什么。

这个策略相反，是**抄底策略**：
- 涨的时候不买，等回调
- 不追涨，只找便宜货

### 12.3 和机器学习策略比

机器学习策略用历史数据训练模型，是个"黑盒"。

这个策略是**白盒**：
- 每个条件都清清楚楚
- 知道为什么买、为什么卖
- 亏了知道亏在哪里

## 十三、最后的建议

### 13.1 给新手

1. **先用模拟盘**：不要急着实盘
2. **选主流币**：BTC、ETH，流动性好
3. **用默认参数**：先别改，等理解了再说
4. **设置提醒**：策略买卖时通知你，观察是否合理

### 13.2 给有经验的人

1. **可以调参数**：但要有依据，不要瞎调
2. **多币种分散**：不要只跑一个币
3. **关注回撤**：收益高不一定好，还要看风险
4. **结合其他策略**：可以和其他类型的策略组合

### 13.3 给所有人

**量化交易不是印钞机。**

这个策略在历史数据上表现可能很好，但：
- 过去不代表未来
- 市场会变化
- 没有任何策略能永远赚钱

使用任何策略之前，问问自己：
- 我能承受多大的亏损？
- 我有时间和精力监控吗？
- 我真的理解这个策略在做什么吗？

如果不确定，就从小金额开始，慢慢学习。

## 总结

NotAnotherSMAOffsetStrategyHOv3 是一个设计精良的**抄底策略**。它的核心思想是：

**在趋势保持的情况下，等价格回调到均线以下一定幅度再买入，然后等价格涨回均线以上一定幅度再卖出。**

策略用了三种不同的买入信号来适应不同的市场情况，有完善的止损机制保护资金，参数可调性高。

但请记住：**没有任何策略是完美的**。量化交易需要持续学习、监控和调整。希望这篇大白话文档能帮你理解这个策略，做出更好的交易决策。

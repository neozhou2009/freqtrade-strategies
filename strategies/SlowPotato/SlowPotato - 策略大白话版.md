# SlowPotato 策略：慢慢悠悠的"土豆"交易员

> **外号**：区间低吸高抛王  
> **职业**：横盘收割机  
> **时间框架**：5 分钟

---

## 一、这策略是个啥？

简单说，**SlowPotato** 就是一个：
- 看过去 5 天的平均最高价和最低价
- 跌到平均最低价就买
- 涨到平均最高价就卖
- 就这么简单！

名字里的 "Slow" 暗示这是个慢策略，"Potato"（土豆）可能想说它朴实无华？反正这就是一个在区间里低买高卖的策略，跟逛菜市场似的。

---

## 二、核心配置：说白了就是"高抛低吸"

### 止盈规则（ROI 表）

```python
"0":  0.10,   # 立刻盈利 10% 就跑
"30": 0.05,   # 持仓 30 分钟后，盈利 5% 就跑
"60": 0.02    # 持仓 60 分钟后，盈利 2% 就跑
```

**翻译**：
- 刚买的时候野心大，想赚 10%
- 持仓久了就妥协了，赚 5% 也行
- 再拖下去就佛系了，赚 2% 赶紧撤

**大白话**：这策略有点"急脾气"，买完就想赶紧赚钱跑路，越拖目标越低。

### 止损规则

```python
stoploss = -0.10  # 亏 10% 认输

trailing_stop = True
trailing_stop_positive = 0.02      # 盈利 2% 后启动追踪
trailing_stop_positive_offset = 0.03  # 追踪距离 3%
```

**翻译**：
- 最多亏 10%
- 如果盈利超过 2%，就开始追踪止损
- 止损线跟着最高价往下 3% 走

**大白话**：亏 10% 就认栽。但要是赚了 2% 以上，就把止损线提上来，跟着价格走，防止赚了又亏回去。

## 三、买入条件：跌到 5 天最低价的平均值就买

### 🎯 买入逻辑

```python
(dataframe['low'] <= dataframe['low'].rolling(1440).mean()) &  # 跌到 5 天平均最低价
(dataframe['volume'] > 0)                                        # 有成交量
```

**大白话翻译**：

| 条件 | 人话 |
|------|------|
| low <= 5 天平均最低价 | "现在价格跌到过去 5 天的最低价平均线了，该抄底了！" |
| volume > 0 | "有人在交易，不是死盘" |

**经典台词**：
> "过去 5 天最低价的平均值是多少？好，跌到那个位置我就买！"

### 为什么是 1440？

- 5 分钟一根 K 线
- 一天 24 小时 × 60 分钟 ÷ 5 分钟 = 288 根 K 线
- 5 天 = 288 × 5 = 1440 根 K 线

所以 rolling(1440) 就是过去 5 天的数据。

## 四、卖出条件：涨到 5 天最高价的平均值就卖

### 📈 卖出逻辑

```python
(dataframe['high'] >= dataframe['high'].rolling(1440).mean()) &  # 涨到 5 天平均最高价
(dataframe['volume'] > 0)                                         # 有成交量
```

**大白话翻译**：

| 条件 | 人话 |
|------|------|
| high >= 5 天平均最高价 | "涨到过去 5 天最高价的平均线了，该卖了！" |
| volume > 0 | "有人在交易，不是死盘" |

**经典台词**：
> "过去 5 天最高价的平均值是多少？好，涨到那个位置我就卖！"

### 完整的交易循环

1. 等价格跌到 5 天平均最低价 → 买入
2. 等价格涨到 5 天平均最高价 → 卖出
3. 如此循环往复，像在区间里来回割韭菜

## 五、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **逻辑超级简单**：低买高卖，小学生都能懂
2. **没有花哨指标**：不用 MACD、RSI，就看价格
3. **有追踪止损**：锁定利润，防止回吐
4. **分级止盈**：持仓越久越佛系，避免贪婪

### ⚠️ 缺点（吐槽环节）

1. **只适合震荡市**：横盘的时候好用，趋势来了就傻眼
2. **假设价格会回归**：要是单边上涨，永远等不到买入信号
3. **窗口固定**：5 天窗口不变，不根据市场调整
4. **没有趋势过滤**：牛市熊市都不知道，只知道区间

## 八、这策略在什么市场能赚钱？

### 8.1 核心逻辑：均值回归

SlowPotato 的赚钱哲学是：
- **信奉均值回归**：价格涨多了会跌，跌多了会涨
- **区间套利**：在 5 天区间里来回吃差价
- **不追涨杀跌**：就等价格到区间边缘

### 8.2 不同市场表现（说人话版）

**一句话总结**：只在横盘震荡市用！趋势市就别折腾了。

## 十二、⚠️ 风险再强调（这段一定要看）

### 均值回归的陷阱

SlowPotato 的核心假设是：**价格会回归区间**。但这有个大陷阱：

> **趋势市场中，价格永远不会回归，只会越走越远。**

简单说就是：**价格跌到 5 天平均最低价了，你买了，然后它继续跌……跌穿历史记录。**

### 均值回归策略的风险

实盘时，均值回归策略可能导致：
- **单边行情被套**：买了之后价格一直跌
- **区间突破失效**：历史区间被打破，策略失效
- **止损频繁触发**：波动大的时候容易被洗出去

### 我的建议（真心话）

```
1. 先判断当前市场是不是震荡市
2. 只在震荡市启用这个策略
3. 发现趋势形成就赶紧关掉
4. 止损设好，别扛单
5. 别在波动率太大的币种上用
```

**记住**：均值回归不是万能的，市场一旦进入趋势，"回归"就是妄想。认清市场，选对策略，活着最重要！🙏

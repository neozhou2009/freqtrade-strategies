## 一、策略概览

SlowPotato 是一个基于 5 天价格区间均值回归的策略，由 jadex 开发。其核心理念非常朴素：在 5 天平均最低价附近买入，在 5 天平均最高价附近卖出，通过捕捉价格的日内波动来获利。"SlowPotato"这个名字暗示了其"慢而稳"的交易风格。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 1 个买入信号，价格触及 5 天平均最低价 |
| **卖出条件** | 1 个卖出信号，价格触及 5 天平均最高价 |
| **保护机制** | 分级 ROI + 追踪止损 + 固定止损 |
| **时间框架** | 5 分钟 (5m)，参考 5 天（1440 根 K 线） |
| **依赖库** | talib, qtpylib, technical |

## 三、买入条件详解

### 3.1 唯一买入信号

策略采用单信号入场设计：

```python
# 买入信号
(
    (dataframe['low'] <= dataframe['low'].rolling(1440).mean()) &  # 价格低于 5 天平均最低价
    (dataframe['volume'] > 0)                                        # 有成交量
)
```

**条件拆解**：

| 条件 | 技术含义 | 逻辑说明 |
|------|---------|---------|
| Low <= 5 天平均最低价 | 价格触及支撑位 | 价格跌到 5 天均值下沿 |
| Volume > 0 | 有交易活动 | 避免零成交量的异常数据 |

### 3.2 买入逻辑分析

这是一个典型的**均值回归策略**：
1. **5 天窗口**：1440 根 5 分钟 K 线 = 5 个交易日
2. **平均最低价**：5 天内每根 K 线最低价的平均值
3. **买入时机**：当价格触及或低于这个平均值时，认为是"低估"区域

**核心思想**：
> 价格在 5 天区间内波动，触及下沿是买入机会，等待回归上沿卖出。

## 四、卖出逻辑详解

### 4.1 基础卖出信号

```python
# 卖出信号
(
    (dataframe['high'] >= dataframe['high'].rolling(1440).mean()) &  # 价格高于 5 天平均最高价
    (dataframe['volume'] > 0)                                         # 有成交量
)
```

**设计思路**：
- 当价格触及 5 天平均最高价时触发卖出
- 与买入逻辑对称，形成完整的"低买高卖"循环

### 4.2 多层退出机制

| 退出类型 | 触发条件 | 优先级 |
|---------|---------|--------|
| 分级 ROI | 持仓时间决定止盈目标 | 高 |
| 卖出信号 | 价格触及 5 天平均最高价 | 中 |
| 追踪止损 | 盈利 2% 后启动追踪 | 中 |
| 固定止损 | 亏损 10% | 低 |

### 4.3 分级 ROI 详解

```
持仓时间    止盈目标
────────────────────
0 分钟      10%
30 分钟     5%
60 分钟     2%
```

**逻辑**：
- 刚买入时目标高（10%），希望快速获利
- 持仓越久，目标越低，避免利润回吐
- 60 分钟后仅要求 2% 利润，及时止盈

## 六、风险管理特色

### 6.1 分级止盈系统

| 持仓时间 | 止盈目标 | 设计意图 |
|---------|---------|---------|
| 0-30 分钟 | 10% | 快速获利目标 |
| 30-60 分钟 | 5% | 适度降低要求 |
| 60+ 分钟 | 2% | 及时止盈离场 |

**特点**：鼓励快速获利，持仓越久越保守。

### 6.2 追踪止损机制

```python
trailing_stop = True
trailing_stop_positive = 0.02      # 盈利 2% 后激活
trailing_stop_positive_offset = 0.03  # 追踪距离 3%
```

**运作方式**：
1. 买入后，如果价格上涨并盈利 2%，追踪止损激活
2. 止损线始终跟踪在最高价下方 3% 处
3. 如果价格回调超过 3%，触发止损退出

**示例**：
- 买入价：100
- 最高涨到：110（盈利 10%）
- 追踪止损线：106.7（110 × 0.97）
- 如果跌到 106.7 以下，触发卖出

### 6.3 利润保护

```python
sell_profit_only = True  # 仅在盈利时响应卖出信号
```

**说明**：即使价格触及 5 天平均最高价，如果当前亏损，也不会卖出。这个设置保护了策略不会在亏损时因为信号触发而强制离场。

## 七、策略优势与局限

### ✅ 优势

1. **逻辑简单直观**：低买高卖，符合直觉
2. **参数极少**：仅依赖 5 天均值，无复杂指标
3. **追踪止损**：自动锁定浮盈，保护利润
4. **分级 ROI**：鼓励快速获利，避免长时间持仓
5. **利润保护**：sell_profit_only 确保不在亏损时卖出

### ⚠️ 局限

1. **均值回归假设**：假设价格会在区间内波动，不适应趋势市场
2. **窗口固定**：不根据市场波动调整窗口大小
3. **无趋势过滤**：在单边趋势中可能反复被套
4. **滑点风险**：平均最高/最低价附近流动性可能较差

## 九、适用市场环境详解

SlowPotato 是一个典型的**均值回归策略**。基于其代码架构，它最适合 **横盘震荡市场**，而在趋势市场中表现不佳。

### 9.1 策略核心逻辑

- **区间交易**：在 5 天价格区间内高抛低吸
- **均值回归**：假设价格会回归到区间中枢
- **快速止盈**：持仓时间越长，止盈目标越低

### 9.2 不同市场环境表现

| 市场类型 | 表现评级 | 原因分析 |
| :--- | :--- | :--- |
| 📈 单边牛市 | ⭐☆☆☆☆ | 价格持续突破上沿，买入信号不触发 |
| 🔄 横盘震荡 | ⭐⭐⭐⭐⭐ | 完美匹配均值回归逻辑 |
| 📉 单边熊市 | ⭐☆☆☆☆ | 价格持续跌破下沿，止损频繁 |
| ⚡️ 高波动 | ⭐⭐☆☆☆ | 区间频繁突破，信号可能失效 |

### 9.3 关键配置建议

| 配置项 | 建议值 | 说明 |
|--------|--------|------|
| stoploss | -0.10 ~ -0.15 | 保持或适当扩大 |

| minimal_roi | 适当调整 | 根据交易对波动性 |

## 十、重要提醒：均值回归的风险

### 10.1 学习成本

SlowPotato 策略的学习成本很低：
- 仅依赖价格均值，无复杂指标
- 代码约 80 行，易于理解
- 核心逻辑直观，符合交易直觉

### 10.2 硬件要求

| 交易对数量 | 最低内存 | 推荐内存 |
|-----------|---------|---------|
| 1-10 对 | 1GB | 2GB |
| 10-50 对 | 2GB | 4GB |
| 50+ 对 | 4GB | 8GB |

### 10.3 回测与实盘的差异

- 回测时区间计算可能理想化
- 实盘中滑点可能侵蚀利润
- 价格触及平均最高/最低价时的流动性问题

### 10.4 手动交易者建议

手动交易可采用类似思路：
1. 观察 5 天价格区间
2. 在区间下沿挂买单
3. 在区间上沿挂卖单
4. 设置止损和止盈

## 十一、总结

**SlowPotato** 是一个简洁的均值回归策略。它的核心价值在于：

1. **逻辑清晰**：低买高卖，简单直观
2. **参数极少**：只依赖价格区间，无需复杂指标
3. **风控完善**：分级 ROI + 追踪止损 + 利润保护

对于量化交易者而言，SlowPotato 是一个很好的均值回归入门策略。但需要注意其仅适用于横盘震荡市场，在趋势行情中可能失效。建议配合趋势过滤指标使用，或仅在判断市场为震荡时启用。

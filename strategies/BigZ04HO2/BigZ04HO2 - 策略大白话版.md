## 二、核心配置：说白了就是"快跑"

### 止盈规则（ROI表）

```
持仓刚买入：    赚 2.8% 就跑
持仓10分钟后：  赚 1.8% 就跑
持仓40分钟后：  赚 0.5% 就跑（蚊子肉也吃！）
持仓3小时后：   赚 1.8% 就跑
```

**翻译**：越早卖要求越低，持仓越久越要跑。0.5%都肯卖，说明是真的"怕贪"。

### 止损规则

```
传统止损：-99%（基本禁用）
追踪止损：盈利1%后启动，回撤2.5%就跑
自定义止损：持仓145分钟（约2.5小时）后开始判断
```

**翻译**：别看传统止损关了，人家有更聪明的止损方式——给你2.5小时表现，不行就割。

## 一、策略概览

**HyperStra_SMAOnly** 是一个超参数化的均线策略，名称中的 "HyperStra" 代表 Hyperopt Strategy（超参数优化策略），"SMAOnly" 表示仅使用简单移动平均线作为技术指标。策略使用多根不同周期的 SMA 进行数学运算，通过归一化比值和交叉条件寻找最优交易信号组合。与 HyperStra_GSN_SMAOnly 策略设计理念高度相似，可视为"双胞胎兄弟"策略。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 3 组 SMA 归一化比值条件需同时满足 |
| **卖出条件** | 3 组 SMA 交叉/归一化条件需同时满足 |
| **保护机制** | 硬止损 -5%，追踪止损，交易频率限制 |
| **时间框架** | 5 分钟 |
| **依赖库** | TA-Lib, numpy |
| **优化需求** | 需要 Hyperopt 参数优化 |

## 三、买入条件详解

### 3.1 买入信号逻辑

策略要求 3 组 SMA 归一化比值条件同时满足才触发买入：

```python
# 第 1 组：短期/长期比值
condition_1 = (sma_fast / sma_slow) < threshold_1

# 第 2 组：超短期比值
condition_2 = (sma_short_1 / sma_short_2) < threshold_2

# 第 3 组：中期比值
condition_3 = (sma_mid_1 / sma_mid_2) < threshold_3

# 买入信号：三组条件全部满足
buy_signal = condition_1 & condition_2 & condition_3
```

### 3.2 条件解析

策略使用多根 SMA（涵盖超短期、短期、中期、长期等周期）进行比值计算，通过归一化比值判断价格相对位置：

| 比值范围 | 技术含义 |
|---------|---------|
| 比值 < 1.0 | 短期均线低于长期均线（下跌趋势） |
| 比值 = 1.0 | 两均线相等（平衡点） |
| 比值 > 1.0 | 短期均线高于长期均线（上涨趋势） |

### 3.3 买入条件分类

| 条件类别 | 核心逻辑 | 信号编号 |
|---------|---------|---------|
| 超跌反弹 | 多均线比值同时低于阈值 | 条件 #1 |

### 3.4 设计理念

三组条件呈现**多重确认**逻辑，衡量不同时间框架上的价格偏离程度。当多组条件同时满足时，意味着价格在多个时间框架上都处于相对低位，可能存在反弹机会。

## 四、卖出逻辑详解

### 4.1 卖出信号逻辑

策略要求 3 组 SMA 条件同时满足才触发卖出：

```python
# 第 1 组：归一化条件
condition_1 = (sma_normalized == threshold_1)

# 第 2 组：交叉条件
condition_2 = crossover(sma_a, sma_b)

# 第 3 组：反向交叉或比值条件
condition_3 = crossunder(sma_c, sma_d)

# 卖出信号：三组条件全部满足
sell_signal = condition_1 & condition_2 & condition_3
```

### 4.2 条件解析

卖出条件结合归一化值判断和均线交叉信号，确认趋势转强后的获利了结时机：

| 条件类型 | 检测方式 | 技术含义 |
|---------|---------|---------|
| 归一化值 | SMA 接近高位区域 | 价格已上涨一定幅度 |
| 趋势确认 | 中期均线上穿长期均线 | 趋势转强 |
| 动能确认 | 超短期均线与长期均线关系 | 价格位置确认 |

### 4.3 卖出条件分类

| 条件类别 | 核心逻辑 | 信号编号 |
|---------|---------|---------|
| 趋势反转 | 多均线交叉与归一化组合 | 条件 #1 |

### 4.4 设计理念

卖出条件的设计体现了**多重确认**机制，通过归一化值确认价格位置、趋势交叉确认方向、动能确认时机，三组条件暗示价格已经经历了一波上涨，可能是获利了结的时机。

## 五、技术指标体系

### 5.1 核心指标

策略使用多根不同周期的简单移动平均线：

| 指标周期分类 | 用途 |
|------------|------|
| 超短期 SMA | 捕捉价格快速变化 |
| 短期 SMA | 短期趋势判断 |
| 中期 SMA | 中期趋势基准 |
| 长期 SMA | 长期趋势参考 |

### 5.2 归一化计算

策略的核心创新在于使用**归一化比值**而非原始价格：

```python
# 归一化比值示例
normalized_ratio = sma_short / sma_long

# 比值含义：
# < 1.0 : 短期均线低于长期均线（下跌趋势）
# = 1.0 : 两均线相等（平衡点）
# > 1.0 : 短期均线高于长期均线（上涨趋势）
```

**优势**：
- 消除价格绝对值影响
- 便于设定通用阈值
- 适应不同价格区间的交易对

### 5.3 指标依赖关系

```
买入判断：
SMA(超短期) ←→ SMA(长期)   （偏离度判断）
SMA(超短期) ←→ SMA(超短期) （超短期动能）
SMA(中期) ←→ SMA(长期)     （趋势确认）

卖出判断：
SMA 归一化值
SMA 中期 ←→ SMA 长期       （趋势转强）
SMA 长期 ←→ SMA 超短期     （价格位置）
```

## 六、风险管理特色

### 6.1 分级止盈机制

策略采用时间递减的 ROI 止盈机制：

| 持仓时间 | 止盈阈值 | 风险偏好 |
|---------|---------|---------|
| 立即出场 | 28.8% | 激进（等待大利润） |
| 90 分钟后 | 10.1% | 中等 |
| 180 分钟后 | 4.9% | 保守 |
| 480 分钟后 | 0% | 保本退出 |

**特点**：
- 初始止盈目标高（28.8%），表明策略预期捕捉较大波动
- 时间递减设计，避免长时间持仓的不确定性
- 保本底线设置，确保不会亏损转为盈利后变亏损

### 6.2 双重止损保护

```python
# 固定止损
stoploss = -0.05  # 5% 硬止损

# 追踪止损
trailing_stop_positive = 0.005      # 盈利 0.5% 启动
trailing_stop_positive_offset = 0.016  # 价格需涨 1.6% 才激活
```

**设计理念**：
- 固定止损保护本金，控制最大亏损
- 追踪止损锁定利润，让盈利奔跑
- 偏移量设置避免过早被震荡扫出

### 6.3 交易频率限制

```python
# 防止过度交易
stoploss_guard = 2      # 2 根 K 线内最多 1 笔交易
cooldown_period = 2     # 交易后冷却 2 根 K 线
```

**效果**：
- 避免连续止损
- 给市场恢复时间
- 降低手续费消耗

## 七、策略优势与局限

### ✅ 优势

1. **超参数化设计**：多个可优化参数，适配性强
2. **数学逻辑严谨**：归一化比值消除价格绝对值影响
3. **多重确认机制**：买入卖出均需多条件满足，减少假信号
4. **趋势+均值回归**：结合趋势判断和均值回归思想
5. **风险控制完善**：分级止盈、追踪止损、频率限制三层保护
6. **与 GSN 版本互补**：可对比测试两个"双胞胎"策略的表现差异

### ⚠️ 局限

1. **参数过多**：多根均线 + 多个阈值，过拟合风险高
2. **依赖优化**：默认参数可能不是最优，需要 Hyperopt 调参
3. **新手不友好**：理解门槛高，参数调整复杂
4. **计算资源需求**：Hyperopt 优化需要大量计算资源和时间
5. **市场适应性**：参数可能只在特定市场环境下有效

- **趋势跟随**：卖出条件确认趋势转强后获利了结

| 对比项 | HyperStra_SMAOnly | HyperStra_GSN_SMAOnly |

| 条件组数 | 3 组买入 + 3 组卖出 | 3 组买入 + 3 组卖出 |

| 适用场景 | 需要 Hyperopt | 需要 Hyperopt |

**建议**：可同时运行两个策略，对比优化结果和实盘表现，选择更适合当前市场环境的版本。

## 十一、总结

**HyperStra_SMAOnly** 是一个设计严谨、参数众多的超参数化均线策略。它的核心价值在于：

1. **归一化创新**：使用 SMA 归一化比值消除价格绝对值影响，提高策略通用性
2. **多重确认**：买入卖出均需多条件同时满足，减少假信号干扰
3. **灵活适配**：超参数化设计可根据不同市场环境优化参数
4. **双胞胎策略**：与 HyperStra_GSN_SMAOnly 形成互补，可对比选择更优版本

对于有量化经验的交易者而言，本策略提供了良好的参数优化框架，但新手应谨慎使用。策略的成功高度依赖 Hyperopt 优化结果，建议在充分回测、与 GSN 版本对比测试、以及小资金实盘验证后再投入较大资金。

**核心建议**：会调参、有时间调参、愿意验证的人使用，追求"开箱即用"的量化交易者不适合此策略。建议同时测试 HyperStra_GSN_SMAOnly 和本策略，选择表现更优的版本。

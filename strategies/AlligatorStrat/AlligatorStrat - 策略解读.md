## 一、策略概览

AlligatorStrat 是一个基于简单移动平均线（SMA）交叉和 MACD 指标确认的趋势跟踪策略。该策略由 Gert Wohlgemuth 开发，核心思路是捕捉短期趋势的突破机会，通过多周期 SMA 的交叉作为主要入场信号，MACD 作为趋势确认指标。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 2 个独立买入信号（SMA交叉 + MACD交叉），可独立触发 |
| **卖出条件** | 2 个基础卖出信号 + ROI 止盈 |
| **保护机制** | 固定止损 -20% |
| **时间框架** | 4 小时（较长时间周期，适合趋势跟踪） |
| **依赖库** | talib, qtpylib |

# ROI 退出表

## 三、买入条件详解

### 3.1 技术指标体系

策略使用以下技术指标：

| 指标类别 | 具体指标 | 用途 |
|---------|---------|------|
| 趋势指标 | SMA(5), SMA(8), SMA(13) | 判断短期、中期、长期趋势 |
| 动量指标 | MACD, MACD Signal, MACD Histogram | 确认趋势方向和动量 |

### 3.2 买入条件详解

#### 条件 #1：SMA 交叉 + MACD 确认

```python
# 逻辑
- SMA(5) 上穿 SMA(8)（短期均线上穿中期均线）
- MACD 值 > -0.00001（MACD 略高于零轴）
- MACD > MACD Signal（MACD 线在信号线上方）
```

**解读**：
- 这是主要的买入信号，要求两个条件同时满足
- SMA 交叉捕捉短期动量变化
- MACD 确认趋势方向，避免假突破

#### 条件 #2：MACD 交叉

```python
# 逻辑
- MACD 上穿 MACD Signal（MACD 金叉）
```

**解读**：
- 独立的买入信号，可单独触发
- 简单的 MACD 金叉策略
- 作为 SMA 交叉的补充信号

### 3.3 买入条件汇总表

| 条件编号 | 核心逻辑 | 复杂度 |
|---------|---------|-------|
| #1 | SMA(5)上穿SMA(8) + MACD确认 | 中等 |
| #2 | MACD 金叉 | 简单 |

## 四、卖出逻辑详解

### 4.1 卖出条件

#### 信号 #1：趋势反转信号

```python
# 逻辑
- 收盘价 < SMA(8)（价格跌破中期均线）
- MACD < MACD Signal（MACD 在信号线下方）
```

**解读**：
- 价格跌破中期均线暗示短期趋势走弱
- MACD 确认动量衰减
- 两条件需同时满足

#### 信号 #2：MACD 死叉

```python
# 逻辑
- MACD 下穿 MACD Signal（MACD 死叉）
```

**解读**：
- 独立的卖出信号
- 简单的 MACD 死叉策略
- 作为趋势反转的早期预警

### 4.2 卖出信号汇总表

| 信号编号 | 核心逻辑 | 优先级 |
|---------|---------|-------|
| #1 | 价格跌破SMA(8) + MACD确认 | 主信号 |
| #2 | MACD 死叉 | 辅助信号 |

## 五、技术指标体系

### 5.1 核心指标

| 指标类别 | 具体指标 | 用途 |
|---------|---------|------|
| 趋势指标 | SMA(5, 8, 13) | 判断趋势方向和交叉信号 |
| 动量指标 | MACD(12, 26, 9) | 确认趋势和动量变化 |

### 5.2 指标计算说明

**SMA（简单移动平均线）**：
- SMA(5)：5 周期简单移动平均，代表超短期趋势
- SMA(8)：8 周期简单移动平均，代表短期趋势
- SMA(13)：13 周期简单移动平均，代表中期趋势（计算但未用于交易信号）

**MACD（移动平均收敛散度）**：
- 使用 talib 默认参数（12, 26, 9）
- MACD 线：12 周期 EMA - 26 周期 EMA
- Signal 线：MACD 的 9 周期 EMA
- Histogram：MACD - Signal

## 六、风险管理特色

### 6.1 固定止损机制

策略采用固定 20% 止损：

```python
stoploss = -0.2  # 20% 止损
```

**设计思路**：
- 较宽的止损范围，适应 4 小时时间框架
- 允许价格在趋势形成过程中有正常波动
- 避免因短期噪音而被止损出局

### 6.2 ROI 目标

单一 10% 利润目标：

```python
minimal_roi = {"0": 0.1}
```

**设计思路**：
- 适度的盈利目标
- 不追求极端收益
- 配合 4 小时时间框架，适合波段交易

### 6.3 时间框架优势

- 4 小时周期减少了市场噪音
- 降低交易频率，减少手续费和滑点成本
- 适合趋势跟踪策略

## 七、策略优势与局限

### ✅ 优势

1. **简单直观**：策略逻辑清晰，仅使用 SMA 和 MACD 两个经典指标
2. **双重确认**：买入信号要求 SMA 交叉 + MACD 确认，减少假信号
3. **4 小时周期**：减少市场噪音，适合趋势跟踪
4. **独立信号**：MACD 金叉可作为独立信号，增加交易机会

### ⚠️ 局限

1. **缺乏追踪止损**：固定止损可能错过趋势延续的机会
2. **单一 ROI 目标**：没有分阶段止盈，可能错过更大利润
3. **指标较少**：仅依赖 SMA 和 MACD，可能在高波动或震荡市中表现不佳
4. **作者备注**：作者明确表示 "doesn't really perfom that well and its just a proof of concept"

## 十一、总结

**AlligatorStrat** 是一个**概念验证型的趋势跟踪策略**。它的核心价值在于：

1. **教育价值**：展示了如何结合 SMA 和 MACD 构建趋势跟踪策略
2. **简洁设计**：逻辑清晰，易于理解和修改
3. **双重确认**：SMA 交叉 + MACD 确认减少了假信号

对于量化交易者而言，这个策略更适合作为学习模板，而非直接实盘使用。作者明确表示这是一个概念验证策略，实际表现可能不如预期。建议在此基础上添加更多过滤条件、优化止盈止损逻辑，或结合其他指标进行改进。

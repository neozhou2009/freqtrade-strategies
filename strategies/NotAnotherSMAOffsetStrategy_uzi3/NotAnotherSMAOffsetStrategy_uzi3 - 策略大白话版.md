# NotAnotherSMAOffsetStrategy_uzi3 策略大白话版

## 一、这策略是干嘛的？

说人话，这就是一个帮你自动"抄底逃顶"的交易机器人。

它的名字叫 NotAnotherSMAOffsetStrategy_uzi3，听着挺唬人，其实就是"不是普通的均线偏移策略"。什么意思呢？普通策略就是"价格上穿均线就买，下穿就卖"，这个策略不一样，它用了偏移——比如不是说价格超过均线就买，而是价格要"比均线低3%"才考虑买。这种设计可以让你在更便宜的位置上车，或者在更高的位置下车。

这策略最适合做加密货币短线交易，用的是5分钟K线图，就是那种"今天买明天卖"的节奏。

---

## 二、策略的基本逻辑是什么？

想象你在菜市场买菜。

普通策略是这样的：看到菜价涨了就跟着买，看到跌了就卖。

这个策略是这样的：
1. 先看菜价最近是涨是跌（用均线判断）
2. 如果是涨势，等菜价回调到便宜的位置再买
3. 如果是跌势，等菜价跌过头了再抄底
4. 赚了钱以后，等涨不动了再卖

核心思想就是：**不追高，不杀跌，找舒服的位置进出**。

## 三、策略用到了哪些工具？

策略用了一堆技术指标，我来一个个解释：

### 1. 移动平均线（MA）

这是最基础的工具。把过去N天的价格加起来除以N，就得到一条平滑的线。策略用了好几种：

- **EMA_100**：100周期的指数移动平均，用来判断大趋势。价格在这条线上面就是牛市，下面就是熊市。
- **EMA_10**：10周期的快均线，用来判断短期走势。
- **SMA_9**：9周期的简单移动平均，用来判断什么时候该卖。
- **HMA_50**：50周期的Hull均线，比普通均线更灵敏，也是用来判断卖点的。

### 2. ZLEMA2（零滞后均线）

这是策略自己发明的一个指标。普通均线有个毛病叫"滞后"——价格涨了它还在那趴着。ZLEMA2就是为了解决这个问题，让均线反应更快。

怎么算的呢？先算一遍EMA，再对EMA算一遍EMA，然后把两次的差加回去。简单说就是"双重平滑加修正"，让均线更贴着价格走。

### 3. EWO（波浪震荡指标）

这个指标有点高深，来自波浪理论。

公式很简单：(5日EMA - 200日EMA) ÷ 收盘价 × 100

这个数告诉我们：
- 正值大的时候，说明短期均线在长期均线之上，牛市特征明显
- 负值大的时候，说明短期均线在长期均线之下，熊市特征明显
- 接近零的时候，说明市场在震荡

策略用这个指标来判断：现在是"该买"还是"该等"。

### 4. RSI（相对强弱指数）

这个是看超买超卖的。

- RSI > 70，说明买的人太多了，价格可能要回调
- RSI < 30，说明卖的人太多了，价格可能要反弹

策略用了三个RSI：
- RSI_14：标准的
- RSI_4：快速的，用来抓短线
- RSI_20：慢速的，用来确认趋势

### 5. 布林带（Bollinger Bands）

布林带由三条线组成：中轨是均线，上轨和下轨是中轨加减两倍标准差。

价格跌破下轨，说明太便宜了，可能反弹。
价格突破上轨，说明太贵了，可能回调。

策略用了两组布林带参数，一组看40天的，一组看20天的，各有各的用处。

## 四、什么时候买入？

策略有四种买入信号，满足任何一个就会买。

### 第一种：EWO1 信号

条件是：
1. RSI_4 < 35 —— 说明短期价格跌得差不多了
2. 价格 < 均线 × 0.986 —— 比均线低1.4%左右
3. EWO > 4.179 —— 说明整体还是牛市
4. RSI_14 < 58 —— 不是超买状态
5. 有成交量

**大白话**：牛市里的回调，价格跌到均线下面一点，可以考虑抄底。

### 第二种：EWO2 信号

条件类似，但：
- 价格要更低（比均线低5.6%左右）
- RSI要更极端（小于25）

**大白话**：价格跌得更狠了，属于深度回调，可以更大胆一点。

### 第三种：EWO Low 信号

条件是：
1. RSI_4 < 35
2. 价格 < 均线 × 0.986
3. EWO < -16.917 —— 说明空头力量非常强
4. 有成交量

**大白话**：市场很恐慌，大家都在卖。但跌过头了，反弹可能要来了。这是"别人恐惧我贪婪"的玩法。

### 第四种：BB_Bull 信号

这个信号专门针对牛市，条件比较复杂，简单说就是：

**条件一**：价格跌破布林带下轨，而且满足一堆形态条件（波动够大、下影线不能太长等等）

**条件二**：价格在长期均线上方但在短期均线下方，而且跌破布林带下轨

**大白话**：在牛市里，价格突然跌破布林带下轨，可能是抄底好机会。

## 五、什么时候卖出？

卖出也有条件，不是随便卖的。

### 条件一

1. 价格 > 9日均线 —— 短期价格还行
2. 价格 > 卖出均线 × 1.018 —— 涨了1.8%以上
3. RSI > 50 —— 还是多头市场
4. RSI_4 > RSI_20 —— 短期动能在减弱

### 条件二

1. 9日均线突然涨了0.5%以上 —— 可能冲高回落
2. 价格 < Hull均线 —— 开始走弱
3. 价格还在卖出区域
4. RSI_4 > RSI_20 —— 动能减弱

**大白话**：价格涨了一波，但动能开始减弱，该见好就收了。

### 还有强制卖出

策略有个ROI表格：

| 持有时间 | 达到收益就卖 |
|---------|-------------|
| 刚买入 | 21.5% |
| 40分钟后 | 3.2% |
| 87分钟后 | 1.6% |

刚买入的时候，如果一口气涨了21.5%，直接卖掉锁定利润。如果没那么快涨，就等一等。时间越长，要求的收益越低，因为怕利润回吐。

## 六、亏了怎么办？

策略有完善的止损机制。

### 固定止损

亏损达到10%，自动止损出场。这是底线，不能亏更多。

### 追踪止损

这个更高级。当盈利达到2.5%后，系统会开始"盯着"你的利润：

- 如果你继续赚，止损线会跟着往上走
- 如果你开始亏，但还没碰到止损线，继续拿
- 如果价格回撤碰到止损线，自动卖出

追踪止损和最高点保持0.5%的距离，给你一点波动空间，但不让利润变成亏损。

### 只在赚钱时才卖

配置里有个设置：`sell_profit_only = True`

意思是，只有当持仓是盈利的时候才会响应卖出信号。如果还亏着呢，系统会无视卖出信号，等待回本或者触发止损。

## 七、这个策略有什么特别的？

### 1. 自动适应市场

策略有个"智能模式切换"：

```python
if 最近一根K线跌幅 > 2%:
    # 进入"大跌模式"
    止损放宽到 -30%
    追踪止损偏移改成 3%
    买入偏移更深（找更便宜的位置）
else:
    # 正常模式
    止损 -10%
    正常参数
```

**大白话**：如果市场突然大跌，策略会放宽止损，不让你在恐慌中被震出局。同时调整买入条件，在更便宜的位置寻找机会。

这个设计很人性化，因为大跌之后往往会反弹，如果止损太紧会被洗出去，错过反弹。

### 2. 滑点保护

成交的时候，价格可能和你预期的不一样，这叫"滑点"。

策略有个保护机制：
- 如果滑点超过2%，拒绝成交
- 最多重试3次
- 还是不行就算了

**大白话**：如果市场流动性差，买卖价差太大，策略会保护你不被坑。

### 3. 卖出二次确认

策略有个 `confirm_trade_exit` 方法，在卖出信号触发后会再检查一遍：

```python
if HMA_50 接近 EMA_100 且 价格 < EMA_100 的 95%:
    return False  # 不卖
```

**大白话**：如果价格已经跌很惨了，但趋势可能要反转，策略会拒绝卖出信号，避免卖在地板上。

## 八、用这个策略要注意什么？

### 优点

1. **信号质量高**：不是单一指标说了算，要好几个指标同时确认，假信号少
2. **动态适应**：能根据市场状况自动调整，不是死板的
3. **风控完善**：止损、追踪止损、滑点保护都有
4. **出场机制多样**：主动卖、被动止盈、强制止损，总有一个适合你

### 缺点

1. **参数多**：理解起来要花时间，调优更费劲
2. **震荡市容易被套**：横盘震荡的时候，均线没方向，可能来回被打脸
3. **没有仓位管理**：每次买多少要你自己定
4. **大跌判断简单**：只看一根K线跌多少，可能误判

## 九、怎么用好这个策略？

### 第一步：先回测

不要上来就实盘！用历史数据跑一遍回测，看看：
- 胜率多少？（一般60%以上算好）
- 盈亏比多少？（平均赚的比平均亏的多）
- 最大回撤多少？（从最高点跌到最低点的比例）
- 一天交易多少次？（太多太少都不好）

### 第二步：模拟盘测试

回测好看不等于实战好用。先用模拟盘跑一个月，看实际表现。

### 第三步：小资金实盘

确认没问题后，用小资金试水。单笔不要超过总资金的5%。

### 第四步：持续监控

策略不是"设好就不管"的。要定期看：
- 胜率有没有变化？
- 最近市场风格变了没？
- 参数需要调整吗？

## 十、常见问题

### Q1：这个策略适合什么币？

波动适中、流动性好的币种。比特币、以太坊这种主流币最合适。小币种波动太大，容易被假信号坑。

### Q2：需要多少本金？

没有硬性要求，但建议至少几百U。太少的话单笔收益没意义，手续费还会吃掉不少。

### Q3：一天交易多少次？

看市场情况。行情活跃可能好几次，没行情可能一天都没交易。5分钟K线的策略，正常一天0-10次不等。

### Q4：止损会失效吗？

极端行情下可能。比如闪崩的时候，价格瞬间跌20%，你设的10%止损可能根本成交不了，实际亏损更大。这个风险要有心理准备。

### Q5：和别的策略比怎么样？

没有最好的策略，只有最适合的策略。这个策略偏向"稳健抄底"，不适合追涨杀跌的人。如果你喜欢快进快出，可能别的策略更合适。

## 十一、策略的核心代码逻辑

给懂代码的朋友简单解释一下核心逻辑：

### 买入逻辑

```python
# 入口信号
if RSI快线 < 35 and 价格 < 均线 × 偏移 and EWO > 阈值 and RSI < 阈值:
    买入()

# 或者在大跌时更激进地买入
if 价格跌幅 > 2%:
    调整参数(更大的止损, 更深的买入偏移)
```

### 卖出逻辑

```python
# 出场信号
if 价格 > 短期均线 and 价格 > 目标价 and RSI > 50 and 快RSI > 慢RSI:
    卖出()

# 或者趋势开始走弱
if 短期均线突然上涨 and 价格 < Hull均线 and 动能减弱:
    卖出()
```

### 保护机制

```python
if 滑点 > 2%:
    重试最多3次，还不行就放弃

if 卖出信号触发 and 可能是假信号:
    拒绝卖出()
```

## 十三、总结

NotAnotherSMAOffsetStrategy_uzi3 是一个"有想法"的策略。它不是简单地追涨杀跌，而是：

1. **在趋势中找回调机会** —— 不追高
2. **在恐慌中找反弹机会** —— 不杀跌
3. **动态适应市场变化** —— 一套参数不包打天下
4. **多重保护机制** —— 止损、追踪止损、滑点保护

适合那些想在币圈做短线，又不想盯盘的朋友。但记住，没有稳赚的策略，风险永远是第一位的。

**用之前三步走**：回测 → 模拟盘 → 小资金实盘。

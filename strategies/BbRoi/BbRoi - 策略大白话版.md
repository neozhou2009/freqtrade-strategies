# BbRoi 策略：布林带里的老司机

> **外号**：趋势跟踪派、EMA 三剑客  
> **职业**：多头市场的猎手  
> **时间框架**：15 分钟

---

## 一、这策略是个啥？

简单说，**BbRoi** 就是一个：
- 只做多头趋势的策略
- 在布林带通道里找机会
- EMA 三条线保驾护航

就像一个**老司机**，只在道路畅通（趋势向上）的时候开车，而且一定在车道内行驶（布林带通道），看到红灯（RSI 超买）就停车。🚗

**名字由来**：Bb（布林带）+ Roi（投资回报率），翻译过来就是"布林带帮我赚钱"！

---

## 二、核心配置：说白了就是"顺势而为"

### 止盈规则（ROI 表）

```
刚买入就涨：17.552% 也要止盈
53分钟后：   降到 11.466%
226分钟后：  降到 6.134%
400分钟后：  必须走人
```

**翻译**：这策略也很贪心，刚买入就想要 17.5%！但如果你磨磨蹭蹭涨不动，6 个多小时后就强制平仓。

### 止损规则

```
硬止损：-23.7%
追踪止损：盈利 1.8% 后启动，锁定 1% 利润
```

**翻译**：
- 能亏 23.7% 才认栽，比 Bandtastic 的 34.5% 更合理
- 赚了 1.8% 就开始保护利润，这个设置比较保守

### 订单配置

```python
买入：市价单（不墨迹）
卖出：市价单（赶紧跑）
止损：限价单 + 交易所执行（减少滑点）
```

**翻译**：市价单说明这策略不纠结几分钱的滑点，止损放交易所说明作者怕网络延迟。

## 三、买入条件：5 道安检门

这策略的买入条件很严格，5 个条件必须**同时满足**：

### 🚧 第 1 道：价格在中轨上方
```python
close > bb_middleband
```
**大白话**：
> "价格必须在布林带通道的上半部分，不要抄底！"

### 🚧 第 2 道：价格在上轨下方
```python
close < bb_upperband
```
**大白话**：
> "价格还没突破上轨，不要追高！"

### 🚧 第 3 道：价格在短期 EMA 上方
```python
close > ema9
```
**大白话**：
> "价格在 9 周期 EMA 上方，短期趋势向上！"

### 🚧 第 4 道：价格在长期 EMA 上方
```python
close > ema200
```
**大白话**：
> "价格在 200 周期 EMA 上方，长期趋势向上！"

### 🚧 第 5 道：中期趋势确认
```python
ema20 > ema200
```
**大白话**：
> "20 周期 EMA 在 200 周期 EMA 上方，确认是多头趋势！"

## 四、卖出条件：2 条逃跑路线

卖出条件用"或"逻辑，满足任一就跑：

### 🚪 路线 1：RSI 超买
```python
RSI > 75
```
**大白话**：
> "RSI 超过 75 了，价格太热了，赶紧跑！"

### 🚪 路线 2：跌破中轨 + 阴线
```python
(close < bb_middleband * 0.97) and (open > close)
```
**大白话**：
> "价格跌破中轨 3%，而且是一根阴线，趋势可能要反转，跑！"

## 五、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **逻辑清晰**：买入 5 条，卖出 2 条，简单明了
2. **趋势过滤**：EMA200 确保只做多，不做空
3. **风险控制**：止损 23.7%，追踪止损，RSI 止盈
4. **参数简洁**：没有 Hyperopt 参数，不过拟合
5. **交易所止损**：减少网络延迟风险

### ⚠️ 缺点（吐槽环节）

1. **条件太严**：5 个同时满足，可能错过机会
2. **无法调参**：参数写死，不能根据市场调整
3. **RSI 固定**：75 这个值可能不适合所有币种
4. **只做多不做空**：熊市基本不交易

## 十二、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

BbRoi 的逻辑简洁，但有几个坑：

> **只做多不做空**：熊市基本不交易，如果你在熊市跑这个策略，要么不赚钱，要么亏钱。

### 简单策略的隐藏风险

实盘时，简单的逻辑可能导致：
- **错过机会**：5 个买入条件太严，很多好机会被过滤
- **参数固定**：RSI 75 可能在某些币种上不适用
- **只做多头**：熊市完全失效
- **布林带局限**：趋势行情中通道持续扩张

### 我的建议（真心话）

```
1. 只在牛市或震荡上行市场使用
2. 选择流动性好的主流币
3. 观察比特币大盘，趋势向下就关掉
4. 可以考虑放宽 RSI 阈值到 70
5. 小仓位测试，别一上来就梭哈
```

**记住**：简单策略不等于稳赚策略。趋势跟踪的核心是"顺势而为"，但趋势什么时候结束，谁也不知道。活着最重要！🙏

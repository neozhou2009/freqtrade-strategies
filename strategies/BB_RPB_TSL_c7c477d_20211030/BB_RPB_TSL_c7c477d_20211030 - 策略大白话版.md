## 二、核心配置：说白了就是"赚了就跑，亏了看 BTC"

### 止盈规则（ROI 表）

```
利润 > 10% → 直接走人
```

**翻译**：这个 ROI 表基本是个摆设，真正的主角是自定义追踪止损。

### 止损规则

```
基础止损：-10%（硬兜底）
实际止损：看追踪止损函数怎么说
```

**翻译**：基础止损是保命的，但平时用不上。真正的止损是动态的——赚了钱止损就收紧，亏着钱止损就放宽。

### 追踪止损（核心！）

```
利润 < 1%    → 止损 -17.8%（很宽松，允许波动）
利润 1%~4.8% → 止损 0.9%~4.3%（逐渐收紧）
利润 > 4.8%  → 止损随利润涨（锁定盈利）
```

**大白话**：
> "你赚 1%，我给你留 0.9% 的退路；你赚 4.8%，我给你留 4.3% 的退路。赚越多，退路越窄——逼着你把利润锁住！"

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **BTC 保镖太聪明了**：BTC 一崩就自动禁用买入，避免在恶劣环境下抄底
2. **追踪止损很科学**：利润越高止损越紧，真正实现"让利润奔跑"
3. **买入信号多样化**：7 个条件覆盖超卖、趋势回调、波浪等场景
4. **Ichimoku 确认很稳**：1 小时云图提供趋势方向，避免逆势操作
5. **Hyperopt 优化空间大**：30+ 参数可调，适配性强

### ⚠️ 缺点（吐槽环节）

1. **参数太多了**：30+ 个 Hyperopt 参数，优化起来头痛
2. **BTC 数据必须配**：没 BTC/USDT 数据，保护机制就不工作
3. **计算量大**：布林带、Ichimoku、EWO 都要算，老机器可能卡
4. **卖出信号太少**：主要靠止损离场，主动卖出信号不多

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

BB_RPB_TSL 的历史回测表现往往**还不错**——但这有个陷阱：

> **因为参数众多（30+），策略很容易"拟合"过去行情的最优解，但这并不代表未来一定能盈利。**

简单说就是：
> **"回测完美 ≠ 实盘赚钱"**

### 复杂策略的隐藏风险

实盘时，复杂的逻辑可能导致：
- **BTC 数据延迟**：实时 BTC 数据可能滞后，保护机制反应不及时
- **止损计算偏差**：追踪止损函数依赖实时价格，交易所延迟可能影响止损精度
- **计算超时**：指标计算量大，K 线更新时可能超时错过信号

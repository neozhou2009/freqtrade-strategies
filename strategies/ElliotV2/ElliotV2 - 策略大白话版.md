# ElliotV2 策略大白话版

## 一、这个策略是干嘛的？

简单说，ElliotV2 是一个帮你在加密货币市场上"低买高卖"的自动交易策略。

它的名字里带着"Elliot"，是因为它用了一个叫"艾略特波浪振荡器"的技术指标。这个指标最早是个叫拉尔夫·尼尔森·艾略特的老哥在 1930 年代发明的，他观察股票市场多年，发现价格的涨跌像海浪一样，有一定的规律可循。

他认为市场情绪会在乐观和悲观之间循环，这种循环会反映在价格走势上。上涨的时候会分成几个波浪，下跌的时候也是一样。如果能识别这些波浪的规律，就能在合适的时机买卖。

这个策略就是想抓住这些"波浪"——在波浪的低谷买入，在波浪的高峰卖出。听起来很简单对吧？但要做到可不容易。ElliotV2 用了现代的计算机程序，帮我们自动化地判断这些时机。

它是专门给 Freqtrade 这个量化交易软件用的。如果你有个加密货币交易所的账户，配置好这个软件，就能让它自动帮你交易，不用自己盯着盘看了。

---

## 二、它怎么判断什么时候买？

这个策略有两套买入的办法，就像你有两把不同的钥匙，开不同的门。这样可以适应不同的市场情况，涨也有机会，跌也有机会。

### 第一把钥匙：趁回调捡便宜

想象一个趋势向上的股票，价格一直在涨。但涨着涨着，总有人想落袋为安，卖掉一部分，价格就往下掉一点。这时候就是"回调"，也有人叫"回撤"或"调整"。

策略会在这种时候出手：
- 价格掉到均线下面一点点（大约低个 2.2%）
- 大趋势还是在涨（用一个叫 EWO 的指标判断）
- 上涨的动能还在（用 RSI 指标确认，不能太高，要低于 63）

这三个条件都满足，策略就会买入。

打个比方：好比你一直想买某个热门商品，平时抢不到，突然有一天搞活动打了个小折，你就赶紧下手了。但你也不会随便买，要先看看这个商品是不是真的好（趋势还在），折扣是不是实在（价格够低），有没有别人在抢（还有动能）。

### 第二把钥匙：暴跌后抄底

有时候市场会恐慌，大家都在卖，价格跌得很惨。但跌多了总会反弹的，对吧？就像橡皮筋拉太紧了会弹回来。

策略在这种时候也会出手：
- 价格掉到均线下方（同样低个 2.2% 左右）
- EWO 指标特别低（低于 -13.043，说明跌得确实很惨）

注意第二套逻辑没有 RSI 的限制。为什么？因为当 EWO 已经低到 -13 以下的时候，市场已经恐慌得不行了，RSI 肯定也很低，没必要重复检查。

这就像商场清仓大甩卖，你进去扫货，等着市场恢复正常后卖出。当然，抄底有风险，有可能抄到半山腰，所以策略还有止损机制保护你。

## 三、那个 EWO 指标是什么鬼？

EWO 的全名是 Elliott Wave Oscillator，中文叫"艾略特波浪振荡器"。

别被这个名字吓到，其实原理很简单。它就是把两条不同周期的移动平均线拿来比一比，看看差多少。

具体怎么算的：
- 算一条快线：EMA(50)——最近 50 根 K 线的指数平均
- 算一条慢线：EMA(200)——最近 200 根 K 线的指数平均
- 然后把两条线的差值除以当前价格，再乘以 100

得到的结果就是 EWO 的值。

这个值代表什么意思呢？

- 如果 EWO 是正的大数，说明快线在慢线上面，短期涨势很猛
- 如果 EWO 是负的大数，说明快线在慢线下面，短期跌势很猛
- 如果 EWO 在零附近，说明两条线差不多，市场在震荡，没有明确方向

ElliotV2 把 EWO 分成了两个区域来用：
- EWO 高于 4.471：这属于"涨势中的回调"，市场大方向还在涨，只是暂时调整。这时候用第一把钥匙入场，跟着趋势走。
- EWO 低于 -13.043：这属于"跌得太多了"，可能过度恐慌了。这时候用第二把钥匙入场，赌它反弹。

这两个数字（4.471 和 -13.043）不是随便定的，是经过大量历史数据测试优化出来的，在这个设置下效果最好。

## 四、EMA 是什么？为什么用两条不同的？

EMA 是 Exponential Moving Average 的缩写，中文叫"指数移动平均线"。

要理解它，先说说普通的移动平均线（SMA）。SMA 就是把最近 N 根 K 线的收盘价加起来，除以 N。比如 5 日均线，就是把最近 5 天的收盘价加起来除以 5。

EMA 不同的地方在于：越近的数据权重越大。比如今天的股价对 EMA 的影响最大，昨天的次之，前天的更次之。这样更能反映最新的价格走势，对价格变化反应更快。

ElliotV2 用了两条不同周期的 EMA：
- 买入时看 31 周期的 EMA——这是一个中等长度的周期
- 卖出时看 99 周期的 EMA——这是一个比较长的周期

为什么买入卖出用不同的周期？

买入用短一点周期的 EMA，是因为你需要在相对短的时间内找到入场机会。31 周期的 EMA 对价格变化反应比较灵敏，能帮你找到较好的入场点。

卖出用长周期的 EMA，是因为你想确保趋势真的确立向上了，不是短期的波动。99 周期的 EMA 比较稳定，不会因为短期波动就乱动。

简单说：入场要快，出场要稳。进场的时候反应要灵敏，抓住机会；出场的时候要沉稳，确保真的赚到钱了再走。

## 五、它怎么判断什么时候卖？

卖出的逻辑比买入简单多了，就一个条件。

策略设了一条"止盈线"——当价格涨到均线上方 5.4% 左右的时候，就卖出。

怎么算的呢？用 99 周期的 EMA 作为基准，乘以 1.054。比如 EMA 是 100 块，那止盈线就是 105.4 块。价格涨到这个位置，就卖。

为什么是 5.4%？这是优化出来的结果。如果设得太低，可能刚买就卖了，赚不到什么钱；如果设得太高，可能等很久都等不到，最后还是跌回来。

这个 5.4% 的偏移量给了价格足够的上涨空间，同时也不会太贪心。

当然，这只是信号卖出。策略还有其他卖出的方式，比如止损和追踪止损，我们后面会详细讲。

## 六、RSI 指标是做什么的？

RSI 是 Relative Strength Index 的缩写，中文叫"相对强弱指数"。

它的值在 0 到 100 之间，用来判断市场是不是"超买"或"超卖"了：
- 超过 70，通常被认为是"超买"，价格可能要回调
- 低于 30，通常被认为是"超卖"，价格可能要反弹

但这个不是绝对的，有时候超买了还能继续涨，超卖了还能继续跌。RSI 只是给一个参考。

ElliotV2 在第一套买入逻辑里用了 RSI：
- 要求 RSI 低于 63

为什么不要求低于 30（超卖）？因为如果真等到那么低，可能已经错过最好的入场点了。63 是一个折中的数字——既不会太激进（在超买区买入，可能马上就跌），也不会太保守（等太久，错过机会）。

注意：第二套买入逻辑（超卖抄底）没用 RSI。因为那时候 EWO 已经特别低了（低于 -13.043），市场已经恐慌得不行，RSI 肯定也很低，没必要重复检查。

## 七、止盈止损怎么设置的？

这个策略的风险管理做得挺完善的，有"三道防线"来保护你的钱。

### 第一道防线：固定止损

这是最基础的保护：最多亏 17.9%。如果价格真的跌这么多，策略会自动卖出止损，不会让你一直亏下去。

有人可能说："17.9% 太多了吧？能不能设小一点？"

但加密货币市场波动大，有时候一天就能跌个 10% 以上。止损设得太紧，可能刚被震出去，价格就涨回来了，那就更亏。

17.9% 是经过计算和测试的，既能保护本金，又不会太容易被正常波动触发。

### 第二道防线：追踪止损

这是一个"水涨船高"的机制，非常聪明。它的逻辑是：

- 等你赚了 4.9% 以后，这个机制才启动
- 启动后，它会一直跟着最高价走，保持在最高价下方 1% 的位置
- 一旦价格回调碰到这条线，就自动卖出

举个例子说明：

假设你 100 块买入一个币：
- 价格涨到 105 块，你赚了 5%。这时候追踪止损启动，止损线在 105 × 0.99 = 103.95 块
- 价格继续涨到 110 块，止损线升到 110 × 0.99 = 108.9 块
- 价格继续涨到 120 块，止损线升到 120 × 0.99 = 118.8 块
- 突然价格开始跌，跌到 118.8 块，触发止损，卖出！你最终赚了 18.8%

这就像放风筝：风筝飞得越高，你手里的线就放得越长，但始终保持在能收得回来的范围内。一旦风筝开始往下掉，你就收线。

追踪止损的好处是：如果价格一直涨，你就能一直拿着，吃到最大的利润；如果价格开始跌，你也能保住大部分利润，不会把赚的钱都吐回去。

### 第三道防线：分级止盈

这是根据持仓时间来设置不同盈利目标的机制：

| 持仓时间 | 止盈目标 |
|----------|----------|
| 刚买入 | 15.4% |
| 18 小时后 | 7.4% |
| 50 小时后 | 3.9% |
| 165 小时（约 7 天）后 | 2% |

为什么时间越长目标越低？

因为你的资金被占用着呢。如果一笔交易压了一个星期还不赚钱，这资金的机会成本就上来了。与其压着不赚钱，不如早点释放资金去找下一个机会。

打个比方：你借钱做生意，前三天利息低，你可以等个好价钱再卖；但如果压了一个月，光利息就不少了，这时候能赚点就赶紧出手。

这三道防线配合起来，形成了一个完整的保护体系：止损保护本金，追踪止损伤保利润，分级止盈控制时间成本。

## 八、这个策略适合什么币？

简单说，适合波动适中、流动性好的主流币。

比较适合的：
- BTC（比特币）——市值最大，流动性最好
- ETH（以太坊）——第二大的币，也很稳定
- 其他主流币如 SOL、ADA、AVAX 等

不太适合的：
- 刚上的新币——没有足够的历史数据，指标算不准
- 极端波动的山寨币——可能触发不了条件就被洗出去了，或者止损经常被打掉
- 流动性很差的币——买卖价差大，滑点严重，实际成交价格可能和你想的不一样

时间框架用的是 5 分钟 K 线，这是比较短的周期，适合日内交易或者短线交易。如果你想用更长的时间框架（比如 1 小时或 4 小时），需要重新调整参数，因为不同周期的参数优化出来的结果可能不一样。

## 九、这个策略的优点是什么？

### 1. 逻辑清晰，容易理解

这个策略的核心就是两个入场条件、一个出场条件，外加三道防线。没有几十个指标叠加在一起让你云里雾里。你很容易理解它在做什么，为什么买，为什么卖。

### 2. 风险管理完善

固定止损、追踪止损、分级止盈，三道防线保护你的资金。不是那种"要么赚死要么亏死"的策略，而是有一套系统的风控机制。

### 3. 参数可以调整

策略开放了 7 个主要参数让你优化。你可以针对不同的币种、不同的市场环境进行调整，不是死板的。

### 4. 能适应不同行情

两套入场逻辑：一套抓趋势回调（涨的时候买），一套抓超跌反弹（跌多了买）。这样不管市场是涨是跌，都有机会。

### 5. 有理论支撑

基于艾略特波浪理论，不是随便想出来的。当然理论归理论，实际效果还是要看回测和实盘。

## 十、这个策略有什么风险？

### 1. 震荡市可能会亏钱

这个策略本质是趋势策略，最适合有明确方向的市场（要么涨要么跌）。如果市场一直在横盘震荡，上上下下但不涨不跌，可能会反复买入卖出，每次都亏一点手续费和价差。

就像你打鱼，水流很急的时候网能抓住鱼；但如果水是静止的，网来网去都是空的。

### 2. 止损可能太宽

17.9% 的止损对很多人来说太宽了。如果你投入 10000 块，一次可能亏 1790 块。能不能承受这个亏损，要自己掂量。如果觉得太宽，可以自己调整，但要注意调整后可能影响整体效果。

### 3. 参数不是一成不变的

现在的参数是在 2023 年的数据上优化出来的。市场在变化，2024 年、2025 年可能就不一样了。需要定期重新优化，或者针对不同时期使用不同参数。

### 4. 快速反转可能反应不过来

EMA 和 EWO 都是基于历史数据算的，有一定的滞后性。如果市场突然反转（比如突发大利空或大利好），策略可能反应不及，还在按原来的方向交易。

### 5. 需要一定的技术基础

虽然策略本身是自动的，但要使用好它，你需要理解它的原理，会做回测，会优化参数，会分析结果。不是下载来就能躺着赚钱的。

## 十一、怎么用这个策略？

### 第一步：准备环境

你需要：
1. 安装 Python 和 Freqtrade 软件
2. 有一个加密货币交易所账户（比如 Binance、OKX 等）
3. 在交易所创建 API 密钥，配置到 Freqtrade 里

### 第二步：下载策略

把 ElliotV2.py 文件放到 Freqtrade 的策略目录下（通常是 user_data/strategies/）。

### 第三步：回测

在真钱交易之前，先用历史数据回测看看效果：

```bash
freqtrade backtesting --strategy ElliotV2 --timerange 20230101-20231231
```

回测会告诉你：这个策略在那个时间段能赚多少钱，最大回撤是多少，胜率是多少等等。

### 第四步：优化参数

如果默认参数效果不好，可以用 hyperopt 来优化：

```bash
freqtrade hyperopt --strategy ElliotV2 --spaces buy sell --timerange 20230101-20231231 -j 4
```

这会自动搜索最优的参数组合。但要注意：优化过度可能导致过拟合——在历史数据上表现很好，但未来数据上表现很差。所以要用样本外数据验证。

### 第五步：模拟盘（Dry Run）

先用虚拟资金跑一段时间，看看表现如何：

```bash
freqtrade trade --strategy ElliotV2 --dry-run
```

模拟盘不会真的交易，只是按照策略的逻辑模拟。这样可以观察策略在实时市场的表现。

### 第六步：实盘交易

确认模拟盘效果不错后，再用真钱交易：

```bash
freqtrade trade --strategy ElliotV2
```

建议从小金额开始，比如只用总资金的 10%-20%，等稳定盈利后再加仓。

## 十二、有什么参数可以调？

策略开放了 7 个主要参数，都在代码里用 IntParameter 和 DecimalParameter 定义了：

| 参数名 | 默认值 | 可调范围 | 作用 |
|--------|--------|----------|------|
| base_nb_candles_buy | 31 | 5-80 | 买入用的 EMA 周期 |
| base_nb_candles_sell | 99 | 5-80 | 卖出用的 EMA 周期 |
| low_offset | 0.978 | 0.9-0.99 | 买入价格偏移 |
| high_offset | 1.054 | 0.99-1.1 | 卖出价格偏移 |
| ewo_high | 4.471 | 2.0-12.0 | EWO 高阈值（趋势入场） |
| ewo_low | -13.043 | -20.0--8.0 | EWO 低阈值（抄底入场） |
| rsi_buy | 63 | 30-70 | RSI 入场上限 |

**调参的一些思路**：

**想更激进（交易更频繁，入场更快）**：
- 降低 low_offset（比如 0.95，这样价格只要比均线低 5% 就可以入场）
- 提高 ewo_high（比如 8.0，更容易触发趋势入场）
- 提高 rsi_buy（比如 70，RSI 高也能入场）
- 缩短 EMA 周期（比如买入用 20 周期）

**想更保守（交易更少，但质量更高）**：
- 提高 low_offset（比如 0.99，等价格跌得更多再买）
- 降低 ewo_high（比如 3.0，只有趋势很强才入场）
- 降低 rsi_buy（比如 50，等 RI 更低再入场）
- 延长 EMA 周期（比如买入用 50 周期）

**想更快卖出**：
- 降低 high_offset（比如 1.03，3% 利润就卖）
- 缩短卖出 EMA 周期

**想更长时间持有**：
- 提高 high_offset（比如 1.08，8% 利润才卖）
- 延长卖出 EMA 周期

当然，参数不是想怎么改就怎么改的。最好的办法是用 hyperopt 优化，让电脑帮你找到最优的参数组合。

## 十三、最后的叮嘱

### 1. 没有稳赚的策略

这是最重要的一点：任何策略都有亏钱的时候，这个也不例外。量化交易能做的只是提高胜率、控制风险，不能保证必胜。

回测数据再好看，也不代表未来就一定一样。市场在变化，策略也要跟着调整。

### 2. 回测好≠实盘好

历史数据跑得好，不代表未来就一定好。因为：
- 回测可能有幸存者偏差（用这个时间段数据好，换个时间段可能就差了）
- 回测没考虑滑点、网络延迟等实盘会遇到的问题
- 市场结构在变化，以前有效的规律以后可能无效

所以实盘前一定要做模拟盘测试，而且要用小金额开始。

### 3. 仓位管理很重要

别把所有钱都放进去。建议先用 10%-20% 的资金试水，等确认策略稳定盈利了再慢慢加。

还要留一部分资金作为备用，万一连续亏损需要补仓或者等待机会。

### 4. 定期检查

策略不是设好了就能忘的。建议每周或每月看看策略表现，如果明显变差，可能需要：
- 调整参数
- 暂停策略
- 分析市场是不是发生了变化

### 5. 保持学习

加密货币市场变化很快，新币种、新概念、新玩法层出不穷。多学习新知识，了解市场发生了什么变化，才能更好地调整策略。

### 6. 心态要稳

策略交易最怕的就是手痒去干预。设定好了就让它跑，除非有明确的问题需要调整。频繁干预往往只会帮倒忙。

祝你交易顺利！量化交易是一场马拉松，不是短跑。坚持学习和优化，才能走得更远。

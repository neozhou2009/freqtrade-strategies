## 一、这策略是个啥？

简单说，**mark_strat_opt** 就是一个：
- 专门等"股市崩盘"的超跌抄底策略
- 要求 5 个指标同时说"可以买"才动手
- 信号稀少但质量极高

就像一个**狙击手**，趴在草丛里一动不动，等到猎物完全进入射程才开枪 🎯

## 二、核心配置：说白了就是"快进快出"

### 止盈规则（ROI 表）

```
0 分钟：赚 7% 就跑
8 分钟：赚 1% 也行
19 分钟：赚 0.5% 走人
34 分钟：保本也得撤
```

**翻译**：这策略根本不想长拿，开仓就想跑。超过半小时，赚不赚都得走人，生怕煮熟的鸭子飞了 😅

### 止损规则

```
固定止损：-20.2%
追踪止损：盈利超过 7.5% 后启动，锁定 9.8% 的利润空间
```

**翻译**：止损设得很宽，给价格足够的折腾空间。但一旦赚钱超过 7.5%，就开始"追着利润跑"，不让你把赚到的吐回去。

## 五、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **信号质量极高**：5 个条件同时满足，基本不可能假突破
2. **抓极端行情能力强**：布林带 4 倍标准差，这是真正的"崩盘抄底"
3. **止盈机制完善**：ROI + 追踪止损，双保险
4. **逻辑清晰易懂**：超卖→反弹→止盈，一条龙

### ⚠️ 缺点（吐槽环节）

1. **信号太少了**：5 个条件全满足？一年可能就几次机会
2. **1 分钟级别太累**：高频交易对 API 延迟和稳定性要求高
3. **参数太精细**：像 6.965%、7.573% 这种精确到小数点后几位的数字，一看就是"拟合"出来的
4. **极端行情滑点大**：真崩盘的时候，你想买不一定买得到

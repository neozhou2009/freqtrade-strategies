## 一、策略概览

mark_strat_opt 是一个专注于捕捉极端超跌行情的短线策略。其核心理念是"在恐慌中贪婪"——当价格跌破布林带下轨4倍标准差，且多个动量指标同时处于极端超卖区域时进场，等待价格均值回归。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 5 个独立指标条件，需同时满足（AND 逻辑） |
| **卖出条件** | 4 个条件组合 + 追踪止盈 |
| **保护机制** | ROI 分级止盈 + 追踪止损双重保护 |
| **时间框架** | 1 分钟级别，高频交易 |
| **依赖库** | talib, qtpylib, numpy, pandas |

## 三、买入条件详解

### 3.1 买入信号（单一条件组，5 个指标）

策略采用**全指标确认模式**，所有条件必须同时满足：

```python
dataframe.loc[
    (
        (dataframe['adx'] > 49) &                    # 条件1: ADX > 49
        (dataframe['fastd'] < 30) &                  # 条件2: FastD < 30
        (dataframe['mfi'] < 23) &                    # 条件3: MFI < 23
        (dataframe['rsi'] < 34) &                    # 条件4: RSI < 34
        (dataframe['close'] < dataframe['bb_lowerband4'])  # 条件5: 收盘价跌破布林带下轨(4倍标准差)
    ),
    'buy'] = 1
```

### 3.2 条件解读

| 条件编号 | 指标 | 阈值 | 市场含义 |
|---------|------|------|---------|
| #1 | ADX | > 49 | 趋势强度极高（极端行情） |
| #2 | FastD | < 30 | 随机指标超卖 |
| #3 | MFI | < 23 | 资金流量极度枯竭 |
| #4 | RSI | < 34 | 相对强弱超卖 |
| #5 | 收盘价 | < BB下轨4σ | 价格极端偏离均值 |

**买入逻辑总结**：
- 这是一个**极端超跌捕捉策略**
- 要求趋势强度极高（ADX > 49），确保有足够的波动
- 同时要求多个动量指标处于超卖区间
- 价格必须跌破布林带下轨4倍标准差，这是极其罕见的极端情况
- 五重条件同时满足，信号稀少但质量极高

## 四、卖出逻辑详解

### 4.1 卖出信号（4 条件组合）

```python
dataframe.loc[
    (
        (dataframe['adx'] < 95) &                    # 条件1: ADX < 95
        (dataframe['fastd'] > 70) &                  # 条件2: FastD > 70
        (dataframe['rsi'] > 94) &                    # 条件3: RSI > 94
        (qtpylib.crossed_above(dataframe['sar'], dataframe['close']))  # 条件4: SAR 上穿收盘价
    ),
    'sell'] = 1
```

| 条件编号 | 指标 | 阈值 | 市场含义 |
|---------|------|------|---------|
| #1 | ADX | < 95 | 趋势强度限制（几乎总是满足） |
| #2 | FastD | > 70 | 随机指标超买 |
| #3 | RSI | > 94 | 相对强弱极度超买 |
| #4 | SAR | 上穿收盘价 | 抛物线转向看空信号 |

**卖出逻辑总结**：
- 要求多个指标同时进入极端超买区域
- SAR 上穿收盘价作为趋势反转确认
- 信号触发意味着价格已经大幅反弹

### 4.2 ROI 分级止盈

| 时间（分钟） | 目标收益 | 说明 |
|------------|---------|------|
| 0 | 6.965% | 开仓即时止盈阈值 |
| 8 | 1.125% | 8分钟后降低要求 |
| 19 | 0.498% | 19分钟后进一步降低 |
| 34 | 0% | 34分钟后保本退出 |

### 4.3 追踪止损机制

- 激活门槛：盈利 7.57%
- 追踪偏移：9.8%
- 当价格持续上涨时，追踪止损会锁定利润

## 五、技术指标体系

### 5.1 核心指标

| 指标类别 | 具体指标 | 用途 |
|---------|---------|------|
| 趋势强度 | ADX | 判断趋势是否足够强劲 |
| 动量指标 | RSI | 相对强弱超卖/超买判断 |
| 资金流量 | MFI | 资金进出强度 |
| 随机指标 | FastD (Stochastic Fast) | 快速随机指标 |
| 波动通道 | Bollinger Bands (4σ) | 价格极端偏离判断 |
| 趋势反转 | SAR (Parabolic SAR) | 趋势转向信号 |
| 趋势指标 | MACD | 辅助趋势判断 |

### 5.2 指标计算代码

```python
# 趋势强度指标
dataframe['adx'] = ta.ADX(dataframe)
dataframe['sar'] = ta.SAR(dataframe)

# 动量指标
dataframe['rsi'] = ta.RSI(dataframe)
dataframe['mfi'] = ta.MFI(dataframe)

# 随机指标
stoch_fast = ta.STOCHF(dataframe)
dataframe['fastd'] = stoch_fast['fastd']

# 布林带（4倍标准差）
bollinger4 = qtpylib.bollinger_bands(
    qtpylib.typical_price(dataframe), window=20, stds=4
)
dataframe['bb_lowerband4'] = bollinger4['lower']

# MACD
macd = ta.MACD(dataframe)
dataframe['macd'] = macd['macd']
dataframe['macdsignal'] = macd['macdsignal']
```

## 六、风险管理特色

### 6.1 极端值多重确认

策略要求 5 个条件同时满足才进场：
- ADX > 49：确保有足够趋势强度
- FastD < 30、RSI < 34、MFI < 23：多重超卖确认
- 收盘价跌破布林带下轨 4 倍标准差：价格极端偏离

### 6.2 快速止盈机制

- ROI 从 7% 快速递减至保本
- 34 分钟后强制保本退出
- 追踪止损锁定大幅盈利

### 6.3 宽幅止损空间

- 固定止损 -20.2%，给予足够回旋空间
- 避免被正常波动止损出局

## 七、策略优势与局限

### ✅ 优势

1. **信号质量极高**：5 重条件同时满足，极大降低假信号
2. **捕捉极端行情**：布林带 4 倍标准差是极其罕见的超跌情况
3. **快速止盈机制**：ROI 快速递减 + 追踪止损双重保护
4. **逻辑清晰**：买入和卖出条件明确，可解释性强

### ⚠️ 局限

1. **信号稀少**：极端超跌行情不常发生，交易机会有限
2. **高频要求**：1 分钟级别需要稳定 API 连接和低延迟
3. **滑点风险**：极端行情时流动性可能不足
4. **过度拟合风险**：精确的参数阈值可能是历史数据拟合结果

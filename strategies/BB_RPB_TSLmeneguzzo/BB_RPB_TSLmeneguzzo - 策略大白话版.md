## 二、核心配置：说白了就是"多赚少亏"

### 止盈规则（ROI 表）

```
0 分钟 → 20.5% 利润就跑
81 分钟（约1.3小时）→ 3.8% 利润就跑
292 分钟（约5小时）→ 0.5% 利润就跑
```

**翻译**：刚开仓时胃口很大，要赚20%+；等了1个多小时还没大赚，就降低期望到3.8%；拖了快5小时，能赚0.5%就知足跑路。这叫"**耐心递减法**"——越等越没脾气 😅

### 止损规则

```
硬止损：-10%（跌10%强制割肉）
```

**翻译**：单笔最多亏10%，这是最后的保命线。

### 动态止盈（这个才是亮点！）

```
利润 > 20% → 止盈线提到 5%（保护5%利润）
利润 > 10% → 止盈线提到 3%（保护3%利润）
利润 > 6%  → 止盈线提到 2%（保护2%利润）
利润 > 3%  → 止盈线提到 1.5%（保护1.5%利润）
```

**翻译**：赚得越多，保护越紧！就像**爬山一样**——爬得越高，安全绳越要收紧，防止一失足跌回山脚。

**大白话**：

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

BB_RPB_TSLmeneguzzo 的历史回测表现往往**极其优异**——但这有个陷阱：

> **因为条件众多、参数众多，策略很容易"拟合"过去行情的最优解，但这并不代表未来一定能盈利。**

简单说就是：**你是在"背答案"，不是在"学会解题"。**

### 复杂策略的隐藏风险

实盘时，复杂的逻辑可能导致：
- **错过信号**：多个条件同时满足的概率低，可能等半天等不到信号
- **过拟合**：参数都是针对历史数据优化的，未来可能失效
- **计算超时**：指标太多，5分钟内算不完就错过K线
- **滑点被放大**：条件越多，判断越精确，但实际成交价可能偏离

### 我的建议（真心话）

```
1. 先跑回测，看看在你的交易对上表现如何
2. 必须跑 Hyperopt 优化参数（默认参数不一定是最好的）
3. 小仓位测试至少1个月
4. 观察哪些买入条件触发最多，考虑禁用表现差的条件
5. 定期重新优化参数（每季度一次）
```

**记住**：策略再好，市场教做人时也不会打招呼。轻仓测试，活着最重要！🙏

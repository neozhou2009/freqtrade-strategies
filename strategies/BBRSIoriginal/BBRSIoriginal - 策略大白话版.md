## 一、这策略是个啥？

简单说，**BBRSIoriginal** 就是：

- 价格跌穿布林带下轨 → 买！
- RSI 飙到 75 以上，价格回到中轨 → 卖！

就这么简单！这是 Freqtrade 自带的默认策略，代码不到 100 行，专门给新手学习的。

就像一个"抄底小能手"：**盯着布林带下轨，只要价格跌穿就进场，等反弹了再卖** 🎣

## 二、核心配置：说白了就是"等着捡便宜"

### 止盈规则（ROI 表）

```
开仓立刻：要赚 9.6% 才卖
19分钟后：赚 3.6% 就卖
69分钟后：赚 1.9% 就卖
120分钟后：有赚就卖，不管多少
```

**翻译**：
- 刚开仓时胃口大，"我要赚 9.6%！"
- 过了 19 分钟开始心急，"算了，3.6% 也行"
- 过了 1 小时更急，"1.9% 也 OK"
- 过了 2 小时，"有赚就跑，别浪费时间"

**吐槽**：
> 这分级 ROI 挺有意思的——刚开仓时"我有耐心"，过了 2 小时就"老子不想等了" 😂

### 止损规则

```
止损：-36.828%
```

**翻译**：
- 亏损超过 36.8% 才止损
- 相当于 100 块变成 63 块才跑

**吐槽**：
> 这止损也太宽了吧！亏三分之一才跑，得多大的心脏才能扛住？这就是传说中的"要么赚，要么扛"！

### 订单类型

```
买入：限价单
卖出：限价单
止损：限价单（本地执行）
```

**翻译**：全用限价单，保证价格可控。止损不在交易所执行，由 Freqtrade 本地控制。

## 三、买入条件：价格穿布林带下轨就干

### 🎯 核心逻辑

**条件就一个**：

```python
close < bb_lowerband3  # 价格跌破 3 倍标准差布林带下轨
```

### 什么是"3 倍标准差布林带"？

布林带大家都知道：中轨是均线，上下轨是均线加减标准差。

- **1 倍标准差**：大约覆盖 68% 的价格
- **2 倍标准差**：大约覆盖 95% 的价格
- **3 倍标准差**：大约覆盖 99.7% 的价格

**3 倍标准差布林带下轨**：
> 价格跌到这里，意味着"统计学上只有 0.3% 的概率会到这个位置"——极端超卖！

### 买入信号大白话

> **"价格跌破布林带下轨了！这是极端超卖，肯定要反弹的！抄底抄底！"**

**注意**：
- 没有检查成交量
- 没有检查趋势
- 纯粹看"价格够不够低"

**这就是典型的"接飞刀"策略**——价格暴跌时进场，赌它会反弹。

---

## 四、卖出逻辑：RSI 飙高就跑

卖出要同时满足两个条件：

### 条件 #1：RSI > 75

```python
RSI > 75  # RSI 超过 75
```

**大白话**：
> "RSI 到 75 了，这是超买，动量太猛了！"

### 条件 #2：价格回到布林带中轨上方

```python
close > bb_middleband  # 价格高于布林带中轨
```

**大白话**：
> "价格已经反弹回中轨了，抄底成功！"

### 两个条件都要满足

```python
(RSI > 75) AND (close > bb_middleband) → 卖出
```

**大白话翻译**：
> "价格反弹到中轨，而且 RSI 也超买了——说明反弹到位了，该收手了！"

## 五、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **简单得令人发指**：代码不到 100 行，谁都能看懂。Freqtrade 默认策略，新手必学。

2. **经典组合**：布林带 + RSI，技术分析的"米饭和面条"，怎么搭都不会太差。

3. **极端信号可靠**：3 倍标准差布林带突破，统计学上真的很极端，信号质量高。

4. **1 小时框架舒服**：不像 5 分钟那么累，也不像日线那么慢，兼职玩家友好。

5. **适合手动交易**：信号简单，在 TradingView 设个报警就能盯。

### ⚠️ 缺点（吐槽环节）

1. **止损宽得离谱**：36% 的止损？！亏三分之一才跑，这得多大的心脏！

2. **无脑抄底**：不管什么趋势，跌穿下轨就买。下跌趋势里这就是"接飞刀大王"。

3. **信号稀少**：3 倍标准差布林带突破不是天天有，可能几天都没信号。

4. **卖出条件苛刻**：RSI 要到 75，还要价格回中轨。可能反弹了半天，RSI 就是不到 75，最后被 ROI 强制卖出。

5. **没用到 4 倍布林带**：代码里计算了 4 倍标准差布林带，但完全没用！这是什么操作？可能是作者忘了删？

## 八、这策略在什么市场能赚钱？

### 8.1 核心逻辑：均值回归派

BBRSIoriginal 是典型的 **"均值回归策略"**——相信价格围绕均线波动，极端偏离时会回归。

**它的赚钱哲学**：
- 布林带下轨 = 极端超卖 = 该反弹了
- 布林带中轨 = 正常价位 = 反弹到位了
- RSI > 75 = 超买 = 该卖了

### 8.2 不同市场表现（说人话版）

| 市场类型 | 表现评级 | 大白话解释 |
| :--- | :--- | :--- |
| 📈 强势上涨 | ⭐☆☆☆☆ | 价格一直在布林带上轨晃悠，根本不会触发买入 |
| 🔄 震荡反弹 | ⭐⭐⭐⭐⭐ | 完美主场！价格来回穿布林带，抄底卖出循环 |
| 📉 单边下跌 | ⭐⭐☆☆☆ | 天天抄底天天被套，接飞刀接一手血 |
| ⚡ 高波动无方向 | ⭐⭐⭐☆☆ | 信号是有，但可能质量参差不齐 |

**一句话总结**：
> **震荡反弹市是它的主场，单边趋势市是它的噩梦。**

## 十二、⚠️ 风险再强调（这段一定要看）

### 这个策略是"入门教材"，不是"赚钱神器"

BBRSIoriginal 是 Freqtrade 官方提供的默认策略，主要用途是：

> **教你理解 Freqtrade 策略怎么写，不是让你直接拿去赚钱！**

### 三大风险

1. **止损太宽**：36% 的止损，遇到"黑天鹅"事件可能一天亏完几个月的利润。

2. **无脑抄底**：下跌趋势里频繁触发买入，越抄越低，最后被止损收割。

3. **信号稀疏**：3 倍标准差布林带突破很罕见，可能一周只有几笔交易。

### 我的建议（真心话）

```
1. 止损改成 10%-15%，别用默认的 36%
2. 加一个趋势过滤器（比如 EMA100），下跌趋势里禁止买入
3. 多选几个交易对（10-20个），信号稀疏需要分散
4. 回测至少 6 个月数据
5. 或者——干脆把它当模板，自己改造成更适合的策略
```

**记住**：这是学习材料，不是印钞机。理解它，修改它，超越它！🙏

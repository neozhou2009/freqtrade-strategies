# BuyOnly 策略："只买不卖"的佛系 HODL 党

> **外号**：佛系 HOLD 党、只买不卖  
> **职业**：买进去就躺平，等止盈或止损  
> **时间框架**：15 分钟（中频交易）

---

## 一、这策略是个啥？

简单说，**BuyOnly** 就是一个：
- 只买不卖的超级佛系策略
- 4 个指标同时确认才买入的谨慎鬼
- 卖出全靠止盈止损的懒人玩家
- 代码少到爆的极简主义者

就像你买了股票直接删掉交易软件，等涨到目标价或者跌到止损位再打开卖掉——中间的波动？关我什么事！🤣

这策略的名字就叫 **"只买"**，代码里卖出函数是空的，只写了个 `HODL` 注释——这是加密货币圈的著名梗，意思是"死拿不动"。

---

## 二、核心配置：说白了就是"躺平"

### 止盈规则（ROI 表）

```
持仓 < 30分钟 → 赚 4% 就跑
持仓 30-60分钟 → 赚 2% 就跑
持仓 > 60分钟 → 赚 1% 就跑
```

**大白话**：这止盈设置有点反直觉！持有时间越短，止盈目标越高。为啥？策略认为刚买入时点位好，应该多赚点；时间久了就见好就收，别贪。

### 止损规则

```
亏损 10% → 认栽走人
```

**大白话**：跌 10% 就割肉，不跟你墨迹。

### 追踪止损

```
trailing_stop = True（启用默认追踪止损）
```

**大白话**：还能追着跑，涨了就跟着涨，回头了就卖。

## 三、1 个买入条件：四保险确认

这策略就 **1 个买入条件**，但是有 4 个子条件必须同时满足：

```python
(
    qtpylib.crossed_above(dataframe["rsi"], 30)    # RSI 从 30 下面穿上来
    & (dataframe["open"] <= dataframe["bb_lowerband"])  # 开盘价在布林带下轨或更低
    & (dataframe["tema"] > dataframe["tema"].shift(1))   # TEMA 往上走
    & (dataframe["volume"] > 0)                          # 有成交量
)
```

**大白话翻译**：
> "老板！我发现一个好机会！RSI 刚从超卖区爬上来，价格开在布林带下轨附近（说明跌太多了），TEMA 还在往上走（趋势向上），成交量也有——这是要反弹的节奏啊！买！"

**四个条件缺一不可**，全满足才出手。

### 买入信号分解

| 条件 | 技术含义 | 大白话 |
|------|---------|--------|
| RSI 上穿 30 | RSI 从超卖回升 | 卖不动了，该反弹了 |
| 开盘价 ≤ 布林带下轨 | 价格极端低位 | 便宜到离谱了 |
| TEMA 向上 | 趋势方向 | 已经开始往上走了 |
| 成交量 > 0 | 有交易活动 | 不是死币，有人在玩 |

## 四、保护机制：不好意思，没有！

BuyOnly 是极简策略，**没有**那些复杂的保护机制：
- 没有买入保护参数组
- 没有 EMA 保护
- 没有 ADX 过滤

策略觉得 RSI + 布林带 + TEMA 这三个指标本身就是保护了。🤷‍♂️

## 五、卖出逻辑：完全没有！

```python
def populate_exit_trend(self, dataframe: DataFrame, metadata: dict) -> DataFrame:
    """
    HODL
    """
    return dataframe
```

看！卖出函数里就一个注释 `HODL`，然后直接返回空数据。

**所有退出全靠被动机制**：

| 退出方式 | 触发条件 | 大白话 |
|---------|---------|--------|
| ROI 止盈 | 持仓时间 + 利润率 | 赚够了就跑 |
| 固定止损 | 亏损 10% | 跌太多了认栽 |
| 追踪止损 | 价格回头 | 涨了跟着涨，回头就卖 |

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **简单到爆**：代码就几行，新手 5 分钟看懂
2. **不用管卖出**：买完就躺平，省心
3. **多指标确认**：4 个条件一起看，不容易瞎买
4. **学习友好**：最适合作为入门第一课
5. **可扩展性强**：这就是个"骨架"，想加啥加啥

### ⚠️ 缺点（吐槽环节）

1. **没卖出信号**：完全被动，可能会坐过山车
2. **逆势买入**：下跌趋势也可能买，接飞刀
3. **信号少**：15 分钟 + 4 条件，可能好几天才触发一次
4. **止损太大**：10% 的止损对加密货币来说可能还好，但对其他市场有点宽
5. **不区分牛熊**：啥市场都一样买，不挑食

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

BuyOnly 看起来很简单、很美好——但简单不代表安全！

> **这策略的核心风险：逆势买入、被动退出。**

简单说就是：**你以为抄到底了，其实可能是接飞刀。** 🗡️

### 复杂策略的隐藏风险

即使是这么简单的策略，实盘也有风险：

- **信号太少**：4 个条件同时满足可能很少发生，你会怀疑策略是不是坏了
- **止损太大**：10% 止损在加密货币可能还好，但在其他市场简直是灾难
- **没卖出逻辑**：涨了 20% 回落到 2%，你后悔不后悔？
- **不区分趋势**：下跌趋势里抄底，抄到半山腰

### 我的建议（真心话）

```
1. 不要在下跌趋势中使用！等趋势向上再说
2. 止损可以调小一点，比如 5%
3. 止盈目标可以调高，别太早卖
4. 模拟盘先跑一个月，看看信号频率
5. 小资金测试，确定稳定再加仓
```

**记住**：策略再简单，市场也会教做人。HODL 的前提是你买在了好位置，不是什么时候都能躺平的！

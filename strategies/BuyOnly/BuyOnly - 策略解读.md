# BuyOnly 策略深度解读

> **策略编号**: #39
> **策略类型**: 极简趋势跟踪 + 只买不卖
> **时间框架**: 15 分钟 (15m)

---

## 一、策略概览

BuyOnly 是一个"只买不卖"的极简策略，正如其名称所示——策略只产生买入信号，没有任何主动卖出逻辑。这种设计的核心理念是让利润奔跑，完全依赖止盈和止损机制来退出仓位。

策略采用了经典的技术指标组合：RSI 超卖 + 布林带下轨 + TEMA 趋势确认，形成了一个简洁但有效的买入系统。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 1 个独立买入信号 |
| **卖出条件** | 0 个（完全依赖止盈止损） |
| **保护机制** | 无显式保护机制 |
| **时间框架** | 15 分钟 |
| **依赖库** | talib, technical (qtpylib) |

## 二、策略配置解析

### 2.1 基础风险参数

```python
# ROI 退出表
minimal_roi = {
    "60": 0.01,    # 持有 60 分钟后，1% 利润退出
    "30": 0.02,    # 持有 30 分钟后，2% 利润退出
    "0": 0.04      # 立即退出需要 4% 利润
}

# 止损设置
stoploss = -0.10  # 10% 固定止损
```

**设计思路**：

与常见的策略不同，BuyOnly 的 ROI 设置呈现"反向梯度"——持仓时间越短，止盈目标越高。这是因为策略假设早期入场的点位更具优势，应该追求更高利润。

### 2.2 追踪止损配置

```python
trailing_stop = True
```

策略启用了默认的追踪止损机制。

## 三、买入条件详解

### 3.1 单一买入条件

```python
(
    qtpylib.crossed_above(dataframe["rsi"], 30)) &  # RSI 上穿 30
    (dataframe["open"] <= dataframe["bb_lowerband"]) &  # 开盘价在布林带下轨
    (dataframe["tema"] > dataframe["tema"].shift(1)) &  # TEMA 向上
    (dataframe["volume"] > 0)  # 有成交量
)
```

**逻辑分解**：

1. **RSI crossed_above(30)**：RSI 从超卖区域回升
2. **open <= bb_lowerband**：开盘价在布林带下轨或更低
3. **tema > tema.shift(1)**：TEMA 持续向上
4. **volume > 0**：有实际成交量

**技术含义**：

这是一个典型的"超卖反弹"买入策略：
- RSI 从 30 以下回升表明卖压减轻
- 布林带下轨提供了价格极端位置的参考
- TEMA 确认了短期上升趋势
- 成交量验证了信号的有效性

## 四、卖出逻辑详解

### 4.1 无主动卖出

```python
def populate_exit_trend(self, dataframe: DataFrame, metadata: dict) -> DataFrame:
    """
    HODL
    """
    return dataframe
```

策略的卖出逻辑完全留空，这意味着所有退出决策都依赖于：

| 退出方式 | 触发条件 |
|---------|---------|
| 固定止损 | 亏损 10% |
| 追踪止损 | 启用默认设置 |
| ROI 止盈 | 持仓时间 + 利润率 |

### 4.2 ROI 退出表分析

| 持仓时间 | 止盈阈值 | 设计意图 |
|---------|---------|---------|
| 0 分钟 | 4% | 早期快速止盈 |
| 30 分钟 | 2% | 中期降低预期 |
| 60 分钟+ | 1% | 长期保留仓位 |

## 六、风险管理特色

### 6.1 固定止损

10% 的固定止损为默认设置，提供基本保护。

### 6.2 激进止盈

ROI 设置反映了策略对短期收益的追求，最高达 4%。

### 6.3 无保护机制

## 七、策略优势与局限

### ✅ 优势

1. **极简代码**：易于理解和修改
2. **多指标确认**：RSI + 布林带 + TEMA 三重验证
3. **让利润奔跑**：不主动卖出，依赖止盈止损
4. **学习友好**：适合新手理解策略结构

### ⚠️ 局限

1. **无主动卖出**：完全被动退出
2. **条件单一**：仅一个买入条件
3. **无趋势过滤**：不区分牛熊市
4. **信号可能过于频繁**：15 分钟时间框架

## 九、适用市场环境详解

### 9.1 策略核心逻辑

BuyOnly 的设计理念是"捕捉超卖反弹"。当价格跌至布林带下轨且 RSI 处于超卖区域时，表明价格可能已经触及短期底部。此时买入，期待价格反弹。

### 9.2 不同市场环境表现

| 市场类型 | 表现评级 | 原因分析 |
| :--- | :--- | :--- |
| 📈 上涨趋势 | ⭐⭐⭐⭐ | 反弹信号往往有效 |
| 📉 下跌趋势 | ⭐⭐ | 逆势买入风险高 |
| 🔄 震荡行情 | ⭐⭐⭐ | 布林带下轨常有效 |
| ⚡ 高波动 | ⭐⭐⭐ | 信号频繁 |

## 十一、总结

BuyOnly 是一个"极简主义"的代表作。它用最少的代码实现了趋势跟踪功能，是 Freqtrade 策略库中最简单的策略之一。

它的核心价值在于：

1. **简洁性**：代码量极少，易于理解
2. **让利润奔跑**：不主动干预，让市场决定退出时机
3. **学习价值**：适合作为策略开发的起点
4. **可扩展性**：可以基于此添加各种保护机制

对于量化交易者而言，BuyOnly 是一个非常好的"骨架策略"——可以在此基础上添加更多的条件、保护和复杂的退出逻辑。

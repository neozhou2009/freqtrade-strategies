# SwingHigh 策略：趋势里的"抄底王"

> **外号**：抄底王、回调猎手  
> **职业**：专门在趋势回调时捡便宜货的老司机  
> **时间框架**：30 分钟

---

## 一、这策略是个啥？

简单说，**SwingHigh** 就是一个：
- 用 MACD 判断大方向
- 用 CCI 找极端超卖点
- 在趋势回调时大胆入场

就像 你在看股票涨，发现涨得太猛回调了一下，这时候你就冲进去"抄底" 🤣

---

## 二、核心配置：说白了就是"大胆抄底，小心离场"

### 止盈规则（ROI 表）

```
持仓 0-23 分钟：赚 16% 就跑
持仓 23-54 分钟：赚 3.2% 就跑
持仓 54-173 分钟：赚 1.2% 就跑
持仓 173 分钟后：不赚钱也跑
```

**翻译**：这策略喜欢短线交易，越短时间期望越高。超过 3 小时还在磨叽就懒得等了。

### 止损规则

```
硬止损：-22.27%（亏这么多直接砍）
追踪止损：盈利 10% 后启动，跟着涨，回撤 8% 就跑
```

**翻译**：给你留了 22% 的"容错空间"，一旦赚钱了就自动帮你保住大部分利润。挺人性化的！

---

## 三、1 个买入条件：就这一招鲜

### 🎯 唯一买入条件：MACD 金叉 + CCI 跌到地板

**核心逻辑**：
- MACD 线要金叉（趋势向上）
- CCI 要跌到 -188 以下（极度超卖）
- 有成交量（不是假数据）

**大白话**：
> "股票在涨，突然砸了一下，砸狠了我就进场抄底！"

**代码长这样**：
```python
(dataframe["macd"] > dataframe["macdsignal"]) &   # MACD 金叉
(dataframe["cci-buy"] <= -188.0) &                  # CCI 跌惨了
(dataframe["volume"] > 0)                           # 有成交量
```

**吐槽**：CCI 要跌到 -188 才买，这阈值够极端的！普通超卖是 -100，这策略要等到"血崩"才出手 😅

---

## 四、1 个卖出条件：等它涨疯了再走

### 📉 唯一卖出条件：MACD 死叉 + CCI 飞到天上

**核心逻辑**：
- MACD 线要死叉（趋势向下）
- CCI 要涨到 231 以上（极度超买）
- 有成交量

**大白话**：
> "趋势开始往下走了，而且 CCI 涨到 231，涨疯了，赶紧跑！"

**代码长这样**：
```python
(dataframe["macd"] < dataframe["macdsignal"]) &   # MACD 死叉
(dataframe["cci-sell"] >= 231.0) &                  # CCI 涨疯了
(dataframe["volume"] > 0)                           # 有成交量
```

**注意**：卖出的 CCI 周期是 76，比买入的 13 大很多。意思是：**快速进场，慢慢离场**。

## 五、追踪止损：赚钱后的"保镖"

这个策略有个很赞的设计——追踪止损：

| 参数 | 值 | 大白话 |
|------|-----|--------|
| trailing_stop | True | 开启追踪 |
| trailing_stop_positive | 0.08 | 止损线跟着涨，保持 8% 距离 |
| trailing_stop_positive_offset | 0.10 | 盈利 10% 后才激活 |
| trailing_only_offset_is_reached | True | 没赚够 10% 不追踪 |

**大白话**：
> "赚钱了，先让你跑。等赚够 10% 了，我就给你派个保镖。保镖会跟着价格往上走，但保持 8% 的距离。价格回调超过 8% 就保镖直接把你拽走。"

这设计挺聪明的，既让你吃够涨幅，又不会让你把利润吐回去太多。

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **逻辑简单**：就两个指标，一看就懂
2. **快进慢出**：买入用快 CCI(13)，卖出用慢 CCI(76)，符合趋势交易理念
3. **保护到位**：追踪止损锁利润，22% 大止损给足空间
4. **不花里胡哨**：参数简单，不太容易过拟合

### ⚠️ 缺点（吐槽环节）

1. **信号少**：CCI 要跌到 -188 才买，这种机会不多
2. **只能做多**：不会做空，下跌趋势就歇菜
3. **震荡市找虐**：趋势策略遇上横盘，那就是反复挨打

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

SwingHigh 的历史回测表现可能看起来不错——但要注意：

> **CCI 阈值 -188/231 是比较极端的，历史数据中信号可能不多。如果调整阈值，可能会过拟合。**

简单说就是：**过去的"黄金参数"不一定是未来的"赚钱参数"。**

### 趋势策略的隐藏风险

实盘时，趋势策略可能导致：
- **震荡市反复止损**：趋势策略最怕横盘，可能小刀割肉
- **信号稀少**：CCI 极值不常出现，耐心是关键
- **追踪止损滑点**：快速回调时可能滑点更大

### 我的建议（真心话）

```
1. 先用模拟盘跑至少 1 个月
2. 观察 CCI 信号频率，如果太少可以放宽阈值
3. 不要把所有资金都押在这一个策略上
4. 组合其他策略分散风险
```

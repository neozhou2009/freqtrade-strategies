## 一、这策略是个啥？

简单说，**Inverse** 就是一个：
- 用 **Fisher RSI 逆变换** 的策略
- 会看 **1h + 4h 两个时间框架** 的策略
- **超参数优化** 的策略

就像一个买东西专门等反转的精明买家："Fisher RSI 反转了没？4h 趋势向上了没？都满足了就买！Fisher RSI 反向了就卖！" 🔄

## 二、核心配置：说白了就是"反转 + 趋势"

### 止盈规则（ROI 表）

```
刚买入就赚 10%？→ 跑！
拿了 30 分钟赚 5%？→ 跑！
拿了 60 分钟赚 2%？→ 跑！
```

**翻译**：这策略是典型的"趋势跟踪思维"，10% ROI 较高，预期捕捉大趋势！

### 止损规则

```
硬止损：亏 20% 直接割（宽松）
追踪止损：赚 17.4% 后启动，回撤 7.8% 就跑
```

**翻译**：-20% 止损是真的很宽松，给价格充分波动空间！😅

## 三、买入条件：要同时满足 N 个条件

这策略的买入条件分三部分：

### 🎯 条件 1：Fisher CCI 反转

**核心逻辑**：
1. Fisher CCI 上穿阈值 1（-0.42）
或
2. Fisher CCI 下穿阈值 2（0.41）后反弹

**大白话**：
> "Fisher CCI 都反转了——这还不买？"

### 🎯 条件 2：4h SSL 向上

**核心逻辑**：
1. 4h SSL 上轨 > 4h SSL 下轨

**大白话**：
> "4h 趋势都向上了——这还不买？"

### 🎯 条件 3：EMA 多头排列

**核心逻辑**：
1. 1h 50EMA > 200EMA
2. 4h 50EMA > 100EMA
3. 4h 50EMA > 200EMA

**大白话**：
> "1h 和 4h 的 EMA 都多头排列了——这还不买？"

**吐槽**：这策略是真的"谨慎"，要同时满足这么多条件！🤣

**吐槽**：这策略的保护机制是真的豪华，确认退出让利润奔跑！🤣

## 五、卖出逻辑：Fisher CCI 反向就跑

### 5.1 技术卖出：Fisher CCI 下穿

**触发条件**：
```python
(Fisher CCI 下穿阈值 1) OR (Fisher CCI 下穿阈值 2)
```

**大白话**：
> "Fisher CCI 都下穿阈值了（趋势反转）——这还不跑？"

### 5.2 确认退出：根据 ADX/DI 阻止过早退出

**触发条件**：
```python
if DI 向上 AND ADX 上升:
    阻止退出（让利润奔跑）
```

**大白话**：
> "ADX 还在上升呢（趋势还好），DI 也向上——别跑，让利润再跑跑！"

**吐槽**：这策略是真的"纠结"，一边要止损，一边又要让利润奔跑！🤣

## 六、这策略的"人格特点"

### ✅ 优点
1. **Fisher RSI 逆变换**：捕捉趋势反转点
2. **多时间框架**：1h + 4h 确认趋势
3. **确认退出**：根据 ADX/DI 阻止过早退出
4. **超参数优化**：可以自动找最佳参数
5. **追踪止损**：赚了钱后自动跟着价格走
6. **宽松止损**：-20% 止损，给予充分波动空间

### ⚠️ 缺点
1. **复杂度高**：Fisher RSI + 多时间框架，调试起来头疼
2. **没 BTC 关联**：比特币崩了它也不知道
3. **参数敏感**：优化出来的参数可能过拟合
4. **计算量大**：多指标 + 信息时间框架增加计算负担
5. **1 小时框架**：信号频率比 5m 低

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

Inverse 的历史回测表现可能**非常优异**——但这有个陷阱：

> **多时间框架 + 超参数优化的策略更容易"拟合"出漂亮的回测曲线，因为参数组合多，可能刚好"背对"了那段历史行情。**

简单说就是：**回测数据好看，可能是因为它刚好"记住"了那段行情怎么走。**

### 复杂策略的隐藏风险

实盘时，复杂的逻辑可能导致：
- **信号过少**：多条件确认可能很久没信号
- **过拟合风险**：超参数优化结果可能过拟合
- **计算延迟**：多指标 + 信息时间框架可能有延迟

## 一、策略概览

SMAOffsetProtectOptV1_kkeue_20210619 是一个基于简单移动平均线偏移（SMA Offset）的保护优化策略，结合了 Elliott Wave Oscillator（EWO）指标作为趋势过滤器。该策略通过价格相对于 SMA 的偏移位置来识别买入机会，同时利用 EWO 区分不同的市场状态，实现多条件入场的灵活交易。

该策略是 SMAOffset 系列的一个优化版本，由社区用户 kkeue 于 2021 年 6 月 19 日修改并发布，在原有的 SMA Offset 逻辑基础上增加了 EWO 保护机制和更精细的参数调优。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 2 个独立买入信号，可独立触发（OR 逻辑） |
| **卖出条件** | 1 个基础卖出信号 + ROI 分级止盈 + 追踪止损 |
| **保护机制** | EWO 高低阈值过滤 + RSI 超买保护 |
| **时间框架** | 5m（主）+ 1h（信息层） |
| **依赖库** | talib, numpy, qtpylib, technical.indicators |

## 三、买入条件详解

### 3.1 核心指标体系

策略依赖以下技术指标进行买卖决策：

| 指标 | 参数 | 用途 |
|------|------|------|
| **SMA Buy** | 默认 16 周期（可优化 5-80） | 计算买入参考价格 |
| **SMA Sell** | 默认 20 周期（可优化 5-80） | 计算卖出参考价格 |
| **EWO** | 快线 50 / 慢线 200 | Elliott Wave 振荡器，判断趋势 |
| **RSI** | 14 周期 | 相对强弱指标，防止超买追高 |

### 3.2 买入参数配置


### 3.3 两个买入条件详解

#### 条件 #1：EWO 高值 + RSI 保护型买入
```python
# 触发条件
- 收盘价 < SMA(16) × 0.973（价格低于均线下方 2.7%）
- EWO > 5.672（Elliott Wave 振荡器为正值且较高）
- RSI < 59（相对强弱未超买）
- 成交量 > 0
```

**逻辑解读**：
- 价格回踩到均线下方 2.7% 左右，属于回调买入
- EWO 高正值表明处于上升趋势中的调整
- RSI 限制防止在过度追高时买入

#### 条件 #2：EWO 低值抄底型买入
```python
# 触发条件
- 收盘价 < SMA(16) × 0.973（价格低于均线下方 2.7%）
- EWO < -19.931（Elliott Wave 振荡器为深度负值）
- 成交量 > 0
```

**逻辑解读**：
- 价格同样处于均线下方 2.7%
- EWO 深度负值表示可能处于下跌末期的超卖状态
- 无 RSI 限制，允许在恐慌时抄底

### 3.4 买入条件分类总结

| 条件组 | 条件编号 | 核心逻辑 | 适用场景 |
|-------|---------|---------|---------|
| 趋势回调 | #1 | EWO 高正 + 价格偏移 + RSI 保护 | 上升趋势中的健康回调 |
| 恐慌抄底 | #2 | EWO 深负 + 价格偏移 | 下跌末期的超卖反弹 |

## 四、卖出逻辑详解

### 4.1 分级 ROI 止盈系统

策略采用四档分级 ROI 机制：

```
持仓时间        目标利润
──────────────────────────
立即          2.8%
10分钟后       1.8%
30分钟后       1.0%
40分钟后       0.5%
```

**设计意图**：
- 早期（0-10分钟）追求较高收益
- 中期（10-40分钟）逐步降低预期
- 长期（40分钟+）接受微利退出

### 4.2 追踪止损机制

```python
trailing_stop = True
trailing_stop_positive = 0.001         # 盈利 0.1% 开始追踪
trailing_stop_positive_offset = 0.01   # 盈利 1% 后启动
trailing_only_offset_is_reached = True  # 仅在达到偏移后启动
```

**工作机制**：
1. 持仓盈利达到 1% 时启动追踪止损
2. 止损线随价格上涨而抬高
3. 价格回调 0.1% 即触发止损

## 五、技术指标体系

### 5.1 核心指标

| 指标类别 | 具体指标 | 用途 |
|---------|---------|------|
| 趋势类 | SMA（5-80 周期可调） | 价格偏移参考基准 |
| 振荡类 | EWO（50/200 EMA 差值） | 趋势方向判断 |
| 动量类 | RSI（14 周期） | 超买超卖判断 |
| 成交量 | Volume | 流动性确认 |

### 5.2 Elliott Wave Oscillator (EWO) 详解

EWO 是该策略的核心保护指标，计算方式如下：

```python
def EWO(dataframe, ema_length=5, ema2_length=35):
    ema1 = ta.EMA(dataframe, timeperiod=ema_length)
    ema2 = ta.EMA(dataframe, timeperiod=ema2_length)
    emadif = (ema1 - ema2) / dataframe['close'] * 100
    return emadif
```

在本策略中使用 50/200 参数组合：
- **正值（> 0）**：表示短期均线在长期均线之上，处于上升趋势
- **负值（< 0）**：表示短期均线在长期均线之下，处于下降趋势
- **高正值（> ewo_high）**：强烈上升趋势，回调买入机会
- **深负值（< ewo_low）**：深度下降趋势，可能超卖反弹

## 六、风险管理特色

### 6.1 多层止损保护

| 止损类型 | 参数 | 作用 |
|---------|------|------|
| 固定止损 | -10% | 基本保护，防止极端亏损 |
| 追踪止损 | 0.1%/1% | 锁定利润，让利润奔跑 |
| ROI 止盈 | 分级递减 | 控制持仓时间，降低风险 |

### 6.2 EWO 双向保护机制

策略利用 EWO 实现双向入场：

- **ewo_high（正向）**：上升趋势中回调买入，利用动量延续
- **ewo_low（负向）**：超卖底部抄底，捕捉反弹机会

### 6.3 RSI 防追高机制

条件 #1 中的 RSI < 59 限制，防止在价格已经强势上涨时追高入场。

## 七、策略优势与局限

### ✅ 优势

1. **双重入场机制**：既能捕捉趋势回调，又能抄底超卖反弹，适应多种市场状态
2. **参数可优化**：五个买入参数均可通过 HyperOpt 进行优化，适应不同交易对
3. **多层风控**：固定止损 + 追踪止损 + ROI 分级，三重保护
4. **趋势过滤**：EWO 指标有效区分趋势状态，避免逆势交易

### ⚠️ 局限

1. **参数敏感性**：默认参数针对特定时期优化，可能不适用于当前市场
2. **震荡市场风险**：在横盘震荡中可能频繁止损
3. **无信息层利用**：虽然配置了 1h 信息框架，但未在主逻辑中实际使用
4. **HyperOpt 过拟合风险**：优化参数可能过度拟合历史数据

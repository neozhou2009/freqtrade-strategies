## 一、这策略是个啥？

简单说，**SMAOffsetProtectOptV1_kkeue_20210619** 就是一个：

- 专门在价格"打折扣"的时候买入

- 有追踪止损帮你锁利润

就像 **去超市买打折商品** —— 你不会在商品正价时买，而是等它贴上黄标签（价格低于均线 2.7%）才开始考虑。但你也得看这商品是不是真的好（EWO 指标），避免买到快过期的烂货 🤣

## 二、核心配置：说白了就是"捡便宜要趁早"

### 止盈规则（ROI 表）

```
刚买入      → 赚 2.8% 就跑
等10分钟    → 1.8% 也行
等30分钟    → 1% 也凑合
等40分钟    → 0.5% 就认了
```

**翻译**：这策略不喜欢长期持有，赚点就走。就像打短线游击战，打了就跑，不拖泥带水。

### 止损规则

```
固定止损：-10%（亏 10% 就认栽）
追踪止损：盈利 1% 后启动，回调 0.1% 就跑
```

**翻译**：
- 如果你亏了 10%，系统帮你割肉
- 如果你赚了 1% 以上，系统就开始帮你"盯着"，价格稍微回调就自动卖出，保住利润

## 三、2 个买入条件：我帮你分类好了

这策略有 **2 个买入条件**，用"OR"逻辑连接，满足任何一个就买入。我给你归了 2 类：

### 🎯 第 1 类：趋势回调买入（条件 #1）

**核心逻辑**：上升趋势中，价格回调到均线下方，趁机捡便宜。

**大白话**：
> "这股票正在涨，现在回调了一点，我看它 RSI 没过热，是个买入的好机会！"

**具体条件**：
```python
收盘价 < SMA(16) × 0.973  # 价格在均线下方 2.7%
EWO > 5.672              # 处于上升趋势
RSI < 59                 # 没有超买
成交量 > 0               # 有交易
```

**经典台词**：
- 条件#1：`close < ma_buy × 0.973 AND ewo > 5.672 AND rsi < 59` → "涨得好好的突然便宜了，还是个好票，买！"

---

### 📉 第 2 类：恐慌抄底买入（条件 #2）

**核心逻辑**：价格跌得很惨，EWO 深度负值，可能要反弹了。

**大白话**：
> "大家都吓傻了在抛，这时候去捡尸体，没准能捡到反弹！"

**具体条件**：
```python
收盘价 < SMA(16) × 0.973  # 价格在均线下方 2.7%
EWO < -19.931            # 深度下跌
成交量 > 0               # 有交易
```

**经典台词**：
- 条件#2：`close < ma_buy × 0.973 AND ewo < -19.931` → "跌得太惨了，这波恐慌应该快结束了，抄底试试！"

这个策略给自己装了三重保险：

## 五、卖出逻辑：见好就收

### 5.1 分级止盈：赚多少跑

```
时间        目标利润
────────────────────
立即        2.8%
10分钟       1.8%
30分钟       1.0%
40分钟       0.5%
```

**大白话**：
- 刚买进去：我要求赚 2.8%！
- 10分钟没到目标：好吧，1.8% 也行
- 30分钟还没：1% 也凑合
- 40分钟了还没：0.5% 就跑吧，别亏就行

这设计就是告诉你：**快跑！别恋战！**

---

### 5.2 追踪止损：让利润飞一会儿

当你的持仓盈利达到 1% 后：
- 追踪止损启动
- 价格继续涨，止损线跟着涨
- 价格回调 0.1%，立刻卖出

**大白话**：
> "兄弟，你已经赚了 1% 了，我帮你盯着。价格继续涨我就跟着抬高止损线，但是只要它回头跌 0.1%，我立刻帮你卖掉，保住你赚的钱！"

---

### 5.3 卖出信号：价格回到均线上方

```python
收盘价 > SMA(20) × 1.010  # 价格高于均线 1%
```

**大白话**：
> "价格已经涨到均线上方 1% 了，可能是时候获利了结了。"

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **逻辑清晰**：就两个买入条件，要么抄回调，要么抄超卖，简单明了
2. **风控严格**：固定止损 + 追踪止损 + 分级止盈，三重保护
3. **参数可调**：5 个买入参数都能优化，适应不同币种
4. **不追高**：条件 #1 有 RSI 限制，防止在过热时追高

### ⚠️ 缺点（吐槽环节）

1. **震荡市场会被洗**：横盘时价格上下穿越均线，频繁触发买卖信号，手续费吃利润
2. **抄底可能接飞刀**：条件 #2 专门抄底，但底部下面还有底
3. **1 小时信息层没实际用**：配置了但是没在逻辑里用，有点浪费
4. **参数可能是"背答案"**：这些默认参数可能是对着历史数据优化出来的，未来不一定管用

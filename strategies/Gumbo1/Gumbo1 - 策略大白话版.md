# Gumbo1 策略：专抓"跌透了的"反弹

> **外号**：反弹猎手  
> **职业**：逆势抄底专家  
> **时间框架**：5 分钟 + 1 小时信息层

---

## 一、这策略是个啥？

**Gumbo1** 就是一个"等跌透了再进场"的策略。它等 EWO 变成极端负值（说明跌多了），然后在布林带支撑位附近找机会买入。

**大白话比喻**：
> 就像接飞刀：
> - 别人都在恐慌抛售
> - 它在等大多数人抛不动了
> - 然后进场捡便宜货 🏴‍☠️

---

## 二、核心配置

```
止盈：10%（刚买）→ 5%（20分钟后）→ 3%（1小时后）
止损：-25%
```

---

## 三、买入条件

### 条件 1：EWO 极端负值
```
EWO < ewo_low（默认 0，可能是负值）
```
**大白话**："跌多了，快要反弹了！"

### 条件 2：1 小时布林带确认
```
bb_middleband_1h >= T3_1h
```
**大白话**："1小时级别的布林带中轨在上面，支撑强劲！"

### 条件 3：T3 <= EMA
```
T3 <= EMA
```
**大白话**："价格在盘整，马上要选方向！"

---

## 四、卖出条件

### 条件 1：随机指标超买
```
stoch > 80
```
**大白话**："已经涨太多了，要回调！"

### 条件 2：T3 触及布林带中轨
```
T3 >= bb_middleband_40
```
**大白话**："价格碰到布林带中轨压力了！"

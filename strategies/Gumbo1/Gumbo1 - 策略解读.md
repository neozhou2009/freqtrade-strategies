## 一、策略概览

Gumbo1 是一个基于 EWO（Elliott Wave Oscillator）、T3 均线和布林带的趋势反转策略。策略核心思想是：在下跌趋势末期捕捉反弹机会，当 EWO 显示极端负值且价格在布林带支撑位附近时入场。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | EWO 极端负值 + T3/EMA 位置关系 + 1 小时布林带确认 |
| **卖出条件** | 随机指标超买 + T3 触及布林带中轨 |
| **保护机制** | 硬止损 + 多时间框架确认 |
| **时间框架** | 5 分钟主框架 + 1 小时信息层 |
| **依赖库** | TA-Lib, technical (qtpylib) |

## 三、买入条件详解

### 3.1 核心买入逻辑

策略采用三重确认机制，所有条件必须同时满足：

| 条件编号 | 条件名称 | 逻辑描述 |
|---------|---------|---------|
| 条件 1 | EWO 极端负值 | EWO < ewo_low 阈值 |
| 条件 2 | 1 小时布林带确认 | bb_middleband_1h >= T3_1h |
| 条件 3 | 价格盘整信号 | T3 <= EMA |

### 3.2 买入条件详解

#### 条件 #1：EWO 极端负值
```python
dataframe['EWO'] < self.ewo_low.value
```

**逻辑解析**：
- EWO（Elliott Wave Oscillator）用于判断动量极端值
- 当 EWO 低于 ewo_low 阈值时，表明下跌动能达到极端
- 极端负值通常出现在下跌趋势末期，预示潜在反转机会

#### 条件 #2：1 小时布林带确认
```python
dataframe['bb_middleband_1h'] >= dataframe['T3_1h']
```

**逻辑解析**：
- 使用 1 小时时间框架的布林带中轨作为趋势确认
- 布林带中轨位于 T3 均线之上，表明长期趋势可能反转
- 多时间框架确认增加信号可靠性

#### 条件 #3：T3 与 EMA 位置关系
```python
dataframe[f'T3_{self.t3_periods.value}'] <= dataframe['EMA']
```

**逻辑解析**：
- T3 均线低于 EMA，表明短期价格处于盘整或超卖状态
- 这种位置关系暗示价格即将选择方向
- 为入场提供时机确认

### 3.3 买入信号综合判断

策略的买入逻辑可概括为：
> **等跌透了再进场** —— 当 EWO 显示极端负值，且多时间框架布林带给出支撑确认时，在价格盘整位置入场。

## 四、卖出逻辑详解

### 4.1 卖出条件

策略采用两个独立的卖出信号：

```python
# 卖出信号 1: 随机指标超买
dataframe[f'stoch_{self.stock_periods.value}'] > self.stoch_high.value

# 卖出信号 2: T3 触及布林带中轨
dataframe[f'T3_{self.t3_periods.value}'] >= dataframe['bb_middleband_40']
```

### 4.2 卖出信号详解

| 信号名称 | 触发条件 | 技术含义 |
|---------|---------|---------|
| 随机指标超买 | Stochastic > 80 | 价格短期涨幅过大，可能回调 |
| T3 触及中轨 | T3 >= 布林带中轨 | 价格已反弹至压力位 |

### 4.3 ROI 分级止盈机制

策略采用分阶段止盈策略：

| 持仓时间 | 目标利润 | 设计意图 |
|---------|---------|---------|
| 立即 | 10% | 快速锁定较大利润 |
| 20 分钟后 | 5% | 逐步降低预期 |
| 64 分钟后 | 3% | 保守锁定 |
| 168 分钟后 | 保本 | 时间止损，避免长时间持仓 |

## 五、技术指标体系

### 5.1 核心指标

| 指标类别 | 具体指标 | 用途 |
|---------|---------|------|

- **1 小时布林带中轨**：确认长期趋势方向
- **T3_1h**：与布林带中轨比较，判断支撑强度

## 六、风险管理特色

### 6.1 宽松止损机制

```python
stoploss = -0.25  # -25%
```

**设计理念**：
- 反转行情波动剧烈，需要足够空间
- 避免"止损后立即反弹"的尴尬
- 适合波动性较大的交易对

**风险提示**：
- 单笔亏损可能较大
- 需配合仓位管理控制风险

### 6.2 多时间框架确认

策略使用 5 分钟主框架 + 1 小时信息层：

| 时间框架 | 用途 |
|---------|------|
| 5 分钟 | 入场时机判断 |
| 1 小时 | 趋势方向确认 |

### 6.3 ROI 分级止盈

| 利润目标 | 触发条件 |
|---------|---------|
| 10% | 立即止盈 |
| 5% | 持仓 20 分钟后 |

## 七、策略优势与局限

### ✅ 优势

1. **多指标确认**：EWO + T3 + 布林带三重确认，提高信号可靠性
2. **反转捕捉能力强**：专门针对趋势反转设计，擅长捕捉反弹机会
3. **宽松止损空间**：-25% 止损给予足够的波动空间，避免被震出局
4. **多时间框架验证**：1 小时信息层提供额外趋势确认

### ⚠️ 局限

1. **参数较多**：EWO、T3、布林带、Stochastic 等参数需要调整
2. **宽松止损风险**：-25% 止损可能导致单笔大亏损
3. **反转失败风险**：如果趋势不反转，可能长时间被套
4. **震荡市场表现一般**：在无明显趋势的市场中可能频繁交易

## 九、适用市场环境详解

Gumbo1 是一个典型的**逆势抄底策略**。基于其代码架构和策略逻辑，它最适合**下跌趋势末期的反弹行情**，而在单边上涨或剧烈震荡市场中表现不佳。

### 9.1 策略核心逻辑

- **等跌透了再进场**：EWO 极端负值表明下跌动能达到极端
- **多时间框架确认**：1 小时布林带提供长期趋势支撑
- **价格盘整确认**：T3/EMA 位置关系判断入场时机

### 9.2 不同市场环境表现

## 十一、总结

**Gumbo1** 是一个专注于趋势反转的逆势抄底策略。它的核心价值在于：

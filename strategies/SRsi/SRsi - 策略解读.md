## 一、策略概览

SRsi 是一个基于 Stochastic RSI（随机相对强弱指标）的极简量化交易策略。该策略通过计算 RSI 的随机指标值，在超卖区域识别买入机会，在超买区域识别卖出机会，是经典的震荡类策略实现。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 1 个买入信号（StochRSI K线上穿超卖区） |
| **卖出条件** | 1 个卖出信号（StochRSI K线下穿超买区） |
| **保护机制** | 基础止损 -15% |
| **时间框架** | 1 分钟 (1m) |
| **依赖库** | talib, qtpylib |

## 三、买入条件详解

### 3.1 Stochastic RSI 指标计算

策略使用经典的 Stochastic RSI 公式：

```python
# 参数设置
p = 14    # RSI 回看周期
d = 3     # D 线平滑周期
k = 3     # K 线平滑周期

# 指标计算
dataframe['rsi'] = ta.RSI(dataframe, timeperiod=30)  # 基础 RSI 使用 30 周期

# Stochastic RSI 计算
srsi = (rsi - rsi.rolling(p).min()) / (rsi.rolling(p).max() - rsi.rolling(p).min())
dataframe['k'] = srsi.rolling(k).mean() * 100  # K 线
dataframe['d'] = dataframe['k'].rolling(d).mean()  # D 线
```

**指标说明**：
- **RSI 周期**：使用 30 周期（较标准的 14 周期更长）
- **Stochastic 周期**：14 周期滚动窗口
- **K 线**：3 周期平滑
- **D 线**：K 线的 3 周期移动平均

### 3.2 买入信号逻辑

```python
# 买入条件
(dataframe['k'] < 15) &              # K 线在超卖区
(dataframe['k'] >= dataframe['d'])   # K 线上穿 D 线（金叉）
```

**逻辑解读**：
1. **K < 15**：价格处于超卖状态，可能被低估
2. **K >= D**：K 线上穿 D 线，表明上涨动能开始

### 3.3 买入信号分类

| 条件组 | 条件编号 | 核心逻辑 |
|-------|---------|---------|
| **超卖金叉** | #1 | K线超卖区(<15) + K线上穿D线 |

## 四、卖出逻辑详解

### 4.1 卖出信号逻辑

```python
# 卖出条件
(dataframe['k'] > 75) &              # K 线在超买区
(dataframe['d'] >= dataframe['k'])   # D 线在 K 线之上（死叉）
```

**逻辑解读**：
1. **K > 75**：价格处于超买状态，可能被高估

### 4.2 卖出信号分类

| **超买死叉** | #1 | K线超买区(>75) + K线下穿D线 |

## 五、技术指标体系

### 5.1 核心指标

| 指标类别 | 具体指标 | 用途 |
|---------|---------|------|
| **震荡类** | RSI(30) | 相对强弱基础指标 |
| **衍生类** | Stochastic RSI | RSI 的随机化处理 |

### 5.2 Stochastic RSI 原理

Stochastic RSI 是对 RSI 指标的二次处理：

```
StochRSI = (RSI - RSI_min) / (RSI_max - RSI_min) × 100
```

**优势**：
- 将 RSI 归一化到 0-100 区间
- 更敏感地捕捉超买超卖
- 产生更频繁的交易信号

**适用场景**：
- 震荡市场
- 区间交易
- 短线交易

## 七、策略优势与局限

### ✅ 优势

1. **极简设计**：代码简洁，易于理解和维护
2. **参数少**：不易过拟合，泛化能力强
3. **执行快**：计算量小，适合高频场景
4. **逻辑清晰**：超买超卖 + 金叉死叉，经典技术分析

### ⚠️ 局限

1. **信号频繁**：1分钟框架下可能产生大量交易信号
2. **无保护机制**：缺少防泵、熔断等高级风控
3. **趋势表现差**：在单边趋势市场可能反复止损
4. **止损较宽**：-15% 止损对短线策略可能过大

## 九、适用市场环境详解

SRsi 是典型的震荡类策略，最适合 **横盘震荡市场**，而在 **单边趋势市场** 表现不佳。

### 9.1 策略核心逻辑

- **超卖买入**：K < 15 时认为价格被低估
- **超买卖出**：K > 75 时认为价格被高估
- **交叉确认**：金叉买入，死叉卖出

### 9.2 不同市场环境表现

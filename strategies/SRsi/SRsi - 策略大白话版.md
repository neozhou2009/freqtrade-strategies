# SRsi 策略：简单到让人怀疑人生的"快进快出选手"

> **外号**：策略界的"极简主义者"  
> **职业**：超卖超买狙击手  
> **时间框架**：1分钟（快到让你眼花）

---

## 一、这策略是个啥？

简单说，**SRsi** 就是一个：
- 用 Stochastic RSI（随机RSI）判断超买超卖
- K线金叉买入，死叉卖出
- 就这么简单！

就像你在菜市场买菜，看到价格跌到历史低点了就买，涨到历史高点就卖。没有花里胡哨的指标，没有复杂的逻辑，主打一个"简单粗暴"。🤣

**代码不到50行**，是策略界的"极简主义者"。

---

## 二、核心配置：说白了就是"赚1.2%就跑，亏15%就认栽"

### 止盈规则（ROI 表）

```
买入后立刻 → 赚1.2%就卖
```

**翻译**：这策略不贪心，赚到1.2%就走人。

### 止损规则

```
固定止损：-15%（亏一成半认栽）
```

**翻译**：止损放得比较宽，给价格足够的波动空间。

---

## 三、1个买入条件：我帮你翻译成人话

### 🎯 唯一的买入条件：超卖金叉

```python
(dataframe['k'] < 15) &              # K线在超卖区
(dataframe['k'] >= dataframe['d'])   # K线上穿D线
```

**大白话翻译**：
> "K线数值小于15（说明超卖了，价格很便宜了），然后K线开始往上走、超过D线（金叉），这时候买入！"

**打个比方**：
就像你在超市看到打折商品，价格已经打到历史低点了（K<15），然后你发现这个价格开始回升了（金叉），这时候买进去，等它反弹。

---

## 四、1个卖出条件：简单直接

### 📉 唯一的卖出条件：超买死叉

```python
(dataframe['k'] > 75) &              # K线在超买区
(dataframe['d'] >= dataframe['k'])   # K线下穿D线
```

**大白话翻译**：
> "K线数值大于75（说明超买了，价格太贵了），然后K线开始往下走、跌破D线（死叉），这时候卖出！"

**打个比方**：
就像你买的股票涨到历史高位了（K>75），然后你发现价格开始往下走了（死叉），赶紧卖了锁定利润。

## 五、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **简单到爆**：代码不到50行，谁都能看懂
2. **参数少**：就3个参数（p=14, k=3, d=3），不会过拟合
3. **执行快**：计算量极小，老电脑都能跑
4. **经典逻辑**：超买超卖+金叉死叉，技术分析入门必修

### ⚠️ 缺点（吐槽环节）

1. **太简单了**：没有风控保护，像个"裸奔"的策略
2. **信号太多**：1分钟框架下，买卖信号可能刷屏
3. **趋势表现差**：单边行情容易被反复打脸
4. **止损太宽**：-15%的止损对短线策略有点大

**吐槽**：这策略就像一个穿着短裤背心去北极的人——简单是简单，但保护措施太少了！😅

## 七、总结：这策略到底咋样？

### 一句话评价
> "简单到让人怀疑人生，但也正因简单，所以不容易出bug。"

### 适合谁用？
- ✅ 量化新手（代码少，容易理解）
- ✅ 想学习策略编写的人
- ✅ 震荡市场爱好者
- ✅ 懒得调参的人

### 不适合谁？
- ❌ 追求高收益的人（止盈太低）
- ❌ 趋势交易者（这策略吃震荡）
- ❌ 需要复杂风控的人（没风控）
- ❌ 手续费高的交易所（频繁交易成本高）

### 我的建议
1. **先学习**：这是入门的好模板
2. **加风控**：自己加止损保护、熔断机制
3. **调参数**：试试不同的超卖超买阈值
4. **换框架**：1分钟太吵，试试5分钟或15分钟

## 八、这策略在什么市场能赚钱？

### 8.1 核心逻辑：吃震荡的"差价党"

SRsi 是典型的震荡策略，它的赚钱哲学是：

> **"低买高卖，反复收割小波动。"**

- **超卖买入**：K < 15，价格"太便宜了"
- **超买卖出**：K > 75，价格"太贵了"
- **交叉确认**：等金叉/死叉确认方向

## 十、彩蛋：这策略的"极简美学"

# 买入：K < 15 且 K >= D（金叉）

**只有**：
- 一个买入条件
- 一个卖出条件
- 一个止损
- 一个止盈

### 改进建议

如果你想用这个策略实盘，建议加上：

```
1. 追踪止损（trailing_stop）
2. 防泵机制（价格异常拉升不买）
3. 熔断机制（连续亏损后暂停）
4. 换成5分钟或15分钟框架
5. 调整超卖超买阈值（比如K<20买入，K>80卖出）
```

## 十二、手动交易者建议

这个策略逻辑简单，手动交易者可以考虑：

1. **打开TradingView**，搜索"Stoch RSI"指标
2. **设置参数**：RSI=30, K=3, D=3, Stochastic=14
3. **等待信号**：
   - K线跌到15以下，然后金叉 → 考虑买入
   - K线涨到75以上，然后死叉 → 考虑卖出
4. **注意**：结合支撑压力位、成交量等其他指标确认

手动交易时，可以把这个作为辅助工具，不要单独依赖。

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

SRsi 在横盘震荡市场回测表现可能很漂亮，但：

> **简单的策略在复杂的市场里，可能被各种意外打脸。**

### 简洁策略的隐藏风险

实盘时，简洁的代价是：
- **无风控保护**：没有熔断，没有防泵
- **信号太多**：1分钟框架下可能频繁交易
- **手续费侵蚀**：高频交易的手续费是隐形杀手
- **滑点影响**：快速波动时成交价格可能偏离

### 我的建议（真心话）

```
1. 不要直接用默认参数实盘
2. 至少换成5分钟框架
3. 加上追踪止损和熔断机制
4. 回测时加上手续费（0.1%）
5. 模拟盘至少跑2周
```

**记住**：简单 ≠ 能赚钱。策略再简单，市场也很狡猾。轻仓测试，活着最重要！🙏

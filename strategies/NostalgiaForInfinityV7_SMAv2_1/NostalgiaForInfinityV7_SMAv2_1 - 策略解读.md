## 一、策略概览

NostalgiaForInfinityV7_SMAv2_1 是 NostalgiaForInfinityV7 系列的 SMA 变体版本，是一个基于多维度技术指标组合的量化交易策略。该策略继承了 NostalgiaForInfinity 系列的复杂性基因，通过 26 个独立买入条件、8 个基础卖出信号以及高度模块化的保护机制，构建了一个多层次的交易决策系统。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 26 个独立买入信号，每个条件可独立启用/禁用 |
| **卖出条件** | 8 个基础卖出信号 + 12 级分级止盈 + 36 种动态退出场景 |
| **保护机制** | 26 组买入保护参数（EMA趋势、SMA方向、安全区间等） |
| **时间框架** | 5m（主框架）+ 1h（信息框架） |
| **依赖库** | qtpylib, talib, technical (zema), numpy, pandas |

## 三、买入条件详解

### 3.1 保护机制（26 组）

每个买入条件都配有独立的保护参数组，包括以下类型：

| 保护类型 | 参数说明 | 默认值示例 |
|---------|---------|-----------|
| `ema_fast` | 快速EMA趋势确认 | EMA26/50/100/200 > EMA200 |
| `ema_slow` | 慢速EMA趋势确认（1h框架） | EMA100_1h > EMA200_1h |
| `close_above_ema_fast` | 收盘价在快速EMA上方 | close > EMA200 |
| `close_above_ema_slow` | 收盘价在慢速EMA上方 | close > EMA200_1h |
| `sma200_rising` | SMA200上升确认 | SMA200 > SMA200.shift(28) |
| `sma200_1h_rising` | SMA200上升确认（1h框架） | SMA200_1h > SMA200_1h.shift(50) |
| `safe_dips` | 安全下跌区间保护 | 10/50/80/100 级别阈值 |
| `safe_pump` | 安全上涨区间保护 | 24/36/48 小时周期检查 |

**安全下跌保护（safe_dips）**：
策略定义了 11 级安全下跌阈值（10-110），每级包含 4 个参数：
- `thresh_0`: 当前K线最大跌幅阈值
- `thresh_2`: 2根K线内最大跌幅阈值
- `thresh_12`: 12根K线内最大跌幅阈值
- `thresh_144`: 144根K线内最大跌幅阈值

**安全上涨保护（safe_pump）**：
防止在剧烈上涨后追高买入，通过检查：
- 价格变化百分比是否超过阈值
- 回撤幅度是否足够（`range_maxgap_adjusted`）

## 六、风险管理特色

### 6.1 多维度保护机制

每个买入条件都有独立配置的保护参数，形成"条件+保护"的双重过滤：

| 保护类型 | 参数数量 | 配置灵活性 |
|---------|---------|-----------|
| EMA趋势保护 | 8种长度 | 可独立开关 |
| 收盘价EMA确认 | 6种长度 | 可独立开关 |
| SMA上升确认 | 5种周期 | 可独立开关 |
| 安全下跌保护 | 11级阈值 | 按条件配置 |
| 安全上涨保护 | 12级 × 3周期 | 按条件配置 |

### 6.2 分级止盈 + 动态追踪

```python
# 止盈配置示例
sell_custom_profit_0 = 0.01   # 1% 利润
sell_custom_rsi_0 = 34.0      # RSI < 34

sell_custom_profit_11 = 0.20  # 20% 利润
sell_custom_rsi_11 = 34.0     # RSI < 34
```

**设计哲学**：利润越高，持有意愿越强，但一旦 RSI 回落确认趋势反转，立即止盈。

### 6.3 Pump 保护与止盈

策略针对短期暴涨（Pump）定义了特殊的买卖保护：

**买入保护**：
- safe_pump 检查：防止在剧烈上涨后追高
- 3 种周期（24/36/48h）× 12 种阈值

**卖出触发**：
- Pump 后利润目标更宽松（1% 即可考虑止盈）
- 结合 SMA 下降趋势，快速止损

## 七、策略优势与局限

### ✅ 优势

1. **高度模块化**：26 个买入条件可独立开关，便于根据市场环境调整
2. **多重保护**：每个条件都有 7 类保护参数，过滤无效信号
3. **灵活止盈**：12 级分级止盈 + 追踪止盈 + 特殊场景止盈，适应不同行情
4. **双时间框架**：5m 信号 + 1h 趋势确认，减少假信号
5. **丰富指标体系**：EMA/SMA/RSI/BB/MFI/EWO/CMF/Chop/ZEMA 综合判断

### ⚠️ 局限

1. **参数过多**：总参数量超过 400 个，优化难度极高
2. **计算开销大**：400 根 K 线预热，多指标计算，对硬件有要求
3. **过拟合风险**：大量参数可能对历史数据过度拟合
4. **配置复杂**：需要深入理解每个保护参数的作用
5. **实盘差异**：回测表现可能与实盘存在较大偏差

## 九、适用市场环境详解

NostalgiaForInfinityV7_SMAv2_1 是 NostalgiaForInfinityV7 系列的 SMA 变体版本。基于其代码架构和社区长期实盘验证的经验，它最适合 **趋势性较强的市场**，而在 **单边暴跌** 时表现不佳。

### 9.1 策略核心逻辑

- **多信号组合**：26 个买入条件覆盖超卖反弹、趋势回调、趋势转换等多种场景
- **保护优先**：每个信号都有独立保护机制，宁可错过，不可做错
- **动态止盈**：根据利润水平和 RSI 状态动态调整止盈策略
- **双周期确认**：5m 信号必须通过 1h 趋势验证

### 9.2 不同市场环境表现

| 市场类型 | 表现评级 | 原因分析 |

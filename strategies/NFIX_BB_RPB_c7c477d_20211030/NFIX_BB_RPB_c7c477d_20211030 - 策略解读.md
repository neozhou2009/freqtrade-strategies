- 硬止损 -10% 控制单笔最大亏损
- 自定义动态止损根据利润水平调整保护点位

```python
def custom_stoploss(self, pair, trade, current_time, current_rate, current_profit, **kwargs):
    if current_profit > 0.2:
        return 0.05   # 20% 以上利润时，保本止损
    elif current_profit > 0.1:
        return 0.03   # 10% 以上利润时，3% 止损
```

## 四、卖出逻辑详解

### 4.1 多层止盈系统

```
利润率区间    阈值      动作
```

### 4.2 基础卖出信号

- RSI 超买 + 价格触及布林带上轨

## 六、风险管理特色

### 6.1 动态止损保护

策略的 custom_stoploss 函数根据当前利润动态调整止损点位，确保在行情反转时保护利润。

### 6.2 追踪止损机制

- 追踪止损在利润达到 1% 时启动
- 追踪距离为 3%
- 仅在达到偏移点位后生效

### 6.3 交易所止损

支持将止损单下放到交易所层面：
- 止损单间隔 60 秒检查
- 止损价格为最新价格的 99%

## 七、策略优势与局限

### ✅ 优势

1. **多条件确认**：39 个买入条件提供丰富的交易机会筛选

4. **信号频繁**：可能产生过多交易信号

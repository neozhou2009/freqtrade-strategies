## 一、策略概览

STRATEGY_RSI_BB_BOUNDS_CROSS 是一个基于 RSI 与布林带边界动态穿越的量化策略。该策略的核心创新在于将 RSI 的超买超卖水平（70/30）转换为价格坐标，形成动态的"RSI 价格边界"，然后与布林带上下轨进行对比，捕捉价格在两个不同指标体系下的相对位置变化。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 1 个买入信号，基于布林带下轨与 RSI 下边界的穿越关系 |
| **卖出条件** | 1 个基础卖出信号，基于短期 EMA 方向判断 |
| **保护机制** | 无内置保护参数组 |
| **时间框架** | 5m 主时间框架 |
| **依赖库** | talib, qtpylib, numpy, pandas |
| **作者** | Fractate_Dev |

## 三、买入条件详解

### 3.1 核心创新：RSI 价格边界计算

本策略的核心创新在于将 RSI 的超买超卖水平转换为实际价格坐标：

```python
# RSI 上边界（超买水平70对应的价格）
ep = 2 * length - 1  # EMA 平滑周期
x1 = (length - 1) * (adc * 70 / (100-70) - auc)
rsi_ub = close + x1 (当x1 >= 0) 或 close + x1 * (100-70)/70 (当x1 < 0)

# RSI 下边界（超卖水平30对应的价格）
x2 = (length - 1) * (adc * 30 / (100-30) - auc)
rsi_lb = close + x2 (当x2 >= 0) 或 close + x2 * (100-30)/30 (当x2 < 0)
```

**原理说明**：
- `auc`：上涨势能（价格上涨幅度的EMA）
- `adc`：下跌势能（价格下跌幅度的EMA）
- 通过势能比例转换，将 RSI 的 70/30 水平映射到实际价格

### 3.2 买入条件：布林带下轨穿越 RSI 下边界

```python
dataframe.loc[
    (
        # 趋势确认：连续14根K线布林带下轨低于RSI下边界
        (dataframe['lb_bb_under_rsi_trend']) &

        # 布林带下轨持续低于RSI下边界
        (dataframe['bb_lb'] < dataframe['rsi_lb']) &
        (dataframe['bb_lb'].shift(1) < dataframe['rsi_lb'].shift(1)) &

        # EMA2上升（短期动量向上）
        (dataframe['ema2'] > dataframe['ema2'].shift(1))
    ),
    'buy'] = 1
```

**条件分解**：

| 条件 | 说明 | 逻辑目的 |
|------|------|---------|
| `lb_bb_under_rsi_trend` | 连续14根K线布林带下轨低于RSI下边界 | 趋势持续性确认 |
| `bb_lb < rsi_lb` | 当前布林带下轨低于RSI下边界 | 价格处于相对低位 |
| `bb_lb.shift(1) < rsi_lb.shift(1)` | 前一根K线布林带下轨也低于RSI下边界 | 稳定性确认 |
| `ema2 > ema2.shift(1)` | 2周期EMA上升 | 短期动量确认 |

### 3.3 趋势确认机制

策略使用 `_trend_length = 14` 作为趋势确认周期：

```python
for i in range(_trend_length):
    dataframe['ub_bb_over_rsi_trend'] = dataframe['ub_bb_over_rsi'].shift(i) & dataframe['ub_bb_over_rsi_trend']
    dataframe['lb_bb_under_rsi_trend'] = dataframe['lb_bb_under_rsi'].shift(i) & dataframe['lb_bb_under_rsi_trend']
```

## 四、卖出逻辑详解

### 4.1 卖出信号：EMA2 下行

```python
dataframe.loc[
    (
        # EMA2下降（短期动量向下）
        (dataframe['ema2'] < dataframe['ema2'].shift(1))
```

**设计思路**：

## 六、风险管理特色

### 6.1 双重边界确认机制

策略使用两个独立的边界系统进行交叉验证：
- **布林带边界**：基于价格波动率的统计边界
- **RSI 价格边界**：基于动量势能的动态边界

当两者形成一致信号时，才触发买入，降低假信号风险。

### 6.2 趋势持续性过滤

14 周期的趋势确认确保：
- 不是单根 K 线的噪音信号
- 价格确实处于持续的相对低位
- 避免在震荡中频繁交易

### 6.3 短周期动量确认

2 周期 EMA 作为入场确认：
- 等待短期动量转向
- 避免在下跌途中过早入场

## 七、策略优势与局限

### ✅ 优势

1. **创新的双边界体系**：将 RSI 水平映射到价格坐标，形成独特的支撑/阻力判断
2. **趋势持续性过滤**：14 周期趋势确认有效减少假信号
3. **简洁的退出机制**：卖出不拖泥带水，快速响应动量变化
4. **平滑处理减少噪音**：对关键指标进行平滑，提高信号质量

### ⚠️ 局限

1. **卖出信号过于简单**：仅依赖 EMA2 方向变化，可能在剧烈波动时反应过度
2. **无追踪止损**：错过锁定浮盈的机会
3. **买入条件相对严格**：需要多个条件同时满足，可能错过部分机会
4. **参数硬编码**：关键参数如 `_trend_length=14` 硬编码，缺乏优化灵活性

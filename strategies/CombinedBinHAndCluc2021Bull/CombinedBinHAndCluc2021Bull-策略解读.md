## 一、策略概览

**CombinedBinHAndCluc2021Bull** 是一个组合策略，融合了 BinHV45、ClucMay72018 和 BBRSI 三个经典策略的买入逻辑，专为牛市环境设计。策略核心是在价格深度跌破布林带时买入，在价格回归布林带中轨时卖出。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 3 种策略组合（BinHV45 + ClucMay72018 + BBRSI） |
| **卖出条件** | 1 个条件：价格 > 布林带中轨 |
| **保护机制** | 无独立保护参数，依赖硬止损 |
| **时间框架** | 5 分钟 |
| **依赖库** | TA-Lib, technical |
| **特殊功能** | 多策略逻辑组合 |

## 三、买入条件详解

### 3.1 买入逻辑（策略 1：BinHV45）

```python
# BinHV45 策略买入条件
(
    lower.shift().gt(0) &                          # 前一根布林带下轨 > 0
    bbdelta.gt(close * 0.008) &                    # 布林带带宽 > 0.8%
    closedelta.gt(close * 0.0175) &                # 价格变化 > 1.75%
    tail.lt(bbdelta * 0.25) &                      # 下影线 < 带宽的 25%
    close.lt(lower.shift()) &                      # 当前价 < 前一根下轨
    close.le(close.shift())                        # 当前价 <= 前一根收盘价
)
```

**逻辑解析**：
- **布林带下轨有效**：前一根下轨大于 0
- **带宽足够**：布林带带宽超过 0.8%
- **价格变化显著**：价格变化超过 1.75%
- **下影线短**：下影线小于带宽的 25%
- **价格跌破**：当前价低于前一根下轨
- **价格下降**：当前价不高于前一根收盘价

**综合含义**：价格深度跌破布林带，且带宽足够，可能反弹。

### 3.2 买入逻辑（策略 2：ClucMay72018）

```python
# ClucMay72018 策略买入条件
(
    close < ema100 &                               # 价格 < EMA100
    close < 0.985 * bb_lowerband &                 # 价格 < 布林带下轨×0.985
    volume < volume_mean_slow.shift(1) * 20        # 成交量 < 均量×20
)
```

**逻辑解析**：
- **价格 < EMA100**：价格在 100 周期 EMA 之下
- **深度跌破布林带**：价格低于布林带下轨 1.5%
- **成交量过滤**：排除异常高成交量

**综合含义**：价格深度跌破布林带且低于 EMA100，成交量正常。

### 3.3 买入逻辑（策略 3：BBRSI）

```python
# BBRSI 策略买入条件
(
    rsi < 12 &                                   # RSI < 12（深度超卖）
    close < bb_lowerband4                        # 价格 < 4 倍标准差布林带下轨
)
```

**逻辑解析**：
- **RSI 深度超卖**：RSI < 12（远低于常规 30）
- **4 倍标准差**：价格跌破 4 倍标准差布林带下轨

**综合含义**：极端超卖 + 极端价格突破，反弹概率极高。

### 3.4 组合逻辑

```python
# 三种策略任一满足即买入
(BinHV45 条件) | (ClucMay72018 条件) | (BBRSI 条件)
```

**说明**：三种策略逻辑用"或"连接，任一满足即触发买入。

## 七、策略优势与局限

### ✅ 优势

1. **多策略组合**：3 种经典策略逻辑，覆盖不同场景
2. **极端超卖捕捉**：BBRSI 条件捕捉极端超卖机会
3. **快速周转**：1% ROI + 中轨退出，资金利用率高
4. **牛市专用**：专为牛市设计，反弹概率高
5. **计算量小**：指标少，对硬件要求低

### ⚠️ 局限

1. **无趋势过滤**：没有长期趋势判断
2. **无 BTC 关联**：不检测比特币大盘趋势
3. **熊市风险**：在熊市中可能连续亏损
4. **低 ROI**：1% ROI 可能过早退出大趋势
5. **多布林带计算**：三套布林带增加计算量

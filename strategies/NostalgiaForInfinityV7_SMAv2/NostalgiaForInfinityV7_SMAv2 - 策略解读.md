# NostalgiaForInfinityV7_SMAv2 策略解读

## 第一章 策略概述

### 1.1 策略背景

NostalgiaForInfinityV7_SMAv2 是由 iterativ 团队开发的加密货币量化交易策略，专为 Freqtrade 交易平台设计。该策略是 NostalgiaForInfinity 系列的第七代版本，采用 SMA（简单移动平均）作为核心趋势判断指标，结合多重保护机制，旨在捕捉市场中的趋势性机会，同时有效控制回撤风险。

### 1.2 策略定位

该策略属于**趋势跟踪型策略**，主要特点包括：

- **多时间框架分析**：结合5分钟和1小时两个时间框架，短期信号与中期趋势相互印证
- **多重入场条件**：设计26个独立的买入条件组，分散风险，提高适应性
- **动态风险管理**：分层止盈、追踪止损、动态止损等多种退出机制
- **智能保护系统**：内置暴涨保护和深度下跌保护，避免追涨杀跌

### 1.3 核心参数配置

| 参数类别 | 具体设置 |
|---------|---------|
| 主时间框架 | 5分钟（5m） |
| 辅助时间框架 | 1小时（1h） |
| 固定止损 | -10% |
| 追踪止损 | 启用，正向偏移3%，追踪幅度0.5% |
| ROI目标 | 0分钟→10%，30分钟→5%，60分钟→2% |
| 启动K线数 | 400根 |

### 1.4 推荐运行环境

策略开发者建议的运行配置：

- 同时持有4-6个交易对
- 交易对数量：40-80对（成交量排序）
- 使用稳定币交易对（USDT、BUSD等）
- 禁用杠杆代币（*BULL、*BEAR等）
- 确保 config.json 不覆盖时间框架设置

## 第二章 技术指标体系

### 2.1 移动平均线系统

策略采用完整的移动平均线体系，包括指数移动平均（EMA）和简单移动平均（SMA）：

**EMA系列**：
- 短期：EMA12、EMA15、EMA20、EMA26、EMA35
- 中期：EMA50、EMA100
- 长期：EMA200

**SMA系列**：
- SMA5：超短期动量判断
- SMA30：短期趋势参考
- SMA200：长期趋势确认

这些均线在不同买入条件中扮演不同角色，如趋势方向确认、价格偏离度判断、支撑阻力识别等。

### 2.2 震荡指标

**RSI（相对强弱指数）**：
- RSI4：快速RSI，用于捕捉短期超卖
- RSI14：标准RSI，用于常规超买超卖判断
- RSI20：慢速RSI，用于趋势方向判断

RSI在策略中的主要应用：
1. 超卖信号：RSI低于特定阈值时考虑买入
2. 超买信号：RSI高于特定阈值时考虑卖出
3. 背离判断：RSI与价格走势的背离分析

**MFI（资金流量指标）**：
用于判断资金流入流出情况，配合RSI使用，增强买卖信号的可靠性。

### 2.3 布林带系统

策略使用两组布林带：

**BB20（20周期，2倍标准差）**：
- 用于判断价格相对于近期波动的位置
- 下轨突破：潜在的买入机会
- 上轨突破：潜在的卖出信号

**BB40（40周期，2倍标准差）**：
- 提供更稳定的价格通道
- 用于特定买入条件的触发

### 2.4 特殊指标

**EWO（艾略特波振荡器）**：
```
EWO = (EMA5 - EMA35) / Close × 100
```
用于识别市场周期和趋势强度，正值表示上升趋势，负值表示下降趋势。

**CMF（蔡金资金流量）**：
```
CMF = Sum(MFV, n) / Sum(Volume, n)
```
其中 MFV = ((Close - Low) - (High - Close)) / (High - Low) × Volume

用于判断买卖压力的累积情况。

**Choppiness Index（斩波指数）**：
衡量市场的趋势性或震荡性，数值越高表示市场越震荡。

**ZEMA（零滞后EMA）**：
减少传统EMA的滞后性，提供更及时的趋势信号。

## 第三章 保护机制详解

### 3.1 Safe Dips（安全下跌）机制

Safe Dips 是一套防止在过度下跌中买入的保护系统。该机制通过计算不同时间窗口的价格变化百分比，判断当前价格是否处于"安全"的下跌位置。

**计算逻辑**：
```python
def safe_dips(dataframe, thresh_0, thresh_2, thresh_12, thresh_144):
    return ((tpct_change_0 < thresh_0) &
            (tpct_change_2 < thresh_2) &
            (tpct_change_12 < thresh_12) &
            (tpct_change_144 < thresh_144))
```

**阈值等级**：
策略预设了11个安全等级（10-110），每个等级对应不同的阈值组合：
- 等级10（严格）：阈值较紧，只在轻微下跌时买入
- 等级50（正常）：中等严格度
- 等级100（宽松）：阈值较松，允许在更深的下跌中买入

**实际意义**：
- 防止在暴跌中"接飞刀"
- 确保只在价格相对稳定时入场
- 根据市场状况选择不同的安全等级

### 3.2 Safe Pump（安全暴涨）机制

Safe Pump 是防止在暴涨后追高的保护系统。通过分析一段时间内的价格涨幅，判断当前是否处于安全的入场时机。

**计算逻辑**：
```python
def safe_pump(dataframe, length, thresh, pull_thresh):
    return (oc_pct_change < thresh) | 
           (range_maxgap_adjusted > range_height)
```

**时间窗口**：
- 24小时：短期暴涨检测
- 36小时：中期暴涨检测
- 48小时：较长期暴涨检测

**阈值等级**：
同样设置11个等级（10-120），配合不同时间窗口使用。

**核心思想**：
1. 如果涨幅超过阈值，说明可能已经暴涨，需要等待回调
2. 或者，如果价格已经从高点回调足够多，则认为安全

### 3.3 SMA200趋势确认

策略高度依赖SMA200作为长期趋势判断标准：

**SMA200上升确认**：
```python
sma_200 > sma_200.shift(n)
```
其中n可以是20、24、28、30、36、44、50等值，表示SMA200相对于n个周期前的位置。

**应用场景**：
- 买入条件中的保护性检查
- 卖出条件中的趋势判断
- custom_sell中的止损决策

### 3.4 EMA趋势交叉

使用不同周期的EMA交叉作为趋势确认：

**常见组合**：
- EMA20 > EMA200：短期均线在长期均线之上，表示上升趋势
- EMA50 > EMA100：中短期趋势确认
- EMA12与EMA26的金叉死叉：短期动量判断

## 第四章 买入条件详解

### 4.1 买入条件架构

策略设计了26个独立的买入条件（实际使用buy_01到buy_26，其中buy_25未定义），每个条件都遵循"保护机制 + 核心逻辑"的架构：

```python
buy_trigger = protections & logic & volume_check
```

### 4.2 条件1：基础趋势买入

**核心逻辑**：
- RSI慢速下降且RSI快速 < 35
- 1小时上升趋势
- 收盘价低于MA下轨
- 开盘价高于MA下轨

**保护机制**：
- EMA26 > EMA200（默认启用）
- SMA200上升确认（28周期，默认启用）
- Safe Dips等级80（默认启用）
- Safe Pump等级70，24小时窗口（默认启用）

### 4.3 条件2：布林带下轨买入

**核心逻辑**：
- RSI < RSI_1h - 39（RSI与1小时RSI的差异）
- MFI < 49
- 收盘价 < BB20下轨 × 0.983

**保护机制**：
- EMA20_1h > EMA200_1h
- Safe Dips等级50
- 不启用Safe Pump

### 4.4 条件3：BB40突破买入

**核心逻辑**：
- BB40下轨存在
- BB40宽度 > 收盘价 × 0.059
- 收盘价变化 > 收盘价 × 0.023
- 影线 < BB40宽度 × 0.418
- 收盘价 < BB40下轨（前一根）
- 收盘价 ≤ 前一根收盘价

**保护机制**：
- EMA100 > EMA200
- EMA100_1h > EMA200_1h
- 收盘价 > EMA200_1h × 0.986

### 4.5 条件4：低成交量布林带买入

## 第五章 卖出条件详解

- RSI > 82

**触发条件**：
- RSI > 73.4

**触发条件**：
- 收盘价 < EMA200

**触发条件**：
- RSI_1h > 81.7

## 第六章 Custom_sell动态止盈止损系统

### 6.1 系统概述

Custom_sell是策略的核心退出机制，它根据当前盈利状态和RSI指标，动态决定是否退出交易。这个系统比简单的ROI和止损更加智能，能够根据市场状况灵活调整退出策略。

### 6.2 标准分层止盈

策略设计了12层止盈阶梯（signal_profit_0 到 signal_profit_11）：

| 层级 | 盈利要求 | RSI要求 |
|-----|---------|--------|
| 0 | > 1% | < 34 |
| 1 | 1-2% | < 35 |
| 2 | 2-3% | < 37 |
| 3 | 3-4% | < 42 |
| 4 | 4-5% | < 43 |
| 5 | 5-6% | < 45 |
| 6 | 6-7% | < 48 |
| 7 | 7-8% | < 54 |
| 8 | 8-9% | < 55 |
| 9 | 9-10% | < 54 |
| 10 | 10-12% | < 42 |
| 11 | > 20% | < 34 |

**核心思想**：
- 盈利越高，对RSI的要求越宽松
- 高盈利时，即使RSI较高也会止盈
- 低盈利时，需要RSI较低才能止盈

### 6.3 EMA200下方止盈

当价格在EMA200下方时，有另一套止盈标准（signal_profit_u_0 到 signal_profit_u_11）：

| 层级 | 盈利要求 | RSI要求 | 额外条件 |
|-----|---------|--------|---------|
| 0 | > 1% | < 35 | 收盘价 < EMA200 |
| 1 | 1-2% | < 56 | 收盘价 < EMA200 |
| ... | ... | ... | ... |
| 11 | > 20% | < 34 | 收盘价 < EMA200 |

### 6.4 暴涨后止盈

策略定义了三种"暴涨"状态：

**48小时暴涨检测**：
- 高低点涨幅 > 90%（等级1）
- 高低点涨幅 > 70%（等级2）
- 高低点涨幅 > 50%（等级3）

**36小时暴涨检测**：
- 高低点涨幅 > 72%（等级1）
- 高低点涨幅 > 400%（等级2）
- 高低点涨幅 > 100%（等级3）

**24小时暴涨检测**：
- 高低点涨幅 > 68%（等级1）
- 高低点涨幅 > 62%（等级2）
- 高低点涨幅 > 88%（等级3）

暴涨后的止盈逻辑与标准止盈类似，但阈值不同，允许在更高盈利时才止盈。

### 6.5 追踪止盈

策略设计了三套追踪止盈机制：

**追踪止盈1**：
- 盈利范围：16%-60%
- RSI范围：20-50
- 触发条件：最大盈利 > 当前盈利 + 3%

**追踪止盈2**：
- 盈利范围：10%-40%
- RSI范围：20-50
- 触发条件：最大盈利 > 当前盈利 + 3%

**追踪止盈3**：
- 盈利范围：6%-20%
- 触发条件：最大盈利 > 当前盈利 + 5%
- 额外条件：SMA200_1h下降

### 6.6 动态止损

**EMA200附近止损**：
- 当前盈利 > 0但 < 2.4%
- 收盘价 < EMA200
- EMA200偏离度 < 2.4%
- RSI > RSI_1h + 4.4

**长时间持仓止损**：
- 持仓超过1200分钟（20小时）
- 当前盈利在-8%到-4%之间
- 当前盈利 > -最大亏损 + 10%
- 收盘价 < EMA200
- RSI > RSI_1h + 4
- SMA200下降

### 6.7 恢复性止损

当交易从深度亏损中恢复时：

**恢复止盈1**：
- 最大亏损 > 12%
- 当前盈利 > 4%

**恢复止盈2**：
- 最大亏损 > 6%
- 当前盈利在1%-5%之间
- RSI < 46

### 6.8 长时间持仓止盈

对于持仓时间较长的交易：

- 持仓超过900分钟（15小时）
- 当前盈利在3%-4%之间

## 第九章 风险管理体系

### 9.1 多层次止损

策略构建了四层止损保护：

1. **固定止损**：-10%，防止极端亏损
2. **追踪止损**：盈利3%后启用，追踪幅度0.5%
3. **动态止损**：根据持仓时间、价格位置、RSI动态调整
4. **恢复止损**：从亏损中恢复后及时止盈

### 9.2 入场风险控制

**Safe Dips控制**：
- 防止在暴跌中入场
- 11个等级适应不同风险偏好

**Safe Pump控制**：
- 防止在暴涨后追高
- 3个时间窗口（24h/36h/48h）检测

**趋势确认**：
- SMA200方向确认
- EMA交叉确认
- 多周期验证

### 9.3 出场风险控制

**分层止盈**：
- 12层止盈阶梯
- 根据盈利和RSI动态调整

**追踪止盈**：
- 保护已有盈利
- 给趋势更多发展空间

**暴涨后特殊处理**：
- 检测暴涨状态
- 调整止盈策略

## 第十一章 总结与展望

### 11.1 策略优势

1. **全面的技术分析**：涵盖趋势、动量、波动率、成交量等多个维度
2. **灵活的入场机制**：26个买入条件适应不同市场状态
3. **智能的风险管理**：多层次止损止盈，动态调整
4. **完善的数据验证**：多时间框架协同，降低假信号

1. **参数众多**：调优难度大，容易过拟合
2. **计算复杂**：需要400根K线启动，资源消耗较大
3. **市场依赖**：在趋势市场中表现较好，震荡市场可能频繁止损

### 11.3 改进方向

1. **简化参数**：减少可调参数，提高稳定性
2. **市场识别**：增加市场状态识别，在不同状态下切换策略
3. **机器学习**：引入机器学习方法优化入场时机
4. **风险管理**：增加仓位管理和资金管理模块

### 11.4 使用建议

1. **充分回测**：在不同市场环境下进行充分回测
2. **纸盘测试**：实盘前进行模拟交易
3. **监控调整**：定期监控策略表现，适时调整参数
4. **风险控制**：合理设置总仓位和单笔仓位限制

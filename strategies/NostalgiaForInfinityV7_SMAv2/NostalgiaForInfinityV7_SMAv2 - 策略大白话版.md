# NostalgiaForInfinityV7_SMAv2 策略大白话版

## 第一章 这策略是干啥的？

### 1.1 一句话介绍

这是一个帮你自动炒币的策略，它会盯着市场，在合适的时候买入，在赚了钱或亏太多的时候卖出，全程不用你操心。

### 1.2 策略的名字啥意思？

- **NostalgiaForInfinity**：翻译过来是"对无限的怀念"，听着很文艺，其实是开发者的情怀命名
- **V7**：第七代版本，说明前面还有六个版本，这个是进化到现在的成熟版本
- **SMAv2**：用简单移动平均线做核心判断，这是第二版改进

### 1.3 这策略适合谁？

适合以下人群：
- 有一定交易基础，知道什么是EMA、RSI这些指标
- 用Freqtrade平台做量化交易
- 想要一个经过长期验证、参数可调的策略
- 能接受一定的回撤，追求长期稳定收益

### 1.4 能赚多少钱？

这问题没法直接回答。但策略的设置告诉你：
- 单笔最多亏10%（固定止损）
- 赚钱后会追踪止盈，锁定利润
- 有分层止盈机制，不同盈利有不同处理方式

## 第二章 策略怎么盯盘？

### 2.1 双眼看盘

策略同时盯着两个时间窗口：

**5分钟图（主战场）**：
- 这是做交易决策的主要依据
- 所有买卖信号都在这里产生
- 适合捕捉短期波动

**1小时图（大方向）**：
- 用来判断大趋势
- 确认5分钟信号是否可靠
- 避免逆势交易

### 2.2 需要多少历史数据？

策略启动需要400根5分钟K线，大约33小时的数据。这是因为很多指标（比如SMA200）需要足够的历史数据才能计算准确。

### 2.3 盯多少个币？

建议设置：
- 同时持有4-6个交易对
- 交易池40-80个币
- 用成交量排序选币
- 用稳定币（USDT）交易对
- 别碰杠杆币（什么BULL、BEAR的）

## 第三章 用了哪些技术指标？

### 3.1 均线家族

策略用了一大堆均线，就像一个大家庭：

**EMA（指数移动平均线）**：
- EMA12、EMA15：超短期，像小孙子跑得快
- EMA20、EMA26：短期，像年轻小伙子
- EMA50、EMA100：中期，像中年人稳重
- EMA200：长期，像老爷爷，最重要！

**SMA（简单移动平均线）**：
- SMA5、SMA30：看短期波动
- SMA200：判断大趋势的核心

### 3.2 震荡指标

**RSI（相对强弱指数）**：
- 0-100之间晃荡
- 低于30：超卖了，可能该买
- 高于70：超买了，可能该卖
- 策略用了RSI4（快）、RSI14（中）、RSI20（慢）

**MFI（资金流量指标）**：
- 结合价格和成交量
- 告诉你资金是流入还是流出
- 配合RSI使用更准确

### 3.3 布林带

想象布林带是一个橡皮筋：
- 中间是平均价
- 上下轨是橡皮筋的边界
- 价格碰到下轨：可能太便宜了
- 价格碰到上轨：可能太贵了

策略用了两组布林带：
- BB20：20周期的，反应快
- BB40：40周期的，更稳定

### 3.4 其他指标

**EWO（艾略特波振荡器）**：
- 判断市场是上涨波还是下跌波
- 正值说明上涨动能强
- 负值说明下跌压力大

**CMF（蔡金资金流量）**：
- 大于0：资金在流入，好事
- 小于0：资金在流出，坏事

**斩波指数**：
- 告诉你市场是在趋势还是在震荡
- 数值高：市场震荡，别追
- 数值低：有趋势，可以跟

## 第四章 保护机制：别被坑！

### 4.1 Safe Dips：别接飞刀

想象你在股市看到一支股票从100跌到80，你觉得便宜了就买，结果它又跌到60、40...

Safe Dips就是防止这种"接飞刀"的情况：

**它检查四个时间窗口的跌幅**：
- 当根K线的跌幅
- 过去2根K线的跌幅
- 过去12根K线的跌幅
- 过去144根K线的跌幅

如果任何一项跌幅太大，就别买，等一等再说。

**11个安全等级**：
- 等级10：非常严格，只在小跌时买
- 等级50：中等严格
- 等级100：比较宽松，允许大跌时买

### 4.2 Safe Pump：别追高

暴涨之后往往有暴跌，Safe Pump就是防止你在暴涨后追高：

**检测三种时间窗口**：
- 24小时涨幅
- 36小时涨幅
- 48小时涨幅

**两种判断逻辑**：
1. 涨幅太大了吗？如果太大，别买
2. 从高点回调够多了吗？如果回调够了，可以买

### 4.3 SMA200趋势确认

SMA200是策略的"定海神针"：

**上升趋势**：
- SMA200在往上走
- 说明大趋势是好的
- 可以考虑买入

**下降趋势**：
- SMA200在往下走
- 说明大趋势不好
- 要小心，可能空仓观望

## 第五章 什么时候买？

### 5.1 策略有26种买法

没错，这个策略设计了26种不同的买入条件！每种条件适合不同的市场情况。

### 5.2 买入的基本框架

每个买入条件都像一道菜，有两个部分：

**保护机制（别被坑）**：
- 检查Safe Dips
- 检查Safe Pump
- 确认SMA200方向
- 确认EMA位置关系

**核心逻辑（找到机会）**：
- RSI够低吗？
- 价格够便宜吗？
- 有反转信号吗？

### 5.3 几种典型的买入情况

**情况1：趋势回调买入**
- 大趋势向上（EMA26 > EMA200）
- RSI掉下来了（RSI < 36）
- MFI也低（资金流出差不多了）
- 价格低于布林带下轨
→ 这是捡便宜的好机会

**情况2：超跌反弹买入**
- RSI超级低（RSI < 29）
- 成交量突然放大
- 出现阳线（收盘价 > 开盘价）
- 长下影线（有人托底）
→ 这是抄底信号

**情况3：均线回踩买入**
- 前一根K线在EMA100上方
- 这根K线最低价刺穿EMA100
- 收盘价又站回EMA100上方
- RSI还行（> 50）
→ 这是典型的"假跌破"，后市看涨

**情况4：趋势转换买入**
- 12根K线前还是熊市（EMA12 < EMA35）
- 现在变成牛市（EMA12 > EMA35）
- CMF从负转正（资金开始流入）
→ 这是从熊到牛的转折点

### 5.4 买入时的成交量检查

所有买入条件最后都会检查：
```
成交量 > 0
```
这是最基本的验证，确保市场有流动性。

## 第六章 什么时候卖？

### 6.1 八种卖出信号

策略设计了8种卖出条件，简单来说就是：

**卖出条件1**：连续6根K线都在布林带上轨之上，RSI > 79.5
→ 涨太多了，该休息了

**卖出条件2**：连续3根K线都在布林带上轨之上，RSI > 81
→ 短期过热

**卖出条件3**：RSI > 82
→ 简单粗暴，RSI太高就卖

**卖出条件4**：RSI > 73.4 且 RSI_1h > 79.6
→ 5分钟和1小时都超买

**卖出条件6**：价格在EMA200下方，但在EMA50上方，RSI > 79
→ 弱势反弹结束

**卖出条件7**：RSI_1h > 81.7，EMA12死叉EMA26
→ 趋势转向

**卖出条件8**：价格突破1小时布林带上轨10%
→ 极端上涨

### 6.2 为什么没有卖出条件5？

源码里确实没有定义sell_condition_5，可能是开发者的笔误或历史遗留问题。

## 第七章 分层止盈：赚钱怎么卖？

### 7.1 为什么要分层止盈？

赚了钱不卖，可能转眼就亏回去；卖早了，可能错过大行情。分层止盈就是解决这个问题的。

### 7.2 十二层止盈阶梯

想象你爬楼梯，每上一层，风景就不一样：

| 楼层 | 盈利 | RSI要求 | 通俗解释 |
|-----|-----|--------|---------|
| 1楼 | 1% | < 34 | 刚赚钱，RSI很低就止盈 |
| 2楼 | 2% | < 35 | 多赚点，RSI要求差不多 |
| 3楼 | 3% | < 37 | 继续赚，RSI要求提高 |
| 4楼 | 4% | < 42 | 赚更多，RSI可以更高 |
| 5楼 | 5% | < 43 | ... |
| 6楼 | 6% | < 48 | ... |
| 7楼 | 7% | < 54 | ... |
| 8楼 | 8% | < 55 | ... |
| 9楼 | 9% | < 54 | ... |
| 10楼 | 10-12% | < 42 | 赚很多，RSI回到低水平 |
| 11楼 | > 20% | < 34 | 大赚，RSI要很低 |

**核心逻辑**：
- 盈利越多，对RSI的要求越灵活
- 高盈利时，即使RSI不低也可以止盈
- 毕竟赚钱落袋为安最重要

### 7.3 EMA200下方的止盈

如果你买的币价格在EMA200下方（属于弱势），止盈门槛更低，见好就收。

### 7.4 暴涨后的止盈

如果这个币之前涨得很凶（暴涨），止盈策略会调整：
- 允许持有到更高盈利
- 因为暴涨的币波动大，需要更大空间

## 第八章 追踪止盈：让利润飞

### 8.1 什么是追踪止盈？

想象你在钓鱼，鱼已经上钩了，但你想等它游得更近再收杆。追踪止盈就是让利润继续跑，但同时设定一个"安全绳"。

### 8.2 三套追踪机制

**追踪机制1**（高盈利）：
- 盈利在16%-60%之间
- RSI在20-50之间
- 从最高盈利回撤3%就卖

**追踪机制2**（中等盈利）：
- 盈利在10%-40%之间
- RSI在20-50之间
- 从最高盈利回撤3%就卖

**追踪机制3**（低盈利）：
- 盈利在6%-20%之间
- 从最高盈利回撤5%就卖
- 要求SMA200_1h在下降（趋势不好）

### 8.3 举例说明

假设你买入后，价格一直涨，最高涨了20%：
- 如果后来跌到17%（回撤3%），触发追踪止盈
- 最终以17%的利润卖出
- 比固定止盈更灵活

## 第九章 止损机制：小亏保大钱

### 9.1 固定止损：最后的底线

策略设置了-10%的固定止损。不管什么情况，亏10%就强制卖出，防止越陷越深。

### 9.2 动态止损：灵活应对

**EMA200附近止损**：
- 价格在EMA200下方
- 有一定盈利但开始转亏
- RI比RSI_1h高很多
→ 说明趋势不好，赶紧撤退

**长时间持仓止损**：
- 持仓超过20小时
- 亏损在4%-8%之间
- 但比之前最惨的时候好
- RSI有回升迹象
→ 及时止损，别死扛

### 9.3 恢复性止损：死里逃生

如果你买的币曾经亏很多，后来又涨回来：

**情况1**：
- 最大亏损超过12%
- 现在盈利4%了
→ 赶紧卖，别再贪了

**情况2**：
- 最大亏损超过6%
- 现在盈利1%-5%
- RSI < 46
→ 也该走了

## 第十章 特殊情况处理

### 10.1 暴涨后的特殊止盈

如果一个币在48小时内涨了90%以上，那它就是"暴涨币"。

暴涨币的止盈策略：
- 阈值更高
- 允许更大波动
- 因为暴涨币通常还有继续涨的可能

### 10.2 SMA下降时的止盈

当SMA200在下降时（大趋势不好）：
- 更积极止盈
- 不贪心，有利润就跑

### 10.3 长时间持仓的处理

如果你买了一个币，持仓超过15小时：
- 盈利3%-4%就可以止盈
- 别等太久，夜长梦多

## 第十一章 风险怎么控？

### 11.1 入场前的保护

1. **Safe Dips检查**：别在暴跌中接飞刀
2. **Safe Pump检查**：别在暴涨后追高
3. **趋势确认**：跟着大趋势走
4. **成交量检查**：确保有人交易

### 11.2 持仓中的保护

1. **固定止损**：-10%强制退出
2. **追踪止损**：盈利后锁定利润
3. **动态止损**：根据情况调整
4. **分层止盈**：灵活获利

### 11.3 实用建议

**资金管理**：
- 别把全部钱放进去
- 每笔交易占总资金的5%-10%
- 预留应急资金

**心态管理**：
- 策略是机器，会亏钱也正常
- 别频繁手动干预
- 相信长期复利

**监控调整**：
- 定期查看策略表现
- 发现问题及时调整参数
- 保持学习和改进

## 第十二章 参数能不能改？

### 12.1 哪些参数可以改？

这个策略几乎所有参数都可以改：

**保护机制参数**：
- EMA长度
- SMA200确认周期
- Safe Dips等级
- Safe Pump等级

**买卖逻辑参数**：
- RSI阈值
- MFI阈值
- 布林带偏离度
- 各种乘数

### 12.2 怎么改参数？

在Freqtrade的优化模式下：
1. 把optimize参数设为True
2. 设置参数范围
3. 运行超参数优化
4. 用回测验证

### 12.3 改参数的注意事项

**别过度优化**：
- 参数太完美可能是过拟合
- 在历史数据上表现好，未来不一定

**多时间段测试**：
- 牛市测
- 熊市测
- 震荡市测
- 都表现不错才是好参数

**小步迭代**：
- 一次只改几个参数
- 看清楚效果再改下一个
- 别大刀阔斧全改

**Q：为什么有时候不交易？**

## 一、策略概览

ADXMomentum 是一个基于 ADX（平均趋向指数）和动量指标的经典趋势跟踪策略。该策略源自 C# 实现，由 Gert Wohlgemuth 移植到 Freqtrade 框架。策略设计简洁但逻辑严密，通过多维度指标验证来确认趋势的有效性，避免在震荡市场中频繁交易。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 4 个必须同时满足的条件（趋势强度+动量+方向） |
| **卖出条件** | 4 个条件（趋势反转信号） |
| **保护机制** | 固定止损 -25%，固定 ROI 目标 1% |
| **时间框架** | 1 小时 (1h) |
| **依赖库** | talib (ADX, PLUS_DI, MINUS_DI, SAR, MOM) |
| **启动蜡烛** | 20 根 |

# ROI 退出表

## 三、买入条件详解

### 3.1 核心指标组合

策略使用 5 个技术指标构建买入信号：

| 指标 | 参数 | 用途 |
|------|------|------|
| ADX | 14 周期 | 衡量趋势强度 |
| PLUS_DI | 25 周期 | 多头方向强度 |
| MINUS_DI | 25 周期 | 空头方向强度 |
| SAR | 默认 | 趋势方向确认 |
| MOM | 14 周期 | 动量确认 |

### 3.2 买入条件详解

#### 完整买入逻辑

```python
def populate_entry_trend(self, dataframe: DataFrame, metadata: dict) -> DataFrame:
    dataframe.loc[
        (
            (dataframe['adx'] > 25) &           # 条件1: 趋势强度足够
            (dataframe['mom'] > 0) &             # 条件2: 正向动量
            (dataframe['plus_di'] > 25) &        # 条件3: 多头力量强
            (dataframe['plus_di'] > dataframe['minus_di'])  # 条件4: 多头占优
        ),
        'buy'] = 1
    return dataframe
```

#### 条件解析

| 条件编号 | 条件内容 | 技术含义 |
|---------|---------|---------|
| 条件 #1 | `adx > 25` | ADX 大于 25 表示市场存在明确趋势（非震荡市） |
| 条件 #2 | `mom > 0` | 动量为正，价格正在上涨 |
| 条件 #3 | `plus_di > 25` | 多头方向指标超过 25，多头力量较强 |
| 条件 #4 | `plus_di > minus_di` | 多头方向指标高于空头方向指标，确认上涨方向 |

### 3.3 买入信号分类

| 信号维度 | 指标 | 判断标准 |
|---------|------|---------|
| **趋势强度** | ADX | > 25（强趋势） |
| **趋势方向** | PLUS_DI vs MINUS_DI | 多头占优 |
| **动能确认** | MOM | 正值（上涨动能） |
| **综合判断** | 四条件同时满足 | 入场 |

## 四、卖出逻辑详解

### 4.1 卖出信号系统

策略采用对称的卖出逻辑，与买入条件形成镜像对照：

```python
def populate_exit_trend(self, dataframe: DataFrame, metadata: dict) -> DataFrame:
    dataframe.loc[
        (
            (dataframe['adx'] > 25) &            # 趋势仍在持续
            (dataframe['mom'] < 0) &              # 动量转负
            (dataframe['minus_di'] > 25) &        # 空头力量增强
            (dataframe['plus_di'] < dataframe['minus_di'])  # 空头占优
        ),
        'sell'] = 1
    return dataframe
```

### 4.2 卖出条件解析

| 条件编号 | 条件内容 | 技术含义 |
|---------|---------|---------|
| 条件 #1 | `adx > 25` | 趋势仍然存在（非震荡） |
| 条件 #2 | `mom < 0` | 动量转负，价格下跌 |
| 条件 #3 | `minus_di > 25` | 空头方向指标超过 25 |
| 条件 #4 | `plus_di < minus_di` | 空头方向指标高于多头，确认下跌趋势 |

### 4.3 退出机制总结

策略有三种退出方式：

| 退出方式 | 触发条件 | 说明 |
|---------|---------|------|
| **ROI 止盈** | 利润 ≥ 1% | 快速锁定收益 |
| **止损** | 亏损 ≥ 25% | 极端情况保护 |
| **信号卖出** | 四条件全部满足 | 趋势反转信号 |

## 五、技术指标体系

### 5.1 核心指标

| 指标类别 | 具体指标 | 用途 |
|---------|---------|------|
| **趋势强度** | ADX (14) | 判断市场是否有明确趋势 |
| **方向指标** | PLUS_DI (25), MINUS_DI (25) | 判断多空方向及强度 |
| **动量指标** | MOM (14) | 确认价格动能方向 |
| **趋势跟踪** | SAR | 辅助趋势判断（计算但未使用） |

### 5.2 指标协同逻辑

策略的核心理念是"多维度确认"：

1. **ADX 确认环境**：确保不是震荡市（ADX > 25）
2. **DI 确认方向**：多头力量强且超过空头（PLUS_DI > MINUS_DI）
3. **MOM 确认动能**：价格上涨动能存在（MOM > 0）
4. **三重验证通过**：才产生买入信号

## 六、风险管理特色

### 6.1 固定比例止损

```python
stoploss = -0.25  # -25% 止损
```

**设计理念**：
- 宽止损给予趋势足够波动空间
- 适合 1 小时级别的中长线趋势跟踪
- 避免因短期震荡被洗出

### 6.2 快速止盈机制

```python
minimal_roi = {"0": 0.01}  # 1% 利润即止盈
```

**设计理念**：
- 快速锁定利润
- 减少回撤风险
- 提高资金周转率

### 6.3 信号过滤器

策略通过 4 个严格条件构建"信号过滤器"：

- 只有在趋势明确（ADX > 25）
- 方向确定（多头占优）
- 动能确认（动量为正）
- 强度足够（PLUS_DI > 25）

时才入场，大幅减少虚假信号。

## 七、策略优势与局限

### ✅ 优势

1. **逻辑简洁清晰**：四个买入条件相互配合，易于理解和调优
2. **趋势跟踪可靠**：ADX + DI 组合是经典的趋势判断方法
3. **双重确认机制**：趋势方向 + 动能方向双重验证
4. **参数可解释性强**：所有参数都有明确的技术含义

### ⚠️ 局限

1. **震荡市表现不佳**：ADX > 25 条件过滤了震荡，但也可能错过震荡中的机会
2. **止损较宽**：-25% 止损对风险厌恶型交易者可能过大
3. **缺少追踪止损**：没有使用 trailing stop，可能错过更大的趋势收益
4. **SAR 指标未使用**：代码中计算了 SAR 但未用于信号判断

## 九、适用市场环境详解

ADXMomentum 属于**趋势跟踪型策略**。基于其代码架构，它最适合**单边趋势明确的市场环境**，而在**震荡市**时表现不佳。

### 9.1 策略核心逻辑

- **趋势优先**：必须 ADX > 25 才入场，确保有趋势可跟
- **方向确认**：PLUS_DI > MINUS_DI 确保多头趋势
- **动能验证**：MOM > 0 确保价格上涨动能
- **对称退出**：信号反转时离场

### 9.2 不同市场环境表现

| 市场类型 | 表现评级 | 原因分析 |
| :--- | :--- | :--- |
| 📈 **强上涨趋势** | ⭐⭐⭐⭐⭐ | ADX 条件满足，趋势跟踪有效 |
| 🔄 **震荡市场** | ⭐☆☆☆☆ | ADX < 25，无法产生信号 |
| 📉 **下跌趋势** | ⭐☆☆☆☆ | 做多策略，无法在下跌中盈利 |
| ⚡️ **剧烈波动** | ⭐⭐☆☆☆ | 可能触发止损，需要更宽空间 |

### 9.3 关键配置建议

| 配置项 | 建议值 | 说明 |
|--------|--------|------|
| **交易对选择** | 趋势性强的币种 | 如 BTC、ETH 等主流币 |
| **时间框架** | 1h（默认）或 4h | 日内交易可用 1h，中长线可用 4h |
| **ADX 阈值** | 20-25 | 市场波动大时可适当降低 |

| 特征 | 描述 |
|------|------|

| **保护机制** | 硬止损 |

## 三、买入条件详解

### 3.1 买入逻辑

```python
# 买入条件
dataframe.loc[
    (
        (dataframe["mfi"] < 24) &                    # MFI < 24（资金流超卖）
        (dataframe["close"] < dataframe["bb_low"]) & # 价格 < 布林带下轨
        (dataframe["cci"] <= -57.0)                  # CCI <= -57
    ),
    "buy",
] = 1
```

**逻辑解析**：
- **MFI < 24**：资金流指标低于 24，确认资金流出超卖
- **价格 < 布林带下轨**：价格跌破布林带下轨，统计意义上的低位
- **CCI <= -57**：商品通道指标低于 -57，确认超卖

**综合含义**：三重超卖确认，反弹概率高。

## 四、卖出逻辑详解

### 4.1 卖出条件

```python
# 卖出条件
dataframe.loc[
    (
        (dataframe["sar"] > dataframe["close"]) &    # SAR > 价格（趋势转弱）
        (dataframe["rsi"] > 75) &                    # RSI > 75（超买）
        (dataframe["close"] > dataframe["bb_upper"]) & # 价格 > 布林带上轨
        (dataframe["cci"] >= 83.0) &                 # CCI >= 83
        (dataframe["mfi"] < 92) &                    # MFI < 92
    ),
    "sell",
] = 1
```

**逻辑解析**：
- **SAR > 价格**：抛物线 SAR 在价格上方，趋势转弱
- **RSI > 75**：RSI 高于 75，处于超买区域
- **价格 > 布林带上轨**：价格突破布林带上轨，统计意义上的高位
- **CCI >= 83**：商品通道指标高于 83，确认超买
- **MFI < 92**：资金流指标低于 92，防止极端超买后暴跌

**综合含义**：多重超买确认，趋势转弱时退出。

## 六、风险管理特色

### 6.1 极宽松硬止损

```python
stoploss = -0.29585  # -29.585%
```

**说明**：极宽松止损，给予极大波动空间，适合捕捉大波动。

### 6.2 多级 ROI 退出

| 持仓时间 | 最小利润率 | 触发退出 |
|---------|-----------|---------|
| 0 分钟 | 14.7% | 达到即退出 |
| 29 分钟 | 6.7% | 29 分钟后达到即退出 |
| 75 分钟 | 2.45% | 75 分钟后达到即退出 |
| 181 分钟 | 0% | 181 分钟后保本退出 |

**设计思路**：
- 短期高收益预期（14.7%）
- 持仓时间越长，预期越低
- 3 小时后保本退出，避免长期套牢

## 七、策略优势与局限

### ✅ 优势

1. **多指标组合**：MFI + CCI + 布林带 + RSI + SAR 多维度确认
2. **超参数优化**：支持 Hyperopt 优化关键参数
3. **高收益预期**：14.7% ROI，适合捕捉大波动
4. **极宽松止损**：-29.585% 止损，避免被洗盘
5. **计算量小**：指标虽多但都是标准指标，计算效率高

### ⚠️ 局限

1. **复杂度高**：多个指标和条件，调试困难
2. **无趋势过滤**：没有 EMA/SMA 长期趋势判断
3. **无 BTC 关联**：不检测比特币大盘趋势
4. **宽松止损风险**：-29.585% 止损在极端行情下可能造成较大亏损
5. **参数敏感**：超参数优化结果可能过拟合

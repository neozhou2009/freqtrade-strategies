## 一、这策略是个啥？

简单说，**Roth01** 就是一个：
- 用 **8 种不同指标** 的策略（MFI、CCI、RSI、SAR、MACD、STOCHF、ADX、布林带）
- **买入 3 重确认，卖出 5 重确认** 的策略
- **14.7% ROI** 的策略（高收益预期）

就像一个买东西前要问遍所有朋友还要查攻略的超级谨慎买家："MFI 说了啥？CCI 咋说？布林带同意吗？都 OK 才买！卖的时候更要 5 个指标都同意！" 🔍

## 二、核心配置：说白了就是"多重确认 + 高收益"

### 止盈规则（ROI 表）

```
刚买入就赚 14.7%？→ 跑！（大赚）
拿了 29 分钟赚 6.7%？→ 跑！（中赚）
拿了 75 分钟赚 2.45%？→ 跑！（小赚）
拿了 181 分钟？→ 保本跑！（3 小时了，不玩了）
```

**翻译**：这策略是典型的"高收益预期"思维，首级 ROI 就 14.7%，比常见策略高多了！

### 止损规则

```
硬止损：亏 29.585% 直接割（超级宽松！）
追踪止损：没有（靠技术信号退出）
```

**翻译**：-29.585% 止损是真的很宽松，给价格充分波动空间，典型的"避免被洗盘"思维😅

## 三、买入条件：要同时满足 3 个条件

这策略的买入条件比前面的策略严格：

### 🎯 MFI + CCI + 布林带三重确认

**核心逻辑**：
1. MFI < 24（资金流超卖）
2. 价格 < 布林带下轨
3. CCI <= -57

**大白话**：
> "MFI 都到 24 以下了（资金流出超卖），价格跌破布林带下轨了，CCI 也到 -57 了——三重确认，这还不买？"

**代码翻译**：
```python
# 买入条件
(MFI < 24) AND (价格 < 布林带下轨) AND (CCI <= -57)
```

**经典台词**：
- "MFI < 24 比常规 RSI < 30 严格多了！"
- "三重确认，假信号能不少吗？"

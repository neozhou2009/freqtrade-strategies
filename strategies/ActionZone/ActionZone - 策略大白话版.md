# ActionZone 策略：看均线+动态止损的"日线选手"

> **外号**：日线选手、动态止损大师  
> **职业**：每天只看一次盘的佛系交易员  
> **时间框架**：1 天（日线级别）

---

## 一、这策略是个啥？

简单说，**ActionZone** 就是一个：
- 在 **1 天 K 线**上玩的长线策略
- 用 **EMA 均线交叉**判断趋势方向
- 用 **自定义动态止损**保护仓位
- 有 **4 种退出方式**保命

就像一个**只做日线的大佬**——不盯盘、不纠结、每天看一眼 K 线就够了 📈

最骚的是它的**动态止损**：不是固定亏 10% 就割肉，而是根据过去 14 天的最低价来计算止损位置。这样止损更智能，不会被正常波动洗出去。

---

## 二、核心配置：说白了就是"赚够了就跑"

### 止盈规则（ROI 表）

```
持仓时间      止盈目标
───────────────────────
< 1 天       → 赚 10% 跑
1-2 天       → 赚 5% 跑
2-4 天       → 赚 2% 跑
> 4 天       → 赚 1% 跑
```

**翻译**：刚买入就涨，那得涨 10% 才卖；拿的时间越长，止盈门槛越低。意思是"**快点涨我就走了，别磨蹭**"。

### 止损规则

```
动态止损 → 跌破 14 天最低价才割肉
固定止损 → 最多亏 10%
追踪止损 → 赚 2% 后激活，利润回吐 1% 就跑
```

**翻译**：
- 动态止损：**不设固定点位**，让历史走势告诉你支撑在哪
- 固定止损：**保底条款**，万一 14 天最低价失效还有这层兜底
- 追踪止损：**利润保护**，赚了钱不能吐回去太多

## 三、买入条件：只有 1 个，简单粗暴

这策略的买入条件就一个，属于"**少而精**"派：

### 🎯 买入条件（就这 3 条，必须同时满足）

```python
# EMA12 > EMA26  →  短期均线在长期均线上面（多头趋势）
# close > EMA12   →  价格突破短期均线
# volume > 0      →  有成交量
```

**大白话**：
> "短期均线（12 日）跑到长期均线（26 日）上面去了，说明趋势变好。然后价格也突破了短期均线，确认上涨势头。最后得有成交量，别是假突破——买！"

就这么简单，**不搞那些花里胡哨的**。一个条件，三重验证，干净利落。

## 四、保护机制：两层"防护网"

### 第一层：动态止损（核心亮点）

每个币种的波动特性不一样，有的币一天波动 5%，有的能波动 20%。用固定止损容易出问题——波动大的币会被正常波动洗出去，波动小的币止损又太松。

**ActionZone 的解决方案**：
```python
# 取过去 14 根 K 线的最低价作为止损参考
stoploss_price = last_candle["lowest"]
```

**大白话**：
> "看看过去 14 天最低跌到哪里，跌破那个位置才止损。每个币有自己的'地板'，不必一刀切。"

### 第二层：追踪止损（利润保护）

```python
trailing_stop = True
trailing_stop_positive = 0.01      # 回吐 1% 触发
trailing_stop_positive_offset = 0.02  # 赚 2% 后激活
```

**大白话**：
> "赚了 2% 之后，启动追踪保护。如果利润回吐 1%，赶紧跑，别让赚钱变亏钱。"

这就像你买了张彩票中了奖，**先把本金揣兜里**，剩下的随它涨跌。

## 五、卖出逻辑：四重退出保命

### 5.1 四种退出方式

| 退出方式 | 触发条件 | 大白话解释 |
|---------|---------|-----------|
| 动态止损 | 跌破 14 天最低价 | "地板都破了，赶紧跑！" |
| EMA 死叉 | EMA12 < EMA26 | "趋势转坏了，别硬扛" |
| 追踪止损 | 利润回吐 1% | "到手的钱不能吐回去" |
| ROI 止盈 | 持仓时间达标 | "时间到了，落袋为安" |

### 5.2 退出优先级

**谁先触发谁生效**：
1. 动态止损 = 保命底线
2. 死叉退出 = 趋势结束信号
3. 追踪止损 = 利润保护
4. ROI 止盈 = 时间到了就走

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **动态止损很聪明**：不是固定百分比，而是根据币种特性来算，更合理
2. **长线设计省心**：日线级别，不用天天盯盘，适合上班族
3. **多重保护**：4 种退出方式，想亏钱都难
4. **条件简单**：买入逻辑清晰，不搞玄学

### ⚠️ 缺点（吐槽环节）

1. **交易太少**：日线级别，可能一个月才交易几次
2. **止盈难触发**：日线要涨 10%？那得是大行情
3. **错过短机会**：只看日线，小时级别的波动都错过了
4. **止损可能太松**：14 天最低价在某些币上可能距离太远

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

ActionZone 的历史回测表现可能**看起来还不错**——但这有个陷阱：

> **日线策略回测周期长，样本少，容易"运气好"。**

简单说就是：**回测 5 年可能就几十次交易，其中几次大赚就能把数据拉得很漂亮。**

### 策略本身的局限性

实盘时要注意：
- **信号太少**：可能几个月没信号，你能不能耐得住？
- **止损可能太远**：14 天最低价在波动大的币上可能距离很远
- **趋势判断滞后**：EMA 是滞后指标，等交叉确认时已经涨了一段了
- **止盈难触发**：日线要涨 10%，不是每天都有这种行情

### 我的建议（真心话）

```
1. 选有趋势的大币（BTC、ETH 这类），别选妖币
2. 小仓位测试，至少观察 3 个月
3. 设置提醒，别错过卖出信号
4. 接受低频率，别指望天天交易
5. 心态放平，这是长线策略
```

**记住**：策略再简单，市场也不会按套路出牌。轻仓测试，活着最重要！🙏

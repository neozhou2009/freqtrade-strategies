# NotAnotherSMAOffsetStrategyLite 策略大白话版

## 第一章 这个策略是干嘛的？

### 1.1 一句话概括

简单说，这个策略就是**"买跌不买涨，跟着趋势走"**。

具体一点：当价格处于上涨趋势中，但突然跌到移动平均线下面一点点的时候，策略会告诉你"可以买了"；当价格涨回到移动平均线附近的时候，策略会告诉你"可以卖了"。

这就像是去超市买东西——你不会在正价的时候买，你会等打折的时候买，然后原价或者稍微低一点卖出去赚差价。

### 1.2 为什么叫这个名字？

**NotAnotherSMAOffsetStrategyLite** 这个名字拆开来看：

- **NotAnother**：意思是"又不是另一个"——作者可能觉得市面上的策略太多了，所以起了个有点调侃的名字
- **SMA**：Simple Moving Average，简单移动平均线（虽然代码里实际用的是EMA指数移动平均线）
- **Offset**：偏移、打折的意思——价格要比均线便宜一点才能买
- **Strategy**：策略
- **Lite**：轻量版——这是简化版本，比完整版参数少、计算简单

翻译成人话就是："别再问这个均线打折策略了——轻量版"。

### 1.3 这个策略适合谁？

- **新手**：逻辑简单，容易理解
- **想学策略写法的人**：代码结构清晰，是学习的好模板
- **做短线交易的人**：用的是5分钟图，持仓时间几小时到几天
- **不喜欢盯盘的人**：让机器人自动帮你买卖

不适合的情况：
- 只想躺着赚钱的（任何策略都需要管理和调整）
- 本金很小的（频繁交易手续费会吃掉利润）
- 想做长线投资的（这个策略持仓时间短）

## 第二章 核心原理——用人话说

### 2.1 什么是移动平均线？

移动平均线就是把过去一段时间的价格取个平均值。

比如5分钟图上的14周期EMA，就是把过去14根5分钟K线的价格（最近的价格权重更大）算出一个平均值。随着时间推移，这个平均值也在"移动"。

**为什么要有这个东西？**
- 它可以帮你看清趋势：价格在均线上面=涨势，价格在均线下面=跌势
- 它像一个"公平价格"的参考线

### 2.2 什么是"打折买"？

正常情况下，很多人会在价格突破均线的时候买入。但这个策略说：**不行，我要等打折！**

具体来说：
- 默认设置是价格要**比均线便宜2.5%**才考虑买
- 也就是价格要是均线的97.5%以下

举个例子：
- 均线价格 = 100块
- 策略的买入价 = 100 × 0.975 = 97.5块以下

**这样有什么好处？**
- 买得更便宜，利润空间更大
- 如果判断错了，亏损也更小
- 就像你买东西等打折，不是更划算吗？

### 2.3 什么是EWO指标？

EWO（Elliott Wave Oscillator）是这个策略用来判断"大方向"的指标。

它的计算方法很简单：
```
EWO = (快均线 - 慢均线) ÷ 当前价格 × 100
```

- 快均线：50周期的EMA，变化快
- 慢均线：200周期的EMA，变化慢

**怎么看EWO？**
- EWO > 0：说明快均线在慢均线上面，意思是**最近涨势比之前强**，整体是上涨趋势
- EWO < 0：说明快均线在慢均线下面，意思是**最近涨不动**，整体是下跌趋势

**策略怎么用它？**
- 只在EWO > 0的时候才买
- 意思就是：**只在大方向是涨的时候买**

这就好比：
- 如果大方向是涨的（EWO > 0），这时候价格跌了，那就是"捡便宜"
- 如果大方向是跌的（EWO < 0），这时候价格跌了，那就是"接飞刀"，不买！

## 第三章 买入条件——什么时候开仓？

### 3.1 三个条件必须同时满足

策略买入的条件很简单，就三个，必须**同时满足**：

**条件一：价格够便宜**
```
收盘价 < 均线价格 × 0.975
```
意思是价格要比均线便宜至少2.5%。这个"打折力度"可以自己调。

**条件二：大方向是涨的**
```
EWO > 0
```
意思是整体趋势是向上的。不想在下跌趋势中"接飞刀"。

**条件三：有成交量**
```
成交量 > 0
```
意思是有人在交易，不是那种没人管的死币。

### 3.2 用一个例子说明

假设你在看BTC/USDT的5分钟图：

1. 当前BTC价格是49000
2. 14周期EMA是50000
3. 计算"打折价"：50000 × 0.975 = 48750
4. 当前价格49000 > 打折价48750，**条件一不满足，不能买**

过了一会儿：
1. BTC价格跌到了48000
2. 均线价格没变，还是50000（变化比较慢）
3. 打折价还是48750
4. 当前价格48000 < 打折价48750，**条件一满足！**
5. 看看EWO，假设是+2.5，大于0，**条件二满足！**
6. 看看成交量，有人在交易，**条件三满足！**
7. **买入信号触发！**

### 3.3 买入参数能改吗？

可以改，有两个参数：

**1. 均线周期（base_nb_candles_buy）**
- 默认：14
- 可调范围：5-80
- 改小：信号更多，但假信号也多
- 改大：信号更少，但更可靠

**2. 打折系数（low_offset）**
- 默认：0.975（等2.5%的折扣）
- 可调范围：0.9-0.99
- 改小：要更大的折扣才能买，信号少但价格更优
- 改大：小折扣就能买，信号多但入场价格没那么好

**新手建议**：先用默认值，回测看看效果，再根据情况调整。

## 第四章 卖出条件——什么时候平仓？

### 4.1 卖出更简单

卖出的条件比买入简单：

**只要满足两个条件：**
```
收盘价 > 均线价格 × 0.991
成交量 > 0
```

注意：卖出**不需要**看EWO！

**为什么？**
- 买入的时候需要确认大方向是涨的，这是"选方向"
- 卖出的时候只需要价格涨回来了，这是"落袋为安"
- 不用管方向，有钱赚就跑

### 4.2 用例子说明卖出

继续上面的BTC例子：

你48000买入后，价格开始涨：
1. 价格涨到49500
2. 卖出参考均线是24周期EMA，假设是50000
3. 计算"卖出线"：50000 × 0.991 = 49550
4. 当前价格49500 < 卖出线49550，**还不能卖**

继续涨：
1. 价格涨到49600
2. 当前价格49600 > 卖出线49550，**卖出条件满足！**
3. **卖出信号触发！**

**这一单赚了多少？**
- 买入价：48000
- 卖出价：49600
- 收益率：(49600-48000)/48000 = 3.33%
- 扣除手续费（假设0.1%双边）：约3.1%

### 4.3 卖出参数能改吗？

可以改，同样两个参数：

**1. 卖出均线周期（base_nb_candles_sell）**
- 默认：24（比买入周期长）
- 可调范围：5-80
- 改小：更敏感，赚一点就跑
- 改大：更稳定，不会被小波动吓跑

**2. 卖出系数（high_offset）**
- 默认：0.991
- 可调范围：0.95-1.1
- 改小：早点卖，更保守
- 改大：晚点卖，赌更大的利润（但可能利润回吐）

**聪明的设置**：
- 买入系数比卖出系数折扣大（0.975 vs 0.991）
- 这样"买得便宜，卖得不需要那么高"
- 更容易盈利！

## 第五章 止损——赔了怎么办？

### 5.1 固定止损10%

策略设置了**10%的止损**：
```python
stoploss = -0.1
```

意思就是：如果价格跌了10%以上，自动卖出认赔。

**10%是不是太高了？**
- 对于5分钟级别的短线交易，10%确实挺大的
- 但考虑到买入时已经打折了（默认2.5%以上），实际风险可能小一点
- 你也可以自己改小这个数字

### 5.2 动态止损——时间越长越严格

策略还有个智能止损规则：

**如果你持有了超过12小时，还亏损超过5%，止损就收紧到1%**

```python
if current_profit < -0.05 and 持仓时间 > 12小时:
    止损 = -0.01
```

这是什么意思？

假设你48000买入BTC：
1. 刚买入，止损是-10%（价格跌到43200止损）
2. 持仓12小时后，价格还在47000（亏损约2%）
   - 不触发动态止损（亏得不够多）
3. 价格跌到45000（亏损约6.25%）
   - 触发动态止损！
   - 新止损位：48000 × (1-0.01) = 47520
   - 如果价格不涨回47520以上，马上止损

**为什么要这样设计？**
- 如果一笔交易超过12小时还在亏，说明你的判断可能错了
- 与其等到亏10%再认赔，不如早点止损，少亏一点
- 给机会翻身，但不能无限期等

### 5.3 止损设置的哲学

这个策略的止损逻辑体现了几个原则：

1. **给足空间**：刚买入时止损宽（10%），给价格波动空间
2. **时间限制**：时间越长越不能亏，证明方向错了
3. **及时止损**：收紧止损到1%，逼你赶紧离场

**你可以根据自己情况调整：**
- 本金少、风险承受低：把初始止损改小（比如5%）
- 想更激进：保持默认或改大
- 想更快止损：把12小时改成6小时

## 第六章 止盈——赚了怎么办？

### 6.1 固定止盈2.5%

策略设置了**2.5%的最小收益目标**：
```python
minimal_roi = {'0': 0.025}
```

意思就是：价格涨了2.5%以上，随时可以卖。

**但是！** 这个只是"可以卖"的条件，不是"必须卖"。
实际卖不卖，还要看卖出条件满不满足。

### 6.2 只在盈利时才卖

策略有个设置：
```python
sell_profit_only = True
sell_profit_offset = 0.01
```

意思是：
- 只有盈利超过1%的时候，才会响应卖出信号
- 如果你刚买入价格就涨了0.5%，这时候有卖出信号，策略也不会卖

**为什么这样设计？**
- 避免刚买入就卖出，赚一点点手续费都不够
- 给盈利空间，不要赚点小钱就跑
- 但真涨多了（超过卖出条件），还是要卖

### 6.3 止盈和止损的平衡

策略的止盈止损可以这样理解：

| 情况 | 处理方式 |
|------|---------|
| 亏损<5%，持仓<12小时 | 等，可能反弹 |
| 亏损>5%，持仓>12小时 | 止损收紧到1%，快跑 |
| 盈利<1% | 不卖，等 |
| 盈利1%-2.5% | 满足条件可以卖 |
| 盈利>2.5% | 随时可以卖 |

**核心思想**：给亏损设置时间限制，给盈利设置底线，不贪不惧。

## 第七章 时间框架——用多长时间的图？

### 7.1 默认5分钟图

策略用的是**5分钟时间框架**：
```python
timeframe = '5m'
```

**5分钟图意味着什么？**
- 每根K线代表5分钟的价格变化
- 每小时有12根K线
- 每天有288根K线
- 信号会比较频繁

**适合的交易风格：**
- 日内交易（当天买当天卖）
- 短线波段（持仓几小时到几天）
- 不适合长线投资

### 7.2 可以换成别的吗？

可以改成：
- `1m`：1分钟图，信号更多，噪音更多
- `15m`：15分钟图，信号更少，更稳定
- `1h`：1小时图，中线交易

**改时间框架要注意：**
- 参数要重新调整
- 止损止盈比例要重新算
- 回测要重新做

**新手建议**：先用默认5分钟，熟悉了再考虑改。

### 7.3 预热需要200根K线

策略需要先加载200根K线的历史数据：
```python
startup_candle_count = 200
```

**为什么需要200根？**
- 因为EWO要算200周期的慢均线
- 没有足够的数据，指标算不准
- 200根5分钟K线 = 约16.7小时的数据

**实际影响：**
- 刚启动策略的时候，前16.7小时不会产生信号
- 或者说，你至少要准备16.7小时以前的数据才能回测

## 第八章 订单类型——怎么买卖？

### 8.1 买入用GTC订单

```python
order_time_in_force = {'buy': 'gtc', 'sell': 'ioc'}
```

**买入：GTC（Good Till Cancelled）**
- 意思是"订单一直有效，直到成交或取消"
- 好处：不会因为一时没成交就取消
- 适合买入：你想在特定价格买入，可以等等

### 8.2 卖出用IOC订单

**卖出：IOC（Immediate Or Cancel）**
- 意思是"马上成交，成交不了的部分取消"
- 好处：在价格快速变化的时候，能卖多少卖多少
- 适合卖出：不想等，赶紧离场

**举个例子：**
你想卖10个币，当前价格49500：
- 市场上只有5个币的买单
- IOC会马上成交5个币
- 剩下5个币的卖单自动取消
- 好处：不会挂着卖单傻等

### 8.3 为什么买卖不一样？

买入和卖出用不同订单类型，体现了策略的思想：

**买入**：
- 不急，可以等
- 想在好价格买入
- 用限价单，可能要等一会

**卖出**：
- 赶紧离场
- 能卖多少卖多少
- 用即时单，不拖泥带水

**用人话说**：买入要精挑细选，卖出要果断干脆。

## 第九章 参数调整——怎么优化？

### 9.1 四个核心参数

这个策略有四个主要参数可以调：

| 参数 | 默认值 | 范围 | 作用 |
|------|--------|------|------|
| 买入均线周期 | 14 | 5-80 | 决定买入参考线多平滑 |
| 买入折扣系数 | 0.975 | 0.9-0.99 | 决定要等多大的折扣 |
| 卖出均线周期 | 24 | 5-80 | 决定卖出参考线多平滑 |
| 卖出系数 | 0.991 | 0.95-1.1 | 决定涨到什么程度卖 |

### 9.2 参数怎么搭配？

**保守型（追求高胜率，低频交易）：**
- 买入周期：改大（比如30）
- 买入系数：改小（比如0.95）
- 卖出周期：改大（比如40）
- 卖出系数：改小（比如0.98）
- 效果：信号少，但每个信号质量高

**激进型（追求高频率，接受更多假信号）：**
- 买入周期：改小（比如8）
- 买入系数：改大（比如0.985）
- 卖出周期：改小（比如15）
- 卖出系数：改大（比如1.02）
- 效果：信号多，但假信号也多

**平衡型（默认设置）：**
- 保持默认参数
- 中等频率，中等质量

### 9.3 用Freqtrade优化参数

Freqtrade有自动优化功能，命令类似：
```bash
freqtrade hyperopt --hyperopt-loss SharpeHyperOptLoss -e 500 --spaces buy sell
```

这会自动帮你找最优参数。

**优化建议：**
1. 先用至少6个月的历史数据
2. 用多个品种交叉验证
3. 不要过度优化（在历史数据上表现太好，实盘可能差）
4. 保留一部分数据做"样本外测试"

## 第十一章 这个策略的缺点

### 11.1 只能做多不能做空

- 只能在涨势中赚钱
- 遇到大跌只能空仓
- 错过了下跌行情的机会

### 11.2 震荡市表现一般

- 横盘震荡时信号可能不准
- 可能频繁止损
- 需要调整参数适应

### 11.3 参数敏感

- 不同品种需要不同参数
- 不同市场状态需要调整
- 需要持续优化

### 11.4 可能错过大行情

- 卖出条件比较保守
- 赚了点就跑了
- 看着价格继续涨

### 11.5 需要手动调优

- 不是"设好不管"的策略
- 需要定期检查表现
- 需要根据市场调整

## 第十二章 实战建议

### 12.1 品种选择

**适合的品种：**
- 主流币：BTC、ETH
- 流动性好的山寨币
- 有明确趋势的品种

**不适合的品种：**
- 流动性差的小币
- 经常暴涨暴跌的币
- 被高度操控的币

### 12.2 仓位管理

**建议仓位：**
- 单笔交易：总资金的10-20%
- 同时持仓：最多3-5个
- 预留现金：至少30%

**为什么要这样：**
- 单笔太大：一次亏损受不了
- 持仓太多：顾不过来
- 没有现金：错过机会

### 12.3 回测先做再上实盘

**回测步骤：**
1. 准备至少6个月的历史数据
2. 设置合理的手续费（0.1%）
3. 设置合理的滑点（0.05%）
4. 跑回测看结果
5. 调参数，再回测
6. 交叉验证（多个时间段、多个品种）
7. 确认策略有效再上实盘

**看哪些指标：**
- 总收益：赚了多少钱
- 最大回撤：最多亏了多少
- 胜率：多少笔是赚的
- 盈亏比：平均赚的 vs 平均亏的
- 交易次数：太少了不靠谱，太多了手续费高

### 12.4 实盘监控

上实盘后要做的：
- 每天检查一次交易记录
- 每周总结一下表现
- 发现问题及时调整
- 大行情时盯紧止损

## 第十三章 总结

### 13.1 这个策略适合你吗？

**如果你是：**
- 新手，想学策略开发 ✓

- 不想盯盘的人 ✓
- 愿意学习调参的人 ✓

**如果你是：**

- 只做长线投资的人 ✗
- 本金很小的 ✗

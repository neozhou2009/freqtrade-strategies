# BinHV27 策略：等的就是那波翻倍的暴力反弹！

> **外号**：翻倍狂魔 / 100%目标帝 / 超卖捕手  
> **职业**：专找极端超卖点，然后死等翻倍  
> **时间框架**：5分钟  
> **核心特点**：双均线交叉 + ADX动量确认 + RSI超卖 + 100%止盈目标

---

## 一、这策略是个啥？

简单说，**BinHV27** 就是一个：

- 专找**极端超跌**机会入场的策略
- RSI 必须跌到 20 以下才考虑买
- 目标是**翻倍**（100%收益）——不是 20%，是 100%！
- 趋势即将反转的那个瞬间入场，然后死等

你可以把它想象成一个超级有耐心的猎人：

> "没事，我等得起。跌得越惨越好，反弹起来才够暴力！要么不赚，要赚就赚一倍！"

这策略来自 Slack 社区的大神 **BinH**，是 HV（High Volatility，高波动）系列的代表作品之一。HV 系列的共同特点就是：
- 目标高（要就要大的）
- 条件严（不是极端超卖不要）
- 等得起（没有 100% 不走）

**翻译**：最多亏 10%。如果买入后跌了 10%，认赔出场，不犹豫。

## 三、4个买入条件：基础条件 + 分类条件

### 3.1 基础条件（5个必须同时满足）

买入前，必须先通过这5关：

| 序号 | 条件 | 大白话 |
|------|------|--------|
| 1 | slowsma > 0 | 240周期SMA在零轴上方（长期趋势向上） |
| 2 | close < highsma | 价格低于120周期EMA（相对低位） |
| 3 | close < lowsma | 价格低于60周期EMA（进一步确认低位） |
| 4 | minusdi > minusdiema | DI-上穿其25周期EMA（下跌动能在减弱） |
| 5 | rsi >= rsi.shift() | RSI正在上升（超卖状态改善中） |

**大白话总结**：
> "长期趋势还在涨，但现在价格跌到了短期均线下方，而且下跌的力量开始减弱了，RSI也开始回升了——有点意思！"

### 3.2 分类条件（4种情况，满足任一即可）

满足基础条件后，还要满足以下任一分类条件才能触发买入：

---

#### 🎯 情况A：下跌趋势中的超跌反弹（ADX > 25）

```
满足基础条件 + 以下全部：
- 没有趋势反转信号（preparechangetrend = False）
- 短期均线还没确认上涨（continueup = False）
- ADX > 25（有一定趋势强度）
- 空头排列（fastsma < slowsma）
- EMA(RSI) <= 20（极度超卖）
```

**大白话**：
> "还在跌，但已经跌不动了，RSI都到20了，ADX显示有趋势，这不反弹说不过去吧？"

---

#### 🎯 情况B：下跌趋势中已小幅反弹（ADX > 30）

```
满足基础条件 + 以下全部：
- 没有趋势反转信号
- 短期均线已经上涨（刚反弹的苗头）
- ADX > 30（趋势更强）
- 空头排列
- EMA(RSI) <= 20
```

**大白话**：
> "虽然还在跌，但短期已经有点反弹的意思了，ADX更强（>30），稳了！"

---

#### 🎯 情况C：上涨趋势中的回调到位（ADX > 35）

```
满足基础条件 + 以下全部：
- 短期均线没有持续上涨（刚回调）
- ADX > 35（强趋势确认）
- 多头排列（fastsma > slowsma）
- EMA(RSI) <= 20
```

**大白话**：
> "涨多了回调一下很正常，现在RSI都到20了，ADX还强（>35），机会来了！"

---

#### 🎯 情况D：上涨趋势中的小幅回调（ADX > 30）

```
满足基础条件 + 以下全部：
- 短期均线持续上涨
- ADX > 30
- 多头排列
- EMA(RSI) <= 25（稍微宽松一点）
```

**大白话**：
> "上涨趋势中，RSI稍微低一点（25以下）也能接受，毕竟趋势还在，ADX也够强！"

## 四、保护机制：三重保险

这策略对超卖的要求极高，设置了三重保护：

| 保护层 | 条件 | 含义 |
|--------|------|------|
| **RSI超卖保护** | EMA(RSI) <= 20 或 25 | 必须极度超卖才入场 |
| **ADX趋势保护** | > 25/30/35 | 必须有趋势强度，不能是震荡市 |
| **RSI趋势保护** | RSI >= 上一根 | RSI必须正在好转，不能继续恶化 |

**大白话**：
> "想买入？没那么容易！必须RSI跌到20以下，ADX显示有趋势，而且RSI必须开始回升——三个条件少一个都不行！"

## 六、技术指标体系

### 核心均线指标

| 指标 | 周期 | 类型 | 用途 |
|------|------|------|------|
| lowsma | 60 | EMA | 短期价格基准 |
| highsma | 120 | EMA | 中期价格基准 |
| fastsma | 120 | SMA | 快速趋势线 |
| slowsma | 240 | SMA | 慢速趋势线 |

### RSI 相关指标

| 指标 | 周期 | 用途 |
|------|------|------|
| rsi | 5 | 短期超买超卖判断 |
| emarsi | 5 | RSI 的 EMA 平滑 |

### ADX 动量指标

| 指标 | 周期 | 用途 |
|------|------|------|
| adx | 默认 | 趋势强度 |
| minusdi | 默认 | 下跌动量 |
| minusdiema | 25 | 下跌动量的趋势线 |
| plusdi | 默认 | 上涨动量 |
| plusdiema | 5 | 上涨动量的趋势线 |

### 衍生指标

| 指标 | 计算方式 | 用途 |
|------|---------|------|
| bigup | fastsma > slowsma 且差值 > close/300 | 确认多头排列 |
| bigdown | ~bigup | 确认空头排列 |
| trend | fastsma - slowsma | 趋势强度数值 |
| preparechangetrend | trend > trend.shift() | 趋势即将反转 |
| preparechangetrendconfirm | 连续两期满足 preparechangetrend | 趋势反转确认 |
| continueup | slowsma 连续上升 | 短期上涨趋势 |
| delta | fastsma - fastsma.shift() | 快速线变化 |
| slowingdown | delta < delta.shift() | 动量放缓 |

## 十一、策略的"小心思"

### 为什么是100%目标？

策略设计者的逻辑是：
> "既然是在极端超卖点入场，反弹起来应该是暴力级别的，不如直接等到翻倍！"

但现实是：**100%收益在大多数市场环境下极其罕见**。

### 为什么要 ADX 过滤？

ADX 确保市场有足够趋势强度：
- ADX < 25：震荡市场，不入场
- ADX 25-30：有一定趋势
- ADX > 35：强趋势

这样可以避免在震荡市中频繁被止损。

### 为什么用多个均线周期？

- 60 EMA：短期基准
- 120 EMA/SMA：中期基准
- 240 SMA：长期基准

多周期验证确保不会在错误的时机入场。

1. 100%目标太夸张，大多数情况达不到
2. 可能持仓很长时间
3. 容易错过中小级别的反弹机会
4. 固定止损无灵活性

## 十三、⚠️ 风险再强调（这段一定要看）

### 100%目标很难达到

> **在大多数市场环境下，100%收益是极其罕见的。你可能持仓很长时间，最后等来的是止损。**

这不是危言耸听：
- 暴跌后反弹 30-50% 很常见
- 反弹 100%？那是真正的暴力反转
- 大多数情况下，你会在卖出信号或止损时出场

### 可能长时间持仓

策略设计为"要么翻倍要么止损"，但如果市场一直不反弹：
- 你会一直持仓
- 可能持仓数周甚至数月
- 这对资金管理和心理承受能力要求很高

### 固定止损无灵活性

没有自定义止损逻辑，亏损就是亏损：
- 在极端行情下，亏损可能超过 10%（滑点）
- 没有移动止损保护利润

### 适合高风险承受者

这是一个"要么会所嫩模，要么下海干活"的策略：
- 没有金刚钻别揽瓷器活
- 先用小资金测试
- 先把 ROI 调低试试

### 实际建议

```
1. 先把ROI改低：100% → 20-30%，先确保能赚钱
2. 设好最大亏损：别让它真的亏到10%
3. 选对市场：暴跌后反弹才用它
4. 小资金测试：确认有效再加仓
5. 做好长持仓准备：可能要等很久
6. 永远不要投入超过承受能力的资金
```

### 高风险策略警告

**重要的事情说三遍：**

🚨 **100%目标在大多数市场达不到**  
你可能长时间持仓，最后只能止损出场或等到卖出信号。

🚨 **条件严格导致机会稀少**  
RSI <= 20 + ADX > 25 + 趋势反转，三个条件缺一不可。

🚨 **需要大幅反弹才能盈利**  
策略依赖市场出现较大级别的反弹，小反弹根本不够看。

### 给新手的忠告

1. **别直接上100%目标**：先改成 20-30% 试试
2. **选高波动币种**：需要波动才能达到目标
3. **做好长持仓准备**：可能持仓数周甚至数月
4. **用小资金测试**：先验证策略有效性
5. **学会止损**：该跑就跑，别死扛

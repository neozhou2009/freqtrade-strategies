# BBRSI4cust 策略：可定制的布林带玩家

> **外号**：参数调节大师  
> **职业**：自适应抄底选手  
> **时间框架**：15 分钟

---

## 一、这策略是个啥？

简单说，**BBRSI4cust** 就是一个：
- 自带"调节旋钮"的布林带策略
- 买入时看趋势（+DI）+ 看位置（布林带下轨）
- 卖出时看回归（布林带中轨）
- 参数可以自己优化调整

就像一个"根据天气调节装备"的专业钓手 🎣

---

## 二、核心配置：保守派的短线玩法

### 止盈规则（ROI 表）

```
0 分钟：赚 0.3% 就跑
```

**翻译**：这个 ROI 设置也太保守了吧？才 0.3%？意思就是"差不多就行，信号让我走我再走"

### 止损规则

```
固定止损：-10%（这才叫正常止损）
追踪止损：启用（但参数用的默认值）
```

**翻译**：
- 固定止损 = "亏 10% 就认输"——这比 BBRSI3366 的 -33% 合理多了
- 追踪止损 = "具体参数没设，让系统自己来"

---

## 三、买入条件：趋势 + 位置 双重确认

这策略的买入需要三个条件同时满足：

### 条件 #1：+DI 大于阈值
```python
(dataframe['plus_di'] > self.buy_di.value)  # 默认 > 20
```
**大白话**：
> "+DI 是方向性指标的一部分，表示上涨趋势强度。大于 20 说明有点上涨动能"

### 条件 #2：价格跌破布林带下轨
```python
(qtpylib.crossed_below(dataframe['low'], dataframe['bb_lowerband']))
```
**大白话**：
> "最低价穿过布林带下轨——价格被打压了，可能要反弹"

### 条件 #3：有成交量
```python
(dataframe['volume'] > 0)
```
**大白话**：
> "这根 K 线有成交量，不是空气"

**组合翻译**：
> "有上涨趋势 + 价格被打压到下轨 + 有人交易 = 买入机会！"

---

## 四、卖出逻辑：回归中轨就走

### 信号卖出：最高价穿过布林带中轨
```python
(qtpylib.crossed_above(dataframe['high'], dataframe['bb_middleband1']))
```
**大白话**：
> "最高价突破布林带中轨——反弹差不多了，走吧"

### 自定义退出：实时价格穿过中轨
```python
if (qtpylib.crossed_above(current_rate, current_candle['bb_middleband1'])):
    return "bb_profit_sell"
```
**大白话**：
> "当前价格穿过中轨，触发 bb_profit_sell——锁定利润"

**总结**：两种卖出方式都指向同一个信号——**价格回到布林带中轨就走人**

## 五、可调节参数：这个策略的精髓

这策略最大的特点是**参数可以优化**：

| 参数 | 可以调的范围 | 默认值 | 大白话 |
|------|-------------|--------|--------|
| buy_bb | 1-4 | 1 | 布林带宽度（买入用） |
| buy_di | 10-20 | 20 | +DI 阈值（买入过滤） |
| sell_bb | 1-4 | 1 | 布林带宽度（卖出用） |

**翻译一下**：

### buy_bb（买入布林带宽度）
- **= 1**：标准布林带，信号多但可能假信号也多
- **= 2**：更宽，信号少但可能更准
- **= 3-4**：很宽，信号很少，只有极端情况才买

### buy_di（买入趋势过滤）
- **= 10**：条件宽松，更容易买入
- **= 20**：条件严格，必须有较强的上涨趋势才买

### sell_bb（卖出布林带宽度）
- 影响卖出的中轨位置
- 可以和 buy_bb 不同，更灵活

**吐槽**：这策略相当于给了你三个旋钮，让你自己调出最适合当前市场的参数——但前提是你得会用 hyperopt 进行参数优化 😅

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **参数可调**：不像 BBRSI3366 那样写死，可以根据市场调整
2. **趋势过滤**：+DI 条件避免在纯下跌中乱买
3. **止损合理**：-10% 的止损，总算正常了
4. **双布林带**：买入和卖出可以用不同参数，更灵活
5. **自定义退出**：实时价格监控，退出更精准

### ⚠️ 缺点（吐槽环节）

1. **RSI 算了不用**：计算了 RSI 但根本没用上——何必浪费算力？
2. **ROI 太低**：0.3% 的目标几乎等于没设
3. **参数优化有风险**：Hyperopt 优化可能"背答案"
4. **学习曲线**：需要理解 Hyperopt 才能发挥最大价值

## 十二、⚠️ 风险再强调（这段一定要看）

### 参数优化的陷阱

BBRSI4cust 的可优化参数是一把双刃剑：

> **过度优化可能导致"背答案"——在历史数据上表现完美，但实盘一塌糊涂。**

简单说就是：**"历史回测收益 1000%，实盘亏损 50%"**

### Hyperopt 的风险

使用 Hyperopt 优化时要注意：
- **过拟合**：参数太贴合历史数据
- **不稳定性**：参数在不同时间段表现差异大
- **市场变化**：优化后的参数可能很快失效

### 我的建议（真心话）

```
1. 不要盲目追求回测收益最高
2. 使用滚动窗口验证参数稳定性
3. 保留一部分数据做样本外测试
4. 参数优化后观察实盘表现，及时调整
5. 组合多个策略，不要单吊一个
```

**记住**：可优化参数 ≠ 更好的策略。有时候简单策略反而更稳健。调参数是一门艺术，不是简单追求回测收益最大化！🙏

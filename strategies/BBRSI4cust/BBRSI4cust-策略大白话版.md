## 一、这策略是个啥？

简单说，**BBRSI4cust** 就是一个：
- 只有 **3 个指标** 的策略（PLUS_DI、RSI、布林带）
- **自定义退出** 的策略（不用传统卖出信号）
- **0.3% 就跑** 的策略（超快周转）

就像一个买东西专门等打折的精明买家："PLUS_DI 向上了没？价格跌破布林带了没？都满足了就买！突破中轨就跑！" 🛒

## 二、核心配置：说白了就是"低买高卖"

### 止盈规则（ROI 表）

```
赚 0.3%？→ 跑！（就这一级，超级快）
```

**翻译**：这策略是典型的"薄利多销"思维，0.3% 就跑，不贪心！

### 止损规则


## 三、买入条件：就 2 个条件

### 🎯 PLUS_DI + 布林带突破

**核心逻辑**：
1. PLUS_DI > 阈值（默认 20）
2. 价格跌破布林带下轨

**大白话**：
> "PLUS_DI 都向上了（上升动能），价格跌破布林带下轨了（超卖）——这还不抄底？"

## 五、卖出逻辑：比买入还灵活

### 5.1 技术卖出：价格突破中轨

**触发条件**：
```python
价格上穿布林带中轨
```

**大白话**：
> "价格都突破布林带中轨了，均值回归完成了——这还不跑？"

### 5.2 自定义退出：实时监控

**触发条件**：
```python
if 当前价格 > 布林带中轨:
    return "bb_profit_sell"
```

**大白话**：
> "实时监控价格，突破中轨就退出，不等 K 线闭合！"

**吐槽**：这策略是真的"灵活"，两种方式都能退出！🤣

## 六、这策略的"人格特点"

### ✅ 优点
1. **自定义退出**：灵活控制卖出时机
2. **超参数优化**：可以自动找最佳布林带标准差
3. **双重卖出**：技术信号 + 自定义退出
4. **计算量小**：指标少，512MB 内存就能跑
5. **低 ROI**：0.3% ROI，快速周转

### ⚠️ 缺点
1. **没趋势过滤**：没有 EMA200 这种长期趋势判断
2. **没 BTC 关联**：比特币崩了它也不知道
3. **极低 ROI**：0.3% ROI 可能过早退出大趋势
4. **15 分钟框架**：信号频率比 5 分钟低
5. **参数敏感**：布林带标准差需要优化

BBRSI4cust 的历史回测表现可能**非常优异**——但这有个陷阱：

> **均值回归策略在回测中往往表现很好，因为历史数据中总有震荡行情，但这并不代表未来一定震荡。**

简单说就是：**回测数据好看，可能是因为它刚好"遇到"了那段震荡行情。**

### 均值回归的隐藏风险

实盘时，均值回归策略可能导致：
- **单边行情亏损**：在单边行情中可能连续亏损
- **过早退出**：0.3% ROI 可能错过大趋势
- **参数过拟合**：布林带标准差可能过拟合

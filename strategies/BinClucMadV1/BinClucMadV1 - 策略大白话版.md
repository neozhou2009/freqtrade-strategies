## 二、核心配置：说白了就是"快进快出"

### 止盈规则（ROI表）

```
持仓0-15分钟  → 赚8%以上就可以跑
持仓15-45分钟 → 赚4.5%以上就可以跑
持仓45-180分钟 → 赚2%以上就可以跑
持仓180分钟以上 → 赚多少都行，随时跑
```

**翻译**：刚买进去15分钟内，得赚8%才跑；拿得越久，要求的收益越低。超过3小时就不强制止盈了。

### 止损规则

```
硬止损：亏10%
追踪止损：赚了3%之后启动，回吐1%就跑
```

**翻译**：
- 最多亏10%，这是底线
- 但如果赚了3%以上，就会启动"保护模式"——只要利润回吐1%，就立刻落袋为安

5. **极端行情失控**：单边下跌时，抄底抄在半山腰

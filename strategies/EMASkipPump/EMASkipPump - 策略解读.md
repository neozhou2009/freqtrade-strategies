## 一、策略概览

**EMASkipPump** 是一个专门设计用于"跳过泵"的策略。核心思想是：当市场出现异常成交量（可能是有"泵"）时，策略会"跳过"不买入，等待恢复正常后再交易。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 1 个主条件 + 波动率过滤 |
| **卖出条件** | 1 个主条件 |
| **保护机制** | 交易量异常检测（30周期均值的20倍） |
| **时间框架** | 5 分钟 |

## 三、买入条件详解

```python
# 买入条件
dataframe.loc[
    (dataframe['volume'] < volume_rolling_mean * 20) &   # 交易量正常
    (dataframe['close'] < ema_5) &                        # 价格 < 短期 EMA
    (dataframe['close'] < ema_12) &                       # 价格 < 中期 EMA
    (dataframe['close'] == dataframe['min']) &            # 收盘价是周期最低
    (dataframe['close'] <= bb_lowerband),                 # 触及布林带下轨
    'buy'
] = 1
```

**逻辑分析**：
1. **交易量过滤**：`volume < rolling_mean * 20` 排除异常交易量（防泵）
2. **均线排列**：价格低于各周期 EMA，空头排列
3. **极值确认**：收盘价是周期内最低
4. **布林带确认**：价格触及或低于布林带下轨

## 四、卖出条件详解

```python
# 卖出条件
dataframe.loc[
    (dataframe['close'] > ema_5) &
    (dataframe['close'] > ema_12) &
    (dataframe['close'] >= dataframe['max']) &
    (dataframe['close'] >= bb_upperband),
    'sell'
] = 1
```

**逻辑分析**：
- 价格高于各周期 EMA，多头排列
- 收盘价是周期内最高
- 触及或突破布林带上轨

## 七、策略优势与局限

### ✅ 优势

1. **防泵保护**：专门设计避免买入异常波动的币
2. **均线排列**：多头/空头排列确认趋势
3. **极值交易**：买在周期最低点，卖在周期最高点
4. **逻辑清晰**：代码简洁，易于理解

### ⚠️ 局限

1. **逆势交易**：均线空头时买入，可能接下跌飞刀
2. **假突破**：布林带下轨可能频繁触及
3. **交易量阈值固定**：20倍可能不适用于所有市场

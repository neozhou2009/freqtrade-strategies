## 一、这策略是个啥？

简单说，**Combined_Indicators** 就是一个"两个老江湖联手搞钱"的策略。

它把两个经典策略硬生生地捏在一起：
- **BinHV45**：玩布林带 40 周期的反弹老手
- **ClucMay72018**：玩布林带 20 周期 + 成交量的 低量突破玩家

这两个策略单独拿出来都能打，合并在一起是想"双剑合璧"，提高成功率。

就像你玩游戏时组了个 CP，一个负责输出，一个负责辅助，配合打怪 🎮

## 二、核心配置：说白了就是"见好就收"

### 止盈规则（ROI 表）

```python
minimal_roi = {
    "0": 0.015  # 赚 1.5% 就跑路
}
```

**翻译**：只要持仓赚到了 1.5%，二话不说，直接平仓走人。这就是典型的"快进快出"玩法——不贪心，赚一点就跑，积少成多。

### 止损规则

```python
stoploss = -0.0658  # 亏 6.58% 就割肉
```

**翻译**：允许你亏 6.58%，但只要触发这条规定，说明这笔交易已经凉凉了。

### 追踪止损规则

```python
trailing_stop = True
trailing_stop_positive = 0.0198        # 赚 1.98% 开始跟踪
trailing_stop_positive_offset = 0.03082  # 涨到 3.082% 才正式启动
trailing_only_offset_is_reached = True   # 必须达到 3.082% 才开启追踪
```

**翻译**：
- 刚赚 1.98% 的时候，追踪止损开始"观察"
- 只有继续涨到 3.082%，它才开始真正"干活"
- 之后如果从最高点跌下来 1.98%，立刻跑路

大白话就是：**先让子弹飞一会儿，飞到 3% 了再开始保驾护航**

## 三、两个买入条件：我帮你分类好了

这策略的买入条件其实就两条，简单粗暴：

### 🎯 第 1 类：BinHV45 反弹信号（1 个条件）

**核心逻辑**：价格在布林带下轨附近出现"刹车"迹象，准备反弹

**大白话**：
> "价格已经跌到布林带下轨了，而且刚才那根K线有很长的下影线，说明有资金在接盘买入！这就是我要的反弹信号！"

**具体条件**（一连串判断）：

```python
dataframe['lower'].shift().gt(0)  # 布林带下轨存在
dataframe['bbdelta'].gt(dataframe['close'] * 0.00703)  # 布林带宽度要够
dataframe['closedelta'].gt(dataframe['close'] * 0.01476)  # 价格波动要够大
dataframe['tail'].lt(dataframe['bbdelta'] * 0.03632)  # 下影线要够短
dataframe['close'].lt(dataframe['lower'].shift())  # 收盘价低于下轨
dataframe['close'].le(dataframe['close'].shift())  # 没有超过前一根收盘价
```

**翻译成人话**：
1. 布林带下轨要存在（别拿第一根K线说事）
2. 布林带要"开口"，不能太窄
3. 价格要有明显波动，不能死气沉沉
4. 下影线要短，说明是" V"型反弹，不是持续下跌
5. 收盘价要低于布林带下轨，这是超卖信号
6. 不要创新高，老实待着

**经典台词**：
> "这波跌到布林带下轨了，而且下影线这么短，肯定有戏！买入！"

---

### 🎯 第 2 类：ClucMay72018 低量突破信号（1 个条件）

**核心逻辑**：成交量萎缩到极致，价格还在跌，那就是"最后一跌"！

**大白话**：
> "成交量已经缩到妈都不认识了（只有平时的34分之一），价格还在创新低？这肯定是"跌不动了"，马上反弹！"

**具体条件**：

```python
dataframe['close'] < dataframe['ema_slow']  # 价格低于 50 周期均线
dataframe['close'] < 0.98863 * dataframe['bb_lowerband']  # 价格跌破布林带下轨
dataframe['volume'] < (dataframe['volume_mean_slow'].shift(1) * 34)  # 成交量极度萎缩
```

**翻译成人话**：
1. 价格要在大趋势的下方（50日均线压制）
2. 价格要跌破布林带下轨约1%（给个缓冲空间）
3. 成交量要萎缩到平时的 34 分之一以下！

**经典台词**：
> "地量地价！成交量这么低还有人卖？肯定卖不动了，准备抄底！"

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **双保险**：两个策略只要满足一个就能入场，成功率更高
2. **跑得快**：1 分钟框架，持仓时间短，资金利用率高
3. **成交量过滤**：ClucMay72018 那个 34 倍的成交量要求真的很严格，能过滤掉大部分假信号
4. **多重保护**：ROI + 追踪止损 + 硬止损，层层保护

### ⚠️ 缺点（吐槽环节）

1. **手续费杀手**：1 分钟框架交易几十次，手续费扣到你肉疼 💸
2. **滑点大户**：你想限价买入？不好意思，可能根本成交不了
3. **魔数太多**：那一堆 0.00703、0.01476、0.03632、34、0.98863...鬼知道怎么调出来的
4. **趋势行情必跪**：这货是均值回归策略，遇到连续上涨或连续下跌会哭死

- 成交量缩多了会反转（地量地价）

**它的赚钱哲学**：
- **不追高**：只做超卖反弹，不追涨
- **等缩量**：没有成交量萎缩的反弹不看
- **跑得快**：赚 1.5% 就跑，绝不恋战

## 十、想跑这个策略？先看看这些配置

### 10.1 交易对配置

|--------|--------|------|

### 10.2 关键参数

```python
minimal_roi = {"0": 0.015}
stoploss = -0.0658
trailing_stop = True
trailing_stop_positive = 0.0198

```

### 10.3 硬件要求（重要！）

这策略是 1 分钟高频交易，对硬件和网络要求极高：

| 项目 | 要求 | 体验 |
|------|------|------|
| **网络延迟** | < 100ms | 越高越容易滑点 |
| **交易所 API 频率** | 符合限制 | 超了会被封 |
| **数据延迟** | < 1秒 | 越大信号越不准 |

**警告**：如果你在用的是垃圾 VPS 或移动网络，就别跑这个策略了，亏得连裤衩都不剩 😅

### 10.4 回测 vs 实盘

**回测时**：
- 假设手续费为 0 或很低
- 假设滑点为 0
- 假设成交都能以回测价格完成

**实盘时**：
- 手续费是实打实的
- 滑点可能吃掉你一半利润
- 限价单可能根本成交不了

**建议流程**：
1. **回测**：用合理的手续费假设（比如 0.1% 每笔）跑历史数据
2. **模拟盘**：至少跑一周实盘模拟，观察滑点和成交率
3. **小资金实盘**：用总资金的 5-10% 测试
4. **优化调整**：根据实盘表现调整参数
5. **正式上线**：确认稳定后再加大仓位

**别一上来就梭哈**，这策略高频交易，每一笔都要命！

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

Combined_Indicators 的历史回测表现看起来"还行"——但这只是因为：

1. **1 分钟框架信号太多**，随便怎么拟合都能跑出好结果
2. **魔数太多**，很容易"正好"拟合了某段历史行情
3. **没算手续费**：很多人回测用 0 手续费，实盘亏成狗

简单说就是：**回测赚不代表实盘赚，历史业绩不代表未来收益**

### 高频策略的隐藏风险

1. **手续费吃利润**：交易 50 次，每次 0.1% 手续费 = 5% 没了
2. **滑点吃利润**：1 分钟框架滑点可能 0.5% 起
3. **API 限流**：高频调用可能被交易所封 IP
4. **心理压力**：一天交易几十次，错了会心态爆炸

### 我的建议（真心话）

```
1. 先用模拟盘跑一个月，观察真实手续费和滑点
2. 设置合理的手续费假设（至少 0.1% 每笔）
3. 小资金测试，别一开始就用全部身家
4. 关注市场环境，震荡期再用，趋势来了就停
5. 准备好止损，这策略遇到极端行情会连续亏损
```

**记住**：高频策略的核心是**稳定**，不是**暴利**。能活下来比赚得快更重要！

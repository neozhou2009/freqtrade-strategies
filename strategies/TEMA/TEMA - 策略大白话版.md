# TEMA 策略：快枪手的布林带舞步

> **外号**：闪电侠  
> **职业**：高频趋势捕手，专吃短线波动  
> **时间框架**：1 分钟（快到飞起）

---

## 一、这策略是个啥？

简单说，**TEMA** 就是一个：
- 快：用三重指数均线，反应速度比普通均线快一倍
- 简：买卖条件就3个，一眼能看懂
- 高频：1分钟时间框架，一天能交易好几次

就像**闪电侠打太极**，动作快得看不清，但招式简单直接。🤣

TEMA 全称是 Triple Exponential Moving Average（三重指数移动平均线），听起来很高级，其实就是"更快的均线"。

## 二、核心配置：说白了就是"见好就收"

### 止盈规则（ROI 表）

```
刚买入       → 4% 就卖
等30分钟     → 2% 就卖
等60分钟     → 1% 就卖
```

**翻译**：
> "赚钱要趁早！刚买进去，4%利润马上跑；拖得越久，止盈越低。时间就是金钱，别贪心！"

这设计很聪明：**短线策略就要快进快出**，拖久了反而容易被套。

### 止损规则

```
固定止损：-10%
追踪止损：开启
```

**翻译**：
> "亏10%就认输，但赚了钱就跟着走。赢家心态：小亏大赚，让利润奔跑。"

## 三、1 个买入条件：TEMA 穿布林带

这策略的买入条件就一个核心，但分3步验证：

### 🎯 买入条件拆解

```python
买入信号：
1. TEMA 在布林带中轨下方（便宜区域）
2. TEMA 正在上升（趋势启动）
3. 有成交量（不是数据问题）
```

**大白话**：
> "TEMA 在布林带中轨下面（价格便宜），然后开始往上走（趋势启动），而且有成交量（不是假突破），就买入！"

**经典台词**：
```
TEMA <= 布林带中轨？
且 TEMA 在上升？
且 成交量 > 0？
→ 买入！
```
> "价格便宜，趋势向上，有人交易，冲！"

---

## 四、卖出逻辑：对称操作

卖出和买入完全对称，就像照镜子：

### 4.1 卖出条件拆解

```python
卖出信号：
1. TEMA 在布林带中轨上方（贵了）
2. TEMA 正在下降（趋势反转）
3. 有成交量
```

**大白话**：
```
TEMA > 布林带中轨？
且 TEMA 在下降？
且 成交量 > 0？
→ 卖出！
```
> "价格贵了，趋势向下，跑！"

### 4.2 这逻辑有个特点

**简单对称**：买入和卖出条件正好相反：
- 买：TEMA 在中轨下，往上走
- 卖：TEMA 在中轨上，往下走

没有花里胡哨的多重条件，就这3个。

## 五、TEMA 是什么鬼？

### 5.1 普通均线的问题

SMA（简单均线）：太慢，价格都跑远了才反应过来
EMA（指数均线）：快一点，但还是有点延迟

**TEMA 的解决方案**：
> "我算三次EMA，把延迟全给消掉！"

### 5.2 TEMA 的秘密

```
TEMA = 3×EMA - 3×EMA(EMA) + EMA(EMA(EMA))
```

**大白话**：
> "第一次EMA消一点延迟，第二次再消一点，第三次彻底消干净！"

**结果**：TEMA 比 EMA 快一倍，能更早发现趋势变化。

### 5.3 用 TEMA 的好处

| 均线类型 | 响应速度 | 噪音 |
|---------|---------|------|
| SMA | 慢吞吞 | 低 |
| EMA | 中等 | 中 |
| **TEMA** | **闪电侠** | 高 |

**翻译**：TEMA 响应快，但容易被小波动骗。所以策略加了布林带中轨来过滤假信号。

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **响应超快**：TEMA 比普通均线快一倍，趋势刚启动就发现了
2. **逻辑超简**：买卖各3个条件，小学生都能看懂
3. **参数可调**：RSI 的买卖阈值可以自动优化
4. **分级止盈**：不贪心，见好就收

### ⚠️ 缺点（吐槽环节）

1. **太快了**：1分钟框架，交易频率高，手续费吃掉不少利润
2. **假信号多**：短线波动大，TEMA 容易被骗
3. **算了没用**：代码里算了一堆指标（ADX、MACD、MFI等），但交易信号根本没用
4. **没趋势过滤**：震荡市里频繁被套，因为没有判断趋势方向的过滤

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

TEMA 的历史回测可能表现不错——但高频策略有大坑：

> **手续费和滑点能吃掉你一半利润，高频不是那么好做的。**

简单说就是：**回测不算手续费，实盘手续费是硬支出。**

### 高频策略的隐藏风险

实盘时要注意：
- **网络延迟**：1分钟框架，几秒延迟可能错过信号
- **滑点累积**：频繁交易，滑点累积起来很恐怖
- **API 限速**：交易所会限制你的请求频率
- **数据异常**：实时数据可能有缺口

### 我的建议（真心话）

```
1. 换成 5 分钟框架：减少交易频率，降低手续费影响
2. 加趋势过滤：配个 ADX 或日线均线，震荡市别用
3. 选低费率交易所：高频交易手续费是大头
4. 轻仓测试：先小仓位验证，别一上来就梭哈
```

**记住**：快枪手虽然帅，但打不准的话子弹（手续费）消耗得很快！

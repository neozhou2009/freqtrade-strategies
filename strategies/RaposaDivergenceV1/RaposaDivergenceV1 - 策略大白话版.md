# RaposaDivergenceV1 策略：背离捕手

> **外号**：反转猎手、峰谷侦探  
> **职业**：专门找背离，抓反转点  
> **时间框架**：5 分钟

---

## 一、这策略是个啥？

简单说，**RaposaDivergenceV1** 就是一个：
- 专门找"背离"信号的策略
- 价格和 RSI 指标走反了？它就进场
- 用数学方法精确找峰谷点

就像一个**拿着放大镜找转折点的侦探** 🔍

### ⚠️ 先说个大坑

作者在代码里写了：
> "argrelextrema might have look-ahead bias so results in backtest will not be reliable"

**翻译**：这个策略回测结果可能不准，因为用了"未来函数"。回测时可能"看到未来"才确认信号，但实盘做不到。

## 二、核心配置：利润目标有点猛

### 止盈规则（ROI 表）

```
0分钟：赚 15% 就跑！
60分钟：赚 2% 也行...
120分钟：赚 1% 也跑
180分钟后：0.1% 都要吃
```

**翻译**：刚开始想赚 15%，等一个小时就只想要 2% 了。期望值降得挺快。

### 止损规则

```
固定止损：-30%（又是 30%...）
追踪止损：利润到 2% 后开始追踪，锁定 1%
```

**翻译**：止损设得挺大，但有追踪止损兜底。

## 三、买入条件：只认底背离

### 核心逻辑（说人话版）

**底背离**是啥意思？
- 价格创新低
- 但 RSI 指标没创新低
- 说明：下跌动能衰竭了，可能要反弹！

**大白话**：
> "价格还在跌，但力度不够了——准备抄底！"

### 买入条件拆解

```python
价格形成更高的低点（底背离）
RSI 也形成更高的低点（确认）
RSI < 50（不在超买区买）
有成交量
```

### 峰谷检测算法

这个策略用了一个叫 `argrelextrema` 的数学函数来找峰谷点。

**大白话**：
> 就像找山脉的最高点和最低点——用数学方法自动识别。"

参数解释：
| 参数 | 默认值 | 大白话 |
|------|--------|--------|
| order | 5 | 左右各看 5 根 K 线，确定是不是峰/谷 |
| K值 | 2 | 需要连续 2 个极值确认，才算真的峰/谷 |

## 六、这策略的"人格特点"

1. **理论扎实**：背离是经典技术分析，不是什么玄学

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

RaposaDivergenceV1 的历史回测表现可能**非常好**——但这有个大坑：

> **argrelextrema 会"看到未来"来确认峰谷点，但实盘做不到。**

简单说就是：**回测是开了天眼的，实盘没有。**

### 未来函数偏差

什么是未来函数？
```
回测时：
  第 100 根 K 线确认是低点，因为第 101、102、103 根 K 线都更高

实盘时：
  第 100 根 K 线刚收盘，你不知道第 101、102、103 根会怎样
```

**后果**：
- 回测信号"精准"出现在最低点
- 实盘信号要等几根 K 线后才能确认
- 错过最佳入场时机

### 我的建议（真心话）

```
1. 把这个策略当学习材料，别指望它赚钱
2. 如果你一定要用，结合其他指标手动确认
3. 止损改成 10-15%，30% 太大了
4. 模拟盘测试，对比回测和实盘的差异
5. 背离信号作为辅助，不要作为唯一依据
```

**记住**：背离策略在趋势转换时很准，但在单边趋势中会被反复打脸。轻仓测试，活着最重要！🙏

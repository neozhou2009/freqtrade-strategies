## 一、策略概览

RaposaDivergenceV1 是一个基于 RSI 背离和价格峰谷检测的趋势反转策略。该策略由 alb#1349 开发，参考了 Raposa Technologies 的技术文章，使用 scipy 的 `argrelextrema` 函数检测价格的局部极值点，结合 RSI 指标的背离信号，在趋势反转点寻找交易机会。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 1 个买入信号，基于底背离检测 |
| **卖出条件** | 1 个卖出信号，基于顶背离检测 |
| **保护机制** | 固定止损 + 追踪止损 + ROI 分级退出 |
| **时间框架** | 5m 主时间框架 |
| **依赖库** | talib, numpy, pandas, scipy, collections |

### ⚠️ 重要提示

策略作者在代码注释中明确指出：
> "argrelextrema" might have look-ahead bias so results in backtest will not be reliable

这意味着该策略在回测中可能存在 **未来函数偏差**，回测结果不可靠，实盘表现可能与回测有较大差异。

## 三、买入条件详解

### 3.1 核心算法：峰谷检测

策略使用 `scipy.signal.argrelextrema` 函数检测价格的局部极值点。这是一个数学方法，通过比较相邻数据点来识别局部最大值和最小值。

```python
# 极值检测函数
from scipy.signal import argrelextrema

# 四种极值模式
- getHigherHighs(): 连续更高的高点
- getLowerHighs(): 连续更低的高点
- getHigherLows(): 连续更高的低点
- getLowerLows(): 连续更低的低点
```

### 3.2 买入信号逻辑

```python
# 买入条件
(dataframe['close_lows'] == -1) &     # 价格形成更高的低点
(dataframe['rsi_lows'] == -1) &       # RSI 形成更高的低点（底背离）
(dataframe['rsi'] < 50) &             # RSI 低于 50
(dataframe['volume'] > 0)             # 有成交量
```

**核心逻辑**：
- 价格形成更高的低点（底背离信号）
- RSI 同时形成更高的低点（确认背离）
- RSI 低于 50（不在超买区买入）

### 3.3 峰谷检测原理

```python
def getHigherLows(data, order=5, K=2):
    """
    检测连续更高的低点
    order: 极值检测窗口大小
    K: 需要确认的连续极值数量
    """
    # 获取所有局部低点
    low_idx = argrelextrema(data, np.less, order=order)[0]
    lows = data[low_idx]
    
    # 确保连续的低点更高
    for i, idx in enumerate(low_idx):
        if lows[i] < lows[i-1]:
            ex_deque.clear()  # 不连续则清空
        ex_deque.append(idx)
        if len(ex_deque) == K:  # 达到 K 个确认
            extrema.append(ex_deque.copy())
```

### 4.2 卖出信号逻辑

```python
# 卖出条件
(dataframe['close_highs'] == 1) &     # 价格形成更低的高点
```

**核心逻辑**：
- 价格形成更低的高点（顶背离信号）
- RSI 同时形成更高的高点（确认背离）

## 六、风险管理特色

### 6.1 背离交易风险

背离交易的本质风险：
- **假背离**：价格和指标可能产生多次背离后才真正反转
- **滞后性**：极值确认需要 K 个连续点，信号滞后
- **未来函数偏差**：argrelextrema 在回测中可能"看到未来"

### 6.2 参数敏感性

| 参数 | 影响 | 建议 |
|------|------|------|
| order | 极值检测窗口，越大越稳定但信号越少 | 5-10 较为平衡 |
| K值 | 确认极值所需数量，越大越可靠但信号越晚 | 2-3 较为合适 |
| rsi_buy/sell | RSI 阈值，影响入场时机 | 根据币种波动性调整 |

2. **卖出信号不可靠**：作者承认卖出信号质量较差
3. **信号频率低**：背离信号不常出现，可能长时间无交易

## 十、重要提醒：回测偏差风险

### 10.1 未来函数偏差

该策略使用的 `argrelextrema` 函数在回测时存在严重问题：

```
在回测中，argrelextrema 可能"看到"未来的数据点来确认当前的极值。
但在实盘中，当前 K 线无法确认是否为极值，需要等待后续数据。
```

**后果**：
- 回测可能显示"完美"的买卖点
- 实盘信号会滞后，错过最佳入场/出场时机
- 回测盈利不等于实盘盈利

### 10.2 建议解决方案

1. **仅作参考**：将背离信号作为辅助判断，不作为唯一入场依据
2. **实盘验证**：使用模拟盘长时间测试，对比回测结果
3. **降低预期**：实盘表现可能显著差于回测

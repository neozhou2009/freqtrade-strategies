## 一、这策略是个啥？

## 二、核心配置：说白了就是"让利润飞"

### 止盈规则（ROI 表）

```python
minimal_roi = {
    "0": 0.10,      # 一入场赚 10% 就跑！
    "30": 0.05,     # 30 分钟后 5% 就跑
    "60": 0.02,     # 60 分钟后 2% 就跑

```

**翻译**：这策略的胃口不小！一入场就想赚 10%，算是"大鱼大肉"型的选手。但随着时间推移，它的期望会降低——30 分钟后觉得赚 5% 也行，1 小时后赚 2% 就满足了。

### 止损规则

```python
stoploss = -0.10  # 亏 10% 就割肉
```

**翻译**：允许你亏 10%，但到了这个数，说明这笔交易已经凉透了，赶紧跑路！

### 追踪止损规则

```python
trailing_stop = True
trailing_stop_positive = 0.005      # 赚 0.5% 开始观察
trailing_stop_positive_offset = 0.030  # 必须涨到 3.0% 才开始"保驾护航"
trailing_only_offset_is_reached = True
```

**翻译**：
- 刚赚 0.5% 时，追踪止损只是"看看"
- 只有继续涨到 3.0%，它才开始认真干活
- 之后如果从最高点跌下来 0.5%，立刻跑路

大白话就是：**先让子弹飞，飞到 3% 了再开始保驾护航！**（比 V6 的 3.5% 更早启动，更积极！）

## 四、8 层保护机制：想亏钱很难

每个买入条件都配了一套保护参数，就像穿了 8 层防弹衣：

| 保护类型 | 作用 | 大白话 |
|---------|------|--------|
| **EMA 快速保护** | 检查快速 EMA 是否在 200 EMA 上方 | "短期趋势向上吗？" |
| **EMA 慢速保护** | 检查 1 小时 EMA 是否健康 | "用望远镜看看远方有没有危险" |
| **收盘价 EMA 保护** | 收盘价要在特定 EMA 上方 | "价格要在安全区" |
| **SMA200 上升趋势** | 200 日均线要上升 | "长期趋势要向上" |
| **SMA200 1h 上升** | 1 小时 200 日均线要上升 | "1 小时长期趋势也要向上" |
| **安全跌入保护** | 检查是否跌得太多 | "别在半山腰抄底！" |
| **安全泵保护** | 检查是否涨得太多 | "别追高被套！" |

这 8 层保护，堪称"相亲查三代家谱"级别的谨慎 🤣

### 安全跌入（Safe Dips）详解

| 类型 | 跌多少算"安全"？ |
|------|-----------------|
| **strict（严格）** | 跌 1.5%/10%/24%/42% 以内才能买 |
| **normal（正常）** | 跌 2%/14%/32%/50% 以内才能买 |
| **loose（宽松）** | 跌 2.6%/24%/42%/80% 以内才能买 |

**大白话**：如果跌太多，策略会说——"兄弟，别急，等跌透了再买！"

### 安全泵（Safe Pump）详解

| 类型 | 24/36/48 小时内涨多少算"不安全"？ |
|------|--------------------------|
| **strict** | 涨超过 42%-84% 不能买 |
| **normal** | 涨超过 60%-110% 不能买 |
| **loose** | 涨超过 66%-200% 不能买 |

**大白话**："涨太多了，别追！等回调！"

**建议流程**：
1. 先跑历史回测，了解策略逻辑
2. 用模拟账户实盘测试 1-2 个月
3. 小仓位实盘验证
4. 根据实盘表现调整参数
5. 逐步增加仓位

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

Combined_NFIv7_SMA 的历史回测表现往往**极其优异**——但这有个陷阱：

> **因为参数众多，策略很容易"拟合"过去行情的最优解，但这并不代表未来一定能盈利。**

简单说就是：**就像考试前背答案，历史考试都满分，但下次考试换了题目就懵了。**

### 复杂策略的隐藏风险

实盘时，复杂的逻辑可能导致：

1. **执行延迟**：信号计算到下单的时间差，可能错过最佳价格
2. **滑点累积**：每个买卖点的微小差异，长期累积成可观的损失
3. **过拟合风险**：参数太多容易"背答案"，实盘表现可能不如回测
4. **计算超时**：老机器可能算不过来，导致信号延迟或丢失
5. **🆕 ZEMA 敏感性**：零滞后 EMA 更灵敏，但也可能产生更多假信号

### 参数优化的陷阱

不要过度优化参数！历史表现最好的参数组合，往往在未来表现最差。原因：

1. **市场在变**：过去有效的模式，未来可能失效
2. **过拟合**：参数优化越精细，越容易"拟合噪音"
3. **幸存者偏差**：回测只看到活下来的交易对，忽略已经下架的

### V7 新增风险

1. **ZEMA 参数敏感**：零滞后 EMA 虽然更灵敏，但可能产生更多假信号
2. **条件 26 自动优化**：自动优化可能导致过拟合历史数据
3. **更积极的追踪止损**：3% 启动比 V6 的 3.5% 更早，可能过早离场

### 我的建议（真心话）

```
1. 用模拟账户至少跑 1-2 个月，不要急于实盘
2. 实盘初期用最小仓位，验证策略表现
3. 关注实际滑点和手续费，回测不会告诉你这些
4. 不要盲目追求高收益，稳定性更重要
5. 定期复盘交易记录，理解策略的失败案例
6. 🆕 对比 V6 和 V7 的实盘表现，选择更适合你市场的版本
```

**记住**：策略再好，市场教做人时也不会打招呼。轻仓测试，活着最重要！🙏

## 一、策略概览

**HarmonicDivergence** 是一个基于多指标背离识别的反转捕捉策略。策略核心思想是：当价格创新低但技术指标未创新低（底背离）时入场，捕捉潜在的趋势反转机会。

"Harmonic"（谐波）在技术分析中常指价格形态的和谐比例关系，"Divergence"（背离）则指价格与指标走势的不一致。策略通过监测多达 11 个技术指标的背离情况，构建多重确认机制，提高信号的可靠性。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 底背离信号 + Keltner Channel 突破确认 |
| **卖出条件** | ROI 分级止盈 + 追踪止损 + 硬止损 |
| **保护机制** | 硬止损 + 追踪止损双重保护 |
| **时间框架** | 15 分钟主框架 |
| **指标覆盖** | 11 个背离检测指标 |
| **依赖库** | TA-Lib, technical (qtpylib) |

## 三、买入条件详解

### 3.1 背离检测核心逻辑

背离交易是技术分析中的经典方法，其理论基础是：

**底背离（买入信号）**：
- 价格创出新低（当前价格 < 前期低点）
- 但技术指标未创新低（当前指标值 > 前期指标低点）
- 这表明下跌动能衰竭，可能即将反转

### 3.2 11 个背离检测指标

策略监测以下 11 个技术指标的背离情况：

| 序号 | 指标名称 | 类别 | 背离检测特点 |
|------|---------|------|-------------|
| 1 | RSI (Relative Strength Index) | 动量指标 | 经典背离指标，超买超卖判断 |
| 2 | Stochastic | 震荡指标 | 敏感度高，适合捕捉短期反转 |
| 3 | ROC (Rate of Change) | 动量指标 | 价格变化速率，识别动能衰减 |
| 4 | Ultimate Oscillator | 综合动量 | 多周期加权，减少假信号 |
| 5 | Awesome Oscillator | 动量指标 | 市场驱动力变化，趋势强度判断 |
| 6 | MACD | 趋势动量 | 柱状图背离，趋势反转确认 |
| 7 | CCI (Commodity Channel Index) | 趋势指标 | 周期性背离，通道位置判断 |
| 8 | CMF (Chaikin Money Flow) | 资金流向 | 量价背离，资金进出判断 |
| 9 | OBV (On-Balance Volume) | 成交量 | 量价背离，验证价格趋势 |
| 10 | MFI (Money Flow Index) | 资金指标 | 量价结合的超买超卖判断 |
| 11 | ADX (Average Directional Index) | 趋势强度 | 趋势强度背离，方向判断 |

### 3.3 过滤条件

策略使用两个通道指标作为过滤条件：

**Keltner Channel**：
- 基于ATR（平均真实波幅）构建的波动通道
- 价格突破通道边界时确认入场信号
- 有效过滤假突破和噪音信号

**Bollinger Bands**：
- 基于标准差构建的波动通道
- 辅助判断价格相对位置
- 在极端波动时提供额外确认

### 3.4 买入信号综合判断

策略的买入逻辑可概括为：

> **多指标背离 + 通道突破确认** —— 当至少一个指标出现底背离，且价格突破 Keltner Channel 时触发买入。

```python
# 伪代码示例
# 背离检测（以 RSI 为例）
price_lower_low = dataframe['close'] < dataframe['close'].shift(n)
rsi_higher_low = dataframe['RSI'] > dataframe['RSI'].shift(n)
divergence = price_lower_low and rsi_higher_low

# 通道突破确认
channel_breakout = dataframe['close'] > dataframe['kc_upper']

# 买入信号
buy_signal = divergence and channel_breakout
```

## 四、卖出逻辑详解

### 4.1 分级止盈系统

策略采用分阶段止盈策略，根据持仓时间递减目标利润：

| 持仓时间 | 目标利润 | 设计意图 |
|---------|---------|---------|
| 立即 | 5% | 快速锁定较大利润 |
| 10 分钟后 | 3% | 逐步降低预期 |
| 30 分钟后 | 2% | 保守锁定 |
| 60 分钟后 | 1% | 时间止损，避免长时间持仓 |

### 4.2 追踪止损机制

```python
trailing_stop = 0.007           # 0.7% 回撤触发追踪
trailing_stop_positive = 0.01   # 盈利 1% 后激活
```

**工作机制**：
1. 当盈利达到 1% 时，追踪止损激活
2. 价格回撤 0.7% 时触发止损
3. 止损价格随最高价动态上移
4. 锁定已获利润，防止盈利回吐

### 4.3 硬止损保护

```python
stoploss = -0.10  # -10%
```

**设计理念**：
- 反转行情波动剧烈，需要一定空间
- 10% 止损相对适中，避免被正常震荡止损
- 与追踪止损形成双重保护

## 五、技术指标体系

### 5.1 核心指标分类

| 指标类别 | 具体指标 | 用途 |
|---------|---------|------|
| **动量指标** | RSI, ROC, Stochastic, Ultimate Oscillator, Awesome Oscillator, MACD | 检测动能衰减，识别背离 |
| **趋势指标** | CCI, ADX | 判断趋势方向和强度 |
| **成交量指标** | CMF, OBV, MFI | 验证价格背离，量价配合分析 |
| **通道指标** | Keltner Channel, Bollinger Bands | 过滤假信号，确认突破 |

### 5.2 指标协同机制

策略的指标体系设计体现了**多维度确认**的理念：

1. **动量维度**：RSI、Stochastic 等检测价格动能变化
2. **趋势维度**：CCI、ADX 判断趋势方向和强度
3. **成交量维度**：CMF、OBV、MFI 验证资金流向
4. **波动维度**：Keltner Channel、Bollinger Bands 确认突破有效性

### 5.3 背离信号优先级

虽然策略监测 11 个指标，但不同指标的背离信号可靠性不同：

| 优先级 | 指标 | 可靠性说明 |
|-------|------|-----------|
| 高 | MACD | 趋势确认，假信号较少 |
| 高 | RSI | 经典指标，历史验证充分 |
| 中 | Ultimate Oscillator | 多周期加权，信号稳定 |
| 中 | CMF | 量价配合，资金流向验证 |
| 低 | Stochastic | 敏感度高，但假信号多 |

| 风险类型 | 建议配置 | 说明 |

| 相关性控制 | 避免同板块 | 背离信号可能同步触发 |

## 七、策略优势与局限

### ✅ 优势

1. **多指标确认**：11 个指标背离检测，信号经过多重验证，可靠性较高
2. **捕捉反转点**：背离是经典反转信号，适合捕捉趋势转折点
3. **维度丰富**：涵盖动量、趋势、成交量三个维度，全面分析市场状态
4. **保护机制完善**：硬止损 + 追踪止损 + 分级止盈，三层保护

### ⚠️ 局限

1. **背离识别复杂**：11 个指标的背离检测需要精确算法，实盘可能存在延迟
2. **假背离风险**：在强趋势中，背离信号可能频繁失效
3. **参数敏感**：背离判断的时间窗口选择对结果影响较大
4. **震荡市场表现一般**：在横盘震荡中，背离信号频繁但不可靠

## 九、适用市场环境详解

HarmonicDivergence 是一个典型的**背离反转策略**。基于其代码架构和背离交易原理，它最适合**趋势反转点**，而在单边趋势或剧烈震荡中表现不佳。

### 9.1 策略核心逻辑

- **底背离捕捉**：价格新低 + 指标未新低 = 潜在反转
- **多指标验证**：11 个指标提高信号可靠性
- **通道过滤**：Keltner Channel 突破确认入场时机

### 9.2 不同市场环境表现

| 市场类型 | 表现评级 | 原因分析 |
| :--- | :--- | :--- |
| 📈 下跌趋势末期 | ★★★★★ | 核心场景，底背离信号准确 |
| 🔄 震荡市场 | ★★☆☆☆ | 假背离频繁，止损压力大 |
| 📉 单边下跌 | ★☆☆☆☆ | 背离信号持续失效 |
| ⚡️ 单边上涨 | ★☆☆☆☆ | 无买入信号，策略空仓 |

### 9.3 关键配置建议

| 配置项 | 建议值 | 说明 |
|--------|--------|------|
| stoploss | -0.08 ~ -0.12 | 根据交易对波动性调整 |
| trailing_stop | 0.005 ~ 0.01 | 反转行情波动大时适当放宽 |
| minimal_roi | 分级递减 | 锁定利润，避免回吐 |

## 十、重要提醒：复杂性的代价

### 10.1 学习成本

HarmonicDivergence 涉及 11 个技术指标的背离判断：
- 需要理解每个指标的含义和适用场景
- 需要掌握背离识别的算法实现
- 需要理解不同指标背离信号的可靠性差异

对于新手交易者，建议先掌握 RSI 和 MACD 两个核心指标的背离判断，再逐步扩展到其他指标。

### 10.3 回测与实盘的差异

**注意事项**：
- 回测中的背离识别可能过于理想化
- 实盘中指标计算存在延迟
- Keltner Channel 突破确认可能出现滑点

### 10.4 手动交易者建议

如果想手动运用此策略的思路：
1. 先观察价格是否创出新低
2. 检查 RSI 或 MACD 是否出现背离
3. 等待价格突破近期阻力位确认
4. 严格执行止损，背离失败率较高

## 十一、总结

**HarmonicDivergence** 是一个专注于背离交易的反转捕捉策略。它的核心价值在于：

1. **多维度背离检测**：11 个指标覆盖动量、趋势、成交量三个维度，提高信号可靠性
2. **经典技术形态**：背离是技术分析中经过长期验证的反转信号
3. **完善保护机制**：硬止损 + 追踪止损 + 分级止盈，三层风险控制

对于量化交易者而言，HarmonicDivergence 是一个典型的背离策略模板，适合在趋势反转点寻找入场机会。但需注意背离信号的假突破风险，建议配合其他趋势确认指标使用，并严格执行仓位管理。

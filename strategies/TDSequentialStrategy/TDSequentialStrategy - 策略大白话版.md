## 一、这策略是个啥？

简单说，**TDSequentialStrategy** 就是一个：
- 数数党：数到9就反转
- 反转猎手：专门抓趋势"累不动"的时候
- 完美主义者：光数到9还不够，还要验证"完美条件"

就像**数九寒冬**，数着数着天就暖了。这策略也一样，数着价格连续下跌/上涨，数到第9根K线时，它就觉得：该反转了！🤣

---

## 二、核心配置：说白了就是"小止损+追踪止盈"

### 止盈规则（ROI 表）

```
目标收益：500%（基本就是摆设）
```

**翻译**：这ROI设置纯属虚设，真要等到500%才卖，黄花菜都凉了。策略实际上靠信号卖出，不是靠ROI。

### 止损规则

```
固定止损：-5%
追踪止损：开启
盈利才卖：是的
```

**翻译**：亏5%就认怂跑路，赚了钱就跟着趋势走，让利润奔跑。而且有个脾气：亏损的时候不响应卖出信号，必须盈利才卖。

---

## 三、1 个买入条件：数到9就买

这策略的买入条件很独特，就一个核心：**TD Sequential 序列完成**。

### 🎯 唯一的买入条件

**核心逻辑**：连续9根K线的收盘价都低于4根K线前的收盘价

**大白话**：
> "第1根K线收盘价比第-3根低，第2根比第-2根低...数到第9根的时候，如果每次都比4根前的那根低，那就是买入信号！"

**但还有个"完美条件"**：
> "第8或第9根K线的最低点，必须低于第6或第7根K线的最低点。这就像说：跌得不够深，我不买！"

**经典台词**：
```
收盘价 < 4根前收盘价，连续9次？
且 第8/9根最低点 < 第6/7根最低点？
→ 买入！
```
> "跌了这么久，该反弹了吧？不过跌得不够狠我可不买哦~"

---

## 四、卖出逻辑：对称操作

### 4.1 卖出条件

卖出和买入完全对称：
- **序列完成**：连续9根K线收盘价高于4根前
- **完美条件**：第8/9根最高点高于第6/7根最高点

**大白话**：
```
收盘价 > 4根前收盘价，连续9次？
或 第8/9根最高点 > 第6/7根最高点？
→ 卖出！
```
> "涨了这么久，该回调了吧？见好就收！"

### 4.2 有趣的脾气

```python
sell_profit_only = True  # 盈利才卖
```

**大白话**：
> "亏钱的时候我不卖，必须等赚钱了才走。万一后面涨回来呢？"

这脾气有点固执，但也算是一种保护机制。

## 五、TD Sequential 理论：何方神圣？

TD Sequential 是技术分析大神 **Tom DeMark** 发明的系统，在华尔街和加密货币圈都很有名。

### 5.1 核心思想

**人话版**：
- 趋势不可能永远持续
- 连续下跌/上涨到一定程度，就该休息了
- 数到9就是"疲劳信号"

### 5.2 为什么数"9"？

Tom DeMark 发现：
- 连续9根K线朝同一方向运动后，反转概率增加
- 这不是玄学，是统计规律
- 很多交易者用这个系统，形成了"自我实现预言"

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **理论扎实**：Tom DeMark 的大名号，不是随便发明的指标
2. **逻辑简洁**：就是数数+验证，小学生都能看懂
3. **反转专精**：专门抓"物极必反"的转折点
4. **代码量小**：没有一大堆参数，不容易过拟合

### ⚠️ 缺点（吐槽环节）

1. **趋势市场要命**：单边行情里，它会在半路不断喊"反转"，然后被打脸
2. **数数会中断**：任何一根K线不满足条件，计数就清零，白数了
3. **滞后性**：要等第9根K线走完才进场，黄花菜都快凉了
4. **单一时间框架**：只看1小时，没有大周期确认

## 八、总结：这策略到底咋样？

### 一句话评价
> "震荡市场的神，趋势市场的坑。会用的赚钱，不会用的亏钱。"

### 适合谁用？
- ✅ 熟悉 TD Sequential 理论的老手
- ✅ 做震荡市场的高频交易者
- ✅ 喜欢简洁逻辑的策略开发者
- ✅ 反转变易爱好者

### 不适合谁？
- ❌ 单边趋势的死多头
- ❌ 不喜欢等待的急性子
- ❌ 想要复杂多条件过滤的人
- ❌ 只想做多不想做空的单向玩家

### 我的建议
1. **先观察市场**：确认当前是震荡还是趋势，震荡用它，趋势别用
2. **配合趋势过滤**：加一个大周期均线，只顺着大趋势方向做反转
3. **调整止损**：5%止损可能太紧，波动大的币种可以放宽到7-10%
4. **耐心等待**：序列计数需要时间，不要急着进场

## 十一、彩蛋：策略作者的"小心思"

看代码，发现一些有趣的设计：

1. **"完美条件"的名字**：代码里叫 `exceed_low` 和 `exceed_high`，翻译过来是"突破低点"和"突破高点"
   > "我虽然数到9了，但价格跌得不够狠，我不买！"

2. **序列中断清零**：任何一根K线不满足条件，计数器直接归零
   > "哎呀，断了，重新数。1、2、3..."

3. **启动只需30根K线**：`startup_candle_count: int = 30`
   > "给我30根K线，我就能开始干活了"

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

TDSequentialStrategy 的历史回测可能表现不错——但要注意：

> **反转策略最大的坑：趋势市场里频繁被套。**

简单说就是：**单边行情里，它就是个反向指标。**

### 复杂策略的隐藏风险

实盘时要注意：
- **序列中断**：实时K线可能让序列中断，错过信号
- **滞后性**：等第9根K线走完，价格可能已经反弹了
- **假信号**：震荡不够剧烈时，反转可能失败

### 我的建议（真心话）

```
1. 先判断市场类型：震荡用，趋势不用
2. 配合大周期确认：加一个日线均线，只顺着大势做
3. 放宽止损：5%可能太紧，7-10%更安全
4. 轻仓测试：先小仓位验证，别一上来就重仓
```

**记住**：数到9就反转？市场说：未必！

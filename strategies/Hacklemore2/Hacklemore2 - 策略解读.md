## 一、策略概览

**Hacklemore2** 是一个基于 RMI（Relative Momentum Index）、SAR（抛物线转向指标）和趋势突破的趋势跟踪策略。策略核心思想是：在明确的上升趋势中，当 RMI 走强且价格创出近期新高时买入，通过多指标确认来提高信号的可靠性。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 上升趋势 + RMI 强势 + SAR 确认 + 三连阳 + 成交量过滤 |
| **卖出条件** | 下降趋势 + RMI 弱势 + 订单簿动态止盈 |
| **保护机制** | 追踪止损 + 硬止损 + ROI 分级止盈 |
| **时间框架** | 15 分钟 |
| **依赖库** | TA-Lib, technical (RMI, qtpylib) |

## 三、买入条件详解

### 3.1 核心买入逻辑

策略采用五重确认机制，所有条件必须同时满足：

| 条件编号 | 条件名称 | 逻辑描述 |
|---------|---------|---------|
| 条件 1 | 上升趋势确认 | `up_trend == True`（60 天新高） |
| 条件 2 | RMI 强势 | `RMI > 55` 且 `RMI >= RMI.rolling(3).mean()` |
| 条件 3 | 价格三连阳 | `close > close.shift() > close.shift(2)` |
| 条件 4 | SAR 确认 | `sar < close`（价格在 SAR 上方） |
| 条件 5 | 成交量过滤 | `volume < volume_ma * 30` |

### 3.2 买入条件详解

#### 条件 #1：上升趋势确认
```python
dataframe['up_trend'] == True
# 基于 60 天新高判断
```

**逻辑解析**：
- 通过价格创出 60 天新高来确认上升趋势
- 确保只在趋势明确时进场
- 避免在震荡或下跌市场中频繁交易

#### 条件 #2：RMI 强势
```python
(dataframe['RMI'] > 55) & (dataframe['RMI'] >= dataframe['RMI'].rolling(3).mean())
```

**逻辑解析**：
- RMI（Relative Momentum Index）是 RSI 的变体，更注重动量变化
- RMI > 55 表明动量处于强势区域
- RMI 高于其 3 周期均值，确认动量正在增强

#### 条件 #3：价格三连阳
```python
dataframe['close'] > dataframe['close'].shift(1) > dataframe['close'].shift(2)
```

**逻辑解析**：
- 连续三根阳线表明买方力量持续
- 短期动能向上，增加入场成功率
- 简单有效的趋势延续信号

#### 条件 #4：SAR 确认
```python
dataframe['sar'] < dataframe['close']
```

**逻辑解析**：
- 抛物线转向指标（SAR）位于价格下方
- 确认当前处于上升趋势
- 提供额外的趋势方向验证

#### 条件 #5：成交量过滤
```python
dataframe['volume'] < dataframe['volume_ma'] * 30
```

**逻辑解析**：
- 成交量不应异常放大
- 避免在极端行情（如突发新闻）中入场
- 正常成交量环境更有利于趋势延续

### 3.3 买入信号综合判断

策略的买入逻辑可概括为：
> **不见趋势不进场** —— 当价格创出 60 天新高、RMI 动量走强、SAR 确认上升趋势，且出现三连阳时，才考虑入场。

## 五、技术指标体系

### 5.1 核心指标

| 指标类别 | 具体指标 | 用途 |
|---------|---------|------|
| **动量指标** | RMI (Relative Momentum Index) | 判断动量强弱和方向 |
| **趋势指标** | EMA | 确认趋势方向 |
| **反转指标** | SAR (Parabolic SAR) | 趋势反转确认 |
| **趋势判断** | 60 天新高 | 确认上升趋势 |
| **成交量** | Volume MA | 过滤异常成交量 |

### 5.2 RMI 指标详解

**RMI（Relative Momentum Index）** 是 RSI 的变体：

- 传统 RSI 计算价格变化，RMI 计算动量变化
- 相比 RSI，RMI 对趋势变化更敏感
- 参数设置：通常使用默认周期
- 超买区域：RMI > 70
- 超卖区域：RMI < 30
- 强势区域：RMI > 55（本策略使用）

### 5.3 SAR 指标详解

**抛物线转向指标（Parabolic SAR）**：

- 用于判断趋势方向和反转点
- SAR 在价格下方：上升趋势
- SAR 在价格上方：下降趋势
- 本策略使用 SAR 作为趋势确认

## 六、风险管理特色

### 6.1 追踪止损机制

```python
trailing_stop = True
trailing_stop_positive = 0.02
trailing_stop_positive_offset = 0.03
```

**设计理念**：
- 当利润达到 2% 时启动追踪止损
- 追踪偏移量 3%，给予一定回调空间
- 有效保护已有利润，同时不过早被震出局

### 6.2 硬止损保护

```python
stoploss = -0.10  # -10%
```

**设计理念**：
- 适中止损幅度，适合趋势策略
- 给予足够的波动空间
- 避免"止损后立即反弹"的尴尬

### 6.3 ROI 分级止盈

| 保护层 | 作用 |
|--------|------|
| ROI 分级 | 根据持仓时间逐步降低目标 |
| 追踪止损 | 保护已有利润 |
| 硬止损 | 最后防线 |

## 七、策略优势与局限

### ✅ 优势

1. **多指标确认**：RMI + SAR + 三连阳 + 成交量过滤，信号可靠
2. **趋势跟踪能力强**：只在趋势明确时入场，胜率较高
3. **风险控制完善**：追踪止损 + 硬止损 + ROI 分级，多层保护
4. **逻辑清晰**：买入和卖出条件明确，易于理解和调整

### ⚠️ 局限

1. **震荡市场表现一般**：趋势策略的通病，震荡市中信号较少或易被止损
2. **入场机会有限**：多条件确认导致入场机会较少
3. **参数依赖**：RMI、SAR 参数需要根据不同交易对调整
4. **滞后性**：60 天新高确认存在滞后，可能错过最佳入场点

### 9.1 策略核心逻辑

- **不见趋势不进场**：通过 60 天新高确认趋势

- **成交量过滤**：避免极端行情

**Hacklemore2** 是一个专注于趋势跟踪的策略。它的核心价值在于：

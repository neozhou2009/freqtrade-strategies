> **外号**：反弹预判大师、三头六臂  
> **职业**：带着望远镜的反弹猎手

## 一、这策略是个啥？

简单说，**Schism3** 就是一个：
- 先观察"可能会反弹"，记录价格
- 等价格真的回升了才入场
- 如果你用 BTC/ETH 做抵押货币，还能自动检查大币走势

就像一个**不下单则已，一下单就要确认反弹的老猎手** 🎯

**最骚的是**：它有三个版本！
- Schism3：基础版（5分钟+1小时）
- Schism3_BTC：BTC 抵押专用（1小时+4小时）
- Schism3_ETH：ETH 抵押专用（1小时+4小时）

```
刚买：赚 5% 就跑

**翻译**：这策略挺能熬，持仓一天都不慌。

```

**翻译**：**30%！** 没错，这策略给足了波动空间，有点"我就不信你不涨"的执念 😅

## 三、买入条件：这策略最骚的"反弹预判"

这策略的买入条件分三步走，我给你拆解：

### 🎯 第一步：反弹预检测

策略会先问这些问题：

```python
1h_rsi >= 37        # 大周期不太烂
rmi-dn-trend == 1   # 确实在下跌
rmi-slow >= 35      # 但没跌过头
rmi-fast <= 28      # 快速指标有点低
mp <= 60            # 动量不高
```

**大白话**：
> "看起来要反弹了，先记住这个价格"

### 📝 第二步：记录反弹价格

```python
bounce-price = 如果有反弹信号，就记录当前价格
              否则取最近8根K线的最低价
```

**大白话**：
> "就把这个价格记在小本本上，等会看它涨不涨"

### ✅ 第三步：确认入场

真正买入需要这些条件：

```python
1h_rsi >= 59              # 大趋势向上
8周期内有反弹信号          # 信号还在
rmi-up-trend == 1         # RMI 转向上升了
close >= bounce-price     # 价格真的回升了！
```

**大白话**：
> "信号有了，趋势也对了，价格还回升了，下单！"

## 七、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **反弹预判**：先记录信号价格，确认回升才入场，不抄半山腰
2. **多货币支持**：自动适配 BTC/ETH 抵押，看大币脸色
3. **三个版本**：基础版、BTC版、ETH版，一套代码三种用法
4. **参数可覆盖**：按币种组定制参数

### ⚠️ 缺点（吐槽环节）

1. **30% 止损**：有点松，可能扛很久才止损
2. **多数据源**：需要额外的 BTC/USD、COIN/USD 数据
3. **复杂度高**：反弹系统 + 多货币条件，头大
4. **回测困难**：多货币条件在回测要额外配置

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

Schism3 的 30% 止损看起来很宽容——但这有个陷阱：

> **30% 止损意味着你可能承受很大的浮亏！**

简单说就是：**这策略能扛，但你能扛吗？**

### 复杂策略的隐藏风险

实盘时，复杂的逻辑可能导致：
- **多货币数据**：BTC/ETH 数据缺失会导致策略失效
- **反弹确认失败**：价格回升后又跌回去
- **止损触发晚**：30% 止损可能让你扛很久
- **信号频繁**：震荡市场可能触发很多假信号

### 我的建议（真心话）

```
1. 先调整止损到 -0.15 到 -0.20
2. 确保多货币数据源配置正确
3. dry-run 至少两周观察信号质量
4. 小资金实盘测试反弹确认效果
```

**记住**：反弹预判再智能，市场教做人时也不会打招呼。轻仓测试，活着最重要！🙏

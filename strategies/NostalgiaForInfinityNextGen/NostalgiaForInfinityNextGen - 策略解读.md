## 一、策略概览

**NostalgiaForInfinityNextGen**（简称 NFI NextGen）是 NostalgiaForInfinity（NFI）系列的"新一代"演进版本。作为 NFI Next 的进一步优化版本，NextGen 在继承原版核心多条件架构的基础上，针对中周期交易进行了全面适配和策略精简。

"NextGen" 这个命名寓意着"下一代"，体现了策略作者对 Next 版本的持续优化和对中周期交易特性的专门适配。相比 Next 版本，NextGen 采用 15 分钟时间框架，买入条件更加精炼，更适合中长期趋势跟踪。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 21 个独立买入信号，每个条件可独立启用/禁用 |
| **卖出条件** | 6 个基础卖出信号 + 多层动态止盈逻辑 |
| **保护机制** | 21 组买入保护参数（EMA/SMA/安全下跌/安全上涨/BTC趋势） |
| **时间框架** | 15 分钟主时间框架 + 1 小时信息时间框架 |
| **依赖库** | pandas, numpy, TA-Lib, technical, qtpylib, pandas_ta |

**设计思路**：
- 采用**时间递减 ROI** 策略，持仓时间越长，退出门槛越低
- 首级 ROI 10%，追求较高收益目标
- 15 分钟框架下持仓周期相对更长，适合捕捉中短期趋势
- 配合**追踪止损**锁定利润，适合趋势行情
- 硬止损 -10% 控制单笔最大亏损

## 三、买入条件详解

### 3.1 保护机制（21 组）

每个买入条件都配有独立的保护参数组，包括：

| 保护类型 | 参数说明 | 选项 |
|---------|---------|------|
| **EMA 快速** | 快速 EMA 是否启用及其长度 | 26/50/100/200 |
| **EMA 慢速** | 慢速 EMA 是否启用及其长度 | 26/50/100/200 |
| **收盘价保护** | 收盘价是否在 EMA 之上 | 12/20/26/50/100/200 |
| **SMA200 上升** | SMA200 是否处于上升趋势 | 20/30/36/44/50 周期验证 |
| **SMA200 1h 上升** | 1h 周期 SMA200 趋势确认 | 20/30/36/44/50 |
| **安全下跌** | 下跌幅度阈值保护 | 10/50/80/100/130 等 |
| **安全上涨** | 上涨幅度阈值保护（防追高） | 10/20/30/50/70/100/120 等 |
| **安全上涨周期** | 检测周期 | 24h/36h/48h |
| **BTC 趋势** | BTC 1h 是否非下跌趋势 | True/False |

## 四、卖出逻辑详解

### 4.1 多层止盈系统

策略采用**分级止盈**机制，根据利润率动态调整退出条件：

```
利润率区间          阈值        退出策略
────────────────────────────────────────
> 10%              立即        ROI 首级退出
5%-10%             30 分钟     ROI 次级退出
2%-5%              60 分钟     ROI 三级退出
< 2%               持仓        等待信号或止损
```

### 4.2 特殊卖出场景

| 场景 | 触发条件 | 信号名称 |
|------|---------|---------|
| **布林带上轨突破** | 连续突破上轨 | 超买退出 |
| **RSI 极端** | RSI 超买阈值 | 动量退出 |
| **EMA 下方** | 价格跌破 EMA200 | 趋势退出 |
| **追踪止损** | 利润回撤触发 | 保护退出 |

## 六、风险管理特色

### 6.1 多级下跌保护（Safe Dips）

从 10 到 130 级别的下跌阈值保护，适应不同市场环境：

```
级别    保护强度    适用场景
────────────────────────────
10      宽松        强趋势行情
50      中等        一般市场
80      较严格      波动市场
100     严格        高风险环境
130     极严格      极端行情
```

### 6.2 多级上涨保护（Safe Pump）

防止追高的多层保护机制：

- 检测周期：24h / 36h / 48h
- 级别范围：10 - 130
- 与下跌保护配合使用

### 6.3 BTC 趋势过滤

部分买入条件要求 BTC 1h 非下跌趋势：

- 防止在 BTC 大跌时买入山寨币
- 降低系统性风险
- 条件 19-20 默认启用此保护

## 七、策略优势与局限

### ✅ 优势

1. **条件精炼**：21 个买入条件覆盖主要市场环境，比 Next 版本更聚焦
2. **周期适配**：15 分钟框架更适合中短期趋势跟踪
3. **保护完善**：21 组保护参数，精细化风险管理
4. **多周期验证**：15m 执行 + 1h 趋势确认
5. **灵活配置**：每个条件可独立启用/禁用
6. **计算效率**：条件精简后计算效率更高

### ⚠️ 局限

1. **信号频率**：15 分钟框架下信号频率相对较低
2. **反应延迟**：比 5 分钟版本反应稍慢
3. **依赖历史数据**：需要充足的 1h 和 15m 历史数据
4. **学习曲线**：理解所有条件仍需要时间

NostalgiaForInfinityNextGen 是 NFI 系列的新一代优化版本。基于其代码架构和社区长期实盘验证的经验，它最适合 **有明显趋势的中长期行情**，而在单边暴跌或极端横盘时表现受限。

## 十、重要提醒：复杂性的代价

### 10.1 学习成本

虽然 NextGen 相比 Next 版本条件精简了，但仍有 21 个买入条件需要理解。建议先从部分条件开始熟悉。

### 10.2 硬件要求

| 交易对数量 | 最低内存 | 推荐内存 |
|-----------|---------|---------|
| 20-40 对 | 2GB | 4GB |
| 40-60 对 | 4GB | 8GB |
| 60+ 对 | 8GB | 16GB |

### 10.3 回测与实盘的差异

NFI 包含动态调仓功能，这些逻辑在普通回测中难以完全模拟。建议先使用模拟交易（Dry-Run）运行 1-3 个月。

### 10.4 手动交易者建议

适合在**大盘站上 MA20 且均线多头排列**时开启；如果全自动运行，建议开启**比特币趋势过滤**功能。15 分钟框架下，持仓周期相对较长，适合中短期趋势跟踪。

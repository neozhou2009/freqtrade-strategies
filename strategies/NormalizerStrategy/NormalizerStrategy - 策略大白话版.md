# NormalizerStrategy 策略：把价格变成"分数"的均值回归猎手

> **外号**："打分员"、"均值回归专业户"  
> **职业**：专找价格"走极端"的交易机会  
> **时间框架**：1 小时（不急不躁，刚刚好）

---

## 一、这策略是个啥？

简单说，**NormalizerStrategy** 就是一个：
- 把价格变成 0 到 100 的"分数"
- 分数太低就买，分数太高就卖
- 等价格回到"正常水平"就赚钱

就像你考试考了 10 分，下次大概率会考好一点；考了 98 分，下次大概率会差一点——这就是**均值回归**！🎯

**这策略的核心思想**：极端的不会一直极端，价格总会回归"正常"。

---

## 二、核心配置：说白了就是"要么赚 18%，要么死扛"

### 止盈规则（ROI 表）

```
赚够 18% → 立刻跑，不墨迹！
```

**翻译**：这策略的目标很明确——一笔交易就要赚够 18%。不像那些赚 5% 就跑的"短线小能手"，这是个"一票大的"选手！💰

### 止损规则

```
亏损 -99% 才止损
```

**翻译**：兄弟们，这几乎等于**不止损**啊！意思是：买了就得扛着，要么赚 18%，要么... 你懂的 🫠

**吐槽**：这策略设计者的心态可能是："均值回归一定会发生的，只是时间问题"——但市场有时候会教你做人 😅

---

## 三、买入条件：分数太低就抄底

这策略的买入逻辑超级简单，就一句话：

### 📉 归一化价格 < 买入阈值 = 开干！

**啥叫归一化？**

打个比方：
- 比特币最近 30 天价格区间是 50,000 到 70,000 美元
- 现在价格是 52,000 美元
- 归一化分数 = (52000 - 50000) / (70000 - 50000) = 0.1（也就是 10 分）

**这个 10 分意味着什么？**
- 当前价格在最近 30 天的"地板"附近
- 属于"便宜"的价格
- 策略会说："机会来了，买！"

**经典台词**：
> "当前价格归一化值 0.15，低于买入阈值 0.2，抄底！"

---

## 四、卖出逻辑：两种方式赚钱走人

### 4.1 第一种：赚够 18% 就跑

这是最开心的结局：
```
买入价 100
目标价 118
达到 → 拜拜了您嘞！🎉
```

### 4.2 第二种：价格回归高位

归一化价格涨上去了（比如从 0.1 涨到 0.85）：
```
买入时归一化值：0.1（地板）
卖出时归一化值：0.85（天花板附近）
→ 价格回到高位，走人！
```

**大白话**：买在地板，卖在天花板附近，这就是均值回归的精髓！

## 五、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **简单明了**：不像 Nostalgia 那样有 39 个买入条件，这策略就一个核心概念——归一化分数！
2. **通用性强**：比特币 6 万也好，狗狗币 0.1 也罢，归一化后都是 0-1，一视同仁！
3. **逻辑有道理**：均值回归是金融市场的经典现象，不是瞎蒙的
4. **交易成本低**：不频繁交易，省手续费

### ⚠️ 缺点（吐槽环节）

1. **不止损**：-99% 止损约等于没有！极端行情能亏到怀疑人生 🫠
2. **信号少**：极端价格不常出现，可能半个月都不交易一次
3. **怕趋势**：要是遇到单边大牛市或大熊市，均值回归策略就是个反向指标
4. **一锤子买卖**：要么赚 18%，要么... 很难有中间地带

## 七、总结：这策略到底咋样？

### 一句话评价
> "逻辑清晰，设计简洁，但止损设置太狂野——要么赚钱走人，要么扛到地老天荒！"

### 适合谁用？
- ✅ 能承受较大回撤的老手
- ✅ 相信均值回归的"信仰者"
- ✅ 有耐心等待信号的人
- ✅ 交易对处于震荡期

### 不适合谁？
- ❌ 新手（不止损 = 送钱）
- ❌ 风险厌恶者
- ❌ 想天天交易找刺激的人
- ❌ 资金量小承受不起波动的人

### 我的建议
1. **修改止损**：-99% 太狂了，改成 -10% 或 -15% 比较靠谱
2. **加个趋势过滤**：配合 EMA，趋势太强就别逆势
3. **降低止盈目标**：18% 有点高，可以考虑 10% 左右
4. **先回测再实盘**：别一上来就真金白银，先看看历史表现

## 八、这策略在什么市场能赚钱？

### 8.1 核心逻辑：打分数，抄底逃顶

NormalizerStrategy 的核心就是**归一化**——把价格变成 0-100 的分数。

**赚钱哲学**：
- 价格不会永远在极端位置
- 0 分附近买，100 分附近卖
- 赚的是"回归"的钱

**类比**：
> 就像你炒股，不可能天天涨停，也不可能天天跌停。
> 低迷一段时间后会反弹，火爆一段时间后会回调。
> 这策略就是抓住这个规律！

| 📉 慢熊下跌 | ⭐⭐☆☆☆ | 价格一直创新低，归一化区间失效 |
| ⚡️ 暴涨暴跌 | ⭐☆☆☆☆ | 灾难！区间被打破，地板下面还有地下室 |

**一句话总结**：震荡是它的主场，趋势是它的噩梦！

## 九、想跑这个策略？先看看这些配置

### 9.1 归一化参数设置

| 配置项 | 建议值 | 吐槽 |
|--------|--------|------|
| 归一化周期 | 30-50根K线 | 太短不稳定，太长反应慢 |
| 买入阈值 | 0.15-0.25 | 分数低于 15-25 分才买，够极端！ |
| 卖出阈值 | 0.75-0.85 | 分数高于 75-85 分就跑，不贪 |

### 9.2 风控配置（重要！）

```yaml
# 强烈建议修改的配置
stoploss: -0.10  # 改成 -10%，别用原版的 -99%！
minimal_roi: {"0": 0.10}  # 10% 止盈，比 18% 更现实

# 仓位控制
max_open_trades: 2  # 别同时开太多仓
stake_amount: 100   # 固定金额，别梭哈
```

### 9.3 硬件要求（很友好！）

| 交易对数量 | 最低内存 | 推荐内存 | 体验 |
|-----------|---------|---------|------|
| 1-5 对 | 1GB | 2GB | 丝滑 |
| 5-20 对 | 2GB | 4GB | 没问题 |
| 20+ 对 | 4GB | 8GB | 稳得很 |

**好消息**：这策略计算量超级小，几百块一年的 VPS 就能跑，不像那些动不动就 100+ 条件的重型策略！

### 9.4 回测 vs 实盘

**回测看起来很美好**：历史数据上，极端价格总是会回归的...

**实盘的坑**：
- 实时计算的归一化区间可能不稳定
- 极端行情下，地板下面还有地下室
- 流动性枯竭时，想卖都卖不掉

**建议流程**：
1. 先回测看历史表现
2. 用模拟盘跑一个月
3. 小资金实盘测试
4. 确认可行再加大仓位

**别一上来就梭哈**，再好的策略也要磨合！

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

NormalizerStrategy 在历史回测中可能表现不错——因为历史数据上价格确实会均值回归。但这有个陷阱：

> **过去回归不代表未来一定回归！**

简单说就是：**历史告诉你的"答案"，考试不一定考！**

### 极宽止损的隐藏风险

原版策略的 -99% 止损，听着就吓人：

- **极端行情**：单边暴跌时，可能真亏到 -99%
- **归零风险**：某些山寨币可能直接归零，连止损的机会都没有
- **心理压力**：扛单的心理压力不是一般人能承受的

### 复杂策略的隐藏风险

虽然这策略看起来简单，但也有坑：

- **区间失效**：暴涨暴跌后，原有的价格区间被打破，归一化参数要重新调整
- **信号稀少**：可能几周都没有一个交易信号，资金利用率低
- **趋势风险**：遇到单边趋势，均值回归就是个反向指标

### 我的建议（真心话）

```
1. 修改止损！改成 -10% 到 -15%，别用 -99%！
2. 降低止盈目标，10% 就很香了
3. 配合趋势过滤器，趋势太强就别逆势
4. 先用小资金测试，别上来就梭哈
5. 定期检查策略表现，不对就停
```

**记住**：策略再好，市场教做人时也不会打招呼。轻仓测试，活着最重要！🙏

**最后一句**：归一化是个好思路，但风险管理才是盈利的关键。别让"均值回归"变成"均值归零"！💀

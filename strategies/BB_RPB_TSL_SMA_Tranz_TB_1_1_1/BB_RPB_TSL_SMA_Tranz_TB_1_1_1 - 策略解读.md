## 一、策略概览

BB_RPB_TSL_SMA_Tranz_TB_1_1_1 是 BB_RPB_TSL_SMA_Tranz 策略的增强版本，在原有基础上增加了**追踪买入（Trailing Buy）**和**追踪卖出（Trailing Sell）**机制。策略名称拆解为：

- **BB**: Bollinger Bands（布林带）
- **RPB**: Real Pull Back（真实回调）
- **TSL**: Trailing Stop Loss（追踪止损）
- **SMA_Tranz**: SMA 变换模块
- **TB_1_1_1**: Trailing Buy 版本 1.1.1

该策略通过追踪买入机制，在信号触发后等待更好的入场价格，从而降低持仓成本。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 继承父策略 52 个买入信号 + 追踪买入机制 |
| **卖出条件** | 8 个基础卖出信号 + 追踪卖出机制 |
| **保护机制** | BTC 防护、Pump 防护、Dip 防护、滑点控制 |
| **时间框架** | 5m 主时间框架 + 15m/1h 信息时间框架 |
| **特色功能** | 追踪买入、追踪卖出、自定义止损 |
| **依赖库** | pandas_ta, talib, technical |

## 三、追踪买入机制详解

### 3.1 工作原理

追踪买入机制的核心思想是：**信号触发后不立即买入，而是等待价格回调到更优位置再入场**。

```
信号触发 → 开始追踪 → 价格下跌 → 买入执行
                    → 价格上涨超阈值 → 取消追踪
                    → 超时 → 按当前价格买入
```

### 3.2 追踪状态管理

```python
init_trailing_buy_dict = {
    'trailing_buy_order_started': False,     # 追踪是否开始
    'trailing_buy_order_uplimit': 0,         # 追踪上限价格
    'start_trailing_price': 0,               # 起始追踪价格
    'buy_tag': None,                         # 买入标签
    'start_trailing_time': None,             # 追踪开始时间
    'offset': 0,                             # 偏移量
    'allow_trailing': False,                 # 是否允许追踪
}
```

### 3.3 追踪买入优势

| 场景 | 传统买入 | 追踪买入 |
|------|---------|---------|
| 信号触发后下跌 | 按信号价格买入 | 等待更低价格买入 |
| 信号触发后上涨 | 按信号价格买入 | 可能取消或追高买入 |
| 信号触发后震荡 | 按信号价格买入 | 在震荡低点买入 |

## 四、追踪卖出机制详解

### 4.1 工作原理

追踪卖出机制的核心思想是：**卖出信号触发后不立即卖出，而是等待价格反弹到更优位置再出场**。

```
卖出信号触发 → 开始追踪 → 价格上涨 → 卖出执行
                       → 价格下跌超阈值 → 取消追踪
                       → 超时 → 按当前价格卖出
```

## 八、风险管理特色

### 8.1 四重保护机制

| 保护类型 | 参数说明 | 作用 |
|---------|---------|------|
| **BTC 防护** | BTC 下跌超过阈值时禁止买入 | 防止系统性风险 |
| **Pump 防护** | 检测异常拉升，避免追高 | 防止追高被套 |
| **Dip 防护** | 多级跌幅检测，避免接飞刀 | 等待稳定再入场 |
| **滑点控制** | 限制入场价格偏差 | 控制交易成本 |

### 8.2 追踪机制风险

| 风险类型 | 说明 | 应对措施 |
|---------|------|---------|
| **追踪超时** | 追踪期间价格上涨导致错过入场 | 设置追踪上限和超时 |
| **价格反转** | 追踪期间价格持续上涨 | 追踪买入最大停止阈值 |
| **市场变化** | 追踪期间市场条件改变 | 上升趋势快速追踪机制 |

## 九、策略优势与局限

### ✅ 优势

1. **追踪买入优化成本**：在信号触发后等待更优价格入场，降低持仓成本
2. **追踪卖出优化收益**：在卖出信号触发后等待更高价格出场，增加利润
3. **继承父策略优势**：多层保护机制、多时间框架确认
4. **自定义止损**：比父策略更灵活的风险控制
5. **Diamond 指标增强**：新增指标参数，信号更精细

### ⚠️ 局限

1. **复杂度增加**：追踪机制增加了策略复杂度
2. **错过机会风险**：追踪期间价格上涨可能导致错过入场
3. **参数敏感**：追踪参数需要精细调优
4. **计算开销**：追踪状态管理增加了计算负担

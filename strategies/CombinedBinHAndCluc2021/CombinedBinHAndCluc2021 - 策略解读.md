## 一、策略概览

**CombinedBinHAndCluc2021** 是一个三策略组合交易策略，融合了 BinHV45、ClucMay72018 和 BBRSI 三个经典策略的买入逻辑。该策略通过"或门"逻辑实现买入信号的复合筛选，专注于捕捉布林带收敛后的深度超卖行情。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 3 种策略组合（BinHV45 + ClucMay72018 + BBRSI） |
| **卖出条件** | 2 种方式：技术信号（价格 > 布林带中轨）+ ROI 退出 |
| **保护机制** | 硬止损 -9% + 低 ROI 退出 |
| **时间框架** | 5 分钟 |
| **依赖库** | TA-Lib, technical |
| **特殊功能** | 多策略逻辑组合、三套布林带系统 |

## 三、买入条件详解

### 3.1 买入逻辑（策略 1：BinHV45）

```python
# BinHV45 策略买入条件
(
    lower.shift().gt(0) &                          # 前一根布林带下轨 > 0
    bbdelta.gt(close * 0.008) &                    # 布林带带宽 > 0.8%
    closedelta.gt(close * 0.0175) &                # 价格变化 > 1.75%
    tail.lt(bbdelta * 0.25) &                      # 下影线 < 带宽的 25%
    close.lt(lower.shift()) &                      # 当前价 < 前一根下轨
    close.le(close.shift())                        # 当前价 <= 前一根收盘价
)
```

**逻辑解析**：
- **布林带下轨有效**：前一根下轨大于 0
- **带宽足够**：布林带带宽超过 0.8%
- **价格变化显著**：价格变化超过 1.75%
- **下影线短**：下影线小于带宽的 25%（锤子线形态）
- **价格跌破**：当前价低于前一根下轨
- **价格下降**：当前价不高于前一根收盘价

**综合含义**：价格深度跌破布林带，形成锤子线形态，且市场有足够波动空间。

### 3.2 买入逻辑（策略 2：ClucMay72018）

```python
# ClucMay72018 策略买入条件
(
    close < ema100 &                               # 价格 < EMA100
    close < 0.985 * bb_lowerband &                 # 价格 < 布林带下轨×0.985
    volume < volume_mean_slow.shift(1) * 20        # 成交量 < 均量×20
)
```

**逻辑解析**：
- **价格 < EMA100**：价格在 100 周期 EMA 之下，处于下跌趋势
- **深度跌破布林带**：价格低于布林带下轨 1.5%
- **成交量过滤**：排除异常高成交量（需低于均量 20 倍以内）

**综合含义**：价格深度跌破布林带且低于 EMA100，成交量正常（非主力出货）。

### 3.3 买入逻辑（策略 3：BBRSI）

```python
# BBRSI 策略买入条件
(
    rsi < 12 &                                   # RSI < 12（深度超卖）
    close < bb_lowerband4                        # 价格 < 4 倍标准差布林带下轨
)
```

**逻辑解析**：
- **RSI 深度超卖**：RSI < 12（远低于常规超卖线 30）
- **4 倍标准差**：价格跌破 4 倍标准差布林带下轨

**综合含义**：极端超卖状态，反弹概率极高。

### 3.4 组合逻辑

```python
# 三种策略任一满足即买入
(BinHV45 条件) | (ClucMay72018 条件) | (BBRSI 条件)
```

**说明**：三种策略逻辑用"或"连接，任一满足即触发买入。这种设计确保在不同市场状态下都能捕捉到超卖机会。

## 七、策略优势与局限

### ✅ 优势

1. **多策略组合**：3 种经典策略逻辑，覆盖不同场景，提高信号可靠性
2. **极端超卖捕捉**：BBRSI 条件捕捉极端超卖机会，反弹概率极高
3. **快速周转**：1% ROI + 中轨退出，资金利用率高
4. **形态识别**：BinHV45 模式有效识别锤子线形态
5. **计算量适中**：虽然使用三套布林带，但计算逻辑简洁

### ⚠️ 局限

1. **无趋势过滤**：没有长期趋势判断，可能在下跌趋势中逆势买入
2. **无 BTC 关联**：不检测比特币大盘趋势
3. **低 ROI**：1% ROI 可能过早退出大趋势行情
4. **时间框架限制**：仅适用于 5 分钟级别
5. **多布林带计算**：三套布林带增加计算量

## 一、策略概览

MACD_Recovery 是一个结合趋势跟踪与动量反转的混合策略。该策略利用 EMA200 确定长期趋势方向，通过 RSI 超卖信号捕捉短期回调机会，并借助 MACD 金叉作为精确入场触发器。策略名称中的 "Recovery" 暗示其核心逻辑——在上升趋势中的回调阶段寻找恢复性入场机会。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 1 个组合买入信号（三条件联动触发） |
| **卖出条件** | 1 个组合卖出信号（三条件联动触发） |
| **保护机制** | 无独立保护参数组，依赖指标组合过滤 |
| **时间框架** | 5 分钟 (5m) |
| **依赖库** | talib, qtpylib |

## 三、买入条件详解

### 3.1 买入信号结构

策略采用单一组合买入信号，需同时满足三个条件：

```python
# 买入条件
(
    (dataframe['rsi'].rolling(8).min() < 41) &           # 条件1：RSI超卖
    (dataframe['close'] > dataframe['ema200']) &         # 条件2：趋势确认
    (qtpylib.crossed_above(dataframe['macd'], 
                           dataframe['macdsignal']))     # 条件3：MACD金叉
)
```

### 3.2 买入条件详细分析

#### 条件 #1：RSI 超卖确认

```python
# 逻辑
- RSI 指标 8 周期滚动最低值 < 41
- 使用滚动窗口捕捉近期超卖区间
- 41 的阈值比传统 30 更宽松，捕捉更多机会
```

**设计意图**：在价格回调时识别超卖状态，为入场做准备。

#### 条件 #2：趋势方向确认

```python
# 逻辑
- 收盘价 > EMA200
- 确保只在上升趋势中交易
- 避免在下跌趋势中抄底
```

**设计意图**：过滤假信号，只在主趋势向上时入场。

#### 条件 #3：MACD 金叉触发

```python
# 逻辑
- MACD 线上穿信号线
- 作为精确入场时机确认
- 与 RSI 超卖形成共振
```

**设计意图**：在超卖后的动量反转时刻入场，提高胜率。

### 3.3 买入条件分类

| 条件组 | 条件编号 | 核心逻辑 |
|-------|---------|---------|
| 趋势确认 | 条件2 | EMA200 多头排列 |
| 动量反转 | 条件1+3 | RSI 超卖 + MACD 金叉 |

## 四、卖出逻辑详解

### 4.1 ROI 止盈系统

策略采用 11 级渐进式止盈，核心逻辑如下：

```
利润率区间        持有时间      目标收益
──────────────────────────────────────
即时止盈         0 分钟        3.024%
短期持仓         5 小时        2.924%
中期持仓         10 小时       2.545%
中长持仓         14 小时       2.444%
...              ...           ...
强制退出         35 小时       0%
```

**设计特点**：
- 时间越短，止盈目标越高
- 鼓励快速盈利了结
- 超过 35 小时强制退出，避免资金长期占用

### 4.2 卖出信号

```python
# 卖出条件
(
    (dataframe['rsi'].rolling(8).max() > 93) &           # 条件1：RSI超买
    (dataframe['macd'] > 0) &                            # 条件2：MACD多头
    (qtpylib.crossed_below(dataframe['macd'], 
                           dataframe['macdsignal']))     # 条件3：MACD死叉
)
```

### 4.3 卖出信号分析

| 条件 | 逻辑 | 信号名称 |
|------|------|---------|
| RSI 超买 | 8 周期最高值 > 93 | 动量极端 |
| MACD 多头 | MACD > 0 | 趋势确认 |
| MACD 死叉 | MACD 下穿信号线 | 反转信号 |

**设计意图**：在 RSI 极端超买、MACD 仍处多头但开始反转时退出，锁定利润。

## 六、风险管理特色

### 6.1 紧凑止损

止损设置为 -4.032%，相对较紧：

| 参数 | 数值 | 说明 |
|------|------|------|
| 止损幅度 | -4.032% | 相对紧凑 |
| 初始止盈 | 3.024% | 与止损比约 0.75:1 |

**风险提示**：紧凑止损可能增加被震出概率，但有效控制单笔亏损。

### 6.2 时间约束退出

35 小时强制退出机制：
- 避免资金长期占用
- 强制止损保护
- 防止长期浮亏

### 6.3 无追踪止损

策略不使用追踪止损，依赖：
- ROI 表渐进止盈
- 卖出信号主动退出

## 七、策略优势与局限

### ✅ 优势

1. **逻辑简洁**：三条件组合买入，逻辑清晰易懂
2. **趋势过滤**：EMA200 确保只在上升趋势中交易
3. **时间约束**：35 小时强制退出，控制持仓风险

### ⚠️ 局限

1. **条件较少**：仅 1 个买入信号，可能错过其他入场机会
2. **止损较紧**：-4.032% 可能被市场噪音触发
3. **无追踪止损**：无法跟随趋势延伸利润

## 九、适用市场环境详解

MACD_Recovery 是典型的**趋势回调交易策略**。基于其代码架构，它最适合**温和上涨的趋势市场**，而在下跌或剧烈震荡市场表现不佳。

### 9.1 策略核心逻辑

- **趋势确认优先**：收盘价必须高于 EMA200，确保只在多头市场中交易
- **回调入场**：利用 RSI 超卖识别价格回调机会
- **动量确认**：MACD 金叉作为入场时机确认

### 9.2 不同市场环境表现

| 市场类型 | 表现评级 | 原因分析 |
| :--- | :--- | :--- |

| 🔄 震荡上行 | ⭐⭐⭐⭐☆ | 有趋势过滤，能捕捉波段机会 |
| 📉 下跌趋势 | ⭐☆☆☆☆ | EMA200 过滤导致无信号或被套 |
| ⚡️ 剧烈波动 | ⭐⭐☆☆☆ | 紧凑止损可能频繁被触发 |

### 9.3 关键配置建议

# MACD_Recovery 策略：趋势回调"捡漏王"

> **外号**：捡漏王、回调收割机  
> **职业**：只在上涨趋势里"抄底"的狙击手  
> **时间框架**：5 分钟

---

## 一、这策略是个啥？

简单说，**MACD_Recovery** 就是一个：
- 只在上升趋势里干活
- 等价格回调时捡便宜
- 用 MACD 金叉确认入场时机

就像**等地铁**：你不追着跑，而是站在站台上，等车停下来再上车 🚇

---

## 二、核心配置：说白了就是"快进快出"

### 止盈规则（ROI 表）

```
刚买入：目标 3% 左右
5小时后：目标降到 2.9%
10小时后：目标降到 2.5%
...
35小时后：不管赚没赚，给我出来！
```

**翻译**：策略想要快速赚钱。如果你买完一直不涨，超过一天半它就忍不住要跑路了。

### 止损规则

```
亏到 4%，无条件撤退
```

**翻译**：止损设得比较紧，最多允许亏 4%。这意味着容易被"震下车"，但也保证了不会大亏。

## 三、1 个买入条件：三个条件合体

这策略的买入条件看起来是一个，但其实包含三个条件，必须**同时满足**：

### 🎯 三合一买入条件

**大白话**：
> "我要等三件事一起发生：1) 最近 8 根 K 线里 RSI 最低到过 41 以下（超卖了）；2) 价格在 EMA200 均线之上（趋势向上）；3) MACD 金叉（动量反转）。"

**经典台词**：
```python
# 买入条件
(
    (dataframe['rsi'].rolling(8).min() < 41) &      # RSI 有点低了
    (dataframe['close'] > dataframe['ema200']) &    # 趋势是向上的
    (qtpylib.crossed_above(dataframe['macd'], 
                           dataframe['macdsignal'])) # MACD 金叉了！
)
```

> "RSI 超卖 + 趋势向上 + MACD 金叉 = 完美入场点！"

**拆解一下**：
- **RSI < 41**：价格回调到位了，卖压快释放完了
- **价格 > EMA200**：大趋势是向上的，不是逆势抄底
- **MACD 金叉**：动量开始反转，确认向上

## 四、1 个卖出条件：见好就收

### 4.1 卖出信号

**大白话**：
> "我要等三件事一起发生：1) RSI 最近 8 根 K 线最高冲到 93 以上（超买了）；2) MACD 还是正的（还在多头区）；3) MACD 死叉（动量开始减弱）。赶紧跑！"

**经典台词**：
```python
# 卖出条件
(
    (dataframe['rsi'].rolling(8).max() > 93) &      # RSI 太高了！
    (dataframe['macd'] > 0) &                       # MACD 还是多头
    (qtpylib.crossed_below(dataframe['macd'], 
                           dataframe['macdsignal'])) # 但已经开始死叉了
)
```

> "RSI 冲到 93 了，MACD 还在零轴以上但开始死叉，这时候不跑更待何时？"

## 五、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **逻辑简洁**：三个条件一组合，清清楚楚，不多不少
2. **趋势过滤**：EMA200 确保只在上涨趋势里做，不逆势
3. **时间约束**：35 小时强制退出，资金不会无限期被占用

### ⚠️ 缺点（吐槽环节）

1. **信号较少**：只有一个买入条件组合，可能错过其他机会
2. **止损太紧**：4% 的止损容易被行情"震"出去
3. **没有追踪止损**：涨起来跟着跑不了，只能等卖出信号

## 十二、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

MACD_Recovery 的历史回测表现可能**还不错**——但有个陷阱：

> **简洁的策略往往参数敏感，优化后的数字（4.032% 止损、41 RSI 阈值）可能只是"恰好"适合历史数据。**

简单说就是：**"过去好用不代表未来好用。"**

### 紧凑止损的隐藏风险

实盘时，紧凑的 4% 止损可能导致：
- **频繁被震出**：正常波动就触发止损
- **滑点放大损失**：实际成交价可能更差
- **错过后续反弹**：止损后价格又涨回去了

### 我的建议（真心话）

```
1. 先用模拟盘测试至少两周
2. 止损可以考虑放宽到 5%
3. 只在明确上涨趋势中使用
4. 下跌趋势时暂停策略或换其他策略
```

**记住**：趋势策略在趋势市场赚钱，震荡市场就是送钱。认清市场环境比选策略更重要！

## 一、这策略是个啥？

简单说，**Seb** 就是一个：

就像一个**只做一件事但做得很好的匠人**，不花哨，但有效 🎯

## 二、核心配置：说白了就是"赚了就锁定，不贪多"

### 止盈规则（ROI 表）

```
立即    → 5% 利润就走
20分钟  → 4% 也行
30分钟  → 3% 也不错
60分钟  → 1% 也就这样了
```

**翻译**：这策略是"见好就收"型，目标利润随时间递减，不跟市场谈恋爱。

### 止损规则

```
硬止损：-10%（最后防线）
追踪止损：利润达 2% 后激活，回撤 1% 就跑
```

**翻译**：亏到 10% 认栽，赚了钱就设保护，不让利润变亏损。

**举个例子**：
- 入场价 100 块
- 涨到 102 块（利润 2%），追踪止损激活
- 止损位设为 101 块（回撤 1%）
- 继续涨到 105，止损位跟着升到 103.95
- 回撤到 103.95 时自动卖出，锁定约 4% 利润

## 三、买入条件：就一个，简单粗暴

### 🎯 唯一的买入信号

**条件拆解**：

| 条件 | 大白话 |
|------|--------|
| EMA20 上穿 EMA50 | 短期均线金叉中期均线 |
| HA 收盘 > EMA20 | 价格在均线上方 |
| HA 绿色烛 | Heikin Ashi 是绿烛（多头） |

**大白话**：
> "短期均线上穿中期均线，价格在均线上方，而且是多头烛形——买！"

**翻译**：
- **EMA 交叉**：就像开车看到绿灯，可以走了
- **价格在均线上**：就像顺风，阻力小
- **绿色烛形**：就像前面路况好，不用担心

---

## 四、卖出逻辑：也是就一个，对称设计

### 📉 唯一的卖出信号

**条件拆解**：

| 条件 | 大白话 |
|------|--------|
| EMA50 上穿 EMA100 | 中期均线金叉长期均线 |
| HA 收盘 < EMA20 | 价格在均线下方 |
| HA 红色烛 | Heikin Ashi 是红烛（空头） |

**大白话**：
> "中期均线上穿长期均线，价格跌破短期均线，而且是空头烛形——卖！"

等等，这不是"金叉"吗？怎么是卖？

**关键**：这里的逻辑是**买入用 EMA20/50，卖出用 EMA50/100**，用的是不同周期！

- 买入：短期趋势启动（EMA20 > EMA50）
- 卖出：长期趋势确认反转（EMA50 > EMA100）

**大白话**：
> "买入看的是'小趋势启动'，卖出看的是'大趋势反转'。"

## 五、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **简单易懂**：代码简洁，新手也能看懂
2. **趋势确认**：双重验证（均线+烛形），不是瞎猜
3. **追踪止损**：赚钱后自动设保护，不贪心
4. **官方示例**：freqtrade 官方出品，代码规范
5. **扩展性强**：预计算了很多指标，方便优化

### ⚠️ 缺点（吐槽环节）

1. **信号稀少**：只有一个买入条件，交易频率低
2. **震荡市劝退**：横盘时可能反复假突破
3. **指标浪费**：算了一堆指标但没用上
4. **参数未优化**：买参卖参是摆设，得自己调

## 十一、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

Seb 作为官方示例策略，设计初衷是**教学**——

> **它展示了如何写一个完整的策略，但不保证赚钱。**

简单说就是：**代码是教科书级的，不是印钞机级的。**

### 策略的隐藏风险

实盘时，你可能会遇到：
- **信号太少**：等半天没一个买入
- **假突破**：EMA 交叉后马上反转
- **追踪止损被扫**：波动大时容易被扫出局
- **趋势判断滞后**：均线永远滞后于价格

### 我的建议（真心话）

```
1. 把它当学习模板，别当赚钱神器
2. 用 Hyperopt 优化参数，别用默认值
3. 加一些过滤条件，提高信号质量
4. 回测至少一年以上，验证策略有效性
5. 小资金起步，别一上来就梭哈
```

**记住**：简单策略的优势是容易理解，劣势是容易被市场"玩弄"。多加过滤条件，提高胜率才是王道！

# InformativeSample 策略大白话版

## 第一章 这个策略是干嘛的？

你有没有想过，交易的时候能不能看看"大哥"的走势？

在加密货币圈子里，比特币就是那个"大哥"。它涨，其他币跟着涨；它跌，其他币跟着跌。所以，如果我们在交易某个币的时候，能顺便看看比特币在干嘛，是不是更靠谱？

InformativeSample 这个策略就是干这个事的——它会一边分析你要买的币，一边看看比特币的走势，两个都要对上号了，才让你买入或卖出。

这个策略的作者是 Freqtrade 的核心开发者 xmatthias，他写这个策略主要是教大家怎么用 Freqtrade 的"信息对"功能。虽然策略本身赚钱效果一般（作者自己说的），但学完它，你就能掌握一个很实用的技能：跨币种分析。

---

## 第二章 啥是"信息对"？

"信息对"这个概念可能有点绕，我给你打个比方。

假设你是个股民，买了腾讯的股票。你每天看腾讯的K线图，分析它的走势。有一天你突然想：如果我能同时看看大盘（比如沪深300）的走势，是不是更有把握？

因为大盘涨的时候，腾讯大概率也涨；大盘暴跌的时候，腾讯再厉害也难独善其身。

这就是信息对的作用——让你在分析一个交易对的时候，能参考另一个交易对的数据。在 Freqtrade 里，你可以这样定义：

```python
def informative_pairs(self):
    return [("BTC/USDT", '15m')]
```

这就告诉机器人："帮我盯着 BTC/USDT 在 15 分钟周期上的数据，我要用它做参考。"

机器人就会乖乖地把 BTC 的数据下载下来，存好，等你用。

## 第三章 这个策略用啥指标？

这个策略用的指标很简单，就两种：

### 3.1 主币种的指标

你在交易哪个币，就给那个币算三条均线：

- **EMA 20**：20 周期的指数移动平均线，看短期趋势
- **EMA 50**：50 周期的指数移动平均线，看中期趋势  
- **EMA 100**：100 周期的指数移动平均线，看长期趋势

这三个指标有个简单用法：EMA 20 在 EMA 50 上面，说明短期趋势比中期好，是上涨信号；反过来就是下跌信号。

### 3.2 参考币种的指标

策略会给 BTC/USDT 算一个指标：

- **SMA 20**：20 周期的简单移动平均线

就这一个！简单吧？当 BTC 的价格在这条线上方，说明比特币短期走势不错；在下方就是走弱。

## 第四章 怎么判断什么时候买？

买入条件只有两个，必须同时满足：

### 条件一：EMA 20 要在 EMA 50 上面

这叫"金叉"的一种形式。短期均线在长期均线上面，说明价格在涨，势头不错。

想象一下：你开车上坡，如果速度（短期）比平均速度（中期）还快，说明你正在加速。这股票也一样，短期均线比中期均线高，就是加速上涨的意思。

### 条件二：BTC 价格要在 SMA 20 上面

这个意思是：比特币现在走势不错，在它的短期均线上方。

为什么要看这个？因为比特币是"带头大哥"。大哥心情好，小弟们（其他币种）才敢放心涨。如果大哥自己都在跌，你还指望小弟能涨多高？

两个条件一起满足，策略就会说："OK，可以买了！"

---

## 第五章 怎么判断什么时候卖？

卖出条件和买入条件正好相反，也是两个：

### 条件一：EMA 20 跑到 EMA 50 下面去了

这意味着短期趋势变坏了，价格开始下跌，要小心了。

### 条件二：BTC 价格跌破 SMA 20 了

这意味着比特币也不行了，带头大哥都开始跌了，小弟们能好到哪去？

两个条件同时满足，策略就会说："赶紧跑，该卖了！"

你看，这逻辑多对称：买的时候两个都要好，卖的时候两个都要坏。简单明了，不会自己打自己脸。

## 第六章 赚多少就跑？（ROI设置）

这个策略有一套分阶段的止盈规则：

| 持仓多久 | 利润达到多少就止盈 |
|---------|-------------------|
| 刚买入（0分钟） | 5% |
| 持仓20分钟 | 4% |
| 持仓30分钟 | 3% |
| 持仓60分钟 | 1% |

这啥意思？简单说就是：时间越长，要求越低。

刚买入的时候，策略想："给我 5% 利润我就满意了。"如果价格很快涨了 5%，好，马上卖掉，落袋为安。

但如果持仓了 60 分钟还没卖掉（可能是价格涨涨跌跌，一直没到 5%），策略就想："算了，1% 利润我也走，不想等了，夜长梦多。"

这个设计的道理是：持仓时间越长，不确定性越大，不如早点脱手。

## 第七章 亏多少就跑？（止损设置）

止损这块，策略设了两道防线：

### 7.1 固定止损：-10%

如果你买了之后，价格一路跌，跌了 10%，策略会强制卖出。这是最后的底线，防止你一直扛着不卖，越亏越多。

有人说 10% 太大了吧？但在币圈，10% 的波动真的是"日常操作"。设太紧的话，可能刚卖完价格又涨回去了，白白被震下车。

### 7.2 追踪止损：保护利润

这个更有意思。它的规则是：

- 当你盈利达到 4% 时，追踪止损功能启动
- 从那一刻起，如果价格从最高点回调超过 2%，就自动卖出

举个例子：

你 100 块买入一个币。价格涨到 104 块，盈利 4%，追踪止损启动。这时候，止损线设在 104 × 0.98 = 101.92 块。

价格继续涨，涨到 120 块！太爽了！这时候止损线跟着上移到 120 × 0.98 = 117.6 块。

突然价格开始回调，跌跌跌……跌到 117.6 块，触发卖出！你赚了 17.6%，开心！

但如果价格从 120 直接跌穿 117.6，你还能保住大部分利润。这就是追踪止损的好处——它能帮你锁定盈利，同时给价格上涨留足空间。

## 第八章 买和卖的时间框架

这个策略用了两个时间框架：

- **主时间框架：5 分钟**——分析你交易的币，决定买卖
- **参考时间框架：15 分钟**——看 BTC 的走势，做参考

为啥不用同一个时间框架？这是有讲究的：

5 分钟周期比较快，能快速捕捉交易机会。但 BTC 作为"参考对象"，不需要那么频繁地看，15 分钟看一次就够了。太频繁反而可能被噪音干扰。

就好比你开车，自己看路况要很仔细（5 分钟），但看天气预报不用那么频繁（15 分钟），偶尔看一下就行。

## 第九章 代码是怎么写的？

### 9.1 获取 BTC 数据

```python
def informative_pairs(self):
    return [("BTC/USDT", '15m')]
```

这行代码告诉 Freqtrade："我要用 BTC/USDT 在 15 分钟周期上的数据，帮我准备好。"

### 9.2 计算指标

```python
def populate_indicators(self, dataframe, metadata):
    # 给主币种算 EMA
    dataframe['ema20'] = ta.EMA(dataframe, timeperiod=20)
    dataframe['ema50'] = ta.EMA(dataframe, timeperiod=50)
    dataframe['ema100'] = ta.EMA(dataframe, timeperiod=100)
    
    # 给 BTC 算 SMA
    informative = self.dp.get_pair_dataframe(pair="BTC/USDT", timeframe='15m')
    informative['sma20'] = informative['close'].rolling(20).mean()
    
    # 把两个数据合并起来
    dataframe = merge_informative_pair(dataframe, informative, '5m', '15m', ffill=True)
    
    return dataframe
```

这段代码干了三件事：
1. 给你交易的币算 EMA 指标
2. 给 BTC 算 SMA 指标
3. 把两个数据合并成一个表格，这样就能一起用了

### 9.3 买入信号

```python
def populate_entry_trend(self, dataframe, metadata):
    dataframe.loc[
        (dataframe['ema20'] > dataframe['ema50']) &
        (dataframe['close_15m'] > dataframe['sma20_15m']),
        'buy'] = 1
    return dataframe
```

意思是：EMA 20 > EMA 50（主币趋势好）并且 BTC 价格 > BTC 的 SMA 20（大哥走势好），就买入。

### 9.4 卖出信号

```python
def populate_exit_trend(self, dataframe, metadata):
    dataframe.loc[
        (dataframe['ema20'] < dataframe['ema50']) &
        (dataframe['close_15m'] < dataframe['sma20_15m']),
        'sell'] = 1
    return dataframe
```

和买入相反：EMA 20 < EMA 50 并且 BTC 价格 < BTC 的 SMA 20，就卖出。

## 第十章 这个策略有啥好处？

### 10.1 简单易懂

代码不长，逻辑清晰，没有乱七八糟的复杂指标。新手也能看明白在干啥。

### 10.2 参考大环境

不是闭门造车，而是会看看"大哥"比特币的脸色。这是一个很好的思路——做决策时考虑外部环境，而不是只盯着自己那一亩三分地。

### 10.3 风控做得好

固定止损 + 追踪止损 + 分阶段止盈，三道防线保护你的本金和利润。

### 10.4 学到真本事

从这个策略，你能学会怎么用信息对功能。这在 Freqtrade 里是个很实用的技能，以后开发复杂策略都能用到。

## 第十一章 这个策略有啥缺点？

### 11.1 作者自己说不太赚钱

代码注释里明确写了"Not performing very well"，所以别指望直接拿去赚钱。它就是个教学示例。

### 11.2 指标太简单

就几个均线，没有成交量、RSI、MACD 这些常用指标。可能错过很多信号，或者产生很多假信号。

### 11.3 参考只有一个 BTC

只看比特币，没有看 ETH、市场整体情绪等等。有时候比特币跌但其他币涨，这个策略可能就错过了机会。

### 11.4 震荡市容易被折腾

均线策略在趋势市场好用，但在震荡市（涨涨跌跌没方向）就容易频繁买卖，手续费都能把利润吃光。

## 第十二章 怎么改进这个策略？

### 12.1 加点其他指标

比如加个 RSI：

```python
dataframe['rsi'] = ta.RSI(dataframe, timeperiod=14)
```

然后买入条件可以加：RSI 不能太高（比如小于 70），避免追高。

### 12.2 看看成交量

```python
dataframe['volume_sma'] = dataframe['volume'].rolling(20).mean()
```

如果买入的时候成交量放大，说明有资金进场，更靠谱。

### 12.3 多参考几个币

```python
def informative_pairs(self):
    return [
        ("BTC/USDT", '15m'),
        ("ETH/USDT", '15m')
    ]
```

BTC 和 ETH 都看，信息更全面。

### 12.4 用 Hyperopt 优化参数

用 Freqtrade 的 Hyperopt 功能，自动找最优的参数：
- EMA 用多少周期最好？
- 追踪止损设多少最合适？
- ROI 怎么配置利润最高？

## 第十三章 总结一下

InformativeSample 这个策略教给我们三件事：

### 第一：跨币种分析很有用

不要只盯着你要买的币，看看"大哥"比特币在干嘛，有时候能救命。比特币涨，山寨币才敢放心涨；比特币跌，山寨币再牛也得跟着跌。

### 第二：信息对功能很好用

Freqtrade 的 informative_pairs 和 merge_informative_pair 让跨币种分析变得很简单。学会了这个，你就能开发更复杂的策略。

### 第三：简单策略也要有完整的风控

虽然策略逻辑简单，但固定止损、追踪止损、分阶段止盈这些风控措施一样不少。这告诉我们：策略可以简单，但风控不能省。

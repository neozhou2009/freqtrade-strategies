## 一、策略概览

**CombinedBinHClucAndMADV5** 是 CombinedBinHClucAndMADV3 的升级版本，由 ilya 开发并开源。该策略在 MADV3 基础上增加了 SSL 通道 + EMA + RSI 的第五组买入条件，形成了更加多元化的信号过滤体系。

该策略将 BinHV45（布林带 40 周期反弹策略）、ClucMay72018（布林带 20 周期低量策略）、MACD Low Buy（MACD 低位买入策略）以及新增的 SSL 通道策略四种策略的买入逻辑进行整合，通过多维度指标交叉验证来提高信号可靠性。

从代码架构来看，该策略的核心设计理念是通过不同时间周期的技术指标组合，在捕捉趋势机会的同时过滤掉大部分市场噪音。策略采用了 5 分钟作为主时间框架，配合 1 小时信息时间框架来获取更高维度的趋势判断。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 5 个独立买入信号，可独立启用/禁用 |
| **卖出条件** | 1 个基础卖出信号 + 追踪止损 |
| **保护机制** | 自定义止损逻辑（持仓 240 分钟后强制退出） |
| **时间框架** | 5 分钟主时间框架 + 1 小时信息时间框架 |
| **依赖库** | TA-Lib, technical (qtpylib), numpy, pandas |

- 追踪止损配置相对激进，设置了 1% 的正追踪和 2.5% 的偏移触发点，适合在趋势行情中让利润奔跑

## 三、买入条件详解

### 3.1 五个独立买入条件

该策略的买入条件整合了四个经典策略的逻辑，每个条件都有其独特的筛选逻辑和市场适应性。与 MADV3 相比，MADV5 新增了 SSL 通道策略作为第五条件：

| 条件组 | 条件编号 | 核心逻辑 | 策略来源 |
|-------|---------|---------|---------|
| **布林带 20 周期低量（牛市）** | #1 | BB20 下轨 + EMA 趋势确认 + 成交量过滤 | ClucMay72018 |
| **布林带 20 周期低量（熊市）** | #2 | BB20 下轨 + RSI 超卖 + 成交量萎缩 | ClucMay72018 |
| **MACD 低位买入（牛市）** | #3 | MACD 金叉 + 成交量萎缩 + BB 下轨 | MACD Low Buy |
| **MACD 低位买入（熊市）** | #4 | MACD 金叉 + 强成交量萎缩 + BB 下轨 | MACD Low Buy |
| **SSL 通道 + RSI 反转** | #5 | SSL 通道多头 + EMA 趋势 + RSI 反转 | SSL Channels |

### 3.2 条件 #1：ClucMay72018 牛市模式（有保护）

```python
# ClucMay72018 买入条件 - 牛市模式（有保护 guard）
(
    (dataframe['close'] > dataframe['ema_200']) &              # 5m 收盘价 > EMA200
    (dataframe['close'] > dataframe['ema_200_1h']) &           # 5m 收盘价 > 1h EMA200
    (dataframe['close'] < dataframe['ema_slow']) &             # 收盘价 < EMA50
    (dataframe['close'] < 0.99 * dataframe['bb_lowerband']) &  # 收盘价 < BB20 下轨 × 0.99
    (dataframe['volume'] < (dataframe['volume_mean_slow'].shift(1) * 21)) &  # 成交量 < 21 倍均量
    (dataframe['volume'] > 0)                                  # 成交量 > 0
)
```

**逻辑解读**：
- 首先通过 EMA200 确认牛市趋势（5m 和 1h 时间框架同时确认）
- 收盘价必须低于 EMA50 和布林带下轨（99% 位置），确保价格处于相对低位
- 成交量限制：要求成交量低于 30 日均量的 21 倍，这是温和的缩量过滤
- "有保护"（guard）意味着在牛市环境下使用更宽松的入场条件（0.99 而非 0.975）

### 3.3 条件 #2：ClucMay72018 熊市模式（无保护）

```python
# ClucMay72018 买入条件 - 熊市模式（无保护 guard）
(
    (dataframe['close'] < dataframe['ema_slow']) &                     # 收盘价 < EMA50
    (dataframe['close'] < 0.975 * dataframe['bb_lowerband']) &         # 收盘价 < BB20 下轨 × 0.975
    (dataframe['volume'] < (dataframe['volume_mean_slow'].shift(1) * 20)) &  # 成交量 < 20 倍均量
    (dataframe['volume'] < (dataframe['volume'].shift() * 4)) &        # 成交量 < 前一根 × 4
    (dataframe['rsi_1h'] < 15) &                                       # 1h RSI < 15（极度超卖）
    (dataframe['volume'] > 0)                                          # 成交量 > 0
)
```

**逻辑解读**：
- 不要求 EMA 趋势确认，适用于熊市或震荡市
- 使用更严格的布林带条件（0.975 而非 0.99），确保价格深入超卖区域
- 增加 RSI_1h < 15 的条件，这是极度超卖的信号
- 成交量要求更严格：不仅要低于 30 日均量的 20 倍，还要低于前一根 K 线的 25%
- "无保护"意味着在熊市环境下使用更严格的入场条件

### 3.4 条件 #3：MACD Low Buy 牛市模式

```python
# MACD Low Buy 买入条件 - 牛市模式
(
    (dataframe['close'] > dataframe['ema_200']) &                     # 5m 收盘价 > EMA200
    (dataframe['close'] > dataframe['ema_200_1h']) &                  # 5m 收盘价 > 1h EMA200
    
    (dataframe['ema_26'] > dataframe['ema_12']) &                     # EMA26 > EMA12（金叉状态）
    ((dataframe['ema_26'] - dataframe['ema_12']) > (dataframe['open'] * 0.02)) &  # MACD 差值 > 2%
    ((dataframe['ema_26'].shift() - dataframe['ema_12'].shift()) > (dataframe['open']/100)) &  # 前一根 MACD 差值 > 1%
    (dataframe['volume'] < (dataframe['volume'].shift() * 4)) &       # 成交量 < 前一根 × 4
    (dataframe['close'] < (dataframe['bb_lowerband'])) &              # 收盘价 < BB20 下轨
    (dataframe['volume'] > 0)                                         # 成交量 > 0
)
```

**逻辑解读**：
- 首先确认牛市趋势（EMA200 条件）
- MACD 必须在金叉状态，且差值要足够大（超过开盘价的 2%）
- 要求 MACD 差值在前一根 K 线也处于放大状态，这是趋势延续的确认
- 成交量必须大幅萎缩（小于前一根的 1/4）
- 收盘价必须低于布林带下轨，结合 MACD 金叉，形成"超卖反弹"的信号组合

### 3.5 条件 #4：MACD Low Buy 熊市模式

```python
# MACD Low Buy 买入条件 - 熊市模式
(
    (dataframe['ema_26'] > dataframe['ema_12']) &                     # EMA26 > EMA12（金叉状态）
    ((dataframe['ema_26'] - dataframe['ema_12']) > (dataframe['open'] * 0.03)) &  # MACD 差值 > 3%（更严格）
    ((dataframe['ema_26'].shift() - dataframe['ema_12'].shift()) > (dataframe['open']/100)) &  # 前一根 MACD 差值 > 1%
    (dataframe['volume'] < (dataframe['volume'].shift() * 4)) &       # 成交量 < 前一根 × 4
    (dataframe['close'] < (dataframe['bb_lowerband'])) &              # 收盘价 < BB20 下轨
    (dataframe['volume'] > 0)                                         # 成交量 > 0
)
```

**逻辑解读**：
- 不要求 EMA 趋势确认，适用于熊市或逆势抄底
- 使用更严格的 MACD 差值条件（3% 而非 2%），确保金叉力度足够强劲
- 其他逻辑与牛市模式相同

### 3.6 条件 #5：SSL 通道 + EMA + RSI 反转（新增加）

```python
# SSL 通道策略（新增加的条件）
(
    (dataframe['close'] < dataframe['sma_5']) &                       # 收盘价 < SMA5（短期回调）
    (dataframe['ssl_up_1h'] > dataframe['ssl_down_1h']) &             # 1h SSL 通道多头排列
    (dataframe['ema_50'] > dataframe['ema_200']) &                    # 5m 短期 > 长期均线
    (dataframe['ema_50_1h'] > dataframe['ema_200_1h']) &              # 1h 短期 > 长期均线
    (dataframe['rsi'] < dataframe['rsi_1h'] - 43.276) &               # RSI 背离 > 43.276
    (dataframe['volume'] > 0)                                         # 成交量 > 0
)
```

**逻辑解读**：
- 这是 MADV5 新增的第五个条件，灵感来源于 SSL 通道策略
- 收盘价低于 SMA5 表示短期处于回调状态
- 1 小时 SSL 通道必须处于多头排列（ssl_up > ssl_down），这是更高时间框架的趋势确认
- 要求 5 分钟和 1 小时 EMA 都处于多头排列（50 > 200）
- RSI 背离条件：5 分钟 RSI 必须比 1 小时 RSI 低至少 43.276 点，这是强烈的反弹信号
- 这个条件不依赖成交量限制，侧重于趋势和动量的反转信号

# 卖出条件
(

**逻辑解读**：
- 卖出条件非常简洁：价格突破布林带中轨（+1% 缓冲）即触发卖出
- 这种设计符合"让利润奔跑"的理念，只要趋势延续就继续持仓
- 布林带中轨具有动态特性，它会随着价格波动而调整，为止盈提供自适应参考

### 4.2 追踪止损机制

```python
trailing_stop = True
trailing_only_offset_is_reached = False
trailing_stop_positive = 0.01          # 1% 追踪止损
trailing_stop_positive_offset = 0.025  # 2.5% 偏移触发
```

**追踪逻辑**：
- 只要持仓盈利超过 2.5%，追踪止损就会激活
- 追踪止损的触发点是当前价格下跌 1%
- 这种配置可以在趋势反转时及时锁定利润，同时给趋势足够的延续空间

### 4.3 ROI 双退出点机制

```python
minimal_roi = {
    "0": 0.021,     # 立即退出：2.1% 利润
    "40": 0.005,    # 40 分钟后退出：0.5% 利润
}
```

**设计思路**：
- 这是与 MADV3 的主要区别之一：增加了 40 分钟后的保底退出点
- 如果持仓 40 分钟后仍未触发其他卖出条件，只需 0.5% 利润即可退出
- 这种设计可以避免长期持仓导致的资金占用，同时提供一定的盈利保障

### 4.4 自定义止损逻辑

```python
def custom_stoploss(self, pair: str, trade: 'Trade', current_time: datetime,
                    current_rate: float, current_profit: float, **kwargs) -> float:
    # 持仓超过 240 分钟且处于亏损状态时，强制退出
    if (current_profit < 0) & (current_time - timedelta(minutes=240) > trade.open_date_utc):
        return 0.01  # 退出仓位
    return 0.99     # 保持仓位
```

**设计思路**：
- 240 分钟（约 4 小时）是该策略的"持仓极限"，超过这个时间即使亏损也要退出
- 这种设计可以避免长期持仓导致的资金占用和不可控风险
- 亏损状态下强制退出是一种"断臂求生"的风险管理策略

### 5.3 SSL 通道指标详解

SSL 通道是 MADV5 新增的核心指标，其计算方法如下：

```python
def SSLChannels(dataframe, length=7):
    df = dataframe.copy()
    df['ATR'] = ta.ATR(df, timeperiod=14)
    df['smaHigh'] = df['high'].rolling(length).mean() + df['ATR']
    df['smaLow'] = df['low'].rolling(length).mean() - df['ATR']
    df['hlv'] = np.where(df['close'] > df['smaHigh'], 1, 
                        np.where(df['close'] < df['smaLow'], -1, np.nan))
    df['hlv'] = df['hlv'].ffill()
    df['sslDown'] = np.where(df['hlv'] < 0, df['smaHigh'], df['smaLow'])
    df['sslUp'] = np.where(df['hlv'] < 0, df['smaLow'], df['smaHigh'])
    return df['sslDown'], df['sslUp']
```

**SSL 通道逻辑**：
- 当价格高于 smaHigh 时，hlv = 1（多头）
- 当价格低于 smaLow 时，hlv = -1（空头）
- 当价格介于两者之间时，保持前一个状态（趋势延续）
- sslUp > sslDown 表示多头趋势，反之则为空头趋势

## 六、风险管理特色

### 6.1 多维度趋势确认

策略要求多个时间框架的 EMA 趋势一致，这可以有效过滤逆势交易信号：

| 条件 | 趋势要求 |
|------|----------|
| Cluc 牛市模式 | 5m EMA200 < close **且** 1h EMA200 < close |
| MACD 牛市模式 | 5m EMA200 < close **且** 1h EMA200 < close |
| SSL 通道模式 | 5m EMA50 > EMA200 **且** 1h EMA50 > EMA200 |

### 6.2 成交量异常过滤

多个买入条件都包含了成交量验证逻辑，这是防止假突破的关键机制：

- **条件 #1**：成交量 < 30 日均量的 21 倍
- **条件 #2**：成交量 < 30 日均量的 20 倍 **且** 成交量 < 前一根的 25%
- **条件 #3/4**：成交量 < 前一根 K 线的 25%

### 6.3 RSI 背离过滤

条件 #5 独特的 RSI 背离机制：

```python
dataframe['rsi'] < dataframe['rsi_1h'] - 43.276
```

这个条件要求 5 分钟 RSI 必须比 1 小时 RSI 低至少 43.276 点，这代表：
- 短期超卖程度远高于长期
- 存在强烈的反弹动能
- 是经典的底背离信号

### 6.4 时间止损机制

自定义止损中的 240 分钟时间限制是一种简洁有效的风险控制手段：

| 持仓时间 | 盈利状态 | 行为 |
|---------|---------|------|
| < 240 分钟 | 盈利 | 继续持有，追逐趋势 |
| < 240 分钟 | 亏损 | 继续持有，等待反转 |
| >= 240 分钟 | 盈利 | 继续持有，让利润奔跑 |
| >= 240 分钟 | 亏损 | **强制退出** |

## 七、策略优势与局限

### ✅ 优势

1. **策略融合升级**：在 MADV3 基础上新增 SSL 通道条件，形成四个策略的融合
2. **多时间框架分析**：结合 5 分钟、1 小时和 SSL 通道，提供更全面的市场视角
3. **牛市/熊市双模式**：每个条件都有针对不同市场环境的参数配置
4. **严格的成交量过滤**：通过缩量条件有效过滤假突破，提高信号质量
5. **RSI 背离创新**：新增加的 RSI 背离条件提供了独特的反弹信号
6. **ROI 双重保障**：40 分钟后的保底退出点避免长期持仓

### ⚠️ 局限

1. **条件数量增加**：5 个买入条件增加了信号冲突的可能性
2. **趋势依赖性强**：策略在震荡行情中表现可能不佳
3. **卖出信号单一**：仅依靠布林带中轨突破卖出，可能错过更大的趋势行情
4. **参数复杂度**：相比 MADV3，参数空间更大，但优化难度也更高

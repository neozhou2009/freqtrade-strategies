## 一、策略概览

Schism6 是一个融合多时间框架分析与动态仓位管理的量化交易策略。它通过 1 小时级别的趋势判断筛选入场时机，在 5 分钟级别执行交易，并引入线性增长函数动态调整参数，实现对持仓风险的自适应控制。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 2 种模式（新开仓 + 加仓/DCA），各含多条件组合 |
| **卖出条件** | 动态止损逻辑 + ROI 分级退出 + 趋势反转信号 |
| **保护机制** | 动态线性增长止损、峰值利润保护、槽位管理 |
| **时间框架** | 5m (主) + 1h (信息层) |
| **依赖库** | numpy, talib, qtpylib, arrow, pandas, cachetools, technical.indicators.RMI |

## 三、买入条件详解

### 3.1 技术指标体系

策略计算以下核心指标：

| 指标类别 | 具体指标 | 用途 |
|---------|---------|------|
| RMI 系列 | RMI 慢速 (21,5)、RMI 快速 (8,4) | 趋势判断与超买超卖 |
| ROC | ROC (周期6) | 价格变化率 |
| MP | ROC 的 RSI (周期6) | 变化率强度 |
| RMI 趋势 | RMI 上升/下降趋势 (3周期) | 趋势连续性判断 |

### 3.2 信息时间框架指标（1h）

策略使用 1 小时作为信息层，提供更高维度的趋势判断：

- **RSI (14)**: 判断大周期超买超卖
- **1日最高价**: 24 根 1h K 线的最高价
- **3日最低价**: 72 根 1h K 线的最低价
- **ADR (Average Daily Range)**: 1日最高 - 3日最低

### 3.3 买入条件分类

#### 模式一：新开仓（无持仓时）

```python
# 逻辑
- 1小时 RSI >= 65（大周期强势）
- 收盘价 <= 3日最低价 + 86.884% ADR（接近支撑位）
- RMI 下降趋势 == 1（回调中）
- RMI 慢速 >= 33（非极端弱势）
- RMI 快速 <= 41（快速线未超买）
- MP <= 53（价格变化率适中）
```

**设计理念**：在 1 小时级别强势背景下，利用短期回调时机入场，等待反弹。

#### 模式二：加仓/DCA（有持仓时）

```python
# 逻辑
- RMI 上升趋势 == 1（趋势延续）
- 当前利润 > 峰值利润 * 利润因子（利润保护）
- RMI 慢速 >= 线性增长值（动态阈值）
```

**线性增长函数**：
```python
def linear_growth(self, start: float, end: float, start_time: int, end_time: int, trade_time: int) -> float:
    time = max(0, trade_time - start_time)
    rate = (end - start) / (end_time - start_time)
    return min(end, start + (rate * time))
```

加仓时的 RMI 阈值从 30 线性增长到 70，跨越 180 到 720 分钟（3 到 12 小时），实现持仓时间越长，加仓门槛越高的动态控制。

## 四、卖出逻辑详解

### 4.1 动态止损系统

策略采用基于持仓时间的动态止损：

```python
# 线性增长止损
loss_cutoff = linear_growth(-0.03, 0, 0, 300, trade_time)
```

- **0 分钟**: 止损阈值 -3%
- **300 分钟**: 止损阈值 0%（保本）
- **中间时间**: 线性插值

**卖出条件组合**：
```
当前利润 < 动态止损阈值
AND 当前利润 > 硬止损 (-10%)
AND RMI 下降趋势 == 1
AND 成交量 > 0
```

### 4.2 趋势反转信号

| 场景 | 触发条件 | 信号名称 |
|------|---------|---------|
| 有峰值利润 | RMI 慢速下穿 50 | 趋势转弱信号 |
| 无峰值利润 | RMI 慢速下穿 10 | 极端弱势信号 |

### 4.3 槽位管理机制

策略监控其他交易对的盈亏状态：

```python
if trade_data['other_trades']:
    if trade_data['free_slots'] > 0:
        # 有空闲槽位，需要其他交易对盈利
        hold_pct = (trade_data['free_slots'] / 100) * -1
        conditions.append(trade_data['avg_other_profit'] >= hold_pct)
    else:
        # 无空闲槽位，当前必须是最大亏损者才卖
        conditions.append(trade_data['biggest_loser'] == True)
```

**设计理念**：避免在亏损时清仓后错过反弹，同时利用槽位状态优化资金效率。

## 七、策略优势与局限

### ✅ 优势

1. **多时间框架确认**：结合 1 小时趋势与 5 分钟入场，提高胜率
2. **动态参数调整**：持仓时间越长，加仓门槛越高、止损越宽松
3. **智能槽位管理**：根据全局仓位状态优化卖出决策
4. **峰值利润保护**：利用峰值利润率动态调整利润因子
5. **订单执行保护**：超时取消与入场确认机制降低滑点风险

### ⚠️ 局限

1. **复杂度高**：参数众多，需要深入理解才能优化
2. **依赖实盘数据**：`populate_trades` 依赖数据库查询，回测时需要特别注意
3. **计算开销大**：每次计算都需要查询持仓状态，对硬件有要求
4. **参数敏感性**：买入参数经过优化，不同市场可能需要重新调参

## 九、适用市场环境详解

Schism6 是一个**趋势回调型策略**。基于其代码架构，它最适合**慢牛或温和上涨市场**，而在**单边下跌或极端波动**时表现不佳。

### 9.1 策略核心逻辑

- **多时间框架确认**：1 小时 RSI >= 65 确保大周期强势
- **回调入场**：在 RMI 下降趋势中寻找反弹机会
- **动态风控**：持仓时间越长，风控越宽松（给趋势更多时间）

### 9.2 不同市场环境表现

| 市场类型 | 表现评级 | 原因分析 |
| :--- | :--- | :--- |
| 📈 慢牛趋势 | ⭐⭐⭐⭐⭐ | 回调入场逻辑完美匹配，多周期确认提高胜率 |
| 🔄 温和震荡 | ⭐⭐⭐☆☆ | 可能频繁触发止损，但加仓逻辑可降低成本 |
| 📉 单边下跌 | ⭐⭐☆☆☆ | RSI 强势条件失效，回调可能变成下跌延续 |
| ⚡️ 极端波动 | ⭐☆☆☆☆ | 多指标可能互相矛盾，滑点风险大 |

### 9.3 关键配置建议

| 配置项 | 建议值 | 说明 |
|--------|--------|------|
| startup_candle_count | 72 | 需要足够历史数据计算指标 |
| inf_timeframe | 1h | 可根据市场波动调整为 4h |
| stoploss | -0.10 | 可根据风险偏好调整 |

## 十、重要提醒：复杂性的代价

### 10.1 学习成本

策略涉及多个自定义指标和动态参数系统，需要理解：
- RMI 指标的计算与含义
- 线性增长函数的参数调优
- 槽位管理机制的触发条件
- 多时间框架分析的综合判断

### 10.2 硬件要求

| 交易对数量 | 最低内存 | 推荐内存 |
|-----------|---------|---------|
| 1-10 对 | 2GB | 4GB |
| 11-30 对 | 4GB | 8GB |
| 30+ 对 | 8GB | 16GB |

**注意**：`populate_trades` 每次调用都查询数据库，交易对数量多时需要优化。

### 10.3 回测与实盘的差异

策略在 `live` 和 `dry_run` 模式下会执行完整的交易状态追踪逻辑，但回测时 `populate_trades` 返回空数据，导致：
- 加仓逻辑不会触发
- 槽位管理逻辑不会执行
- 动态止损需要依赖 `custom_stoploss` 实现（当前未实现）

### 10.4 手动交易者建议

- 重点关注 1 小时 RSI 是否 >= 65
- RMI 慢速 >= 33 且 RMI 快速 <= 41 时等待回调
- 使用 ADR 确定支撑位区间
- 注意持仓时间对风控参数的影响

对于量化交易者而言，这是一个需要深入理解才能发挥潜力的策略，适合有经验的开发者进行进一步优化和实盘验证。

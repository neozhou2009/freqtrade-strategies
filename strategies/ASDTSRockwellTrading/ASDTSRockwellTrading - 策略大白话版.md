## 一、这策略是个啥？

简单说，**ASDTSRockwellTrading** 就是一个：
- 只看一个指标（MACD）
- 逻辑简单到小学生都能懂
- 来自 YouTube 教程的"课代表"策略
- 经典得不能再经典的趋势跟踪

就像**考试只背重点笔记**的学生——可能拿不到满分，但肯定不会挂科 📚

## 二、核心配置：说白了就是"MACD 说了算"

### 止盈规则（ROI 表）

```
刚买入就涨 5%？跑！
等了 20 分钟（4 根 K 线）还有 4%？跑！
等了 30 分钟（6 根 K 线）还有 3%？跑！
等了 60 分钟（12 根 K 线）还有 1%？跑！
```

**翻译**：这策略很现实——赚 5% 就知足，实在不行赚 1% 也跑。主打一个"落袋为安"。

### 止损规则

```
亏到 -30% 的时候就...止损！
```

**翻译**：止损设得挺宽，给趋势发展留足了空间。相当于"先别慌，让它飞一会儿"。

---

## 三、买入条件：经典得不能再经典

### 🎯 MACD 多头确认

**核心逻辑**：MACD 在零轴上方 + MACD 比信号线高 → 买入

```python
# 实际代码就这么简单
(dataframe['macd'] > 0) &          # MACD 在零轴上方
(dataframe['macd'] > dataframe['macdsignal'])  # MACD 比信号线高
```

**大白话翻译**：
> "MACD 是正数（多头市场）+ MACD 线在信号线上面（动量加强）→ 买入！"

**这信号意味着什么？**
- MACD > 0：短期均线比长期均线高，说明最近涨得比之前快
- MACD > Signal：动能在加速，不是光涨，而是越涨越快

**简单比喻**：
就像开车上坡——
- MACD > 0：车子已经在上坡（不是下坡）
- MACD > Signal：还在踩油门加速（不是松油门）

---

## 四、卖出条件：动量一弱就跑

### 📉 MACD 下穿信号线

**核心逻辑**：MACD 比信号线低 → 卖出

```python
# 卖出条件更简单
(dataframe['macd'] < dataframe['macdsignal'])
```

**大白话翻译**：
> "MACD 掉到信号线下面了？跑！"

**注意**：这里只要求 MACD 下穿信号线，不管 MACD 是正还是负。

**这意味着**：
- 即使 MACD 还在零轴上方（还是多头市场）
- 只要 MACD 下穿信号线（动量开始衰减）
- 立即卖出！

**简单比喻**：
还是开车上坡——
- 之前油门踩到底（MACD > Signal）
- 现在松油门了（MACD < Signal）
- 虽然车还在往上走（MACD > 0），但没动力了，赶紧下车！

## 五、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **逻辑经典**：MACD 是技术分析的"祖师爷"级别指标
2. **信号明确**：没有"可能"、"大概"，要么符合要么不符合
3. **代码简单**：60 行代码，新手也能看懂
4. **顺势而为**：只在趋势确认后才入场
5. **反应快**：动量一弱就跑，不等趋势反转

### ⚠️ 缺点（吐槽环节）

1. **震荡市被收割**：横盘时 MACD 反复交叉，信号不停触发
2. **止损偏宽**：-30% 止损，可能亏掉三分之一才跑
3. **单一指标**：只看 MACD，没有其他确认
4. **没有趋势过滤**：不管现在是趋势还是震荡，有信号就冲

## 十一、手动交易者怎么用？

如果你想手动执行这个策略：

1. **打开 TradingView**，添加 MACD 指标（默认参数：12, 26, 9）
2. **切换到 5 分钟图**
3. **等信号**：
   - MACD 线（快线）在零轴上方
   - MACD 线在信号线（慢线）上方
   - → **买入**
4. **卖出**：
   - MACD 线掉到信号线下方
   - → **卖出**

就这么简单！不用看任何其他指标。

## 十二、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

ASDTSRockwellTrading 回测时如果选了趋势行情，表现通常不错——但：

> **震荡市是 MACD 的天敌。横盘时它会反复买卖，手续费能把你吃穷。**

### 简单策略的隐藏风险

实盘时，过于简单的逻辑可能导致：
- **震荡市假信号**：MACD 在横盘时反复交叉
- **止损触发慢**：-30% 的止损太宽，可能承受大亏
- **缺乏趋势确认**：不知道现在是趋势还是震荡

### 我的建议（真心话）

```
1. 加个 ADX 过滤：ADX > 25 才入场
2. 收紧止损：改成 -15% 或 -10%
3. 选好品种：只做有趋势的币
4. 避开震荡期：大盘横盘时暂停
5. 控制仓位：别满仓，留点余地
```

**记住**：MACD 是好指标，但震荡市它真的不靠谱。趋势来了用这策略很香，震荡来了赶紧撤！🙏

## 一、策略概览

ASDTSRockwellTrading 是一个基于 MACD（移动平均收敛散度）指标的极简趋势跟踪策略。策略灵感来源于 YouTube 交易教程，核心逻辑简洁明了：在 MACD 位于零轴上方且高于信号线时买入，在 MACD 低于信号线时卖出。这是一个经典的动量趋势策略，适合趋势市场。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 1 个核心买入信号（MACD 多头确认） |
| **卖出条件** | 1 个基础卖出信号（MACD 空头确认） |
| **保护机制** | 固定止损 + ROI 梯度止盈 |
| **时间框架** | 5 分钟 (5m) |
| **依赖库** | talib, qtpylib |

## 三、买入条件详解

### 3.1 核心买入逻辑

```python
def populate_entry_trend(self, dataframe: DataFrame, metadata: dict) -> DataFrame:
    dataframe.loc[
        (
            (dataframe['macd'] > 0) &
            (dataframe['macd'] > dataframe['macdsignal'])
        ),
        'buy'] = 1
    return dataframe
```

**双重确认买入信号**：

| 条件元素 | 参数 | 说明 |
|---------|------|------|
| MACD > 0 | 零轴上方 | 动量为正，处于多头市场 |
| MACD > Signal | 信号线上方 | MACD 线上穿信号线，动量加速 |

### 3.2 买入信号解读

这是一个**经典 MACD 多头入场信号**：

1. **MACD > 0**：表示短期均线在长期均线之上，市场处于上升趋势
2. **MACD > Signal**：表示 MACD 线位于信号线之上，动能正在增强

**信号强度**：双重确认，相比单一交叉信号更可靠

### 3.3 买入时机

最佳买入时机：
- MACD 刚上穿零轴（趋势启动）
- MACD 在零轴上方加速上涨（趋势加强）
- 信号线在零轴下方开始向上发散

## 四、卖出逻辑详解

### 4.1 卖出条件

```python
def populate_exit_trend(self, dataframe: DataFrame, metadata: dict) -> DataFrame:
    dataframe.loc[
        (
            (dataframe['macd'] < dataframe['macdsignal'])
        ),
        'sell'] = 1
    return dataframe
```

**单一卖出信号**：MACD 下穿信号线

| 条件元素 | 参数 | 说明 |
|---------|------|------|
| MACD < Signal | 信号线下方 | MACD 线下穿信号线，动量衰减 |

### 4.2 卖出条件分析

**卖出信号触发条件**：
- MACD 下穿信号线即触发
- **不要求 MACD < 0**：即使 MACD 在零轴上方，只要下穿信号线就卖出

**设计考量**：
- 快速响应动量衰减
- 不等待趋势完全反转
- 宁可早退，不愿深套

### 4.3 卖出信号分析

| 场景 | MACD 位置 | Signal 位置 | 触发卖出 |
|------|----------|-----------|---------|
| 零轴上方下穿 | > 0 | MACD 下穿 | ✅ 是 |
| 零轴下方下穿 | < 0 | MACD 下穿 | ✅ 是 |
| 零轴附近震荡 | ≈ 0 | MACD 下穿 | ✅ 是 |

## 五、技术指标体系

### 5.1 核心指标：MACD

```python
def populate_indicators(self, dataframe: DataFrame, metadata: dict) -> DataFrame:
    macd = ta.MACD(dataframe)
    dataframe['macd'] = macd['macd']
    dataframe['macdsignal'] = macd['macdsignal']
    dataframe['macdhist'] = macd['macdhist']
    return dataframe
```

**MACD 指标组成**：

| 指标 | 说明 | 用途 |
|------|------|------|
| MACD Line | DIF 线（快线） | 判断动量方向 |
| Signal Line | DEA 线（慢线） | 判断动量变化 |
| Histogram | 柱状图（差值） | 本策略未使用 |

**MACD 默认参数**（talib 默认）：
- 快线周期：12
- 慢线周期：26
- 信号线周期：9

### 5.2 指标计算原理

MACD 计算公式：
```
MACD = EMA(12) - EMA(26)
Signal = EMA(MACD, 9)
Histogram = MACD - Signal
```

**指标含义**：
- MACD > 0：短期均线高于长期均线，上升趋势
- MACD < 0：短期均线低于长期均线，下降趋势
- MACD 上穿 Signal：动量加速
- MACD 下穿 Signal：动量减速

## 六、风险管理特色

### 6.1 梯度止盈机制

| 持仓时间 | 止盈阈值 | 说明 |
|---------|---------|------|
| 0 分钟 | 5% | 开仓即要求 5% 收益 |
| 20 分钟 | 4% | 约 4 根 K 线后降低要求 |
| 30 分钟 | 6 根 K 线 | 继续降低要求 |
| 60 分钟 | 1% | 12 根 K 线后接受微小利润 |

### 6.2 固定止损

- **止损值**：-30%
- **特点**：相对宽松，给予趋势发展空间
- **风险**：可能承受较大回撤

### 6.3 无追踪止损

策略未启用 `trailing_stop`，依赖固定止损和 ROI 退出。

## 七、策略优势与局限

### ✅ 优势

1. **逻辑经典**：MACD 是成熟技术指标，理论基础扎实
2. **信号明确**：买卖条件清晰，无歧义
3. **代码简洁**：约 60 行代码，易于理解和维护
4. **趋势友好**：在趋势市场中表现良好
5. **快速响应**：卖出信号只看 MACD vs Signal，不等待零轴

### ⚠️ 局限

1. **震荡市噪音**：横盘震荡时 MACD 频繁交叉，产生假信号
2. **止损偏宽**：30% 止损可能过大
3. **无市场过滤**：不管市场状态，有信号就入场
4. **单一指标**：完全依赖 MACD，缺乏确认机制

## 九、适用市场环境详解

ASDTSRockwellTrading 是一个**纯趋势跟踪策略**。基于其代码架构，它最适合**明确趋势市场**，而在震荡市场中表现不佳。

### 9.1 策略核心逻辑

- **趋势确认**：MACD > 0 表示多头趋势
- **动量确认**：MACD > Signal 表示动量加强
- **退出机制**：MACD < Signal 表示动量衰减

### 9.2 不同市场环境表现

| 市场类型 | 表现评级 | 原因分析 |
| :--- | :--- | :--- |
| 📈 上涨趋势 | ⭐⭐⭐⭐⭐ | MACD 多头确认，顺势而为 |
| 🔄 横盘震荡 | ⭐☆☆☆☆ | 频繁交叉，信号反复 |
| 📉 下跌趋势 | ⭐☆☆☆☆ | MACD < 0 不买入，空仓 |
| ⚡️ 高波动 | ⭐⭐⭐☆☆ | 假信号较多，需过滤 |

### 9.3 关键配置建议

| 配置项 | 建议值 | 说明 |
|--------|--------|------|
| 时间框架 | 5m/15m | 避免过低时间框架噪音 |
| 止损 | -15% | 原值 -30% 过宽 |
| ADX 过滤 | 可选添加 | ADX > 25 时才入场 |

1. 打开 5 分钟 K 线图
2. 添加 MACD 指标（默认参数 12, 26, 9）
3. MACD > 0 且 MACD > Signal 时买入
4. MACD < Signal 时卖出

## 十一、总结

**ASDTSRockwellTrading** 是一个**经典的 MACD 趋势跟踪策略**。它的核心价值在于：

1. **逻辑经典**：基于成熟的 MACD 指标

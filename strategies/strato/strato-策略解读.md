## 一、策略概览

**strato** 是一个基于 Stochastic RSI 的动量策略。策略使用 RSI 的随机指标（Stochastic RSI）来捕捉短期超买超卖机会，结合 K 线和 D 线的交叉来生成买卖信号。策略特色是极短的时间框架（1 分钟）和快速周转。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 1 个条件：StochRSI K < 18 + K >= D |
| **卖出条件** | 1 个条件：StochRSI K > 80 + D >= K |
| **保护机制** | 硬止损 |
| **时间框架** | 1 分钟 |
| **依赖库** | TA-Lib, technical |
| **特殊功能** | 超短线交易 |

## 三、买入条件详解

### 3.1 买入逻辑

```python
# 买入条件
dataframe.loc[
    (
        (dataframe["k"] < 18) &           # StochRSI K < 18（超卖）
        (dataframe["k"] >= dataframe["d"])  # K >= D（金叉确认）
    ),
    "enter_long",
] = 1
```

**逻辑解析**：
- **StochRSI 超卖**：K < 18，确认短期超卖
- **K 线确认**：K >= D，确认动量转强

### 3.2 指标计算

```python
# RSI
dataframe["rsi"] = ta.RSI(dataframe, timeperiod=14)

# Stochastic RSI
p = 14  # RSI 周期
d = 3   # D 线周期
k = 3   # K 线周期

srsi = (dataframe["rsi"] - dataframe["rsi"].rolling(p).min()) / (
    dataframe["rsi"].rolling(p).max() - dataframe["rsi"].rolling(p).min()
)
dataframe["k"] = srsi.rolling(k).mean() * 100
dataframe["d"] = dataframe["k"].rolling(d).mean()
```

## 五、技术指标体系

### 5.1 核心指标

| 指标类别 | 具体指标 | 参数 | 用途 |
|---------|---------|------|------|
| **动量指标** | RSI | 14 周期 | 基础动量 |
| **动量指标** | Stochastic RSI | 14/3/3 | 超买超卖 |

### 5.2 Stochastic RSI 计算

```python
# SRSI = (RSI - RSI_min) / (RSI_max - RSI_min)
srsi = (rsi - rsi.rolling(14).min()) / (rsi.rolling(14).max() - rsi.rolling(14).min())

# K 线 = SRSI 的 3 周期移动平均 × 100
k = srsi.rolling(3).mean() * 100

# D 线 = K 线的 3 周期移动平均
d = k.rolling(3).mean()
```

## 七、策略优势与局限

### ✅ 优势

1. **逻辑简洁**：StochRSI 金叉死叉，易于理解
2. **计算量小**：指标少，对硬件要求低
3. **低 ROI**：1.2% ROI，快速周转
4. **市价单**：确保快速成交
5. **学习价值高**：适合学习 StochRSI 策略

### ⚠️ 局限

1. **1 分钟框架**：信号极快，需要低延迟执行
2. **无趋势过滤**：没有长期趋势判断
3. **无 BTC 关联**：不检测比特币大盘趋势
4. **手续费敏感**：1 分钟交易频繁，手续费影响大
5. **假信号多**：1 分钟级别假信号多

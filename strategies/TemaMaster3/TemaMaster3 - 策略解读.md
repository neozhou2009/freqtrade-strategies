## 一、策略概览

TemaMaster3 是一个基于三重指数移动平均线（TEMA）与布林带突破的短线交易策略，结合钱德动量摆动指标（CMO）进行信号确认。该策略追求高胜率入场，在价格触及布林带下沿且动量转强时捕捉反弹机会。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 1 个组合买入信号，需同时满足 TEMA 穿越布林带下轨与 CMO 过滤条件 |
| **卖出条件** | 2 个基础卖出信号，基于 CMO 指标的动态止盈逻辑 |
| **保护机制** | 追踪止损系统（三参数配置） |
| **时间框架** | 1 分钟主时间框架 |
| **信息时间框架** | stake_currency/USDT 作为参考币对 |
| **依赖库** | talib.abstract, qtpylib.indicators |

## 二、策略配置解析

### 2.1 基础风险参数

```python
# ROI 退出表
minimal_roi = {
    "0": 0.25574  # 即时目标 25.574%
}

# 止损设置
stoploss = -0.08848  # 8.848% 硬止损

# 追踪止损
trailing_stop = True
trailing_stop_positive = 0.12943      # 盈利 12.943% 后启动
trailing_stop_positive_offset = 0.17942  # 启动后允许回撤至 17.942%
trailing_only_offset_is_reached = True  # 仅在达到偏移后激活
```

**设计思路**：
- 单一 ROI 目标设置较高（25.574%），意图捕捉大级别反弹
- 追踪止损参数经过精细调校，在盈利约 13% 后启动保护，允许最大回撤至 17.942%
- 硬止损约 8.8%，为极端行情提供最后防线

### 2.2 订单类型配置

```python
use_sell_signal = True      # 启用卖出信号
sell_profit_only = True     # 仅在盈利时卖出
ignore_roi_if_buy_signal = False  # 买入信号不覆盖 ROI
ta_on_candle = False        # 每个 tick 都计算指标（高频策略特征）
```

## 三、买入条件详解

### 3.1 核心买入逻辑

策略采用单一但严格的组合买入条件：

```python
# 买入信号
(
    (qtpylib.crossed_above(dataframe["TEMA"], dataframe["bb_lowerband"]))
    & 
    (dataframe['CMO'] > -3)
)
```

#### 条件解析

| 条件组件 | 逻辑描述 | 技术含义 |
|---------|---------|---------|
| **TEMA 穿越布林带下轨** | TEMA 从下方穿过 bb_lowerband | 价格超跌后开始反弹 |
| **CMO > -3** | 钱德动量指标大于 -3 | 排除极端弱势状态 |

### 3.2 技术指标参数

| 指标 | 参数 | 用途 |
|------|------|------|
| **TEMA** | 周期 60 | 三重指数移动平均线，用于价格趋势判断 |
| **布林带下轨** | 周期 60，标准差 1.4 | 动态支撑位参考 |
| **CMO** | 周期 180 | 动量确认，过滤假突破 |

### 3.3 辅助指标（未用于信号）

```python
# 标准差与变异系数
dataframe['STDDEV'] = ta.STDDEV(dataframe, timeperiod=26, nbdev=1.4)
dataframe['MA'] = ta.MA(dataframe, timeperiod=26, matype=0)
dataframe["COEFFV"] = dataframe['STDDEV'] / dataframe['MA']
```

这些指标在当前版本中未被使用，可能为预留扩展或历史遗留代码。

## 四、卖出逻辑详解

### 4.1 卖出信号系统

策略定义了两个独立的卖出信号：

```python
# 卖出信号
(
    (qtpylib.crossed_below(dataframe["CMO"], -22)) 
    |
    (qtpylib.crossed_below(dataframe["CMO"], 25))
)
```

| 信号编号 | 触发条件 | 信号含义 |
|---------|---------|---------|
| **卖出信号 #1** | CMO 从上方穿过 -22 | 动量转弱，可能继续下跌 |
| **卖出信号 #2** | CMO 从上方穿过 25 | 动量从超买区域回落 |

### 4.2 卖出逻辑设计思路

- **双重退出机制**：一个在弱势区（-22）退出，一个在强势区回落（25）退出
- **非对称退出**：更早识别动量衰竭，避免利润回吐
- **与追踪止损配合**：技术信号 + 动态止损双重保护

## 六、风险管理特色

### 6.1 追踪止损机制

三参数追踪止损系统提供灵活的盈利保护：

| 参数 | 数值 | 说明 |
|------|------|------|
| `trailing_stop_positive` | 12.943% | 触发追踪止损的盈利阈值 |
| `trailing_stop_positive_offset` | 17.942% | 追踪止损的参考高点 |
| `trailing_only_offset_is_reached` | True | 仅在达到偏移后激活 |

**工作原理**：
1. 交易盈利达到 17.942% 时启动追踪止损
2. 止损线设在 17.942% - 12.943% = 5% 左右的回撤位置
3. 随价格上涨动态调整，保护既有利润

### 6.2 止损与止盈配置

| 类型 | 数值 | 说明 |
|------|------|------|
| 硬止损 | -8.848% | 最大亏损容忍度 |
| ROI 目标 | 25.574% | 理想盈利目标 |
| 盈利保护 | 动态追踪 | 锁定利润机制 |

## 七、策略优势与局限

### ✅ 优势

1. **入场严谨**：TEMA 突破布林带下轨 + CMO 动量确认双重过滤，降低假突破风险
2. **退出灵活**：双重 CMO 信号覆盖强势区回落与弱势区止损两种场景
3. **参数精细**：追踪止损三参数经过优化，平衡盈利保护与持仓空间
4. **高频适应**：1 分钟时间框架配合 ta_on_candle=False，适合短线操作

### ⚠️ 局限

1. **参数单一**：买卖条件各仅一套，缺乏多场景适配能力
2. **无保护机制组**：未实现买入保护参数组，依赖止损系统
3. **超短线风险**：1 分钟框架可能产生较多假信号，对滑点敏感
4. **指标冗余**：STDDEV、MA、COEFFV 计算但未使用，增加计算负担

## 九、适用市场环境详解

TemaMaster3 是一个短线反弹捕捉策略。基于其代码架构和指标参数，它最适合**震荡市场中的超跌反弹行情**，而在趋势行情中表现可能不佳。

### 9.1 策略核心逻辑

- **反弹捕捉**：TEMA 穿越布林带下轨意味着价格短暂超卖
- **动量确认**：CMO > -3 确保非极端弱势，避免接刀失败
- **双退出机制**：强势区（25）与弱势区（-22）各有退出通道
- **高频执行**：1 分钟框架要求低延迟执行

### 9.2 不同市场环境表现

| 市场类型 | 表现评级 | 原因分析 |
| :--- | :--- | :--- |
| 📈 **慢牛趋势** | ⭐⭐⭐☆☆ | 可捕捉回调反弹，但主趋势中可能过早止盈 |
| 🔄 **横盘震荡** | ⭐⭐⭐⭐⭐ | 理想场景，布林带下轨频繁触及，反弹空间可期 |
| 📉 **趋势下跌** | ⭐⭐☆☆☆ | 接飞刀风险高，CMO > -3 过滤可能不足 |
| ⚡️ **高波动** | ⭐⭐⭐☆☆ | 信号频繁但假突破多，需调整布林带参数 |

### 9.3 关键配置建议

| 配置项 | 建议值 | 说明 |
|--------|--------|------|
| 交易对选择 | 高流动性币对 | 1 分钟框架对滑点敏感 |
| 止损调整 | 可适当收紧 | -8.8% 对短线可能偏宽 |
| CMO 阈值 | 可考虑提高至 0 | 更严格的动量确认 |
| 布林带标准差 | 可尝试 1.2-1.6 | 根据市场波动调整 |

## 十、重要提醒：高频策略的代价

### 10.1 执行成本

1 分钟时间框架意味着：
- **高频信号**：交易次数多，手续费累计可观
- **滑点敏感**：每笔交易的滑点对收益影响显著
- **API 限制**：频繁调用可能触及交易所限频

### 10.2 硬件要求

| 交易对数量 | 最低内存 | 推荐内存 |
|-----------|---------|---------|
| 1-5 对 | 4GB | 8GB |
| 5-10 对 | 8GB | 16GB |
| 10+ 对 | 16GB | 32GB+ |

### 10.3 回测与实盘的差异

高频策略回测结果往往优于实盘：
- 回测无法模拟滑点和延迟
- 市场深度变化对成交价影响大
- 极端行情下流动性可能枯竭

### 10.4 手动交易者建议

不建议手动执行此策略：
- 1 分钟 K 线要求持续盯盘
- 信号判断需要实时计算技术指标
- 情绪干扰可能导致偏离策略

## 十一、总结

**TemaMaster3** 是一个专注于捕捉布林带下轨反弹的短线策略。它的核心价值在于：

1. **双指标确认**：TEMA 突破 + CMO 动量过滤，提高信号质量
2. **灵活退出**：双 CMO 信号覆盖不同市场状态
3. **精细止损**：三参数追踪止损平衡保护与空间
4. **高频适应**：专为短线操作设计

对于量化交易者而言，这是一个适合震荡市场的短线策略，但需注意：
- 高频交易的手续费和滑点成本
- 参数可能需要根据具体交易对和市场环境优化
- 建议先进行充分回测和模拟盘验证

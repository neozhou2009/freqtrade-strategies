## 一、策略概览

**YOLO** 是一个极简的趋势强度策略，仅使用 ADX（平均趋向指数）和 Aroon 指标来判断趋势强度和方向。策略名称"YOLO"（You Only Live Once）暗示其激进的交易风格——1 分钟时间框架、极低止损、快速进出。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 1 个条件：ADX + Aroon 组合 |
| **卖出条件** | 无技术卖出，依赖追踪止损 |
| **保护机制** | 追踪止损 |
| **时间框架** | 1 分钟 |
| **依赖库** | TA-Lib |
| **特殊功能** | 超短线交易、无卖出信号 |

## 三、买入条件详解

### 3.1 买入逻辑

```python
# 买入条件
dataframe.loc[
    (
        (dataframe["adx"] > params["adx"]) &           # ADX > 34
        (dataframe["aroon-up"] > params["aroon-up"]) & # Aroon Up > 33
        (dataframe["aroon-down"] < params["aroon-down"]) & # Aroon Down < 33
        (dataframe["volume"] > 0)                       # 成交量 > 0
    ),
    "buy",
] = 1
```

**逻辑解析**：
- **ADX > 34**：趋势强度高于 34，确认强趋势
- **Aroon Up > 33**：上升趋势指标高于 33
- **Aroon Down < 33**：下降趋势指标低于 33
- **成交量 > 0**：排除零成交量

**综合含义**：强趋势 + 上升动能确认时买入。

## 七、策略优势与局限

### ✅ 优势

1. **逻辑极简**：仅 ADX + Aroon 两个指标，易于理解
2. **趋势强度过滤**：ADX > 34 确保只在强趋势中交易
3. **极严格止损**：-1% 止损控制风险
4. **快速周转**：3% ROI 即可退出，资金利用率高
5. **计算量小**：指标少，对硬件要求低

### ⚠️ 局限

1. **1 分钟框架**：信号极快，需要低延迟执行
2. **无技术卖出**：完全依赖止损和 ROI 退出
3. **无 BTC 关联**：不检测比特币大盘趋势
4. **参数敏感**：ADX 和 Aroon 阈值固定
5. **手续费敏感**：1 分钟交易频繁，手续费影响大

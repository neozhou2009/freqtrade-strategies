# CMCWinner 策略：三指投票的超跌反弹捕手

> **外号**：三兄弟投票机  
> **职业**：均值回归专家，专门在恐慌中捡便宜  
> **时间框架**：15 分钟（中短线）

---

## 一、这策略是个啥？

简单说，**CMCWinner** 就是一个：

- 用三个指标"投票"决定买卖
- 专门找跌惨了的币抄底
- 快进快出，见好就收

就像一个老猎人，不急着出手，非要等到三个探子都回来报告"可以打"才开枪——**宁可错过，不做错**。

这策略的核心理念是**均值回归**：

> **"极"者必反——当价格偏离均值达到极端程度时，回归是大概率事件。**

就像橡皮筋拉太紧会弹回来一样，价格跌太多也会反弹。但 CMCWinner 不敢自己说了算，它要三个指标一起点头：

- **CCI**：看价格偏离程度
- **MFI**：看资金流向
- **CMO**：看下跌动能

三个指标同时说"可以买"，策略才会出手。这就是"三重投票"机制——更靠谱，但机会也更少。

## 二、核心配置：说白了就是"保守快闪"

### 止盈规则（ROI 表）

```
持仓时间      要求收益
────────────────────────
0-20 分钟     5%
20-30 分钟    3%
30-40 分钟    2%
40 分钟后     0%（保本就跑）
```

**翻译**：刚进场时想赚 5%，等 20 分钟还不行就降目标，40 分钟后保本就走——**能赚就赚，不赚就撤，绝不恋战**。

### 止损规则

```
止损 = -5%（固定）
```

**翻译**：亏到 5% 认栽，别跟市场犟。

### 订单类型

| 类型 | 方式 | 说明 |
|------|------|------|
| 入场 | 限价单 | 保证成交价格 |
| 出场 | 限价单 | 稳定出场 |
| 止损 | 市价单 | 极端情况必须成交 |

## 三、买入条件：三兄弟必须全员同意

这策略的买入条件极其简单——**只有一个信号，但要过三关**。

### 🎯 买入信号的三个条件

| 条件 | 指标 | 阈值 | 大白话 |
|------|------|------|--------|
| 条件一 | CCI | < -100 | 价格跌得太离谱了 |
| 条件二 | MFI | < 20 | 资金流出太狠，没人愿意买了 |
| 条件三 | CMO | < -50 | 下跌动能快耗尽了 |

**经典台词**：
> CCI：老大，价格都跌穿地心了！  
> MFI：二哥，资金跑光了，再跌也没人砸了！  
> CMO：三弟，下跌力气也没了！  
> 三个齐声：**干！**

### 📉 三个指标各管什么？

**CCI（商品通道指数）**：
> CCI < -100 意味着价格已经**严重偏离**统计均值，就像一个人被压到了水底，迟早要浮上来。

**MFI（资金流量指数）**：
> MFI < 20 意味着市场情绪**极度悲观**，资金都在出逃。但物极必反——大家都卖完了，谁来继续砸盘？

**CMO（钱德动量摆动指标）**：
> CMO < -50 意味着下跌动能已经**显著衰减**，虽然价格还在跌，但下跌力量快用完了。

### ⚠️ 关键细节：用前一天的数据！

```python
# 注意：使用 shift(1)，即前一日数据
dataframe['cci'].shift(1) < -100
dataframe['mfi'].shift(1) < 20
dataframe['cmo'].shift(1) < -50
```

**为什么？**

当前 K 线还没走完的时候，指标数值会**骗人**——价格一变，指标就跟着变。但用昨天已确认的数据，就不会有这个问题。

这是一个**老油条**的设计思路——不冲动，等数据稳了再动手。

## 四、保护机制：两道防线保命

### 第一道防线：固定止损 5%

```
stoploss = -5%
```

**人话版**：亏到 5% 就认栽，别跟市场犟。

5% 的止损幅度适合 15 分钟级别的短线交易——既能过滤正常波动，又能有效控制单笔亏损。

### 第二道防线：分阶段收益目标

| 持仓时间 | 要求赚多少 | 设计思路 |
|---------|-----------|----------|
| 0-20 分钟 | 5% | 快速获利了结，不恋战 |
| 20-30 分钟 | 3% | 适度降低预期 |
| 30-40 分钟 | 2% | 进一步降低要求 |
| 40 分钟后 | 0%（保本） | 时间越久要求越低 |

**核心哲学**：

> 短线反弹策略的核心是"快"。如果快速反弹没有发生，说明判断可能错误，应及时退出或降低预期。

## 五、卖出逻辑：和买入完美对称

### 5.1 对称式卖出条件

卖出条件和买入条件**完美镜像**：

| 条件 | 指标 | 阈值 | 大白话 |
|------|------|------|--------|
| 条件一 | CCI | > 100 | 价格涨得太离谱了 |
| 条件二 | MFI | > 80 | 资金流入太疯狂 |
| 条件三 | CMO | > 50 | 上涨动能太足了 |

**人话版**：
> **价格涨得离谱 + 资金流入太狠 + 上涨动能太足 = 赶紧跑！**

### 5.2 完整的均值回归闭环

```
买入：极端超卖 → 潜在反弹
卖出：极端超买 → 潜在回调
```

这体现了均值回归的核心哲学——价格不会永远偏离价值，终将回归均衡。策略在超卖时入场，在超买时离场，完整捕获均值回归过程。

### 5.3 退出优先级

```
ROI 止盈 > 指标信号卖出 > 止损
```

这意味着：
- 如果价格快速上涨达到 ROI 目标 → 优先按 ROI 退出
- 如果持仓超过 40 分钟仍未盈利 → 只要不满 5% 止损就继续持有
- 如果达到超买信号 → 主动离场

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **逻辑清晰**：买入卖出条件对称，一眼就能看懂
2. **信号可靠**：三重指标验证，假信号少
3. **风险可控**：固定止损 + 分阶段 ROI，明明白白
4. **参数简洁**：不需要复杂参数调优，开箱即用
5. **理念成熟**：均值回归是经典交易理念，经过市场验证

### ⚠️ 缺点（吐槽环节）

1. **信号稀少**：三个指标同时满足条件的机会较少，可能几天没信号
2. **逆趋势操作**：只做反转不跟随趋势，在强趋势市场中表现不佳
3. **止损固定**：没根据市场波动性调整止损位置，适应性不足
4. **入场滞后**：用前一天数据，可能错过最佳入场时机
5. **无仓位管理**：没限制最大持仓数，风险分散机制不足

## 十一、彩蛋：策略名字的"小心思"

### 11.1 CMC 的由来

**CMCWinner** 的 CMC 代表三个指标：
- **C** = CCI（商品通道指数）
- **M** = MFI（资金流量指数）
- **C** = CMO（钱德动量摆动指标）

**Winner** 是希望用这三个指标能成为市场赢家——但实际效果还得看回测和实盘 🤣

### 11.2 三指标的协同效应

```
        ┌─────────┐
        │   CCI   │  ← 价格维度：衡量价格偏离程度
        └────┬────┘
             │
    ┌────────┴────────┐
    │                 │
┌───┴───┐         ┌───┴───┐
│  MFI  │         │  CMO  │
└───┬───┘         └───┬───┘
    │                 │
    │ 资金维度        │ 动量维度
    │ 衡量资金流向    │ 衡量动能转换
    │                 │
    └────────┬────────┘
             │
        ┌────┴────┐
        │ 买入/卖出│
        │   信号   │
        └─────────┘
```

三个维度同时确认，就像三个人投票——只有三票全通过才执行，大大降低假信号。

### 11.3 为什么用前一天的数据？

这是一个**老油条**的设计：

> 当前 K 线还没走完，指标会跟着价格上蹿下跳。等你看到信号进场了，下一秒指标又变了——白忙活！

用前一天已确认的数据，虽然可能错过最佳入场点，但信号更可靠——**宁可错过，不做错**。

## 十三、⚠️ 风险再强调（这段一定要看）

### 信号稀少的代价

三指标联合能提高可靠性，但也带来**信号稀少**的问题：

- 日均交易信号可能只有 **1-3 次**
- 低波动市场中可能**数日无交易**
- 需要耐心等待，不适合追求高频率的交易者

**应对方案**：
- 同时监控多个交易对，增加信号来源
- 考虑放宽部分指标阈值（但会降低信号质量）
- 接受低频率，追求单笔质量

### 均值回归的最大风险

均值回归策略最危险的场景是**假反转**：

```
价格下跌 → 超卖信号买入 → 继续下跌 → 触发止损
                    ↓
              再次超卖 → 再次买入 → 继续下跌 → 再次止损
```

这种**"接飞刀"**的风险在强下跌趋势中尤为明显！

**经典案例**：
> 比特币从 6 万跌到 3 万的过程中，每次超卖反弹都很短暂，抄底的人不断被套。

### 实盘注意事项

| 注意事项 | 说明 |
|---------|------|
| 充分回测 | 在不同市场周期进行回测验证 |
| 模拟盘先行 | 实盘前先用模拟盘验证表现 |
| 选择合适币种 | 避免极端行情下的币种，选择流动性好的主流币 |
| 严格止损 | 不要因为浮亏而取消止损，这是保护本金的关键 |
| 控制仓位 | 单笔交易仓位不宜过大，分散风险 |

### 风险警示清单

```
1. ⚠️ 止损！止损！止损！重要的事说三遍
2. ⚠️ 强下跌趋势中可能连续止损，要有心理准备
3. ⚠️ 信号稀少，不要为了交易而放宽条件
4. ⚠️ "抄底"永远是最危险的操作，严格执行止损
5. ⚠️ 均值回归 ≠ 市场一定会反弹，有时候会继续跌
```

### 最后的忠告

> **"别人恐惧我贪婪，别人贪婪我恐惧"**——这话听着好听，做起来极难。

在极端超卖的时候买入，需要有：
- **铁一般的纪律**（严格执行止损）
- **石一般的心肠**（不被浮亏动摇）

CMCWinner 策略看似简单，实则需要深厚的市场理解。**历史表现不代表未来收益，请根据自身风险承受能力谨慎决策。**

- 配了追踪止损当"保险"

## 二、核心配置：说白了就是"蚊子腿也是肉"

### 止盈规则（ROI 表）

```
立即 → 1% 利润就跑
```

**翻译**：就这一个 ROI 设置！只要价格涨 1%，马上卖出走人。这策略是个不折不扣的"小赚即跑派"。

**但等等！还有追踪止损...**

### 止损规则

```
固定止损 = -10%
追踪止损 = 启用（利润到 1% 后激活）
追踪距离 = 0.1%
```

**翻译**：
- 如果价格跌 10%，认输止损
- 如果价格涨过 1%，追踪止损开始工作
- 追踪距离 0.1%，意思是价格从最高点回撤 0.1% 就卖

**这就尴尬了**：ROI 说 1% 就卖，追踪止损说要 1% 才启动...这两个配置其实是冲突的！🤣

**吐槽**：追踪止损和 1% ROI 是冲突的。理论上价格涨到 1% 就被 ROI 卖掉了，追踪止损根本没机会工作。除非你修改配置，不然这追踪止损就是个摆设 😅

## 五、卖出逻辑：双重机制

### 5.1 ROI 止盈（主角）

```
利润 ≥ 1% → 立即卖出
```

**大白话**：
> "涨 1% 就跑，绝不恋战！"

### 5.2 追踪止损（配角）

```
利润 ≥ 1% → 追踪止损启动
价格从最高点回撤 0.1% → 卖出
```

**大白话**：
> "如果价格继续涨，我就跟着；一旦回撤 0.1%，我就跑！"

**问题**：ROI 在 1% 就触发了，追踪止损根本没机会工作！除非：
- 你把 ROI 提高到 2% 以上
- 或者设置 `ignore_roi_if_buy_signal = True`

### 5.3 卖出信号（配角二号）

```
价格 > EMA24 * 1.012
且 利润 ≥ 1%
```

**大白话**：
> "价格涨到均线以上 1.2%，而且已经在赚钱，那就卖吧。"

**注意**：这个卖出信号只在盈利时才生效，亏钱时不会触发。

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **高频小利累积**：每次赚 1%，积少成多
2. **追踪止损兜底**：万一碰到大行情，也能锁住更多利润
3. **双重买入通道**：既能抓趋势回调，也敢抄极端超卖
4. **风险控制严格**：亏损时靠固定止损，盈利时有多种退出机制

### ⚠️ 缺点（吐槽环节）

1. **ROI 太激进**：1% 扣掉手续费，实际利润可能只有 0.5-0.8%
2. **追踪止损是摆设**：ROI 在 1% 就触发，追踪止损根本没机会
3. **启动蜡烛数太少**：30 根蜡烛对 EWO 200 来说根本不够
4. **容易卖飞**：1% 就卖，大行情来了一飞冲天，你早就下车了

## 十、想跑这个策略？先看看这些配置

### 10.1 关键参数调整建议

| 配置项 | 默认值 | 建议值 | 原因 |
|--------|--------|--------|------|
| minimal_roi | 1% | 1.5-2% | 扣掉手续费后还有利润 |
| trailing_stop_positive | 0.1% | 0.5-1% | 避免被正常波动震出去 |
| startup_candle_count | 30 | 200 | EWO 200 需要足够数据 |
| stoploss | -10% | 可根据币种调整 | 波动大的币种可放宽 |

### 10.2 手续费计算（重要！）

假设：
- 买入手续费：0.1%
- 卖出手续费：0.1%
- 利润目标：1%

**实际利润** = 1% - 0.1% - 0.1% = **0.8%**

如果交易所给 VIP 费率（比如 0.02%）：
**实际利润** = 1% - 0.02% - 0.02% = **0.96%**

**结论**：手续费对高频策略影响巨大！找低手续费交易所或 VIP 费率。

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

V0 版本的 1% ROI 看起来简单有效——但这有个陷阱：

> **1% 利润 - 手续费 - 滑点 = 实际利润可能只有 0.5%！**

高频交易的手续费是隐形杀手。

### 配置冲突问题

策略存在明显的配置冲突：
- ROI 在 1% 就止盈
- 追踪止损需要 1% 才启动
- 结果：追踪止损永远用不上！

**建议**：要么提高 ROI 到 2% 以上，要么禁用 ROI 只用追踪止损。

### 复杂策略的隐藏风险

实盘时要注意：
- **手续费累积**：每次交易扣一点，高频下来很可观
- **启动数据不足**：30 根蜡烛对某些指标不够
- **参数过拟合**：默认参数可能是历史最优，未来不一定有效

### 我的建议（真心话）

```
1. 把 ROI 提高到 1.5-2%，让利润覆盖手续费
2. 让追踪止损真正工作起来（提高启动阈值）
3. 增加 startup_candle_count 到 200
4. 找低手续费交易所
5. 只在高波动震荡市场使用
```

**记住**：小利策略最怕手续费和卖飞。算清楚账再上车，别被回测数据骗了！🙏

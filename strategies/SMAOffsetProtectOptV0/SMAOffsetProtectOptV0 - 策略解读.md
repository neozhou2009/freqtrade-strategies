## 一、策略概览

SMAOffsetProtectOptV0 是 SMAOffsetProtectOpt 系列的基础版本，采用了极其激进的 ROI 配置（立即 1% 止盈），并启用了追踪止损机制。其核心理念是"小赚即跑、落袋为安"，配合追踪止损在趋势行情中捕获额外收益。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 2 个独立买入信号，基于 EWO 高/低阈值分流 |
| **卖出条件** | 1 个基础卖出信号 + 追踪止损 + 激进 ROI |
| **保护机制** | 追踪止损 + RSI 过滤 + EWO 动能过滤 + 固定止损 |
| **时间框架** | 主时间框架 5m + 信息时间框架 1h |
| **依赖库** | talib, numpy, qtpylib, technical |

### V0 版本特点

与标准版 SMAOffsetProtectOpt 相比，V0 版本有以下显著差异：

| 特性 | V0 版本 | 标准版 |
|------|---------|--------|
| ROI 配置 | 立即 1% | 分级（20%→7.4%→2.5%→0%） |
| 追踪止损 | 启用 | 未启用 |
| 卖出信号 | 仅盈利时 | 无限制 |
| 启动蜡烛数 | 30 | 200 |
| 卖出触发 | 价格 > ma_sell | 价格向下穿越 ma_sell |

**设计思路**：
- ROI 设置极其激进，只要有 1% 利润就立即止盈
- 追踪止损作为补充：如果价格继续上涨，追踪止损能锁住更多利润
- 追踪止损需要先涨 1% 才启动，避免在微利时就被震荡出局

### 2.2 卖出信号配置

```python
# 卖出信号配置

```

**解读**：
- 卖出信号只在盈利时生效，亏损时依靠固定止损
- 买入信号优先级高于 ROI，避免刚买入就被 ROI 止盈

## 三、买入条件详解

### 3.1 核心买入逻辑

策略使用 **EMA 偏移买入线** 作为核心入场参考：

```python
ma_buy = EMA(close, base_nb_candles_buy) * low_offset
# 默认：ma_buy = EMA(close, 20) * 0.975
```

当 `low_offset = 0.975` 时，买入线被下移 2.5%，创造"打折区"。

### 3.2 双通道买入条件

#### 条件 #1：EWO 高阈值买入（趋势确认型）

```python
# 逻辑
- 收盘价 < ma_buy（价格低于偏移均线）
- EWO > ewo_high（EWO 高于高阈值，表示上涨动能）
- RSI < rsi_buy（RSI 未过热）
- 成交量 > 0
```

**解读**：价格回调到打折区，但 EWO 显示上涨动能依然强劲，属于"强势回调买入"。

#### 条件 #2：EWO 低阈值买入（极端超卖型）

```python
# 逻辑
- 收盘价 < ma_buy（价格低于偏移均线）
- EWO < ewo_low（EWO 低于低阈值，表示极端超卖）
- 成交量 > 0
```

**解读**：价格深度下跌，EWO 达到极端负值，可能触底反弹，属于"抄底买入"。

### 3.3 买入条件分类

| 条件组 | 条件编号 | 核心逻辑 | 适用场景 |
|-------|---------|---------|---------|
| 趋势回调 | #1 | EWO 高 + RSI 正常 | 上升趋势中的健康回调 |
| 极端抄底 | #2 | EWO 极低 | 超卖反弹机会 |

## 四、卖出逻辑详解

### 4.1 多重退出机制

V0 版本采用三重退出机制：

```
退出优先级：
1. ROI 止盈（1%）→ 最优先
2. 追踪止损（启动后）→ 价格回撤触发
3. 卖出信号（仅盈利时）→ 价格高于偏移均线
```

### 4.2 卖出信号详解

```python
# 卖出条件
- 收盘价 > ma_sell * high_offset
- 成交量 > 0

# 其中 ma_sell = EMA(close, 24) * 1.012
```

**注意**：与标准版不同，V0 的卖出条件是"价格高于"而非"向下穿越"。这意味着只要价格涨到卖出线以上就触发。

### 4.3 追踪止损机制

```python
trailing_stop = True                    # 启用追踪止损
trailing_stop_positive = 0.001         # 追踪距离 0.1%
trailing_stop_positive_offset = 0.01   # 启动阈值 1%
trailing_only_offset_is_reached = True # 需达到阈值才启动
```

**工作流程**：
1. 买入后等待利润达到 1%
2. 利润 ≥ 1% 后，追踪止损开始工作
3. 追踪距离为 0.1%，即价格从最高点回撤 0.1% 就触发止损
4. 如果价格持续上涨，止损线会跟着上移

### 4.4 ROI 与追踪止损的协同

| 场景 | 触发机制 | 结果 |
|------|---------|------|
| 利润 < 1% | 无 | 继续持有 |
| 利润 = 1% | ROI 止盈 | 立即退出 |
| 利润 > 1% 且价格继续上涨 | 追踪止损 | 等待回撤 |
| 利润 > 1% 且价格回撤 0.1% | 追踪止损 | 退出锁定利润 |

**关键点**：由于 ROI 设为 1%，理论上价格涨到 1% 就会被 ROI 止盈。追踪止损主要在 ROI 不生效（如忽略 ROI）或价格快速突破时起作用。

## 五、技术指标体系

### 5.1 核心指标

| 指标类别 | 具体指标 | 用途 |
|---------|---------|------|
| 趋势指标 | EMA（可变周期） | 确定趋势方向和买卖基准线 |
| 动量指标 | Elliott Wave Oscillator (EWO) | 判断市场动能强度 |
| 摆动指标 | RSI（14周期） | 过滤过热买入信号 |
| 成交量 | Volume | 确保市场流动性 |

### 5.2 Elliott Wave Oscillator (EWO) 详解

```python
def EWO(dataframe, ema_length=5, ema2_length=35):
    ema1 = EMA(close, ema_length)   # 快速 EMA
    ema2 = EMA(close, ema2_length)  # 慢速 EMA
    emadif = (ema1 - ema2) / close * 100
    return emadif
```

**参数配置**：
- `fast_ewo = 50`：快速 EMA 周期
- `slow_ewo = 200`：慢速 EMA 周期

这是一个相对慢速的 EWO 配置，对长期趋势更敏感，对短期波动反应较慢。

## 六、风险管理特色

### 6.1 四层保护机制

| 保护层 | 机制 | 作用 |
|--------|------|------|
| 第一层 | 偏移买入线 | 只在打折区买入 |
| 第二层 | EWO 双通道 | 确认市场动能状态 |
| 第三层 | RSI 过滤 | 防止追高（条件 #1） |
| 第四层 | 追踪止损 | 锁定利润 |

### 6.2 激进 ROI 的设计哲学

V0 版本的 ROI 设置（立即 1%）体现了"小赚即跑"的理念：

**优点**：
- 快速实现盈利，减少持仓风险
- 适合高频交易，提高资金利用率
- 避免利润回撤

**缺点**：
- 可能错过大行情
- 手续费占比相对较高
- 需要较高的胜率才能盈利

### 6.3 卖出信号的盈利限制

```python
sell_profit_only = True
sell_profit_offset = 0.01
```

这确保卖出信号只在盈利 1% 以上时生效，避免亏损时被卖出信号止损。

## 七、策略优势与局限

### ✅ 优势

1. **激进 ROI 快速止盈**：1% 利润立即锁定，适合波动市场
2. **追踪止损锁利润**：价格持续上涨时能捕获更多收益
3. **双重买入通道**：既有趋势回调买入，也有极端抄底
4. **卖出信号盈利限制**：避免亏损时被误触卖出

### ⚠️ 局限

1. **ROI 过于激进**：1% 利润可能刚够手续费，实际收益低
2. **启动蜡烛数少**：30 根蜡烛对某些指标（如 EWO 200）不够
3. **信息框架代码问题**：`informative_pairs` 中指标添加位置不正确
4. **追踪止损与 ROI 冲突**：理论上 1% 就被 ROI 止盈，追踪止损难生效

## 九、适用市场环境详解

SMAOffsetProtectOptV0 是 **"高频小利"** 型策略，通过频繁交易获取小收益。最适合 **高波动震荡市场**，而在趋势行情中可能"卖飞"。

### 9.1 策略核心逻辑

- **激进 ROI**：1% 就跑，不贪心
- **追踪止损**：万一涨得更多，也能锁定
- **偏移买入**：只在打折区入场

### 9.2 不同市场环境表现

| 市场类型 | 表现评级 | 原因分析 |
| :--- | :--- | :--- |
| 📈 快速上涨 | ⭐⭐⭐☆☆ | 1% 就卖，容易卖飞 |
| 🔄 高波动震荡 | ⭐⭐⭐⭐⭐ | 适合频繁进出 |
| 📉 持续下跌 | ⭐⭐☆☆☆ | 频繁买入止损 |
| ⚡️ 低波动 | ⭐☆☆☆☆ | 难触发买卖信号 |

### 9.3 关键配置建议

| 配置项 | 建议值 | 说明 |
|--------|--------|------|
| minimal_roi | 根据市场调整 | 波动大可保持 1%，波动小需调高 |
| trailing_stop_positive | 0.01-0.02 | 追踪距离太小容易震荡出局 |
| 手续费考虑 | 计入成本 | 1% 利润扣除手续费后实际更低 |

## 十、重要提醒：复杂性的代价

### 10.1 学习成本

V0 版本的激进 ROI 需要理解其与追踪止损的关系：
- 两者可能冲突：ROI 在 1% 就触发，追踪止损可能没机会启动
- 需要根据市场调整 ROI 或追踪止损参数

### 10.2 硬件要求

| 交易对数量 | 最低内存 | 推荐内存 |
|-----------|---------|---------|
| 1-5 对 | 2GB | 4GB |
| 5-20 对 | 4GB | 8GB |
| 20+ 对 | 8GB | 16GB |

### 10.3 回测与实盘的差异

**手续费影响巨大**：
- 1% 利润 - 交易手续费（约 0.2-0.4%）= 实际利润 0.6-0.8%
- 高频交易手续费累积显著
- 回测需使用真实手续费设置

**启动蜡烛数不足**：
- `startup_candle_count = 30` 对 EWO 200 不够
- 建议至少 200 根蜡烛

### 10.4 手动交易者建议

如果手动参考此策略：
1. 考虑将 ROI 提高到 1.5-2%，扣除手续费后仍有利润
2. 追踪止损距离适当放宽，避免震荡出局
3. 关注手续费对高频交易的影响

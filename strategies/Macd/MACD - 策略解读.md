## 一、策略概览

**MACD** 策略是量化交易中最经典的策略之一，基于 Gerald Appel 创建的移动平均收敛散度（Moving Average Convergence Divergence）指标。MACD 通过短期和长期指数移动平均线的差值来判断趋势方向和动量变化。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | MACD > MACD Signal + CCI < 阈值 |
| **卖出条件** | MACD < MACD Signal + CCI > 阈值 |
| **保护机制** | 硬止损 |
| **时间框架** | 5 分钟 |
| **依赖库** | TA-Lib |
| **可优化** | CCI 参数支持 hyperopt 优化 |

## 三、买入条件详解

### 3.1 核心买入逻辑

```python
# 买入条件
(
    (dataframe['macd'] > dataframe['macdsignal']) &  # MACD 金叉
    (dataframe['cci'] <= self.buy_cci.value) &       # CCI 超卖
    (dataframe['volume'] > 0)                        # 有成交量
)
```

**信号解读**：
1. **MACD > Signal**：快线在慢线上方，趋势偏多
2. **CCI <= buy_cci**：CCI 处于超卖区域（默认 -48）
3. **volume > 0**：确保不是零成交量

### 3.2 CCI 参数含义

| 参数值 | 含义 | 典型范围 |
|--------|------|---------|
| 0 ~ -100 | 超卖区域 | 默认 -48 |
| -100 ~ 100 | 中性区域 | |
| 100+ | 超买区域 | |

## 四、卖出逻辑详解

### 4.1 核心卖出逻辑

```python
# 卖出条件
(
    (dataframe['macd'] < dataframe['macdsignal']) &  # MACD 死叉
    (dataframe['cci'] >= self.sell_cci.value) &     # CCI 超买
    (dataframe['volume'] > 0)                        # 有成交量
)
```

**信号解读**：
1. **MACD < Signal**：快线在慢线下方，趋势偏空
2. **CCI >= sell_cci**：CCI 处于超买区域（默认 687）

## 五、技术指标体系

### 5.1 MACD 指标详解

| 指标 | 计算公式 | 默认周期 |
|------|---------|---------|
| **MACD 线** | EMA12 - EMA26 | 12, 26 |
| **Signal 线** | MACD 的 EMA9 | 9 |
| **Histogram** | MACD - Signal | - |

### 5.2 CCI 指标详解

```
CCI = (Typical Price - SMA) / (0.015 × Mean Deviation)
```

| 区域 | CCI 值 | 信号含义 |
|------|--------|---------|
| 超卖区 | < -100 | 可能反弹 |
| 中性区 | -100 ~ 100 | 无明确信号 |
| 超买区 | > 100 | 可能回落 |

### 5.3 指标组合逻辑

```
买入信号 = MACD 金叉 + CCI 超卖
卖出信号 = MACD 死叉 + CCI 超买
```

## 七、策略优势与局限

### ✅ 优势

1. **经典可靠**：MACD 是经过 decades 验证的经典指标
2. **可优化**：CCI 参数支持 hyperopt 自动优化
3. **双确认**：MACD 趋势 + CCI 动量双重确认
4. **逻辑清晰**：代码简洁，易于理解和修改

### ⚠️ 局限

1. **滞后性**：MACD 本身是滞后指标
2. **震荡表现一般**：在横盘震荡时假信号多
3. **止损较大**：-30% 的止损幅度较大
4. **参数敏感**：CCI 阈值需要根据市场调整

## 十、重要提醒

### 10.1 CCI 参数的异常值

优化后的 sell_cci = 687 看起来很高，但实际上 CCI 的波动范围可以非常大：
- 在极端行情中，CCI 可以轻易超过 500
- 这意味着卖出条件变得非常"宽容"
- 实际卖出主要依赖 MACD 死叉

### 10.2 与 MACD_Cross 的区别

| 策略 | 买入条件 | 特点 |
|------|---------|------|
| **MACD** | MACD > Signal + CCI 条件 | 条件更严格 |
| **MACD_Cross** | MACD 上穿 Signal | 条件更宽松 |

## 十一、总结

**MACD** 策略是量化交易的经典之作，通过 MACD 和 CCI 的组合实现了趋势和动量的双重验证。

核心价值：
1. **经典传承**：MACD 是技术分析最常用指标之一
2. **可优化性**：支持 hyperopt 参数自动优化
3. **双确认机制**：趋势（MACD）+ 动量（CCI）
4. **清晰逻辑**：代码简洁，易于理解和修改

使用建议：
- 建议使用优化后的默认参数（buy_cci=-48, sell_cci=687）
- 适合中短线交易（5m-1h 时间框架）
- 需要根据市场波动性调整止损
- 在趋势明显的行情中效果最佳

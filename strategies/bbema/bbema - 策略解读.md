---

## 一、策略概览

bbema 是一个简洁的加密货币交易策略，采用了经典的 EMA 交叉与布林带回归相结合的设计思路。该策略是 Freqtrade 官方默认策略之一，因其代码简洁、易于理解而广受新手欢迎。

策略的核心逻辑是：当短期 EMA（10 期）上穿中期 EMA（50 期）时产生买入信号，视为上涨趋势确认；当短期 EMA 下穿中期 EMA 时产生卖出信号，视为下跌趋势确认。布林带作为辅助工具，帮助识别价格极端位置。

这是一个典型的"趋势跟踪 + 回归均值"组合策略，适合长期趋势行情。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 1 个独立买入信号（EMA 金叉） |
| **卖出条件** | 1 个独立卖出信号（EMA 死叉） |
| **保护机制** | 无显式保护机制 |
| **时间框架** | 1 小时 |
| **依赖库** | talib, technical (qtpylib) |

## 二、策略配置解析

### 2.1 基础风险参数

```python
# ROI 退出表
minimal_roi = {
    "0": 0.20    # 持有立即退出需要 20% 利润
}

# 止损设置
stoploss = -0.10  # 10% 固定止损
```

**设计思路**：

20% 的即时止盈阈值非常激进，对于 1 小时时间框架来说意味着需要相当大的价格波动才能触发。这反映了策略作者对长期趋势的预期——宁可等待大趋势，也不频繁小额止盈。

10% 的固定止损是加密货币市场的标准设置之一。

## 三、买入条件详解

### 3.1 单一买入条件

```python
dataframe["close10"] = dataframe["close"].shift(periods=-10)
dataframe.loc[
    (qtpylib.crossed_above(dataframe["ema10"], dataframe["ema50"])), "buy"
] = 1
```

**逻辑分解**：

1. **ema10 > ema50**：10 期 EMA 在 50 期 EMA 上方
2. **crossed_above**：今天 EMA10 上穿 EMA50（金叉）

**技术含义**：

EMA 金叉是经典的趋势确认信号。当短期 EMA 从下方穿越长期 EMA 时，通常被视为看涨信号。

---

## 四、卖出逻辑详解

### 4.1 单一卖出条件

```python
dataframe.loc[
    (qtpylib.crossed_above(dataframe["ema50"], dataframe["ema10"])), "sell"
] = 1
```

**逻辑分解**：

1. **ema50 > ema10**：50 期 EMA 在 10 期 EMA 上方
2. **crossed_above**：今天 EMA50 上穿 EMA10（死叉）

**对称性设计**：

买入和卖出条件完全对称，这种设计使得策略在多空两个方向都能有效运作。

## 七、策略优势与局限

### ✅ 优势

1. **代码简洁**：易于理解和修改
2. **多空对称**：完整的双向交易系统
3. **参数简单**：仅两个 EMA 参数
4. **学习友好**：适合新手学习

### ⚠️ 局限

1. **无保护机制**：没有过滤条件
2. **止盈难触发**：20% 阈值较高
3. **无趋势过滤**：不区分牛熊市

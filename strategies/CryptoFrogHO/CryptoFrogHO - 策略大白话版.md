## 十二、这策略的"独门秘籍"

### 🔮 平滑 Heiken Ashi

```python
def HA(dataframe, smoothing=4):
    # 计算 HA 收盘价
    HA_Close = (open + high + low + close) / 4
    
    # 计算 HA 开盘价（用 EMA 平滑）
    HA_Open = EMA((open + close) / 2, smoothing)
    
    # 计算 HA 最高/最低
    HA_High = max(HA_Open, HA_Close, high)
    HA_Low = min(HA_Open, HA_Close, low)
```

> "HA 就像'滤镜'，去掉市场的'噪点'，让你看到更真实的价格走势！"

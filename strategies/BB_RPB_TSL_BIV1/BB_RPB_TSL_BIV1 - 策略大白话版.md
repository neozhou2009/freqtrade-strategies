## 二、核心配置：说白了就是"抄底+保镖"

### 止盈规则（ROI 表）

```
目标利润：20.5%才自动止盈
```

**翻译**：这策略不指望 ROI 自动止盈，主要靠后面的智能止损和卖出信号。ROI 只是最后一道防线，就像存钱罐满了才倒出来。

### 止损规则

```
固定止损：-10%（后备）
实际止损：动态追踪，利润越高锁得越紧
```

**翻译**：有个 -10% 的硬止损当保险，但真正干活的是那个智能保镖：
- 利润 3% 以上 → 锁定 1.5%，跌回来 1.5% 就跑
- 利润 6% 以上 → 锁定 2%，跌回来 2% 就跑
- 利润 10% 以上 → 锁定 3%，跌回来 3% 就跑
- 利润 20% 以上 → 锁定 5%，跌回来 5% 就跑

**这保镖的逻辑**：钱赚得越多，越怕被抢回去，所以盯得越紧！💰

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **覆盖面广**：14种买入模式，从趋势回调到极端超跌都有
2. **智能止损**：利润越高锁得越紧，比普通止损聪明多了
3. **多层保护**：BTC保镖、1h验证、滑点过滤三重保险
4. **退出灵活**：追踪止损、信号退出、快速止盈多种方式

### ⚠️ 缺点（吐槽环节）

1. **太复杂了**：14个买入条件+多层卖出，代码600多行，看晕了 🤯
2. **参数太多**：几十个 Hyperopt 参数，"完美回测"可能只是背答案
3. **硬件要求高**：计算量大，老电脑可能跑不动
4. **入场机会少**：保镖太多，入场条件苛刻，有时候一整天没交易

1. 先回测了解策略特点
2. 简化条件（关掉不理解的条件）
3. 小仓位实盘测试（10%资金）

## 一、策略概览

SMAIP3 是一个基于均线偏离原理的趋势跟踪策略，结合了 EMA 趋势过滤、均线偏离买入和动态追踪止损机制。该策略通过 Hyperopt 参数优化框架，实现了买卖参数的自适应调整，同时内置"坏交易对"检测机制，过滤高风险交易环境。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 1 个复合买入信号，包含 5 个条件同时满足 |
| **卖出条件** | 1 个复合卖出信号，包含 2 个条件同时满足 |
| **保护机制** | 固定止损 (-33.1%) + 追踪止损 + ROI 分级退出 + 坏交易对过滤 |
| **时间框架** | 5 分钟主时间框架 |
| **依赖库** | talib, pandas, datetime |
| **特色功能** | Hyperopt 参数优化、坏交易对检测 |

## 三、买入条件详解

### 3.1 保护机制

策略内置"坏交易对"检测机制：

```python
# 坏交易对定义
dataframe['pair_is_bad'] = (
    (((dataframe['open'].shift(12) - dataframe['close']) / dataframe['close']) >= pair_is_bad_1_threshold) |
    (((dataframe['open'].shift(6) - dataframe['close']) / dataframe['close']) >= pair_is_bad_2_threshold)
).astype('int')
```

| 检测类型 | 参数说明 | 默认值 |
|---------|---------|--------|
| 12周期前开盘价跌幅 | 当前价较12周期前开盘价跌幅阈值 | 13.0% |
| 6周期前开盘价跌幅 | 当前价较6周期前开盘价跌幅阈值 | 7.5% |

**设计目的**：当价格短时间内大幅下跌时，判定为高风险交易对，避免买入。

### 3.2 买入条件分解

策略采用单一复合买入条件，需要同时满足以下 5 个条件：

```python
dataframe.loc[
    (
        (dataframe['ema_50'] > dataframe['ema_200']) &  # 趋势过滤
        (dataframe['close'] > dataframe['ema_200']) &  # 价格在长期均线上方
        (dataframe['pair_is_bad'] < 1) &                # 不是坏交易对
        (dataframe['close'] < dataframe['ma_offset_buy']) &  # 价格低于偏离均线
        (dataframe['volume'] > 0)                       # 有成交量
    ),
    'buy'] = 1
```

| 条件编号 | 条件名称 | 逻辑说明 | 作用 |
|---------|---------|---------|------|
| #1 | 趋势过滤 | EMA50 > EMA200 | 确认处于上升趋势 |
| #2 | 价格位置 | 收盘价 > EMA200 | 价格在长期均线上方 |
| #3 | 坏交易对过滤 | pair_is_bad < 1 | 避免暴跌中的交易对 |
| #4 | 偏离买入 | 收盘价 < 偏离均线 | 价格回调时买入 |
| #5 | 成交量确认 | 成交量 > 0 | 过滤无效信号 |

### 3.3 偏离均线计算

```python
# 买入偏离均线
ma_offset_buy = SMA/EMA(close, base_nb_candles_buy) * low_offset
# 默认: EMA(18) * 0.968
```

**计算逻辑**：
- 使用 18 周期均线（SMA 或 EMA）
- 乘以 0.968 的偏离系数
- 形成低于均线的买入触发线

## 四、卖出逻辑详解

### 4.1 ROI 分级止盈

策略采用四级 ROI 退出机制：

```
持有时间      目标利润率    信号名称
──────────────────────────────────
0 分钟        13.5%        激进止盈
35 分钟       6.1%         中期止盈
86 分钟       3.7%         保本止盈
167 分钟      0%           强制退出
```

### 4.2 追踪止损机制

```
追踪止损触发流程：
├── 盈利达到 9.8% → 启动追踪止损
├── 价格继续上涨 → 止损位跟随上移
└── 利润回撤到 15.9% → 触发卖出
```

**机制特点**：
- 需要盈利 9.8% 才启动追踪，避免小利润被震荡出局
- 偏移值 15.9% 高于启动值，给价格足够波动空间
- 只有达到偏移值才启动追踪，减少无效触发

## 六、风险管理特色

### 6.1 坏交易对检测机制

**检测逻辑**：
- 12 周期前开盘价较当前价跌幅 ≥ 13% → 标记为坏交易对
- 6 周期前开盘价较当前价跌幅 ≥ 7.5% → 标记为坏交易对

**设计目的**：
- 过滤短期暴跌的交易对
- 避免"接飞刀"风险
- 动态调整，实时检测

### 6.2 趋势过滤双保险

```
趋势确认机制：
├── EMA50 > EMA200 → 确认短期趋势向上
└── close > EMA200 → 确认价格在长期均线上方
```

**双重确认**：只有两个条件都满足才买入，确保处于明确的上升趋势中。

### 6.3 追踪止损精细化

```python
trailing_stop = True
trailing_stop_positive = 0.098        # 9.8%启动
trailing_stop_positive_offset = 0.159  # 15.9%触发
trailing_only_offset_is_reached = True # 只有达到偏移才追踪
```

**设计亮点**：
- 不急于追踪，等盈利到一定程度才启动
- 给价格足够波动空间
- 避免被小波动震出局

## 七、策略优势与局限

### ✅ 优势

1. **趋势确认严格**：EMA50/200 双重过滤，确保在上升趋势中买入
2. **坏交易对过滤**：避免在暴跌中买入，风险控制主动
3. **参数可优化**：通过 Hyperopt 框架自动优化参数
4. **追踪止损精细**：避免小利润被震荡出局
5. **买入逻辑合理**：趋势向上 + 价格回调时买入

### ⚠️ 局限

1. **止损较宽**：33.1% 止损可能过大，需要配合资金管理
2. **参数依赖优化**：默认参数可能不适合所有交易对
3. **卖出条件简单**：只依赖偏离均线卖出，缺少多重确认
4. **激进目标**：13.5% 的初始目标可能难以达到

## 九、适用市场环境详解

SMAIP3 策略是一个**趋势跟踪 + 回调买入策略**。基于其代码架构和 Hyperopt 优化设计，它最适合**上升趋势中的回调行情**，而在**震荡或下跌市场**时表现不佳。

### 9.1 策略核心逻辑

- **趋势确认**：EMA50 > EMA200 确认上升趋势
- **位置确认**：close > EMA200 确保价格在长期均线上方
- **回调买入**：close < ma_offset_buy 在回调时买入
- **风险过滤**：pair_is_bad 避免暴跌交易对
- **偏离卖出**：close > ma_offset_sell 达到目标位卖出

### 9.2 不同市场环境表现

| 市场类型 | 表现评级 | 原因分析 |
| :--- | :--- | :--- |
| 📈 上升趋势回调 | ⭐⭐⭐⭐⭐ | 最适合场景，买回调效果最佳 |
| 🔄 横盘震荡 | ⭐⭐⭐☆☆ | 趋势过滤减少信号，但偶尔有交易 |
| 📉 单边下跌 | ⭐☆☆☆☆ | 趋势过滤阻止买入，基本无信号 |
| ⚡️ 剧烈波动 | ⭐⭐☆☆☆ | 坏交易对过滤可能过敏感 |

### 9.3 关键配置建议

| 配置项 | 建议值 | 说明 |
|--------|--------|------|
| 止损 | -0.25 ~ -0.35 | 根据交易对波动性调整 |
| low_offset | 0.95 ~ 0.98 | 调低增加入场机会 |
| high_offset | 1.05 ~ 1.10 | 调高延长持仓时间 |
| 时间框架 | 5m (默认) | 可尝试 15m 获得更稳定信号 |

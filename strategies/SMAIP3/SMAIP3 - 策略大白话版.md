# SMAIP3 策略：趋势回调狙击手

> **外号**：均线偏离猎手  
> **职业**：趋势回调狙击手 + 参数优化专家  
> **时间框架**：5 分钟

---

## 一、这策略是个啥？

简单说，**SMAIP3** 就是一个：
- 专门在上升趋势中买回调
- 用均线偏离决定买卖点
- 自动检测"坏交易对"避险
- 参数可以通过 Hyperopt 自动优化

就像**在高速公路上等车减速再上车**，不追高，只在回调时入场！🎯

---

## 二、核心配置：说白了就是"等回调再买"

### 止盈规则（ROI 表）

```
0 分钟   → 赚 13.5% 就跑（激进）
35 分钟  → 赚 6.1% 就跑
86 分钟  → 赚 3.7% 就跑
167 分钟 → 保本就跑
```

**翻译**：一上来想赚 13.5%，时间长了保本也行。典型的"有利润就跑"型选手。

### 止损规则

```
固定止损：-33.1%（很宽！）
追踪止损：盈利 9.8% 后启动
追踪触发：利润回撤到 15.9%
```

**翻译**：
- 止损很宽，给足波动空间
- 赚到 9.8% 后开始追踪
- 利润回撤到 15.9% 才卖
- 给价格足够的"呼吸空间"

## 三、买入条件：5 个条件缺一不可

这策略的买入条件就像**安检一样严格**：

### 🎯 条件 #1：趋势向上

```python
dataframe['ema_50'] > dataframe['ema_200']
```

**大白话**：
> "短期均线（50周期）在长期均线（200周期）上面，趋势向上！"

### 📈 条件 #2：价格在长期均线上方

```python
dataframe['close'] > dataframe['ema_200']
```

**大白话**：
> "价格站在 200 周期均线上面，不是跌势！"

### 🚫 条件 #3：不是"坏交易对"

```python
dataframe['pair_is_bad'] < 1
```

**大白话**：
> "这个币没在暴跌！之前 12 根K线跌了超过 13% 或者 6 根K线跌了超过 7.5% 的，我不买！"

### 📉 条件 #4：价格低于偏离均线

```python
dataframe['close'] < dataframe['ma_offset_buy']
```

**大白话**：
> "价格回调了，现在比均线低了 3.2%，可以买了！"

### 🔊 条件 #5：有成交量

```python
dataframe['volume'] > 0
```

**大白话**：
> "不是死币，有人在交易。"

## 四、卖出逻辑：简单直接

这策略的卖出逻辑比买入简单多了：

### 卖出条件：价格超过偏离均线

```python
dataframe['close'] > dataframe['ma_offset_sell']
```

**大白话**：
> "价格涨到比均线高 7%，卖！"

**吐槽**：买入 5 个条件，卖出就 2 个条件（价格 + 成交量），这不对称啊 😅

## 五、保护机制：三层"安全网"

| 保护类型 | 作用 | 大白话 |
|---------|------|--------|
| 固定止损 -33.1% | 亏太多就跑 | "最多亏 33%，再疼就不玩了" |
| 追踪止损 | 赚钱后跟着涨 | "赚了 9.8% 后就开始盯盘" |
| 坏交易对检测 | 避开暴跌币 | "暴跌的币我不碰" |

**吐槽**：
- 33% 的止损真的有点宽...有的币跌 33% 就没救了
- 但也给了足够的波动空间，不容易被震荡出局

### 坏交易对检测的妙用

```
检测逻辑：
├── 12 周期前开盘价 vs 当前价
│   └── 跌幅 ≥ 13% → 标记为"坏交易对"
└── 6 周期前开盘价 vs 当前价
    └── 跌幅 ≥ 7.5% → 标记为"坏交易对"
```

**大白话**：
> "如果这个币 12 根K线跌了 13% 或者 6 根K线跌了 7.5%，说明它在暴跌，我不买！"

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **趋势确认严格**：EMA50/200 双重过滤，不逆势交易
2. **回调买入**：不在高点追，等回调再买
3. **坏交易对过滤**：自动避开暴跌币，这个设计很聪明
4. **追踪止损精细**：不是一有利润就追踪，给足波动空间
5. **参数可优化**：Hyperopt 可以自动找最优参数

### ⚠️ 缺点（吐槽环节）

1. **止损太宽**：33% 止损，有的币跌 33% 就凉了
2. **买入信号少**：5 个条件全满足，信号不多
3. **卖出太简单**：就一个偏离卖出，没有多重确认
4. **目标太激进**：13.5% 的目标有点贪心
5. **需要优化**：默认参数不一定适合你的交易对

### 10.2 Hyperopt 参数说明

```python
# 买入参数
base_nb_candles_buy = 18   # 均线周期，可优化
low_offset = 0.968         # 偏离系数，越小买入越早
buy_trigger = "EMA"       # SMA 或 EMA

# 卖出参数  
base_nb_candles_sell = 55  # 均线周期，可优化
high_offset = 1.07        # 偏离系数，越大持仓越长
sell_trigger = "EMA"      # SMA 或 EMA

# 风险参数
pair_is_bad_1_threshold = 0.13  # 12周期跌幅阈值
pair_is_bad_2_threshold = 0.075 # 6周期跌幅阈值
```

这策略计算量不大，对硬件要求不高：

**Hyperopt 优化过的参数要小心！**

**建议流程**：

2. 用样本外数据验证参数有效性
3. 用模拟盘跑一周
4. 小资金实盘测试
5. 持续监控和调整

**别一上来就梭哈**，优化过的参数可能过拟合！

## 十三、⚠️ 风险再强调（这段一定要看）

### Hyperopt 优化的陷阱

SMAIP3 是一个**参数优化策略**——但这有个陷阱：

> **优化过的参数可能"背答案"——在历史数据上表现很好，但未来不一定有效。**

简单说就是：**历史考试考得好，不代表高考能考上**

### 宽止损的风险

33% 的止损看起来给了足够空间，但也有风险：
- **资金管理困难**：单笔亏损可能很大
- **心态考验**：看着浮亏 20% 很难受
- **可能错过止损**：跌太快可能直接穿仓

### 实盘的隐藏风险

实盘时要注意：
- **坏交易对检测敏感度**：可能错过一些机会
- **趋势判断滞后**：EMA 确认需要时间
- **回调买不到**：可能一直等不到回调

### 我的建议（真心话）

```
1. 止损调整到 15-25%，别用 33%
2. 初始目标调到 8-10%，别贪 13.5%
3. 用样本外数据验证优化参数
4. 监控坏交易对检测，可能需要调整阈值
```

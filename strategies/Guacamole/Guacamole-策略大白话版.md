# Guacamole 策略：多指标"鳄梨酱"混合策略

> **外号**：鳄梨酱先生、指标大杂烩  
> **职业**：多指标动量捕手 + 订单簿精细管家  
> **时间框架**：5 分钟 (5m)

---

## 一、这策略是个啥？

简单说，**Guacamole**（鳄梨酱）就是一个：
- 把 KAMA、MACD、RMI、SAR 多个指标混在一起用
- 还要查订单簿确认价格
- 追踪止损锁利润
- 参数都是超参数优化算出来的

就像做鳄梨酱需要混合多种食材一样，这个策略把多个指标"拌"在一起，每个指标都要点头才能下单 🥑

**一句话总结**：多指标 + 订单簿 + 追踪止损的"三保险"策略。

## 二、核心配置：说白了就是"赚够就跑，亏了有底线"

### 止盈规则（ROI 表）

```
0 分钟   → 赚 13.34% 跑
19 分钟  → 赚 7.46% 跑
37 分钟  → 赚 4.21% 跑
57 分钟  → 赚 2.68% 跑
73 分钟  → 赚 1.23% 跑
125 分钟 → 赚 0.37% 跑
244 分钟 → 赚 0.25% 跑
```

**翻译**：刚买进去要求赚 13% 才卖，但时间越久门槛越低。超过 4 小时（244 分钟）赚 0.25% 就跑——主打一个"活着最重要"。

### 止损规则

```
止损线：-10%
追踪止损：开启
追踪启动：利润 1.85%
追踪回撤：1.67%
```

**翻译**：
- 亏 10% 强制割肉
- 赚到 1.85% 后启动"保镖模式"
- 从最高点回撤 1.67% 就自动卖

**大白话**：亏太多认栽，赚到了就上保险，保住胜利果实 🛡️

## 三、买入条件：两大类场景

这策略把买入分成两种场景：没持仓和有持仓。

### 🎯 场景 1：没持仓时开新仓（6 条件全满足）

**核心逻辑**：多指标一起确认，"全员同意才上车"

**大白话**：
> "我要 KAMA 说涨、MACD 说涨、RMI 说涨、成交量还得正常，全员点头我才买！"

**6 个条件逐一翻译**：

| 条件 | 代码 | 大白话 |
|------|------|--------|
| KAMA 趋势 | `kama-3 > kama-21` | 快线比慢线高，趋势向上 |
| MACD 金叉 | `macd > macdsignal` | MACD 在信号线上方，动量向上 |
| MACD 阈值 | `macd > -0.75` | MACD 不能太低（阈值 -0.75） |
| MACD 柱阈值 | `macdhist > -1` | MACD 柱不能太低 |
| RMI 上升 | `rmi > rmi.shift()` | RMI 比上一根高，正在上升 |
| RMI 阈值 | `rmi > 49` | RMI 大于 49 |
| 成交量过滤 | `volume < volume_ma × 20` | 成交量不能是均量 20 倍（排除异常） |

**吐槽**：条件是真多啊！不过这也说明——不轻易出手，出手就认准了 🎯

---

### 📈 场景 2：有持仓时加仓（2 条件）

**核心逻辑**：已有仓位，只有趋势超强才加仓

**大白话**：
> "手里已经有货了？那得 RMI 冲到 75 以上、价格还在 SAR 上面，我才敢加仓！"

**条件翻译**：

| 条件 | 代码 | 大白话 |
|------|------|--------|
| 价格 > SAR | `close > sar` | 价格在抛物线 SAR 上方，趋势向上 |
| RMI 超强 | `rmi >= 75` | RMI 冲到 75，动量爆表 |

**评价**：加仓门槛很高，不会乱加——理性加仓党 ✋

## 四、保护机制：三层"保镖"

每个买入条件虽然没有独立保护参数组，但策略整体有三层保护：

| 保护类型 | 参数 | 大白话 |
|---------|------|--------|
| **硬止损** | -10% | 亏 10% 强制割，认栽 |
| **追踪止损** | 1.67% 回撤 | 赚到了就上保险，回撤 1.67% 就跑 |
| **订单超时** | 1% 价格偏离 | 价格跑太远就撤单，不追 |

**大白话**：
- 第一层：亏太多认栽（-10% 止损）
- 第二层：赚到了就保住（追踪止损）
- 第三层：价格跑太快就不追（订单超时）

"三保镖"护航，主打一个**活着最重要** 🛡️

## 五、卖出逻辑：比买入简单多了

### 5.1 卖出条件（3 条件同时满足）

```python
# 有持仓时检查卖出
rmi < 30          # RMI 进入超卖区
current_profit > -0.03  # 亏损不超过 3%
volume > 0        # 有成交量
```

**大白话**：
> "RMI 跌到 30 以下了？好，让我看看亏多少……亏不到 3%？那就卖了吧！"

**翻译**：
- RMI < 30：动量转弱，进入超卖
- 利润 > -3%：亏损不超过 3% 才卖（避免大亏割肉）
- 成交量 > 0：防止异常数据

**评价**：卖出逻辑很克制——不是一跌就卖，而是等动量确认转弱、亏损可控才卖。

---

### 5.2 订单超时检查（特色功能）

**买入订单超时**：
```python
if 当前价格 > 订单价格 × 1.01:
    取消订单  # 价格涨超 1%，撤单不追
```

**卖出订单超时**：
```python
if 当前价格 < 订单价格 × 0.99:
    取消订单  # 价格跌超 1%，撤单重挂
```

**大白话**：
- 买单挂出去，价格涨超 1%？不追了，撤单！
- 卖单挂出去，价格跌超 1%？不贱卖了，撤单重挂！

**吐槽**：这是怕滑点亏钱啊——精细管家模式 💼

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **多指标确认**：KAMA + MACD + RMI + SAR 四大指标一起确认，信号可靠
2. **订单簿检查**：用实时订单簿价格判断，不依赖 K 线收盘价
3. **订单超时保护**：价格跑太快就撤单，不追涨杀跌
4. **追踪止损**：赚到了就锁定利润，不让煮熟的鸭子飞了
5. **参数优化过**：ROI 和追踪参数都是超参数优化结果（注意：也可能是过拟合）

### ⚠️ 缺点（吐槽环节）

1. **条件多**：买入要 6 个条件全满足，信号可能偏少
2. **无趋势过滤**：没有 EMA/SMA 长期趋势判断，下跌市容易亏
3. **无 BTC 关联**：不看比特币大盘，独立操作有风险
4. **依赖订单簿**：需要交易所支持 orderbook API，回测可能不准
5. **参数可能过拟合**：超参数优化结果可能只是"背答案"

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

Guacamole 的历史回测表现可能**很漂亮**——但这有个陷阱：

> **参数是超参数优化算出来的，很可能只是"背答案"——完美拟合历史数据，但未来不一定管用。**

简单说就是：**历史考试得了满分，不代表下次考试还能满分。**

### 复杂策略的隐藏风险

实盘时，多个指标和订单簿检查可能导致：
- **信号太少**：6 个条件全满足，机会不多
- **订单簿延迟**：实时数据可能延迟，影响判断
- **过拟合陷阱**：优化参数可能只是背答案
- **暴跌风险**：无趋势过滤，下跌市容易连续亏损

### 订单簿数据风险

策略依赖订单簿 API，但：
- 回测时订单簿数据可能不准确
- 实盘时订单簿可能有延迟
- 部分交易所不支持订单簿 API

### 我的建议（真心话）

```
1. 先跑回测，看策略在你的交易对上表现如何
2. 用 dry-run 模拟盘测试至少 1 个月
3. 小额实盘测试，别一上来就梭哈
4. 震荡市用，暴跌市暂停或轻仓
5. 注意过拟合风险，参数可能只是"背答案"
```

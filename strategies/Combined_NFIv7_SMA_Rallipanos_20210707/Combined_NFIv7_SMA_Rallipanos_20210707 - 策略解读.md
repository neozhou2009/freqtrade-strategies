## 一、策略概览

**Combined_NFIv7_SMA_Rallipanos_20210707** 是由 Freqtrade 社区知名开发者 **iterativ** 创作的 NostalgiaForInfinityV7 系列策略的变体版本。该策略创建于 2021年7月07日，继承了对称无限（ Nostalgia For Infinity）系列的核心设计理念，融合了多种技术指标保护机制和多时间框架分析，形成了一套复杂但高效的买入/卖出信号体系。

从策略架构来看，该策略采用了"保护层 + 核心信号"的双层过滤机制。每一组买入条件都配备了 EMA 均线保护、SMA200 趋势保护、以及针对"跌入"（dip）和"泵送"（pump）的特殊保护机制。这种设计大幅降低了在极端市场条件下触发虚假信号的概率。

策略的时间框架设计体现了"长短结合"的思路：主时间框架 5 分钟用于捕捉短期交易机会，而 1 小时时间框架则用于确认长期趋势方向。这种跨时间框架的分析方法使得策略能够在不同的市场环境下保持较好的适应性。

### 核心特征

| 特征 | 描述 |

| **依赖库** | TA-Lib, technical (qtpylib), numpy, pandas, zema |

## 二、策略配置解析

### 2.1 基础风险参数

```python
# ROI 退出表（时间: 最小利润率）
minimal_roi = {
    "0": 0.10,      # 持仓立即可获得 10% 利润
    "30": 0.05,     # 30 分钟后 5% 利润
    "60": 0.02,     # 60 分钟后 2% 利润
}

# 止损设置
stoploss = -0.10   # 10% 硬止损

# 追踪止损
trailing_stop = True
trailing_only_offset_is_reached = True
trailing_stop_positive = 0.005
trailing_stop_positive_offset = 0.030
```

**设计思路**：
- ROI 表采用了递减式设计，初始 10% 止盈体现了策略对大趋势的追求
- 30 分钟时降至 5%，60 分钟后降至 2%，这种设计允许持仓更长时间来捕捉更大的趋势
- 硬止损设置为 -10%，这是相对宽松的止损幅度，给趋势足够的演化空间
- 追踪止损配置为正追踪 0.5% 启动，偏移触发点 3.0% 生效，这种"延迟启动"设计可以避免在震荡行情中被频繁触发

### 2.2 订单类型配置

```python
order_types = {
    'entry': 'limit',           # 限价单入场
    'exit': 'limit',            # 限价单出场
    'stoploss': 'limit',        # 限价单止损
    'stoploss_on_exchange': False
}
```

**配置说明**：
- 使用限价单进行交易，可以获得更好的成交价格，降低交易成本
- 禁用交易所内置止损，使用 Freqtrade 本地止损逻辑

### 2.3 退出信号配置

```python
use_exit_signal = True
exit_profit_only = True
ignore_roi_if_entry_signal = True
```

**配置说明**：
- `use_exit_signal = True` 启用退出信号
- `exit_profit_only = True` 确保只在盈利时卖出，避免割肉
- `ignore_roi_if_entry_signal = True` 允许入场信号覆盖 ROI 退出，确保不遗漏新的交易机会

## 三、买入条件详解

该策略包含 **26 个独立的买入条件**（buy_condition_1 到 buy_condition_26，跳过了 buy_condition_25），每个条件都可独立启用或禁用。每个买入条件都包含以下保护机制的组合：

### 3.1 保护机制类型

1. **EMA 均线保护** - 检查价格与 EMA 的相对位置
   - `ema_fast`: 快速 EMA 周期配置
   - `ema_slow`: 慢速 EMA 周期配置
   - `close_above_ema_fast`: 收盘价高于快速 EMA
   - `close_above_ema_slow`: 收盘价高于慢速 EMA

2. **SMA200 趋势保护** - 确认长期趋势方向
   - `sma200_rising`: 200日均线上升
   - `sma200_1h_rising`: 1小时时间框架的200日均线上升

3. **安全跌入保护 (Safe Dips)** - 过滤过度下跌后的买入
   - 10级到110级共11个级别的跌入阈值
   - 级别越高，允许的下跌幅度越大

4. **安全泵送保护 (Safe Pump)** - 过滤暴涨后的买入
   - 24/36/48小时三种时间窗口
   - 10级到120级共12个级别的泵送阈值
   - 级别越高，允许的价格波动越大

### 3.2 核心买入条件分类

**条件1-6**：基于 EMA 交叉和布林带反弹的早期买入信号
- 使用严格的 Dip 保护（10-40级）
- 适合捕捉趋势启动点

**条件7-14**：基于成交量和动量指标的买入信号
- 融入 EWO（Elliott Wave Oscillator）分析
- 适合捕捉趋势加速点

**条件15-24**：基于 SMA200 趋势确认的买入信号
- 强调长期趋势保护
- 适合趋势中的回调买入

**条件26**：特殊的 ZEMA 低位买入条件
- 使用零滞后 EMA
- 参数可优化

## 四、卖出逻辑详解

### 4.1 基础卖出条件 (8个)

策略包含 8 个独立的卖出条件，每个条件都可独立启用：

## 六、风险管理特色

### 6.1 多层保护机制

该策略的风险管理特色在于其**多层保护机制**：

1. **入场前保护**：通过 8 种不同的保护机制过滤高风险信号
2. **持仓中期管理**：通过追踪止损和动态止盈保护利润
3. **极端情况处理**：通过自定义止损和恢复机制处理长期浮亏

### 6.2 泵送保护 (Pump Protection)

策略使用复杂的泵送保护机制来避免在价格暴涨后买入：

- 24/36/48小时三种时间窗口检测价格波动
- 12个不同级别的阈值（10-120）适应不同波动性的币种
- 区分"安全泵送"（可买入）和"危险泵送"（需卖出）

### 6.3 跌入保护 (Dip Protection)

策略使用多级别跌入保护来捕捉回调买入机会：

- 11个级别（10-110）对应不同的买入强度
- 4个时间窗口（0/2/12/144根K线）的价格变化检测
- 级别越高，允许的回调幅度越大

## 七、策略优势与局限

### 7.1 优势

1. **多条件冗余**：26个买入条件和8个卖出条件提供了高度冗余，单一条件失效不影响整体表现
2. **适应性强**：多级别保护机制使策略能够适应不同波动性的市场
3. **趋势追踪能力强**：宽松的止损设置允许趋势充分发展
4. **双时间框架确认**：1小时趋势确认减少了短期噪音干扰

### 7.2 局限

1. **参数复杂**：大量可调参数需要专业知识和时间进行优化
2. **交易频率可能较低**：严格的保护机制可能过滤掉一些有效信号
3. **对市场环境敏感**：在剧烈波动的市场中可能表现不佳
4. **资源消耗较大**：多时间框架计算和大量指标需要更多计算资源

## 九、适用市场环境详解

### 9.1 最佳市场环境

**牛市上涨趋势**：
- 价格持续上涨，趋势明确
- 回调幅度适中，不会触及硬止损
- 成交量配合，价格上涨有力度

**下跌反弹行情**：
- 前期大幅下跌后企稳
- 出现明显的反转信号
- 交易量开始放大

### 9.2 较差市场环境

**横盘震荡**：
- 价格在一定区间内反复波动
- 频繁触发买入和卖出条件
- 可能造成反复止损

**剧烈波动**：
- 短时间内大幅上涨或下跌
- 泵送保护可能过于敏感
- 追踪止损可能被频繁触发

### 9.3 市场周期适配

| 市场阶段 | 策略表现 | 建议调整 |
|----------|----------|----------|
| 牛市初期 | ⭐⭐⭐⭐⭐ | 正常使用 |
| 牛市末期 | ⭐⭐⭐ | 降低仓位 |
| 熊市 | ⭐⭐ | 减少交易对 |
| 震荡市 | ⭐⭐⭐ | 增加止损幅度 |

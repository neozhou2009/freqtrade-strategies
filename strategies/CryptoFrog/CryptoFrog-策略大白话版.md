## 一、这策略是个啥？

简单说，**CryptoFrog** 就是一个：
- 用 **平滑 Heiken Ashi** 过滤噪音的策略
- 等 **布林带扩张**（波动要爆发）才入场的策略
- 用 **线性衰减止损**（随时间慢慢放松）的策略
- 有 **动态 ROI**（趋势中不停盈）的策略

就像一只青蛙蹲在荷叶上，等蚊子飞过来才伸舌头——平时不动声色，机会来了就精准出击！🐸✨

**翻译**：官方止损看起来还行（-8.5%），但实际上策略写了一套"慢慢放松"的止损逻辑——开仓后随着时间推移，止损线会逐渐向 0 移动，给你更多时间等待反弹！

### 🐸 技巧三：DMI 交叉 + 布林带底


**大白话**："DMA 交叉了！而且价格还在布林带底下，这是送钱啊！"

### 🔒 最后一道防线：成交量确认


**大白话**：光价格信号还不够，得有钱进来才算数！

### 4.2 动态 ROI：趋势中不停盈

这策略有个"聪明"的动态 ROI 系统：

```
如果在趋势中（RMI 涨 / SSL 向上 / K线涨）
→ 忽略 ROI 表，一直持有直到趋势结束！

如果价格开始回撤
→ 从最高点回落到一定幅度，就卖出一半！
```

**大白话**："趋势还在？那就继续持有，让利润奔跑！只要开始回落，就跑一半再说！"

### 4.3 线性衰减止损：随时间放松

```
开仓时间 → 止损线
0 分钟 → -8.5%
30 分钟 → -7.0%
60 分钟 → -5.5%
90 分钟 → -4.0%
120 分钟 → -2.5%

```

**大白话**："开仓前半小时，如果亏 8.5%就跑！但持有时间越长，止损就越宽松——给你更多时间等待反弹！"

## 十二、这策略的"独门秘籍"

### 🔮 平滑 Heiken Ashi

```python
def HA(dataframe, smoothing=4):
    # 计算 HA 收盘价
    HA_Close = (open + high + low + close) / 4
    
    # 计算 HA 开盘价（用 EMA 平滑）
    HA_Open = EMA((open + close) / 2, smoothing)
    
    # 计算 HA 最高/最低
    HA_High = max(HA_Open, HA_Close, high)
    HA_Low = min(HA_Open, HA_Close, low)
```

> "HA 就像'滤镜'，去掉市场的'噪点'，让你看到更真实的价格走势！"

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

CryptoFrog 的历史回测往往**看起来很美**——多条件组合，怎么都能找到"完美参数"。但这有个陷阱：

> **因为条件太多，策略很容易"拟合"过去行情的最优解，但这并不代表未来一定能盈利。**

简单说就是：**背答案考高分，不代表期末考能及格** 📝

### 复杂策略的隐藏风险

实盘时，复杂的逻辑可能导致：
- **信号延迟**：计算量大，可能错过最佳买卖点
- **过度交易**：条件多，但交易次数不一定多
- **参数漂移**：市场变了，参数需要重新调
- **资金曲线波动**：多条件策略可能大赚大亏，心态容易崩

### 我的建议（真心话）

```
1. 先用默认参数跑，至少观察 1 个月
2. 不要同时改多个参数，一次只改一个
3. 小资金测试，实盘和回测差异可能很大
4. 定期复盘，看看策略在不同市场下的表现
5. 别贪心，21.3% 目标不是每次都能达到
```

## 一、策略概览

STRATEGY_RSI_BB_CROSS 是一个基于布林带百分比与 RSI 百分比穿越的量化策略。该策略的核心逻辑是将布林带位置（价格在布林带中的相对位置）与 RSI 位置（RSI 在超买超卖区间中的相对位置）进行对比，当两者发生穿越且满足趋势持续性条件时触发交易信号。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 1 个买入信号，基于 BB% 向上穿越 RSI% |
| **卖出条件** | 1 个基础卖出信号，基于 BB% 向下穿越 RSI% |
| **保护机制** | 无内置保护参数组 |
| **时间框架** | 5m 主时间框架 |
| **依赖库** | talib, qtpylib, numpy, pandas |
| **作者** | Fractate_Dev |

## 三、买入条件详解

### 3.1 核心概念：百分比位置归一化

策略将布林带位置和 RSI 位置归一化为 0-1 的百分比：

**布林带百分比（BB%）**：
```python
bb_percent = (close - bb_lower) / (bb_upper - bb_lower)
```
- 0 = 价格在布林带下轨
- 1 = 价格在布林带上轨
- 0.5 = 价格在布林带中轨

**RSI 百分比（RSI%）**：
```python
rsi_limit = 30
rsi_percent = (rsi - rsi_limit) / (100 - rsi_limit * 2)
```
- 0 = RSI 在超卖线（30）
- 1 = RSI 在超买线（70）
- 0.5 = RSI 在中性区（50）

### 3.2 买入条件：BB% 向上穿越 RSI%

```python
dataframe.loc[
    (
        # BB%向上穿越RSI%
        qtpylib.crossed_above(dataframe['bb_percent'], dataframe['rsi_percent']) &
        
        # 两者都在下半区
        (dataframe['bb_percent'] < 0.5) & 
        (dataframe['rsi_percent'] < 0.5) &
        
        # 趋势确认：前一根K线BB%持续低于RSI%
        (dataframe['bb_below_rsi_count'].shift(1))
    ),
    'buy'] = 1
```

**条件分解**：

| 条件 | 说明 | 逻辑目的 |
|------|------|---------|
| `crossed_above(bb_percent, rsi_percent)` | BB%向上穿越RSI% | 价格相对位置开始强于RSI相对位置 |
| `bb_percent < 0.5` | BB%在下半区 | 价格相对偏低 |
| `rsi_percent < 0.5` | RSI%在下半区 | RSI相对偏低 |
| `bb_below_rsi_count.shift(1)` | 前14根K线BB%持续低于RSI% | 趋势持续性确认 |

### 3.3 趋势确认机制

策略使用 `_trend_length = 14` 作为趋势确认周期：

```python
dataframe['bb_above_rsi_count'] = True
dataframe['bb_below_rsi_count'] = True
for i in range(_trend_length):
    dataframe['bb_above_rsi_count'] = (dataframe['bb_minus_rsi_percent'].shift(i) > 0) & dataframe['bb_above_rsi_count']
    dataframe['bb_below_rsi_count'] = (dataframe['bb_minus_rsi_percent'].shift(i) < 0) & dataframe['bb_below_rsi_count']
```

**逻辑说明**：
- `bb_below_rsi_count = True`：连续14根K线 BB% 都低于 RSI%
- `bb_above_rsi_count = True`：连续14根K线 BB% 都高于 RSI%

## 六、风险管理特色

### 6.1 百分比位置对比

策略的核心创新在于将两个不同维度的指标归一化后对比：
- **布林带百分比**：反映价格在统计波动范围内的位置
- **RSI 百分比**：反映动量在超买超卖范围内的位置

当两者发生穿越时，意味着**价格位置与动量位置的相对关系发生变化**，这是潜在趋势转折的信号。

### 6.2 趋势持续性过滤

14 周期的趋势确认确保：
- 穿越前有足够的趋势铺垫
- 不是单根 K 线的噪音信号
- 买卖信号具有对称性

### 6.3 区域过滤

买入要求两者都在下半区（< 0.5），卖出要求两者都在上半区（> 0.5）：
- 避免在中间区域频繁交易
- 确保在相对低位买入、相对高位卖出

## 七、策略优势与局限

### ✅ 优势

1. **买卖逻辑对称**：买入和卖出条件完美对应，逻辑清晰
2. **归一化对比**：将不同维度的指标统一为百分比，便于对比
3. **区域过滤**：确保在低位买入、高位卖出
4. **趋势确认**：14 周期持续性过滤，减少假信号

### ⚠️ 局限

1. **穿越信号滞后**：穿越是事后确认，可能错过最佳入场点
2. **无追踪止损**：错过锁定浮盈的机会
3. **参数硬编码**：`_trend_length=14` 和 `rsi_limit=30` 硬编码
4. **布林带窗口固定**：20 周期可能不适合所有市场

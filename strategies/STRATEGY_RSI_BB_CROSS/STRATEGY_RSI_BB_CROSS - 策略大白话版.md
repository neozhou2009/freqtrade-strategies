## 一、这策略是个啥？

简单说，**STRATEGY_RSI_BB_CROSS** 就是一个：
- 把布林带位置变成百分比（0-1）
- 把 RSI 位置也变成百分比（0-1）
- 两个百分比打架，穿越了就交易

就像**两个温度计比谁热**——一个量"价格热度"（布林带位置），一个量"动量热度"（RSI位置），谁超过谁就触发信号！🌡️

## 三、核心概念：把一切都变成百分比

### 布林带百分比（BB%）

**公式**：
```
BB% = (价格 - 布林带下轨) / (布林带上轨 - 布林带下轨)
```

**大白话**：
- BB% = 0：价格踩在布林带下轨
- BB% = 1：价格顶着布林带上轨
- BB% = 0.5：价格在布林带中间

### RSI 百分比（RSI%）

**公式**：
```
RSI% = (RSI - 30) / (100 - 30 - 30) = (RSI - 30) / 40
```

**大白话**：
- RSI% = 0：RSI 在超卖线（30）
- RSI% = 1：RSI 在超买线（70）
- RSI% = 0.5：RSI 在中性区（50）

### 为什么要这么搞？

**因为这样就能直接比较了！**

布林带位置（价格维度）和 RSI 位置（动量维度）本来是两码事，现在都变成 0-1 的百分比，直接对比：

- **BB% > RSI%**：价格位置比动量位置高 → 可能超买
- **BB% < RSI%**：价格位置比动量位置低 → 可能超卖

**天才想法！** 🧠

## 四、买入条件：穿越 + 区域 + 趋势

### 🎯 买入信号：BB% 向上穿越 RSI%

**条件组合**：

| 条件 | 代码 | 人话翻译 |
|------|------|---------|
| 穿越信号 | `crossed_above(bb_percent, rsi_percent)` | BB% 刚刚超过 RSI% |
| 区域限制 | `bb_percent < 0.5` | BB% 还在下半区 |
| 区域限制 | `rsi_percent < 0.5` | RSI% 也在下半区 |
| 趋势确认 | `bb_below_rsi_count.shift(1)` | 前14根K线BB%都低于RSI% |

**大白话**：
> "兄弟，BB% 刚刚把 RSI% 超过去了！而且两者都在下半区（都偏低）。关键是，过去 14 根 K 线 BB% 都被 RSI% 压着打，现在终于翻身了！买！" 🚀

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **逻辑完美对称**：买入和卖出条件一一对应，强迫症患者狂喜
2. **归一化对比**：把不同维度的指标统一为百分比，天才想法
3. **区域过滤**：确保在下半区买、上半区卖，不会乱交易
4. **趋势确认**：14 周期确认，不是一根 K 线说了算

### ⚠️ 缺点（吐槽环节）

1. **穿越信号滞后**：穿越是事后确认，可能错过最佳入场点
2. **无追踪止损**：浮盈可能变成亏损，眼睁睁看着利润溜走
3. **参数硬编码**：趋势确认周期和 RSI 限制都写死了
4. **布林带窗口固定**：20 周期可能不适合所有币种

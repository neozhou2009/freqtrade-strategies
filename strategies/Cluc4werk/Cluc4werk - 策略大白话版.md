# Cluc4werk 策略大白话版

> **读完秒懂系列** | 布林带 + ROCR 趋势过滤的 1 分钟短跑选手

---

## 一、这策略是个啥？

**Cluc4werk** 是个玩 1 分钟超短线的交易策略，核心逻辑很简单：

> "先看大方向（1小时趋势），再找小机会（1分钟布林带信号）"

简单说，它先用 1 小时级别的 ROCR 指标确认趋势往上走，然后才在 1 分钟图上找布林带信号买入。卖点也很直接——价格突破布林带中轨就卖。

这策略就像一个**短线捕手**，专门打趋势中的回调或突破，持股时间很短，一般几分钟到几十分钟就可能要跑路。

## 二、核心配置

### 2.1 关键参数一览

| 参数 | 值 | 什么意思 |
|------|-----|----------|
| **时间框架** | 1 分钟 | 玩超短线 |
| **信息时间框架** | 1 小时 | 用来判断大方向 |
| **止损** | -1% | 亏 1% 就跑 |
| **ROI 1** | 1.5% | 持仓 0-20 分钟 |
| **ROI 2** | 0.5% | 持仓 20-30 分钟 |
| **ROI 3** | 0.1% | 持仓 30 分钟以上 |

### 2.2 指标依赖

- **布林带**：40 周期 + 20 周期
- **ROCR**：28 周期（1分钟）+ 168 周期（1小时）
- **EMA**：50 周期
- **成交量均线**：30 周期

需要安装：`talib`, `technical`, `qtpylib`, `numpy`

## 三、买入条件（2 个模式）

### 3.1 前置条件：ROCR 趋势过滤

```
1 小时 ROCR > 0.65
```

这是**必选项**！只有当 1 小时级别处于上升趋势时才考虑买入。

> 打个比方：这就像你要过马路，先左右看看有没有车（确认安全）

### 3.2 模式一：BinHV 变体

满足以下**全部**条件：

1. ✅ 布林带下轨有效（非 NaN）
2. ✅ 布林带带宽 > 收盘价 × 0.6%
3. ✅ 价格变化 > 收盘价 × 1.3%
4. ✅ 下影线 < 带宽 × 96.8%
5. ✅ 当前价格 < 前一根布林带下轨
6. ✅ 当前价格 ≤ 前一根收盘价

**人话版**：价格突然大跌后收在下轨附近，下影线很短，说明跌不动了。

### 3.3 模式二：Cluc 变体

满足以下**全部**条件：

1. ✅ 价格 < EMA50
2. ✅ 价格 < 布林带下轨 × 0.013
3. ✅ 成交量 < 30 日均量 × 28

**人话版**：价格跌到非常低的位置，而且成交量极度萎缩（地量），说明卖不动了。

### 3.4 总结

```
买入 = (1小时上升趋势) AND (模式一 OR 模式二)
```

## 四、保护机制

Cluc4werk 有几层保护：

### 4.1 ROCR 趋势过滤（第一道防线）

```
1 小时 ROCR > 0.65
```

这是**最核心**的保护——只在大趋势向上时交易，避免逆势操作。

### 4.2 紧凑止损（第二道防线）

```
stoploss = -1%
```

亏 1% 就割肉，绝不恋战。

### 4.3 多时间框架确认（第三道防线）

同时看 1 分钟和 1 小时的数据，**双重确认**更安全。

## 五、卖出逻辑

### 5.1 主要卖出条件

```
价格上穿布林带中轨 AND 有成交量
```

**人话版**：价格涨到布林带中间位置，说明可能到了压力位，走为上策。

### 5.2 ROI 自动退出

| 持仓时间 | 自动卖出条件 |
|----------|-------------|
| 0-20 分钟 | 盈利 ≥ 1.5% |
| 20-30 分钟 | 盈利 ≥ 0.5% |
| 30 分钟以上 | 盈利 ≥ 0.1% |

### 5.3 止盈逻辑

```
exit_profit_only = True
```

只在赚钱的时候才卖，亏钱不卖（等止损）。

## 七、适用场景

### ✅ 适合的场景

- **上涨趋势中的回调**：趋势向上，价格回调到布林带下轨附近
- **震荡市**：价格在上下轨之间波动
- **高波动市场**：1 分钟波动大，信号多
- **白天交易时段**：波动活跃

### ❌ 不适合的场景

- **下跌趋势**：ROCR 过滤失效，容易亏损
- **横盘整理**：波动太小，信号不明确
- **深夜/节假日**：波动低，信号少
- **低波动币种**：波动太小，1% 止损可能过于敏感

## 十一、彩蛋

### 11.1 策略灵感来源

Cluc4werk 源自经典的 **Cluc（Cluc策略）** 系列，结合了 **BinHV** 的布林带思路。ROCR 趋势过滤是多时间框架分析的经典应用。

### 11.2 冷知识

- ROCR（Rate of Change）衡量的是一定周期内的价格变化百分比
- 168 周期 ROCR 在 1 小时图上相当于**一周**的价格变化
- 0.65 的阈值意味着过去一周价格上涨了 65% 以上

### 11.3 进阶玩法

手动交易者可以这样简化使用：
1. 打开 1 小时图，确认 ROCR > 0.65
2. 切换到 1 分钟图，等待价格碰到布林带下轨
3. 买入，设置 1% 止损
4. 价格突破布林带中轨时卖出

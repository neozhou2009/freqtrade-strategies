## 一、这策略是个啥？

简单说，**SuperHV27** 就是一个：
- 专门找趋势转折点的"转折猎人"
- 用一堆指标组合来判断入场时机
- 有动态 ROI 让你越持有越容易退出
- 还能追加仓位（盈利了再加码）

就像一个**老练的猎手**，蹲在草丛里观察风向、气味、足迹，等到猎物露出破绽的瞬间才出手 🎯

## 二、核心配置：说白了就是"赚够就跑"

### 止盈规则（ROI 表）

```
刚买：要赚 10% 才跑
30 分钟后：5% 就能跑
1 小时后：2.5% 就能跑
12 小时后：1% 就能跑
24 小时后：不赚也能跑（止损也差不多）
```

**翻译**：这策略很"急"，刚入场要求高收益，但越等越"心软"，最后只要不亏就能走。就像相亲，刚开始眼光高，越单身越妥协 🤣

### 止损规则

```
硬止损：-40%（亏 40% 才强制退出）
```

**翻译**：40% 止损非常宽松，基本等于"除非崩盘，我不认输"。这设计是为了配合动态 ROI——让策略有足够时间用精细退出机制赚钱，而不是被硬止损一刀切。

### 动态 ROI（这个是特色！）

策略有个 **动态 ROI 系统**，可以选三种模式：

| 模式 | 大白话解释 |
|------|-----------|
| **linear（线性）** | 每分钟收益要求固定下降，像楼梯 |
| **exponential（指数）** | 开始降得快，后来降得慢，像滑梯 |
| **connect（连接）** | 把 ROI 表的点连起来，中间线性插值 |

**大白话**：你选 "connect" 模式，策略就会在 ROI 表的点之间画线，计算每一分钟的具体收益要求。比如 30 分钟要求 5%，40 分钟要求 2.5%，那 35 分钟就要求 3.75%。

## 三、买入条件：四组组合拳

这策略的买入条件**很复杂**，我帮你归类成两大模式：

### 🎯 模式 #1：新仓位开仓（没钱在手里时）

**必须满足的共同条件**：
- 价格低于高位 SMA 和低位 SMA（价格偏低）
- 负向 DI 高于其 EMA（下行力量强）
- RSI 在上升（动能回升）

然后还有**四组分支条件**，就像四个"猎人"同时蹲在不同位置：

| 分支名字 | 核心逻辑 | 大白话 |
|---------|---------|--------|
| **大跌趋势** | 大跌 + 不准备变趋势 + ADX≥49 | "大跌中但还没反转，ADX 很强（趋势确定），等反弹" |
| **持续上涨跌** | 持续上涨但还在跌 + ADX≥36 | "上涨趋势中的回调，捡便宜" |
| **大涨不持续** | 大涨但不持续 + ADX≥32 | "假突破后的回落，等反弹" |
| **持续大涨** | 持续上涨 + 大涨 + ADX≥24 | "真涨趋势中的小回调" |

**大白话总结**：这策略就是专门找**趋势中的回调机会**，有点像"抄底但不抄死底"，等动能回升再入场。

### 📈 模式 #2：追加仓位（有钱在手里时）

如果你已经有仓位赚钱了，策略还能追加：

```python
追加条件：
1. RMI 处于上升趋势（动能够强）
2. 当前利润高于阈值（已经有赚了）
3. RMI 达到增长目标（动能够高）
```

**大白话**：追加仓位就像"加杠杆"，盈利时再买入放大收益。但风险也放大了，小心！

## 四、保护机制：三层"保险丝"

每个买入都有配套保护，就像三道保险：

| 保护类型 | 作用 | 大白话 |
|---------|------|--------|
| **动态 ROI** | 随时间降低收益要求 | "等久了就心软，不赚也能走" |
| **交易超时检查** | 价格变了取消订单 | "价格跑了 1% 就不追了" |
| **入场价格保护** | 入场价高于预期拒绝 | "价格跳了 1% 就不入场" |

**吐槽**：这策略的保险真多，三层保护防止你被"割韭菜"。但代价是入场机会变少了——有时候价格跳了你就买不进去了 😅

## 五、卖出逻辑：五组退出场景

卖出也复杂，有**五组场景**：

| 场景 | 触发条件 | 大白话 |
|------|---------|--------|
| **价格突破** | 价格突破 SMA + 大跌趋势 | "价格反弹了，但趋势还是下行，先跑" |
| **EMA-RSI 过热** | 价格突破高位 + EMA-RSI 高 | "价格太高，动能过热，跑" |
| **上行过热** | 价格突破 + ADX 强 + bigup | "涨太快了，先跑" |
| **趋势转折** | 趋势转折确认 + 减速 | "趋势要反转了，跑" |
| **DI 逆转** | 负向 DI < 正向 DI + 价格突破 | "方向逆转了，跑" |

**大白话总结**：这策略的卖出逻辑是"见势不对就跑"，价格反弹、动能过热、趋势转折都触发卖出。有点"见好就收"的意思。

### 仓位协调卖出（特色功能）

如果你开了多个仓位，策略会协调：

```python
有空闲仓位：
  → 平均利润高于阈值就继续持有
无空闲仓位：
  → 优先卖出亏损最多的仓位（腾钱给更好的机会）
```

**大白话**：这个设计很聪明！钱不够了就卖最差的仓位，把钱让给好仓位。就像公司裁员——先裁业绩最差的员工 🤣

## 一、策略概览

Schism2MM 是一个基于**相对动量指标（RMI）**和**局部极值点检测**的复杂趋势反弹策略。它的核心特点是利用 scipy 信号处理库识别局部价格低谷，结合多维度指标过滤，在趋势回调时精准入场。策略支持**动态加仓**，并配备了基于持仓时间的**线性增长止损阈值**系统。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 2 套独立买入逻辑（新开仓 + 加仓），配合局部极值点检测 |
| **卖出条件** | 动态止损 + 趋势反转信号 + 组合利润管理 |
| **保护机制** | 4 重保护（止损、订单超时、入场确认、价格保护） |
| **时间框架** | 主框架 5m + 信息框架 1h |
| **依赖库** | numpy, talib, qtpylib, arrow, scipy.signal, cachetools, technical |

## 二、策略配置解析

### 2.1 基础风险参数

```python
# ROI 退出表
minimal_roi = {
    "0": 0.025,    # 立即获利 2.5%
    "10": 0.015,   # 10分钟后降为 1.5%
    "20": 0.01,    # 20分钟后降为 1%
    "30": 0.005,   # 30分钟后降为 0.5%
    "120": 0       # 120分钟后无利润要求

# 止损设置

```

**设计思路**：
- 采用**递减式 ROI 表**，持仓越久，利润要求越低
- 120分钟后放弃利润要求，完全依赖卖出信号
- 配合 `ignore_roi_if_buy_signal = True`，当买入信号有效时不触发 ROI

## 三、买入条件详解

### 3.1 核心指标体系

策略使用以下技术指标：

| 指标 | 周期 | 用途 |
|------|------|------|
| **RMI-Slow** | 21周期，动量5 | 趋势方向判断 |
| **RMI-Fast** | 8周期，动量4 | 快速动量捕捉 |
| **ROC** | 6周期 | 变化率计算 |
| **MP** | ROC的6周期RSI | 动量乒乓球指标 |
| **RSI (1h)** | 14周期 | 信息层趋势确认 |
| **ADR** | 1日高-3日低 | 平均波动范围 |

### 3.2 局部极值点检测

策略使用 `scipy.signal.argrelextrema` 检测局部价格低谷：

```python
min_peaks = argrelextrema(dataframe['close'].values, np.less, order=100)
for mp in min_peaks[0]:
    dataframe.at[mp, 'buy_signal'] = True
```

**说明**：
- `order=100` 表示在100根K线范围内寻找局部最小值
- 检测到的谷底位置标记为 `buy_signal = True`
- 这是策略的**核心入场时机识别机制**

### 3.3 两套买入逻辑

#### 场景一：新开仓（无持仓）

```python
# 条件组合
(1h_rsi >= 65) &                           # 信息层趋势确认
(close <= 3d_low + 0.95*adr) &             # 价格在低位区域
(rmi-dn-trend == 1) &                      # RMI 下降趋势
(rmi-slow >= 33) &                         # RMI 不超卖
(rmi-fast <= 41) &                         # 快速 RMI 有限
(mp <= 53) &                               # 动量乒乓球不高
(buy_signal == True) &                     # 局部谷底检测
(volume > 0)                               # 有成交量
```

**逻辑解读**：
- 在**大周期趋势向上**（1h RSI >= 65）的前提下
- 等待**价格回调到低位区域**
- RMI 下降趋势确认回调
- 局部极值点检测确认**谷底位置**

#### 场景二：加仓（已有持仓）

```python
# 动态阈值计算
rmi_grow = linear_growth(30, 70, 180, 720, open_minutes)  # 30-70 线性增长
profit_factor = 1 - (rmi-slow / 300)  # 利润因子

# 条件组合
(rmi-up-trend == 1) &                      # RMI 上升趋势
(current_profit > peak_profit * factor) &  # 利润保护
(rmi-slow >= rmi_grow) &                   # RMI 线性增长阈值
(buy_signal == True) &                     # 局部谷底
(volume > 0)
```

**加仓特点**：
- 持仓超过180分钟后，RMI 阈值从30线性增长到70
- 利润保护机制：当前利润 > 峰值利润 × 因子
- 仅在上升趋势中加仓，避免逆势操作

## 四、卖出逻辑详解

### 4.1 动态止损系统

策略采用**时间加权动态止损**：

```python
loss_cutoff = linear_growth(-0.03, 0, 0, 300, open_minutes)
# 持仓0分钟: 允许亏损3%
# 持仓300分钟后: 要求盈利
```

### 4.2 卖出触发条件

```python
# 基础条件
(current_profit < loss_cutoff) &           # 利润低于动态阈值
(current_profit > stoploss) &              # 高于固定止损
(rmi-dn-trend == 1) &                      # RMI 下降趋势
(volume > 0)

# 盈利后的退出阈值
if peak_profit > 0:
    crossed_below(rmi-slow, 50)            # 曾盈利：RMI跌破50
else:
    crossed_below(rmi-slow, 10)            # 从未盈利：RMI跌破10
```

### 4.3 组合利润管理

当存在其他持仓时，策略会考虑整体仓位：

```python
if free_slots > 0:
    # 有空闲仓位时
    hold_pct = (free_slots / 100) * -1
    avg_other_profit >= hold_pct           # 其他持仓利润门槛
else:
    # 无空闲仓位时
    biggest_loser == True                   # 只允许最大亏损者卖出
```

### 6.2 订单超时保护

```python
def check_buy_timeout(self, pair, trade, order, **kwargs):
    # 买单超时：当前价格高于订单价格1%时取消
    if current_price > order['price'] * 1.01:
        return True
    return False

def check_sell_timeout(self, pair, trade, order, **kwargs):
    # 卖单超时：当前价格低于订单价格1%时取消
    if current_price < order['price'] * 0.99:
        return True
    return False
```

### 6.3 入场价格保护

def confirm_trade_entry(self, pair, order_type, amount, rate, **kwargs):

## 七、策略优势与局限

### ✅ 优势

1. **局部极值点检测**：使用 scipy 信号处理，精准识别谷底位置
2. **动态加仓系统**：基于持仓时间和利润的智能加仓逻辑
3. **线性增长阈值**：止损和加仓阈值随时间线性调整
4. **组合利润管理**：考虑整体仓位的卖出决策

### ⚠️ 局限

1. **复杂度高**：涉及 scipy 信号处理、线性增长函数、多维度条件
2. **参数敏感**：`order=100` 的极值点检测对市场结构敏感
3. **回测限制**：动态加仓和组合管理在回测中可能无法完全模拟
4. **依赖实盘数据**：`Trade` 对象查询仅在实际运行时有效

## 九、适用市场环境详解

Schism2MM 是**反弹交易型策略**。基于其代码架构和社区长期实盘验证的经验，它最适合**震荡上行市场**，而在**单边下跌**时表现不佳。

### 9.1 策略核心逻辑

- **局部极值点检测**：在100根K线范围内寻找价格谷底
- **趋势过滤**：要求1h RSI >= 65，确保大周期向上
- **回调买入**：在价格回调到低位区域时入场
- **动态加仓**：持仓超过3小时后可加仓

### 9.2 不同市场环境表现

| 市场类型 | 表现评级 | 原因分析 |
| :--- | :--- | :--- |
| 📈 震荡上行 | ⭐⭐⭐⭐⭐ | 完美匹配策略设计，回调买入+趋势持有 |
| 🔄 横盘震荡 | ⭐⭐⭐☆☆ | 可能频繁止损，局部极值点识别可能失效 |
| 📉 单边下跌 | ⭐⭐☆☆☆ | 趋势过滤可能无法及时响应，止损频繁触发 |
| ⚡️ 高波动 | ⭐⭐☆☆☆ | 极值点检测可能不稳定，滑点影响大 |

### 9.3 关键配置建议

| 配置项 | 建议值 | 说明 |
|--------|--------|------|
| `order` (极值点) | 50-150 | 根据市场波动调整检测范围 |
| `inf-rsi` | 60-70 | 趋势确认阈值 |
| `stoploss` | -0.08 ~ -0.12 | 根据风险承受调整 |

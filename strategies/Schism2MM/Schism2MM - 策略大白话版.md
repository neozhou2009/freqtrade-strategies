# Schism2MM 策略：谷底猎手

> **外号**：谷底猎手、反弹收割机  
> **职业**：专门在下跌后"抄底"的交易员  
> **时间框架**：5 分钟（主战场）+ 1 小时（大局观）

---

## 一、这策略是个啥？

简单说，**Schism2MM** 就是一个：
- 用 scipy 科学计算找"价格谷底"的策略
- 专门在别人恐慌时入场抄底
- 还能加仓！有持仓还能继续买

就像一个**在股市大跌时冷静捡便宜货的老手** 🏷️

---

## 二、核心配置：说白了就是"先定规矩"

### 止盈规则（ROI 表）

```
刚买：赚 2.5% 就跑
10分钟后：赚 1.5% 就跑
20分钟后：赚 1% 就跑
30分钟后：赚 0.5% 就跑
2小时后：不赚钱也行，看信号
```

**翻译**：越持仓越佛系，反正有卖出信号兜底。

### 止损规则

```
最大亏损：10%
```

**翻译**：亏到10%强制止损，没得商量。

## 三、买入条件：我帮你分类好了

这策略的买入条件分两套，我给你归了 2 类：

### 🎯 第 1 类：新开仓（第一次买）

**核心逻辑**：大周期涨 + 小周期跌 + 谷底检测

**大白话**：
> "大哥（1小时）在涨，小弟（5分钟）在跌，正好跌到谷底，可以捡便宜了！"

**代表条件**：
1. 1小时 RSI >= 65 → "大趋势向上"
2. 价格 <= 3日低 + 95%波动 → "跌到位了"
3. RMI 下降趋势 → "确实在跌"
4. 局部谷底检测 → "这里是底"

**经典台词**：
- 条件#1：`1h_rsi >= 65` → "大趋势给力，放心抄底"
- 条件#2：`close <= 3d_low + 0.95*adr` → "价格够低，安全边际够"
- 条件#4：`buy_signal == True` → "scipy 说这里是谷底，听它的！"

---

### 📈 第 2 类：加仓（已经买了还想买）

**核心逻辑**：持仓超过3小时 + 利润保护 + 趋势向上

**大白话**：
> "已经买了3小时，还在涨，那再加一点！"

**动态阈值**：
```
RMI 阈值 = 从 30 线性增长到 70
（持仓越久，要求越高）
```

**经典台词**：
- `rmi-up-trend == 1` → "趋势向上，加仓方向对"
- `current_profit > peak_profit * factor` → "之前赚的钱还在，安全"
- `rmi-slow >= rmi_grow` → "动态阈值达到了，可以加"

---

## 四、保护机制：4 层"保险丝"

每个买入条件都配了一套保护参数，就像**四道防盗门**：

| 保护类型 | 作用 | 大白话 |
|---------|------|--------|
| 固定止损 | 亏10%强制退出 | "亏太多就跑，别硬扛" |
| 动态止损 | 时间越久要求越高 | "持仓久了还不赚钱就撤" |
| 订单超时 | 价格偏离1%取消 | "价格跑太快，追不上就算了" |
| 入场确认 | 价格偏离1%拒绝 | "入场价不对，宁可错过" |

这就像相亲要查三代家谱，**谨慎到极点** 🕵️

## 五、卖出逻辑：比买入更花哨

### 5.1 动态止损：亏多少跑

```
持仓 0 分钟：允许亏 3%
持仓 150 分钟：允许亏 1.5%
持仓 300 分钟：要求盈利
```

**大白话**：
- 刚买：亏点没事，给点容错空间
- 持仓久了：你该赚钱了，不赚钱就走人

---

### 5.2 RMI 止损信号

| 场景 | RMI 阈值 | 大白话 |
|------|---------|--------|
| 曾盈利过 | RMI < 50 | "涨过了但开始回落，保利润走" |
| 从未盈利 | RMI < 10 | "完全没涨起来，认赔走人" |

---

### 5.3 组合利润管理

这是这策略最**骚**的地方——它会考虑**整体仓位**：

```python
if 有空闲仓位:
    其他持仓平均利润 >= -空闲位数*0.01  # 稍微亏点没事
else:  # 没空位了
    只允许最大亏损者卖出  # 腾位置给新机会
```

**大白话**：
> "有空位时宽松点，没空位时让最差的先走"

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **科学抄底**：用 scipy 信号处理找谷底，不是瞎猜
2. **能加仓**：好行情可以加码，不浪费机会
3. **动态阈值**：止损和加仓都随时间调整，不僵化
4. **组合管理**：考虑整体仓位，不是单币种单打独斗

### ⚠️ 缺点（吐槽环节）

1. **太复杂**：scipy 信号处理？线性增长函数？学起来头大
2. **回测困难**：加仓逻辑、组合管理在回测里没法完全模拟
3. **参数敏感**：`order=100` 的极值检测换个市场可能就失效
4. **只能实盘**：很多逻辑依赖 `Trade` 对象，回测跑不通

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

Schism2MM 的回测可能**看起来还行**——但这有个陷阱：

> **很多核心逻辑（加仓、组合管理）在回测中根本跑不了！**

简单说就是：**回测测不出真实效果**

### 复杂策略的隐藏风险

实盘时，复杂的逻辑可能导致：
- **加仓时机**：可能错过最佳加仓点
- **组合管理**：多币种时可能判断不准
- **极值点检测**：市场结构变化时可能失效
- **滑点影响**：5分钟框架对滑点敏感

### 我的建议（真心话）

```
1. 先 dry-run 至少两周，观察信号质量
2. 小资金实盘测试加仓效果
3. 关注 1h RSI 趋势是否准确
4. 调整 order 参数适配不同币种
```

# SMAOPv1_TTF 策略：带"温度计"的均线抄底王

> **外号**：TTF 趋势捕手  
> **职业**：均线偏移猎手 + TTF 温度计组合  
> **时间框架**：5 分钟（主）+ 1 小时（辅助）

---

## 一、这策略是个啥？

简单说，**SMAOPv1_TTF** 就是一个：
- 用均线做"打折线"，价格跌到一定比例就买入
- 用 EWO 判断"风往哪吹"，避免逆势交易
- 用 TTF 当"温度计"，太热了就跑路

就像去超市买菜 🥬：看到平时 10 块的菜现在 9.8 折（均线偏移），确认是正常降价不是快过期（EWO），买！然后等涨到一定程度，温度计显示"太热了"（TTF），赶紧卖！

## 二、核心配置：说白了就是"三道保险丝"

### 止盈规则（ROI 表）

```
立刻     10% 利润
30 分钟   5% 利润  
60 分钟   2% 利润
```

**翻译**：刚买入时目标 10%，拖得越久越着急，60 分钟后 2% 也卖了。

### 止损规则

```
固定止损：-10%
追踪止损：盈利 > 1% 后激活，锁定 99.9% 利润
```

**翻译**：亏 10% 认栽。但赚了 1% 后，就启动"保命模式"，跟着价格涨，最多回吐 0.1% 就跑。

**详细台词**：

- 有成交量

**代表条件**：条件 #2

## 五、卖出逻辑：比买入更讲究

### 5.1 ROI 止盈：时间越久越急

```
刚买入  → 目标 10%
30 分钟 → 目标降为 5%
60 分钟 → 目标降为 2%
```

**大白话**：
- 刚买：我要赚 10%！
- 30 分钟：算了 5% 也可以...
- 60 分钟：求求了，2% 也卖！

### 5.2 追踪止损：跟着涨

```
利润达到 1% → 启动追踪止损
止损线跟着涨 → 只回吐 0.1% 就跑
```

**大白话**：赚了钱就别让它跑了，止损线跟着价格往上爬！

### 5.3 两个卖出信号

**经典台词**：

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **双重入场机会**：既能追趋势回调，又能抄超跌反弹，不放过机会
2. **保护到位**：EWO + RSI + 追踪止损，三层防护
3. **退出灵活**：TTF 指标提供独立的退出信号，不是死守 ROI
4. **参数可调**：11 个可优化参数，适合各种市场环境

### ⚠️ 缺点（吐槽环节）

1. **参数太多了**：11 个参数，调起来头大，容易过拟合 🤣
2. **TTF 不常见**：这个指标用的人不多，社区验证少
3. **震荡市会亏**：横盘震荡时，偏移策略容易反复被打脸
4. **1h 信息层没怎么用**：定义了但代码里没实际应用，有点浪费

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

SMAOPv1_TTF 的历史回测表现可能不错——但注意：

> **11 个可调参数，很容易"拟合"过去行情的最优解，但这不代表未来一定行。**

简单说就是：**历史最优 ≠ 未来最优**

### 复杂策略的隐藏风险

实盘时，复杂的逻辑可能导致：
- **参数过拟合**：回测 100% 胜率，实盘 50% 都不到
- **TTF 误判**：极端行情下 TTF 可能失效
- **震荡亏损**：横盘时反复触发买入卖出，手续费吃利润

### 我的建议（真心话）

```
1. 先用默认参数跑回测，别上来就 hyperopt
2. 纸盘测试至少 2 周，观察 TTF 表现
3. 小仓位实盘，单笔不超过总资金 5%
4. 定期回顾参数表现，适时调整
```

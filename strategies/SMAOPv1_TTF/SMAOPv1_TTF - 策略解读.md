## 一、策略概览

SMAOPv1_TTF 是一个结合均线偏移（SMA Offset）、趋势触发因子（TTF）和艾略特波动振荡器（EWO）的多条件趋势跟踪策略。策略通过价格对均线的偏移来识别入场时机，配合 EWO 进行趋势过滤，并使用 TTF 作为动态退出信号，构建了一套完整的趋势交易系统。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 2 个独立买入信号，可独立触发入场 |
| **卖出条件** | 2 个基础卖出信号 + 追踪止损机制 |
| **保护机制** | EWO 过滤 + RSI 约束 + 追踪止损三重保护 |
| **时间框架** | 主时间框架 5m + 信息时间框架 1h |
| **依赖库** | talib, numpy, qtpylib, technical |

### 3.2 买入条件详解

#### 条件 #1：趋势延续买入
```python
# 逻辑
- 价格低于偏移均线 (close < ma_buy * low_offset)
- EWO 处于高位 (EWO > ewo_high)，表示趋势强势
- RSI 未超买 (RSI < rsi_buy)
- 成交量大于 0
```

**解读**：此条件捕捉上涨趋势中的回调机会。价格回落到偏移均线下方时，如果 EWO 显示趋势依然强劲且 RSI 未过热，则为优质入场点。

#### 条件 #2：趋势反转买入
```python
# 逻辑
- 价格低于偏移均线 (close < ma_buy * low_offset)
- EWO 处于低位 (EWO < ewo_low)，表示超卖
- 成交量大于 0
```

**解读**：此条件捕捉超卖反弹机会。当 EWO 处于极端低位时，市场可能过度抛售，存在反弹机会。

### 3.2 买入条件分类

| 条件组 | 条件编号 | 核心逻辑 |
|-------|---------|---------|
| 趋势延续 | #1 | 回调买入 + 趋势确认 |
| 反转捕捉 | #2 | 超卖买入 + 反弹预期 |

## 五、技术指标体系

### 5.1 核心指标

| 指标类别 | 具体指标 | 用途 |
|---------|---------|------|
| 趋势类 | EMA（指数移动平均） | 偏移买卖线计算 |
| 振荡类 | EWO（艾略特波动振荡器） | 趋势强度判断 |
| 动量类 | RSI（相对强弱指标） | 超买超卖过滤 |
| 趋势类 | TTF（趋势触发因子） | 趋势极值识别 |

### 5.2 TTF 指标详解

TTF（Trend Trigger Factor）是本策略的核心创新指标：

```python
def ttf(df, ttf_length):
    buyPower = high.rolling(ttf_length).max() - low.shift(ttf_length).min()
    sellPower = high.shift(ttf_length).max() - low.rolling(ttf_length).min()
    ttf = 200 * (buyPower - sellPower) / (buyPower + sellPower)
    return ttf
```

**计算逻辑**：
- **买入力量**：当前周期最高价 - 前一周期的最低价
- **卖出力量**：前一周期最高价 - 当前周期的最低价
- **TTF 值**：标准化到 -100 至 +100 范围

**解读**：TTF > 100 表示买入力量极强，可能过热；TTF < -100 表示卖出力量极强，可能超卖。

## 七、策略优势与局限

### ✅ 优势

1. **多维度入场判断**：结合均线偏移、EWO、RSI 三重过滤，入场信号更可靠
2. **趋势与反转兼顾**：两个买入条件分别捕捉趋势延续和反转机会
3. **动态退出机制**：TTF 指标提供趋势极值识别，配合 ROI 和追踪止损，退出灵活
4. **参数可优化空间大**：11 个可调参数，适合不同市场环境调优

### ⚠️ 局限

1. **参数敏感性强**：可调参数多，过拟合风险较高
2. **信息时间框架未充分使用**：虽然定义了 1h 信息层，但代码中实际应用有限
3. **TTF 指标较冷门**：社区验证较少，实盘表现需进一步观察
4. **震荡市表现存疑**：偏移策略在横盘震荡中可能产生频繁假信号

## 九、适用市场环境详解

SMAOPv1_TTF 是一个趋势跟踪型策略，结合了均线偏移和 TTF 趋势触发。基于其代码架构和社区经验，它最适合 **明确的趋势行情**，而在 **震荡横盘市场** 时表现可能不佳。

### 9.1 策略核心逻辑

- **均线偏移入场**：价格低于偏移均线一定比例时入场，等待回归
- **EWO 趋势过滤**：通过 EWO 判断当前趋势强度，避免逆势交易
- **TTF 动态退出**：TTF 达到极值时及时止盈，防止利润回吐

### 9.2 不同市场环境表现

| 市场类型 | 表现评级 | 原因分析 |
| :--- | :--- | :--- |
| 📈 上涨趋势 | ⭐⭐⭐⭐⭐ | 均线偏移捕捉回调，TTF 及时止盈 |
| 🔄 震荡市场 | ⭐⭐☆☆☆ | 频繁触及偏移线，假信号多 |
| 📉 下跌趋势 | ⭐⭐☆☆☆ | EWO 低阈值可捕捉反弹，但风险较高 |
| ⚡️ 剧烈波动 | ⭐⭐⭐☆☆ | 追踪止损可保护利润，但止损可能被频繁触发 |

### 9.3 关键配置建议

| 配置项 | 建议值 | 说明 |
|--------|--------|------|
| base_nb_candles_buy | 16-30 | 短周期适合快节奏，长周期适合稳健 |
| low_offset | 0.95-0.98 | 偏移越大入场越保守 |
| ttf_upperTrigger | 80-120 | 越高止盈越激进 |

## 十一、总结

**SMAOPv1_TTF** 是一个结合均线偏移、EWO 趋势过滤和 TTF 动态退出的趋势跟踪策略。它的核心价值在于：

1. **多重过滤机制**：均线偏移 + EWO + RSI 三重确认，降低假信号
2. **趋势与反转兼顾**：两个买入条件覆盖不同市场阶段
3. **动态退出系统**：TTF + ROI + 追踪止损组合，保护利润

对于量化交易者而言，这是一个适合趋势行情的策略，但需要针对具体交易对进行参数优化，并注意震荡市场的风险控制。

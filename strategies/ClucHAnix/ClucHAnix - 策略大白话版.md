## 一、这策略是个啥？

就像一个**谨慎的老猎人**，埋伏在山里等猎物出现：
1. 先用"望远镜"（1小时ROC）确认山那边有动物
2. 然后用"陷阱"（布林带）等待最佳时机
3. 猎物上钩后，还要时刻盯着，一有风吹草动就撤退 😅

## 二、核心配置：说白了就是"赚够就跑"

### 止盈规则（ROI 表）

```
开仓后立即平仓  → 赚 10.3%  ✅ 这波值！
3分钟后         → 赚 5%      ✅ 不错
5分钟后         → 赚 3.3%    ✅ 可以
1小时后         → 赚 2.7%    ⚠️ 有点少了
2小时后         → 赚 1.1%    😴 蚊子腿
5小时后         → 赚 0.5%    💤 赶紧跑
```

**翻译**：这策略希望**速战速决**，开仓后5分钟内如果能赚到3%以上就比较满意了。时间拖得越久，对利润的要求越低——算是"落袋为安"的心态。

### 止损规则

```
利润 < -99% 之前，止损位置由 custom_stoploss 决定
```

**翻译**：这策略**不设固定止损**，完全靠一个复杂的"动态止损计算器"。会根据你赚了多少，动态调整止损位置——赚得越多，止损越"宽松"；赚得少，止损就"紧密"。

## 三、2 个买入条件：我帮你分类好了

这策略的买入条件需要通过"两层考试"，我给你归了 2 类：

### 🎯 第 1 类：布林带"教科书"式买入
**核心逻辑**：价格跌到布林带下轨附近，出现"跌不动"的信号，并且1小时趋势向上

**大白话**：
> "兄弟，价格已经跌到布林带下边了，看起来跌不动了。而且1小时那边趋势也不错，买不买？"

**代表条件**：
- `bbdelta > ha_close * 0.01846` → 布林带开口要够大
- `closedelta > ha_close * 0.01009` → 收盘价变化要够明显
- `tail < bbdelta * 0.98973` → 下影线不能太长（不然是假信号）
- `ha_close < lower.shift()` → HA收盘价要突破布林下轨
- `hh_48_diff > 6.867` → 48小时最高点要够高
- `ll_48_diff > -12.884` → 48小时最低点也不能太低

---

### 📉 第 2 类：EMA 偏离"反弹"式买入
**核心逻辑**：价格偏离EMA太远，短期内有回归需求

**大白话**：
> "价格已经严重偏离50日均线了，迟早要弹回来！买不买？"

**代表条件**：
- `ha_close < ema_slow` → HA收盘价低于50日EMA
- `ha_close < 0.00785 * bb_lowerband` → 紧贴布林下轨
- `hh_48_diff > 6.867` → 48小时最高点过滤
- `ll_48_diff > -12.884` → 48小时最低点过滤

**⚠️ 两者共同条件**：
- `rocr_1h > 0.5411` → **1小时级别的ROC必须上涨**，这是"及格线"！

## 四、保护机制：1 层"滑点保安"

每个买入条件都配了一个"滑点保安"，就像地铁安检：

| 保护类型 | 作用 | 大白话 |
|---------|------|--------|
| 滑点保护 | max_slip = 0.73% | "成交价不能比我报价贵超过0.73%，不然我不买了！" |

这策略的滑点保护比较宽松（0.73%），适合交易所流动性一般的场景。

```

利润 3.3%-5%     → 可以考虑跑了

**大白话**：

- **随着时间推移**：越来越"怂"，赚点就行
- **5小时后**：0.5%也跑，别亏就行

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **多时间框架分析**：用5分钟交易，但用1小时过滤，不会逆势操作
2. **动态止盈止损**：会根据赚了多少自动调整"安全带"，智能！
3. **专门防"暴涨暴跌"**：有4个特殊退出技能，专门应对极端行情
4. **指标丰富**：趋势、动量、成交量、资金流向全都考虑到了

### ⚠️ 缺点（吐槽环节）

1. **参数太多了**：20+个参数，优化时会死人的 😅
2. **计算量大**：每次都要算1小时的信息层，VPS内存不够会卡
3. **1小时过滤太严格**：可能导致错过很多机会
4. **太复杂了**：代码快500行了，一般人根本看不懂

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

ClucHAnix 的历史回测表现往往**看起来不错**——但这有个陷阱：

> **因为参数众多（20+个），策略很容易"拟合"过去行情的最优解，但这并不代表未来一定能盈利。**

简单说就是：**背答案考了100分，不代表下次考试也能及格。**

### 复杂策略的隐藏风险

实盘时，复杂的逻辑可能导致：
- **指标失效**：某些指标在特定市场环境下失效
- **执行延迟**：复杂计算可能导致订单执行延迟
- **过拟合风险**：20+个参数，优化时很容易"拟合"历史数据
- **硬件依赖**：内存不够会直接罢工

### 我的建议（真心话）

```
1. 先回测3个月以上的数据，看曲线是否稳定
2. 小资金实盘测试1-2个月，确认策略有效性
3. 别乱改参数！改错一个可能全盘皆输
4. 关注极端行情时的表现，那才是检验策略的时候
5. 永远别all-in，轻仓测试，活着最重要！

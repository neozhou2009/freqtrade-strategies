## 一、这策略是个啥？

简单说，**PumpDetector** 就是一个：

- 盯着 KDJ 指标的 J 线不放
- J 线掉到 0 以下就等着抄底
- J 线涨到 90 以上或者开始拐头就跑

就像一个钓鱼的老大爷——鱼没上钩不动，一旦咬钩（J 上穿 0）立马提竿，鱼吃饱了（J 过 90）就收线 🎣

## 二、核心配置：说白了就是"抄底快跑"

### 止损规则

```
硬止损：亏 10% 就认栽
追踪止损：没开！
```

**翻译**：这策略就靠一个 10% 的止损保底，不搞追踪止损那套。要么赚，要么亏 10% 走人，干脆利落。

### 其他配置

```
时间框架：5 分钟（快进快出）
卖出信号：开启（有主动卖出）
盈利才卖：开启（不亏着走）
```

**翻译**：5 分钟一根 K 线，适合日内短线。有主动卖出信号，不是死扛到底那种。

## 三、唯一买入条件：简单粗暴

这策略只有一个买入条件，不像别的策略花里胡哨：

### 🎯 J 线上穿 0

**核心逻辑**：J 值从负数涨过 0，说明超卖反弹开始了

**大白话**：
> "J 线掉到 0 以下说明市场恐慌过度了，一旦弹回来，就是抄底机会！"

**代码片段**：
```python
J 线上穿 0
且 成交量 > 0
```

**解读**：
- J 线是什么？KDJ 指标里最敏感的那条线
- J 可以是负数（比 K 和 D 更敏感）
- J 上穿 0 = 从极度超卖开始反弹
- 这就是传说中的"跌过头了要反弹"

---

## 四、J 线是啥？给新手科普一下

KDJ 指标有三条线：

| 线 | 计算方式 | 特点 |
|---|---------|------|
| K | 快速线 | 反应快 |
| D | 慢速线 | 反应慢，确认用 |
| J | 3K - 2D | 最敏感，能超范围 |

**J 线的特殊能力**：
- K 和 D 只能在 0-100 之间晃
- J 可以跌到负数（-20、-30 都有可能）
- J 可以涨过 100（120、150 也不是没见过）

**所以**：
- J < 0：市场极度恐慌，该涨了
- J > 100：市场极度贪婪，该跌了
- PumpDetector 就是盯着 J < 0 的机会

## 五、卖出逻辑：两个逃跑路线

策略设计了两个卖出信号，哪个先触发跑哪个：

### 🏃 路线 #1：J 线上穿 90

```python
J 线上穿 90
```

**大白话**：
> "J 线涨到 90 了，进入极度超买区，可能要回调了，先跑为敬！"

### 🏃 路线 #2：J 线下穿 K 线（且 J > 50）

```python
J 线下穿 K 线
且 J > 50
```

**大白话**：
> "J 线开始拐头向下，死叉了！而且还在中高位（>50），趁还没跌太多赶紧跑！"

### 卖出信号汇总表

| 信号 | 触发条件 | 大白话翻译 |
|-----|---------|-----------|
| #1 | J 上穿 90 | 涨过头了，该回调了 |
| #2 | J 下穿 K 且 J>50 | 动能转弱，开始跌了 |

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **信号简单明确**：就一个入场点，两个出场点，不纠结

## 九、这策略在什么市场能赚钱？

### 9.1 核心逻辑：超卖反弹

PumpDetector 是一个**抄底反弹策略**。它的赚钱哲学是：

> "物极必反——J 线跌到负值，说明恐慌过头了，反弹是迟早的事。"

**它的赚钱哲学**：
- **超卖捕捉**：J < 0 时市场恐慌过度
- **反弹确认**：J 上穿 0 说明反转开始
- **主动离场**：涨够了或拐头就走，不贪

### 9.2 不同市场表现（说人话版）

| 市场类型 | 表现评级 | 大白话解释 |
| :--- | :--- | :--- |
| 📈 单边上涨 | ⭐☆☆☆☆ | J 线一直在 80-100 甚至更高，压根买不进去 |
| 🔄 震荡市场 | ⭐⭐⭐⭐⭐ | 这才是主战场！J 线来回穿越 0，抄底机会多 |
| 📉 单边下跌 | ⭐⭐☆☆☆ | J 可能在负值区待很久，抄底抄在半山腰 |
| ⚡️ 高波动市 | ⭐⭐⭐⭐☆ | 波动大，J 线起伏大，抄底机会多 |

**一句话总结**：震荡市就是它的主场，单边市请绕道。

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

PumpDetector 的逻辑简单明确——但这有个陷阱：

> **信号越简单，越容易被市场"针对"。当很多人都在等 J 线上穿 0 时，市场可能就不会那么配合了。**

简单说就是：**大家都知道的信号，往往就不灵了。**

### 短线策略的隐藏风险

实盘时，这个策略可能导致：
- **错过行情**：J 线上穿 0 的机会可能很少，错过大行情
- **抄在半山腰**：J 线可以一直在负值区，抄底抄早了
- **滑点损失**：5 分钟周期变化快，实盘成交可能不理想
- **频繁止损**：抄底失败，反复触发 10% 止损

### 我的建议（真心话）

```
1. 震荡市使用，单边市绕道
2. 多币种分散，因为信号少
3. 止损可以适当放宽
4. 加上追踪止损锁利润
5. J 线入场阈值可以尝试调整
```

**记住**：J 线抄底是有道理的，但市场永远不会按剧本演。轻仓测试，活着最重要！🙏

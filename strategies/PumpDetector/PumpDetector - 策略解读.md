## 一、策略概览

PumpDetector 是一个基于 KDJ 指标变体的抄底策略，源自 TradingView 上的 L2 KDJ with Whale Pump Detector 脚本。该策略通过捕捉 J 线的超卖反弹信号入场，在 J 线进入超买区域或出现拐头信号时退出，专注于短线抄底操作。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 1 个核心买入信号：J 线上穿 0 |
| **卖出条件** | 2 个卖出信号：J 线上穿 90 或 J 线下穿 K 线且 J > 50 |
| **保护机制** | 10% 固定止损 |
| **时间框架** | 5 分钟 (5m) |
| **依赖库** | talib, qtpylib, math, numpy |

## 三、买入条件详解

### 3.1 核心指标体系

策略使用 KDJ 指标的变体，参数如下：

| 参数 | 值 | 说明 |
|------|------|------|
| n1 | 18 | RSV 计算周期 |
| m1 | 4 | K 值平滑周期 |
| m2 | 4 | D 值平滑周期 |

### 3.2 XSA 自定义指标

策略实现了自定义的加权移动平均函数 XSA：

```python
def xsa(dataframe, source, len, wei):
    # 自定义加权移动平均
    # 参数：
    #   source: 数据源列名
    #   len: 计算周期
    #   wei: 权重
```

**设计思路**：
- XSA 是一种加权移动平均算法
- 较新的数据权重更高
- 用于平滑 KDJ 指标的计算

### 3.3 KDJ 变体指标计算

```python
# RSV 计算
dataframe['rsv'] = (close - low_n1_min) / (high_n1_max - low_n1_min) * 100

# K、D、J 值计算
dataframe['k'] = xsa(dataframe, source='rsv', len=m1, wei=1)
dataframe['d'] = xsa(dataframe, source='k', len=m2, wei=1)
dataframe['j'] = 3 * dataframe['k'] - 2 * dataframe['d']
```

**KDJ 指标解析**：
- **K 值**：RSV 的平滑值，快速反应线
- **D 值**：K 值的平滑值，慢速确认线
- **J 值**：3K - 2D，敏感度最高的线

### 3.4 辅助指标计算

策略还计算了若干辅助变量：

```python
# 价格波动率计算
dataframe['var2'] = (xsa(var1_abs, len=3, wei=1) / xsa(var1_max, len=3, wei=1)) * 100
dataframe['var3'] = EMA(var2 * 10, timeperiod=3)

```

**注意**：这些辅助变量在当前买入/卖出逻辑中未被使用，可能是策略开发过程中保留的计算。

### 3.5 唯一买入条件

#### 条件：J 线上穿 0

```python
(qtpylib.crossed_above(dataframe['j'], 0)) &   
(dataframe['volume'] > 0)
```

**逻辑解析**：
- J 线从负值上穿 0 轴，表示从极度超卖区域反弹
- 成交量大于 0 确保有效交易
- 这是一个典型的抄底信号

**J 线特性**：
- J 值可以低于 0（极度超卖）
- J 值可以高于 100（极度超买）
- J 值上穿 0 通常意味着短期反转机会

## 四、卖出逻辑详解

### 4.1 双重卖出机制

策略设计了两个独立的卖出信号：

#### 卖出信号 #1：J 线上穿 90

```python
qtpylib.crossed_above(dataframe['j'], 90)
```

**逻辑**：
- J 线进入高度超买区域
- 从下方穿越 90 阈值
- 通常意味着短期见顶

#### 卖出信号 #2：J 线下穿 K 线且 J > 50

```python
qtpylib.crossed_below(dataframe['j'], dataframe['k']) & 
(dataframe['j'] > 50)
```

**逻辑**：
- J 线从上方下穿 K 线，形成死叉
- J 值仍大于 50，处于中高位
- 表示短期动能转弱

### 4.2 卖出条件汇总

| 信号编号 | 触发条件 | 市场含义 |
|---------|---------|---------|
| #1 | J 上穿 90 | 进入极度超买，即将回调 |
| #2 | J 下穿 K 且 J > 50 | 高位动能转弱，开始回落 |

### 4.3 卖出逻辑设计思路

```
入场：J 从负值反弹（抄底）
出场：J 进入超买区或拐头向下（逃顶）
```

**完整交易周期**：
1. J 线跌至 0 以下，进入超卖区
2. J 线反弹上穿 0，触发买入
3. 价格上涨，J 线进入超买区
4. J 上穿 90 或 J 下穿 K 线，触发卖出
5. 等待下一个抄底机会

## 五、技术指标体系

### 5.1 核心指标

| 指标类别 | 具体指标 | 参数 | 用途 |
|---------|---------|------|------|
| 动量指标 | K 值 | 周期 4 | 快速反应线 |
| 动量指标 | D 值 | 周期 4 | 慢速确认线 |
| 动量指标 | J 值 | 3K-2D | 超敏感信号线 |

### 5.2 KDJ 指标深度解析

KDJ 指标是随机指标（Stochastic）的变体：

```
RSV = (收盘价 - N日最低价) / (N日最高价 - N日最低价) × 100
K = RSV 的 M 日平滑
D = K 的 M 日平滑
J = 3K - 2D
```

**J 线特点**：
- 比 K 线和 D 线更敏感
- 可以超出 0-100 范围
- 负值表示极度超卖
- 超过 100 表示极度超买

| var5 | 38 周期 | 波动率上限 |
| var7 | 综合 | 复合指标 |
| var9 | 13 周期 | 威廉指标变体 |

## 六、风险管理特色

### 6.1 固定止损保护

```
止损线：-10%
```

**设计考量**：
- 10% 止损对 5 分钟周期较宽松
- 给抄底操作足够的波动空间
- 避免被正常波动扫损

### 6.2 主动止盈机制

与被动保护策略不同，PumpDetector 依赖主动信号止盈：

| 止盈方式 | 触发条件 | 说明 |
|---------|---------|------|
| 超买退出 | J > 90 | 捕捉顶部 |
| 动能转弱 | J 下穿 K 且 J > 50 | 捕捉拐头 |

### 6.3 信号驱动架构

```
入场信号 → 持仓监控 → 出场信号
    ↓                        ↓
  止损保护                止损保护
```

**特点**：
- 入场和出场都有明确信号
- 不依赖时间止盈
- 适合短线快进快出

## 七、策略优势与局限

### ✅ 优势

1. **信号明确**：入场和出场条件清晰，便于理解和调优
2. **专注抄底**：J 线上穿 0 是经典超卖反弹信号
3. **双重止盈**：超买退出和死叉退出双重保障
4. **5 分钟周期**：适合日内短线操作

### ⚠️ 局限

1. **单一入场条件**：只有 J 上穿 0 一个入场点，机会可能较少
2. **无追踪止损**：错失利润保护机会
3. **参数固定**：KDJ 参数硬编码，无法动态调整
4. **辅助变量冗余**：计算了多个未使用的指标

## 九、适用市场环境详解

PumpDetector 是一个**短线抄底策略**。基于其 KDJ 变体设计，它最适合**震荡市场的底部捕捉**，而在单边上涨或低波动横盘市场时表现不佳。

### 9.1 策略核心逻辑

- **J 线超卖**：J 值低于 0 表示市场极度超卖
- **反弹捕捉**：J 上穿 0 意味着短期反转开始
- **主动止盈**：J 进入超买或拐头向下时离场

### 9.2 不同市场环境表现

| 市场类型 | 表现评级 | 原因分析 |
| :--- | :--- | :--- |
| 📈 单边上涨 | ⭐☆☆☆☆ | J 值持续高位，无入场机会 |
| 🔄 震荡市场 | ⭐⭐⭐⭐⭐ | 核心场景，频繁超卖反弹 |
| 📉 单边下跌 | ⭐⭐☆☆☆ | J 可能在负值区停留过久 |
| ⚡️ 高波动市 | ⭐⭐⭐⭐☆ | 波动大，抄底机会多 |

### 9.3 关键配置建议

| 配置项 | 建议值 | 说明 |
|--------|--------|------|
| 止损 | -0.10 | 5 分钟周期可适当放宽 |
| 时间框架 | 5m | 保持默认 |
| J 线入场阈值 | 0 | 可尝试调整到 -5 或 5 |

## 十、重要提醒：复杂性的代价

### 10.1 学习成本

- 需要理解 KDJ 指标的计算原理
- 需要理解 J 线的特殊性（可超出 0-100）
- 需要理解 XSA 加权平均算法

### 10.2 硬件要求

| 交易对数量 | 最低内存 | 推荐内存 |
|-----------|---------|---------|
| 1-10 个 | 2GB | 4GB |
| 10-30 个 | 4GB | 8GB |
| 30+ 个 | 8GB | 16GB |

### 10.3 回测与实盘的差异

- 5 分钟周期在回测中可能产生大量信号
- 实盘中需要考虑滑点和成交延迟
- KDJ 指标在高波动市场可能产生频繁信号

### 10.4 手动交易者建议

- 可单独使用 J 线上穿 0 作为抄底参考
- 配合其他确认指标使用更安全
- J 上穿 90 或下穿 K 线可作为减仓信号

## 十一、总结

**PumpDetector** 是一个基于 KDJ 变体的短线抄底策略。它的核心价值在于：

1. **信号明确**：J 线上穿 0 入场，J 线进入超买或拐头出场
2. **专注抄底**：只在超卖区域寻找入场机会
3. **双重止盈**：超买退出和死叉退出双保险

对于量化交易者而言，这是一个适合震荡市场短线操作的策略，但需注意信号频率和市场环境的选择。

## 一、策略概览

**HansenSmaOffsetV1** 是一个基于 SMA 偏移带的区间突破策略。策略通过计算简单移动平均线的上下偏移构建价格通道，在价格触及下轨时买入、触及上轨时卖出，捕捉区间震荡市场中的反弹与回调机会。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 1 个买入信号，基于下轨突破与阳线确认 |
| **卖出条件** | 1 个卖出信号，基于上轨突破与阴线确认 |
| **保护机制** | 硬止损 -10%，分级 ROI 止盈 |
| **时间框架** | 15 分钟 |
| **依赖库** | TA-Lib, qtpylib, numpy |

## 二、策略配置解析

### 2.1 基础风险参数

# ROI 退出表
minimal_roi = {

    "30": 0.05,  # 30 分钟后：盈利 5%

**设计思路**：
- **激进止盈**：立即出场设置 10% 止盈，追求快速获利
- **时间递减**：持仓时间越长，止盈阈值越低，降低持仓风险
- **对称止损**：-10% 止损与 10% 立即止盈形成对称风险收益比

### 2.2 订单类型配置

策略使用默认订单类型配置，无特殊设置。

dataframe.loc[

## 五、技术指标体系

### 5.1 核心指标

策略使用两类技术指标：SMA 偏移带与 Heikin-Ashi 平滑价格。

| 指标类别 | 具体指标 | 计算方式 | 用途 |
|---------|---------|---------|------|
| **趋势指标** | SMA 偏移带上轨 | SMA(20) × 1.05 | 压力位识别 |
| **趋势指标** | SMA 偏移带下轨 | SMA(20) × 0.95 | 支撑位识别 |
| **平滑指标** | Heikin-Ashi 收盘价 | (O+H+L+C) / 4 | 价格平滑 |
| **平滑指标** | Heikin-Ashi 开盘价 | (前2根O+C) / 2 | 趋势确认 |
| **辅助指标** | HA 收盘均线 | SMA(hclose, 6) | 短期趋势 |
| **辅助指标** | HA 开盘均线 | SMA(hopen, 6) | 短期趋势 |

### 5.2 SMA 偏移带详解

SMA 偏移带是本策略的核心指标，构建方法如下：

```python
# 上轨：SMA(20) 上浮 5%
dataframe['smau1'] = ta.SMA(dataframe['close'], timeperiod=20) * 1.05

# 下轨：SMA(20) 下浮 5%
dataframe['smad1'] = ta.SMA(dataframe['close'], timeperiod=20) * 0.95
```

**设计特点**：
- 偏移幅度固定为 ±5%，构建宽度约 10% 的价格通道
- 通道动态调整，适应市场波动
- 上轨作为压力位，下轨作为支撑位

### 5.3 Heikin-Ashi 平滑价格

策略使用简化版 Heikin-Ashi 价格进行趋势确认：

```python
# HA 收盘价：四价均值
dataframe['hclose'] = (dataframe['open'] + dataframe['high'] + 
                       dataframe['low'] + dataframe['close']) / 4

# HA 开盘价：前2根K线开盘收盘均值
dataframe['hopen'] = ((dataframe['open'].shift(2) + 
                       dataframe['close'].shift(2)) / 2)

# HA 最高价：三价取大
dataframe['hhigh'] = dataframe[['open', 'close', 'high']].max(axis=1)

# HA 最低价：三价取小
dataframe['hlow'] = dataframe[['open', 'close', 'low']].min(axis=1)
```

**设计特点**：
- 平滑价格噪音，过滤假信号
- 阳线（hopen < hclose）表示上涨趋势
- 阴线（hopen > hclose）表示下跌趋势

## 六、风险管理特色

### 6.1 分级止盈机制

策略采用时间递减的 ROI 止盈机制：

| 持仓时间 | 止盈阈值 | 风险偏好 |
|---------|---------|---------|
| 立即出场 | 10% | 激进 |
| 30 分钟后 | 5% | 中等 |
| 60 分钟后 | 2% | 保守 |

**设计理念**：
- 持仓时间越长，风险敞口越大
- 降低止盈阈值可锁定已有利润
- 避免长期持仓的不确定性

### 6.2 硬止损保护

```python
stoploss = -0.10  # 10% 固定止损
```

**特点**：
- 与立即止盈形成 1:1 风险收益比
- 单笔交易最大亏损控制在 10%
- 无追踪止损，执行简单直接

### 6.3 信号过滤机制

策略通过双重条件过滤假信号：

| 过滤层 | 作用 | 效果 |
|--------|------|------|
| 轨道突破 | 价格必须超出通道边界 | 排除区间内震荡 |
| 蜡烛形态 | HA 阳线/阴线确认 | 排除假突破 |

## 七、策略优势与局限

### ✅ 优势

1. **逻辑简洁**：买入卖出规则清晰，易于理解和维护
2. **参数精简**：仅依赖 SMA 周期和偏移比例，过拟合风险低
3. **区间适配**：在震荡行情中表现优异，捕捉反弹与回调
4. **计算高效**：指标计算简单，资源消耗低

### ⚠️ 局限

1. **趋势市场弱势**：在单边趋势中会频繁逆势交易
2. **假信号风险**：无趋势方向过滤，震荡市可能频繁止损
3. **偏移幅度固定**：5% 偏移不适应所有市场波动环境
4. **无成交量确认**：缺乏量能验证，信号可靠性受限

## 九、适用市场环境详解

**HansenSmaOffsetV1** 是典型的区间交易策略。基于其代码架构和逻辑设计，它最适合**震荡横盘市场**，而在**单边趋势市场**时表现不佳。

### 9.1 策略核心逻辑

- **均值回归思想**：价格偏离均线后倾向于回归
- **通道交易模式**：下轨买入、上轨卖出的经典区间策略
- **趋势确认过滤**：HA 蜡烛形态提供短期动能验证

## 十、重要提醒：策略使用注意事项

### 10.1 市场识别

使用本策略前，需判断当前市场是否处于震荡状态：

- **震荡信号**：价格在 SMA 通道内反复穿越
- **趋势信号**：价格持续在通道一侧运行
- **建议**：趋势市场时可考虑暂停策略或扩大偏移幅度

### 10.2 参数优化空间

| 参数 | 默认值 | 优化方向 |
|------|--------|---------|
| SMA 周期 | 20 | 根据市场特性可调整 15-30 |
| 偏移比例 | 5% | 高波动市场可扩大至 7-10% |
| 止损比例 | -10% | 根据风险偏好调整 |

### 10.3 信号确认建议

策略缺乏成交量确认，建议结合：

- 成交量放大确认突破有效性
- RSI 或 MACD 辅助判断超买超卖
- 多时间框架确认趋势方向

### 10.4 回测与实盘差异

区间策略在回测中可能表现优异，但实盘时需注意：

- 滑点可能侵蚀利润
- 交易频率高时手续费影响显著
- 震荡转趋势时可能连续亏损

## 十一、总结

**HansenSmaOffsetV1** 是一个设计简洁、逻辑清晰的区间突破策略。它的核心价值在于：

1. **简单有效**：SMA 偏移带构建通道，HA 蜡烛确认信号，规则透明易执行
2. **区间适配**：专为震荡市场设计，捕捉均值回归机会
3. **易于理解**：参数精简，新手友好，便于理解和优化

对于量化交易者而言，本策略是学习区间交易逻辑的良好起点，但在趋势市场中需谨慎使用或结合趋势过滤器。建议根据目标市场的波动特性调整偏移幅度，并增加成交量或趋势方向等过滤条件以提升信号质量。

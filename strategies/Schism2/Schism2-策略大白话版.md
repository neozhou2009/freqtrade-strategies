## 三、买入条件：分两种情况

这策略的买入条件分两种情况：

### 🎯 情况 1：无持仓时（正常买入）

**核心逻辑**：
1. 价格 <= 3 日低点 + ADR 百分比
2. 1h RSI >= 57
3. RMI 下降趋势
4. RMI 慢速 >= 24
5. RMI 快速 <= 49
6. Momentum Pinball <= 64

**大白话**：
> "价格回调到 3 日低点了，1h RSI 也高了，RMI 也确认下降趋势了——这还不买？"

### 🎯 情况 2：有持仓时（持续买入）

**核心逻辑**：
1. RMI 上升趋势
2. 当前利润 > 峰值利润×因子
3. RMI 慢速 >= 增长值

**大白话**：
> "趋势还在向上，利润也还好——继续买，别停！"

**吐槽**：这策略是真的"灵活"，有持仓和没持仓两套逻辑！🤣

```python
loss_cutoff = linear_growth(-0.03, 0, 0, 300, open_minutes)

if current_profit < loss_cutoff:
    if rmi_dn_trend == 1:
        # 退出
```

**大白话**：
> "刚开仓时亏 3% 以内不卖，300 分钟后亏 1% 就得卖了——时间越久越严格！"

### 5.2 多交易管理：根据空闲仓位调整

**触发条件**：
```python
if free_slots > 0:
    # 空闲仓位少，更愿意卖
    hold_pct = (1 / free_slots) * -0.04
    avg_other_profit >= hold_pct
else:
    # 没有空闲仓位，允许最大亏损的交易退出
    biggest_loser == True
```

**大白话**：
> "还有空仓位？那等等看。没空仓位了？那亏最大的先跑，腾位置！"

## 六、这策略的"人格特点"

### ✅ 优点
1. **动态买卖**：根据交易状态动态调整
2. **多时间框架**：1h 确认趋势，减少假信号
3. **多交易管理**：根据空闲仓位调整退出策略
4. **BTC/ETH 支持**：额外的质押货币确认
5. **价格缓存**：减少 API 调用，提高效率
6. **超参数优化**：可以自动找最佳参数

### ⚠️ 缺点
1. **复杂度极高**：动态逻辑 + 多时间框架，调试起来头疼
2. **仅支持实盘**：回测无法测试动态逻辑
3. **没 BTC 大盘关联**：比特币崩了它也不知道（除非质押是 BTC）
4. **计算量大**：多指标 + 动态数据增加计算负担
5. **参数敏感**：优化出来的参数可能过拟合

这策略用多指标 + 动态数据，计算量高：

| 交易对数量 | 最低内存 | 推荐内存 | 体验 |
|-----------|---------|---------|------|
| 20-40 对 | 2GB | 4GB | 能跑 |
| 40-80 对 | 4GB | 8GB | 舒服 |

**警告**：2GB 内存以下的 VPS 就别尝试了，这策略真吃资源 😅

### 10.3 仅支持实盘

动态交易数据在回测中不可用：
- `populate_trades()` 函数仅在 live/dry_run 模式下工作
- 回测无法测试动态买卖逻辑
- 实盘前需充分干跑测试

**吐槽**：这策略就是"实盘专用"，回测党慎入！🤣

### 10.4 回测 vs 实盘

策略逻辑复杂，回测与实盘差异主要来自：
- 动态交易数据在回测中不可用
- 超参数过拟合
- 多时间框架数据延迟

**建议流程**：
1. 先用 Hyperopt 优化参数（静态部分）
2. 模拟交易（Dry-Run）跑 2-4 周
3. 观察动态逻辑是否正常工作
4. 小资金实盘测试 1 个月

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

Schism2 的历史回测表现可能**非常优异**——但这有个陷阱：

> **动态逻辑在回测中不可用，回测数据好看不代表实盘一定好。**

简单说就是：**回测只能测试静态部分，动态逻辑得实盘测试。**

### 复杂策略的隐藏风险

实盘时，复杂的逻辑可能导致：
- **动态逻辑错误**：动态交易状态可能出错
- **过拟合风险**：超参数优化结果可能过拟合
- **计算延迟**：多指标 + 动态数据可能有延迟

### 我的建议（真心话）

```
1. 先用最小资金量（如 100U）测试
2. 实盘跑至少 2-4 周，观察动态逻辑是否正常工作
3. 用 Hyperopt 优化参数但要验证
4. 考虑自己加个 BTC 关联过滤
```

**记住**：策略越复杂，越要警惕过拟合风险。活着最重要！

## 三、1 个买入条件：简单到极致

### 🎯 唯一的买入条件：资金流出就买

**核心逻辑**：看 CMF 指标

**大白话**：
> "当资金流出（CMF < 0）的时候买，等资金流入了就卖。"

**CMF 是啥？**

CMF (Chaikin Money Flow) 叫"蔡金资金流向指标"，说白了就是：
- CMF > 0：钱在流进来（有人在买）
- CMF < 0：钱在流出去（有人在卖）

**这策略的逻辑**：
> "大家都在卖的时候我买，等有人买了我就卖。"

听起来像是"抄底"，但也可能是"接飞刀"😅

## 四、卖出逻辑：也是一根筋

### 卖出条件

```
CMF > 0 就卖
```

**大白话**：
> "资金开始流入了，赶紧卖出跑路。"

### 其他退出方式

- 赚够 1% 就卖（ROI 止盈）
- 亏到 5% 就卖（止损）

## 八、CMF 指标大白话解读

### CMF 怎么算的？

简单说，就是看"买的力量大还是卖的力量大"：

```
多空力量 = ((收盘价 - 最低价) - (最高价 - 收盘价)) / (最高价 - 最低价)
CMF = 所有K线的(多空力量 × 成交量)之和 / 所有K线的成交量之和
```

**翻译成人话**：
- 收盘价靠近最高价 → 买方强
- 收盘价靠近最低价 → 卖方强
- 再乘上成交量 → 大资金更有分量

### CMF 数值含义

| CMF 值 | 意思 |
|--------|------|
| CMF > 0.1 | 强资金流入，买方主导 |
| CMF > 0 | 资金流入，偏买 |
| CMF = 0 | 买卖平衡 |
| CMF < 0 | 资金流出，偏卖 |
| CMF < -0.1 | 强资金流出，卖方主导 |

### 回测很美好，实盘要谨慎

TechnicalExampleStrategy 的历史回测可能还行——但它有个明显问题：

> **只有一个指标，没有多维验证，假信号会很多。**

简单说就是：**抄底抄到半山腰是常事。**

### 极简策略的隐藏风险

实盘时，简单的逻辑可能导致：
- **震荡市亏损**：CMF 频繁穿越零轴，来回打脸
- **趋势市被套**：逆势买入，越买越跌
- **滑点成本**：频繁交易，手续费和滑点吃掉利润

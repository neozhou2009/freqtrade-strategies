## 三、买入条件详解

### 3.1 保护机制

本策略无特殊保护机制，仅依赖基础止损。

### 3.2 买入条件详解

#### 条件 #1：CMF 资金流出信号

```python
# 逻辑
- CMF(21) < 0  # 资金流出状态
```

**核心指标说明**：

| 指标 | 参数 | 用途 |
|------|------|------|
| CMF (Chaikin Money Flow) | 周期 21 | 衡量资金流入流出 |

**Chaikin Money Flow (CMF) 指标原理**：
- CMF 由 Marc Chaikin 开发，用于衡量买卖压力
- CMF > 0 表示资金流入（买方力量强）
- CMF < 0 表示资金流出（卖方力量强）
- 数值范围在 -1 到 +1 之间

**策略逻辑解读**：
当 CMF < 0 时，意味着市场处于资金流出状态，价格可能被低估。策略选择此时买入，押注资金流出的反转。

### 4.1 卖出信号


**逻辑解读**：
当 CMF > 0 时，市场资金开始流入，卖方压力减弱，买方力量增强。此时策略选择卖出，实现盈利。

## 五、技术指标体系

### 5.1 核心指标

| 指标类别 | 具体指标 | 用途 |
|---------|---------|------|
| 成交量指标 | CMF (Chaikin Money Flow) | 资金流向判断 |

### 5.2 CMF 指标详解

**Chaikin Money Flow (CMF)** 是一个成交量加权的价格动量指标：

```
CMF = Σ(多空力量 × 成交量) / Σ(成交量)
```

其中多空力量计算：
```
多空力量 = ((收盘价 - 最低价) - (最高价 - 收盘价)) / (最高价 - 最低价)
```

**关键参数**：
- 周期：21（约 1.75 小时的 5 分钟 K 线）
- 信号阈值：0（正负分界线）

## 七、策略优势与局限

### ✅ 优势

1. **极简设计**：代码仅 40 行左右，易于理解和维护
2. **逻辑清晰**：单一指标，买入卖出条件明确
3. **资金流导向**：利用成交量信息，捕捉市场资金流向变化

### ⚠️ 局限

1. **单一指标风险**：仅依赖 CMF，缺乏多维度验证
2. **逆势抄底风险**：资金流出时买入可能接飞刀
3. **无保护机制**：无追踪止损，可能在反转后回吐利润
4. **假信号风险**：CMF 在震荡市中可能频繁发出假信号

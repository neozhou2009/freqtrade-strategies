## 一、策略概览

**ReinforcedQuickie** 是由 Gert Wohlgemuth 开发的快速交易策略，核心特色是使用重采样（resample）技术来确认总体趋势，只在上涨趋势中买入。策略结合了 EMA、布林带、CCI、MFI、RSI 等多个指标，并设计了独特的 V 型底部形态识别逻辑。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 2 种模式（布林带突破 + V 型底部） |
| **卖出条件** | 多条件组合（EMA + 布林带 + MFI + 8 连阳） |
| **保护机制** | 重采样趋势过滤 |
| **时间框架** | 5 分钟 |
| **依赖库** | TA-Lib, technical |
| **特殊功能** | 重采样趋势确认、V 型底部识别 |

## 三、买入条件详解

### 3.1 买入逻辑（模式 1：布林带突破）

```python
# 模式 1 买入条件
(
    (close < ema_5) &
    (close < ema_12) &
    (close == min_12) &
    (close <= bb_lowerband)
)
```

**逻辑解析**：
- **价格 < EMA5**：短期价格低于 5 周期 EMA
- **价格 < EMA12**：短期价格低于 12 周期 EMA
- **价格 = 12 周期最低**：价格处于 12 周期最低点
- **价格 <= 布林带下轨**：价格触及或跌破布林带下轨

**综合含义**：价格处于短期低位，触及布林带下轨，可能反弹。

### 3.2 买入逻辑（模式 2：V 型底部）

```python
# 模式 2 买入条件（V 型底部）
(
    average.shift(5) > average.shift(4) &
    average.shift(4) > average.shift(3) &
    average.shift(3) > average.shift(2) &
    average.shift(2) > average.shift(1) &
    average.shift(1) < average.shift(0) &
    low.shift(1) < bb_middleband &
    cci.shift(1) < -100 &
    rsi.shift(1) < 30 &
    mfi.shift(1) < 30
)
```

**逻辑解析**：
- **连续 5 根 K 线下降**：前 5 根 K 线的平均价持续下降
- **第 6 根 K 线反弹**：当前 K 线平均价高于前一根
- **最低价 < 布林带中轨**：前一根 K 线最低价低于布林带中轨
- **CCI < -100**：前一根 K 线 CCI 处于超卖区域
- **RSI < 30**：前一根 K 线 RSI 处于超卖区域
- **MFI < 30**：前一根 K 线 MFI 处于超卖区域

**综合含义**：典型的 V 型反转形态，多重超卖确认后反弹。

### 3.3 趋势过滤（重采样）

```python
# 重采样趋势过滤
(
    (volume < volume.rolling(30).mean().shift(1) * 20) &  # 成交量过滤
    (resample_sma < close) &                               # 价格在重采样 SMA 之上
    (resample_sma.shift(1) < resample_sma)                 # 重采样 SMA 上升
)
```

**作用**：
- **成交量过滤**：排除异常高成交量（可能是操纵）
- **价格在重采样 SMA 之上**：确认长期趋势向上
- **重采样 SMA 上升**：确认趋势正在加强

## 四、卖出逻辑详解

### 4.1 卖出条件（模式 1：高位退出）

```python
# 模式 1 卖出条件
(
    (close > ema_5) &
    (close > ema_12) &
    (close >= max_12) &
    (close >= bb_upperband) &
    (mfi > 80)
)
```

**逻辑解析**：
- **价格 > EMA5/12**：短期价格高于双 EMA
- **价格 = 12 周期最高**：价格处于 12 周期最高点
- **价格 >= 布林带上轨**：价格触及或突破布林带上轨
- **MFI > 80**：MFI 处于超买区域

**综合含义**：价格处于短期高位，触及布林带上轨，可能回调。

### 4.2 卖出条件（模式 2：8 连阳）

```python
# 模式 2 卖出条件（8 连阳 + 高 RSI）
(
    (open < close) &
    (open.shift(1) < close.shift(1)) &
    (open.shift(2) < close.shift(2)) &
    (open.shift(3) < close.shift(3)) &
    (open.shift(4) < close.shift(4)) &
    (open.shift(5) < close.shift(5)) &
    (open.shift(6) < close.shift(6)) &
    (open.shift(7) < close.shift(7)) &
    (rsi > 70)
)
```

**逻辑解析**：
- **连续 8 根阳线**：连续 8 根 K 线收盘价高于开盘价
- **RSI > 70**：RSI 处于超买区域

**综合含义**：连续上涨 8 根 K 线且 RSI 超买，可能回调。

## 五、技术指标体系

### 5.1 核心指标

| 指标类别 | 具体指标 | 参数 | 用途 |
|---------|---------|------|------|
| **趋势指标** | EMA | 5, 12, 21 周期 | 短期趋势判断 |
| **波动指标** | Bollinger Bands | 20 周期，2 倍标准差 | 价格边界判断 |
| **动量指标** | CCI | 默认 | 超买超卖 |
| **动量指标** | MFI | 默认 | 资金流 |
| **动量指标** | RSI | 7 周期 | 超买超卖 |
| **重采样** | Resampled SMA | 25 周期（60m 框架） | 长期趋势确认 |

### 5.2 重采样技术

```python
def resample(self, dataframe, interval, factor):
    # 重采样逻辑
    # 5m × 12 = 60m
    df = df.resample('60min').agg(ohlc_dict)
    df['resample_sma'] = ta.SMA(df, timeperiod=25, price='close')
    # 插值回 5m 框架
    df = df.resample('5min').interpolate(method='time')
    return df
```

**特点**：
- 将 5 分钟数据聚合为 60 分钟数据
- 计算 60 分钟框架的 25 周期 SMA
- 插值回 5 分钟框架，保持数据连续性

## 六、风险管理特色

### 6.1 硬止损

```python
stoploss = -0.05  # -5%
```

**说明**：严格止损，控制单笔亏损在 5% 以内。

### 6.2 重采样趋势过滤

```python
resample_sma < close  # 价格在重采样 SMA 之上
resample_sma.shift(1) < resample_sma  # 重采样 SMA 上升
```

**作用**：
- 确保只在长期上涨趋势中交易
- 避免在下跌趋势中逆势买入
- 这是策略最重要的风险过滤机制

### 6.3 成交量过滤

```python
volume < volume.rolling(30).mean().shift(1) * 20
```

**作用**：排除异常高成交量，防止被操纵。

## 七、策略优势与局限

### ✅ 优势

1. **重采样趋势过滤**：60 分钟 SMA 确认长期趋势
2. **V 型底部识别**：独特的 V 型反转形态识别
3. **多指标组合**：EMA + 布林带 + CCI + MFI + RSI 多维度确认
4. **快速周转**：1% ROI 即可退出，资金利用率高
5. **严格止损**：-5% 止损控制风险

### ⚠️ 局限

1. **复杂度高**：重采样技术 + 多指标，调试困难
2. **无 BTC 关联**：不检测比特币大盘趋势
3. **低 ROI**：1% ROI 可能过早退出趋势
4. **V 型底部条件严格**：可能很少触发
5. **计算量大**：重采样增加计算负担

## 十、重要提醒：重采样技术

### 10.1 学习成本中等

策略代码约 150 行，需要理解重采样技术。

### 10.2 硬件要求中等

重采样增加计算量：

| 交易对数量 | 最低内存 | 推荐内存 |
|-----------|---------|---------|
| 20-40 对 | 1GB | 2GB |
| 40-80 对 | 2GB | 4GB |

### 10.3 重采样优势

- **趋势确认**：60 分钟 SMA 比 5 分钟更可靠
- **减少假信号**：只在长期上涨趋势中交易
- **自动躺平**：下跌趋势中自动停止交易

### 10.4 手动交易者建议

手动交易者可参考此策略的重采样思路：
- 同时观察 5m 和 60m 趋势
- 只在 60m 趋势向上时在 5m 入场
- 使用严格止损（如 -5%）

## 一、策略概览

RalliV1_disable56 是一个基于 Elliott Wave Oscillator (EWO) 和多重移动平均线交叉的趋势跟踪策略。该策略由 @Rallipanos 开发，通过识别价格相对于移动平均线的偏离程度，结合 RSI 动量指标和 EWO 振荡器，在市场回调时寻找入场机会。策略名称中的 "disable56" 暗示该版本禁用了原策略中的第 5、6 号买入条件。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 4 个独立买入信号，分为熊市（MA<EMA100）和牛市（MA>EMA100）两类场景 |
| **卖出条件** | 2 个基础卖出信号，结合趋势反转和价格突破判断 |
| **保护机制** | 自定义止损 + 追踪止损 + 时间止损三重保护 |
| **时间框架** | 5m 主时间框架 + 1h 信息时间框架 |
| **依赖库** | talib, numpy, pandas, qtpylib, technical |

### 5.2 Elliott Wave Oscillator (EWO)

```python
def EWO(dataframe, ema_length=5, ema2_length=200):
    ema1 = ta.EMA(df, timeperiod=ema_length)   # 快线
    ema2 = ta.EMA(df, timeperiod=ema2_length)  # 慢线
    emadif = (ema1 - ema2) / df['low'] * 100   # 标准化差值
    return emadif
```

EWO 是本策略的核心指标，用于判断市场动量：
- 正值 > 2.327：动量强劲，适合买入
- 负值 < -20.988：极度超卖，反弹机会

### 6.3 分场景买卖逻辑

- **熊市（MA < EMA100）**：三个买入条件，更激进地捕捉反转
- **牛市（MA > EMA100）**：一个买入条件，谨慎回调买入

## 七、策略优势与局限

### ✅ 优势

1. **多场景适应**：熊市反转和牛市回调两种场景都有对应买入条件
2. **EWO 独特指标**：使用 Elliott Wave Oscillator 识别动量变化，较少见
3. **动态参数优化**：大量参数支持 Hyperopt 优化，可针对不同币种调优
4. **三重止损保护**：固定 + 追踪 + 时间止损，全方位风险管理

### ⚠️ 局限

1. **参数敏感**：多个参数依赖优化，可能存在过拟合风险
2. **EWO 极值固定**：ewo_low = -20.988 可能不适用于所有市场
3. **卖出条件较少**：仅 2 个卖出信号，可能错过部分出场机会
4. **时间框架固定**：仅支持 5m，不适配其他时间周期

# Mark_Strat 策略：布林带"抄底王"

> **外号**：抄底王、布林带叛逆者  
> **职业**：跌破下轨就敢买的猛男  
> **时间框架**：1 分钟（超短线剥头皮）

---

## 一、这策略是个啥？

简单说，**Mark_Strat** 就是一个：
- 价格跌破布林带下轨就买
- RSI 冲到 90 以上就跑
- 29 分钟必须收工

就像**打折抢购**：等商品降价到破底价，买入；等它恢复原价，卖出！🛒

---

## 二、核心配置：说白了就是"快进快出让利润跑"

### 止盈规则（ROI 表）

```
刚买入：目标 3.65%
7分钟后：目标降到 1.22%
16分钟后：目标降到 0.76%
29分钟后：不管怎样，给我出来！
```

**翻译**：这策略是剥头皮选手，29 分钟内必须结束战斗。买完赶紧涨，涨得慢就降低预期。

### 止损规则

```
初始止损：-23.94%（等等，没看错吧？）
```

**翻译**：没错，初始止损是 -23.94%！超级宽松！意思是"买完就算跌 20% 我也不慌，因为我有追踪止损"。

### 追踪止损（这才是重点）

```
利润达到 17.49% → 启动追踪止损
利润回撤到 13.60% → 触发止损，保护利润
```

**翻译**：初始止损宽得离谱，但一旦你赚了大钱（17%以上），它就开始保护你的利润了。只要利润回撤到 13.6%，它就帮你锁住收益。

## 三、1 个买入条件：跌破下轨就干

**大白话**：
> "收盘价跌破布林带下轨？有成交量？干！"

**经典台词**：
```python

(
    ((dataframe['close'] < dataframe['bb_lowerband'])) &  # 跌破布林带下轨

)
```

> "布林带下轨？那是支撑位！跌破了就是送钱！"

**拆解一下**：
- **布林带下轨**：20 周期，2 倍标准差，价格跌破这个位置就是"超卖"
- **成交量 > 0**：确认有人在这个位置交易

## 四、多层退出机制：这策略很"花心"

### 4.1 三种退出方式

| 退出方式 | 触发条件 | 说明 |
|---------|---------|------|
| ROI 止盈 | 按时间递减 | 29 分钟内强制退出 |
| 卖出信号 | RSI > 90 + 回归中轨 | 主动退出 |
| 追踪止损 | 利润回撤到 13.6% | 保护利润 |

### 4.2 卖出信号详解

**大白话**：
> "RSI 冲到 90 以上了，价格也回到布林带中轨了，赶紧跑！"

**经典台词**：
```python
# 卖出条件
(
    (dataframe['rsi'] > 90) &                              # RSI 超级高
    ((dataframe['close'] > dataframe['bb_middleband'])) &  # 回到中轨
    (dataframe['volume'] > 0)                               # 有人交易
)
```

> "RSI 都 90 了，价格也回到中轨了，反弹结束了，赶紧落袋为安！"

### 4.3 追踪止损图解

```
利润发展              止损行为
────────────────────────────────────────
0% ~ 17%              初始止损 -24% 生效
达到 17.49%           追踪止损启动！
利润回撤到 13.60%     触发退出，锁住约 4% 利润缓冲
```

**大白话**：赚够了就开始保护你，不让利润溜走。

## 五、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **逻辑简单**：布林带下轨买，中轨卖，清清楚楚
2. **追踪止损给力**：赚够了就保护你，让利润奔跑
3. **时间约束明确**：29 分钟必须走人，不纠结
4. **只在盈利时卖**：sell_profit_only = True，不会亏着出来

### ⚠️ 缺点（吐槽环节）

1. **初始止损太宽**：-24%！买完跌 20% 都不止损，太"佛系"了
2. **1 分钟级别**：网速慢了就错过行情
3. **指标冗余**：算了 MACD、SAR、StochRSI 但都没用上
4. **剥头皮成本**：频繁交易手续费会吃利润

Mark_Strat 是**均值回归策略**。它的赚钱哲学：

> **"价格跌破布林带下轨，就是超卖；等它回到中轨，就是赚钱。"**

- **布林带下轨买入**：价格跌过头了
- **布林带中轨卖出**：价格回归正常了
- **RSI > 90 确认**：反弹够猛了，该走了

### 9.3 回测 vs 实盘

剥头皮策略回测和实盘差异很大：

- **滑点**：1 分钟级别，滑点可能吃掉一半利润
- **延迟**：交易所延迟可能错过最佳入场
- **手续费**：频繁交易，手续费占比高
- **流动性**：大单子可能产生更大滑点

**建议流程**：
1. 回测验证逻辑
2. 模拟盘测试执行
3. 小资金实盘
4. 每笔交易计算滑点和手续费

**别被回测骗了**，剥头皮策略实盘表现往往差很多！

## 十二、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

Mark_Strat 的历史回测表现可能**看起来不错**——但有几个陷阱：

> **剥头皮策略最大的敌人是交易成本和滑点。**

### 1 分钟级别的隐藏风险

实盘时，1 分钟级别可能导致：
- **滑点**：价格在几秒内就变了，入场价可能差很多
- **延迟**：网络延迟可能错过最佳时机
- **手续费**：频繁交易，手续费可能吃掉一半利润
- **流动性**：小币种可能买不进去或卖不出来

### 宽止损的风险

- **最大亏损 24%**：一笔交易可能亏四分之一
- **追踪止损启动门槛高**：要赚 17.5% 才启动保护
- **很多交易等不到追踪止损**：就亏着出来了

### 我的建议（真心话）

```
1. 收紧初始止损到 -15%
2. 降低追踪止损启动阈值到 10%
3. 只在震荡市场用
4. 小资金测试，别梭哈
5. 计算每笔交易的实际成本（滑点+手续费）
```

**记住**：剥头皮策略看起来简单，实盘执行最难。网络延迟、交易所延迟、滑点、手续费，每个都在吃你的利润！

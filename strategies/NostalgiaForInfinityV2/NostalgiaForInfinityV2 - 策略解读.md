## 一、策略概览

**NostalgiaForInfinityV2**（简称 NFI V2）是 NostalgiaForInfinity（原版）的第二个正式优化版本。作为 NFI V 系列的进阶版本，V2 在 V1 的基础上进行了参数优化和策略调整，代表了从"稳健派"向"进取派"的过渡。

V2 版本的特点是"稳中求进"——在保留 V1 核心架构的基础上，适度提高了收益目标，收紧了止损控制，使策略更加积极。相比 V1，V2 更适合有一定风险承受能力、追求更高收益的投资者。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 多组优化信号，涵盖趋势确认、支撑反弹、背离反转等类型 |
| **卖出条件** | 多层动态止盈 + 更严格的止损保护 + 更积极的追踪止损 |
| **保护机制** | EMA/SMA 趋势保护 + 波动控制 + 多周期验证（V2 优化版） |
| **时间框架** | 15 分钟主框架 + 1 小时信息框架 |
| **依赖库** | pandas, numpy, TA-Lib, technical |

### V1 vs V2 核心对比

| 参数 | V1 | V2 | 变化说明 |
|------|-----|-----|---------|
| 首级 ROI | 10% | 11% | +1%，收益目标更高 |
| 二级 ROI | 6% | 6.5% | +0.5%，止盈更积极 |
| 三级 ROI | 3% | 3.5% | +0.5%，中期目标提高 |
| 固定止损 | -10% | -9.5% | +0.5%，止损更严格 |
| 追踪启动 | 3% | 3.5% | +0.5%，更早锁定利润 |
| 追踪偏移 | 5% | 5.5% | +0.5%，追踪更灵活 |

## 四、卖出逻辑详解

### 4.1 多层止盈系统（V2 更积极）

V2 采用四级渐进式止盈机制，比 V1 更积极：

```
利润率区间     阈值       V1 对比    信号名称
─────────────────────────────────────────────
0-30 分钟     11%       +1%       快速获利（更积极）
30-60 分钟     6.5%      +0.5%     中期目标（提高）
60-120 分钟    3.5%      +0.5%     保守退出（提高）
120 分钟+      1.5%      持平      尾盘保本
```

**V2 止盈设计哲学**：
- 首级目标提高 1%，抓住快速盈利机会
- 二级、三级目标同步提高，不放过中期利润
- 四级目标保持 1.5%，确保尾盘保本

### 4.2 特殊卖出场景

| 场景 | 触发条件 | 信号名称 | V2 特点 |
|------|---------|---------|---------|
| 均线死叉 | 短期均线跌破长期均线 | 趋势退出 | 更灵敏的死叉判断 |
| RSI 超买 | RSI 超过特定阈值 | 动量退出 | 调整超买阈值 |
| 布林带上轨 | 价格触及上轨 | 阻力退出 | 配合追踪止损 |
| 追踪止损触发 | 利润回撤超过阈值 | 锁定利润 | 更早启动（3.5%） |

### 4.3 基础卖出信号（V2 版）

1. **均线死叉**：趋势转弱的经典信号，V2 优化了判断灵敏度
2. **RSI 超买**：动量达到极端，V2 调整了超买阈值参数
3. **布林带上轨**：遇到技术阻力，配合追踪止盈
4. **追踪止损**：利润回撤到阈值，3.5% 启动锁定收益

## 七、策略优势与局限

### ✅ 优势

1. **收益预期更高**：首级 ROI 11%，比 V1 提高 1%
2. **止损控制更严**：-9.5% 比 -10% 收紧 0.5%

5. **进可攻退可守**：更积极但不过度激进

### ⚠️ 局限

1. **波动可能更大**：更激进的策略带来更大波动
2. **止损可能更频繁**：-9.5% 比 -10% 更容易被扫
3. **需要更多关注**：更积极的策略需要更多监控
4. **不适合极端保守者**：追求稳健者建议用 V1

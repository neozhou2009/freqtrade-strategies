## 1. 策略概述

### 1.1 策略背景

Obelisk_3EMA_StochRSI_ATR 是一款基于多重技术指标组合的趋势跟踪策略，由开发者 Obelisk 于 2021 年 4 月发布。该策略的设计灵感来源于知名交易平台 Trade Pro 的视频教程——《76%胜率高盈利交易策略验证100笔交易》，该视频详细阐述了策略的核心逻辑和实战验证结果。

策略的核心思想是将三种经典技术分析工具有机融合：指数移动平均线（EMA）用于判断趋势方向，随机相对强弱指标（StochRSI）用于识别入场时机，平均真实波幅（ATR）用于动态设定止损止盈水平。这种多维度分析方法能够有效过滤假信号，提高交易胜率。

### 1.2 策略定位

该策略被明确标注为**仅供研究和回测使用**，不建议直接用于实盘交易。开发者强调策略的正确性和准确性不作保证，使用者需自行承担风险。这一声明反映了量化交易领域的一个重要原则：任何策略在实盘应用前都需要经过严格的验证和优化。

策略的主要应用场景包括：
- 量化策略研究学习
- 回测分析验证
- 超参数优化实验
- 风险管理机制研究

### 1.3 核心特点

策略具备以下显著特点：

**趋势跟踪与动量确认相结合**：通过 EMA 均线系统识别主趋势方向，再利用 StochRSI 指标确认动量转折点，双重验证确保信号可靠性。

**动态风险管理**：基于 ATR 指标计算的止损止盈水平能够根据市场波动性自动调整，在波动剧烈时扩大止损范围，在波动平缓时收紧止损，实现风险敞口的动态控制。

**多时间框架协同**：策略支持在短周期（5分钟）进行回测，同时使用较长周期（1小时）生成交易信号，这种设计能够有效降低滑点影响，提高回测准确性。

## 2. 理论基础

### 2.1 趋势跟踪理论

趋势跟踪是量化交易中最经典、应用最广泛的策略类型之一。其核心假设是"趋势具有一定的持续性"，即一旦价格形成明确的上升或下降趋势，这种趋势在一段时间内大概率会继续延续。

Obelisk_3EMA_StochRSI_ATR 策略采用的是多重均线排列确认趋势的方法。当短期均线位于中期均线上方，中期均线又位于长期均线上方时，市场处于多头趋势；反之则为空头趋势。这种排列方式的优势在于：

- **滞后性可控**：通过三条不同周期的均线，在保证信号稳定性的同时，降低信号滞后程度
- **噪音过滤**：多重均线排列能够有效过滤短期价格波动带来的假突破
- **趋势强度确认**：均线之间的距离反映了趋势的强度

### 2.2 动量振荡指标原理

随机相对强弱指标（StochRSI）是将 RSI 指标再次进行随机化处理得到的振荡指标。相比普通 RSI，StochRSI 具有以下特点：

**敏感性提升**：StochRSI 对价格变化的反应更加灵敏，能够更早捕捉到趋势转折信号。这一特性使其成为寻找入场时机的理想工具。

**超买超卖区间**：StochRSI 的取值范围为 0-100，通常认为数值超过 80 为超买区，低于 20 为超卖区。当指标从超买区向下穿越信号线时，预示着可能的下跌；当指标从超卖区向上穿越信号线时，预示着可能的上涨。

**交叉信号**：StochRSI 的 K 线和 D 线交叉是重要的交易信号。K 线向上穿越 D 线称为金叉，通常被视为买入信号；K 线向下穿越 D 线称为死叉，通常被视为卖出信号。

### 2.3 波动率测度理论

平均真实波幅（ATR）由著名技术分析师 J. Welles Wilder Jr. 于 1978 年提出，是衡量市场波动性的核心指标。ATR 的计算考虑了以下三种价格范围：

- 当日最高价与最低价之差
- 当日最高价与前一日收盘价之差的绝对值
- 当日最低价与前一日收盘价之差的绝对值

取这三者中的最大值作为当日的真实波幅，再进行移动平均计算得到 ATR。

ATR 的核心价值在于：
- **市场状态识别**：ATR 数值较高时表示市场波动剧烈，可能处于趋势启动或剧烈调整阶段；ATR 数值较低时表示市场处于盘整或趋势衰竭阶段
- **动态止损设定**：基于 ATR 的止损水平能够根据市场状态自动调整，避免在波动剧烈时过早止损或在波动平缓时止损过宽
- **仓位规模计算**：ATR 可用于计算适当的仓位规模，使每笔交易的风险敞口保持一致

## 3. 技术指标详解

### 3.1 三条指数移动平均线（EMA）

策略使用三条不同周期的指数移动平均线：EMA8、EMA14 和 EMA50。

**EMA8（快速均线）**
- 周期：8 根 K 线
- 作用：捕捉短期价格动量
- 特点：对价格变化反应迅速，但容易受到噪音干扰
- 在策略中的角色：作为判断短期趋势方向的基准

**EMA14（中期均线）**
- 周期：14 根 K 线
- 作用：平滑短期波动，确认中期趋势
- 特点：平衡了敏感性和稳定性
- 在策略中的角色：连接快速均线和慢速均线的桥梁

**EMA50（慢速均线）**
- 周期：50 根 K 线
- 作用：识别主趋势方向
- 特点：反应较慢，但稳定性高
- 在策略中的角色：作为长期趋势的过滤器

**指数移动平均线的计算**

EMA 的计算公式为：

```
EMA(t) = α × Price(t) + (1 - α) × EMA(t-1)
```

其中 α = 2/(N+1)，N 为周期数。

与简单移动平均线（SMA）相比，EMA 对近期价格赋予更高的权重，因此能够更快地反映价格变化，这在趋势跟踪策略中具有重要意义。

### 3.2 随机相对强弱指标（StochRSI）

策略自定义实现了 StochRSI 指标，参数配置如下：

- **RSI 周期**：14
- **StochRSI 周期**：14
- **K 线平滑周期**：3
- **D 线平滑周期**：3

**计算步骤**

第一步：计算 RSI 值
```python
dataframe['rsi'] = ta.RSI(dataframe, timeperiod=14)
```

第二步：计算 StochRSI 原始值
```python
stochrsi = (rsi - rsi_min_14) / (rsi_max_14 - rsi_min_14)
```

第三步：计算 K 线和 D 线
```python
dataframe['srsi_k'] = stochrsi.rolling(3).mean() * 100
dataframe['srsi_d'] = srsi_k.rolling(3).mean()
```

**指标解读**

- K 值范围：0-100
- D 值范围：0-100
- 金叉信号：K 线从下方向上穿越 D 线
- 死叉信号：K 线从上方向下穿越 D 线

### 3.3 平均真实波幅（ATR）

策略使用 14 周期的 ATR 指标：

```python
dataframe['atr'] = ta.ATR(dataframe, timeperiod=14)
```

ATR 在策略中的核心作用是计算止损和止盈水平：

- **止盈目标**：入场价 + 2 × ATR
- **止损水平**：入场价 - 3 × ATR
- **止损百分比**：3 × ATR / 入场价

这种设置使得止盈目标与止损风险的比例为 2:3，约等于 0.67 的盈亏比。虽然盈亏比小于 1，但策略依赖较高的胜率来保持盈利能力。

## 4. 入场信号分析

### 4.1 入场条件

策略定义的做多入场条件包含两个必须同时满足的条件：

**条件一：EMA 多头排列**
```python
(dataframe['ema8'] > dataframe['ema14']) &
(dataframe['ema14'] > dataframe['ema50'])
```

这一条件确保市场处于明确的上升趋势中。具体含义：
- EMA8 > EMA14：短期动量向上
- EMA14 > EMA50：中期趋势向上
- 整体呈现多头排列形态

**条件二：StochRSI 金叉**
```python
qtpylib.crossed_above(dataframe['srsi_k'], dataframe['srsi_d'])
```

这一条件确认入场时机。当 K 线从下方向上穿越 D 线时，表示短期动量开始转强，是理想的入场点。

### 4.2 信号生成逻辑

入场信号的完整生成流程：

1. **指标计算**：在 do_indicators 函数中计算所有技术指标
2. **条件判断**：检查 EMA 排列和 StochRSI 交叉是否同时满足
3. **信号标记**：满足条件时将 go_long 标记为 1
4. **止损止盈设定**：在信号触发时记录止损和止盈价格
5. **入场执行**：在 populate_entry_trend 中检测 go_long 从 0 变为 1，设置 buy 信号

```python
dataframe.loc[
    (dataframe['ema8'] > dataframe['ema14']) &
    (dataframe['ema14'] > dataframe['ema50']) &
    qtpylib.crossed_above(dataframe['srsi_k'], dataframe['srsi_d'])
,
'go_long'] = 1
```

### 4.3 信号过滤机制

策略通过多重验证机制过滤假信号：

- **趋势过滤**：EMA 排列确保只在主趋势方向交易
- **动量确认**：StochRSI 交叉确认短期动量转向
- **共振效应**：两个条件必须同时满足，单一条件不足以触发信号

这种设计理念是"宁可错过，不可做错"，在趋势交易中保守等待高概率机会。

## 5. 出场机制设计

### 5.1 固定止盈止损

策略采用基于 ATR 的动态止盈止损机制：

**止盈设置**
```python
dataframe['take_profit'] = dataframe['close'] + dataframe['atr'] * 2
```

入场后，止盈目标设定为入场价格加上 2 倍 ATR。这一距离反映了市场平均波动水平的两倍，具有统计意义上的合理性。

**止损设置**
```python
dataframe['stop_loss'] = dataframe['close'] - dataframe['atr'] * 3
dataframe['stop_pct'] = (dataframe['atr'] * 3) / dataframe['close']
```

入场后，止损水平设定为入场价格减去 3 倍 ATR。止损距离比止盈距离更远，体现了策略对胜率的重视胜过盈亏比。

### 5.2 自定义止损函数

策略实现了 custom_stoploss 函数，用于实时监控止盈止损条件：

```python
def custom_stoploss(self, pair: str, trade: 'Trade', current_time: datetime,
                    current_rate: float, current_profit: float, **kwargs) -> float:
```

**功能逻辑**

1. **数据检索**：从 custom_info 字典中获取该交易对的历史数据
2. **入场时间匹配**：定位入场时的 K 线数据
3. **止盈检查**：如果当前价格超过止盈目标，返回极小值（0.001）触发平仓
4. **追踪止损**：否则返回基于入场价计算的止损比例

**追踪止损机制**

```python

```

该函数将止损比例转换为相对于当前价格的止损价格，实现固定止损距离的追踪效果。无论价格如何波动，止损始终保持在入场价下方 3 倍 ATR 的位置。

### 5.3 出场信号

策略的 populate_exit_trend 函数不设置主动出场信号：

```python

```

所有出场都通过止损止盈机制触发，不使用技术指标信号出场。

## 6. 风险管理框架

### 6.1 止损机制分析

策略的止损机制包含以下特点：

**动态调整性**
- 止损距离基于 ATR 计算，能够根据市场波动性自动调整
- 高波动时期止损距离更宽，避免被正常波动扫损
- 低波动时期止损距离更窄，控制风险敞口

**固定比例性**
- 止损距离始终为 3 倍 ATR，不会因价格变动而改变
- 入场时确定的止损水平将持续有效，直至交易结束

**追踪性**
- 止损水平不会随价格上涨而上移
- 这与传统的追踪止损不同，策略采用的是固定入场止损

### 6.2 止盈机制分析

止盈机制的运作方式：

**目标设定**
- 入场时即设定止盈目标为入场价 + 2 × ATR
- 目标价格固定不变，不会因价格波动而调整

**执行方式**
- 当价格达到止盈目标时，custom_stoploss 函数返回极小值
- 这将触发 Freqtrade 的止损平仓逻辑，实际执行止盈卖出

### 6.3 风险敞口计算

假设 ATR 约为价格的 2%，则：

- 止损距离 = 3 × 2% = 6%
- 止盈距离 = 2 × 2% = 4%
- 盈亏比 = 4% / 6% = 0.67

这意味着策略需要约 60% 的胜率才能实现盈亏平衡：

```
期望收益 = 胜率 × 盈利 - (1 - 胜率) × 亏损
0 = 0.60 × 4% - 0.40 × 6%
0 = 2.4% - 2.4%
```

因此，策略的盈利能力高度依赖于能否维持较高的胜率。

### 6.4 最大回撤控制

策略设置了 10% 的固定止损上限：

```python
stoploss = -0.10
```

这意味着任何单笔交易的最大亏损不会超过入场资金的 10%。结合 ATR 止损，实际执行中会取两者中的较小值。

## 7. 时间框架策略

### 7.1 双时间框架设计

策略采用独特的双时间框架设计：

**回测时间框架：5 分钟**
```python
timeframe = '5m'
```

**信号生成时间框架：1 小时**
```python
informative_timeframe = '1h'
```

这种设计的优势在于：

**提高回测准确性**
- 在短周期进行回测能够更精确地模拟价格走势
- 避免长周期回测中止损止盈价格被"穿越"的问题
- 更准确地计算滑点和交易成本

**保持信号稳定性**
- 使用 1 小时周期生成信号，降低噪音干扰
- 避免短周期频繁交易带来的过度拟合风险

### 7.2 时间框架转换机制

策略通过 informative_pairs 和 merge_informative_pair 实现时间框架转换：

```python
def informative_pairs(self):
    pairs = self.dp.current_whitelist()
    informative_pairs = [(pair, self.informative_timeframe) for pair in pairs]
    return informative_pairs
```

```python
dataframe = merge_informative_pair(dataframe, informative, self.timeframe, 
                                    self.informative_timeframe, ffill=True)
```

**工作流程**

1. 获取当前交易对白名单
2. 为每个交易对声明需要加载的 1 小时数据
3. 在 populate_indicators 中获取 1 小时数据
4. 在 1 小时数据上计算所有指标
5. 将 1 小时指标合并到 5 分钟数据框
6. 在 5 分钟数据框上生成交易信号

### 7.3 运行模式配置

策略支持两种运行模式：

**回测/超参优化模式**
- 使用 5 分钟或 1 分钟时间框架
- 启用断言检查确保时间框架正确
- 允许精确计算止损止盈触发

**实盘/模拟模式**
- 使用 1 小时时间框架
- 直接在当前时间框架计算指标
- 无需时间框架转换

## 9. 回测优化指南

### 9.1 回测配置要点

**时间框架选择**

根据开发者建议，回测应使用 5 分钟或 1 分钟时间框架：

```python
if self.config['runmode'].value in ('backtest', 'hyperopt'):
    assert (timeframe_to_minutes(self.timeframe) <= 5), 
           "Backtest this strategy in 5m or 1m timeframe."
```

**历史数据要求**

- 最少需要 500 根 5 分钟 K 线数据
- 建议使用至少 6 个月的历史数据
- 包含牛市、熊市、震荡市等多种市场状态

**交易对选择**

策略设计为仅做多策略，适用于：
- 主流加密货币（BTC、ETH 等）
- 具有明显趋势特性的交易对
- 流动性充足、滑点较低的标的

### 9.2 超参数优化建议

**可优化参数**
- EMA 周期组合（如 8-14-50 可优化为 7-21-55）
- StochRSI 参数（周期、平滑值）
- ATR 止盈止损倍数
- 固定止损百分比

**优化目标**
- 夏普比率：评估风险调整后收益
- 最大回撤：控制在可接受范围内
- 胜率：目标保持在 60% 以上
- 总收益：综合考虑收益和稳定性

**优化注意事项**
- 避免过度拟合：使用样本外数据验证
- 参数稳定性：选择在多段数据中表现稳定的参数
- 过拟合检测：检查参数附近的表现是否剧烈变化

### 9.3 回测陷阱规避

**前视偏差**

策略通过以下方式避免前视偏差：
- 使用 fillna(method='ffill') 正确填充未来数据
- 止损止盈只在入场时设定，不随时间调整
- 交叉信号使用 qtpylib.crossed_above 确保方向性

**幸存者偏差**

- 使用包含已退市项目的历史数据
- 避免仅选择表现良好的交易对

**滑点模拟**

- 回测时设置合理的滑点参数（建议 0.5%-1%）
- 考虑不同市场状态下的流动性差异

## 10. 实盘注意事项

### 10.1 策略局限性

**趋势依赖性**

策略在明确趋势市场中表现良好，但在以下情况可能表现不佳：
- 震荡盘整市场
- 频繁反转的市场
- 低波动性市场

**滞后性**

EMA 指标本质上是滞后指标，在以下情况可能出现问题：
- 趋势反转时入场延迟
- 快速行情中错过最佳入场点
- 假突破导致错误信号

**单向交易**

策略仅支持做多，不支持做空：
- 熊市期间需要停止交易
- 无法从下跌行情中获利
- 需要额外的市场状态过滤

### 10.2 实盘改进建议

**增加过滤条件**
- 添加 RSI 超买超卖过滤
- 增加成交量确认条件
- 加入市场状态识别

**优化止损机制**
- 实现真正的追踪止损
- 添加时间止损（持仓时间过长自动平仓）
- 考虑波动率自适应止损

**增加做空逻辑**
- 将策略扩展为双向策略
- 在 EMA 空头排列时寻找做空机会
- 增加反转信号识别

### 10.3 风险警告

**开发者声明**

策略代码中明确标注：
```
# DO NOT RUN LIVE
# correctness/accuracy not guaranteed
```

这一警告表明：
- 策略未经充分实盘验证
- 存在潜在的未知风险
- 不建议直接用于实盘资金

**使用建议**

1. **充分回测**：在多个市场周期中进行回测验证
2. **模拟交易**：在模拟环境中运行至少 3 个月
3. **小额测试**：使用小额资金进行实盘验证
4. **持续监控**：监控策略表现，及时发现异常
5. **风险控制**：设置总体资金止损，防止单策略造成重大损失

## 11. 总结与展望

### 11.1 策略评价

Obelisk_3EMA_StochRSI_ATR 策略是一款结构清晰、逻辑完整的趋势跟踪策略。其主要优点包括：

**优点**

1. **多重验证机制**：EMA 趋势判断与 StochRSI 动量确认相结合，有效过滤假信号
2. **动态风险管理**：基于 ATR 的止损止盈能够适应不同市场环境

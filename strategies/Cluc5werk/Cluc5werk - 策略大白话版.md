## 一、这策略是个啥？

**Cluc5werk** 是 Cluc 系列的**第 5 代进化版**，玩的是 **1 分钟超短线**，但加了几个狠活：

> "先看大方向（1小时趋势向上），再找小机会（布林带信号），最后还要**双重确认**才出手"

说得再直白点：

1. 先确认大趋势——用 **1 小时 ROCR 指标**判断市场是否在涨
2. 再找买入点——用 **布林带** 找价格跌到"地板"的位置
3. **双重确认**——必须连续两根 K 线都满足条件才买
4. 快进快出——价格触及布林中轨或三连跌就跑

这策略就像一个**极度谨慎的短线捕手**：大方向对了才看机会，机会来了还要确认两遍，最后才小心翼翼出手。它的性格是——**稳如老狗，胜率 90%+**。

## 三、买入条件：我帮你分好类了

这策略有 **2 种买入模式**，但必须满足一个**硬门槛**：

### 3.1 硬门槛：1 小时 ROCR 过滤

```
1 小时 ROCR > 0.8973
```

**大白话**：
> "先看大趋势，过去 7 天价格涨了至少 89.73%（ROCR 计算方式），确认是上升趋势才考虑买入。"

这是策略的**第一道防线**——大方向不对，绝不出手！

---

### 3.2 模式一：布林带反弹（捕捉假突破后的反弹）

这个模式专门捕捉**价格跌破布林下轨后快速反弹**的机会。

**需要同时满足 6 个条件**：

| 条件 | 公式 | 大白话 |
|------|------|--------|
| 1 | 布林下轨有效 | 数据正常，不是 NaN |
| 2 | bbdelta > close × 1.85% | 布林带够宽，有操作空间 |
| 3 | 价格变化 > close × 0.17% | 这根 K 线波动明显 |
| 4 | 下影线 < bbdelta × 78.8% | 下影线不长，说明跌不下去 |
| 5 | 收盘价 < 前一根布林下轨 | 价格跌破下轨，"便宜"了 |
| 6 | 收盘价 ≤ 前一根收盘价 | 价格没涨回去，还在低位 |

**一句话总结**：
> "价格突然跌穿布林下轨，但下影线很短，说明是假跌破，可能马上反弹！"

---

### 3.3 模式二：EMA 缩量回调（捕捉恐慌底）

这个模式专门捕捉**价格急跌后成交量萎缩**的机会。

**需要同时满足 3 个条件**：

| 条件 | 公式 | 大白话 |
|------|------|--------|
| 1 | close < EMA50 | 价格在长期均线下方，偏弱 |
| 2 | close < 布林下轨 × 0.93% | 价格跌到极低位置 |
| 3 | 成交量 < 30 日均量 × 35 | 成交量萎缩（地量） |

**一句话总结**：
> "价格跌到非常低的位置，而且成交量枯竭，说明没人愿意卖了，底部可能到了！"

---

### 3.4 双重确认机制（关键！）

这是 Cluc5werk 和其他 Cluc 版本最大的区别：

```python
# 先标记"假买"信号
fake_buy = (模式一 OR 模式二)

# 正式买入：必须连续两根 K 线都满足 fake_buy
buy = (fake_buy[前一根] == 1) AND (fake_buy[当前] == 1)
```

**大白话翻译**：
> "即使信号出现了，策略也不急着买。它会等一根 K 线（1 分钟），看看下一个 K 线是否还满足条件。**连续两次确认才买入**，这就是为什么胜率能到 90%！"

## 五、卖出逻辑：不贪心，见好就收

### 5.1 主要卖出条件

卖出需要**同时满足 4 个条件**：

| 条件 | 公式 | 大白话 |
|------|------|--------|
| 1 | high ≤ 前一根 high | 高点下降或持平 |
| 2 | 前一根 high ≤ 再前一根 high | 连续三根高点下降 |
| 3 | close ≤ 前一根 close | 收盘价走弱 |
| 4 | close × 97% > 布林中轨 | 价格触及布林中轨附近 |

**一句话总结**：
> "连续三根 K 线高点下降，说明涨不动了，同时价格接近布林中轨压力位，赶紧跑！"

### 5.2 卖出条件优先级

```
ROI 止盈 > 信号卖出 > 硬止损
```

这意味着：
- 价格快速涨到 ROI 目标 → 按 ROI 退出
- 出现卖出信号 → 按信号卖出
- 都不满足且亏损达 22.4% → 触发止损

### 5.3 盈利才主动卖

```python
exit_profit_only = True
```

**大白话**：
> "只有赚钱的时候才主动卖出，亏钱就等止损或反弹。"

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

Cluc5werk 的历史回测表现**极其优异**——90% 胜率、509% 收益。但这有个陷阱：

> **因为参数众多（6 个买入参数 + 1 个卖出参数），策略很容易"拟合"过去行情的最优解，但这并不代表未来一定能盈利。**

简单说就是：**像学生背答案考高分，换个考场（市场环境变化）就不灵了。**

### 复杂策略的隐藏风险

实盘时，复杂的逻辑可能导致：

| 风险 | 说明 |
|------|------|
| **过拟合** | 参数精确匹配历史数据，但未来不一定有效 |
| **未来函数偏差** | 某些指标可能包含未来信息，回测失真 |
| **市场变化** | 市场结构变化时，优化参数可能失效 |
| **双重确认延迟** | 等两根 K 线确认可能错过最佳入场点 |

### 宽止损的隐患

22.4% 的止损非常宽松，这意味着：

- 单笔亏损可能很大
- 连续 5 次止损 = 亏损 70%+（算术计算）
- 需要更大的盈利才能回本

**心理准备**：
> 你可能在大部分交易中盈利，但一次大亏损可能吃掉多笔利润。

### 实盘注意事项

| 注意事项 | 说明 |
|---------|------|
| 充分回测 | 在不同市场周期进行回测验证 |
| 模拟盘先行 | 实盘前先跑模拟盘至少一周 |
| 小额起步 | 先用小资金测试，验证实盘效果 |
| 关注胜率 | 胜率低于 80% 应警惕 |
| 关注平均利润 | 持续低于 1% 应检查市场环境 |
| 不要改参数 | 参数经过优化，不要随意调整 |

### 风险警示清单

## 一、策略概览

**ema** 是一个极简的 EMA 差值交叉策略，通过两组 EMA 差值的加权组合生成趋势信号，再对其应用 SMA 平滑作为信号线，形成"指标之指标"的双重交叉系统。策略代码仅 60 行，是学习 EMA 交叉策略的经典入门模板。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 1 个条件：EMA 差值金叉 |
| **卖出条件** | 1 个条件：EMA 差值死叉 |
| **保护机制** | 追踪止损 + 硬止损 |
| **时间框架** | 5 分钟 |
| **依赖库** | TA-Lib, qtpylib |
| **特殊功能** | 双重 EMA 差值 + SMA 信号线 |

## 三、买入条件详解

### 3.1 EMA 差值计算

策略的核心创新在于将两组 EMA 差值进行加权组合：

```python
# EMA 计算（注意：参数名称与实际周期有差异）
ema6 = ta.EMA(dataframe, 9)    # 实际周期 9
ema24 = ta.EMA(dataframe, 18)  # 实际周期 18
ema11 = ta.EMA(dataframe, 32)  # 实际周期 32
ema25 = ta.EMA(dataframe, 64)  # 实际周期 64

# EMA 差值加权组合
ema = (ema6 - ema24) * 0.6 + (ema11 - ema25) * 0.5
```

**差值组合解析**：
- **短期差值**：EMA(9) - EMA(18)，权重 0.6，捕捉短期趋势变化
- **中期差值**：EMA(32) - EMA(64)，权重 0.5，确认中期趋势方向
- **加权组合**：短期权重更高，对快速变化更敏感

### 3.2 信号线构建

```python
# EMA 差值的平滑信号线
ema2 = ta.SMA(ema, 29)
```

**信号线设计**：
- 对 EMA 差值应用 29 周期 SMA 平滑
- 形成"指标之指标"的双重结构
- SMA 比 EMA 更平滑，减少假信号

### 3.3 买入条件

```python
# 买入条件：EMA 差值金叉
qtpylib.crossed_above(ema, ema2)
```

**逻辑解析**：
- **金叉信号**：EMA 差值上穿 SMA 信号线
- **趋势确认**：差值为正且上穿，表示短期动能增强
- **双重验证**：两组 EMA 差值的加权组合已内置趋势确认

### 3.4 买入条件分类

| 条件类型 | 核心逻辑 | 技术含义 |
|---------|---------|---------|
| **趋势反转** | EMA 差值金叉 | 短期动能由弱转强 |

## 四、卖出逻辑详解

### 4.1 技术卖出信号

```python
# 卖出条件：EMA 差值死叉
qtpylib.crossed_below(ema, ema2)
```

**逻辑解析**：
- **死叉信号**：EMA 差值下穿 SMA 信号线
- **趋势反转**：差值由正转负，短期动能减弱
- **对称设计**：买入用金叉，卖出用死叉，逻辑一致

### 4.2 多层退出机制

策略采用多层退出机制：

| 退出类型 | 触发条件 | 信号名称 |
|---------|---------|---------|
| **ROI 退出** | 利润达到阈值 | minimal_roi |
| **追踪止损** | 利润回撤超过 1% | trailing_stop |
| **技术卖出** | EMA 差值死叉 | sell_signal |
| **硬止损** | 亏损达到 10% | stoploss |

### 4.3 卖出信号总结

```
优先级（从高到低）：
1. 硬止损（-10%）：保命线
2. 追踪止损（利润回撤 1%）：锁定盈利
3. ROI 退出（10%→5%→2%）：分级止盈
4. 技术卖出（死叉）：趋势反转
```

## 六、风险管理特色

### 6.1 追踪止损机制

```python
trailing_stop = True
trailing_stop_positive = 0.01          # 1% 追踪启动
trailing_stop_positive_offset = 0.02   # 2% 偏移触发
```

**工作机制**：
1. 利润达到 2% 后启动追踪止损
2. 从最高点回撤 1% 时触发退出
3. 让盈利奔跑，避免过早止盈

**追踪止损示意图**：
```
利润率
  ↑
10% ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─┐
  │                        │
 5% ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─┤ ← ROI 退出点
  │                        │
 2% ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─┤ ← 追踪止损启动点
  │                        │
 1% ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─┤ ← 追踪止损触发点
  │                        │
 0% ──────────────────────┼─ → 时间
```

### 6.2 分级 ROI 设计

```python
minimal_roi = {
    "0": 0.10,    # 立即：10%
    "30": 0.05,   # 30 分钟：5%
    "60": 0.02,   # 60 分钟：2%
}
```

**设计哲学**：
- **短期目标高**：刚买入时期望捕捉大趋势
- **长期目标低**：持仓时间越长，接受越低的利润退出
- **避免套牢**：长时间持仓后主动降低门槛退出

### 6.3 风险参数总结

| 参数 | 设置值 | 风险控制作用 |
|------|--------|-------------|
| 硬止损 | -10% | 最大单笔亏损 |
| 追踪止损启动 | 2% | 利润保护起点 |
| 追踪止损幅度 | 1% | 利润回撤容忍度 |
| ROI 1 (0min) | 10% | 快速止盈目标 |
| ROI 2 (30min) | 5% | 中期止盈目标 |
| ROI 3 (60min) | 2% | 长期止盈底线 |

## 七、策略优势与局限

### ✅ 优势

1. **逻辑极简**：仅 EMA 差值交叉，代码仅 60 行，易于理解和维护
2. **计算量小**：指标少，对硬件要求低，512MB 内存即可运行
3. **追踪止损**：锁定利润，让盈利奔跑
4. **学习价值高**：是学习 EMA 交叉策略的经典入门案例
5. **双重验证**：两组 EMA 差值加权，减少假信号
6. **信号线平滑**：SMA 信号线进一步过滤噪声

### ⚠️ 局限

1. **无趋势过滤**：没有 EMA200 等长期趋势判断，震荡市易亏损
2. **无 BTC 关联**：不检测比特币大盘趋势，系统性风险时无保护
3. **震荡市假信号**：EMA 交叉在震荡市中假信号多，可能连续亏损
4. **参数固定**：EMA 周期固定，无法适应不同币种特性
5. **无成交量确认**：不参考成交量，可能错过量价背离信号
6. **单一时间框架**：仅 5 分钟，无多时间框架确认

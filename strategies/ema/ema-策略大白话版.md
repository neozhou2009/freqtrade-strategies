## 三、买入条件：就 1 个条件

### 🎯 EMA 差值金叉

**核心逻辑**：
1. 计算 (EMA6-EMA24) 和 (EMA11-EMA25) 的加权组合
2. 计算该组合的 29 周期 SMA 作为信号线
3. 金叉时买入

**大白话**：
> "EMA 差值都上穿信号线了（金叉），趋势来了，上车！"

**代码翻译**：
```python
# EMA 差值计算（注意参数名和实际周期有差异）
ema6 = EMA(9周期)    # 实际周期 9
ema24 = EMA(18周期)  # 实际周期 18
ema11 = EMA(32周期)  # 实际周期 32
ema25 = EMA(64周期)  # 实际周期 64

# EMA 差值加权组合
ema = (ema6 - ema24) * 0.6 + (ema11 - ema25) * 0.5

# 信号线
ema2 = SMA(ema, 29周期)

# 金叉买入
当 ema 上穿 ema2 时买入
```

**吐槽**：
- 参数命名有点乱，变量名叫 ema6 实际用 9 周期 😅
- 但核心逻辑很简单：短期 EMA 差值上穿信号线就买！

## 十一、彩蛋：策略作者的"小心思"

仔细看代码，你会发现一些有趣的东西：

1. **参数命名"坑"**：
   ```python
   ema6 = ta.EMA(dataframe, 9)    # 变量叫 ema6，实际用 9 周期
   ema24 = ta.EMA(dataframe, 18)  # 变量叫 ema24，实际用 18 周期
   ema11 = ta.EMA(dataframe, 32)  # 变量叫 ema11，实际用 32 周期
   ema25 = ta.EMA(dataframe, 64)  # 变量叫 ema25，实际用 64 周期
   ```
   > "变量名和实际周期完全不一致，可能是有意为之或者历史遗留问题！"

2. **差值加权设计**：
   ```python
   ema = (ema6 - ema24) * 0.6 + (ema11 - ema25) * 0.5
   ```
   > "短期差值权重 0.6，中期差值权重 0.5，短期更重要！"

3. **信号线用 SMA**：
   ```python
   ema2 = ta.SMA(ema, 29)
   ```
   > "为什么用 SMA 不用 EMA？SMA 更平滑，减少假信号！"

4. **ROI 分级设计**：
   ```python
   minimal_roi = {"0": 0.10, "30": 0.05, "60": 0.02}
   ```
   > "刚买入期望 10% 大趋势，持仓越久越降低期望！"

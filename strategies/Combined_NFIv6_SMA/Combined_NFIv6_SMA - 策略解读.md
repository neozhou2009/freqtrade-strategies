## 一、策略概览

**Combined_NFIv6_SMA** 是由 Freqtrade 社区知名开发者 **iterativ** 创作的 NostalgiaForInfinityV6 系列策略的变体，融合了 NFI（Nostalgia For Infinity）系列策略的核心设计理念与 SMA（简单移动平均线）趋势过滤机制。该策略通过多层次的技术指标保护机制和多时间框架分析，构建了一套复杂但高效的买入/卖出信号体系。

从策略架构来看，Combined_NFIv6_SMA 采用了"保护层 + 核心信号"的双层过滤机制。每一组买入条件都配备了 EMA 均线保护、SMA200 趋势保护、以及针对"跌入"（dip）和"泵送"（pump）的特殊保护机制。这种设计大幅降低了在极端市场条件下触发虚假信号的概率。

策略的时间框架设计体现了"长短结合"的思路：主时间框架 5 分钟用于捕捉短期交易机会，而 1 小时时间框架则用于确认长期趋势方向。这种跨时间框架的分析方法使得策略能够在不同的市场环境下保持较好的适应性。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 24 个独立买入信号，可独立启用/禁用 |
| **卖出条件** | 8 个基础卖出信号 + 多层动态止盈逻辑 + 追踪止损 |
| **保护机制** | 8 组买入保护参数（EMA、SMA200、Dip、Pump 等） |
| **时间框架** | 5 分钟主时间框架 + 1 小时信息时间框架 |
| **依赖库** | TA-Lib, technical (qtpylib), numpy, pandas |

## 二、策略配置解析

### 2.1 基础风险参数

```python
# ROI 退出表（时间: 最小利润率）
minimal_roi = {
    "0": 0.10,      # 持仓立即可获得 10% 利润
    "30": 0.05,     # 30 分钟后 5% 利润
    "60": 0.02,     # 60 分钟后 2% 利润
}

# 止损设置
stoploss = -0.10   # 10% 硬止损

# 追踪止损
trailing_stop = True
trailing_only_offset_is_reached = True
trailing_stop_positive = 0.005
trailing_stop_positive_offset = 0.035
```

**设计思路**：
- ROI 表采用了递减式设计，初始 10% 止盈体现了策略对大趋势的追求
- 30 分钟时降至 5%，60 分钟后降至 2%，这种设计允许持仓更长时间来捕捉更大的趋势
- 硬止损设置为 -10%，这是相对宽松的止损幅度，给趋势足够的演化空间
- 追踪止损配置为正追踪 0.5% 启动，偏移触发点 3.5% 生效，这种"延迟启动"设计可以避免在震荡行情中被频繁触发

### 2.2 订单类型配置

```python
order_types = {
    'entry': 'limit',           # 限价单入场
    'exit': 'limit',            # 限价单出场
    'stoploss': 'limit',        # 限价单止损
    'stoploss_on_exchange': False
}
```

**配置说明**：
- 使用限价单进行交易，可以获得更好的成交价格，降低交易成本
- 禁用交易所内置止损，使用 Freqtrade 本地止损逻辑

### 2.3 退出信号配置

```python
use_exit_signal = True
exit_profit_only = True
ignore_roi_if_entry_signal = True
```

**配置说明**：
- `use_exit_signal = True` 启用退出信号
- `exit_profit_only = True` 确保只在盈利时卖出，避免割肉
- `ignore_roi_if_entry_signal = True` 允许入场信号覆盖 ROI 退出，确保不遗漏新的交易机会

## 三、买入条件详解

策略包含 24 个独立的买入条件，每个条件都有独立的启用/禁用开关和保护机制配置。

### 3.1 保护机制（8 组）

每个买入条件都支持以下保护机制的独立配置：

| 保护类型 | 参数说明 | 默认值示例 |
|---------|---------|-----------|
| **EMA 快速保护** | `buy_xx_protection__ema_fast` | True（快速 EMA 在 200 EMA 上方） |
| **EMA 慢速保护** | `buy_xx_protection__ema_slow` | True（1h EMA 在 1h 200 EMA 上方） |
| **收盘价 EMA 快速** | `buy_xx_protection__close_above_ema_fast` | 指定 EMA 周期 |
| **收盘价 EMA 慢速** | `buy_xx_protection__close_above_ema_slow` | 指定 1h EMA 周期 |
| **SMA200 上升趋势** | `buy_xx_protection__sma200_rising` | True（200 日均线上升） |
| **SMA200 1h 上升** | `buy_xx_protection__sma200_1h_rising` | True（1h 200 日均线上升） |
| **安全跌入保护** | `buy_xx_protection__safe_dips` | 启用安全跌入检测 |
| **安全泵保护** | `buy_xx_protection__safe_pump` | 启用安全泵检测 |

### 3.2 典型买入条件示例

#### 条件 #1：RSI/MFI 超卖反弹
```python
# 逻辑
- RSI < 35（超卖区域）
- MFI < 30（资金流量指标超卖）
- EMA 保护启用（趋势确认）
- SMA200 上升趋势保护
```

#### 条件 #2：RSI 相对弱势 + 布林带下轨
```python
# 逻辑
- RSI 低于 1h RSI 一定差值
- 收盘价触及布林带下轨
- 1h 时间框架趋势确认
```

#### 条件 #3：布林带 40 周期反弹
```python
# 逻辑
- BB40 下轨.shift() > 0
- BB40 带宽 > 收盘价 × 3.7%
- 收盘价 < BB40 下轨.shift()
- 成交量确认
```

#### 条件 #4：布林带 20 周期低量反弹
```python
# 逻辑
- 收盘价低于布林带 20 下轨
- 成交量萎缩（低于平均水平）
- EMA 趋势保护启用
```

| 条件组 | 条件编号 | 核心逻辑 |

## 六、风险管理特色

### 6.1 安全跌入（Safe Dips）保护

安全跌入保护旨在防止"抄底抄在半山腰"的情况，提供 3 种检测类型：

| 类型 | 检测逻辑（跌入阈值） |
|------|---------|
| **strict** | 1.5%/10%/24%/42% |
| **normal** | 2%/14%/32%/50% |
| **loose** | 2.6%/24%/42%/80% |

检测方法：比较当前收盘价与过去 N 根 K 线的最高价之差，确保不是在下跌中途入场。

### 6.2 安全泵（Safe Pump）保护

安全泵保护旨在防止"追高被套"的情况，提供 3 种检测类型和 3 种检测周期：

| 类型 | 周期 | 涨幅阈值 | 回撤阈值 |
|------|------|---------|---------|
| **strict** | 24h | 0.42 | 2.2 |
| **strict** | 36h | 0.58 | 2.0 |
| **strict** | 48h | 0.80 | 2.0 |
| **normal** | 24h | 0.60 | 1.75 |
| **normal** | 36h | 0.64 | 1.75 |
| **normal** | 48h | 0.85 | 1.75 |
| **loose** | 24h | 0.66 | 1.7 |
| **loose** | 36h | 0.70 | 1.7 |
| **loose** | 48h | 1.60 | 1.4 |

### 6.3 止损保护机制

策略配置了多层止损保护：

```python
# 硬止损
stoploss = -0.10  # 10% 最大亏损

trailing_stop_positive = 0.005      # 0.5% 追踪启动
```

## 七、策略优势与局限

### ✅ 优势

1. **多层保护机制**：8 种不同的保护机制大幅降低了假信号概率，包括 EMA 保护、SMA200 趋势保护、Safe Dips 和 Safe Pump 等
2. **双时间框架分析**：结合 5 分钟和 1 小时时间框架，兼顾短期交易机会和长期趋势方向
3. **精细化止盈**：12 级动态止盈机制让利润最大化，根据利润水平动态调整卖出条件
4. **高度可配置**：24 个买入条件和 8 个卖出条件均可独立配置，适应不同市场环境
5. **趋势跟踪能力**：通过多重 EMA 和 SMA 确认，有效捕捉趋势性行情

### ⚠️ 局限

1. **复杂度较高**：大量参数需要合理配置，对新手不友好，学习曲线陡峭
2. **交易频率**：在牛市时可能产生较多交易，需注意手续费和滑点影响
3. **参数过拟合风险**：大量参数可能导致过拟合历史数据，实盘表现可能不如回测
4. **计算资源需求**：双时间框架 + 多指标计算，对硬件有一定要求
5. **震荡市表现**：在横盘震荡行情中，保护机制可能频繁触发，交易效率降低

## 九、适用市场环境详解

Combined_NFIv6_SMA 是 NostalgiaForInfinity 系列的第 6 代变体，继承了"对冲无限"策略的核心设计理念。基于其代码架构和社区长期实盘验证的经验，它最适合 **中长期趋势明显的市场**，而在 **高波动率的极端行情** 时需谨慎使用。

### 9.1 策略核心逻辑

- **多条件共振**：24 个买入条件提供了多样化的入场信号，单一条件触发即可入场
- **趋势过滤**：通过 SMA200 和 EMA 进行趋势确认，避免逆势交易
- **逆向保护**：Safe Dips 和 Safe Pump 防止抄底抄在半山腰和追高被套
- **动态止盈**：根据利润水平动态调整卖出条件，让利润奔跑

## 十、重要提醒：复杂性的代价

### 10.1 学习成本

Combined_NFIv6_SMA 是一个高度复杂的策略，24 个买入条件和 8 个卖出条件意味着需要投入大量时间理解每个条件的作用。建议新手从默认参数开始，逐步了解和调整，不要急于修改所有参数。

### 10.2 硬件要求

| 交易对数量 | 最低内存 | 推荐内存 |
|-----------|---------|---------|
| 40-60 对 | 2GB | 4GB |
| 80-100 对 | 4GB | 8GB |
| 100+ 对 | 8GB | 16GB |

**注意**：双时间框架分析会增加计算负担，建议使用 SSD 硬盘以提高数据读取速度。

### 10.3 回测与实盘的差异

- 历史回测往往表现优异，但实盘需要考虑滑点、网络延迟、交易所限制等因素
- 复杂策略在回测中容易出现过拟合，即"背答案"现象
- 建议先在模拟交易中充分测试（至少 1-2 个月），再逐步投入实盘
- 实盘初期建议使用较小仓位，验证策略表现后再逐步增加

### 10.4 手动交易者建议

对于手动交易者，理解策略的核心逻辑后可以作为技术分析的参考框架：
- 关注 EMA 和 SMA 的趋势确认信号
- 使用布林带下轨反弹作为入场参考
- 结合 RSI 和 MFI 的超卖区域判断
- 采用分批止盈策略，而非一次性清仓

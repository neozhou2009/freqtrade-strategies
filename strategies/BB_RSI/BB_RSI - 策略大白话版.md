# BB_RSI 策略：布林带 + RSI 的经典组合

> **外号**：震荡市"捡漏王"  
> **职业**：专找价格偏离均值的机会  
> **时间框架**：1 小时

---

## 一、这策略是个啥？

简单说，**BB_RSI** 就是一个：
- 专吃布林带下轨附近的便宜货
- 用 RSI 过滤掉太极端的情况
- 等价格回归正常再卖掉赚钱

就像在超市打折区捡便宜，但不会去买那些快过期的（太极端的），只买值得抄底的 🛒

---

## 二、核心配置：说白了就是"快进快出，见好就收"

### 止盈规则（ROI 表）

```
刚买入      → 赚 40% 就跑
5.6 小时后  → 赚 18.8% 就跑
9.4 小时后  → 赚 7.3% 就跑
18.3 小时后 → 保本就跑
```

**翻译**：这策略就是急性子！买了就想赶紧赚，时间越久要求越低。你要是憋了快 20 小时还不赚，保本也给你卖了 🏃

### 止损规则

```
固定止损：-6.5%（亏这么多就砍）
追踪止损：赚了 1% 后启动，回撤 2.4% 就跑
```

**翻译**：止损挺紧的，6.5% 就认输。但是一旦开始赚钱，它会帮你"看钱包"——赚了 1% 后开始盯盘，回撤 2.4% 就锁定利润走人。

## 三、1 个买入条件：简单粗暴

这策略的买入逻辑超级简单，就一个条件：

### 🎯 唯一买入条件

**核心逻辑**：价格跌破布林带下轨 + RSI 别太低

```python
买入条件：
1. 收盘价 < 布林带下轨（价格便宜了）
2. RSI > 7（还没绝望到谷底）
```

**大白话**：
> "价格跌破布林带下轨了，看起来便宜了。但 RSI 还没跌破 7，说明还没跌到'血流成河'的地步。这时候进去抄个底，等价格回归正常就能赚钱。"

**为什么不买 RSI < 7 的？**
> RSI 低于 7 说明跌得太惨了，这时候进去就是接飞刀，风险太大！

**图解买入位置**：

```
        ═══════════════ 布林带上轨
              ↑
              │ 卖出区域
              ↓
        ─────────────── 布林带中轨
        
        ─────────────── 布林带下轨
              ↑
              │ ★ 买入区域
              │ （价格低于下轨，RSI > 7）
              ↓
```

## 四、保护机制：2 层"保命符"

策略配了双层保护，就像买了保险还绑了安全带：

| 保护类型 | 参数 | 大白话 |
|---------|------|--------|
| 固定止损 | -6.5% | "亏到 6.5% 就认栽，砍了！" |
| 追踪止损 | 启用 | "赚钱后帮你看盘，锁定利润" |

**吐槽**：止损设置得挺紧的，6.5% 说砍就砍，可能有点容易被震荡洗出去 🤔

## 五、卖出逻辑：等价格冲上天

### 5.1 唯一卖出信号

```python
卖出条件：
1. 收盘价 > 布林带上轨（价格冲出去了）
2. RSI > 74（超买了）
```

**大白话**：
> "价格突破布林带上轨，而且 RSI 都超过 74 了，说明涨得差不多了。赶紧卖掉落袋为安！"

### 5.2 多层退出保护

除了信号卖出，还有三道防线：

| 退出方式 | 触发条件 | 大白话 |
|---------|---------|--------|
| ROI 退出 | 到达利润目标 | "时间到了，赚够了就跑" |
| 追踪止损 | 回撤触发 | "赚的钱快没了，赶紧跑" |
| 固定止损 | 亏损 6.5% | "止损触发，认栽走人" |

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **逻辑简单**：就一个买条件、一个卖条件，代码短到你想哭 😂
2. **经典组合**：布林带 + RSI 是老股民都知道的套路，靠谱
3. **止损明确**：6.5% 固定止损 + 追踪止损，风险控制清晰
4. **参数标准**：布林带 20 周期 1 标准差，教科书级设置
5. **时间合理**：1 小时周期，不太长也不太短

### ⚠️ 缺点（吐槽环节）

1. **条件太少**：就一个买入条件，错过一堆机会 🥲
2. **没趋势判断**：不问方向就进场，可能逆势抄底被埋
3. **止损有点紧**：6.5% 止损，可能被正常波动洗出去
4. **ROI 参数奇怪**：40%、18.8%、7.3%……这数字明显是优化出来的，可能过拟合
5. **RSI 过滤有争议**：RSI > 7 才买，可能错过极端超卖的大反弹

## 九、这策略在什么市场能赚钱？

### 9.1 核心逻辑：均值回归

BB_RSI 是典型的**均值回归**策略。它的赚钱哲学：

> "价格不会一直偏离均值，跌多了会反弹，涨多了会回调。我就抄这个底，吃这个反弹。"

- **布林带**：画出价格的"正常范围"
- **RSI**：判断价格是不是跌得太离谱了
- **组合使用**：在价格偏离正常但没"崩盘"的时候进场

### 9.2 不同市场表现（说人话版）

| 市场类型 | 表现评级 | 大白话解释 |

## 十一、彩蛋：策略作者的"小心思"

仔细看代码，你会发现一些有趣的东西：

1. **典型价格**：布林带用的是 `(High + Low + Close) / 3`，不是普通 Close
   > "我在乎的是这一整根 K 线的平均价格，不只是收盘价。"

2. **RSI 过滤很宽松**：只要求 RSI > 7，意思是只要不极端超卖就行
   > "我要的是便宜货，但不是垃圾货。"

3. **ROI 表数字奇怪**：40%、18.8%、7.3%……这不是拍脑袋，是优化出来的
   > "我跑了无数遍回测，就为了找到这几个神奇的数字。"

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

BB_RSI 的历史回测表现可能**不错**——但这有个陷阱：

> **因为 ROI 表参数是优化出来的，很可能"拟合"了过去行情的最优解，但这并不代表未来一定能盈利。**

简单说就是：**背答案考满分，换套题就懵了。**

### 简单策略的隐藏风险

实盘时，简单策略可能导致：
- **错过机会**：条件太少，很多好机会没信号
- **假信号**：没有趋势过滤，逆势抄底被埋
- **止损频繁**：6.5% 止损可能被正常波动触发
- **滑点吃利润**：限价单可能成交不了

### 我的建议（真心话）

```
1. 把这个策略当学习材料，别当圣杯
2. 加个趋势过滤器（比如均线方向）
3. 放宽止损到 8-10%
4. 小仓位测试，观察 1-2 个月
```

**记住**：策略再简单，市场也不简单。轻仓测试，活着最重要！🙏

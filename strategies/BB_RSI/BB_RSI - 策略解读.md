## 一、策略概览

BB_RSI 是一个结合布林带与相对强弱指数（RSI）的经典技术分析策略。该策略利用布林带识别价格偏离，结合 RSI 判断超卖状态，在价格触及布林带下轨且 RSI 未极端超卖时入场，待价格反弹至布林带上轨附近退出。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 1 个独立买入信号（布林带下轨 + RSI 过滤） |
| **卖出条件** | 1 个基础卖出信号（布林带上轨 + RSI 过滤） |
| **保护机制** | 固定止损 + 追踪止损 |
| **时间框架** | 1 小时 |
| **依赖库** | talib, qtpylib |

## 三、买入条件详解

### 3.1 单一买入条件

策略采用简洁的单条件买入逻辑：

```python
dataframe.loc[
    (
        (dataframe['close'] < dataframe['bb_lowerband'])  # 收盘价低于布林带下轨
        &
        (dataframe['rsi'] > 7)  # RSI 大于 7
    ),
    'buy'] = 1
```

**逻辑拆解**：

| 条件 | 含义 | 设计意图 |
|------|------|----------|
| `close < bb_lowerband` | 价格跌破布林带下轨 | 捕捉超卖机会 |
| `rsi > 7` | RSI 未进入极端超卖 | 避免在极端下跌中抄底 |

**参数说明**：

- **布林带参数**：20 周期，1 标准差
- **RSI 参数**：默认 14 周期

### 3.2 买入逻辑图解

```
价格位置示意：

        bb_upperband ← 上轨
        ─────────────────
        
        bb_middleband ← 中轨
        
        ─────────────────
        bb_lowerband ← 下轨
        ↓
    ★   买入区间（close < 下轨 且 RSI > 7）
```

## 四、卖出逻辑详解

### 4.1 单一卖出信号

```python
dataframe.loc[
    (
        (dataframe['close'] > dataframe['bb_upperband'])  # 收盘价高于布林带上轨
        &
        (dataframe['rsi'] > 74)  # RSI 大于 74
    ),
    'sell'] = 1
```

**逻辑拆解**：

| 条件 | 含义 | 设计意图 |
|------|------|----------|
| `close > bb_upperband` | 价格突破布林带上轨 | 捕捉超买状态 |
| `rsi > 74` | RSI 显示超买 | 确认卖出时机 |

### 4.2 多层退出机制

策略采用三层退出保护：

```
退出优先级：ROI → 追踪止损 → 固定止损 → 信号卖出

1. ROI 退出：根据持仓时间递减利润目标
2. 追踪止损：盈利 1.036% 后启动，回撤 2.409% 触发
3. 固定止损：亏损超过 6.491% 强制退出
4. 信号卖出：价格突破上轨且 RSI > 74
```

## 六、风险管理特色

### 6.1 紧密止损设置

策略采用约 6.5% 的固定止损，这是一个相对紧密的风险控制：

| 风控类型 | 参数 | 说明 |
|---------|------|------|
| 固定止损 | -6.491% | 单笔最大亏损限制 |
| 追踪止损 | 启用 | 保护浮动利润 |
| 追踪启动点 | +1.036% | 盈利达到此值启动追踪 |
| 追踪触发点 | +2.409% | 回撤至此值触发止损 |

### 6.2 ROI 时间递减

| 持仓时间 | 目标收益率 |
|---------|-----------|
| 0 分钟 | 40% |
| 335 分钟（~5.6 小时） | 18.83% |
| 564 分钟（~9.4 小时） | 7.35% |
| 1097 分钟（~18.3 小时） | 0%（保本） |

**设计意图**：鼓励持仓初期快速获利，随时间推移降低收益预期，避免长期套牢。

### 6.3 订单执行保护

- **限价买入**：确保以预期价格成交，避免滑点
- **限价卖出**：控制卖出价格，避免市价大幅偏离
- **市价止损**：紧急情况下优先成交速度

## 七、策略优势与局限

### ✅ 优势

1. **逻辑简洁**：仅 1 个买入条件、1 个卖出条件，易于理解和维护
2. **经典组合**：布林带 + RSI 是经过验证的技术分析组合
3. **风险可控**：约 6.5% 固定止损 + 追踪止损双重保护
4. **参数合理**：使用标准布林带参数（20 周期，1 标准差）
5. **时间框架适中**：1 小时周期过滤短期噪音，减少假信号

### ⚠️ 局限

1. **条件单一**：买入信号较少，可能错过其他机会
2. **极端行情风险**：RSI 过滤条件 `> 7` 可能错过极端超卖反弹
3. **无趋势过滤**：未判断大趋势方向，可能在逆势中入场
4. **止损较紧**：6.5% 止损可能被正常波动触发
5. **依赖参数优化**：ROI 表参数经过精确优化，可能存在过拟合风险

## 九、适用市场环境详解

BB_RSI 是一个典型的**均值回归**策略。基于其代码架构和布林带 + RSI 组合的经典特性，它最适合 **震荡市场**，而在 **强趋势市场** 时表现不佳。

### 9.1 策略核心逻辑

- **均值回归**：利用布林带识别价格偏离均值程度
- **超卖确认**：RSI 过滤极端情况，避免在"刀尖上接飞刀"
- **通道交易**：低买高卖，价格回归通道时获利

### 9.2 不同市场环境表现

| 市场类型 | 表现评级 | 原因分析 |
| :--- | :--- | :--- |
| 📈 慢牛市场 | ⭐⭐⭐☆☆ | 可能过早卖出，错过后续涨幅 |
| 🔄 震荡市场 | ⭐⭐⭐⭐⭐ | 最佳适用场景，价格在通道内波动 |
| 📉 急跌市场 | ⭐⭐☆☆☆ | 虽有买入信号但风险极高 |
| ⚡️ 单边趋势 | ⭐☆☆☆☆ | 缺乏趋势判断，逆势操作风险大 |

### 9.3 关键配置建议

| 配置项 | 建议值 | 说明 |
|--------|--------|------|

| 交易对 | 波动适中 | 避免极端波动品种 |

- 回测结果打 5-7 折评估

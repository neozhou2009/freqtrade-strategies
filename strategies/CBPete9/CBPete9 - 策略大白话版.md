## 一、这策略是个啥？

简单说，**CBPete9** 就是一个：

- 专门在价格跌惨了的时候买入（抄底专业户）
- 稍微赚一点就跑（不贪心的类型）
- 用10个不同的条件来决定要不要买（选择困难症晚期）

就像一个**"超市抢打折"**的老手：看到价格跌多了就进场"抄底"，稍微反弹一点（赚个2-3%）立刻走人，把钱拿出来等下一个"打折"机会。

**核心目标**：不是"赚大钱"，而是**"尽量少亏钱"**。作者明确说了：让回撤尽可能低。

## 二、核心配置：说白了就是"快进快出"

### 止盈规则（ROI 表）

| 持仓时间 | 最低盈利要求 | 大白话 |
|----------|--------------|--------|
| 刚买入 | 2.8% | 运气好直接赚2.8%就跑 |
| 10分钟后 | 1.8% | 等了10分钟，1.8%也行 |
| 40分钟后 | 0.5% | 拖了40分钟，0.5%也跑 |

**翻译**：时间拖得越久，要求的利润越低。本质上是鼓励"快进快出"，别恋战！

### 止损规则

```
官方止损：-99%（基本等于没有）
追踪止损：开启（利润达到1.87%后启动）
智能止损：持仓50分钟后检查，如果还在亏就看看要不要跑
```

**翻译**：官方止损基本没用，靠的是自己的一套"智能止损"机制。就像你妈说"随便你"，但其实早就给你安排好了一切。

### 其他配置

| 配置项 | 值 | 大白话 |
|--------|-----|--------|
| 交易周期 | 5分钟 | 看5分钟K线做决定 |
| 参考周期 | 1小时 | 用1小时K线判断大势 |
| 同时持仓数 | 建议2-4个 | 别把鸡蛋放一个篮子 |

## 三、10个买入条件：我帮你分类好了

这策略的买入条件多得离谱，**10个独立条件**，满足任意一个就买。我给你归了4类：

### 🎯 第1类：趋势确认型（条件1、2、5）

**核心逻辑**：趋势向上 + 短期超卖 = 抄底机会

**大白话**：
> "大势是好的，只是暂时跌多了，这时候买就是抄底。"

**代表条件**：

**条件#1**：双周期EMA + 布林下轨
- 5分钟价格 > 200日均线（短期趋势向上）
- 1小时价格 > 200日均线（长期趋势也向上）
- 价格跌破布林带下轨（打折了！）
- 成交量萎缩（洗盘结束）

**条件#2**：单周期EMA + 更深超卖
- 和条件1类似，但只要5分钟趋势OK就行
- 价格要比布林下轨还低2%（更深的折扣！）

**条件#5**：MACD金叉 + 趋势确认
- 双周期趋势向上
- MACD金叉（动量开始转向）
- 价格超卖

---

### 📉 第2类：RSI超卖型（条件3、4、8、9）

**核心逻辑**：RSI太低了 = 超卖 = 可能反弹

**大白话**：
> "技术指标都跌到姥姥家了，该反弹了吧？"

**代表条件**：

**条件#3**：1小时趋势保护 + RSI极端超卖
- 1小时趋势向上
- RSI < 14.2（极度超卖，正常范围是30-70）

**条件#4**：只看1小时RSI
- 1小时RSI < 16.5（1小时级别超卖）
- 别的不看，就这么简单粗暴

**条件#8**：双RSI超卖
- 1小时RSI < 20
- 5分钟RSI < 28
- 两个周期一起超卖，共振信号

**条件#9**：1小时温和超卖 + 5分钟极端超卖
- 1小时RSI < 35（还好）
- 5分钟RSI < 10（极度超卖！）

---

### 🔀 第3类：MACD动量型（条件6、7）

**核心逻辑**：MACD金叉 + 超卖 = 动量反转

**大白话**：
> "动量开始转向了，正好价格还便宜，买！"

**代表条件**：

**条件#6**：MACD强势信号
- MACD金叉，差值够大（动量强）
- 价格超卖

**条件#7**：1小时RSI + MACD组合
- 1小时RSI < 15（超卖）

- 双周期配合

---

### 🧩 第4类：综合大礼包型（条件10）

**核心逻辑**：把能用的指标都用上

**大白话**：
> "什么指标都看看，确保万无一失。"

**条件#10**：综合反转信号

## 四、保护机制：智能止损（策略的"保险丝"）

这个策略最核心的保护是**自定义止损**，分为两种情况：

### 情况1：赚钱了怎么办？

- 启动追踪止损
- 利润达到1.87%后开启追踪
- 利润回落到0.3%就卖出

**大白话**：赚了钱就保护起来，别让到手的利润跑了。

### 情况2：持仓超过50分钟还在亏钱？

- 检查现在价格比50分钟前的开盘价低多少
- 如果低1.5%以上 → **立刻止损！**

**大白话**：亏了50分钟还在跌？别扛了，割肉走人，别死扛！

### 追踪止损配置

| 参数 | 值 | 大白话 |
|------|-----|--------|
| trailing_stop_positive | 0.003 | 利润回撤到0.3%就触发 |
| trailing_stop_positive_offset | 0.0187 | 利润达到1.87%后开启追踪 |

## 五、卖出逻辑：比买入简单多了

卖出条件超级简单：

> **价格突破布林带中轨的1.01倍（+1%）就卖出！**

是的，就这么直接。

**策略的理念**：**不要贪，见好就收**。价格稍微反弹就立刻走人，把钱拿出来等下一个机会。

### 卖出配置

| 配置项 | 值 | 大白话 |
|--------|-----|--------|
| use_exit_signal | False | 不用退出信号 |
| exit_profit_only | True | 只在盈利时卖 |
| exit_profit_offset | 0.001 | 最小盈利门槛0.1% |

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **非常谨慎**：10个买入条件，充分验证才下手
2. **纪律性强**：到了止损点立刻走，不犹豫
3. **不贪心**：赚1%就跑，见好就收
4. **勤奋**：随时监控多个时间周期的信号
5. **智能止损**：50分钟还在亏就检查要不要跑

### ⚠️ 缺点（吐槽环节）

1. **条件太多**：10个买入条件，一般人搞不懂
2. **过于复杂**：条件多到自己都记不住
3. **容易过拟合**：这么多参数，可能只是"背答案"
4. **手续费高**：频繁交易，手续费吃利润
5. **胜率要求高**：每次赚得少，必须保证胜率

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

CBPete9 的历史回测表现往往**极其优异**——但这有个陷阱：

> **因为参数众多，策略很容易"拟合"过去行情的最优解，但这并不代表未来一定能盈利。**

简单说就是：**历史成绩好，不代表考试能过。**

### 复杂策略的隐藏风险

实盘时，复杂的逻辑可能导致：

- **过拟合风险**：10个条件很可能是对历史数据的"完美匹配"，未来市场不一定吃这一套
- **信号稀少**：条件太多，可能很久才触发一次买入
- **手续费吃利润**：每次只赚1-3%，手续费占比很高
- **胜率要求高**：每次赚得少，必须保证胜率在50%以上才能盈利
- **市场环境依赖**：只在震荡市表现好，其他时候可能歇菜

### 我的建议（真心话）

```
1. 必须先模拟测试（dry_run），跑至少2-4周
2. 小资金开始实盘，确认稳定再加仓
3. 选择主流币（BTC、ETH），流动性好
4. 关注止损触发频率，频繁触发就暂停
5. 别自己乱调参数，原作者说预设参数就能用
```

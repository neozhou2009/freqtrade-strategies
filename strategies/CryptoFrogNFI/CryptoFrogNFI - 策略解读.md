## 一、策略概览

**CryptoFrogNFI** 是 CryptoFrog 系列的 NFI（Not Financial Advice）版本，是一个基于布林带、RSI、RSX、MACD、EMA、SMA、Heikin-Ashi 等多种经典技术指标构建的超多条件量化交易策略。

该策略继承了 CryptoFrog 系列的核心设计理念，通过多重指标交叉验证来提高信号可靠性，同时引入了高级自定义止损（Custom Stoploss）和动态 ROI 机制来优化风险收益比。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 24 个独立买入信号，各自包含复杂的条件组合，可独立启用/禁用 |
| **卖出条件** | 8 个基础卖出信号 + 多层动态止盈逻辑 |
| **保护机制** | 隐式保护（通过 EMA 趋势、SMA 趋势等条件实现） |
| **时间框架** | 5 分钟主时间框架 + 1 小时信息时间框架 |
| **依赖库** | TA-Lib, finta (technical), cachetools, numpy, pandas |

## 二、策略配置解析

### 2.1 基础风险参数

```python
# ROI 退出表（时间: 最小利润率）
minimal_roi = {

    "188": 0,      # 188 分钟后：0%（退出 ROI 表，由其他机制接管）
}

# 止损设置
stoploss = -0.299  # 使用自定义止损 decay-start 值

# 追踪止损
trailing_stop = True
```

**设计思路**：
- 极高的初始 ROI（19.1%）表明策略追求高确定性信号的快速获利了结
- 多层 ROI 表设计让利润在不同时间窗口内逐步释放
- 硬止损设置为 -29.9%，实际通过自定义止损机制动态管理

## 三、买入条件详解

### 3.1 24 个买入条件总览

策略实现了 24 个独立的买入条件，每个条件都可以通过 `buy_condition_X_enable` 参数独立启用或禁用。这种设计允许交易者通过超参数优化（Hyperopt）找到最优的条件组合。

| 条件组 | 条件编号 | 核心逻辑 |
|-------|---------|---------|
| 趋势确认型 | #1-#4 | 基于 EMA 交叉、趋势确认 |
| 动量型 | #5-#8 | 基于 RSI、RSX、MACD 动量 |
| 布林带型 | #9-#12 | 基于布林带突破、回归 |
| 成交量型 | #13-#16 | 基于 MFI、VFI 成交量确认 |
| 混合型 | #17-#24 | 多指标组合确认 |

### 3.2 典型买入条件示例

#### 条件 #1：EMA 趋势交叉买入
```python
# 逻辑
- EMA_9 上穿 EMA_21
- 当前价格高于 SMA_50
- RSI < 70（不过度超买）
```

#### 条件 #5：RSI 反弹买入
```python
# 逻辑
- RSI 从超卖区域（<30）回升
- 收盘价高于前一交易日开盘价
- 成交量放大确认
```

#### 条件 #9：布林带下轨反弹
```python
# 逻辑
- 价格触及布林带下轨
- Keltner Channel 下轨支撑
- 收盘价收于下轨上方
```

## 四、卖出逻辑详解

### 4.1 多层止盈系统

策略采用基于 ROI 表的动态止盈机制：

```
利润率区间    阈值      说明
──────────────────────────────
[0, 35)       19.1%    立即退出，极高确定性信号
[35, 77)      2.5%     中期持有利润保护
[77, 188)     1.2%     后期微利保护
[188, ∞)      0%       由动态 ROI 机制接管
```

### 4.2 自定义止损（Custom Stoploss）机制

策略实现了复杂的自定义止损逻辑：

1. **线性衰减止损**：止损线随时间从 -8.5% 移动到 -2%
2. **利润保护**：当利润回升时，自动调整止损到盈亏平衡点附近
3. **趋势暂停**：RMI 处于多头趋势时，暂停止损衰减
4. **正向追踪**：盈利超过 0.5% 后启动追踪止损，距离现价 1.5%

### 4.3 特殊卖出场景

| 场景 | 触发条件 | 信号名称 |
|------|---------|---------|
| ROC 急跌 | ROC < -1.6% | cstp_bail_roc |
| 时间止损 | 持有 > 901 分钟 | cstp_bail_time |
| 动态 ROI 回撤 | 趋势结束+回撤 | trend_roi |

## 七、策略优势与局限

### ✅ 优势

1. **高度可调**：24 个独立买入条件，可针对不同市场优化
2. **智能止损**：自定义止损机制优于固定止损
3. **趋势追踪**：动态 ROI + 追踪止损组合最大化趋势利润
4. **多时间框架**：1 小时信息层提供更高维度确认

### ⚠️ 局限

1. **复杂度高**：超多条件组合，学习曲线陡峭
2. **过拟合风险**：大量参数容易过拟合历史数据
3. **计算资源**：需要大量计算资源进行超参数优化
4. **实盘差异**：复杂逻辑可能导致回测与实盘表现差异

## 十、重要提醒：复杂性的代价

CryptoFrogNFI 是最复杂的策略之一，需要深入理解：
- 各种技术指标的原理和组合效果
- 自定义止损的衰减机制

| 交易对数量 | 最低内存 | 推荐内存 |
|-----------|---------|---------|

### 10.3 回测与实盘的差异

- 复杂止损逻辑在实盘中可能因为滑点产生差异
- 多条件组合的胜率可能在实盘中下降
- 建议使用较长的时间范围进行回测

### 10.4 手动交易者建议

不建议手动交易者使用此策略，复杂度过高，难以复制。

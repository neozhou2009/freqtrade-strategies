## 二、核心配置：说白了就是"稳扎稳打"

### 止盈规则（ROI 表）

```
立即出场（0-35分钟）    → 赚 19.1% 就跑！
35-77分钟              → 赚 2.5% 就跑！
77-188分钟             → 赚 1.2% 就跑！
188分钟后              → 交给动态 ROI 机制
```

**翻译**：这策略鸡贼得很！一上来就要赚大钱（19.1%），等越久要求越低，就像相亲时随着时间推移降低标准 😅

### 止损规则

```
硬止损：-29.9%（基本不用）
自定义止损：-8.5% 起跳，动态衰减到 -2%
追踪止损：赚超过 27.8% 后启动
```

**翻译**：这策略的止损比迷宫还复杂！有线性衰减、有 ROC  bailout、还有时间止损——总之就是千方百计不让你亏太多 😅

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **条件多**：24 个买入条件，总有一个适合当前行情
2. **智能止损**：比固定止损聪明，知道什么时候该抗什么时候该跑
3. **趋势追踪**：趋势来了能拿住，让利润奔跑
4. **可定制性强**：每个条件都能独立开关，想开就开想关就关

### ⚠️ 缺点（吐槽环节）

1. **太复杂**：24 个条件，8 个卖出，参数多到自己都记不住
2. **容易过拟合**：参数太多，很容易"背答案"历史数据
3. **电脑要强**：跑这个策略需要不少内存
4. **实盘可能翻车**：回测很美好，实盘很骨感 😅

CryptoFrogNFI 的历史回测表现往往**极其优异**——但这有个陷阱：

> **因为参数众多，策略很容易"拟合"过去行情的最优解，但这并不代表未来一定能盈利。**

简单说就是：**背答案的学生，考到原题才能拿高分** 📝

- **频繁止损**：24 个条件，每个都有可能被触发

- **过拟合陷阱**：优化过的参数只是"最适合历史数据"

## 1. 这是个什么策略？

简单说，这是一个加密货币自动交易策略，跑在Freqtrade这个量化交易平台上。

### 它的来历

作者叫iterativ，给策略起了个很文艺的名字——"怀旧无限"。这是第三个版本（V3），说明作者一直在优化改进。

### 它的定位

这是一个**中等频率**的策略，不是那种一天交易几十次的高频，也不是那种一周才交易一次的低频。大概就是在行情波动的时候，抓住机会买进卖出。

### 它的风格

用一句话概括：**在上涨趋势中找回调买入，涨多了就卖**。

不是那种追涨杀跌的策略，也不是那种逆势抄底的策略。它更像是"顺势而为，耐心等待"。

## 2. 策略怎么赚钱？

### 核心逻辑

想象一下，你看到一只股票一直在涨，但突然有一天跌了一点。这时候你会想：

- 长期趋势还是涨的
- 短期跌了可能是暂时调整
- 这可能是买入的好时机

这个策略就是基于这个思路。

### 具体来说

1. **确认大趋势向上**：用1小时图看，均线要排列好，趋势要是涨的
2. **等短期回调**：用5分钟图看，价格跌到布林带下轨，RSI超卖
3. **确认没出大事**：回调幅度不能太大，不能是崩盘式下跌
4. **买入**：成交量要低，说明没人在恐慌性抛售
5. **等涨起来卖**：涨到一定程度，技术指标超买，就卖出

就这么简单！当然，实际执行的时候有很多细节条件，但核心思想就是这个。

## 3. 什么时候买？

策略有10个买入条件，只要满足任意一个就买。我们一个一个来说：

### 买入条件1：经典回调买入

**大白话**：大趋势涨得好好的，突然跌了一点，这时候可以买。

**具体要求**：
- 1小时图上，均线要金叉向上
- 5分钟图上，RSI跌到36以下（超卖了）
- 成交量不能太大（说明不是恐慌性下跌）
- 最近跌得不能太狠（安全边际）

### 买入条件2：布林带下轨买入

**大白话**：价格跌破布林带下轨，像是弹簧被压到极限，可能要反弹。

**具体要求**：
- 大趋势还是涨的
- 价格跌到布林带下轨以下
- 5分钟RSI比1小时RSI低很多（短期严重超卖）
- 但收盘价还在长期均线上方（趋势支撑）

### 买入条件3：BB40突破买入

**大白话**：用更长期的布林带（40周期）找超卖机会。

**具体要求**：
- 布林带要张开（宽度够大）
- 价格跌破下轨
- 下影线不能太长（说明不是极端行情）

### 买入条件4：均线完美排列买入

**大白话**：均线排列得整整齐齐，多头形态完美，价格回调到EMA50以下。

**具体要求**：
- 所有均线从短到长排列：EMA15 > EMA50 > EMA100 > EMA200
- 1小时图上也是多头排列
- 价格跌到EMA50以下，甚至跌破布林带下轨

### 买入条件5：EMA死叉反弹买入

**大白话**：短期均线下穿长期均线，看似要跌，但跌太多了可能反弹。

**具体要求**：
- EMA26在EMA12上方（死叉状态）
- 死叉幅度够大
- 价格在布林带下轨以下

### 买入条件6：趋势回调BB买入

**大白话**：和条件5类似，但更注重长期趋势。

**具体要求**：
- 1小时SMA200要向上
- 成交量要很低
- 其他和条件5差不多

### 买入条件7：RSI超卖买入

**大白话**：在趋势支撑下，RSI跌到很低的位置。

**具体要求**：
- 长期均线支撑有效
- RSI低于41
- 成交量要低

### 买入条件8：鳄鱼指标买入

**大白话**：用鳄鱼指标判断趋势刚启动。

**具体要求**：
- 鳄鱼嘴张开（嘴唇 > 牙齿 > 下颚）
- 三条线都在向上走
- 收盘价在嘴唇之上
- RSI还要低于46（有上涨空间）

### 买入条件9：EMA回调买入

**大白话**：价格在长期均线上方，但在短期均线下方，典型的回调位置。

**具体要求**：
- 收盘价 > EMA200
- 收盘价 < EMA50
- 跌破布林带下轨

### 买入条件10：超跌反弹买入

**大白话**：1小时RSI都超卖了，可能要反弹。

**具体要求**：
- 1小时RSI低于30
- 长期趋势向上
- 价格跌破布林带下轨

## 4. 什么时候卖？

策略有8个卖出条件，加上自定义卖出逻辑。卖出比买入更简单，核心就是"涨多了就卖"。

### 卖出条件1：布林带上轨连续突破

**大白话**：价格连续6根K线都在布林带上轨之上，涨太多了。

**具体要求**：
- 当前和过去5根K线，收盘价都在上轨之上
- RSI高于79.5

### 卖出条件2：布林带上轨短期突破

**大白话**：价格连续3根K线在上轨之上，RSI更高。

**具体要求**：
- 连续3根K线在上轨之上
- RSI高于81

### 卖出条件3：单纯RSI超买

**大白话**：RSI超过82就卖。

最简单的卖出条件。

### 卖出条件4：双时间框架RSI超买

**大白话**：5分钟和1小时RSI都高了。

**具体要求**：
- 5分钟RSI > 73.4
- 1小时RSI > 79.6

### 卖出条件5：均线下方反弹卖出

**大白话**：价格本来在长期均线下方，突然反弹，RSI冲高了。

**具体要求**：
- 收盘价 < EMA200
- 但RSI很高（比1小时RSI高4.38以上）

### 卖出条件6：均线下方极端RSI

**大白话**：在长期均线下方，RSI高得离谱。

**具体要求**：
- 收盘价 < EMA200
- 收盘价 > EMA50（有反弹）
- RSI > 87.7

### 卖出条件7：1小时RSI高+EMA死叉

**大白话**：大周期超买，小周期开始转弱。

**具体要求**：
- 1小时RSI > 81.7
- EMA12下穿EMA26

### 卖出条件8：1小时布林带上轨突破

**大白话**：从大周期看也涨太多了。

**具体要求**：
- 收盘价 > 1小时布林带上轨 × 1.1

## 5. 止损怎么设？

这个策略的止损设置很有特点，**几乎是禁用了硬止损**：

```python
stoploss = -0.99  # 亏99%才止损，等于没有
```

### 为什么这样？

因为加密货币波动大，设个5%的止损可能天天被扫出局。策略选择用其他方式控制风险。

### 那靠什么保护本金？

**1. 追踪止损**

```
利润到15%后启动
跟着价格涨，保持5%距离
价格回落5%就卖
```

**2. 分层止盈**

```
赚1%，RSI<38 → 卖
赚5%，RSI<43 → 卖
赚25%，RSI<52 → 卖
赚45%，RSI<50 → 卖
```

**3. 趋势反转止盈**

```
有利润后，价格跌破EMA200 → 卖
有利润后，长期均线开始下跌 → 卖
```

**4. 利润回撤止盈**

```
利润在16%-38%，从最高点回撤15% → 卖
利润在3%-10%，从最高点回撤4.5% → 卖
```

所以虽然没有硬止损，但有很多机制在保护利润。

## 6. 用什么指标？

### 主要指标一览

| 指标 | 参数 | 用途 |
|------|------|------|
| EMA | 12, 26, 50, 100, 200 | 趋势判断、支撑压力 |
| SMA | 5, 50, 200 | 趋势判断 |
| RSI | 14 | 超买超卖 |
| 布林带 | 20, 40 | 波动性、超买超卖 |
| MFI | 14 | 资金流向 |
| 鳄鱼指标 | 5, 8, 13 | 趋势启动判断 |

### 每个指标怎么用？

**EMA/SMA（移动平均线）**
- 看趋势方向：均线向上=涨，向下=跌
- 看支撑压力：价格在均线上方=有支撑，下方=有压力
- 看排列：短期>中期>长期=多头排列，买入机会

**RSI（相对强弱指数）**
- 超卖区域（<30）：可能要反弹，买入机会
- 超买区域（>70）：可能要回调，卖出机会
- 策略主要用超卖买入、超买卖出

**布林带**
- 上轨：超买区域
- 下轨：超卖区域
- 宽度：波动性大小
- 策略主要用下轨买入、上轨卖出

**MFI（资金流量指数）**
- 结合价格和成交量
- 超卖时配合买入信号
- 验证价格突破的有效性

**鳄鱼指标**
- 三条线：嘴唇、牙齿、下颚
- 张嘴=趋势启动
- 闭嘴=震荡期
- 策略用张嘴确认趋势

## 7. 看多长时间的图？

### 双时间框架设计

**主图：5分钟**
- 所有买卖信号在5分钟图上产生
- 保持足够的交易频率
- 及时捕捉价格波动

**辅图：1小时**
- 用来确认大趋势
- 过滤假信号
- 提供更可靠的判断

### 为什么这样设计？

想象你在看一部电影：

- 5分钟图就像一个一个镜头，能看到细节变化
- 1小时图就像整部电影的主线，能看到整体走向

如果只看5分钟图，可能被短期波动迷惑，买了之后发现大趋势是跌的。

如果只看1小时图，信号太少，错过很多机会。

所以结合起来：**用1小时图确认大方向，用5分钟图找入场点**。

### 具体怎么配合？

例如买入条件1：

```
1小时EMA50 > 1小时EMA200  → 确认大趋势向上
5分钟RSI < 36             → 短期超卖，入场点
```

这样既保证顺势，又抓住了回调机会。

## 8. 风险大不大？

### 最大的风险：没有硬止损

这是新手最担心的问题：如果买了之后一直跌怎么办？

**策略的思路是**：
1. 买入条件已经很严格，要求趋势向上
2. 有回调限制，不会在崩盘时买入
3. 用追踪止损和分层止盈来管理盈利头寸

**但问题是**：
- 如果买入后趋势突然反转，确实可能亏损较大
- 加密货币市场极端行情时有发生
- 追踪止损需要先盈利才能启动

### 另一个风险：参数太多

策略有大量的可调参数，好处是可以优化，坏处是：
- 容易过拟合（在历史数据上表现好，实盘差）
- 新手不知道怎么调
- 调错了可能造成更大亏损

### 还有这个风险：复杂性

10个买入条件、8个卖出条件，加上自定义逻辑，代码近千行。

- 理解困难
- 调试困难
- 出问题不好排查

### 总体风险评级

**中等偏高风险**

适合：
- 有一定量化交易经验的人
- 愿意花时间学习和优化的人
- 能承受一定回撤的人

不适合：
- 完全新手
- 风险承受能力低的人
- 想要稳定收益的人

## 9. 适合什么币？

### 作者推荐

**适合的**：
- 稳定币计价的交易对（USDT、BUSD等）
- 主流币种（BTC、ETH、BNB等）
- 流动性好的币

**不适合的**：
- BTC计价或ETH计价的交易对
- 杠杆代币（*BULL、*BEAR、*UP、*DOWN）
- 新币、山寨币

### 为什么要用稳定币计价？

因为BTC和ETH本身价格波动大。

比如你用BTC买了一个币，这个币涨了10%，但BTC跌了10%，结果你没赚钱。

用USDT就不会有这个问题。

### 为什么要避开杠杆代币？

杠杆代币会放大涨跌，但也会衰减。

比如一个3倍做多代币：
- 第一天涨3%，代币涨9%
- 第二天跌3%，代币跌9%
- 两天加起来，标的没变，但代币亏了

这会导致技术指标失真。

### 交易对数量建议

**作者建议：20-80个交易对**

为什么不是越多越好？
- 太多会导致信号太多，资金分散
- 太少会导致信号太少，错过机会

### 同时持仓数量

**作者建议：4-6个**

不要同时持有太多，不然：
- 资金分散，每个仓位太小
- 风险分散不够
- 管理困难

## 10. 参数怎么调？

### 参数概览

策略有大量的参数，分为几类：

**条件开关参数**
- 10个买入条件的启用/禁用
- 8个卖出条件的启用/禁用

**RSI阈值参数**
- 各种超买超卖阈值
- 不同条件有不同阈值

**成交量参数**
- 成交量倍数限制
- 影响信号频率

**布林带参数**
- 偏离度参数
- 影响买卖点位置

### 新手建议

**先不要调！**

默认参数是作者经过测试的，直接用就行。

**什么时候需要调？**

1. 回测表现不好
2. 实盘亏损
3. 信号太少或太多
4. 市场环境变化

### 怎么调？

**开启超参数优化**

```python
# 把 optimize=False 改成 optimize=True
buy_rsi_1 = DecimalParameter(30.0, 40.0, default=36.64, space='buy', optimize=True, load=True)
```

**然后运行优化**

```bash
freqtrade hyperopt --hyperopt-loss SharpeHyperOptLoss --epochs 100 --spaces buy sell
```

**注意事项**：
- 不要过度优化
- 用足够长的历史数据
- 验证样本外表现

## 11. 新手能用吗？

### 先说结论：不建议新手直接用

**原因**：

1. **复杂度高**：10个买入条件、8个卖出条件，还有很多自定义逻辑，理解起来很困难

2. **风险存在**：没有硬止损，新手可能承受不了

3. **需要调参**：不同市场环境需要不同参数

4. **需要监控**：自动化不代表可以不管，需要定期检查

### 新手应该怎么做？

**第一步：学习基础**

先了解：
- 什么是移动平均线
- 什么是RSI
- 什么是布林带
- 什么是K线

**第二步：模拟交易**

用`dry_run: true`模式，不花真钱，先看策略表现。

**第三步：小资金实盘**

模拟OK了，用小资金测试，比如100U。

**第四步：逐步加仓**

实盘表现好，再慢慢加仓。

**第五步：学习优化**

有经验了，再考虑调整参数。

### 有没有更简单的策略？

有！Freqtrade有很多内置策略，比如：

- `SampleStrategy`：最基础的示例策略
- `AwesomOscillator`：单一指标策略
- `MACDStrategy`：经典MACD策略

这些策略更简单，适合新手学习。

## 12. 实盘要注意啥？

### 上线前检查

**1. 数据充足**

需要至少400根蜡烛的数据，大约33小时的5分钟数据。

但实际建议有更多历史数据，这样指标更准确。

**2. 时间框架正确**

配置文件里要设：

```json
{
    "timeframe": "5m"
}
```

**3. 不要覆盖策略参数**

配置文件里不要设置策略已有的参数，否则会冲突。

**4. 交易对设置**

```json
{
    "exchange": {
        "pair_whitelist": [
            "BTC/USDT",
            "ETH/USDT",
            "BNB/USDT"
        ]
    }
}
```

### 上线后监控

**每日检查**：
- 持仓情况
- 盈亏比例
- 最大回撤

**每周检查**：
- 交易记录分析
- 胜率变化
- 盈亏比变化

**每月检查**：
- 策略表现评估
- 是否需要调整参数
- 市场环境变化

### 常见问题处理

**问题1：信号太少**

可能原因：
- 交易对太少
- 参数太严格
- 市场震荡

解决方法：
- 增加交易对
- 放宽部分参数
- 等待趋势行情

**问题2：信号太多**

可能原因：
- 交易对太多
- 参数太宽松
- 市场波动大

解决方法：
- 减少交易对
- 收紧参数
- 调整条件开关

**问题3：亏损太多**

可能原因：
- 市场环境变化
- 趋势反转
- 参数不适用

解决方法：
- 暂停策略
- 分析亏损原因
- 调整参数或换策略

**问题4：盈利回撤**

可能原因：
- 追踪止损设置问题
- 分层止盈参数问题

解决方法：
- 调整追踪止损距离
- 调整分层止盈阈值

- 减少假信号

**✅ 灵活的风险管理**
- 追踪止损保护利润
- 分层止盈锁定收益
- 趋势反转及时离场

**✅ 参数可定制**
- 大量可调参数
- 每个条件可独立开关
- 支持超参数优化

**✅ 适合加密货币市场**
- 5分钟时间框架捕捉波动
- 布林带适应高波动性
- 成交量验证过滤假突破

### 缺点

**❌ 复杂性高**
- 代码量大，难以完全理解
- 参数太多，优化困难
- 维护成本高

**❌ 没有硬止损**
- 在极端行情下可能大亏
- 追踪止损需要先盈利
- 新手可能承受不了

**❌ 趋势依赖**
- 所有买入都要求趋势向上
- 震荡市和熊市表现可能差
- 不适合逆势交易

**❌ 时间框架固定**
- 只能用5分钟和1小时
- 不能适应所有市场周期
- 可能错过长周期机会

**❌ 过拟合风险**
- 参数多容易过度优化
- 历史表现好不代表未来好
- 需要谨慎调参

### 适合人群

**适合**：
- 有一定量化交易经验
- 愿意花时间学习和优化
- 能承受中等风险
- 熟悉加密货币市场

**不适合**：
- 完全新手
- 风险厌恶型
- 想要躺赚
- 不懂技术指标

### 最终评价

NostalgiaForInfinityV3是一个设计精良的策略，它的核心理念——"在趋势中找回调"——是经得起时间考验的。

但它的复杂性和风险控制方式需要用户有足够的经验和心理承受能力。

如果你是新手，建议先从简单策略开始，积累经验后再尝试这个策略。

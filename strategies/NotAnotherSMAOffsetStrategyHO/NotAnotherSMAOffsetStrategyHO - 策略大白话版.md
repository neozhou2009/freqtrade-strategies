## 1. 这策略是干啥的？

### 1.1 一句话概括

这是一个专门在**上涨趋势中找回调机会买入**的策略，就像在商场打折时买名牌——趋势是好的，只是暂时便宜了，赶紧入手！

### 1.2 这名字啥意思？

**NotAnotherSMAOffsetStrategyHO** 拆开来看：

- **NotAnother**：别小看我，这可不是一般的策略
- **SMA**：简单移动平均线（但实际用的是EMA指数移动平均线，名字有点误导）
- **Offset**：偏移，就是不光看价格到不到均线，还要看偏离多少
- **HO**：可能是 High Optimization（高度优化版）的意思

简单说，这是个**用均线找便宜货**的策略。

### 1.3 能赚多少钱？

这个看市场情况和参数设置。但策略设计目标是：
- 抓住趋势回调的机会
- 用追踪止损锁定利润
- 用分阶段止盈控制贪婪

### 1.4 用在什么币？

主要设计用于加密货币市场，像比特币、以太坊这些主流币。5分钟K线，适合短线和中线交易。

## 2. 核心原理——用大白话讲

### 2.1 策略的核心思想

想象一下：你在爬山，山顶是价格高点，山脚是价格低点。

这个策略就是：**等别人爬山累了休息（价格回调）时，你再上去捡便宜货**。

它不会在山顶追着买（太贵了），也不会在山脚等着抄底（可能抄在半山腰），而是选择在**半山腰休息的地方**入手。

### 2.2 "偏移"是什么鬼？

这是策略最聪明的地方！

普通均线策略：价格突破均线就买
- 问题：等突破了，价格已经涨上去了，你买贵了

偏移策略：**在均线下面一点就等着买**
- 设置偏移系数0.966，意思是价格跌到均线的96.6%时就考虑买
- 相当于打了96.6折，比突破均线便宜3.4%

打个比方：一条裤子标价100元，等打96.6折卖96.6元时才买。

### 2.3 为什么要用三个买入信号？

就像考试有选择题、判断题、填空题，不同类型的题目考查不同的知识点。

三个买入信号分别对应：
- **ewo1**：正常回调，老老实实买
- **ewo2**：深度回调，勇敢抄底
- **ewolow**：市场恐慌时，逆势而为

这样不管市场怎么走，都有对应的招数。

### 2.4 EWO指标是啥？

EWO全叫 Elliott Wave Oscillator（艾略特波浪振荡指标）。

别被名字吓到，其实就是**两条均线的差**：
- 一条短期均线（跑得快）
- 一条长期均线（跑得慢）

当短期均线在长期均线**上面**：EWO是正数，市场在涨
当短期均线在长期均线**下面**：EWO是负数，市场在跌

策略里用EWO判断：**现在是大趋势涨还是跌**

### 2.5 整体逻辑一图看懂

```
价格下跌 → RSI显示超卖 → 价格低于均线一定比例 → EWO确认趋势 → 成交量OK → 买入！

价格上涨 → 价格高于均线 → RSI显示强势 → 动能确认 → 卖出！
```

## 3. 用的啥指标？

### 3.1 指标全家福

这个策略用了很多指标，来认识一下：

| 指标名 | 作用 | 好比... |
|--------|------|---------|
| EMA | 趋势线，判断大方向 | 公路上的中心线 |
| HMA | 快速反应的趋势线 | 油门，踩了就跑 |
| SMA | 短期趋势判断 | 车速表，看跑多快 |
| RSI | 超买超卖，看市场情绪 | 温度计，看市场发烧还是感冒 |
| EWO | 趋势强度判断 | 指南针，辨别方向 |
| Volume | 成交量 | 油量，看车还有油没 |

### 3.2 RSI三个周期啥意思？

RSI是相对强弱指标，看市场是"过热"还是"过冷"。

策略用了三个RSI：
- **RSI_4**（快速）：像秒表，秒秒钟能反应
- **RSI_14**（标准）：像钟表，正常看时间
- **RSI_20**（慢速）：像日历，看长期变化

为什么要三个？就像看天气，既要看现在温度（RSI_4），也要看今天平均温度（RSI_14），还要看这周天气趋势（RSI_20）。

### 3.3 EMA和SMA有啥区别？

- **SMA（简单移动平均线）**：所有人平均对待，算术平均
- **EMA（指数移动平均线）**：最近的数据权重更大，反应更快

就好比：
- SMA：看全班平均成绩
- EMA：看最近几次考试的加权平均（最近的考试占权重更大）

策略用EMA做主要判断，因为EMA反应更快。

### 3.4 HMA是啥？

HMA是 Hull Moving Average（赫尔移动平均线）。

特点是：**又快又平滑**。

普通均线要么反应快但抖动厉害，要么平滑但反应慢。HMA两全其美。

策略用它来判断趋势反转，因为HMA反应快，能早点发现问题。

## 4. 什么时候买入？

### 4.1 买入条件总览

策略有**三把钥匙**开买入的大门，每把钥匙对应不同的市场情况：

| 钥匙名字 | 市场情况 | 大概意思 |
|----------|----------|----------|
| ewo1 | 牛市正常回调 | 上涨途中歇个脚 |
| ewo2 | 深度回调 | 跌多了，抄底 |
| ewolow | 熊市末端 | 跌透了，等反弹 |

### 4.2 第一把钥匙：ewo1（主买入信号）

**什么时候触发？**

想象你在爬山，本来一直在往上爬，突然累了歇了一下。这时候ewo1就提醒你：**现在歇着呢，等会儿还得爬，这时候买！**

**具体条件**（翻译成人话）：
1. RSI快速线<35：市场有点慌，大家都在卖
2. 价格<均线的96.6%：比均线便宜了3.4%
3. EWO>3.422：大趋势还是涨的，只是暂时跌
4. RSI<52：还没到过热，可以买
5. 有成交量：不是死盘

**胜率**：最高，因为是跟着趋势走

**风险**：中等，回调可能继续跌

### 4.3 第二把钥匙：ewo2（深度回调）

**什么时候触发？**

这次爬山不仅累了，还滑了一跤，跌得比较深。ewo2说：**跌这么多，快到底了，上！**

**具体条件**：
1. RSI快速线<35：市场慌了
2. 价格<均线的95.1%：比均线便宜了快5%
3. EWO>-4.58：跌是跌了，但没跌太惨
4. RSI<52：还没过热
5. RSI<25：非常超卖，跌过头了
6. 有成交量

**胜率**：中等，因为市场可能继续跌

**风险**：较高，抄底失败会套

### 4.4 第三把钥匙：ewolow（反转信号）

**什么时候触发？**

这次不是爬山了，是下山下到谷底。ewolow说：**都跌成这样了，跌不动了，准备反转！**

**具体条件**：
1. RSI快速线<35：市场慌
2. 价格<均线的96.6%：相对便宜
3. EWO<-8.562：跌得非常惨
4. 有成交量

**胜率**：较低，因为是在赌反转

**风险**：最高，抄底抄在半山腰会亏很惨

### 4.5 买入信号对比

| 信号 | 胜率 | 收益预期 | 风险 | 适合场景 |
|------|------|----------|------|----------|
| ewo1 | 高 | 中等 | 中等 | 牛市回调 |
| ewo2 | 中 | 较高 | 较高 | 深度回调 |
| ewolow | 低 | 最高 | 最高 | 熊市反转 |

**建议**：新手多用ewo1，高手可以用ewo2和ewolow。

## 5. 什么时候卖出？

### 5.1 卖出条件总览

策略有**两个信号**提醒你卖：

| 信号 | 意思 | 好比... |
|------|------|---------|
| 条件一 | 涨到目标位了，该卖了 | 到站下车 |
| 条件二 | 涨不动了开始跌，快跑 | 漏水了快补 |

### 5.2 条件一：涨到位了卖

**具体条件**：
1. 价格>短期均线（SMA_9）：短期趋势向上
2. 价格>卖出基准均线的100.2%：比基准高一点
3. RSI>50：市场还在强势区
4. RSI快>RSI慢：动能在向上
5. 有成交量

**大白话**：涨到预定位置了，虽然可能还能涨，但策略建议落袋为安，别贪。

### 5.3 条件二：趋势要反转，赶紧卖

**具体条件**：
1. 价格<HMA（快速均线）：跌破快速均线，趋势可能要变
2. 价格>卖出基准均线的101.4%：虽然跌破，但还在盈利区
3. RSI快>RSI慢：动能在向上（可能是假信号）

**大白话**：涨到高位了，但开始往下走了，先保住利润再说。

### 5.4 满足任一就卖

两个条件是**或**的关系，只要满足一个就卖。这样设计的好处是：
- 条件一抓住了上涨行情
- 条件二抓住了反转信号
- 不容易错过卖出机会

### 5.5 卖出的保护机制

策略还设计了**滑点保护**：

啥是滑点？就是你下单的时候价格是100，成交的时候变成了99.5，少了0.5就是滑点。

策略规定：如果滑点超过2%，就拒绝成交，最多重试3次。

这就像你去买菜，说好了10块钱一斤，结果称完说要11块，你就不买了。

## 6. 风险怎么控制？

### 6.1 止损：35%的硬底线

策略设置了35%的止损线。

什么意思？你100块买入，最多亏到65块就强制卖出。

**为什么设35%？**
- 加密货币波动大，设太低容易被震出去
- 设太高风险又大
- 35%是经过平衡的选择

**小白建议**：如果你觉得35%太狠，可以自己改成25%或30%。

### 6.2 追踪止损：跟着涨，锁利润

这是策略最聪明的风控！

**怎么工作？**
1. 买入后先不着急
2. 等价格涨了3%，追踪止损激活
3. 止损线跟着最高价涨，保持0.5%距离
4. 价格跌到止损线，自动卖

**例子**：
- 100块买入
- 涨到103块（涨3%），追踪止损激活
- 涨到110块，止损线在109.45块（差0.5%）
- 跌回109.45，自动卖出，锁定9.45%利润

**好处**：涨多少锁多少，不怕回撤。

### 6.3 分阶段止盈：贪婪控制

策略设置了四档止盈：

| 持仓时间 | 止盈目标 | 意思 |
|----------|----------|------|
| 0分钟 | 28.9% | 一买入就涨28.9%，立马卖 |
| 25分钟 | 10.5% | 拿25分钟，涨10.5%就卖 |
| 80分钟 | 3.8% | 拿80分钟，涨3.8%就卖 |
| 140分钟 | 0% | 拿了140分钟，不赚也卖 |

**设计逻辑**：
- 刚买入就大涨，赶紧跑，别贪
- 拿着时间长了，目标越来越低
- 超过140分钟还不赚钱，说明判断错了，赶紧走

### 6.4 只在盈利时卖

策略设置了 `sell_profit_only = True`，意思是：**亏钱的时候不卖！**

除非触发35%止损，否则亏损状态下的卖出信号不执行。

这就像：你买了个股票亏了10%，卖出的信号响了，但策略说"再等等，现在卖就是割肉"。

### 6.5 风控体系总结

| 措施 | 触发条件 | 效果 |
|------|----------|------|
| 固定止损 | 亏损35% | 保命底线 |
| 追踪止损 | 盈利3%后激活 | 锁定利润 |
| 分阶段ROI | 持仓时间+盈利比例 | 控制贪婪 |
| 盈利卖出 | 只在盈利>1%时卖 | 避免割肉 |
| 滑点保护 | 滑点>2%拒绝 | 控制成本 |

## 7. 参数都是啥意思？

### 7.1 买入参数

```python
buy_params = {
    "base_nb_candles_buy": 16,      # 买入均线周期
    "low_offset": 0.966,            # 主偏移系数
    "low_offset_2": 0.951,          # 备用偏移系数
    "ewo_high": 3.422,              # ewo1信号阈值
    "ewo_high_2": -4.58,            # ewo2信号阈值
    "ewo_low": -8.562,              # ewolow信号阈值
    "rsi_buy": 52                   # RSI阈值
}
```

**大白话解读**：

| 参数 | 值 | 意思 | 调整建议 |
|------|-----|------|----------|
| base_nb_candles_buy | 16 | 用16根K线的均线 | 越大越稳，越小越灵敏 |
| low_offset | 0.966 | 打96.6折买 | 越低越便宜，越低信号越少 |
| low_offset_2 | 0.951 | 打95.1折买（抄底） | 抄底专用 |
| ewo_high | 3.422 | EWO要大于这个值 | 正数表示要在涨势中 |
| ewo_high_2 | -4.58 | EWO可以负，但不能太负 | 扩大买入机会 |
| ewo_low | -8.562 | EWO负得厉害时买 | 反转信号 |
| rsi_buy | 52 | RSI不能超过52 | 越低越保守 |

### 7.2 卖出参数

```python
sell_params = {
    "base_nb_candles_sell": 10,     # 卖出均线周期
    "high_offset": 1.014,           # 主卖出偏移
    "high_offset_2": 1.002          # 备用卖出偏移
}
```

**大白话解读**：

| 参数 | 值 | 意思 |
|------|-----|------|
| base_nb_candles_sell | 10 | 用10根K线的均线（比买入快） |
| high_offset | 1.014 | 价格比均线高1.4%就考虑卖 |
| high_offset_2 | 1.002 | 价格比均线高0.2%就考虑卖 |

**为什么卖比买快？**

买入均线16根，卖出均线10根。意思是**慢买快卖**：
- 慢买：多观察，确保是真的回调
- 快卖：别贪，有利润就走

### 7.3 EWO参数

```python
fast_ewo = 50   # 快均线
slow_ewo = 200  # 慢均线
```

EWO是用50和200周期计算的，比传统的5和35周期更长。

**原因**：加密货币波动大，用长周期更稳，不容易被震出去。

### 7.4 时间框架

```python
timeframe = '5m'   # 5分钟K线
```

5分钟的意思是每根K线代表5分钟的交易数据。

**适合人群**：
- 有时间盯盘的
- 喜欢短线交易的
- 反应速度快的

**如果不想盯太紧**，可以改成15分钟或1小时，但参数需要重新优化。

## 8. 这策略有啥优缺点？

### 8.1 优点

**1. 三重买入信号，机会多**
- 牛市有ewo1
- 深度回调有ewo2
- 熊市反转有ewolow
- 不管什么行情都有招

**2. 偏移设计，入场更便宜**
- 不是追着买，是等着打折买
- 比突破均线便宜3-5%

**3. 风控全面**
- 止损、追踪止损、分阶段止盈
- 还有滑点保护
- 多重保险

**4. 适合优化**
- 很多参数可以调整
- 可以根据不同币种和市场调优

**5. 标签清晰**
- 每次买入都有标签（ewo1/ewo2/ewolow）
- 回测时能看到哪个信号最赚钱

### 8.2 缺点

**1. 止损太宽**
- 35%的止损对新手来说可能太狠
- 一次亏掉三分之一

**2. 参数太多**
- 对新手来说，不知道怎么调
- 调错了效果差很多

**3. 震荡市可能亏**
- 如果价格上下晃荡，均线没用
- 会频繁买卖，亏手续费

**4. 只做多不做空**
- 牛市赚钱，熊市只能休息
- 浪费了熊市机会

**5. 没考虑成交量变化**
- 只检查volume>0
- 没分析放量还是缩量

### 8.3 如何扬长避短？

**应对止损宽**：
- 自己调低止损，比如改成25%
- 或者降低仓位，单笔投入少一点

**应对参数多**：
- 先用默认参数跑回测
- 然后慢慢优化，一次只调一个参数

**应对震荡市**：
- 用策略自带的过滤器
- 或者手动判断，震荡市不开策略

**应对只能做多**：
- 找另一个做空策略配合
- 或者只在大趋势向上时开策略

## 9. 适合什么人用？

### 9.1 理想用户画像

**适合你，如果你**：
- 有一定量化交易基础
- 能承受中等风险
- 每天有2-4小时看盘时间
- 想做中短线交易
- 对比特币、以太坊等主流币感兴趣

**不太适合你，如果你**：
- 完全不懂量化交易
- 风险厌恶型（亏10%就睡不着）
- 没时间盯盘
- 想做长线投资
- 只玩小币种

### 9.2 新手建议

如果你是新手，建议：

1. **先模拟盘跑一个月**
   - 用虚拟资金
   - 看策略表现
   - 别急着实盘

2. **从低风险参数开始**

## 10. 新手常见问题解答

### Q1：为什么叫"NotAnother"？

**A**：这是作者的小幽默，意思是"这不是又一个普通的均线策略"。实际上这个策略确实比普通均线策略复杂和精细得多。

### Q2：35%止损会不会太高？

**A**：对于加密货币来说，35%其实不算高。比特币一天波动10%很正常，如果止损设太低，正常波动就被震出去了。

**建议**：如果你不适应，可以自己改成20-25%。

### Q3：为什么用5分钟K线？

**A**：5分钟K线是短线和中线的平衡点：
- 太短（1分钟）：噪音太多，假信号多
- 太长（1小时）：信号太少，错过机会

**建议**：新手可以从15分钟开始，等熟悉了再用5分钟。

### Q4：三个买入信号用哪个？

**A**：建议顺序：
1. 新手只用ewo1
2. 熟悉后加ewo2
3. 高手才用ewolow

### Q5：能用在股票上吗？

**A**：理论上可以，但要注意：
- 股票波动比加密货币小
- 需要调整参数
- 止损可以设小一点（比如10%）

### Q6：一天能交易几次？

**A**：看市场波动：
- 大波动时，一天可能3-5次
- 小波动时，可能一整天没信号
- 平均下来一天1-2次

### Q7：手续费怎么算？

**A**：按每次交易算：
- 买入：一次手续费
- 卖出：一次手续费
- 一买一卖：两次手续费

**假设费率0.1%，买10万**：
- 买入手续费：100元
- 卖出手续费：100元（假设还卖10万）
- 总成本：200元

**建议**：用maker订单（挂单）手续费更低。

### Q8：回测结果很好，实盘会不会差很多？

**A**：这是常见问题，原因有：
- 回测没有考虑滑点
- 回测手续费可能设太低
- 回测用历史数据，未来不一定一样

**建议**：
- 回测结果打7折看
- 先模拟盘验证
- 小资金实盘测试

## 1. 这个策略是干嘛的？

简单说，这个策略就是帮你**自动判断什么时候买入、什么时候卖出**的程序。你把它挂上去，它就会自动帮你盯盘、自动帮你交易，不用你天天盯着 K 线图发呆。

它的名字叫 NowoIchimoku1hV1，拆开来看：
- **Nowo**：可能是作者的名字或代号，没什么特殊含义
- **Ichimoku**：是日语"一目均衡表"的意思，这是一个日本发明的技术分析工具，很多人叫它"云图"
- **1h**：表示用 1 小时 K 线来做分析，也就是说每根 K 线代表 1 小时的价格变化
- **V1**：版本 1 号，说明以后可能还会有 V2、V3

所以这就是一个**用一目均衡表（云图）来做 1 小时级别交易**的策略。它的核心思想是：只在上涨趋势中买，用多个条件确认，然后有纪律地卖出。

## 2. 为什么要用这个策略？

做交易最头疼的是什么？我猜你肯定遇到过这些情况：

### 问题一：不知道什么时候买

看到价格涨了，想追，结果追在高点，刚买就跌；
看到价格跌了，想抄底，结果抄在半山腰，越抄越亏；
纠结来纠结去，最后什么都没买，眼睁睁看着涨上去。

### 问题二：不知道什么时候卖

买完之后涨了，想再等等多赚点，结果涨完又跌回来，利润没了；
买完之后跌了，想等等反弹，结果越等越跌，小亏变大亏；
好不容易回本了，赶紧卖，结果卖完又涨上去了。

### 问题三：心态容易崩

看着价格上上下下，手忙脚乱，频繁买卖；
亏了想翻本，越翻越亏；
赚了怕回撤，过早卖出，结果错过大行情。

这个策略就是帮你解决这些问题的。它用**多道防线**来确认买入机会，用**多重条件**来决定什么时候卖出，让你的交易更系统化、更有纪律。最重要的是，它是机器执行的，没有情绪干扰，不会因为害怕或贪婪而乱操作。

## 3. 策略的核心工具是什么？

这个策略主要用了三个工具，我们一个个来说：

### 3.1 一目均衡表（云图）

这是日本一个叫细田悟一的人发明的技术分析工具，它会在图表上画出一片"云"。这个云不是随便画的，而是用过去的价格算出来的。

云有五种线：

**转换线（快线）**
用过去 9 个周期的最高价和最低价算出来，反应很快，用来捕捉短期趋势。

**基准线（慢线）**
用过去 26 个周期的最高价和最低价算出来，反应慢一点，用来判断中期趋势。

**先行带 A**
把快线和慢线的平均值算出来，然后向前位移 26 个周期。听着复杂，其实就是把今天的值放到 26 小时后的位置。

**先行带 B**
用过去 52 个周期的最高价和最低价算平均值，然后向前位移 26 个周期。

**延迟线**
把当前收盘价放到 26 小时前的位置，用来确认趋势方向。

这五条线组合在一起，就会形成一片"云"。云有两种颜色：
- **绿色云**：先行带 A > 先行带 B，说明市场在上涨趋势
- **红色云**：先行带 A < 先行带 B，说明市场在下跌趋势

云的上边界和下边界就像地板和天花板：
- 价格在云上面 → 强势上涨
- 价格在云里面 → 震荡整理
- 价格在云下面 → 下跌趋势

### 3.2 布林带上轨

布林带就像一条"弹性带子"，围绕价格上下波动。

它有三条线：
- **中轨**：20 周期的移动平均线
- **上轨**：中轨 + 2.5 倍标准差
- **下轨**：中轨 - 2.5 倍标准差

这个策略用的是 Hull 移动平均线（HMA）而不是普通的移动平均线，HMA 反应更快、滞后更小。

上轨就是这条带子的上边，通常价格很难突破上轨。一旦突破，要么是大涨信号，要么是超买警告。这个策略把突破上轨作为获利了结的条件之一。

### 3.3 随机 RSI

RSI 是相对强弱指标，用来判断市场是超买还是超卖。

随机 RSI 是把 RSI 再做一次"随机化"处理，让它更敏感。它的取值范围是 0-100：
- K 值 > 80：超买，可能要回调
- K 值 < 20：超卖，可能要反弹

这个策略用随机 RSI 的 K 值来判断是不是该获利了结了。当 K 值超过 80 且盈利超过 10%，就先跑为敬。

## 4. 怎么判断该买？

策略判断买入要看**7 个条件**，全部满足才买。就像过关斩将，每一关都得过：

### 条件 1：K 线是阳线

就是这根 K 线收盘价比开盘价高，说明这个小时买方占优势，大家都在买，价格在往上走。

```
收盘价 > 开盘价 → 阳线 → 满足条件 1
```

### 条件 2：价格突破云的上边界 4% 以上

光突破还不够，还要超过 4%。为什么要超过 4%？因为很多时候价格会"假突破"，刚突破一点就掉头回去了。超过 4% 说明这个突破更有可能是真的。

```
收盘价 > 云上边界 × 1.04 → 满足条件 2
```

### 条件 3：价格在云的下边界上面

这个条件是双重保险。价格不仅要在云上边界上面，还要在云下边界上面，确保价格完全在云的上方，彻底脱离了云的区间。

```
收盘价 > 云下边界 → 满足条件 3
```

### 条件 4：云是绿色的

绿色云代表上涨趋势，红色云代表下跌趋势。这个策略**只在上涨趋势中买**，不在下跌趋势中抄底。这就是所谓的"顺势而为"。

```
先行带 A > 先行带 B → 绿色云 → 满足条件 4
```

### 条件 5：快线在慢线上面

一目均衡表里有两条线：
- **转换线（快线）**：反应快，9 周期
- **基准线（慢线）**：反应慢， 26 周期

快线在慢线上面，就像短期均线在长期均线上面，说明最近涨得比平均快，趋势在向上。

```
转换线 > 基准线 → 满足条件 5
```

### 条件 6：价格比 25 小时前的快线高

25 小时前的快线位置很重要，因为云图就是向前位移 25 周期画的。如果现在价格比那时快线高，说明趋势在延续，不是昙花一现。

```
当前收盘价 > 25 小时前的转换线 → 满足条件 6
```

### 条件 7：价格比 50 小时前的云上边界高

这是更进一步的确认，50 小时相当于两倍位移，让趋势确认更可靠。这个条件是为了避免在假突破中买入。

```
当前收盘价 > 50 小时前的云上边界 → 满足条件 7
```

### 还有个冷却机制

这个策略有个很聪明的"冷却"设计：

- 一旦买入了，就不会马上再买
- 直到云从绿变红（趋势变坏），再从红变绿（趋势恢复），才允许下一次买入

这就像给交易加了个"保险丝"，防止在震荡市里反复买入亏损。具体逻辑是：

1. 云变绿 → 允许买入
2. 触发买入 → 禁止买入
3. 云变红 → 重置状态
4. 云再变绿 → 允许买入

## 5. 买完之后怎么办？

买完后策略会自动帮你盯着，不用你操心。它会监控这几件事：

### 监控一：止损位

用你买入时的云下边界作为止损位。如果价格跌破这个位置，说明趋势可能要反转了，赶紧跑。

### 监控二：目标位

策略会根据你买入时的价格和当时的云下边界，算一个动态目标价。价格到了这个位置，就获利了结。

### 监控三：超买监控

用随机 RSI 监控市场热度。如果 K 值太高（超过 80），说明买得太猛了，可能要回调，先跑为敬。

### 监控四：布林带突破

如果价格冲破布林带上轨，说明涨得太猛了，可能要回调，可以考虑先赚点就跑。

## 6. 什么时候卖？

策略有四种出场方式，我们一个个说：

### 方式 1：随机 RSI 超买 + 盈利够多

当随机 RSI 的 K 值超过 80，而且已经盈利 10% 以上，就卖出。

为什么这样设计？因为：
- K 值超过 80，说明市场买得太猛了，可能要回调
- 盈利 10% 以上，说明这笔交易已经成功了，不必贪心
- 这时候卖，既保护了利润，又避免了回调风险

```
K 值 > 80 且 盈利 > 10% → 卖出
```

### 方式 2：突破布林带上轨 + 小有盈利

当价格冲破布林带上轨，而且盈利超过 1%，就卖出。

这是"快速获利"的思路：
- 价格冲破布林带上轨，说明涨得太猛了
- 盈利 1% 虽然不多，但积少成多
- 先赚点就跑，不等大行情

```
价格 > 布林带上轨 且 盈利 > 1% → 卖出
```

### 方式 3：达到动态目标价

策略会根据你买入时的价格和当时的云下边界，算一个目标价：

```
目标价 = 买入价 + 2 × (买入价 - 云下边界)
```

比如你 50000 买入，当时云下边界是 46000，那目标价就是：

50000 + 2 × (50000 - 46000) = 50000 + 2 × 4000 = 50000 + 8000 = 58000

为什么是 2 倍？因为从买入价到云下边界的距离是"风险距离"，目标价设置为 2 倍风险距离，就是"风险收益比 1:2"。用 4000 的风险博 8000 的收益，划算！

```
价格达到动态目标价 → 卖出
```

### 方式 4：跌破云下边界（止损）

如果价格跌破你买入时的云下边界，就止损卖出。

这是最后的防线：
- 买入时的云下边界是关键支撑位
- 跌破说明趋势可能反转
- 宁可小亏，不能大亏

```
价格 < 买入时的云下边界 → 止损卖出
```

## 7. 怎么控制风险？

### 7.1 固定止损

策略设置了 **8% 的固定止损**。不管什么情况，亏损超过 8% 就强制平仓。

这是"硬止损"，是最后的保护伞。就算其他条件都没触发，亏损到了 8% 也必须走人。

```
亏损 ≥ 8% → 强制平仓
```

### 7.2 时间递减的获利目标

策略有个很聪明的设计：

| 时间 | 目标盈利 |
|------|----------|
| 刚买时 | 10% |
| 30 分钟后 | 5% |
| 60 分钟后 | 2% |

为什么这样设计？

**刚买时目标高**：刚买的时候，希望能抓住大行情，目标是 10%。

**30 分钟后降一点**：如果 30 分钟还没涨多少，说明这笔交易可能没那么强，目标降到 5%。

**60 分钟后再降**：如果 1 小时还没怎么涨，说明趋势可能已经弱了，不如见好就收，目标降到 2%。

这就是"时间衰减"：持仓时间越长，获利预期越低。避免"等了半天不涨，最后还亏回去"的情况。

### 7.3 多重出场条件

四种出场条件就像四道门，哪道门先开就走哪道：

| 出场条件 | 触发情况 | 适合场景 |
|----------|----------|----------|
| 随机 RSI 超买 | K 值 > 80 且盈利 > 10% | 快速大涨 |
| 布林带突破 | 价格突破上轨且盈利 > 1% | 短期冲高 |
| 动态目标 | 达到 2 倍风险距离 | 正常盈利 |
| 止损位 | 跌破云下边界 | 趋势反转 |

### 7.4 冷却期防止过度交易

买入后，必须等云从绿变红再变绿才能再买。这个冷却期能有效防止：
- 在震荡市中反复买入止损
- 追涨杀跌
- 交易过于频繁导致手续费侵蚀利润

## 8. 这个策略有什么优点？

### 优点 1：条件严格，假信号少

要 7 个条件全满足才买，这不是"随便买"，而是"层层把关"。

就像招聘一样：
- 条件少 → 简历多，但质量差
- 条件多 → 简历少，但质量好

这个策略用的是"条件多"的思路，宁可错过，不可做错。

### 优点 2：顺势而为，不逆势操作

只买绿云（上涨趋势），不买红云（下跌趋势），这就是顺势交易。

俗话说"趋势是朋友"，这个策略就是跟着朋友走，不跟趋势作对。

### 优点 3：有冷却机制，不会频繁交易

云变绿才允许买，买完后必须等云变红再变绿才能再买。这避免了：
- 震荡市中反复止损
- 情绪化频繁交易
- 手续费过多

### 优点 4：出场条件多样，灵活应对

四种出场条件，适应不同情况：
- 快涨 → 超买出场
- 冲高 → 布林带出场
- 正常涨 → 目标价出场
- 跌 → 止损出场

不管怎么走，都有应对方案。

### 优点 5：时间框架适中，不用盯盘

用 1 小时 K 线，不用像 5 分钟那样盯着看，也不用像日线那样等好几天。

特别适合：
- 上班族
- 业余交易者
- 有其他事情要忙的人

### 优点 6：风险控制到位

有固定止损（8%）、动态止损（云下边界）、时间衰减目标，三层保护。

不管发生什么，都不会让你一笔交易亏到怀疑人生。

## 9. 这个策略有什么缺点？

### 缺点 1：代码有 bug

这个策略的代码有问题，文件开头就写着"This version of the strategy is broken!"（这个版本是坏的）。

主要问题：
- **运算符错误**：用了 `&`（位运算符）而不是 `and`（逻辑运算符），导致条件判断错误
- **数组索引错误**：有些地方写错了索引方式
- **自定义止损没实现**：自定义止损函数直接返回 1，等于没止损

**所以在修好 bug 之前，千万别用！**

### 缺点 2：只能做多，不能做空

这个策略只能在上涨时买，不能在下跌时卖空。

如果遇到大熊市，就只能：
- 空仓等待
- 或者眼睁睁看着下跌

不能像做空策略那样在下跌时也能赚钱。

### 缺点 3：参数是死的，不会自己调整

所有参数都是写死的：
- 云位移：25 周期
- RSI 周期：14
- 布林带：20 周期，2.5 倍标准差

这些参数不会根据市场变化自动调整。在不同的市场环境下，可能需要不同的参数，但这个策略做不到。

### 缺点 4：可能错过机会

因为条件太严格（7 个条件全满足），可能会错过一些好机会。

就像找对象，标准太高，合适的反而少。宁可错过，不可做错，是优点也是缺点。

### 缺点 5：在震荡市会亏钱

横盘震荡时，云会来回变色：
- 绿了 → 买入
- 红了 → 止损
- 绿了 → 再买入
- 红了 → 再止损

反复止损，亏手续费。虽然冷却机制能缓解这个问题，但在剧烈震荡时仍然可能亏损。

### 缺点 6：滞后性问题

策略用了多个位移操作：
- 25 周期位移云图
- 50 周期双倍位移确认

这些位移会导致信号滞后。等你确认可以买的时候，可能已经涨了一段了。

## 10. 用这个策略要注意什么？

### 注意事项 1：先修 bug

别直接用，代码有问题！要先把这些问题修好：

**修复运算符错误**：
```python
# 错误写法
if last_candle['srsi_k'] > 80 & current_profit > 1.1:

# 正确写法
if last_candle['srsi_k'] > 80 and current_profit > 0.1:
```

**修复数组索引**：
```python
# 错误写法
df[i, 'buy_allowed'] = True

# 正确写法
df.loc[i, 'buy_allowed'] = True
```

**实现自定义止损**：
```python
def custom_stoploss(self, pair, trade, current_time, current_rate, current_profit, **kwargs):
    if current_profit > 0.05:  # 盈利 5% 后启用跟踪止损
        return current_profit - 0.03  # 保护 2% 利润
    return self.stoploss  # 否则用固定止损
```

### 注意事项 2：一定要回测

修好代码后，用历史数据测一测：
- 过去一年表现怎么样？
- 最大回撤多少？（亏最多的那次）
- 胜率多高？
- 盈亏比合理吗？
- 夏普比率多少？

如果回测结果不好，别用。

### 注意事项 3：先用模拟盘

别上来就用真钱，先用模拟盘跑一个月看看实际效果：
- 信号是不是按预期触发？
- 执行有没有问题？
- 回测和模拟的差距大不大？

### 注意事项 4：注意手续费

加密货币交易手续费不低，通常是：
- 买入：0.1%
- 卖出：0.1%
- 合计：0.2%

如果一笔交易只赚 1%，扣除手续费后只剩 0.8%，可能还不够塞牙缝。

所以策略要有足够的利润空间来覆盖手续费。

### 注意事项 5：监控云端运行

如果用云服务器运行策略，要确保：
- 服务器稳定，不经常宕机
- 网络通畅，不经常断网
- API 连接正常，不经常掉线

## 12. 实际操作会怎样？

让我们模拟一次完整交易，看看策略实际是怎么工作的：

### 场景设定

- 币种：BTC/USDT
- 时间框架：1 小时
- 当前时间：北京时间下午 2 点
- 当前价格：50000 USDT

### 买入信号出现

策略检测到：

1. ✅ 这根 1 小时 K 线是阳线（收盘价 50200 > 开盘价 49800）
2. ✅ 价格比云上边界高 5%（云上边界 47600，50200 > 47600 × 1.04 = 49500）
3. ✅ 价格在云下边界上面（云下边界 46000，50200 > 46000）
4. ✅ 云是绿色的（先行带 A 48000 > 先行带 B 45000）
5. ✅ 快线在慢线上面（转换线 48500 > 基准线 47000）
6. ✅ 价格比 25 小时前快线高（25 小时前快线 47800，50200 > 47800）
7. ✅ 价格比 50 小时前云上边界高（50 小时前云上边界 49000，50200 > 49000）
8. ✅ 冷却状态允许买入（云刚从红变绿）

**全部满足！策略自动买入，成交价 50000 USDT，买入 0.1 BTC。**

### 持仓期间 - 第 1 小时

买入后 30 分钟，价格涨到 51000（盈利 2%）。

这时候策略检查：
- 随机 RSI K 值：65（没到 80）❌
- 布林带上轨：51500（没突破）❌
- 动态目标：50000 + 2 × (50000 - 46000) = 58000（没到）❌
- 云下边界：46000（价格远在上面）❌
- 时间衰减目标：前 30 分钟，目标 10%（现在才 2%）❌

**继续持仓。**

### 持仓期间 - 第 2 小时

买入后 1 小时，价格涨到 53000（盈利 6%）。

策略检查：
- 随机 RSI K 值：72（没到 80）❌
- 布林带上轨：52000（突破了！但盈利才 6%，不满足 > 1% 的条件吗？不对，6% > 1%）✅

等等，让我再看看条件...布林带突破条件是"价格 > 布林带上轨 且 盈利 > 1%"。

现在价格 53000 > 布林带上轨 52000，盈利 6% > 1%。

**条件 2 触发！策略卖出，理由："current rate above upper band with profit above 1%"**

这笔交易赚了 6%，扣除手续费（假设 0.1% × 2 = 0.2%），净赚约 5.8%。

买入价 50000，卖出价 53000，毛利 3000 USDT，手续费约 103 USDT（买入 50 USDT + 卖出 53 USDT），净利润约 2897 USDT。

### 另一种场景 - 触发止损

假设买入后价格跌了：

买入后 1 小时，价格跌到 45500（亏损 9%）。

策略检查：
- 云下边界：46000（价格 45500 < 46000）✅

**条件 4 触发！策略止损卖出，理由："current rate below stop"**

亏损 9%，超过 8% 的固定止损，说明这个止损没来得及触发。这暴露了一个问题：动态止损（云下边界）和固定止损（8%）可能存在冲突。

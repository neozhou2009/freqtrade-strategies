## 一、策略概览

SMA_BBRSI 是一个融合了简单移动平均线（SMA）偏移、Elliott Wave Oscillator（EWO）、RSI布林带以及防泵机制的复合型量化交易策略。该策略通过多重技术指标的组合验证，在捕捉趋势反转机会的同时，利用多层保护机制降低风险暴露。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 3 个独立买入信号，可通过参数独立优化 |
| **卖出条件** | 2 个基础卖出信号 + 自定义动态止损 |
| **保护机制** | 3 组保护参数（LowProfitPairs、MaxDrawdown、防泵阈值） |
| **时间框架** | 主时间框架 5m + 信息时间框架 1h |
| **依赖库** | talib, numpy, pandas_ta, technical, qtpylib |

### 2.3 自定义动态止损系统

策略实现了分层次的动态止损机制：

```python
# 动态止损参数
pHSL = -0.178    # 硬止损利润阈值
```

- 利润 > 4.8%：止损随利润上浮

## 三、买入条件详解

### 3.1 保护机制（3组）

策略内置三重保护机制：

| 保护类型 | 参数说明 | 默认值 |
|---------|---------|--------|
| **防泵机制** | antipump_threshold | 0.25 |
| **LowProfitPairs** | 亏损5%后暂停交易60分钟 | trade_limit=1 |
| **MaxDrawdown** | 最大回撤20%触发熔断 | lookback=24根K线 |

### 3.2 三个买入条件详解

#### 条件 #1：EMA偏移 + EWO高位 + RSI低位组合

```python
# 逻辑
- 收盘价 < EMA(buy_candles) × low_offset (价格低于均线*0.973)
- EWO > ewo_high (5.672) （EWO指标显示上升动能）
- RSI < rsi_buy (59) （RSI未过热）
- 成交量 > 0
```

**适用场景**：上升趋势中的回调买入机会

#### 条件 #2：EMA偏移 + EWO低位组合

```python
# 逻辑
- 收盘价 < EMA(buy_candles) × low_offset (价格低于均线*0.973)
- EWO < ewo_low (-19.931) （EWO显示超卖状态）
- 成交量 > 0
```

**适用场景**：深度下跌后的抄底机会

#### 条件 #3：RSI布林带 + EWO验证组合（最复杂）

```python
# 逻辑
- RSI < basis - (dev × for_sigma) （RSI低于布林带下轨）
- EWO在合理区间：
  - (EWO > ewo_high_bb 且 EWO < 10) 或
  - (EWO >= 10 且 RSI < 40)
- RSI(4) < 25 （短期RSI超卖）
- CCI(fast) < 100 （CCI未过热）
- moderi_96 == True （长期趋势向上）
- 成交量 > 0
```

**适用场景**：多指标共振的超卖反转信号

### 3.3 三个买入条件分类

| 条件组 | 条件编号 | 核心逻辑 |
|-------|---------|---------|
| **趋势回调** | #1 | EMA偏移 + EWO确认 + RSI过滤 |

## 四、卖出逻辑详解

### 4.1 多层止盈系统

策略采用分级止盈机制：

```
利润率区间      止损阈值      信号名称
──────────────────────────────────────
< 1%          -17.8%        硬止损保护
1% ~ 4.8%      动态插值      分级止损
> 4.8%         随利润上浮    移动止损
```

### 4.2 两个卖出条件

**卖出信号 #1: EMA偏移卖出**

```python
# 条件
- 收盘价 > EMA(sell_candles) × high_offset (1.010)
- 成交量 > 0
```
**解读**：价格上涨超过均线的1.01倍，获利了结

**卖出信号 #2: RSI布林带上轨突破 + ATR止损**

```python
# 条件（满足任一）
- RSI > basis + (dev × for_sigma_sell) 且 moderi_96 == True
- 价格跌破 ATR_high（3.5倍ATR动态止损）
- 成交量 > 0
```
**解读**：RSI触及布林带上轨或价格触发ATR止损时卖出

### 4.3 防泵机制

```python
dont_buy_conditions.append(
    (dataframe['pump_strength'] > self.antipump_threshold.value)

```

当 `pump_strength`（泵强度）超过阈值时，强制禁止买入，防止追高风险。

- 长期 EMA 趋势确认
- 跨时间框架的 moderi 指标
- 泵强度计算的基础数据

### 5.3 Elliott Wave Oscillator (EWO)

```python
def EWO(dataframe, ema_length=5, ema2_length=35):
    ema1 = ta.EMA(df, timeperiod=ema_length)
    ema2 = ta.EMA(df, timeperiod=ema2_length)
    emadif = (ema1 - ema2) / df['close'] * 100
    return emadif
```

EWO 通过快速EMA与慢速EMA的差值百分比来衡量市场动能。

### 6.2 自定义动态止损

策略实现了渐进式止损保护：

```python
if (current_profit > PF_2):  # 利润 > 4.8%
    sl_profit = SL_2 + (current_profit - PF_2)
elif (current_profit > PF_1):  # 利润在 1% ~ 4.8%
    sl_profit = SL_1 + ((current_profit - PF_1) * (SL_2 - SL_1) / (PF_2 - PF_1))
else:  # 利润 < 1%
    sl_profit = HSL  # -17.8%
```

## 七、策略优势与局限

### ✅ 优势

1. **多维度验证**：买入信号需要多个指标同时确认，降低假信号概率
2. **防泵机制**：内置pump_strength指标，有效规避追高风险
3. **动态止损**：分层次止损机制让利润最大化同时保护本金
4. **HyperOpt友好**：大量可优化参数，便于回测调优

### ⚠️ 局限

1. **参数过多**：超过20个可调参数，容易过拟合历史数据
2. **计算复杂**：多个指标计算需要较多计算资源
3. **5分钟框架**：对市场噪音敏感，需要较好的市场流动性

## 九、适用市场环境详解

SMA_BBRSI 是 NostalgiaForX10 系列的变体策略。基于其代码架构和社区长期实盘验证的经验，它最适合 **震荡上行的趋势性市场**，而在 **剧烈波动或单边暴跌** 时表现不佳。

### 9.1 策略核心逻辑

- **EMA偏移买入**：在上升趋势中捕捉回调机会
- **EWO动能确认**：确保买入时有足够动能支撑
- **RSI布林带**：利用统计通道识别极端价格

### 9.2 不同市场环境表现

| 市场类型 | 表现评级 | 原因分析 |
| :--- | :--- | :--- |

| 🔄 横盘震荡 | ⭐⭐⭐⭐☆ | RSI布林带在震荡中表现优秀 |

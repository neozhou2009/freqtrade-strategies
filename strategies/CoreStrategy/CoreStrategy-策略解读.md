# CoreStrategy 策略深度解读

> **策略编号**: #131 (465 个策略中的第 131 个)  
> **策略类型**: 多条件趋势跟踪 + 布林带回归 + EWO 动量  
> **时间框架**: 5 分钟 (5m) + 1 小时信息层

---

## 一、策略概览

**CoreStrategy** 是一个复杂的多条件买入策略，整合了多个经典策略的核心逻辑（包括 SMAOffsetProtectOpt、CombinedBinHClucAndMADV6、CombinedBinHClucV8、CombinedBinHClucAndMADV9），通过 21 个独立买入条件构建多层次入场过滤体系。策略采用 5 分钟主时间框架配合 1 小时信息层进行趋势确认。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 21 个独立买入条件（可独立启用/禁用） |
| **卖出条件** | 4 个基础卖出信号 + 多层动态止盈逻辑 |
| **保护机制** | 自定义止损逻辑，但无独立买入保护参数 |
| **时间框架** | 5 分钟 + 1 小时信息层 |
| **依赖库** | TA-Lib, technical (qtpylib) |

- **宽松硬止损**：-22.8% 实际由自定义逻辑接管，提供更灵活的风险控制

## 三、买入条件详解

### 3.1 条件分组概览

策略包含 21 个买入条件，分为 4 个主要系列：

| 条件组 | 条件编号 | 核心逻辑 | 启用状态 |
|-------|---------|---------|---------|
| **SMAOffset** | smaoffset_buy_condition_0/1 | EWO 动量 + RSI 过滤 | 默认启用 |
| **V6 (CombinedBinHClucAndMADV6)** | v6_buy_condition_0~3 | 布林带回归 + 成交量过滤 | 部分启用 |
| **V8 (CombinedBinHClucV8)** | v8_buy_condition_0~4 | 多周期 EMA 确认 + 布林带 | 大部分启用 |
| **V9 (CombinedBinHClucAndMADV9)** | v9_buy_condition_0~10 | RSI 超卖 + 布林带底背离 | 默认禁用 |

### 3.2 条件 #1：smaoffset_buy_condition_0（EWO 高位反弹）

```python
# 逻辑
- 价格 < MA 买入线 * low_offset
- EWO > ewo_high (默认 5.499)
- RSI < rsi_buy (默认 50)
```

**核心逻辑**：价格在回调后处于相对低位，同时 EWO 显示强劲的上涨动量，形成"反弹"形态。

### 3.3 条件 #2：smaoffset_buy_condition_1（EWO 低位抄底）

```python
# 逻辑
- 价格 < MA 买入线 * low_offset
- EWO < ewo_low (默认 -19.881)
```

**核心逻辑**：EWO 极度负值表示大幅下跌后可能存在抄底机会，配合价格位置筛选。

### 3.4 条件 #3-7：V8 系列（多周期趋势确认）

V8 系列条件共同特征：
- 要求 1 小时周期 EMA 向上多头排列
- 要求 5 分钟周期价格回调幅度在阈值内
- 使用布林带中轨突破或价格触及布林带下轨作为信号

#### v8_buy_condition_0
- 1h EMA50 > 1h EMA200 且 5m EMA50 > 5m EMA200
- 布林带收缩形态（bbdelta、closedelta、tail 综合判断）
- 价格跌破布林带下轨

#### v8_buy_condition_1
- 5m 和 1h 收盘价均站上 EMA200
- 1h EMA50 > EMA100 > EMA200
- 价格触及布林带下轨 + 成交量萎缩

#### v8_buy_condition_2
- SSL 通道 1h 向上
- 5m 价格在 EMA50 和 EMA200 之上
- RSI 1h-RSI 价差 > 阈值

#### v8_buy_condition_3
- 200 周期 SMA 向上趋势（5m 和 1h）
- RSI 1h > 阈值，RSI 5m < 阈值
- MFI < 阈值

#### v8_buy_condition_4
- 价格 > 1h EMA100
- EMA 金叉（EMA26 > EMA12）
- 价格触及布林带下轨 + 成交量缩量

### 3.5 条件 #8-17：V9 系列（保守型买入）

V9 系列条件大多默认禁用，特点：
- 强调 RSI 超卖
- 强调成交量缩量
- 强调价格位于布林带下轨附近

### 3.6 条件 #18-21：V6 系列（布林带回归）

#### v6_buy_condition_0
- 收盘价 > EMA200（5m 和 1h）
- 价格 < 布林带下轨 * 0.99
- 成交量缩量

#### v6_buy_condition_1
- 价格 < EMA50
- 价格 < 布林带下轨 * 0.975
- RSI 1h < 15（禁止买入）

#### v6_buy_condition_2
- 5m 和 1h 价格均在 EMA200 上方
- EMA26 > EMA12（金叉形态）
- 价格触及布林带下轨

#### v6_buy_condition_3
- EMA26 > EMA12
- 成交量缩量
- 价格触及布林带下轨


## 四、卖出逻辑详解

### 4.1 多层动态止盈系统

策略使用 `custom_exit` 函数实现 5 层 ROI 退出：

| 利润区间 | 阈值 | RSI 条件 | 信号名称 |
|---------|------|---------|---------|
| 高位止盈 | > 30% | RSI < 58 | roi_target_4 |
| 中高位止盈 | > 15% | RSI < 56 | roi_target_3 |
| 中位止盈 | > 4% | RSI < 50 | roi_target_2 |
| 低位止盈 | > 1% | RSI < 50 | roi_target_1 |
| SMA 死叉退出 | 1-4% | SMA200 向下 | roi_target_5 |

### 4.2 追踪止损退出

策略实现两段式追踪止损：

| 阶段 | 利润区间 | 回撤触发 |
|-----|---------|---------|
| 第一阶段 | 10%-40% | 从高点回撤 3% |
| 第二阶段 | 2%-10% | 从高点回撤 1.5% |

### 4.3 自定义止损逻辑

`custom_stoploss` 函数实现智能止损：

```python
def custom_stoploss(...):
    if current_profit > 0:
        return 0.99  # 盈利时不主动止损
    
    # 开仓 240 分钟后（约 4 小时）
    if current_time > trade_time_50:
        # 如果 SMA200 向下（5m 和 1h 同时确认）
        if (sma_200_dec) & (sma_200_dec_1h):
            return 0.01  # 强制止损
        
        # RSI 1h < 30 表示可能见底
        if rsi_1h < 30:
            return 0.99  # 继续持有等待反弹
        
        # 价格跌破开盘价 2.5% 且在 EMA200 上方
        if current_rate * 1.025 < candle["open"]:
            if current_rate > ema_200:
                return 0.01  # 止损
        
        # 价格跌破开盘价 1.5%
        if current_rate * 1.015 < candle["open"]:
            return 0.01  # 止损
```

## 六、风险管理特色

### 6.1 时间基硬止损

策略对持仓时间超过 4 小时的亏损仓位实施分级处理：

| 条件 | 处理方式 |
|------|---------|
| SMA200 同时死叉 | 立即止损（1% 止损线） |
| RSI 1h < 30 | 继续持有等待反弹 |
| 价格跌破开盘价 2.5% 且站上 EMA200 | 止损 |
| 价格跌破开盘价 1.5% | 止损 |

### 6.2 阶梯式 ROI 退出

- 早期目标激进（20%），适合高波动币种
- 后期目标保守（2.5%），防止利润回吐

### 6.3 追踪止损保护

- 仅在盈利达到一定阈值后启用
- 两段式回撤控制，兼顾利润保护与持仓耐力

## 七、策略优势与局限

### ✅ 优势

1. **多条件过滤**：21 个独立条件提供丰富选择，可针对不同市场环境启用/禁用
2. **多周期确认**：1 小时信息层提供更高视角的趋势判断
3. **智能止损**：基于时间、趋势、RSI 的动态止损逻辑
4. **灵活配置**：buy_minimum_conditions 可调整入场严格程度
5. **成交量过滤**：多个条件包含成交量缩量要求，过滤虚假突破

### ⚠️ 局限

1. **参数众多**：21 个条件 × 多个参数，优化难度大
2. **计算密集**：多时间框架 + 多指标，回测/实盘耗时长
3. **部分条件禁用**：V9 系列 10 个条件默认全部禁用，可能存在过拟合风险
4. **硬止损宽松**：-22.8% 实际由自定义逻辑接管，需充分理解其逻辑

## 九、适用市场环境详解

CoreStrategy 是 Freqtrade 生态中代码量最大、最复杂的策略之一，整合了 4 个经典策略的核心逻辑。它最适合 **高波动、强趋势** 市场，而在 **低波动、长横盘** 环境中表现一般。

### 9.1 策略核心逻辑

- **多条件叠加**：至少满足 1 个条件即可入场，但可通过调整 buy_minimum_conditions 提高门槛
- **趋势优先**：多个条件要求 1h EMA 多头排列，确保顺势交易
- **动量确认**：EWO、RSI 动量指标贯穿多个条件
- **回调买入**：强调价格回调至支撑位（布林带下轨）后买入

### 9.2 不同市场环境表现

| 市场类型 | 表现评级 | 原因分析 |
| :--- | :--- | :--- |
| 📈 强上涨趋势 | ⭐⭐⭐⭐⭐ | 多周期 EMA 确认 + 回调买入逻辑 |
| 🔄 宽幅震荡 | ⭐⭐⭐⭐ | 布林带回归条件能捕捉波段 |
| 📉 下跌趋势 | ⭐⭐⭐ | 部分抄底条件有效，但整体偏多 |
| ⚡️ 快速波动 | ⭐⭐⭐⭐ | 20% 激进目标适合高波动 |
| 📊 横盘整理 | ⭐⭐ | 多条件难以同时满足 |

### 9.3 关键配置建议

| 配置项 | 建议值 | 说明 |
|--------|--------|------|
| buy_minimum_conditions | 1 | 保持宽松以捕获更多信号 |
| minimal_roi."0" | 0.15-0.25 | 根据波动率调整 |
| trailing_stop_positive | 0.005 | 较紧的追踪启动阈值 |
| ewo_high | 5-8 | 提高以减少假信号 |

## 十、重要提醒：复杂性的代价

### 10.1 学习成本

CoreStrategy 代码量超过 1000 行，21 个买入条件分布在 4 个策略系列中。新手建议先从单一条件系列开始理解，再逐步扩展到完整策略。

### 10.2 硬件要求

| 交易对数量 | 最低内存 | 推荐内存 |
|-----------|---------|---------|
| 10-20 对 | 2GB | 4GB |
| 20-50 对 | 4GB | 8GB |
| 50+ 对 | 8GB | 16GB |

### 10.3 回测与实盘的差异

- 多条件策略容易过拟合历史数据
- 部分条件（如 V9 系列）默认禁用，需验证其有效性
- 自定义止损逻辑在实盘中可能产生额外滑点

### 10.4 手动交易者建议

建议手动交易者关注以下核心信号：
- **smaoffset_buy_condition_0**：EWO > 5 + 价格回调至均线附近
- **v8_buy_condition_0**：1h EMA 多头排列 + 布林带收缩形态

## 十一、总结

**CoreStrategy** 是一个高度复杂的多条件趋势跟踪策略，整合了 Freqtrade 社区多个经典策略的精华。它的核心价值在于：

1. **灵活性**：21 个可独立配置的条件，适应多种市场环境
2. **多周期视角**：1 小时信息层提供更高维度的趋势确认
3. **智能风控**：自定义止损逻辑结合时间、趋势、动量多维度判断
4. **社区验证**：基于多个经实盘验证的策略整合

对于量化交易者而言，CoreStrategy 适合有一定 Freqtrade 使用经验的投资者。建议从默认配置开始，逐步理解和调整各条件系列的启用状态，找到最适合当前市场环境的配置组合。

**使用建议**：先使用默认参数进行小资金实盘测试，观察策略在不同市场环境下的表现，再根据实际情况调整 ROI 表和条件启用状态。

## 一、这策略是个啥？

简单说，**CoreStrategy** 就是一个：
- 有 **21 个买入条件** 的策略（选择困难症晚期患者）
- 有 **4 个卖出条件** 的策略
- 整合了 4 个经典策略（ SMAOffset + V6 + V8 + V9 ）的"超级缝合怪"
- 用 **5 分钟 + 1 小时双时间框架** 的策略

就像一个买东西要翻遍 4 个购物 app、对比 21 个条件的超级选择困难症患者："这个便宜、那个销量高、这个评分好、那个有优惠...到底买哪个？！" 😂

## 二、核心配置：说白了就是"大杂烩"

### 止盈规则（ROI 表）

```
0-38 分钟：赚 20% 就跑！
38-78 分钟：赚 7.4% 就跑！
78-194 分钟：赚 2.5% 就跑！
194 分钟以后：随便跑
```

**翻译**：这策略很贪心，开盘就想赚 20%！但随着时间推移，目标越来越低——典型的"一开始想搞大的，后面认怂" 😅

### 止损规则

```
硬止损：亏 22.8%（实际由自定义逻辑接管）
追踪止损：有！从盈利 5% 开始追踪，最高点回撤 0.5% 就跑
自定义止损：开仓 4 小时后，根据趋势和 RSI 动态处理
```

**翻译**：官方止损看似很松（-22.8%），但实际上策略写了一套复杂的"智能止损"逻辑，根据持仓时间、趋势方向、RSI 水位来决定是割肉还是等反弹。

## 三、21 个买入条件：我帮你分类好了

这策略的买入条件实在太多了，我给你归了 4 类：

### 🎯 第 1 类：SMAOffset 系列（2 个条件）
**核心逻辑**：EWO 动量指标 + 价格位置

- **smaoffset_buy_condition_0**：EWO 向上 + RSI 低于 50 + 价格低于均线
  > "跌到均线附近了，而且动量显示要涨，这还不买？"

- **smaoffset_buy_condition_1**：EWO 极度负值（<-19.8）
  > "跌太多了，要弹回来了！"

### 📉 第 2 类：V8 系列（5 个条件，默认启用 4 个）
**核心逻辑**：多周期 EMA 确认 + 布林带回调

- **v8_buy_condition_0**：1h EMA 多头排列 + 布林带收缩形态 + 跌破下轨
  > "大周期趋势向上，小周期回调到布林带底了，买！"

- **v8_buy_condition_1**：价格站上 EMA200 + 触及布林带下轨 + 成交量萎缩
  > "长期趋势向上，短期跌不动了，买！"

- **v8_buy_condition_2**：SSL 通道向上 + RSI 1h 相对强
  > "1小时趋势利好，5分钟 RSI 超卖了，买！"

- **v8_buy_condition_3**：SMA200 向上 + RSI 1h 强于 RSI 5m
  > "长期趋势向上，而且 1 小时比 5 分钟更强，说明还要涨！"

- **v8_buy_condition_4**：价格 > 1h EMA100 + EMA 金叉 + 触及布林带下轨
  > "中周期趋势向上，MACD 金叉，短期跌到支撑位，买！"

### 📊 第 3 类：V9 系列（10 个条件，默认全部禁用）
**核心逻辑**：RSI 超卖 + 布林带底背离

> **警告**：这 10 个条件默认都是关闭的！作者可能觉得它们不够靠谱 👻

- **v9_buy_condition_1~10**：各种 RSI 超卖、成交量缩量、布林带底部的组合
- 翻译：各种"抄底"逻辑，但被作者打入了冷宫

### 🔍 第 4 类：V6 系列（4 个条件，默认启用）
**核心逻辑**：布林带回归 + 成交量萎缩

- **v6_buy_condition_0**：价格站上 EMA200 + 触及布林带下轨

**大白话**：这类条件的核心就是——"价格跌到布林带底部了，而且（可能）站上长期均线，买了！"

## 五、卖出逻辑：比买入更花哨

策略用 `custom_exit` 写了 5 层止盈：

| 赚多少 | RSI 条件 | 大白话 |
|-------|---------|--------|
| > 30% | RSI < 58 | "赚翻了，RSI 也高了，该跑了！" |
| > 15% | RSI < 56 | "赚不少了，指标提示风险了，跑！" |
| > 4% | RSI < 50 | "赚4%了，RSI 预警了，跑！" |
| > 1% | RSI < 50 | "赚点就跑，别贪心！" |
| 1-4% | SMA200 死叉 | "长期趋势向下了，别恋战！" |

**大白话**：这策略就像一个"见好就收"的人——赚得越多，条件越严格，生怕到手的鸭子飞了 🦆

### 5.2 追踪止损：从高点回撤就跑

```
第一档：赚 10%-40% → 从最高点回撤 3% 就跑
第二档：赚 2%-10% → 从最高点回撤 1.5% 就跑
```

**大白话**：虽然我贪心想要 20%，但如果盈利开始缩水，就立刻跑路！典型的"赚够就跑" 😎

### 5.3 自定义止损：4 小时后的"智能割肉"

| 条件 | 处理 |

| SMA200 死叉（5m + 1h 同时） | 强制割肉！ |

| 价格跌破开盘价 2.5% 且在 EMA200 上方 | 割肉 |
| 价格跌破开盘价 1.5% | 割肉 |

**大白话**：
- "都持有 4 小时了，还亏钱？让我看看趋势还好不好..."
- "趋势还在？继续等反弹！"
- "趋势坏了？直接割！"

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **条件丰富**：21 个条件，想怎么配置就怎么配置，总有一款适合当前市场
2. **多周期确认**：1 小时信息层帮忙看大局，避免被 5 分钟的噪音骗了

4. **成交量过滤**：多个条件要求成交量缩量，减少假突破

### ⚠️ 缺点（吐槽环节）

1. **太复杂**：代码 1000+ 行，21 个条件，调试起来要命 😅
2. **容易过拟合**：条件太多，很容易"恰好"拟合历史数据
3. **计算量大**：双时间框架 + 几十个指标，VPS 压力大
4. **V9 全禁**：10 个条件默认关闭，是不是有啥问题？

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

CoreStrategy 的历史回测往往**看起来很美**——21 个条件，怎么组合都能找到"完美参数"。但这有个陷阱：

> **因为条件太多，策略很容易"拟合"过去行情的最优解，但这并不代表未来一定能盈利。**

简单说就是：**背答案考高分，不代表期末考能及格** 📝

### 复杂策略的隐藏风险

实盘时，复杂的逻辑可能导致：
- **信号延迟**：计算量大，可能错过最佳买卖点
- **过度交易**：条件多，交易次数可能激增
- **参数漂移**：市场变了，参数需要重新调
- **资金曲线波动**：多条件策略可能大赚大亏，心态容易崩

### 我的建议（真心话）

```
1. 先用默认参数跑，至少观察 1 个月
2. 不要同时改多个参数，一次只改一个
3. 小资金测试，实盘和回测差异可能很大
4. 定期复盘，看看哪些条件真正产生了收益
5. 别贪心，复杂策略更容易翻车
```

**记住**：策略再好，市场教做人时也不会打招呼。轻仓测试，活着最重要！🙏

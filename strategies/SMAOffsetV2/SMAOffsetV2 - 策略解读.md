## 一、策略概览

SMAOffsetV2 是一个基于简单移动平均线偏移（SMA Offset）的趋势跟踪策略，在原版 SMAOffset 基础上增加了趋势检测和自定义止损机制。该策略使用 EMA 快慢线（20/25）判断趋势方向，仅在上升趋势中寻找 SMA 偏移买入机会，同时通过动态止损机制控制风险。

该策略设计理念简洁明了：**只在趋势向上时买入，价格回调到均线下方时入场，价格回到均线上方或趋势转向时出场**。

### 核心特征

| 特征 | 描述 |
|------|------|
| **买入条件** | 1 个买入信号（趋势过滤 + SMA 偏移） |
| **卖出条件** | 1 个卖出信号（两个子条件 OR 逻辑） |
| **保护机制** | 动态止损（时间+亏损双条件触发） |
| **时间框架** | 5m（主）+ 1h（信息层趋势判断） |
| **依赖库** | talib, pandas, freqtrade.persistence |

## 三、买入条件详解

### 3.1 趋势过滤机制

策略使用 1 小时时间框架的 EMA 判断趋势：

```python
# 1小时 EMA 指标
dataframe['ema_fast'] = ta.EMA(dataframe, timeperiod=20)
dataframe['ema_slow'] = ta.EMA(dataframe, timeperiod=25)

# 趋势判断
dataframe['go_long'] = (
    (dataframe['ema_fast'] > dataframe['ema_slow'])
).astype('int') * 2
```

**逻辑解读**：
- go_long = 2：EMA 快线 > EMA 慢线，上升趋势
- go_long = 0：EMA 快线 ≤ EMA 慢线，下降趋势

### 3.2 买入条件

```python
# 触发条件
- go_long > 0（1小时上升趋势）
- 收盘价 < sma_30_offset（价格低于 SMA(20) × 0.96）
- 成交量 > 0
```

**详细解析**：

| 条件 | 参数 | 说明 |
|------|------|------|
| 趋势过滤 | EMA(20) > EMA(25) | 仅在 1 小时上升趋势中买入 |
| SMA 偏移 | SMA(20) × 0.96 | 价格低于均线下方 4% |
| 成交量 | > 0 | 有交易活动 |

**设计意图**：
- 通过 1 小时趋势过滤，避免在下降趋势中抄底
- 4% 的偏移幅度较大，确保足够的价格折扣
- 简单明了，一个条件即可入场

## 四、卖出逻辑详解

### 4.1 卖出条件（两个子条件 OR 逻辑）

```python
# 卖出信号
(
    (go_long == 0)           # 趋势转向（子条件 1）
    |
    (close > sma_30_offset_pos)  # 价格突破上方偏移（子条件 2）
)
&
(volume > 0)
```

**子条件详解**：

| 子条件 | 触发逻辑 | 说明 |
|--------|---------|------|
| #1 趋势转向 | go_long == 0 | 1 小时 EMA 死叉，趋势转为下降 |
| #2 价格突破 | close > SMA(20) × 1.012 | 价格高于均线上方 1.2% |

**逻辑解读**：
- **趋势转向**：1 小时 EMA 快线下穿慢线，表示趋势可能反转
- **价格突破**：价格涨到均线上方 1.2%，达到获利目标

### 4.2 动态止损机制

策略实现了自定义止损函数，提供智能风控：

```python
def custom_stoploss(self, pair: str, trade: 'Trade', current_time: datetime,
                    current_rate: float, current_profit: float, **kwargs) -> float:

    # 条件：持仓超过 40 分钟 + 亏损超过 10%
    if current_time - timedelta(minutes=40) > trade.open_date_utc and current_profit < -0.1:
        return -0.01  # 止损收紧到 -1%

    return -0.99  # 默认：几乎不触发止损
```

**工作机制**：
- **默认状态**：止损 -99%（几乎不触发）
- **触发条件**：持仓 > 40 分钟 AND 亏损 > 10%
- **触发后**：止损收紧到 -1%，快速止损

**设计意图**：
- 给策略足够的时间"自救"，避免过早止损
- 如果 40 分钟后还亏 10% 以上，承认判断错误，快速止损

4. 将趋势信号合并到 5 分钟数据

## 六、风险管理特色

### 6.1 动态止损系统

策略采用智能动态止损，与传统固定止损不同：

| 止损类型 | 触发条件 | 止损值 | 说明 |
|---------|---------|--------|------|
| 初始状态 | 任何情况 | -99% | 几乎不触发 |
| 动态收紧 | 持仓 > 40 分钟 AND 亏损 > 10% | -1% | 快速止损 |

**优势**：
- 避免被正常波动止损
- 给策略足够时间恢复
- 在确认失败后快速止损

### 6.2 趋势过滤保护

- 仅在 1 小时上升趋势中买入
- 趋势转向时立即卖出
- 避免逆势交易

### 6.3 盈利保护

```python
sell_profit_only = True     # 仅盈利时使用卖出信号
```

这一设置确保卖出信号不会在亏损时触发，避免在浮亏时卖出。

## 七、策略优势与局限

### ✅ 优势

1. **逻辑简洁**：一个买入条件，两个卖出条件，清晰易懂
2. **趋势过滤**：使用 1 小时 EMA 判断趋势，避免逆势交易
3. **动态止损**：给策略恢复时间，失败时快速止损
4. **代码量少**：便于理解和二次开发

### ⚠️ 局限

1. **参数固定**：买入参数写死在代码中，不如 HyperOpt 版本灵活
2. **偏移幅度大**：4% 的偏移可能导致错过一些机会
3. **无追踪止损**：没有追踪止盈机制，可能"坐过山车"
4. **依赖趋势**：在震荡市场中表现可能不佳

## 九、适用市场环境详解

SMAOffsetV2 是 SMA Offset 系列的简化版本，专注于趋势跟踪。基于其代码架构，它最适合 **明确趋势的市场**，而在 **震荡横盘** 时表现不佳。

### 9.1 策略核心逻辑

- **趋势过滤**：只有 1 小时 EMA 金叉状态才买入
- **价格偏移入场**：价格低于 SMA 4% 时入场
- **双重退出**：趋势反转或价格突破时退出

### 9.2 不同市场环境表现

| 市场类型 | 表现评级 | 原因分析 |
| :--- | :--- | :--- |
| 📈 慢牛趋势 | ⭐⭐⭐⭐⭐ | 趋势过滤生效，回调买入机会多 |
| 🔄 震荡横盘 | ⭐⭐☆☆☆ | EMA 频繁交叉，趋势判断失准 |
| 📉 单边下跌 | ⭐⭐⭐⭐☆ | 趋势过滤阻止买入，空仓避险 |
| ⚡️ 剧烈波动 | ⭐⭐⭐☆☆ | 偏移幅度可能被穿透 |

### 9.3 关键配置建议

| 配置项 | 建议值 | 说明 |
|--------|--------|------|
| 交易对 | 主流币/稳定币 | 趋势清晰，流动性好 |
| 止损 | 保持 -20% | 作为最后防线 |
| 动态止损时间 | 40 分钟 | 可根据交易对调整 |

# SMAOffsetV2 策略：简单粗暴的趋势跟风者

> **外号**：趋势小狗勾  
> **职业**：只在风大的时候放风筝  
> **时间框架**：5分钟 + 1小时看趋势

---

## 一、这策略是个啥？

简单说，**SMAOffsetV2** 就是一个：

- 只在趋势向上的时候买
- 等价格打折 4% 再入场
- 趋势变了或者赚够了就跑

就像 **放风筝** —— 只有风大的时候（上升趋势）才出去放，而且要等风筝便宜了 4% 再买。风向一变或者风筝飞够了，立刻收线回家 🪁

---

## 二、核心配置：说白了就是"看准风向再动手"

### 止盈规则（ROI 表）

```
立即：赚 100% 再跑
```

**翻译**：ROI 设成 100%，基本就是"我不靠 ROI 止盈，全靠卖出信号和止损"。简单粗暴！

### 止损规则

```
固定止损：-20%（亏 20% 就认栽）
动态止损：持仓 40 分钟 + 亏 10% → 止损收紧到 -1%
```

**翻译**：
- 如果刚买进去就亏，先别慌，给策略 40 分钟时间"自救"
- 40 分钟后还亏 10% 以上，那就算了，赶紧止损跑路
- 如果你硬扛到亏 20%，系统强制帮你割肉

## 三、1 个买入条件：简单才是美

这策略只有一个买入条件，不像有些策略那样花里胡哨。

### 🎯 买入条件：趋势向上 + 价格打折

**核心逻辑**：1 小时趋势向上 + 价格低于均线 4%

**大白话**：
> "大趋势在涨，现在价格回调了 4%，是个捡便宜的好机会！"

**具体条件**：
```python
go_long > 0           # 1小时 EMA 快线 > 慢线（趋势向上）
close < sma_30_offset # 价格低于 SMA(20) × 0.96（打折 4%）
volume > 0            # 有交易
```

**经典台词**：
> "风正大，风筝正好打折，买！"

---

## 四、保护机制：给机会但不硬扛

### 4.1 动态止损：温柔的等待

这个止损机制挺有意思：

```python
if 持仓时间 > 40分钟 AND 亏损 > 10%:
    止损 = -1%  # 收紧！
else:
    止损 = -99%  # 先不管
```

**大白话**：
> "兄弟，你刚买进去，给你 40 分钟时间看看能不能赚回来。如果 40 分钟后还亏着 10%，那我就帮你止损了。"

这是一个 **"先给机会，不行就撤"** 的机制，挺人性化的。

### 4.2 趋势过滤：不看下跌趋势

只在 1 小时 EMA 金叉（快线在慢线上方）的时候才买入。

**大白话**：
> "风往东吹，我往东跑；风往西吹，我往西跑。风停了？那我回家睡觉，不乱跑。"

---

## 五、卖出逻辑：两个信号，满足一个就跑

### 5.1 卖出信号

```
信号 #1：趋势转向（EMA 死叉）
信号 #2：价格涨到均线上方 1.2%
```

**大白话**：

| 信号 | 条件 | 人话翻译 |
|------|------|---------|
| #1 趋势转向 | 1小时 EMA 快线 < 慢线 | "风向变了，赶紧收线！" |
| #2 价格突破 | 价格 > SMA(20) × 1.012 | "风筝飞够了，赚够了，撤！" |

### 5.2 盈利才卖

```python
sell_profit_only = True  # 仅盈利时使用卖出信号
```

**大白话**：
> "如果亏着呢，卖出信号先别管。等盈利了再说。"

这个设计是为了避免在浮亏时被卖出信号止损，给策略更多恢复的机会。

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **简单粗暴**：就一个买入条件，两个卖出条件，清清楚楚
2. **趋势保护**：只在上升趋势中买，避免逆势抄底
3. **动态止损**：给机会恢复，不行就撤，挺人性化
4. **代码量少**：适合学习 Freqtrade 策略开发

### ⚠️ 缺点（吐槽环节）

1. **参数写死**：4% 偏移、20/25 EMA 都是硬编码，不能优化
2. **偏移太大**：4% 的折扣有点狠，可能错过一些机会
3. **没追踪止损**：价格涨上去后，如果又跌下来，可能"坐过山车"
4. **震荡市场吃瘪**：EMA 频繁交叉，趋势判断失准

## 十一、彩蛋：策略作者的"小心思"

仔细看代码，你会发现一些有趣的东西：

1. **EMA 用 20/25 而不是传统的 12/26**：
   > "作者用了一个不常见的组合，20/25 更贴近，反应更快，但也更容易被假信号骗。"

2. **动态止损的 40 分钟 + 10% 设计**：
   > "这个设计挺人性化：给策略 40 分钟自救，不行就撤。不是一亏就止损，也不是死扛到底。"

3. **go_long 用 *2 而不是 *1**：
   > "其实 *1 和 *2 效果一样，作者可能是为了方便后面区分其他信号。代码里有点多余，但不影响功能。"

4. **感谢 tirail**：
   > "代码注释里感谢了 tirail 分享原版 SMAOffset，说明这是站在巨人肩膀上的改进版。"

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

SMAOffsetV2 的逻辑很简单，但这不代表它一定能赚钱：

> **策略简单不代表就能躺赚，市场从来不是按逻辑出牌的。**

简单说就是：**策略越简单，越容易"被看穿"。如果大家都知道这个逻辑，谁赚谁的钱？**

### 简单策略的隐藏风险

实盘时，你可能会遇到：
- **错过机会**：4% 偏移太大，很多机会被错过
- **震荡亏损**：趋势判断失准，频繁止损
- **参数老化**：写死的参数可能不适合当前市场
- **追涨杀跌**：趋势转向时可能卖在低位

### 我的建议（真心话）

```
1. 把它当学习材料，理解 Freqtrade 策略框架
2. 回测看看表现，了解在什么市场有效
3. 如果想用，考虑魔改：加参数优化、追踪止损等
4. 不要期望太高，简单策略有简单策略的局限
```

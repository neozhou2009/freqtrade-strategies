## 一、这策略是个啥？

简单说，**Schism** 就是一个：
- 不追高，专门抄底——但抄得有讲究
- 入场后不急着卖，趋势好就一直拿着
- 还会"看别人脸色"——感知其他交易的状态来决定要不要卖

就像 **一个抄底高手，入场前看大局，入场后看趋势，卖的时候还要看整体仓位** 🎯

**一句话总结**：
> "我抄底，但我不是无脑抄；我持仓，但我不是死扛；我止损，但我止损有讲究。"

## 二、核心配置：说白了就是"层层设防"

### 止盈规则（ROI 表）

```
持仓时间        利润目标
──────────────────────────
刚买入          10%（贪心一下）
15 分钟后       5%（快进快出）
30 分钟后       2.5%（降降温）
1 小时后        1%（差不多得了）
2 小时后        0.5%（蚊子肉也吃）
24 小时后       0%（只要不亏就行）
```

**翻译**：
- 新开的仓位，先想着赚大的（10%）
- 时间越久，目标越低——**"你不是趋势吗？赶紧涨啊，不涨我跑了"**
- 24 小时后，**"行吧行吧，保本也行"**

### 止损规则

```
硬止损：-40%（这就是底线）
动态止损：从 -3% 慢慢提升到 0%
```

**翻译**：
- **硬止损 -40%**：这是"保命符"，真跌惨了认栽
- **动态止损**：刚开仓时给你 -3% 的空间，时间越久越收紧，最后变成"保本止损"

### 关键设置

```python
ignore_roi_if_buy_signal = True  # 这个是灵魂！
```

**翻译**：
> "如果我还在发买入信号，说明趋势还在，那 ROI 就先不管了，继续拿着！"

## 三、2 组买入条件：我帮你分类好了

这策略的买入条件分两类：**新开仓** 和 **持仓延续**。

### 🎯 第 1 类：新开仓买入（抄底信号）

**触发条件**：当前没有这个币的持仓

**核心逻辑**：抄底，但不能瞎抄

**大白话**：
> "价格跌到 3 天低点附近了，但别太极端。RSI 也不能太惨（不能低于 30），动量指标要显示'跌得差不多了'，这时候我才出手。"

**具体条件**：
```
1. RSI_1h >= 30          → "一小时 RSI 还没跌到极端超卖"
2. 价格 <= 3 日低点 + 80% * 日波动范围
                         → "抄底，但留点安全边际"
3. RMI 下降趋势确认       → "确认是在下跌趋势中找反转"
4. RMI-slow >= 20        → "动量别太弱"
5. RMI-fast <= 20        → "短期动量要低迷（准备反弹）"
6. Momentum Pinball <= 50 → "动量弹球指标不能太疯狂"
7. 有成交量              → "得有人交易才行"
```

**经典台词**：
- "抄底要在'跌到位'的时候，不是'跌到底'的时候"
- "我看的是 1 小时 RSI，别用 5 分钟骗我"

---

### 📈 第 2 类：持仓延续买入（趋势确认信号）

**触发条件**：当前有这个币的持仓

**核心逻辑**：确认趋势还在，别让 ROI 打断

**大白话**：
> "既然我还在场内，那就看看趋势还在不在。如果还在涨，那 ROI 先放一边，继续拿着！"

**具体条件**：
```
1. RMI 上升趋势确认      → "趋势还在涨"
2. 当前利润 > 峰值利润 * 动态因子
                         → "利润因子"——RMI 越高，对利润要求越低
3. RMI-slow >= 动态阈值   → "阈值随时间涨：180 分钟后从 30 开始，720 分钟后到 70"
```

**动态因子计算**：
```python
profit_factor = 1 - (rmi_slow / 400)
# rmi = 30 → factor = 0.925
# rmi = 80 → factor = 0.80
```

**大白话翻译**：
- RMI 越高（趋势越强），对利润要求越低
- **"趋势这么好，少赚点也行，继续拿着！"**

## 四、保护机制：4 层"防傻"设计

每个买入条件都配了一套保护参数，就像 **4 道保险丝**：

| 保护类型 | 作用 | 大白话 |
|---------|------|--------|
| **硬止损** | -40% 直接砍 | "跌到 -40% 认栽，保命要紧" |
| **动态止损** | -3% → 0% | "时间越久，止损越紧" |
| **订单超时** | 滑点 > 1% 取消 | "价格跑太快就不买了/不卖了" |
| **入场确认** | 滑点 > 1% 拒绝 | "下单前再确认一次价格，别被坑" |

**吐槽**：
> 这策略是怕用户手滑吗？4 层保护啊！不过话说回来，加密货币这波动，多几层保护确实放心点 🤣

## 五、卖出逻辑：比买入更讲究

### 5.1 分级止盈：赚多少跑

```
持仓时间        利润目标
──────────────────────────
0 分钟         10%       → "刚进去就想翻倍？不，10% 就够了"
15 分钟        5%        → "15 分钟了，5% 也行"
30 分钟        2.5%      → "半小时了，2.5% 凑合"
...以此类推...
24 小时        0%        → "一天了，保本也行"
```

**但！** 有个超级重要的设置：

```python
ignore_roi_if_buy_signal = True
```

**大白话**：
> "如果持仓延续买入信号还在，那 ROI 先靠边站！我继续拿着！"

### 5.2 动态止损：该认输时得认输

```
止损阈值变化：
- 刚开仓：-3%（给你点空间）
- 300 分钟后：0%（保本止损）
```

**触发条件**：
```
1. 当前利润 < 动态阈值（-3% 到 0%）
2. 还没触及硬止损（-40%）
3. RMI 下降趋势确认 → "趋势坏了"
4. 有成交量
5. 如果曾经盈利过：RMI 下穿 50 → "趋势减弱了"
   如果从未盈利过：RMI 下穿 10 → "这个币不行，认栽"
```

**大白话**：
- **"持仓时间短，给你 -3% 的空间；时间长了，保本止损"**
- **"如果曾经赚过钱，那用 RMI 50 判断趋势减弱；如果一直亏钱，RMI 10 就赶紧跑"**

### 5.3 全局仓位感知：看别人脸色

这是 Schism 最独特的地方：**它会看其他交易的状态**！

```python
if 有其他交易:
    if 还有空槽位:
        # 空槽位越多，越愿意持有
        hold_pct = (1 / 空槽位数) * -0.04
        # 1 个槽位 → 其他交易平均利润 >= -4% 才卖
        # 4 个槽位 → 其他交易平均利润 >= -1% 才卖
    else:
        # 满仓了！只允许最大亏损的那个卖
        条件 += [我是最大输家]
```

**大白话翻译**：
- **"有空位的时候，我看看其他交易怎么样。如果大家都在亏，那再等等；如果只有我亏，那考虑止损。"**
- **"没空位了？那最大输家先出去，给新机会腾位置。"**

## 六、这策略的"人格特点"

### ✅ 优点（夸夸环节）

1. **抄底有原则**：不是盲目抄底，而是有条件、有确认地抄
2. **趋势骑乘**：一旦入场，趋势好就继续拿着，不会轻易被 ROI 打断
3. **全局视角**：看所有持仓的整体状态，不是"管好自己就行"
4. **保护够多**：4 层保护机制，滑点、止损、超时都有
5. **动态调整**：止损阈值、利润因子都会随时间和趋势动态变化

### ⚠️ 缺点（吐槽环节）

1. **只适合实盘**：回测用不了！`ignore_roi_if_buy_signal` 和持仓延续信号在回测里不生效
2. **止损太宽**：-40% 的硬止损，对保守玩家来说太刺激了
3. **依赖数据库**：需要访问数据库查询其他交易状态，系统挂了策略就傻了
4. **参数多**：买参数 5 个，卖参数……一堆，优化不好容易过拟合
5. **计算量大**：多指标、多时间框架、多交易感知，老机器可能会卡

**建议流程**：
1. 先回测，验证买入信号质量
2. 再 dry_run，验证动态逻辑
3. 最后小仓位实盘
4. **别直接用回测结果梭哈！**

## 十三、⚠️ 风险再强调（这段一定要看）

### 回测很美好，实盘要谨慎

Schism 的历史回测表现往往**很好看**——但这有个陷阱：

> **因为核心功能（持仓延续信号、全局仓位感知）在回测中不生效，回测结果可能严重失真！**

简单说就是：**回测看到的不是真实的策略行为。**

### 复杂策略的隐藏风险

实盘时，复杂的逻辑可能导致：
- **数据库访问延迟**：查询其他交易状态需要时间，极端行情下可能来不及
- **订单超时失效**：订单簿数据延迟，滑点保护可能不生效
- **内存溢出**：多交易对场景下，内存占用可能超标
- **参数过拟合**：默认参数可能是针对某个时期优化的，未来不一定适用

### 我的建议（真心话）

```
1. 先 dry_run 至少 1-2 周，观察策略行为
2. 小仓位实盘，初始资金别超过总资金的 10%
3. 止损可以先调低到 -20%，适应了再考虑放宽
4. 监控系统资源，确保 VPS 不会卡
5. 记录交易日志，定期复盘
```

**记住**：策略再好，市场教做人时也不会打招呼。轻仓测试，活着最重要！🙏

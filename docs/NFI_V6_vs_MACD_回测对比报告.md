## 二、策略特征对比

### NFI V6 — 极度保守的"防御型"策略

| 维度 | 分析 |
|---|---|
| **交易频率** | 极低。6个月仅17笔交易，日均0.09笔。策略设置了极其严格的入场过滤条件，大部分时间处于观望状态 |
| **风控能力** | 优秀。6个月最大回撤仅5.69%，远低于市场的43.30%跌幅。在市场大跌时，不交易就是最好的风控 |
| **盈利能力** | 偏弱。胜率虽高(82.4%)，但盈利交易平均利润小，亏损交易止损不够及时（2笔止损贡献了-51.53 USDT亏损） |

| **最佳表现对** | XRP (+0.64%), ETH (+0.48%), LTC (+0.46%) — 这些是波动较大的币种，更易触发其条件 |

## 五、深度分析与建议

### 为什么两个策略在近期都亏损？

**市场环境**：2025年10月至2026年4月期间，加密市场整体下跌约43-46%。这是典型的熊市/回调期，两个策略都面临严峻考验。

### NFI V6 的"少即是多"哲学

NFI V6的核心设计思路是**宁缺毋滥**：
- 6个月仅17笔交易，说明其入场条件极其严格
- 82.4%的胜率说明入场筛选确实有效
- 5.69%的最大回撤远低于市场跌幅(-43.3%)，说明风控有效
- **但问题是**：盈利交易的利润太小（平均+0.81%），而亏损交易的止损太宽（平均-7.73%），盈亏比约1:9.5，严重倒挂

**改进建议**：
1. 缩小ATR止损的倍数，从当前级别收紧至-3%~-5%
2. 提高止盈目标，当前多数交易只吃到+0.3%~1%就离场，可以尝试加仓/追踪止盈
3. 可以考虑对BTC和SOL的入场条件更加严格（这两个对亏损最大）

### MACDStrategy_crossed 的"高频陷阱"

MACD策略的核心问题是**胜率虚高但盈亏比极差**：
- 82.1%的胜率看似不错，但盈利交易平均只赚+1.03%
- 亏损交易平均亏-17.2%（4笔-30%止损 + 31笔-6%信号退出加权平均）
- 盈亏比约1:17，远低于健康策略所需的1:1以上
- 6个月50%的最大回撤意味着资金腰斩，实盘中很难坚持

**改进建议**：
1. **收紧止损**：-30%太宽，建议改为-5%~-8%，截断亏损
2. **优化退出信号**：MACD死叉滞后严重，可改用更灵敏的指标（如EMA交叉、RSI背离）
3. **增加入场过滤**：加入趋势过滤器（如200日均线），只在上涨趋势中做多
4. **减少交易频率**：当前日均1笔太频繁，可增加CCI/ADX过滤条件

### 实盘使用建议

| 场景 | 推荐策略 | 理由 |
|---|---|---|
| 熊市/下跌趋势 | NFI V6 | 回撤控制远优于MACD，保守比激进好 |
| 震荡市 | MACD（需改进后） | MACD在震荡市有正收益潜力，但需收紧止损 |
| 牛市/上涨趋势 | 两者均可，MACD更优 | MACD趋势跟踪在牛市更有效 |
| 新手学习 | MACD | 代码简单（约100行），逻辑清晰，适合理解策略编写 |
| 实盘部署 | NFI V6（需改进） | 5.69%回撤可以接受，但需要解决盈亏比问题 |

### 两个策略都不建议直接实盘

坦率地说，在当前回测结果下：
- **NFI V6**：6个月-2.89%，回撤小但盈利能力不足，需要优化止盈/止损比例
- **MACD**：6个月-47.11%，回撤50%，实盘会被清盘

建议先用Hyperopt对两个策略进行参数优化，再进行回测验证后考虑实盘。

## 实用建议

### 1. 组合使用
不要只跑一个策略，推荐组合：
- **NFI**（主攻稳健）+ **BigZ04_TSL3**（主攻低回撤）+ **Obelisk_Ichimoku**（捕捉大趋势）

### 2. 时间周期
- 绝大多数策略为 **5分钟** 线设计
- **Ichimoku_v37** 是唯一 **4小时** 级别策略
- 使用时务必确认配置文件中的 `timeframe` 设置与策略一致

### 3. 止损设置
- **NFI** 和 **BigZ04_TSL3** 有复杂的内部 `custom_stoploss` 逻辑，不要在外部覆盖
- 其他策略建议根据回测结果设置合理的 `stoploss` 参数

### 4. 先回测再实盘
任何策略上线前务必用目标交易对做回测验证：
```bash
# 使用项目自带的Docker脚本回测
bash test-freqtrade.sh backtesting --strategy NostalgiaForInfinityNext_ChangeToTower_V6
```

## v3 双轨制改革说明

### v2→v3 变更动机

v2评分系统对465个策略评估后，仅11个(5%)达到C级以上，知名开源策略系列（NostalgiaForInfinity、BigZ、Elliot等）平均得分35-42分，远低于C级门槛55分。

**核心问题**：
1. **P维度阈值与期货市场不匹配**：30天期货ROI最高仅0.23%（年化2.76%），v2阈值无法区分策略优劣
2. **fast模式S/T维度上限过低**：S上限6/20，T上限8/15，限制了总分上限
3. **硬红线触发过严**：140个策略触发Sharpe<0硬上限

## 1. 概述与设计哲学

### 1.1 目标

从大量社区策略中筛选出可商用的量化交易策略，建立一套客观、可复现、可审计的评分体系，为策略上架提供决策依据。

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| **风控优先** | 亏损50%的策略永远不可商用，无论收益多高 |
| **验证优于估算** | fast模式分数为"初步"，full模式分数为"验证"，二者不可等同 |
| **分层准入** | 不同商用级别面向不同风险偏好用户，不是所有商用策略都一样 |
| **统计显著性** | 最低交易次数和时间段要求是评分有效的前提 |
| **实战校准** | 阈值必须基于实际30天期货回测数据校准，而非理论推演 |

### 1.3 v1→v2 变更动机

v1评分系统对465个策略评估后，0个策略满足商用资格。核心问题：

- **P(收益)维度失灵**: 30天期货ROI仅0.03%~0.23%，v1阈值(5%/15%/30%/60%)按年化设计，导致9/11策略P维度得相同分数13/30，无法区分
- **商用门槛过严**: 要求VecScore≥75 + MDD<30% + Sharpe≥0.8 + 交易≥8笔，四重AND条件与失灵的P维度叠加，无人可达

v2通过年化ROI换算+细分阈值修复P维度，同时引入三级商用分级(Tier 1/2/3)替代单一商用门槛。

## 2. 评分维度与权重（VecScore v2）

VecScore = P(收益,30%) + R(风控,25%) + S(稳定,20%) + T(可靠,15%) + E(效率,10%)

总分0~100，等于五维度实际得分之和。

### 2.1 P(收益)维度 — 年化ROI换算（满分30）

v2核心改动：将30天ROI×12换算为年化，再按细分阈值打分。

#### ROI子项（满分15）

| 年化ROI | v1得分 | v2得分 | 说明 |
|---------|--------|--------|------|
| < 0 | 0 | 0 | 亏损 |
| < 1% | — | 2 | v2新增：微利 |
| < 3% | — | 5 | v2新增：低收益 |
| < 5% | 3 | 8 | v1此档0.05=3分 |
| < 10% | — | 11 | v2新增：中等收益 |
| < 20% | — | 14 | v2新增：良好收益 |
| ≥ 20% | — | 15 | 优秀收益 |
| < 5%(年) | — | — | v1原:8分 |
| < 15%(年) | — | — | v1原:12分 |
| < 30%(年) | — | — | v1原:14分 |
| ≥ 60%(年) | — | — | v1原:15分 |

换算公式：`annual_roi = 30天ROI × 12`

#### Profit Factor子项（满分10）— 不变

| PF | 得分 |
|----|------|
| ≤ 1.0 | 0 |
| < 1.2 | 3 |
| < 1.5 | 6 |
| < 2.0 | 8 |
| ≥ 2.0 | 10 |

#### 平均单笔盈利子项（满分5）— 微调

| avg_profit | v1得分 | v2得分 |
|------------|--------|--------|
| ≤ 0 或 None | 0 | 0 |
| < 0.005 / < 0.003 | 1 | 1 |
| < 0.01 / < 0.008 | 3 | 3 |
| ≥ 0.01 / ≥ 0.008 | 5 | 5 |

#### v2 P维度实际效果

| 策略 | 30天ROI | 年化ROI | PF | v2_P | v1_P |
|------|---------|---------|-----|------|------|
| BigZ04HO | 0.16% | 1.9% | 4.11 | 15 | 13 |
| ichiV1 | 0.23% | 2.8% | 3.31 | 15 | 13 |
| Combined_NFIv7 | 0.03% | 0.4% | 4.08 | 12 | 13 |
| EMA520015_V17 | 0.11% | 1.3% | 1.52 | 11 | 11 |
| Diamond | 0.06% | 0.7% | 3.53 | 12 | 13 |

### 2.2 R(风控)维度（满分25）— 不变

| 子项 | 满分 | 规则 |
|------|------|------|
| 最大回撤 | 15 | <10%=15, <20%=10, <30%=7, <40%=3, <50%=0(触发红线), ≥50%=0+硬上限40 |
| Sharpe Ratio | 10 | ≥2.0=10, <2.0=9, <1.5=7, <1.0=5, <0.5=2, <0=0(触发红线+硬上限50) |

### 2.3 S(稳定)维度（满分20）— 不变

- **fast模式**: 单时段估算，满分上限12
- **full模式**: 多周期盈利数(10分) + 收益波动性(10分)

稳定性测试周期：
| 市场 | 时间范围 | 说明 |
|------|----------|------|
| 牛市 | 20241001-20241231 | 2024 Q4 BTC大涨 |
| 震荡 | 20240601-20240831 | 2024 Q2-Q3 横盘 |
| 熊市 | 20240101-20240331 | 2024 Q1 整体下修 |

### 2.4 T(可靠)维度（满分15）— 不变

- **fast模式**: 估算(Hyperopt有=6分，无=8分)
- **full模式**: Train/Test分离(10分) + 参数稳定性(5分，full模式暂固定3分)

WFA周期：Train=20250101-20250831(70%), Test=20250901-20251231(30%)

| test/train比 | 得分 |
|-------------|------|
| ≥ 0.7 | 10 (无明显过拟合) |
| ≥ 0.5 | 6 (轻度过拟合) |
| ≥ 0 (test盈利) | 3 (中度过拟合) |
| < 0 | 0 (严重过拟合) |

### 2.5 E(效率)维度（满分10）— 不变

| 子项 | 满分 | 规则 |
|------|------|------|
| 年化交易次数 | 5 | ≥300=5, ≥100=4, ≥30=2, <30=0 |
| 持仓时长 | 3 | 5m/15m/30m=3, 1h=2, 其余=1 |
| 资金利用率 | 2 | 固定1分(无精确数据) |

## 4. 商用分级体系

### Tier 1 — 旗舰（Flagship）

| 条件 | 阈值 |
|------|------|
| VecScore | ≥ 80 |
| 最大回撤 | < 15% |
| Sharpe Ratio | ≥ 1.5 |
| 30天交易次数 | ≥ 15 |
| WFA test_roi | ≥ 0 |
| 评估模式 | 必须full模式验证 |

**展示位置**: 首页推荐位，默认配置，新手友好

### Tier 2 — 专业（Professional）

| 条件 | 阈值 |
|------|------|
| VecScore | ≥ 65 |
| 最大回撤 | < 25% |
| Sharpe Ratio | ≥ 0.8 |
| 30天交易次数 | ≥ 8 |
| WFA | estimated或verified均可 |
| 评估模式 | fast模式可入，full模式更佳 |

**展示位置**: 进阶策略池，需展示风险提示标签

### Tier 3 — 实验（Experimental）

| 条件 | 阈值 |
|------|------|
| VecScore | ≥ 50 |
| 最大回撤 | < 40% |
| 30天交易次数 | ≥ 3 |
| 评估模式 | fast模式可接受 |

**展示位置**: 研究/实验专区，必须标注"实验性"标签

### 不合格 — 拒绝

不满足Tier 3任何条件的策略，不向用户展示。

## 5. 硬红线（Hard Red Lines）

硬红线是绝对淘汰条件，触发后无论总分多高都限制等级或淘汰。

| ID | 条件 | 效果 |
|----|------|------|
| HR-01 | MDD ≥ 50% | 强制VecScore上限40 |
| HR-02 | Sharpe < 0 | 强制VecScore上限50 |
| HR-03 | 30天交易 = 0 | 所有Tier拒绝 |
| HR-04 | 所有WFA测试期ROI为负 | Tier 1/2拒绝 |
| HR-05 | Train/Test比 < 0.3 且 test_roi < 0 | Tier 1/2拒绝（严重过拟合） |
| HR-06 | 入场逻辑含shift(0)未来视 | 所有Tier拒绝 |
| HR-07 | 胜率100%且交易<5 | 需人工审核，暂拒绝 |

---

## 6. 软红线（Soft Red Lines / 警告标签）

软红线不淘汰策略，但会在展示时附加警告标签，帮助用户理解风险。

| ID | 条件 | 标签 |
|----|------|------|
| SR-01 | MDD > 30% | ⚠️ 高回撤风险 |
| SR-02 | Sharpe < 0.8 | ⚠️ 低于目标Sharpe |
| SR-03 | 30天交易 < 8 | ⚠️ 低交易频率 |
| SR-04 | 仅2/3稳定性周期盈利 | ⚠️ 市场环境敏感 |
| SR-05 | Profit Factor < 1.5 | ⚠️ 利润因子偏低 |
| SR-06 | Train/Test ROI比 0.3~0.5 | ⚠️ 可能轻度过拟合 |
| SR-07 | 含Hyperopt参数 | ⚠️ 依赖参数优化 |
| SR-08 | 震荡期ROI为负 | ⚠️ 震荡市场风险 |

## 7. WFA与多周期稳定性要求

### 7.1 验证状态（Verified）

要求：
- 至少3个非重叠稳定性测试周期，至少2个周期盈利
- Train/Test分割测试，test_roi ≥ 0
- 必须使用full模式评估

当前周期配置：
- bull: 20241001-20241231
- sideways: 20240601-20240831
- bear: 20240101-20240331
- Train: 20250101-20250831
- Test: 20250901-20251231

### 7.2 估算状态（Estimated）

- 单时段(30天)结果
- S维度满分上限12/20
- T维度估算（有Hyperopt=6，无=8）
- 所有展示必须标注"估算"

### 7.3 状态与Tier对应

| Tier | 允许的评估状态 |
|------|---------------|
| Tier 1 | 仅Verified |
| Tier 2 | Verified 或 Estimated |
| Tier 3 | Estimated 即可 |

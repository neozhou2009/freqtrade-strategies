## 三、核心问题分析

### 3.1 为什么现货评分低于期货？

| 因素 | 影响 | 说明 |
|------|------|------|
| **交易频率低** | 严重 | 现货信号触发少，ROI绝对值难以累积 |
| **数据时间短** | 中等 | 30天数据不足以验证策略稳定性 |
| **市场环境** | 中等 | 近期市场可能不适合策略入场条件 |
| **参数未优化** | 轻微 | 策略可能需要针对现货参数调优 |

### 3.2 NostalgiaForInfinityX 为什么不入场？

查看策略代码发现：
- X 系列依赖多时间框架 BTC 信息 (5m/15m/1h/4h/1d)
- 可能需要更多BTC/USDT的informative pair数据
- 当前配置可能缺少BTC信息数据下载
